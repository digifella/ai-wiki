# Boltnew

[[concepts/boltnew|Boltnew]] is a workflow system designed to streamline the development of software agents using [[concepts/anthropic-ai|Claude AI]]. It automates the generation of product requirements documents (PRDs) and task manager files, reducing manual documentation overhead during the [[concepts/agent-development|agent development]] process.

## Functionality

The workflow integrates with [[concepts/claude-ai|Claude AI]] to process requirements and automatically produce structured documentation artifacts. Users can input initial specifications or project parameters, which the system uses to generate both comprehensive requirement documents and organized task lists suitable for project management platforms. This approach aims to bridge the gap between initial concept and actionable development tasks.

## Use Case

Boltnew is intended for developers and teams building AI-powered agents who need to maintain clear documentation and task tracking without manual transcription. By automating document generation, the workflow reduces the [[concepts/friction|friction]] between planning and implementation phases.
