# Command Line Tool

A [[concepts/command-line-interface|command-line]] tool is a [[concepts/software|software]] program operated through text-based [[concepts/commands|commands]] in a terminal or console interface rather than through a graphical [[concepts/user-interface|user interface]]. Command-line tools are widely used in [[concepts/coding|software development]], system administration, and data processing workflows because they offer efficiency, [[concepts/automation|automation]] [[concepts/capabilities|capabilities]], and access to advanced features that may not be exposed in graphical applications.

## FFmpeg

[[concepts/ffmpeg|FFmpeg]] is a comprehensive multimedia framework that provides command-line utilities for handling [[concepts/audio-modality|audio]] and video [[concepts/files|files]]. It supports [[concepts/encoding|encoding]], decoding, [[concepts/transcoding|transcoding]], streaming, and filtering across numerous formats and codecs. FFmpeg is commonly used for batch processing media files, converting between formats, extracting audio or video streams, adjusting quality settings, and automating multimedia workflows in production environments.

The primary FFmpeg [[concepts/command-line-interaction|command-line interface]] allows users to specify input files, apply filters and transformations, and define [[concepts/output|output]] [[concepts/parameters|parameters]] through structured command syntax. This approach enables precise [[concepts/power|control]] over [[concepts/media-processing|media processing]] and makes FFmpeg suitable for [[concepts/integration|integration]] into larger [[concepts/automations|automated systems]] and scripts.
