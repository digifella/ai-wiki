# Ebay

Ebay is a project focused on building an [[entities/ubuntu|Ubuntu]]-based [[concepts/media-server|media server]] designed to provide an alternative to commercial subscription services. The project aims to consolidate multiple paid [[concepts/movie-streaming|streaming platforms]] into a single, self-hosted [[concepts/solution|solution]], reducing ongoing monthly expenses for users.

## Technical Implementation

The project involves setting up Ubuntu as the operating system foundation for the media server. This approach allows users to host and manage their own media content locally, eliminating reliance on third-party subscription platforms and their associated fees.

## Cost Effectiveness

A key goal of the Ebay project is achieving this functionality at minimal financial investment. Documentation and guides suggest building a functional media server for under $100, making it an accessible option for users seeking to reduce their subscription service costs.
