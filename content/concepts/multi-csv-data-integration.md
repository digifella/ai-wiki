# Multi-CSV data integration

The process of aggregating, consolidating, and synchronizing data from multiple CSV [[concepts/files|files]] into a single unified dataset for analysis and Reporting.

## Key Techniques
- [[entities/excel]] `IMPORTCSV` function: Facilitates dynamic linking of multiple CSV files, allowing for automated [[concepts/data-management]] and instant updates when source files change.
- [[concepts/automation]]: Streamlining [[concepts/workflow|workflows]] by replacing manual data entry/importing with live connections to [[concepts/external-data|external data]] sources.
