## Kimi K3.1 weights OUT, open source computer use, SOTA image model, science model, Pika H3: AI NEWS
**Clip title:** Kimi K3.1 weights OUT, open source computer use, SOTA image model, science model, Pika H3: AI NEWS
**Author / channel:** Matthew Berman
**URL:** https://www.youtube.com/watch?v=-M62vWrZh54

### Summary
This video highlights several new AI model releases and updates. 

**Main Topics Covered:**
* **Kimi K3.1 Pro:** Moonshot released open-source weights for this 3-trillion-parameter multimodal model, excelling in coding, math, and general tasks, rivaling top models like OpenAI's o1-preview.
* **NorthCUA-Pro:** A 397B parameter computer-use model designed for executing tasks through graphical user interfaces, offering open weights and a custom harness.
* **P-H3-Image:** Developed by Pruna AI from the MiniMax-H3 video model, this image generation and editing model works 5x faster in 8 steps and is 7x smaller.
* **Sarvam-Prism:** An open-source decision-making model based on Sarvam-105B that returns probabilities for predefined answer sets.
* **Hydrogen-1.0:** An MIT-developed model for scientific discovery, excelling in chemistry, materials science, and biology simulations.
* **Perplexity Embed v2:** New open-weight vision-language embedding models for efficient text and image retrieval.
* **Qwen3.5-4B-GLB-3D-Coder:** A compact 4B parameter model for generating 3D scenes and assets in HTML/JavaScript with GLB export.
* **Pika H3 Flex:** A fast text-to-video model with exportable audio stems and resolutions up to 4K, built on MiniMax-H3.
* **Apriel Voice 27B:** An open-weight voice AI model from ServiceNow handling voice, text, and multimodal interactions.
* **DiffuSpace Clover:** A 35B parameter diffusion model designed for fast reasoning tasks.
* **Unlimited OCR 2:** A Baidu Research model capable of parsing extremely long documents without page limits.
* **GPT-6.1 Terra:** An OpenAI model offering high capability and speed at 50% lower API prices compared to previous versions.

**Conclusion/Takeaways:**
The video showcases a rapid pace of open-source AI model development, with significant improvements in model efficiency, multimodal capabilities, and specialized applications across video, coding, scientific research, and decision-making.
