# 2048

2048 is a popular sliding block puzzle game where the [[concepts/purpose|objective]] is to combine numbered tiles to create a tile with the value 2048. The game is played on a 4×4 grid, with tiles that can be swiped in four directions (up, down, left, right). When two tiles with the same number touch, they merge into a single tile with their combined value. After each move, a new tile (either 2 or 4) appears randomly on the board.

## Gameplay Mechanics

The game continues until no more moves are possible, which occurs when the grid is full and no adjacent tiles have matching values. Players can win by reaching the 2048 tile, though the game allows continued play beyond this goal. The game requires strategy and planning, as careless moves can quickly lead to an unwinnable position.

## Origins and Popularity

2048 was created by Gabriele Cirulli in 2014 as a web-based game. It became a viral phenomenon due to its simple yet challenging mechanics, leading to numerous implementations across different platforms including mobile [[concepts/apps|apps]] and desktop versions. The game's straightforward rules combined with genuine [[concepts/strategic-depth|strategic depth]] made it widely appealing to both casual and dedicated puzzle game players.
