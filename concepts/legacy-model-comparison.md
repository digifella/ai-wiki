# Model Comparison

## Deep Research Implementation Comparison
Comparison between previous [[concepts/visualization-generation|Deep Research]] implementation and current [[entities/chatgpt-deep-research|ChatGPT Deep Research]] model.

### Key Differences

- **Legacy [[entities/deep-research|Deep Research]]**:
  - Limited source control (default [[entities/tomasz-janowski|academic]] databases only)
  - No [[concepts/third-party-app-integration|third-party app integration]]
  - Basic citation generation

- **Current [[concepts/research-control|ChatGPT Deep Research]]** (2026-04-14 update):
  - Granular [[concepts/source-granularity|source selection control]] (e.g., Academic Journals, Industry Reports)
  - Direct integration with third-party tools (e.g., Zotero, Mendeley)
  - Enhanced cross-referencing capabilities
  - Significantly more powerful than legacy model
