# Taskmanagermd

Taskmanagermd is a [[concepts/markdown|markdown]]-based task management system designed to coordinate work between multiple AI [[concepts/subagents|subagents]]. The system is generated from product requirements documents (PRDs) using [[concepts/claude-ai|Claude]], translating formal specifications into structured task lists that guide autonomous [[concepts/agents|agents]] through [[concepts/complex-workflows|complex workflows]].

## Purpose and Function

The primary function of taskmanagermd is to serve as a bridge between high-level product requirements and distributed task execution. Rather than requiring manual [[concepts/task-decomposition|task decomposition]], the system automatically parses [[concepts/prd|PRD]] content to extract actionable items, dependencies, and success criteria. This [[concepts/output|output]] is then rendered as markdown [[concepts/files|files]] that individual agents can consume and execute.

## Implementation

Taskmanagermd tasks are structured in markdown format to ensure compatibility with both human review and machine parsing. The system maintains clarity around task scope, prerequisites, and completion metrics, enabling subagents to work in parallel where dependencies allow. The markdown format also facilitates version [[concepts/power|control]] and transparent task tracking throughout project execution.
