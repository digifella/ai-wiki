# People Masking

People Masking is an artificial intelligence-driven tool within Adobe Lightroom Classic designed to automate the selection of human subjects in photographs. By utilizing machine learning algorithms, the feature identifies individuals within an image and generates precise masks around them. This automation eliminates the need for manual pixel-by-pixel selection, allowing for rapid isolation of people from the background or other elements in the scene.

The functionality relies on single-click presets that streamline the workflow. Upon activation, the software analyzes the image data to detect facial features and body contours, creating a mask that can be refined if necessary. This capability enables photographers to apply targeted adjustments—such as changes to exposure, color balance, or clarity—specifically to the people in the photo without affecting the surrounding environment.

This tool is particularly useful for portraits and group shots where selective editing is required. It supports non-destructive editing by keeping the mask editable, allowing users to adjust the selection boundaries or invert the mask to affect the background instead. The feature integrates with Lightroom’s existing adjustment panels, ensuring that changes made to the masked area are applied consistently across the editing process.
