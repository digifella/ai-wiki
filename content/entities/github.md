# GitHub

Web-based hosting service for version [[concepts/power|control]] using [[entities/git|Git]], enabling collaborative [[concepts/software|software]] development. Hosts repositories, issue tracking, and [[concepts/cicd-pipelines|CI/CD pipelines]].

## GitHub Copilot

AI-powered [[concepts/code|code]] completion tool developed by GitHub (in $\[[concepts/text|text]]{collaboration}$ with [[entities/openai|OpenAI]]). Suggests code snippets in real-time within IDEs. Key characteristics:

- **Environment**: Integrated into IDEs ([[entities/vs-code|VS Code]], JetBrains, etc.)
- **Core Strengths**: Context-aware code suggestions, supports multiple languages
