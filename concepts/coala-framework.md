# CoALA Framework

The **CoALA Framework** (Contextual-Organizational-Associative-[[concepts/learning|Learning]] Architecture) is a conceptual model for structuring [[concepts/ai-agent-memory|AI agent memory]], drawing parallels to human [[concepts/human-cognition|cognitive processes]]. It categorizes [[concepts/memory|memory]] into four distinct types to enhance an agent's ability to retain context, [[concepts/recall|recall]] [[concepts/factual-knowledge|facts]], apply [[concepts/skills|skills]], and learn from interactions.

## Core Memory Types

Based on the overview provided by [[lab-notes/2026-05-27-AI-Agent-Memory-Types-CoALA-Framework-Overview|AI Agent Memory Types: CoALA Framework Overview]] ([[entities/ibm-technology|IBM Technology]], [[entities/martin-keen|Martin Keen]]), the framework defines the following memory layers:

*   **Short-term/Working Memory**: Handles [[concepts/short-term-memory|immediate context]] and current [[concepts/workflow-automation|task execution]], analogous to human short-term [[concepts/retrieving|recall]].
*   **Semantic/Factual Memory**: Stores static, verifiable knowledge and facts, enabling the agent to access foundational information without re-computation.
*   **Procedural/Skill Memory**: Encodes learned behaviors, skills, and operational routines, allowing the agent to perform [[concepts/complex-tasks|complex tasks]] through practiced patterns.
*   **Episodic/Experience Memory**: Retains specific instances of past interactions and outcomes, facilitating learning from history and personalized adaptation.

## Key Insights

*   **Human Analogy**: The framework leverages the biological model of human memory to structure [[concepts/machine-learning-systems|machine learning systems]] for greater coherence and [[concepts/resilience|adaptability]].
*   **Holistic Integration**: Effective [[concepts/agentic-ai|AI agents]] require all four memory types to function seamlessly; [[concepts/disconnection|isolation]] of any type leads to fragmented performance.
*   **[[concepts/contextual-learning|Dynamic Learning]]**: The interplay between episodic and procedural memory allows agents to refine skills based on specific past experiences.
