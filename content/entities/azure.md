# Azure

Azure is Microsoft's [[concepts/cloud-computing|cloud computing]] platform that provides a range of services for building, deploying, and managing [[concepts/software|applications]] and data. Within the context of [[concepts/ai-development|AI development]], Azure offers tools and infrastructure for implementing advanced AI architectures and [[concepts/machine-learning|machine learning]] workflows.

## Azure AI and Retrieval-Augmented Generation

Azure AI is used in conjunction with Foundry to support [[concepts/answer-generation|retrieval-augmented generation]] (RAG) systems. RAG combines [[concepts/knowledge-bases|information retrieval]] with [[concepts/generative-ai-models|generative AI models]], allowing systems to access and incorporate [[concepts/external-data|external data]] sources when generating responses. This integration enables more grounded and contextual [[concepts/ai-powered-applications|AI applications]] built on Azure's cloud infrastructure.

## Agentic RAG on Azure

Microsoft Azure supports the development of [[concepts/agentic-rag-systems|agentic RAG systems]], which extend basic RAG by incorporating autonomous [[concepts/agent-capabilities|agent capabilities]]. These agents can make decisions, plan actions, and iterate on retrieval and generation tasks. [[concepts/educational-resources|Educational resources]] on implementing these systems are available through the [[concepts/azure-innovation-station|Azure Innovation Station]] channel, demonstrating practical approaches to building AI agents within the Azure ecosystem.
