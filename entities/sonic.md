# Sonic

[[concepts/nvidia-sonic|NVIDIA Sonic]] is an [[concepts/ai-technologies|artificial intelligence]] system developed for teleoperation control of [[concepts/humanoid-robots|humanoid robots]]. The system is designed to enable operators to control robots remotely with nuanced, precise movements and actions rather than relying solely on autonomous [[concepts/decision-making|decision-making]] or high-level [[concepts/commands|commands]].

## Technical Approach

Sonic operates as a [[concepts/neural-network|neural network]]-based control interface that translates human operator input into detailed robot commands. The system processes teleoperation signals and converts them into motor control [[concepts/instructions|instructions]] appropriate for humanoid robot platforms, maintaining fine-grained control while managing the latency and [[concepts/network-speed|bandwidth]] challenges inherent in remote robot operation.

## Application Context

The development of Sonic reflects [[entities/nvidia|NVIDIA]]'s broader focus on [[concepts/robotics|robotic systems]] and [[concepts/ai-driven-automation|AI-driven automation]]. Teleoperation control systems like Sonic serve [[concepts/scenarios|use cases]] where direct human oversight is valuable, such as in hazardous environments, complex manipulation tasks, or scenarios where [[concepts/autonomous-operation|autonomous operation]] remains technically limited. The system represents an approach to bridging human [[concepts/expertise|expertise]] and robotic capability through real-time control interfaces.
