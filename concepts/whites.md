[[entities/adobe-camera-raw|Adobe Camera Raw]] (ACR) is a core photo processing [[concepts/engine|engine]] developed by [[entities/adobe|Adobe]] Systems. It serves as the foundational development module for handling RAW image formats within [[entities/adobe-lightroom|Adobe Lightroom]] and as a filter plugin in [[entities/adobe-photoshop|Adobe Photoshop]]. ACR enables [[concepts/non-destructive-editing|non-destructive editing]], allowing photographers to adjust [[concepts/exposure|exposure]], color correction, tonal range, and [[concepts/sharpness|sharpness]] before committing changes to the final [[concepts/digital-images|pixel data]].

## Core Functionality & Integration

ACR acts as the bridge between raw sensor data and standard image formats. Key capabilities include:
- **[[concepts/non-linear-editing|Non-Destructive Editing]]:** [[concepts/adjustments|Adjustments]] are stored as [[concepts/metadata|metadata]] or sidecar files, preserving original image [[concepts/integrity|integrity]].
- **AI-Driven [[concepts/layer-masks|Masking]]:** Utilizes [[concepts/machine-learning|machine learning]] for [[concepts/subject-masking|subject selection]], [[concepts/depth-mapping|depth range masking]], and [[concepts/sky-detection|sky detection]] to isolate specific areas for targeted adjustments.
- **Advanced [[concepts/gradient-tools|Gradient Tools]]:** Includes linear, radial, and brush-based gradients for precise [[concepts/local-control|local control]] over exposure, [[concepts/contrast|contrast]], and color.
