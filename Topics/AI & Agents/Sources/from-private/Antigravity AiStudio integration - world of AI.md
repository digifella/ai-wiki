# [[entities/google-ai-studio|Google AI Studio]] Update: Powered by Antigravity

Google AI Studio has undergone its most significant infrastructure upgrade to date, transitioning from a simple model playground into a dynamic, agent-powered environment for building full-stack applications. This transformation is driven by **Antigravity**, Google's new agentic IDE framework.

## Key Highlights and New Features

* **Agentic Development:** Powered by Antigravity, AI agents can now help users build entire applications, manage [[concepts/code|code]], and handle automations rather than just providing text responses.
* **New "Build" ([[entities/agent|Agent]]) Mode:** A dedicated environment for developing production-ready applications directly within the platform.
* **Full-Stack Capabilities:** Users can now build applications with features like:
	* **Multiplayer Collaboration:** Real-time, multi-user project development.
	* **Professional UI Tools:** [[concepts/integration|Integration]] with Lucide [[entities/react|React]] and Framer Motion for polished, high-quality designs.
	* **Real-World Integrations:** Built-in support for connecting to databases and services like [[entities/slack|Slack]], Twilio, and [[entities/github|GitHub]].
* **Expanded Framework Support:** Developers can choose from popular frameworks including **React**, **Next.js**, and **Angular**, with **XR Blocks** support coming soon.
* **Firebase Integration:** A new authentication layer and live data syncing are being integrated via Firebase, allowing for more [[concepts/secure|secure]] and dynamic app development.
* **Advanced Project Management:** The studio now includes tools for:
	* **App Versioning:** Accessing and restoring previous versions of a project.
	* **Secrets Management:** Securely storing [[concepts/api-keys|API keys]] and other sensitive data.
	* **Direct Publishing:** The ability to publish applications directly to cloud projects.

## Enhanced [[concepts/workflow|Workflow]] and Model Access

* **[[concepts/system-instructions|System Instructions]]:** Users can provide highly specific, detailed instructions to guide the AI agents in their [[concepts/coding|coding]] and [[concepts/design|design]] tasks.
* **[[entities/gemini-31-pro|Gemini 3.1 Pro]]:** The update highlights the capabilities of the latest models, including the Gemini 3.1 Pro preview, for handling complex coding and creative requests.
* **Improved UI:** The overall interface of Google AI Studio has been streamlined for a better user experience across the playground and build modes.

## Real-World Applications

The video demonstrates the studio's power through several built-in examples, including:

* A functional car racing video game.
* A multiplayer neon-style laser tag game.
* A complete, high-quality e-commerce landing page.
* An SVG image generation tool.

These features are currently being rolled out gradually to all Google AI Studio users.
