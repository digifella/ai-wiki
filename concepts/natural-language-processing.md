# Natural Language Processing (NLP)

[[concepts/nlp|Natural language processing]] is a branch of [[concepts/ai-technologies|artificial intelligence]] that focuses on enabling computers to understand, interpret and generate human language. It involves the development of [[concepts/algorithms|algorithms]] and models to process natural [[concepts/language-data|language data]] for tasks such as [[concepts/sentiment-analysis|sentiment analysis]], machine translation, text [[concepts/summarization|summarization]], and [[concepts/fact-based-queries|question answering]].
