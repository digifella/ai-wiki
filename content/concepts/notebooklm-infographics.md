# Notebooklm Infographics

[[concepts/notebooklm|NotebookLM]] Infographics is a [[concepts/workflow|workflow]] that converts [[concepts/infographic|infographic]] outputs generated by [[concepts/ai-integrated-notebooks|NotebookLM]] into [[concepts/interactive-html-web-applications|interactive web applications]]. NotebookLM, [[concepts/google-search|Google]]'s AI-powered [[concepts/notebook|notebook]] tool, can produce visual [[concepts/infographic-design|infographics]] from source materials and [[concepts/notes|notes]]. This workflow extends that capability by using [[entities/gemini-models|Gemini AI]] to transform static infographic designs into functional, interactive web-based experiences.

## Workflow Process

The typical workflow involves extracting infographic designs from NotebookLM, analyzing their visual [[concepts/structure|structure]] and content [[concepts/hierarchy|hierarchy]] using [[entities/gemini-ai|Gemini AI]], and then generating [[concepts/code|code]] to recreate and enhance them as interactive [[concepts/web-applications|web applications]]. This approach preserves the original [[concepts/design|design]] intent while adding functionality such as [[concepts/hover-states|hover states]], dynamic data visualization, responsive layouts, and user interactivity that static infographics cannot provide.

## Application

This workflow is useful for content creators, educators, and organizations that need to convert research summaries or educational materials into engaging digital experiences. Rather than manually rebuilding infographics from scratch, the workflow leverages AI to automate the translation from [[concepts/aesthetic-design|visual design]] to interactive [[concepts/adoption|implementation]], reducing production time and maintaining visual [[concepts/logical-consistency|consistency]] between the original and digital versions.
