Fahd Mirza

Fahd Mirza is an AI educator and content creator specializing in local large language model (LLM) deployment, fine-tuning, and inference optimization. His work focuses on making advanced AI capabilities accessible through open-source tools like llamacpp, unsloth, and Ollama, with a strong emphasis on privacy, efficiency, and agentic workflows.

Recent Content & Tutorials (2026)

  • Agentic Note Management: Demonstrated the integration of hermes-agent with Obsidian and Ollama to create a private, hands-free knowledge management system Local AI-Powered Note Management: Hermes Agent, Obsidian, Ollama Integration.
  • Inference Acceleration: Guides on TurboQuant and DFlash speculative inference; advanced stacked speculative decoding (MTP + Ngram) in llamacpp for Qwen3.6.
  • Model Deployment & Quantization: Local deployment of MiniMax-M2.7 via llamacpp quantization; introduction to llamacpp’s Router Mode for native hot-swappable local LLM switching.
  • Specialized Models:
    • Review of MiniCPM-1B for efficient on-device hybrid reasoning.
    • Analysis of NVIDIA’s Audex-2B unified audio-text model (Nemotron family).
    • DwarfStar for native DeepSeek V4 Flash inference.
  • Multimodal & Generation: Introduction to Bonsai Image for local 1-bit image generation; video LLM techniques.
  • RAG & Data Processing:
    • EdgeQuake framework: high-performance local Rust Graph-RAG system using Ollama.
    • Review of Lift by Datalab for schema-constrained local structured data extraction.
    • Tutorials on PDF processing, document parsing, and OCR.
  • Fine-Tuning: Tutorials on fine-tuning models like Gemma-4 E2B using custom datasets and unsloth.
