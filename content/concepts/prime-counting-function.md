# Prime-counting Function (π(n))

The **prime-counting function** or π(n) is a mathematical function that counts the number of [[concepts/prime-numbers|prime numbers]] less than or equal to a given real number n. It plays a fundamental role in [[concepts/number-theory|number theory]], particularly in understanding the [[concepts/distribution|distribution]] of prime numbers.

### Related Concepts
- Prime Number
- [[concepts/riemann-hypothesis]]
- [[concepts/distribution|Distribution]] of [[concepts/prime-numbers|Prime Numbers]]

### Key Properties
- **Definition**: π(n) is defined as the number of primes not exceeding n.
- **Asymptotic Behavior**: The [[concepts/prime-number-theorem|prime number theorem]] gives an approximation for π(n), stating that π(n) ~ n / ln(n).
