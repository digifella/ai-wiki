# Privacy Controls

Privacy Controls in Claude Code refer to the configuration options that govern how user workflows, code artifacts, outputs, and personal data are processed and stored. These settings allow developers and organizations to enforce privacy practices that align with internal security policies and external regulatory requirements. By providing granular control over data handling, these controls form a foundational element of the platform's security posture, ensuring users maintain authority over sensitive information throughout the development lifecycle.

The configuration scope encompasses several key areas, including data retention policies, logging verbosity, and the handling of temporary files. Users can adjust these parameters to determine the duration for which interaction history is kept, the level of detail recorded in system logs, and the management of intermediate data generated during code execution. This flexibility enables teams to balance operational visibility with strict data minimization principles.

Additionally, these controls facilitate compliance with enterprise governance standards by allowing administrators to restrict the transmission of specific data types to external services. This ensures that proprietary code and confidential project details remain within designated boundaries, reducing the risk of unauthorized exposure. The implementation of these controls supports a secure development environment where privacy is integrated into the tooling rather than treated as an afterthought.
