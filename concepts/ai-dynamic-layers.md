# AI Dynamic Layers

**AI Dynamic Layers** refers to a feature set in [[concepts/adobe-photoshop|Photoshop]] Beta that enables non-destructive, AI-driven layer management and enhanced visual comparison workflows. This concept is central to the recent updates highlighted in the PhotoshopCAFE tutorial series.

## Key Features

*   **[[concepts/non-destructive-workflow|Non-Destructive Workflow]]:** Maintains editability of AI-generated elements without flattening the image.
