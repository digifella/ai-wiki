# GPU Parallel Computing

**[[concepts/llms|Definition]]**: GPU parallel computing refers to leveraging [[concepts/graphics-processing-units-gpus|Graphics Processing Units (GPUs)]] for non-graphics tasks such as scientific simulations, [[concepts/machine-learning|machine learning]], and [[concepts/training-process|AI training]] due to their ability to handle multiple calculations simultaneously.

## Key Concepts
- **[[concepts/cuda|CUDA]] ([[concepts/compute|Compute]] Unified Device [[concepts/architecture|Architecture]])**: Developed by Nvidia, CUDA enables GPUs to perform general-[[concepts/purpose|purpose]] computing tasks beyond graphics rendering.
