# Computer Use

Computer Use refers to AI systems designed to interact with computers through direct interface manipulation, combining [[concepts/visual-perception|visual perception]] and programmatic action. Rather than relying solely on APIs or code execution, these systems can perceive screen content, identify UI elements, and execute [[concepts/commands|commands]] to accomplish tasks across [[concepts/software|applications]]—functioning as an [[concepts/ai-agent|autonomous agent]] that operates computers similarly to how humans do.

## Development and Applications

The capability emerged as a natural evolution in [[concepts/ai-development|AI development]], with systems like those from [[entities/anthropic-institute|Anthropic]] and [[entities/openai|OpenAI]] extending beyond text and code generation. Computer Use systems can perform [[concepts/coding|software development]] tasks, automate workflows, and navigate complex applications by understanding visual context and responding to on-screen information. This approach bridges the gap between [[concepts/specialized-tools|specialized tools]] and generalist AI by enabling interaction with [[concepts/vintage-computing|legacy systems]] and graphical interfaces that lack API access.

## Integration with Development Tools

OpenAI's Codex and related systems have evolved toward unified platforms that combine computer perception with code generation and execution. These integrated environments allow developers to [[concepts/leverage-ai|leverage AI]] for everything from [[concepts/writing|writing]] and [[concepts/testing|testing]] code to managing [[concepts/development-workflows|development workflows]] and documentation. The convergence of multiple capabilities—[[concepts/visual-understanding|visual understanding]], [[concepts/reasoning|reasoning]], code synthesis, and action execution—creates more capable development assistants.
