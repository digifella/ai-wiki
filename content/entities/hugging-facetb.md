# Hugging FaceTB

An [[concepts/organization|organization]]/division of [[entities/hugging-face]] focused on developing efficient, small-scale language [[concepts/models|models]].

## Notable Models
- [[concepts/3-billion-parameter-model|SmolLM3-3B]]
    - Part of the [[concepts/smollm-family|SmolLM family]].
    - **Size:** 3 billion [[concepts/parameters|parameters]].
    - **[[concepts/reasoning|Reasoning]]:** Features an advanced "[[concepts/thinking-with-3-pro|thinking mode]]" that displays the model's [[concepts/reasoning-steps|reasoning process]] prior to generating a final [[concepts/solution|answer]].
    - **[[concepts/deployment|Deployment]]:** Can be served locally using [[entities/vllm|vLLM]] (as demonstrated by [[entities/fahd-mirza]]).
