# Microsoft Foundry

Enterprise platform for building and deploying [[concepts/ai-powered-applications|AI applications]] with deep [[concepts/integration|integration]] into [[entities/azure-ai|Azure AI]] ecosystem. Focuses on scalable, production-ready AI solutions using [[entities/microsoft|Microsoft]]'s cloud infrastructure.

## Core Capabilities
- **RAG System Development**: Enables [[concepts/traditional-rag|Retrieval-Augmented Generation]] pipelines for [[concepts/domain-specific-knowledge|domain-specific knowledge]]
- **[[entities/azure|Azure]] [[concepts/ai-integration|AI Integration]]**: Seamlessly connects with [[concepts/azure-ai]] services including Azure Cognitive Search and Azure [[entities/openai|OpenAI]] Service
- **Agentic [[concepts/workflow|Workflows]]**: Supports complex agent-based architectures for multi-step [[concepts/reasoning|reasoning]]

## Agentic RAG Implementation Guide
- **Prerequisites**: Active [[concepts/azure-subscription]]
- **Reference Material**: [Azure Innovation Station tutorial](https://www.youtube.com/watch?v=xXTuxKdzZrI)
- **Key Workflow**:
  ▪️ Ingest [[concepts/e-books|e-books]]/document repositories
  ▪️ Build vector indexes via Azure Cognitive Search
  ▪️ Deploy [[entities/agent|agent]] using [[concepts/azure-ai]] orchestration
  ▪️ Generate answers using domain-specific RAG (not general knowledge)
