# Layer Renaming

Layer renaming is a process in [[concepts/image-editing|image editing]] software where layers are named according to their contents or the [[concepts/creator|creator]]'s preference, aiding in organization and ease of use. The latest advancements include automatic renaming facilitated by AI.

### Key Points
- **Automation**: [[entities/adobe|Adobe]]'s [[concepts/ai-assistant|AI Assistant]] and [[concepts/generative-markup-tools|AI Markup tools]] (available on [[concepts/photoshop|Photoshop]] for the web and soon on desktop) enable automatic layer renaming based on image content, as demonstrated in [[entities/photoshopcafe|photoshopCAFE]]'s [[concepts/tutorial|tutorial]] showing layers named for immediate recognition (e.g., "Tree", "Sky").
- **Workflows**: Streamlined editing processes due to intelligent layer organization and labeling.
- **Integration**: Designed to work seamlessly with existing workflows, offering significant time-saving benefits.
