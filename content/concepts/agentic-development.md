# Agentic Development

A paradigm where AI [[concepts/agents|agents]] autonomously plan, execute, and refine [[concepts/complex-workflows|complex workflows]] to build [[concepts/software|applications]] without explicit step-by-step programming.

## Key Features
- **Agent-Powered IDE**: [[entities/google-ai-studio]] now uses Antigravity as its agentic framework, enabling [[concepts/agents|agents]] to build [[concepts/full-stack-applications|full-stack applications]] end-to-end ([[concepts/code-generation|code generation]], [[concepts/testing|testing]], [[concepts/deployment|deployment]]).
- **Dynamic Application Building**: Agents collaborate to iterate on solutions based on high-level user prompts, moving beyond static model playgrounds.
- **[[concepts/infrastructure-upgrade|Infrastructure Upgrade]]**: Google [[entities/ai-studio|AI Studio]]'s transition to agent-driven development represents its most significant infrastructure update.
- **Antigravity Framework**: [[concepts/google-search|Google]]'s new [[concepts/code-management|agentic IDE framework]] driving the transformation of [[entities/google-ai|Google AI]] Studio into a dynamic, [[concepts/agent-powered-environment|agent-powered environment]].
