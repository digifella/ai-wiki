# Lr Lightroom

Lr is a camera application developed by Adobe for [[entities/iphone|iPhone]] devices, currently in beta. The app is designed specifically for [[entities/iphone-13-pro|iPhone 13 Pro]] and later models, leveraging the advanced camera [[concepts/hardware|hardware]] available in these devices.

## Features

The application offers several computational photography capabilities. These include advanced zoom functionality, enhanced night mode for low-light photography, and a [[concepts/reflection-removal|reflection removal]] tool designed to eliminate unwanted reflections from [[entities/windows|windows]] and glasses. The app integrates with Adobe's Lightroom ecosystem, allowing users to capture and process [[concepts/images|images]] within a unified workflow.

## Development Status

As a beta product, Lr has undergone refinement following initial releases. Early versions experienced thermal management issues that caused device overheating; subsequent updates addressed these performance concerns. The app represents Adobe's effort to extend Lightroom's functionality from post-processing [[concepts/software|software]] into the image capture stage itself.
