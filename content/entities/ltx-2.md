# LTX-2

An [[concepts/open-source|open-source]] and [[concepts/open-weight|open-weights]] [[entities/sora|Video Generation model]] designed for [[concepts/local-execution|local execution]].

## Deployment & Features
- Can be deployed on local [[concepts/hardware|hardware]] using pinokoli to facilitate [[concepts/local-ai|Local AI]] [[concepts/deployment|Deployment]].
- **Key Advantages:**
	- **[[concepts/privacy|Privacy]]:** Processing occurs entirely on the local machine.
	- **Cost-Efficiency:** No subscription fees required.
	- **No Limits:** Operates without usage-based restrictions.
	- **[[concepts/audio-integration|Audio Integration]]:** Supports generating video with [[concepts/synchronized-audio|synchronized audio]].
	- **Weight [[concepts/accessibility|Accessibility]]:** Available as an open-[[concepts/weights|weights]] model.
- **Related [[concepts/models|Models]]:** [[entities/wan|Wan]].

## System Requirements
- High-intensity computational demand.
- Requires a dedicated GPU.
- **[[concepts/low-vram-optimization|Low VRAM Optimization]]:** Capable of [[concepts/running|running]] on consumer-grade [[concepts/hardware|hardware]] with limited [[concepts/hardware|VRAM]].
