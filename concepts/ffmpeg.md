# FFmpeg

[[concepts/netflix|FFmpeg]] is a free and [[concepts/open-source|open-source]] [[concepts/command-line-interface|command-line]] tool and library for processing video, [[concepts/audio-modality|audio]], and multimedia files. It provides functionality for format conversion, stream extraction, filtering, [[concepts/transcoding|transcoding]], and [[concepts/metadata-manipulation|metadata manipulation]] across a wide range of codecs and container formats. The project is widely used in professional media production, broadcasting, [[concepts/streaming-services|streaming services]], and [[concepts/coding|software development]] for its comprehensive feature set and cross-platform availability.

## Core Components

The [[entities/ffmpeg|FFmpeg]] project comprises several key utilities. The [[concepts/command-line-tool|ffmpeg command-line]] tool handles the primary transcoding and processing operations. FFprobe analyzes and displays information about media files, including codec details and stream properties. FFplay provides basic media playback functionality. These components work together to enable complete media [[concepts/ai-driven-workflow-automation|workflow automation]] and integration into larger systems.

## Technical Capabilities

FFmpeg supports hundreds of [[concepts/audio|audio]] and [[concepts/video-codecs|video codecs]] including H.264, H.265, VP8, VP9, AV1, AAC, and FLAC, among others. It can read and write numerous container formats such as MP4, MKV, WebM, and HLS. The tool allows users to apply filters, adjust bitrates, change frame rates, extract streams, and manipulate file [[concepts/metadata|metadata]] through command-line arguments, making it adaptable to diverse [[concepts/media-processing|media processing]] requirements.

## Usage and Adoption

FFmpeg serves as a backend for many commercial and open-source applications, including [[concepts/movie-streaming|streaming platforms]], video editors, and media servers. Its flexibility and breadth of codec support make it a standard choice for systems requiring reliable media processing without [[concepts/licensing|licensing]] restrictions. The tool is maintained by an active community and regularly updated to support new codec standards and formats.
