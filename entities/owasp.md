# Owasp

OWASP (Open Worldwide Application Security Project) is a nonprofit organization dedicated to improving software security through education, tools, and community collaboration. Founded to address the growing need for secure software development practices, OWASP develops and maintains security guidance, standards, and best practices for software developers, security professionals, and organizations worldwide.

The organization is best known for publishing the OWASP Top 10, a regularly updated list of the most critical security risks in web applications. This publication serves as a foundational reference for identifying and mitigating common vulnerabilities. In recent years, OWASP has expanded its scope to address emerging technologies, including the publication of security guidance for AI Agentic Applications.

Through open-source projects and global chapters, OWASP facilitates knowledge sharing among practitioners. The organization operates on a volunteer-driven model, ensuring that its resources remain accessible and relevant to the evolving landscape of application security. Its work covers a broad spectrum of topics, from secure coding practices to supply chain security, aiming to provide practical solutions for complex security challenges.
