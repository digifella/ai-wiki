## Qwen 3.8 27B AI Coding Harness Evaluation: DeepSeek Harness Outperforms
**Clip title:** [[entities/qwen38-27b|Qwen3.8 27B]]: Same Model, Three Harnesses, One Clear Winner
**Author / channel:** James Layne
**URL:** https://www.youtube.com/watch?v=sSySOPGNdjw

### Summary
This video evaluates the performance of three AI coding harnesses—[[entities/pi-coding-agent|Pi Coding Agent]], [[concepts/web-tools|Hermes Agent]], and [[concepts/ai-agent|DeepSeek Harness]]—when used with the [[entities/qwen|Qwen]] 3.8 27B model. The presenter conducts two primary tests: generating a playable [[concepts/minecraft-clone|Minecraft clone]] and creating a sophisticated [[concepts/color-palette-generator|color palette generator]] website. The goal is to determine which harness provides the best results in terms of [[concepts/code-quality|code quality]], functionality, and efficiency for these complex coding tasks.

For the Minecraft clone test, both Pi Coding Agent and [[concepts/hermes-agent|Hermes Agent]] faced significant challenges. Pi Coding Agent required extensive back-and-forth prompting to correct numerous issues, such as missing textures, and while it eventually produced a somewhat playable Minecraft experience with basic elements like block breaking and hostile mobs, its crafting system remained non-functional. Hermes Agent performed even worse, needing many revisions to generate a game that still featured strange-looking animals, lacked proper block-breaking animations, and had an only partially working crafting table. Notably, for both these harnesses, the "low thinking level" of the AI model yielded better, albeit flawed, results compared to higher [[concepts/reasoning|reasoning]] levels, which often produced unusable or bizarre outputs.

[[concepts/ai-agent|DeepSeek Harness]], however, emerged as a clear leader in the Minecraft challenge. It managed to produce a remarkably complete and playable Minecraft clone with minimal revisions. This single-shot generation featured diverse biomes, mountains, functional crafting, correct block physics (like floating blocks), and appropriate mob behavior, including zombies and exploding creepers. Although minor issues like slow wood-block breaking and water not entirely filling were present, DeepSeek Harness delivered the most impressive and closest-to-spec Minecraft experience from a [[concepts/local-ai|local AI]] model.

In the second test, generating a color palette website, the results largely mirrored the Minecraft performance. Pi Coding Agent created a functional website with various palette generation modes and export options, but its visual design was considered decent yet not top-tier. Hermes Agent, despite taking the longest to process, also delivered a functional and visually appealing website with responsive features like dark/light mode toggling. DeepSeek Harness once again excelled, producing the most professional and aesthetically pleasing website among all, closely resembling a high-quality custom-built application with all requested functionalities. Overall, DeepSeek Harness demonstrated superior capability in both code generation and adhering to complex specifications, securing its position as the top-performing harness in this evaluation.
