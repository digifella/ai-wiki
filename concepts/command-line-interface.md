# Command-line interface

A text-based [[concepts/user-interface|user interface]] (TUI) used to interact with software, operating systems, and services by issuing specific [[concepts/commands|commands]] through a [[concepts/cli|shell]].

## Key Characteristics
- **Text-based I/O**: Communication occurs via typed [[concepts/instructions|instructions]] and text output.
- **Automation**: Highly efficient for scripting and automation workflows.
- **Direct Control**: Allows precise manipulation of operating [[concepts/computational-resources|system resources]] and file systems.

## AI-Powered CLI Agents
Recent developments have introduced agentic interfaces that leverage [[concepts/ai-coding|AI coding]] capabilities directly within the command line:
- [[concepts/claude-code|Claude Code]] (by [[entities/anthropic|Anthropic]]): An [[concepts/agentic-tool|agentic tool]] designed for automated [[concepts/coding|coding]] tasks.
- [[entities/github-copilot-agent|GitHub Copilot Agent]] (by [[entities/github|GitHub]] and [[entities/microsoft|Microsoft]]): An agentic interface for code assistance.
- [[concepts/openwiki|OpenWiki]] (by [[entities/langchain|LangChain]]): An [[concepts/open-source|open-source]] [[concepts/terminal-agent|CLI agent]] designed to simplify the generation and maintenance of documentation for codebases, specifically tailored for [[concepts/agentic-ai|AI agents]].
