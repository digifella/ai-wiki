# Bing Copilot

Bing [[concepts/copilot-chat|Copilot]] is an AI-powered [[concepts/conversational-interface|conversational interface]] developed by [[entities/microsoft|Microsoft]] that combines search [[concepts/capabilities|capabilities]] with [[concepts/large-language-model|large language model]] technology. It allows users to query information through Bing search while receiving [[concepts/responses|responses]] generated by an [[entities/ai-assistant|AI assistant]], creating a hybrid experience between traditional search and chat-based interaction.

## Features and Integration

The service integrates directly with Bing's search index, enabling the AI to reference current web results when formulating answers. This approach aims to provide more contextual and up-to-date [[concepts/responses|responses]] compared to standalone chatbots with static [[concepts/training-data|training data]]. Users can refine queries through natural conversation, and the interface maintains context across multiple exchanges within a [[concepts/session|session]].

## Relation to Search Evolution

Bing Copilot represents Microsoft's response to the shift toward [[concepts/generative-ai|generative AI]] in information discovery. The tool addresses how content creators and websites may need to adapt their strategies for visibility in [[concepts/ai-powered-search|AI-powered search]] interfaces, a concept sometimes referred to as [[concepts/ai-overviews|generative engine optimization]], as [[concepts/traditional-seo|traditional search engine optimization]] becomes less relevant in [[concepts/ai-chatbots|conversational AI]] contexts.
