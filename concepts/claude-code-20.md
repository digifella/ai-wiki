# Claude Code 20

[[entities/claude-code-20|Claude Code 2.0]] is an update to Anthropic's [[concepts/10x-developer-productivity|AI-assisted coding]] platform designed to expand automation capabilities for developers. This [[concepts/deployment|release]] focuses on enhancing control flow and integration, allowing for more complex and [[concepts/autonomous-workflows|autonomous workflows]] compared to previous iterations.

The update introduces support for loops and [[concepts/temporary-cron-jobs|scheduled tasks]], enabling the construction of multi-step workflows that can execute repeatedly or at specified times. These control flow enhancements allow developers to design automation [[concepts/scenarios|scenarios]] that extend beyond single-execution tasks, providing greater flexibility in managing development processes.

Additionally, the platform adds [[concepts/google-workspace-access|Google Workspace integration]], allowing developers to automate tasks involving Google services directly within the coding environment. This feature facilitates seamless interaction with [[concepts/external-tools|external tools]] and data sources, further streamlining the development workflow.
