# Ghost Text

Ghost Text is a feature or extension that enables real-time code suggestions and completions within a [[concepts/developer|developer]]'s code editor. The concept facilitates integration with [[concepts/ai-coding-assistance|AI-assisted coding]] tools, most commonly [[concepts/auto-completion-suggestions|GitHub Copilot]], to provide contextual suggestions as code is being written. This allows developers to accept, modify, or reject suggestions without interrupting their workflow.

## Usage in Development

When enabled, Ghost Text displays suggested code in a lighter or faded text style, indicating that the content is not yet committed to the file. Developers can navigate through suggestions, accept them with a keyboard shortcut, or continue typing to dismiss them. This approach reduces the [[concepts/friction|friction]] of looking up syntax or common patterns, as suggestions appear inline where the developer is already focused.

## Practical Applications

Ghost Text is particularly useful for repetitive [[concepts/coding|coding]] tasks, boilerplate generation, and [[concepts/learning|learning]] unfamiliar APIs or language conventions. It works across multiple programming languages and can adapt to the style and patterns present in the surrounding code. The effectiveness of suggestions depends on the quality of the underlying AI model and the clarity of context available to it.
