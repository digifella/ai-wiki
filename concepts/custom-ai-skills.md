# Custom AI Skills

Specialized, programmable [[concepts/plugins|extensions]] for LLMs that enable the execution of specific, repeatable tasks beyond standard [[concepts/text-generation|text generation]], facilitating autonomous [[concepts/agentic-patterns|agentic workflows]].

## Key Capabilities
- **Orchestration**: Coordinating multiple specialized [[concepts/skills|skills]] to manage complex, multi-step [[concepts/autonomous-workflows|autonomous processes]].
- **Design Systems Integration**: Leveraging skills to ensure all automated outputs adhere to standardized brand and visual frameworks.
- **Implementation via [[entities/claude-code]]**: Utilizing advanced [[concepts/coding|coding]] capabilities to build, [[concepts/deployment|deploy]], and manage custom-skill-based automation.

## Core Applications
- **Marketing Automation**: Developing end-to-end [[concepts/automated-marketing-workflows|automated marketing workflows]], ranging from content generation to systematic deployment.
