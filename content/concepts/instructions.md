# Instructions

Instructions are formal directives or guidelines provided to [[concepts/agentic-ai|AI agents]] to shape their behavior, capabilities, and decision-making processes. In the context of [[concepts/anthropic-ai|Claude AI]], instructions define how the model should approach tasks, interact with users, and execute specific functions or [[concepts/skills|skills]]. They serve as the foundational layer for customizing agent behavior beyond the model's default [[concepts/training|training]].

## Purpose and Function

Instructions establish the scope and constraints within which an [[concepts/ai-agent|AI agent]] operates. They clarify objectives, specify output formats, define ethical boundaries, and outline procedural steps for handling particular types of requests. Well-crafted instructions reduce [[concepts/ambiguity|ambiguity]] and enable [[concepts/agents|agents]] to perform consistently across varied [[concepts/scenarios|scenarios]], making them essential for building reliable and predictable AI systems.

## Implementation with Claude

When working with Claude, instructions can be embedded in [[concepts/system-prompts|system prompts]], user messages, or through structured frameworks that define [[concepts/agent-harnesses|agent skills]]. These directives allow developers to create [[concepts/specialized-sub-agents|specialized agents]] for specific domains—whether content generation, data analysis, customer support, or technical [[concepts/problem-solving|problem-solving]]. The effectiveness of instructions depends on clarity, specificity, and alignment with the agent's actual capabilities and limitations.
