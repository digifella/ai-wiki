# Batch Processing In Lightroom

Batch processing in [[concepts/lightroom|Lightroom]] refers to the ability to apply edits, [[concepts/metadata|metadata]] changes, and organizational tasks to multiple photographs simultaneously rather than adjusting each image individually. This functionality is central to Lightroom's [[concepts/efficiency-principles|workflow efficiency]], particularly for photographers managing large image libraries from shoots or imports.

## Application Methods

Users can select multiple photos in the [[concepts/library-module|Library module]] and apply consistent [[concepts/adjustments|adjustments]] through the [[concepts/adobe-lightroom-develop-module|Develop module]] or use sync features to copy settings from one image to others. The Copy Settings function allows photographers to select a reference image, copy its adjustments, and paste them to a selection of other photos. Alternatively, the Sync button in the Develop module applies changes across all selected [[concepts/images|images]] in real time. This approach maintains [[concepts/logical-consistency|consistency]] across images shot under similar conditions while reducing the time required for post-processing.

## Practical Uses

Common batch processing tasks include applying copyright and keyword metadata to entire imports, adjusting [[concepts/exposure|exposure]] and color settings across photos from the same shoot, applying lens corrections, or adding consistent watermarks. Photographers can also batch apply [[concepts/flags|flags]], ratings, and [[concepts/color-labels|color labels]] for organizational purposes, streamlining the triage and cataloging of large photo collections.
