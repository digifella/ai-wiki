# Skill Format Standardization

### Summary
Skill format standardization in the context of [[concepts/large-language-models|Large Language Models (LLMs)]] and [[concepts/agentic-ai|AI agents]] represents a critical evolution towards unified, interoperable skill sets that facilitate seamless integration across various platforms. The concept involves defining a standardized [[concepts/structure|structure]] or file type for [[concepts/skills|skills]], enabling developers to create once and deploy anywhere within an ecosystem.

### Key Points
- **Evolution of Skills**: Since the initial launch by [[entities/anthropic|Anthropic]] in October 2025, the [[entities/notion|notion]] of "skills" has expanded beyond personal configurations.
- **[[concepts/agentic-ai|Agent-First Approach]]**: The new standard emphasizes an agent-centric perspective where skills are designed for modular and scalable use across multiple AI [[concepts/agentic-ai|agents]] rather than being specific to individual users or devices.
- **Interoperability & Portability**: Standardizing skill formats enhances interoperability, allowing skills developed in one environment to work effectively in another without significant modification.
