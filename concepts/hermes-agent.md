# Hermes Agent

**[[entities/hermes-agent|Hermes Agent]]** is an [[concepts/open-source-ai|open-source AI]] [[concepts/agentic-framework|agentic framework]] developed by [[entities/nous-research|Nous Research]]. It provides a robust environment for building and managing [[concepts/agentic-systems|autonomous agents]], with recent [[concepts/software-updates|updates]] focusing on enhanced automation capabilities.

## Key Features

*   **Agentic Framework**: Designed for [[concepts/complex-task-execution|complex task execution]] and autonomous [[concepts/decision-making|decision-making]].
*   **/loop Feature**: A new capability enabling [[concepts/automated-recurring-tasks|automated recurring tasks]], allowing agents to execute predefined workflows at specified intervals without manual intervention.
*   **[[concepts/open-source|Open Source]]**: Fully accessible for community contribution and [[concepts/customization|customization]].
