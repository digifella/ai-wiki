# Lightroom Classic

**[[concepts/lightroom|Lightroom]] Classic** is [[entities/adobe|Adobe]]'s desktop-based [[concepts/photo-management|photo management]] and editing application, part of the [[concepts/adobe|Adobe Creative Cloud]] suite. It is designed for photographers who require robust organizational tools alongside advanced editing capabilities.

## Key Features & Updates

*   **[[concepts/bidirectional-gradient|Bidirectional Gradient]] Support**: While [[entities/adobe-camera-raw]] recently introduced a new bidirectional [[concepts/gradient-tool|gradient tool]], Lightroom Classic users can replicate this specific effect using alternative [[concepts/layer-masks|masking]] techniques.
*   **Integration with ACR**: Lightroom Classic shares the same underlying [[concepts/engine|engine]] as [[entities/adobe-camera-raw]], allowing for consistent editing [[concepts/open-source-philosophy|logic]] across platforms, though specific UI features like the new bidirectional gradient may lag in deployment.
*   **Masking Capabilities**: Users can achieve complex gradient effects through the use of radial, linear, and brush masks, often requiring manual blending to mimic newer ACR features.
