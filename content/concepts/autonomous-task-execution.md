# Autonomous Task Execution

Systems that perform complex operations without human intervention, leveraging local processing for [[concepts/privacy|privacy]], [[concepts/software-reliability|reliability]], and continuous operation.

## Key Implementations

- [[entities/openclaw]]: [[concepts/local-ai-assistant|Local AI assistant]] (formerly [[concepts/local-ai-assistants|ClawdBot]]/MoltBot) [[concepts/running|running]] on [[entities/raspberry-pi|Raspberry Pi]], operating 24/7 to autonomously execute [[concepts/complex-tasks|complex tasks]] like [[concepts/monitoring-and-alerting|system monitoring]] and [[concepts/automation|automation]]—functioning as a personal "[[entities/jarvis|Jarvis]]" without cloud dependency.
- [[concepts/local-ai]]: Enables [[concepts/privacy|privacy]]-preserving task execution on-device (e.g., Raspberry Pi deployments).
- [[concepts/automation]]: Core capability of autonomous systems, including scheduled and event-triggered workflows.
- Raspberry Pi: Common [[concepts/hardware|hardware]] platform for resource-efficient autonomous task execution.
