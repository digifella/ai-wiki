# Apache 2.0 License

The [[concepts/apache-2-0|Apache License 2.0]] is a permissive [[concepts/open-source|open-source]] [[concepts/software|software]] [[concepts/license|license]] maintained by the Apache Software Foundation. First released in 2004, it has become one of the most widely adopted licenses in the open-source ecosystem, particularly in machine [[concepts/learning|learning]], data processing, and enterprise software projects. The license grants users broad freedoms while establishing clear legal conditions for software use, modification, and [[concepts/distribution|distribution]].

## Permissions and Obligations

Under [[concepts/apache-2.0|Apache 2.0]], users may use software for any [[concepts/motivation|purpose]], including commercial applications, modify the source code, and distribute copies or modified versions. In exchange, users must include a copy of the original license and notice file with any distribution, document any significant changes made to the code, and include a statement of which files were modified. The license also grants an explicit patent license from contributors, protecting users from patent claims related to their use of the software.

## Key Characteristics

Apache 2.0 is considered more legally detailed than some other permissive licenses. It explicitly addresses patent rights, which distinguishes it from licenses like MIT or BSD. The license does not require derivative works to use the same license (making it compatible with stricter licenses in some contexts), though modifications must be documented. Like other permissive licenses, Apache 2.0 provides no warranty and offers no liability protection to the original authors.
