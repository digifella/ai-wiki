## Nano Banana 2

**Summary:** [[concepts/camera-angle-control|Nano Banana 2]] is a model designed to enable precise control over AI-generated [[concepts/images|images]] through the use of JSON code within Google's [[entities/gemini|Gemini]] app. It aims to mitigate issues such as image distortion or "[[concepts/data-hallucination|hallucination]]" that often arise when attempting minor edits with traditional [[concepts/ai-models|AI models]].

### Key Points
- **[[concepts/json|JSON Control]] Hack:** Utilizing JSON (JavaScript Object Notation) in [[concepts/gemini|Gemini]] for fine-grained control over AI-generated images.
- **Model Version:** [[entities/gemini-3|Gemini 3]].1 Pro, which is specifically tailored to support the Nano Banana 2 model and its unique editing features.
