# Gemini Chat

**[[concepts/google-ai|Gemini]] Chat** is [[concepts/google-search|Google]]'s [[entities/chatgpt|conversational AI interface]], primarily characterized by its **reactive** nature, responding to user prompts rather than initiating actions. It serves as the foundational interaction layer for [[entities/google|Google]]'s [[entities/gemini]] models, distinct from proactive agents like [[concepts/gemini|Google Gemini]] Spark.

## Key Characteristics
- **Reactive Interface**: Operates on a request-response model, requiring explicit user input to generate outputs.
- **Integration**: Embedded within [[concepts/google-workspace|Google Workspace]] and web interfaces for seamless access to [[entities/gemini]] capabilities.
- **Differentiation**: Contrasts with [[concepts/ai-workflow|proactive AI]] agents that can autonomously execute tasks or initiate workflows without direct [[concepts/prompting|prompting]].
