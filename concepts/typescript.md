[[concepts/typescript-development|TypeScript]] is a statically typed superset of [[concepts/javascript|JavaScript]] developed and maintained by [[entities/microsoft|Microsoft]]. It adds features such as interfaces, enums, and type annotations to help developers build large-scale applications more effectively.

### Features
- **[[concepts/static-typing|Static Typing]]**: Provides better tooling support with type checking.
- **Interfaces & Enums**: Defines contract between objects and enables cleaner code.
- **Modules**: Supports module imports and exports for better organization.
- **Decorators**: Allows adding [[concepts/metadata|metadata]] to classes, methods, accessors, etc.

### Use Cases
[[concepts/typescript-programming|TypeScript]] is widely used in [[concepts/web-applications|web applications]] due to its robust type system and ability to transpile into vanilla JavaScript. It's particularly popular among frameworks like Angular and Next.js.
