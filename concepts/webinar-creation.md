# Webinar Creation

Webinar creation is a video production method that converts presentation slides into video content using a combination of AI-assisted tools. The workflow begins with [[concepts/ai-integrated-notebooks|NotebookLM]], which generates presentation slides from source material, then transitions to [[concepts/google-vids|Google Vids]] for video production. This integrated approach reduces manual steps in converting static presentations into dynamic video format.

## Workflow and Output

The process involves taking slides created by NotebookLM and importing them into Google Vids, which generates video content with narration and visual transitions. The resulting videos typically include Google's default watermark. To create unwatermarked output suitable for distribution or publication, the watermark must be removed through post-processing or export settings. This final step produces clean video files ready for use as webinar content, promotional material, or educational resources.
