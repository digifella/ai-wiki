# Proactive Task Management

**Proactive task management** is a workflow paradigm where [[concepts/ai-agents|AI agents]] anticipate user needs and execute actions before explicit commands are issued, shifting from reactive execution to anticipatory assistance.

## Core Principles
- **Anticipation:** Systems predict next steps based on context, history, and environmental cues.
- **Autonomy:** Agents operate with minimal human intervention, handling routine or [[concepts/complex-workflows|complex workflows]] independently.
- **Integration:** Seamless embedding within existing tools (e.g., [[concepts/chat-interfaces|chat interfaces]], code editors) to reduce context switching.

## Recent Developments (2026)
The landscape of proactive management has shifted significantly with the release of **OpenAI DevDay 2026** announcements, particularly focusing on personal agents and [[concepts/developer-apis|developer APIs]].

- **Dots Agent:** A flagship "always-on" personal agent introduced to integrate seamlessly within [[entities/chatgpt]] and [[entities/codex]]. It is designed to offer continuous, context-aware assistance rather than responding only to discrete prompts.
- **[[entities/gpt-61-sol|GPT-6.1 Sol]]:** New model capabilities supporting more robust reasoning and execution for complex, multi-step proactive tasks.
- **Developer APIs:** Enhanced APIs allow builders to create custom proactive workflows that interact with Dots and other OpenAI services, enabling deeper integration into personal and professional ecosystems.
- **Monetization & Strategy:** Refined strategies focus on empowering builders to create value-added proactive tools, moving beyond simple chat interfaces to active [[concepts/ai-driven-workflow-automation|workflow automation]].
