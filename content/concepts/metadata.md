## Metadata

Metadata refers to data that provides information about other data. In the context of [[concepts/machine-learning|machine learning]] [[concepts/models|models]] like [[entities/google]]'s [[concepts/gemini]], metadata plays a crucial role in managing and controlling various aspects of data interaction and model [[concepts/output|output]]. In digital photography, [[concepts/lightroom|Lightroom]] catalogs serve a similar structural [[concepts/purpose|purpose]].

### Key Points
- Structured format for detailed [[concepts/power|control]] over AI interactions.
- JSON (JavaScript Object Notation) is highlighted as an effective method for achieving total [[concepts/image-editing|image control]] and manipulating metadata within the [[entities/nano-banana|Gemini]] framework.
- [[concepts/lightroom|Lightroom catalogs]] function as a "cookbook," storing metadata and [[concepts/instructions|instructions]] without containing the actual photo [[concepts/files|files]].
- Managing metadata via catalogs is fundamental to a professional [[concepts/photography-workflow|photography workflow]].
