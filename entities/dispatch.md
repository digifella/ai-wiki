# Dispatch
## Overview
Dispatch is a feature introduced by [[entities/anthropic-institute|Anthropic]] as part of its [[entities/claude-cowork|Claude Cowork]] platform. It acts as a remote control for users to interact with [[entities/claude|Claude]] through their desktop environment via a mobile application.

### Key Features:
- [[concepts/persistent-memory|Persistent conversation]] capability.
- Task assignment and [[concepts/knowledge-bases|information retrieval]] from the user's [[concepts/personal-computer|desktop computer]].
