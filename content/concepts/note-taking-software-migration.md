# Note Taking Software Migration

Note taking software migration refers to the process of transferring notes, documents, and organizational structures from one platform to another. This typically occurs when users become dissatisfied with their current provider due to [[concepts/pricing|pricing]] changes, feature limitations, reduced functionality, or shifts in service focus. The migration process involves selecting a suitable alternative, exporting existing data, reformatting content as needed, and establishing new workflows on the destination platform.

## Motivations for Migration

Users commonly initiate migrations in response to significant platform changes. Pricing increases, modifications to free tier offerings, or alterations to core features can prompt users to evaluate alternatives. [[concepts/data-ownership|Data ownership]] concerns, [[concepts/privacy|privacy]] [[concepts/policy-changes|policy changes]], and discontinuation of features that users rely upon also drive migration decisions. The decision to migrate typically involves weighing the effort required against the perceived benefits of switching platforms.

## Migration Considerations

Successful migration requires careful planning and evaluation of alternative platforms. Users must assess whether a new platform offers compatible features, adequate [[entities/storage|storage]] capacity, suitable organizational structures, and reliable export capabilities. The technical process typically involves exporting data in standard formats when possible, manually reorganizing content if necessary, and [[concepts/testing|testing]] the new platform before fully committing. Different platforms vary significantly in their data import functionality and the extent to which they can preserve original formatting and [[concepts/structure|structure]].
