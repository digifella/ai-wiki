# Jarvis

Jarvis is a robotic claw project based on the [[concepts/automated-information-pipelines|OpenClaw]] platform, demonstrated and documented by [[entities/gary-explains|Gary Explains]] on [[entities/raspberry-pi|Raspberry Pi]]. The project showcases practical implementation of robotic manipulation using accessible single-board computer [[concepts/hardware|hardware]].

## Development and Implementation

The project utilizes OpenClaw, an [[concepts/open-source|open-source]] robotic claw design, integrated with Raspberry Pi hardware. This combination allows for relatively affordable experimentation with robotic control and [[concepts/automation|automation]], though OpenClaw components represent a significant cost component of the overall build.

## Documentation

The project has been featured in Gary Explains' educational content focused on Raspberry Pi [[concepts/software|applications]], serving as a practical demonstration of how the platform can be applied to [[concepts/robotics|robotics]] projects beyond [[concepts/classical-computing|traditional computing]] tasks.
