# Generative Fill

Generative Fill is a feature within [[entities/adobe-firefly|Adobe Firefly]] that enables users to modify [[concepts/images|images]] through natural [[concepts/natural-language-prompting|language prompts]]. Rather than relying solely on traditional editing tools, users can describe desired changes or additions to an image, and the system generates content to match the description. This approach bridges the gap between manual editing and AI-assisted image creation.

## Prompt-to-Edit Workflow

The [[concepts/layer-control|Prompt-to-Edit]] feature allows users to select areas of an image and provide [[concepts/text|text]] descriptions of what they want to generate in those spaces. The underlying generative model then produces content consistent with the surrounding image context and the user's textual input. This makes it possible to extend compositions, fill gaps, or modify specific elements without requiring manual drawing or selection techniques.

## Applications

Generative Fill serves designers and creators who need to quickly iterate on visual compositions, adjust image elements, or experiment with different variations. The feature is integrated into Adobe's broader creative [[concepts/software|software]] ecosystem, making it accessible within familiar [[concepts/design-workflows|design workflows]].
