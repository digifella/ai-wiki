# Dataset Repository

A centralized platform for [[concepts/storing|storing]], sharing, and [[concepts/version-numbers|versioning]] datasets, models, and code. These repositories serve as the backbone of the [[concepts/open-source|open-source AI]] ecosystem, facilitating reproducibility and collaboration.

## Key Platforms

*   **[[entities/hugging-face|Hugging Face]]**: The dominant hub for [[concepts/transformer-architectures|transformer models]] and datasets. It provides a [[concepts/unified-interface|unified interface]] for hosting dataset repository content alongside [[concepts/model-weights|model weights]] and [[concepts/ai-inference|inference]] code.
*   **Kaggle**: Primarily focused on data [[concepts/science|science]] competitions, it also hosts extensive datasets and [[concepts/notebook-tools|notebooks]].
*   **Zenodo**: A general-purpose repository often used for [[entities/tomasz-janowski|academic]] datasets with persistent identifiers (DOIs).

The landscape of dataset repositories is heavily influenced by major tech [[concepts/acquisitions|acquisitions]] and platform [[concepts/consolidation|consolidation]].
