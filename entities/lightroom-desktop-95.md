# Lightroom Desktop 9.5

**[[concepts/lightroom-desktop|Adobe Lightroom Classic]]** version 9.5 introduces significant workflow enhancements focusing on masking precision, file format flexibility, and generative AI capabilities.

## Key Updates

*   **[[concepts/mask-refinement|Mask Refinement]]:** Improved tools for refining selection masks, allowing for more precise control over localized adjustments.
*   **[[concepts/render-to-dng|Render to DNG]]:** New capability to render processed images directly into the DNG (Digital Negative) format, preserving all edit history in a standardized, archival-friendly container.
*   **[[concepts/crop-and-expand|Generative Expand]]:** Integration of AI-driven generative fill for expanding canvas boundaries, enabling seamless extension of image backgrounds or elements.
