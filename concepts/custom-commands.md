# Custom Commands

Custom commands are user-defined workflows that extend the functionality of [[concepts/terminal-based-ai-coding-agents|AI coding assistants]] such as [[concepts/ai-assisted-coding|Claude Code]] and [[concepts/cli-tool|Gemini CLI]]. They enable developers to create shortcuts and automation sequences tailored to specific projects and development practices. By combining AI assistance with custom logic, these commands enforce project conventions, integrate with existing tools, and reduce repetitive manual steps in the [[concepts/software-development-process|software development process]].

These commands typically function as wrappers around an [[concepts/ai-assistant|AI assistant]]'s core capabilities, allowing users to define specific prompts, context, and execution parameters. This structure ensures that the AI operates within predefined boundaries, maintaining [[concepts/logical-consistency|consistency]] across codebases and adhering to established [[entities/national-academies|engineering]] standards. The implementation often involves configuring files or settings that map specific command names to complex [[concepts/instruction-sets|instruction sets]] or multi-step processes.

[[concepts/scenarios|Use cases]] for custom commands include automating routine tasks such as code formatting, linting, and testing, as well as facilitating complex operations like scaffolding new components or generating documentation. They serve as a bridge between the flexibility of natural language interaction and the [[concepts/accuracy|precision]] required for structured [[concepts/software-engineering|software engineering]]. This approach allows teams to standardize workflows while retaining the [[concepts/resilience|adaptability]] of AI-driven assistance.
