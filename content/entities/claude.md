# Claude

[[concepts/claude-ai|Claude]] is an [[concepts/ai-assistant|AI assistant]] developed by [[entities/anthropic]]. Originally positioned as a standalone [[concepts/ai-chatbots|conversational AI]] tool, Claude is undergoing a [[concepts/strategic-pivot|strategic shift]] toward an agentic-strategy that emphasizes interconnected, integrated components rather than a single monolithic interface.

## Agentic Strategy

[[entities/anthropic-institute|Anthropic]] is transitioning Claude's [[concepts/design|design]] to support [[concepts/managed-agents|managed agents]] and domain-specific [[concepts/software|applications]]. This approach moves away from a general-[[concepts/motivation|purpose]] [[concepts/chat-application|chat interface]] toward a modular system where [[concepts/specialized-sub-agents|specialized agents]] can be deployed and integrated for specific tasks and [[concepts/scenarios|use cases]]. The strategy includes APIs for building and deploying [[concepts/agentic-systems|autonomous agents]] that can work together as part of larger systems.

Key developments include:
- **Managed [[concepts/agents|Agents]] [[concepts/api-suite|API Suite]]**: APIs for building and deploying autonomous agents.
- **Domain-Specific [[concepts/integration|Integration]]**: Tools like [[concepts/automated-redlining|Claude for Word]] for [[concepts/legal-document-review|legal document review]] and editing.
- **[[concepts/ai-assisted-coding|Claude Code]] Enhancements**: Recent updates focus on improving the [[concepts/developer|developer]] experience and increasing tool autonomy, allowing for more sophisticated [[concepts/coding|coding]] workflows.
