# Built In Skills Testing

Built In [[concepts/skills-testing|Skills Testing]] refers to the integrated testing [[concepts/capabilities|capabilities]] within [[concepts/claude-code-20|Claude Code 2.0]], Anthropic's [[concepts/ai-assisted-coding|AI-assisted coding]] platform. These testing features enable developers to validate code functionality directly within the [[concepts/coding-workspace|development environment]], reducing the need to switch between tools during the coding [[concepts/workflow|workflow]]. The testing framework is designed to work seamlessly with Claude Code 2.0's other features, providing immediate [[concepts/feedback|feedback]] on code behavior and correctness.

## Integration with Claude Code 2.0 Features

Claude Code 2.0's testing capabilities are tightly integrated with the platform's core functionalities, including support for loops, [[concepts/temporary-cron-jobs|scheduled tasks]], and [[concepts/google-workspace-access|Google Workspace integration]]. This means developers can test code that interacts with these systems without requiring external setup or configuration. The testing tools allow [[concepts/verification|verification]] of [[concepts/complex-workflows|complex workflows]], such as those involving repeated operations or time-based task execution, as well as integrations with productivity [[concepts/software|applications]].

## Workflow Benefits

By incorporating testing directly into the coding environment, Built In Skills Testing reduces context switching and accelerates the development cycle. Developers can verify their implementations immediately after [[concepts/writing|writing]] code, identify issues early, and iterate more efficiently. This integrated approach aligns with modern development practices that emphasize continuous validation and rapid feedback loops during the coding process.
