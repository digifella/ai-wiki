# Command-line interface

A text-based [[concepts/user-interface|user interface]] ([[concepts/terminal-user-interface-tui|TUI]]) used to interact with [[concepts/software|software]], operating systems, and services by issuing specific [[concepts/commands|commands]] through a shell.

## Key Characteristics
- **Text-based I/O**: Communication occurs via typed [[concepts/instructions|instructions]] and [[concepts/text|text]] [[concepts/output|output]].
- **[[concepts/automation|Automation]]**: Highly efficient for scripting and [[concepts/automation|automation]] workflows.
- **Direct [[concepts/power|Control]]**: Allows precise manipulation of operating system resources and file systems.

## AI-Powered CLI Agents
Recent developments have introduced agentic interfaces that leverage [[concepts/ai-coding|AI coding]] [[concepts/capabilities|capabilities]] directly within the command line:
- [[concepts/claude-code|Claude Code]] (by [[entities/anthropic|Anthropic]]): An [[concepts/agentic-tool|agentic tool]] designed for automated [[concepts/coding|coding]] tasks.
- [[entities/github-copilot-agent|GitHub Copilot Agent]] (by [[entities/github|GitHub]] and [[entities/microsoft|Microsoft]]): An AI-driven assistant for integrated [[concepts/developer-platforms|development environments]] and terminal workflows.
