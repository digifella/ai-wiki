# Hierarchy

Visual hierarchy is a design principle that organizes and prioritizes information on a [[concepts/user-interface|user interface]] by making certain elements more prominent than others. Through variations in size, color, [[concepts/contrast|contrast]], position, and [[concepts/typography|typography]], designers guide users' [[concepts/attention-mechanisms|attention]] to the most important content first, then secondary elements, and finally tertiary information. This ordering helps users quickly understand page [[concepts/structure|structure]] and navigate efficiently without cognitive overload.

## Application in UI/UX Design

In user interface and [[concepts/user-experience-design|user experience design]], visual hierarchy serves a practical function by establishing clear [[concepts/relationships|relationships]] between interface elements. Primary actions or key information are typically rendered more prominent through larger type, stronger contrast, or strategic positioning, while supporting content remains visible but less immediately noticeable. Effective hierarchy reduces decision fatigue and improves usability by making the intended user flow apparent.

## Techniques

Common techniques for establishing visual hierarchy include size differentiation, color and contrast variation, [[concepts/whitespace|whitespace]] and spatial relationships, typography weight and scale, and element positioning. These techniques work together to create a natural scanning pattern that aligns with how users actually read and interact with digital interfaces. The specific application depends on the content structure and intended user actions within a given design context.
