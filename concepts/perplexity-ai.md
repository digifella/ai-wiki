# Perplexity Ai

Perplexity Ai is an [[concepts/ai-powered-search|AI-powered search]] [[concepts/engine|engine]] that uses [[concepts/large-language-model-llm|large language models]] to retrieve and synthesize information from the web. Unlike traditional search engines that return ranked lists of links, Perplexity presents answers in conversational prose, synthesizing information from multiple sources to address user queries. The service accepts questions in natural language and generates responses designed to be comprehensive and contextually relevant.

## How It Works

The platform combines web [[concepts/document-retrieval|retrieval]] with [[concepts/statistical-language-modeling|language model]] capabilities to [[concepts/solution|answer]] questions directly rather than returning a list of results. When a user submits a query, the system searches for relevant sources and uses them as context for generating a written response. This approach aims to reduce the need for users to manually review and synthesize information across multiple web pages.

## Key Characteristics

Perplexity operates as a [[concepts/conversational-interface|conversational interface]] where users can ask follow-up questions to refine or expand on previous answers. The service cites sources for its generated content, allowing [[concepts/verification|verification]] of claims.
