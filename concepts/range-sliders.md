# Range Sliders

Range sliders are interface controls in Adobe Camera Raw that allow users to define which tones or color ranges are affected by adjustments made through the Point Color feature. By setting upper and lower boundaries, these sliders isolate specific portions of an image's tonal or chromatic spectrum for editing. This selective approach ensures that adjustments target only the intended areas rather than affecting the entire image uniformly.

## Application in Point Color Editing

Within Point Color editing workflows, range sliders work alongside color selection tools to refine which pixels receive the adjustment. After selecting a target color or tone with the Point Color picker, users adjust the range boundaries to expand or contract the selection—determining how similar adjacent colors must be to also receive the modification. This precision prevents unintended color shifts in areas outside the intended range.

## Practical Use

In practice, range sliders help photographers make targeted corrections to specific color casts or tonal issues. For example, a photographer might adjust only the blue tones in a sky without affecting nearby colors, or modify shadows independently from midtones. The sliders provide immediate visual feedback, allowing users to preview exactly which pixels fall within the selected range before committing to changes.
