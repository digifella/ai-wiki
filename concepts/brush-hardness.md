# Brush Hardness

Brush hardness defines the [[concepts/sharpness|sharpness]] of a brush stroke's edge in [[concepts/digital-painting|digital painting]]. A **hard brush** (hardness = 100%) produces crisp, defined edges, while a **soft brush** (hardness < 100%) creates gradual, blurred transitions. This setting directly impacts [[concepts/texture|texture]] [[concepts/accuracy|precision]] and blending capabilities.

## Adjusting Hardness in Adobe Photoshop
- **Quick Key Shortcuts**:
  - `Shift + [` / `Shift + ]` to decrease/increase hardness (while keeping size constant)
  - `[` / `]` adjusts [[concepts/brush-size|brush size]] (hold `Shift` to toggle hardness mode)
- **[[concepts/hud-heads-up-display|Heads Up Display]] (HUD)**:
  - *Mac*: `Ctrl + Option` + drag
  - *[[entities/windows|Windows]]*: `Ctrl + Alt` + right-click + drag
- **Video Reference**: [[entities/julianne-kost]] demonstrates this workflow in her [[entities/adobe-photoshop]] [[concepts/tutorial|tutorial]] series.
