# Bright Data

Bright Data is a web data collection platform that provides infrastructure for extracting and processing data from websites at scale. The platform offers capabilities for [[concepts/web-crawling|web scraping]], data collection, and intelligence gathering through various proxy and collection mechanisms, serving enterprises and developers who need reliable access to public web data.

## MCP Server Integration

Bright Data can be configured as a [[concepts/external-tools|Model Context Protocol]] (MCP) server, which enables [[concepts/large-language-model-llm|large language models]] and AI assistants to access its [[concepts/information-extraction|data extraction]] capabilities through a standardized interface. This integration allows [[entities/ai-tools|AI tools]] to make requests for web data collection and receive structured results without requiring direct [[entities/api-calls|API calls]] or custom integration code.

## Practical Implementation

When configured with [[concepts/autonomous-coding|Gemini CLI]] and [[entities/claude-desktop|Claude Desktop]], Bright Data functions as a tool that these [[concepts/ai-powered-applications|AI applications]] can invoke for web data extraction tasks. This setup requires proper configuration of credentials and server settings to establish the [[concepts/connection|connection]] between the [[concepts/ai-development|AI development]] tool and the Bright Data platform. Once established, users can leverage their [[entities/ai-assistant|AI assistant]]'s capabilities alongside Bright Data's web collection infrastructure within a single workflow.
