# Media Server

A media server is a self-hosted [[concepts/software|software]] system that stores, organizes, and streams digital media content over a home network or internet [[concepts/connection|connection]]. Built on [[concepts/open-source|open-source]] platforms like [[entities/ubuntu|Ubuntu]], media servers function as personal alternatives to commercial [[concepts/streaming-services|streaming services]] by allowing users to manage their own library of films, television shows, music, and other media [[concepts/files|files]]. Common examples include Plex, Jellyfin, and Emby, which provide user-friendly interfaces and [[concepts/metadata|metadata]] management similar to subscription-based platforms.

## Setup and Infrastructure

[[concepts/running|Running]] a media server requires a dedicated machine or network-attached [[entities/storage|storage]] device with sufficient disk capacity and processing [[concepts/power|power]]. Ubuntu [[entities/linux|Linux]] serves as a popular base operating system for these installations due to its stability, community support, and compatibility with media server software. The server must remain powered and connected to the network to serve content on demand, and users typically configure it for [[concepts/remote-access|remote access]] outside their home network with appropriate [[concepts/security|security]] measures.

## Content Management and Streaming

Media servers automatically organize content using metadata like titles, genres, cast information, and artwork, often fetching this data from online databases. They support simultaneous streaming to multiple devices and allow users to maintain watch histories, create playlists, and manage user profiles similar to commercial services. Streaming quality can be adjusted based on available bandwidth, and most systems support common video and [[concepts/audio-modality|audio]] formats across various devices including phones, tablets, computers, and smart televisions.
