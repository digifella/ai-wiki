# Gentabs

Gentabs, also known as Disco or GenTabs, is a user interface feature integrated into Google Gemini that enables the management of multiple concurrent conversations within a single window. This functionality replaces the traditional model of opening separate browser tabs or distinct chat sessions for different topics, providing a unified workspace for complex workflows.

The interface utilizes a tabbed layout where each tab maintains its own independent context and conversation history. This design allows users to switch between distinct inquiries seamlessly without losing the state of previous interactions, thereby streamlining the process of managing related but separate threads of dialogue.
