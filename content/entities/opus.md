# Opus

Opus is a model variant within the [[concepts/claude-ai|Claude]] family of AI assistants developed by [[entities/anthropic-institute|Anthropic]]. It represents one of several capability tiers in Claude's product offering, positioned alongside other model versions to serve different performance and cost requirements.

## Local Deployment and Development

Opus can be run locally using [[entities/ollama|Ollama]], an [[concepts/open-source|open-source]] tool that enables developers to run [[concepts/large-language-model-llm|large language models]] on their own machines without relying on cloud-based APIs. This approach reduces operational costs and allows for greater [[concepts/privacy|privacy]] and control over model execution. The process involves downloading the model through Ollama and configuring it to work with [[concepts/coding|local development]] environments.

## Shift Toward Harness Engineering

The development of Opus and similar models reflects a broader trend in [[concepts/ai-development|AI development]] away from [[concepts/prompt-based-modeling|prompt engineering]] and toward harness engineering. Rather than focusing solely on crafting optimal prompts, practitioners increasingly work with frameworks and systems that orchestrate multiple [[concepts/capabilities|AI capabilities]]—such as code execution, tool use, and agent-based workflows—to accomplish [[concepts/complex-tasks|complex tasks]]. This represents an evolution in how developers interact with and [[concepts/leverage-ai|leverage AI]] models in production [[concepts/software|applications]].
