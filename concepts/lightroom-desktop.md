# Lightroom Desktop

**[[entities/adobe|Adobe]] [[entities/lightroom-classic|Lightroom Classic]]** is the desktop-based photo management and editing application within the Adobe Creative Cloud ecosystem. It serves as the primary [[concepts/non-destructive-workflow|non-destructive editing]] environment for professional photographers, offering deep integration with [[concepts/adobe-camera-raw]], DNG, and cloud-synced workflows via Lightroom Cloud.

## Key Features & Capabilities

*   **Non-Destructive Editing:** All adjustments are stored in sidecar XMP files or the catalog database, preserving original image data.
*   **Catalog Management:** Centralized database for organizing, tagging, and rating large volumes of images.
*   **Module-Based Workflow:** Distinct modules for Library (organization), Develop (editing), Map (geotagging), Book/Slideshow/Print/Web (output).
*   **RAW Processing:** Native support for proprietary RAW formats and DNG standard.
*   **Advanced Masking:** Utilizes AI-driven selection tools (e.g., Subject, Sky) and gradient filters.
*   **[[concepts/gradient-tool|Gradient Tool]] Updates:** Recent updates allow for replicating [[concepts/adobe-camera-raw]]'s [[concepts/bidirectional-gradient|bidirectional gradient]] effects within Lightroom Classic, enhancing sky and horizon transitions.
