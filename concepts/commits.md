# Commits

A Commit is a fundamental [[concepts/data-structure|data structure]] in Git that represents a snapshot of a project at a specific point in time.

## Core Concepts
- Acts as a primary [[entities/nodejs|node]] within a DAG ([[concepts/directed-acyclic-graph-dag|Directed Acyclic Graph]]).
- Forms the structural basis for Branches.
- Understanding commits requires moving beyond memorized [[concepts/commands|commands]] to grasp the underlying operational [[concepts/open-source-philosophy|logic]] and data structures of Git.
