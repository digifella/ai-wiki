# Background AI processing

The execution of computationally intensive [[entities/ai|artificial intelligence]] tasks in a secondary thread or decoupled process, allowing the primary [[concepts/user-interface|user interface]] to remain responsive and preventing interruption of the active user workflow.

### Core Mechanics
- Asynchronous processing: Decouples heavy computation (e.g., [[concepts/masking|masking]], generative fills, and complex [[concepts/thematic-analysis|pattern recognition]]) from the main UI thread to maintain software fluidity.
- Workflow [[concepts/continuity|Continuity]]: Facilitates [[concepts/autonomous-workflows|AI-driven workflows]] by enabling users to continue manual editing, organization, or [[concepts/metadata|metadata]] entry while complex models [[concepts/compute|compute]] in the background.

### Notable Implementations
- [[concepts/lightroom]] (v15.3): Integration of [[entities/adobe-firefly]] features utilizing background processing to prevent interface locking during [[concepts/generative-ai-models|generative AI]] tasks.
