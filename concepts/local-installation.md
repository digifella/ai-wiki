# Local installation

Deployment of software or models on a user's own device/server rather than [[concepts/cloud-based-solutions|cloud services]], offering control, [[concepts/privacy|privacy]], and reduced internet dependency.

**Examples:**
- [[entities/fahd-mirza|Fahd Mirza]] - [[entities/videorefer-suite|Videorefer model]] running locally: Step-by-step guide for installing [[entities/alibaba|Alibaba]]'s [[concepts/videorefer-suite|VideoRefer Suite]] ([[concepts/apache-2-license|Apache 2 license]]), a video model enhancing LLMs with [[concepts/spatial-temporal-object-understanding|spatial-temporal object understanding]] through fine-grained [[concepts/object-tracking|object tracking]] in videos.
- Zero2launch - Guide for local n8n deployment via [[concepts/docker|Docker]], integrating [[concepts/agentic-ai|AI agents]] with the [[concepts/model-context-protocol|Model Context Protocol (MCP)]] for seamless interaction with [[concepts/external-tools|external tools]].
- [[lab-notes/2026-07-30-Microsoft-Fara-1.5-27B-Local-Install-and-Vision-Only-Bro|Microsoft Fara 1.5-27B: Local Install and Vision-Only Browser Automation Performance]]: Demonstrates [[concepts/local-control|local deployment]] of [[entities/microsoft|Microsoft]]'s Fara 1.5-27B, a multimodal [[concepts/computer-use-agent|Computer Use Agent]] (CUA) optimized for vision-only [[concepts/browser-automation|browser automation]] tasks.
