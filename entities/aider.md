**Aider** is an [[concepts/open-source|open-source AI]] pair programmer that runs in your [[concepts/cli|terminal]]. It connects directly to your local git repository, allowing it to read, edit, and commit code changes using [[concepts/demystifying-llms|large language models]] (LLMs).

## Key Features
- **Git Integration**: Automatically stages and [[concepts/commits|commits]] changes, providing a clear history of AI-assisted edits.

- **Multi-Model Support**: Compatible with various LLM providers (e.g., [[concepts/whisper-transcription|OpenAI]], [[entities/anthropic-institute|Anthropic]], [[concepts/gemini|Google Gemini]]).
