# How to Save $200+/Month by Replacing 8 Expensive [[concepts/ai-tools|AI Tools]]

The video argues that [[concepts/ai-models|AI models]] have evolved so fast that specialized "wrapper" tools (tools built on top of models like [[concepts/gpt-4|GPT-4]]) are no longer necessary. By using [[concepts/foundational-models|foundational models]] and smart workflows, businesses can save hundreds of dollars monthly.

## Detailed Workflow Breakdowns

### 1\. Meeting Transcription & Notes

**The Old Way:** Paying for Otter.ai or Fireflies.ai. **The New Workflow:**

1. **Record:** Use **Fathom** (Free Plan) to record and transcribe the call.
2. **Process:** Copy the full transcript from Fathom.
3. **Analyze:** Paste the transcript into **NotebookLM** (Free).
4. **Output:** Use NotebookLM to query the meeting, track trends, write follow-up emails, or generate audio summaries.

### 2\. [[entities/chatgpt-deep-research|Deep Research]] & Analysis

**The Old Way:** Paying for Perplexity Pro. **The New Workflow:**

1. **Tool:** Use **NotebookLM** (Free). It now includes "Deep Research" powered by Gemini.
2. **Process:** Select "Deep Research" from the source dropdown. Type your query (e.g., "Top AI opportunities in Q4 2025").
3. **Result:** It generates a comprehensive report with citations. You can also upload your own PDFs/Docs to research against internal data.

### 3\. [[concepts/content-creation|Content Creation]] (Writing)

**The Old Way:** Dedicated writers like Jasper, Copy.ai, or Writesonic. **The New Workflow:**

1. **Tool:** **Claude Pro** ($20/mo - _The only paid tool recommended in the core stack_).
2. **Why:** Claude writes better than the dedicated tools.
3. **Features:** Use **Claude Projects** to store brand knowledge and **Claude Skills** to create reusable [[concepts/instructions|instructions]] (e.g., "Always format emails in this specific brand voice").

### 4\. Image Generation & [[concepts/design|Design]]

**The Old Way:** Midjourney or Ideogram. **The New Workflow:**

1. **Tool:** **Google AI Studio** (Free).
2. **Model:** Select **[[entities/nano-banana|Nano Banana]]** or **[[entities/imagen|Imagen]] 4**.
3. **[[concepts/prompting|Prompting]]:** If you don't know how to prompt, use the Gemini chat window _inside_ AI Studio to write the image prompt for you.
4. **[[concepts/cost|Cost]]:** Nano Banana requires an API key but costs fractions of a penny (essentially free).

### 5\. Presentations & [[concepts/slide-decks|Slide Decks]]

**The Old Way:** Gamma or Beautiful.ai. **The New Workflow:**

1. **Tool:** **[[entities/google-gemini|Google Gemini]] App** (Free version is sufficient).
2. **Process:** Ask Gemini to create a slide deck based on a topic or a previous research output.
3. **Export:** Click the "Export to Slides" button to immediately open an editable presentation in Google Slides.

### 6\. Automation & AI [[concepts/agents|Agents]]

**The Old Way:** Complex setups using Make.com combined with expensive AI [[entities/agent|agent]] tools like MindPal. **The New Workflow:**

1. **Tool:** **Relay.app** (Free plan) or **Claude Skills**.
2. **Strategy:**
	* **Claude Skills:** Create a "[[concepts/skill|skill]]" inside Claude that creates a workflow (e.g., "Turn this transcript into a blog post").
	* **Relay.app:** Use their [[concepts/ai-assistant|AI assistant]] to build "[[concepts/no-code|No-Code]]" automations. _Example:_ When a new lead arrives -> Draft an [[entities/email|email]] -> Send a [[entities/slack|Slack]] DM for approval -> Send the email.

### 7\. Social Media Content Repurposing

**The Old Way:** Repurpose.io or Descript. **The New Workflow:**

1. **Tool:** **Relay.app**.
2. **Automation:** Build a specific workflow:
	* Trigger: New video posted to [[entities/youtube|YouTube]].
	* Action: Get Transcript.
	* Action: Send to Claude to write a LinkedIn post.
	* Action: Send Slack DM to user for approval.
	* Action: Post to LinkedIn automatically upon approval.

### Bonus: Notion AI

While optional, **Notion AI** ($24/mo/user) allows you to consolidate models. Instead of paying for separate [[entities/chatgpt|ChatGPT]], Claude, and Gemini subscriptions, you can access all latest models (GPT-4, [[entities/claude-35-sonnet|Claude 3.5 Sonnet]], Gemini Pro) directly inside Notion. It creates a unified workspace connected to your docs, [[concepts/google-drive|Google Drive]], and Slack.
