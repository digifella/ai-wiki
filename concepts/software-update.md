# Software Update

A **Software Update** is a [[concepts/deployment|release]] of new code, patches, or improvements for an existing software application. [[concepts/software-updates|Updates]] typically address [[concepts/security|security]] vulnerabilities, fix bugs, improve performance, or introduce [[concepts/new-features|new features]]. In the context of creative tools, updates often refine user interfaces, enhance algorithmic processing (e.g., [[concepts/ai-based-selection|AI masking]]), and expand compatibility with new hardware or file formats.

## Key Characteristics
- **[[concepts/version-numbers|Versioning]]**: Follows semantic versioning or specific vendor schemes (e.g., [[entities/adobe|Adobe]]'s major.minor.patch).
- **Delivery**: Distributed via automatic background checks, manual download prompts, or dedicated update managers.
- **Impact**: Can range from invisible backend fixes to significant workflow alterations.
