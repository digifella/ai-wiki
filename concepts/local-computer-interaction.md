# Local Computer Interaction

## Overview
**Local computer interaction** refers to the [[concepts/causes|mechanisms]] and interfaces through which users engage with software, hardware, and data residing on their immediate device. This concept encompasses direct input/output operations, [[concepts/local-processing|local processing]], and the integration of [[concepts/local-agents|personal AI agents]] that operate within the user's immediate digital environment.

## Key Concepts
- **Proactive Assistance**: Moving beyond reactive command-and-control to anticipatory support.
- **[[concepts/session-resumption|Workflow Continuity]]**: Ensuring seamless transitions between tasks and contexts without data loss or context switching overhead.
- **Ecosystem Orchestration**: Centralizing control over disparate tools and services.

## Emerging Tools & Agents

### OpenAI Dots
[[concepts/whisper-transcription|OpenAI]] has introduced **[[concepts/dots-agent|Dots]]**, an always-on, proactive [[concepts/personal-ai-assistant|personal AI assistant]] agent designed to bridge components of the [[entities/chatgpt]] ecosystem. Currently in [[concepts/early-access|early access]] for Pro and Enterprise users, Dots acts as a [[concepts/orchestrator-model|central orchestrator]] for workflow [[concepts/continuity|continuity]].

- **Capabilities**:
  - Always-on monitoring and assistance.
  - Proactive task initiation based on user context.
  - Integration with existing ChatGPT tools and data.
- **Significance**: Represents a shift toward [[concepts/ai-agents|AI agents]] that manage local and cloud-based interactions seamlessly.
