# Claude Code Workflow

[[concepts/developer-workflow|Claude Code Workflow]] is a systematic approach to managing long-[[concepts/running|running]] [[concepts/mcps|AI coding agents]], designed to address the challenges of maintaining context, [[concepts/continuity|continuity]], and effectiveness over extended periods. The [[concepts/workflow|workflow]] provides a [[concepts/canvas|structured framework]] for deploying [[concepts/claude-ai|Claude]] in [[concepts/code-generation|code generation]] and [[concepts/coding|software development]] tasks that span multiple sessions or iterations, ensuring that [[concepts/agents|agents]] can operate reliably without losing critical information or degrading in performance.

## Core Principles

The workflow emphasizes maintaining clear state management and context [[concepts/preservation|preservation]] throughout an [[entities/agent|agent]]'s execution lifecycle. By establishing [[concepts/effective-harnesses|effective harnesses]] and checkpoints, developers can create agents that sustain productivity across long workflows, reducing the need for manual intervention and allowing [[concepts/claude|Claude]] to handle complex, multi-step coding tasks with greater autonomy and [[concepts/logical-consistency|consistency]].

## Application

This approach is particularly useful for [[concepts/scenarios|scenarios]] involving substantial codebases, iterative development cycles, or tasks requiring the agent to reference and build upon previous work. The workflow documentation provides practical guidance on implementing these patterns, drawing from tested approaches to [[concepts/ai-coding-assistance|AI-assisted coding]] that balance [[concepts/automation|automation]] with human oversight.
