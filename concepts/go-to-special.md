# Go To Special

A [[entities/microsoft|Microsoft]] [[entities/excel]] feature used to quickly select cells within a range that meet specific criteria or possess particular attributes.

## Key Functionalities
- Selects cells by property: Blanks, Formulas, Constants, Comments, etc.
- Facilitates bulk operations such as mass formatting, targeted deletion, or error auditing.

## Applications & Use Cases
- **[[concepts/blank-row-deletion|Blank Row Deletion]]**: An efficient method for removing empty rows in large [[concepts/training-data|datasets]], preventing the need for manual, row-by-row [[concepts/iteration|iteration]].
- **[[concepts/data-cleaning|Data Cleaning]] Alternatives**:
	- Filter: Used for isolating specific rows based on criteria.
	- [[concepts/power-query|Power Query]]: A more robust tool for complex, repeatable [[concepts/data-transformation|data transformation]] and cleaning workflows.
