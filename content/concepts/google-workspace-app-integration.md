# Google Workspace App Integration

[[entities/google-workspace|Google Workspace]] App [[concepts/integration|Integration]] refers to the expansion of [[concepts/google-gemini|Google Gemini]]'s [[concepts/capabilities|capabilities]] within the [[concepts/google-workspace-ecosystem|Google Workspace ecosystem]] through new features that enable deeper interaction with [[concepts/web-applications|web applications]]. These integrations allow users to perform actions and manage workflows directly through [[concepts/gemini|Gemini]]'s interface, bridging the gap between AI assistance and [[concepts/productivity-tools|productivity tools]].

## Scheduled Actions

One of the primary integration features introduced to [[entities/gemini-app|Gemini]] is [[concepts/scheduled-actions|Scheduled Actions]], which enables users to schedule tasks directly within the Gemini [[concepts/web-application|web application]]. This functionality extends Gemini's role beyond real-time conversation assistance to include [[concepts/routine-automation|task automation]] and planning capabilities. Users can access and configure [[concepts/recurring-actions|scheduled actions]] through the application's settings, allowing for greater [[concepts/power|control]] over when and how tasks execute within their [[concepts/workflow|workflow]].

## Integration with Google Workspace

The integration of these features with [[concepts/google-workspace|Google Workspace]] represents an effort to consolidate productivity functionality within a single ecosystem. By embedding scheduling and [[concepts/automation|automation]] capabilities directly into Gemini, [[concepts/google-search|Google]] aims to reduce the need for users to switch between multiple [[concepts/software|applications]] when managing tasks and coordinating work across their [[concepts/organization|organization]].
