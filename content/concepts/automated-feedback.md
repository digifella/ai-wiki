# Automated Feedback

[[concepts/automated-feedback-loops|Automated feedback]] systems provide continuous, real-time [[concepts/responses|responses]] during [[concepts/coding|software development]] by capturing performance metrics, test results, error logs, and validation data. These systems create [[concepts/feedback|feedback]] loops that enable [[concepts/iterative-refinement|iterative refinement]] of code without requiring manual intervention between cycles. When integrated with [[concepts/mcps|AI coding agents]] like [[concepts/claude-ai|Claude]], automated feedback allows developers to identify issues quickly and guide the agent toward improved solutions based on concrete data rather than trial and error.

## Integration with AI Coding Agents

AI coding agents leverage automated feedback to understand whether generated code meets specified requirements. By receiving immediate results from test suites, linters, type checkers, and runtime monitoring, [[concepts/agents|agents]] can adjust their approach within a single [[concepts/session|session]]. This integration reduces the number of manual review cycles needed and allows agents to learn from failures and successes as they work through complex development tasks.

## Common Feedback Sources

Typical automated feedback comes from unit and integration test failures, static analysis tools, performance profilers, and compilation errors. Some workflows also incorporate custom validation scripts tailored to specific project requirements or architectural constraints. This combination of standard and custom feedback mechanisms creates a comprehensive picture of code quality and functionality that guides subsequent iterations.
