# Behavioral Types

Behavioral types define the observable patterns of action, [[concepts/reasoning|reasoning]], and interaction exhibited by software systems or [[concepts/agentic-ai]]. Unlike structural types that focus on data representation, behavioral types characterize *how* an entity responds to stimuli, executes [[concepts/open-source-philosophy|logic]], and adapts over time.

## Core Characteristics

- **Action-Oriented**: Focuses on sequences of operations rather than static state.
- **Contextual Adaptation**: Behavior changes based on input history or environmental [[concepts/feedback|feedback]].
- **Protocol Definition**: Establishes expected interfaces for interaction between components.

## In AI Agent Architecture

In the context of modern [[concepts/large-language-models]] (LLMs), behavioral types are critical for distinguishing simple [[concepts/ai-bots|chatbots]] from [[concepts/agentic-systems|autonomous agents]]. Agents exhibit specific behavioral modes such as:

- **Reasoning**: The ability to break down complex queries into [[concepts/logical-steps|logical steps]].
- **[[concepts/acting|Acting]]**: Executing external actions via tools or [[concepts/open-standard-protocols|APIs]].
- **Adaptation**: Modifying strategy based on success/failure of previous attempts.

## Frameworks and Implementations

- **[[concepts/react-framework|ReAct Framework]]**: A foundational pattern combining Reasoning and Acting, enabling agents to interleave [[concepts/thought-processes|thought processes]] with tool use [[lab-notes/2026-06-13-AI-Agents-Explained-ReAct-Framework-Behavioral-Types-and|AI Agents Explained: ReAct Framework, Behavioral Types, and Google ADK]].
