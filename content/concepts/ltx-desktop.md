# LTX Desktop

**[[entities/ltx|LTX]] Desktop** is the first native, free, [[concepts/open-source|open-source]], and fully local non-linear [[concepts/ai-video-editor|AI video editor]], powered by the [[entities/ltx-23|LTX 2.3]] multimodal engine. It provides a desktop-native environment for private, hardware-accelerated [[concepts/video-creation|video creation]] and manipulation, removing reliance on cloud APIs and [[concepts/subscription-models|subscription models]].

## Key Attributes
- **Local-First [[concepts/architecture|Architecture]]:** Executes entirely on user [[concepts/hardware|hardware]], ensuring data [[concepts/privacy|privacy]] and eliminating cloud latency or API costs.
- **LTX 2.3 [[concepts/integration|Integration]]:** Leverages the LTX 2.3 model for advanced multimodal generation, supporting [[concepts/text-to-video|text-to-video]], [[concepts/image-to-video|image-to-video]], and video-to-video workflows.
- **Non-Linear [[concepts/workflow|Workflow]]:** Combines traditional [[concepts/non-linear-editing-workflow|timeline-based editing]] [[concepts/capabilities|capabilities]] with AI-native tools, diverging from linear prompt-only interfaces.
- **Open Source:** Community-accessible [[concepts/code|codebase]] allowing for [[concepts/customization|customization]], extension, and transparency.
- **Free [[concepts/distribution|Distribution]]:** Released without [[concepts/cost|cost]], reducing barriers to entry for local [[concepts/ai-film-direction|AI video production]].
