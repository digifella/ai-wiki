# pdf-inspector

**pdf-inspector** is an open-source, Rust-powered tool developed by Firecrawl designed for rapid, [[concepts/local-processing|local processing]] of PDF documents. It focuses on high-speed classification and [[concepts/content-extraction|content extraction]], optimized for integration with AI agents.

## Key Features
- **Performance:** Claims to make PDF parsing up to 100x faster for AI workflows.
- **Architecture:** Built with [[concepts/rust-programming-language|Rust]] for efficiency and safety.
- **Functionality:**
  - Rapid [[concepts/pdf-classification|PDF classification]].
  - Content extraction optimized for downstream AI consumption.
  - Local processing capabilities for [[concepts/privacy|privacy]] and speed.
