# Claude Chatbot

[[concepts/claude|Claude]] is an AI chatbot developed by [[entities/anthropic-institute|Anthropic]]. As a [[concepts/large-language-model|large language model]], it processes text input and generates conversational responses across a wide range of topics. By default, Claude functions as a text-based [[concepts/ai-chatbots|conversational AI]], engaging with users through [[concepts/communication|dialogue]] while drawing on knowledge from its [[concepts/language-data|training data]].

## Agentic Capabilities

Claude's functionality extends beyond standard conversational interaction through the [[concepts/model-context-protocol|Model Context Protocol (MCP)]]. This protocol enables Claude to operate as an AI agent by connecting to external tools, databases, and systems. Through MCP, Claude can read files, execute searches, interact with APIs, and perform other actions in external environments, effectively allowing it to take steps beyond generating text responses. This capability transforms Claude from a purely generative system into an agent capable of accomplishing tasks that require interaction with external resources.

The agentic version of Claude maintains the conversational interface while gaining the ability to reason about which tools to use and when to use them. Users can direct Claude to complete objectives that require tool use, and Claude can autonomously decide on the sequence of actions needed to fulfill those requests.
