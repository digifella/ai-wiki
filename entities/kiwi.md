# Kiwi

Kiwi is a beta camera application developed by Adobe, designed specifically for iPhone 13 Pro and later models. The application integrates directly with Adobe Lightroom, enabling users to capture photos within the Lightroom environment rather than relying on the native iOS Camera app and subsequently transferring images. This integration allows for immediate access to Lightroom’s editing tools and cloud storage workflows at the moment of capture.

By leveraging the computational photography hardware available in supported iPhone devices, Kiwi performs advanced image processing at the point of capture. Key features include enhanced zoom capabilities, improved night mode photography, and tools for reflection removal. These functions aim to streamline the workflow for photographers who require immediate post-processing options without the need for manual file management between separate applications.
