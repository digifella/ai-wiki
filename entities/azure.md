# Azure

Azure is [[entities/microsoft|Microsoft]]'s [[concepts/cloud-computing|cloud computing]] platform that provides infrastructure, platform, and software-as-a-service ([[concepts/saas|SaaS]]) solutions for building, deploying, and managing applications and data. As a major cloud provider, Azure serves organizations across various industries and supports a wide range of [[concepts/scenarios|use cases]].

## Azure AI Services

Azure provides dedicated services for [[concepts/ai-development|AI development]] and [[concepts/machine-learning|machine learning]]. These services include tools for model training, deployment, and management. Azure AI supports [[concepts/retrieval-augmented-generation|retrieval-augmented generation (RAG)]] capabilities, which can be integrated with Foundry to enhance search and data retrieval workflows by combining language models with external knowledge sources.
