# Code review automation

The use of [[concepts/ai-agent|AI agent]] technology and [[concepts/automation-tools|automated workflows]] to evaluate code quality, identify bugs, and ensure adherence to architectural standards during the [[concepts/software-development-process|development lifecycle]].

### Specialized Frontend Automation
- [[entities/kombai]]: An [[entities/agent|AI agent]] purpose-built for [[concepts/front-end-development|frontend development]] that integrates directly into IDEs such as [[entities/vs-code]], [[entities/cursor]], and [[entities/windsurf|Windsurf]].
    - Specifically optimized for frontend-centric tasks, distinguishing it from general-purpose [[concepts/coding|coding]] assistants.
    - Demonstrates significantly higher performance in code review tasks, with a 72% [[concepts/success|success]] rate compared to the 30-50% [[concepts/success-rates|success rates]] seen in general-purpose tools like [[entities/github|GitHub]] [[entities/copilot|Copilot]], [[entities/codepal|CodePal]], and [[entities/gemini]].
