# Customizable Extraction

Customizable Extraction refers to the ability to configure and tailor [[concepts/information-extraction|data extraction]] workflows within [[entities/googles-notebooklm|Google's NotebookLM]] platform. This feature allows users to specify which types of information they want to pull from source documents, rather than relying on a fixed extraction process. The capability has become increasingly relevant as [[concepts/ai-integrated-notebooks|NotebookLM]] has expanded its functionality beyond basic note-taking to include [[concepts/json-structuring|structured data]] handling.

## Data Tables and Simulations

Recent updates to NotebookLM have introduced capabilities for working with data tables and [[concepts/running|running]] simulations based on extracted information. These features enable users to organize extracted data into structured formats and perform analytical operations on that data within the same environment. This integration supports workflows where raw document data must be transformed into actionable insights or computational models.

## Integration with AI Tools

NotebookLM's customizable extraction works in conjunction with other AI-driven features, including mind mapping and interactive HTML generation. The platform's integration with [[entities/gemini-models|Gemini AI]] has enabled more sophisticated [[concepts/text-modality|text processing]] and [[concepts/data-transformation|data transformation]] capabilities. This combination allows for more comprehensive document analysis pipelines, from initial extraction through visualization and interactive presentation of results.
