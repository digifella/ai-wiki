# Claude Routines

An evolution in [[concepts/ai-automation]] by [[entities/anthropic]] that shifts [[concepts/automation|automation]] logic from time-based triggers to action-based, event-driven [[concepts/responses|responses]].

## Key Features
- **[[concepts/event-driven-automation|Event-Driven Automation]]**: Moves away from traditional time-based triggers (functioning like an alarm clock) to respond to specific business events.
- **Action-Based Logic**: Focuses on automating [[concepts/workflow|workflows]] triggered by real-time actions rather than scheduled intervals.
