# Output Control

[[concepts/output|Output Control]] refers to the configuration settings and user-facing controls within [[concepts/automated-feedback|Claude Code workflows]] that govern how results are displayed, processed, and shared. These controls allow users to manage the visibility and [[concepts/accessibility|accessibility]] of generated outputs, determine which information is logged or retained, and specify how [[concepts/ai-assisted-coding|Claude Code]] handles sensitive data during execution. Output Control settings bridge [[concepts/workflow|workflow]] management and [[concepts/privacy|privacy]] concerns by providing granular options for output handling.

## Workflow Output Settings

Within [[concepts/custom-tools|Claude Code workflows]], output control encompasses decisions about result formatting, display verbosity, and intermediate step visibility. Users can configure whether outputs are shown in real-time, batched, or presented in [[concepts/summary|summary]] form. These settings affect both the development experience and the final presentation of results to end users or downstream systems.

## Privacy and Data Handling

Output Control also manages privacy-related aspects of [[concepts/code-execution|code execution]], including which outputs are logged for auditing purposes, how long outputs are retained, and whether sensitive information is masked or redacted before [[entities/storage|storage]] or sharing. These controls are essential for workflows processing confidential data or operating in regulated environments where data minimization and retention [[concepts/policies|policies]] must be strictly observed.
