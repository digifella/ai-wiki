# Agent Harnesses

Agent harnesses are computational frameworks that enable AI agents to execute code directly rather than relying solely on natural language generation. By integrating programming capabilities into agent systems, these harnesses allow language models to interact with external APIs, databases, web services, and other computational tools. This addresses a fundamental limitation of text-only language models: the gap between describing an action and actually executing it in external systems.

## Code vs. Markdown Efficiency

Using code for web scraping enhances LLM efficiency compared to using markdown. While markdown provides a human-readable structure, it lacks the precision and programmatic control required for reliable data extraction at scale. Code-based approaches allow agents to parse HTML, handle dynamic content, and manage state more robustly, reducing the ambiguity that often leads to errors in text-based instructions.

## Integration and Execution

These frameworks bridge the gap between high-level reasoning and low-level execution. Instead of generating a textual description of a desired outcome, the agent generates executable scripts that perform the task. This direct execution model ensures that the agent's output is not just a suggestion but a functional operation, enabling more complex workflows involving multiple steps and external dependencies.
