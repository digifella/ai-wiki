# Low Cost Computing

Low Cost Computing refers to building functional computing systems using minimal financial investment, typically by leveraging [[concepts/open-source|open-source]] [[concepts/software|software]] and commodity [[concepts/hardware|hardware]]. A practical demonstration of this approach involves constructing a [[concepts/media-server|media server]] using [[entities/ubuntu|Ubuntu Linux]] for under $100, configured to replace commercial streaming subscription services. This strategy makes [[concepts/digital-infrastructure|digital infrastructure]] accessible to individuals and small organizations with limited budgets while maintaining reasonable performance for typical workloads.

## Implementation

The core approach combines inexpensive hardware—such as older refurbished computers, single-board systems, or basic server components—with Ubuntu's free operating system. Users can install media server software to host and stream personal video and audio collections, eliminating recurring subscription fees. This requires basic technical knowledge for initial setup and configuration, but the resulting system can serve multiple users on a local network without ongoing costs beyond electricity.

## Considerations

While low-cost computing solutions offer significant financial advantages, they involve tradeoffs in convenience, support, and feature parity compared to commercial services. Maintenance responsibilities fall entirely on the user, including security updates, troubleshooting, and hardware management. The approach works best for users with technical aptitude and those seeking to reduce dependency on subscription-based services.
