# Recent Apps Option Consolidation

A UI [[concepts/design|design]] strategy that reduces cognitive load by merging or simplifying access points to application lists, typically streamlining the distinction between "recent apps" and "full [[concepts/app-drawer|app drawer]]" interfaces.

* [[entities/android-16|Android 16]] ([[entities/june-2025-pixel-drop|June 2025 Pixel Drop]]): Home screen overlay menu now includes "App list" option for direct app drawer access, consolidating a previously separate navigation path. See [[entities/android|Android]] 16 review.
