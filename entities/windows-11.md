# Windows 11

[[entities/windows|Windows]] 11 is a major operating system [[concepts/deployment|release]] by [[entities/microsoft|Microsoft]], succeeding [[entities/windows-10|Windows 10]]. It was officially announced in June 2021 and released to the public on October 5, 2021. The operating system introduced a redesigned [[concepts/user-interface|user interface]] with a centered taskbar and Start menu, representing a significant visual departure from its predecessor.

## Key Features

The system includes updated design elements, improved [[concepts/software-performance|performance optimization]], and integration with Microsoft's [[concepts/cloud-computing|cloud services]]. [[concepts/microsoft-windows|Windows]] 11 introduced stricter [[concepts/hardware-requirements|hardware requirements]] compared to Windows 10, including mandatory support for TPM 2.0 (Trusted Platform Module) and UEFI firmware, which raised compatibility concerns for users with older hardware.

### Enhanced Customization

While the initial launch featured limited [[concepts/personalization|personalization]], Microsoft has reintroduced and expanded [[concepts/customization|customization]] options for the taskbar, Start menu, and search [[concepts/experience|experience]]. This shift addresses [[concepts/user-feedback|user feedback]] regarding the reduced flexibility compared to previous Windows versions, allowing for more thorough personalization of the operating system experience. See [[lab-notes/2026-10-03-Windows-11-Enhanced-Customization-for-Taskbar-Start-Menu|Windows 11: Enhanced Customization for Taskbar, Start Menu, and Search]] for detailed analysis.

## System Requirements and Support

Windows 11 requires compatible [[concepts/central-processing-units|processors]] from [[entities/intel|Intel]] (8th generation or newer) or AMD (Ryzen 2000 series or newer), along with at least 4GB of RAM and 64GB of [[entities/storage|storage]].
