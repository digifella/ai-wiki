# Dark Code

[[concepts/software|Software]] [[concepts/running|running]] in production that is not fully understood by any personnel on the payroll—neither the engineers who shipped it, the owning teams, nor the CTO.

## Key Characteristics
- **Comprehension Gap**: Code logic and behavior are opaque to all internal stakeholders
- **Untraceable Risks**: Critical issues cannot be diagnosed or traced due to lack of visibility
- **AI-Generated Proliferation**: Rapid escalation driven by **[[concepts/ai-generated-code|AI-Generated-Code]]** tools bypassing human oversight
- **Systemic Failure Risk**: As demonstrated in Amazon's post-16,000-engineer layoff incident ([[entities/ai-news-strategy-daily|AI News & Strategy Daily]], 2026-04-14)
