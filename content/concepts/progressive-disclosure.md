# Progressive Disclosure

Progressive disclosure is a [[concepts/design|design]] and interaction principle that presents information, features, or [[concepts/capabilities|capabilities]] to users in stages, revealing complexity gradually rather than all [[concepts/assistive-technology|at]] once. By withholding advanced options until they are needed, this approach reduces cognitive load for new users while maintaining full functionality for experienced ones. The concept is particularly relevant in tools and platforms where feature depth might otherwise overwhelm users during onboarding.

## Application in Claude Skills

[[entities/rick-mulready|Rick Mulready]]'s video on [[concepts/instruction-reuse|Claude Skills]] demonstrates how progressive disclosure applies to [[concepts/ai-agent|AI agent]] capabilities. Claude Skills (also called [[concepts/agent-harnesses|Agent Skills]]) represent specialized functions that [[concepts/claude-ai|Claude]] can access and utilize, but rather than exposing all available [[concepts/skills|skills]] immediately, they are introduced contextually as users develop their [[concepts/workflow|workflow]]. This staged approach allows users to master basic interactions first before engaging with more sophisticated agent-based [[concepts/automation|automation]].

## Practical Value

Progressive disclosure improves [[concepts/user-experience-design|user experience]] by creating a smoother [[concepts/learning|learning]] curve and reducing [[concepts/friction|friction]] during initial [[concepts/setup|setup]]. In the context of [[entities/ai-tools|AI tools]] like Claude, this means new users can start with straightforward tasks while advanced users can progressively unlock and configure more complex [[concepts/skill|skill]] chains and [[entities/agent|agent]] behaviors as their needs evolve. This strategy balances [[concepts/accessibility|accessibility]] with power-user capabilities.
