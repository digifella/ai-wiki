# Kiwi

Kiwi is a beta camera application developed by Adobe for iPhone 13 Pro and later models. The app integrates with Adobe Lightroom, allowing users to capture photos directly within the Lightroom environment rather than using the native Camera app and transferring images separately. By leveraging the computational photography capabilities of newer iPhone hardware, Kiwi provides advanced image processing at the point of capture.

## Features

The application includes several computational photography features. These include enhanced zoom capabilities, improved low-light performance for night photography, and a reflection removal tool that can reduce unwanted reflections from glass surfaces and water. These features are processed on-device, enabling real-time previews before capture.

## Availability

As a beta application, Kiwi's availability is limited to iPhone 13 Pro and iPhone 13 Pro Max models, which contain the hardware required to support its computational photography features. The exclusive hardware requirement reflects Adobe's focus on devices with advanced camera systems and processing capabilities.
