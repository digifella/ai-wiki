# Desktop To Mobile Llm Integration

[[entities/anythingllm|AnythingLLM]] 1.12 introduces mobile channel support for privately self-hosted [[concepts/large-language-model-llm|large language models]]. This integration allows users to interact with their LLMs through mobile devices while maintaining the [[concepts/privacy|privacy]] and control benefits of self-hosted infrastructure. The feature bridges the gap between desktop-based LLM [[concepts/deployment|deployment]] and mobile [[concepts/accessibility|accessibility]], enabling consistent AI assistance across devices.

## Mobile Channel Architecture

The mobile channels in AnythingLLM 1.12 connect to locally hosted LLM instances, allowing queries and interactions to be processed through private infrastructure rather than cloud-based services. This approach preserves data privacy while extending LLM functionality to mobile platforms, addressing the growing need for on-the-go access to AI assistants without compromising security requirements.

## Use Cases and Implementation

Organizations using [[concepts/self-hosted-llms|self-hosted LLMs]] can now extend their deployment to support mobile workflows. Users maintain the same privacy guarantees and model configurations across both desktop and mobile interfaces, creating a unified experience regardless of access point. This integration is particularly relevant for enterprises handling sensitive data that cannot be transmitted to external LLM services.
