# Home Screen App List Access

A feature enabling direct navigation to the [[concepts/app-drawer|App Drawer]] from the Home Screen via a dedicated option in the home screen overlay menu.

## Key Changes

- [[entities/android-16|Android 16]] adds a new "App list" option to the home screen overlay menu, providing direct access to the App Drawer (see [[entities/android|Android]] 16 review).
