# Google Search Operators

Specialized [[concepts/commands|commands]] used within [[concepts/google-search]] to refine queries, filter noise, and optimize [[concepts/knowledge-bases|Information Retrieval]] precision.

## Fundamental Operators
- `"phrase"`: Forces an exact match of the specified string.
- `-term`: Excludes specific words from the search results.
- `site:[domain]`: Restricts results to a specific website or Domain.
- `filetype:[extension]`: Filters results by file format (e.g., `pdf`, `doc`, `csv`).
- `intitle:[keyword]`: Searches for the keyword specifically within the page title.
- `related:[url]`: Identifies websites with similar content to the provided URL.
