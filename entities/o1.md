# O1

O1 is an AI model developed by [[entities/openai|OpenAI]], introduced as part of their [[concepts/reasoning|reasoning]]-focused model series. The model is designed to tackle complex problems across [[concepts/mathematics|mathematics]], [[concepts/science|science]], [[concepts/coding|coding]], and [[concepts/open-source-philosophy|logic]] by using extended reasoning processes before generating responses.

## Capabilities

O1 excels at tasks requiring [[concepts/multi-step-reasoning|multi-step reasoning]] and [[concepts/problem-solving|problem-solving]]. It is particularly noted for performance on technical benchmarks, including standardized tests and competitive programming challenges. The model uses a "chain of thought" approach internally, allowing it to work through problems methodically rather than generating immediate responses.

## Release and Availability

[[concepts/whisper-transcription|OpenAI]] released O1 as a limited preview, making it available to select users before broader deployment. The model represents OpenAI's direction toward reasoning-oriented [[concepts/ai-models|AI systems]], positioning it as distinct from faster, more [[concepts/general-purpose-models|general-purpose models]] in their product lineup.
