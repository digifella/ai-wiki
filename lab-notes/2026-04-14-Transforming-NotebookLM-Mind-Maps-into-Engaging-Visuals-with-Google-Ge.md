## Transforming NotebookLM Mind Maps into Engaging Visuals with Google Gemini
**Clip title:** [[entities/notebook-lm|Notebook LM]] MindMaps + [[entities/gemini|Gemini]] = Stunning Mindmaps + Interactive Visuals
**Author / channel:** AI and Tech for Education
**URL:** https://www.youtube.com/watch?v=m25BiEBU7GU

### Summary
This video showcases three distinct workflows for transforming basic information and [[concepts/mind-maps|mind maps]] generated in [[concepts/notebooklm|NotebookLM]] into more visually engaging and interactive formats using [[entities/google-gemini|Google Gemini]]. The overarching goal is to enhance the clarity, [[concepts/design|design]], and usability of learning and presentation materials through [AI-powered visualization](https://en.wikipedia.org/wiki/AI-powered_visualization).

Firstly, the video demonstrates how to convert a standard, text-heavy mind map generated by [[concepts/ai-integrated-notebooks|NotebookLM]] (based on sources about "how [[concepts/memory|memory]] works") into a vibrant, infographic-[[concepts/style|style]] [radial mind map](https://en.wikipedia.org/wiki/Radial_mind_map). This involves downloading the basic mind map as an image from NotebookLM, uploading it to [[entities/gemini-models|Google Gemini]], and then using a detailed prompt to instruct Gemini to create a [radial layout](https://en.wikipedia.org/wiki/Radial_layout). Key prompt elements include centering the main concept, balancing branches, using consistent colors and icons for different themes, and keeping [[entities/nodejs|node]] labels concise. This [[concepts/workflow|workflow]] results in a clear, aesthetically pleasing visual that is much easier to digest than the original linear format.

Secondly, the video illustrates generating a detailed [process flowchart](https://en.wikipedia.org/wiki/Process_flowchart) from an entire [[concepts/notebooklm-notebook|NotebookLM notebook]] on "how to learn a new skill." Instead of exporting a mind map, the full NotebookLM content is imported directly into Gemini. A specific prompt guides Gemini to create a linear, directional flowchart, breaking down the skill acquisition process into distinct phases with sequential steps, arrows indicating [[concepts/flow|flow]], and decision points. This visually maps out a complex process, making it highly understandable. The video emphasizes that this method works best when the source content naturally contains clear stages or processes.

Finally, the third workflow takes a previously generated visual mind map (like the radial one from the first workflow) and transforms it into an interactive mind map dashboard using Gemini's "[[concepts/canvas|Canvas]]" feature. The prompt focuses on creating a minimalist, professional [[concepts/design|design]] with a [[concepts/light|light]] background and structured layout. The interactive element allows users to click on different sections of the mind map, which then expands to reveal detailed information for that specific node while fading the rest of the map to maintain focus. This creates a dynamic and explorable learning tool, moving beyond static [[concepts/images|images]] to offer a more immersive experience.
