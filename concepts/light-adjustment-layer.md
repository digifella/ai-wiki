# Light Adjustment Layer

A feature in [[entities/adobe-photoshop]] designed to control lighting effects, specifically introducing a dedicated **[[concepts/glow-slider|Glow Slider]]** for precise luminance [[concepts/adjustments|adjustments]]. This tool allows users to apply [[entities/glow|glow]] effects without manually creating complex [[concepts/layer-masks|layer masks]] or [[concepts/layer-styles|blend modes]]. It integrates [[entities/camera-raw|Camera Raw]]'s powerful tonal controls into a non-destructive layer format.

## Key Features
- **Glow Slider**: Simplifies the application of glow effects through a single control interface.
- **[[concepts/semi-automatic-camera-modes|Light Adjustment Layer]]**: Provides non-destructive [[concepts/lighting-control|lighting control]], distinct from traditional [[concepts/exposure|exposure]] or levels adjustments.
- **[[concepts/prompt-to-edit|Prompt to Edit]]**: Integration of [[concepts/ai-powered-editing|AI-driven editing]] capabilities to modify lighting based on natural language [[concepts/commands|commands]].
- **Tonal Controls**: Brings [[concepts/camera-raw|Camera Raw]]'s comprehensive [[concepts/color-enrichment|tonal adjustment]] tools directly into the layer workflow.
