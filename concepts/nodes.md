# Nodes

Fundamental units in graph structures representing **entities** (e.g., people, documents, concepts) connected via **edges**. Nodes may contain properties/attributes and form the basis of relationship modeling.

**Key Applications:**
- In [[concepts/graph-retrieval-augmented-generation|GraphRAG]], nodes represent entities (e.g., documents, key concepts) while edges encode [[concepts/relationships|relationships]] between them
- Enables [[concepts/context-aware-retrieval|context-aware retrieval]] beyond single-document matching
- Powering cost-effective [[concepts/local-rag|local RAG]] with [[concepts/llama-31]] via [[entities/neo4j]] [[concepts/graph-databases|graph databases]]
