# AI Art Tools

AI Art Tools refers to software applications and frameworks that utilize [[concepts/ai-technologies|artificial intelligence]], primarily [[concepts/generative-ai|generative models]], to create visual content. Key platforms include [[entities/stable-diffusion|Stable Diffusion]], [[entities/midjourney|Midjourney]], and [[entities/dall-e|DALL-E]].

## Core Platforms & Interfaces

- **[[entities/comfyui|ComfyUI]]**: A node-based graphical interface for Stable Diffusion, offering high [[concepts/customization|customizability]] and [[concepts/ai-driven-workflow-automation|workflow automation]] capabilities.
- **[[entities/automatic1111|Automatic1111]]**: The most popular web UI for Stable Diffusion, known for its extensive feature set and community support.
- **[[concepts/cloud-based-services|Cloud Services]]**: Platforms like [[entities/midjourney|Midjourney]] and [[entities/dall-e|DALL-E]] provide accessible, API-driven generation without local [[concepts/hardware-compatibility|hardware requirements]].
