# Claude Code

**[[entities/claude|Claude]] Code** is an agentic AI coding tool developed by [[entities/anthropic|Anthropic]]. It enables developers to perform complex [[concepts/software-engineering|software engineering]] tasks through natural language interaction.

## Core Capabilities & Frameworks
- **[[concepts/ai-adoption-levels|AI Adoption Levels]]**: Utilizes [[entities/boris-cherny|Boris Cherny]]'s framework to guide adoption from basic usage to "God Mode" productivity.
- **[[concepts/context-management|Context Management]]**: Optimized via [[entities/graft|Graft]], a [[concepts/context-layer|context layer]] tool that enhances performance and reduces costs.
- **[[concepts/automated-diagnostic-analysis|Autonomous Optimization]]**: Employs the [[concepts/karpathy-loop|Karpathy Loop]] methodology for [[concepts/ai-operator|autonomous agent]] refinement.

## Claude Code Mods
Anthropic has introduced "Mods" to allow deep [[concepts/customization|customization]] of the AI's behavior and [[concepts/user-interface|user interface]]. This feature represents a shift from external extensions to internal control.

- **Deep Customization**: Unlike "skills" (which instruct *how* to perform tasks) or "connectors" (which link to external apps), Mods directly alter Claude Code's internal workings.
- **Internal Control**: Provides core-integrated customization that surpasses the capabilities of [[concepts/mcp-server|MCP servers]], hooks, and standard skills.
- **Productivity Impact**: Enables significant changes to workflow and UI, as detailed in recent analyses.
