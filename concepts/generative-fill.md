# Generative Fill

Generative Fill is a feature within Adobe Firefly that enables users to modify images through natural language prompts. Rather than relying on traditional selection tools and manual editing techniques, users describe their desired changes in text form, and the system generates content to match the description. This approach combines conventional image editing workflows with AI-assisted content generation, reducing the technical skill required for complex image modifications.

## How It Works

Users select or define an area within an image and provide a text description of what they want to appear in that space. The AI model then generates new image content based on the prompt, attempting to match the style, lighting, and composition of the surrounding image. The generated content can be regenerated multiple times to explore different variations until the user finds a satisfactory result.

## Applications

Generative Fill is used for tasks such as removing unwanted objects, extending backgrounds, filling gaps in compositions, or adding new elements to images. It can also be applied to modify existing content—for example, changing the appearance of an object or adjusting environmental details without manually recreating sections of an image.
