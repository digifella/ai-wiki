# Scoped Subgraphs

Scoped subgraphs are bounded network graph structures derived from larger stakeholder graph views and filtered to specific organizational or security contexts. Generated by the Cortex-side network graph job, they constrain the broader network to include only nodes and edges relevant to particular use cases, ensuring that graph analysis remains operationally focused and contextually appropriate.

## Generation and Scoring

The network graph job processes scoped subgraphs by scoring both nodes and edges within each bounded context. This scoring mechanism evaluates the significance of individual components based on their relevance to the defined scope. By assigning quantitative values to graph elements, the system prioritizes critical connections and entities, allowing downstream processes to focus on high-value data points while ignoring noise from the wider network.

## Signal Emission

Following the scoring phase, the job emits specific signals to support operational workflows. These include warm-intro signals, which facilitate initial connections between relevant entities, and shared-al signals, which indicate common attributes or relationships across the scoped environment. These outputs enable other platform components to leverage the refined graph data for targeted analysis and decision-making without processing the entire stakeholder graph.
