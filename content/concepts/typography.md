# Typography

Typography is the [[concepts/art|art]] and technique of arranging type to [[entities/make|make]] written language legible, readable, and appealing when displayed. It involves selecting typefaces, point sizes, line lengths, line-spacing (leading), and letter-spacing (tracking).

### Key Concepts
- **Legibility**: The extent to which letters in a font are different from each other.
- **Readability**: How easily [[concepts/text|text]] can be read over prolonged periods of time.
- **[[concepts/hierarchy|Hierarchy]]**: Using typography to create [[concepts/visual-hierarchy|visual hierarchy]] by varying font sizes, [[concepts/weights|weights]], styles, and colors.
- **Grids**: Layout systems that provide [[concepts/structure|structure]] for arranging elements on a page.
