## NotebookLM Mind Map to Interactive HTML Site with Gemini AI
**Clip title:** How to Turn a [[entities/notebooklm|NotebookLM]] Mind Map into an Interactive Site
**Author / channel:** Charles Terrence [[entities/harper|Harper]]
**URL:** https://www.youtube.com/watch?v=3tPzeQX0KVE

### Summary
This video demonstrates a comprehensive [[concepts/workflow|workflow]] for transforming a static
[[concepts/notebooklm|NotebookLM]] mind map into an interactive, self-contained HTML [[concepts/web-application|web application]] complete with an [[concepts/audio-overview|audio overview]]. The process leverages the
capabilities of both [[entities/notebooklm|NotebookLM]] for [[concepts/content-generation|content generation]] and [[entities/google-gemini|Google Gemini]]
([[entities/ai-studio|AI Studio]]) for advanced [[concepts/prompt-engineering|prompt engineering]] and [[concepts/web-development|web development]], concluding
with a publishable asset that can be shared with clients or hosted online.

The initial [[concepts/phase|phase]] involves setting up [[concepts/ai-integrated-notebooks|NotebookLM]] to serve as the "brain"
for content. The [[concepts/creator|creator]] starts with an existing [[concepts/notebooklm-notebook|NotebookLM notebook]] and
generates a mind map from its sources. While NotebookLM's native mind map
generation isn't directly customizable, the video shows how to use
NotebookLM's [[concepts/chat-interface|chat interface]] to prompt for a custom, more targeted mind map
or [[concepts/infographic|infographic]] based on specific content requirements (e.g., for "Kindle
mystery writers"). These generated visual assets, though initially
watermarked if exported directly, provide the [[concepts/structured-data|structured data]] foundational
to the project. Furthermore, NotebookLM is utilized to produce a concise
audio overview of the mind map content, guided by a precise prompt from
[[concepts/gemini|Gemini]].

The next critical step involves building the interactive application within
[[entities/google-ai-studio|Google AI Studio]], primarily using [[concepts/gemini|Gemini]]'s [[concepts/prompt-engineering|prompt engineering]] capabilities.
[[entities/gemini|Gemini]] is first tasked with crafting a prompt designed to generate a
fast-paced, structured audio overview that logically follows the mind map's
branches. This prompt is then applied within NotebookLM's audio overview
feature. Subsequently, Gemini is instructed to act as an expert [[concepts/frontend-development|front-end]]
web [[entities/developer|developer]], integrating the downloaded mind map image, a custom
[[concepts/infographic|infographic]] (also generated via Gemini from the mind map's [[concepts/structure|structure]]), and
the NotebookLM-produced audio file. The detailed prompt specifies
requirements for a single, responsive HTML file, including embedded CSS and
JavaScript, an [HTML5 audio player](https://en.wikipedia.org/wiki/HTML5_audio_player), visual display of both [[concepts/images|images]] with zoom
functionality, and an interactive checklist/accordion reflecting the mind
map's structure.

The culmination of this process results in a complete, production-ready
HTML, CSS, and JavaScript file generated by Gemini. The [[entities/creator|creator]] downloads
this code along with the audio and image assets, then places them in the
same local folder. A minor manual adjustment to image filenames in the HTML
code is necessary due to Gemini's placeholder naming. Once opened in a web
browser, the interactive HTML file presents a polished interface with a
sticky audio player, a clickable companion checklist that expands to reveal
details, and zoomable versions of the infographic and original mind map.
This entire workflow, from initial [[concepts/content-generation|content generation]] to final interactive
web app, can then be encapsulated and replicated as a "Gem" within Gemini,
streamlining future projects by automating the multi-step process for any
new mind map. The resulting interactive app is completely independent of
Google services, making it highly portable and easily distributable.
