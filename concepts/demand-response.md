# Demand Response

Demand response is a program that incentivizes consumers to reduce their electricity usage during peak times. It aims to improve grid [[concepts/software-reliability|reliability]] and efficiency by shifting the load from high-demand periods to lower ones. This can be achieved through voluntary actions, such as reducing non-critical power use during certain hours or days, or automatic [[concepts/causes|mechanisms]] like smart appliances adjusting settings based on real-time [[concepts/pricing|pricing]] signals.

## Key Concepts
- Load management: Techniques used to control and manipulate the electric demand.
- Peak shaving: The practice of reducing peak electricity demand.
- Smart grid: An [[concepts/electricity-grid|electrical grid]] that uses digital technology to detect and [[entities/react|react]] to local changes in usage.
- Distributed energy resources (DER): Small-scale power generation technologies located close to where electricity is consumed.
