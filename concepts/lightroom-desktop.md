# Lightroom Desktop

**[[entities/adobe|Adobe]] [[entities/lightroom-classic|Lightroom Classic]]** is the desktop-based [[concepts/photo-management|photo management]] and editing application within the [[concepts/adobe|Adobe Creative Cloud]] ecosystem. It serves as the primary [[concepts/non-destructive-workflow|non-destructive editing]] environment for professional photographers, offering deep integration with [[concepts/adobe-camera-raw]], DNG, and cloud-synced workflows via [[entities/lightroom-cc|Lightroom Cloud]].

## Key Features & Capabilities

*   **[[concepts/non-destructive-editing|Non-Destructive Editing]]:** All [[concepts/adjustments|adjustments]] are stored in sidecar XMP files or the [[concepts/catalog|catalog]] database, preserving original image data.
*   **[[concepts/flags|Catalog Management]]:** Centralized database for organizing, tagging, and rating large volumes of images.
