# Model Context and Protocol (MCP)

A [[concepts/universal-standard|universal standard]] for [[concepts/ai-connectors|AI connectors]] designed to enable seamless interoperability between [[concepts/ai-models|AI models]] and [[concepts/external-data|external data]] sources or tools.

## Key Trends & Applications
- **[[concepts/workflow|Workflow]] Transformation**: Driving a fundamental shift in [[concepts/design|design]] and creative workflows toward [[concepts/cli-tools|command-line interaction]] and automated processes.
- **Tool Ecosystem**: Serving as a critical [[concepts/integration|integration]] layer for emerging tools such as [[entities/google-stitch]], [[entities/remotion]], and [[entities/blender-mcp]].
- **[[concepts/cost|Operational Efficiency]]**: Enabling the use of [[concepts/markdown|Markdown]] [[concepts/files|files]] to replace traditional, high-[[concepts/cost|cost]] design meetings.
- **[[concepts/local-llm|Local LLM]] Integration**: Enabling [[concepts/privacy|privacy]]-focused local LLMs (e.g., [[entities/ollama]]) to interact with external services (e.g., [[entities/zapier]]) via MCP, as demonstrated in the date 2026 0
- **Agentic Evolution**: Transforming [[concepts/ai-chatbots|AI chatbots]], such as [[entities/claude-code|Claude Code]], into powerful [[concepts/ai-agents|AI agents]].
- **Universal Connectivity**: Acting as a "[[concepts/universal-plug|universal plug]]" that allows [[concepts/ai-models|AI models]] to bypass the limitations of manual data uploads by directly accessing [[concepts/external-data|external data]] sources and systems.
