## Hermes Agent 0.17 Update: iMessage, Background Agents, Unreal Engine Integration

### Summary
The video introduces [[concepts/agentic-ai|Hermes Agent]] 0.17, highlighting it as the "biggest update ever" and claiming it surpasses [[concepts/automated-information-pipelines|OpenClaw]] in functionality. The presenter outlines eight significant changes aimed at enhancing the agent's capabilities and user [[concepts/experience|experience]] across various platforms.

A major update is native iMessage support, allowing users to interact with their Hermes agent directly from their [[entities/iphone|iPhone]]. This includes asking questions or issuing [[concepts/commands|commands]] for tasks on the computer, making it ideal for quick, on-the-go interactions, facilitated by the free Photon service. For more complex, long-running tasks, Hermes now automatically utilizes "Background Agents." This allows the main agent to spin up [[concepts/sub-agents|sub-agents]] that perform work in parallel, enabling continuous user interaction while the background tasks proceed. A new sub-agent tree visually tracks all active sub-agents and their tool calls. Additionally, the new Profile Builder simplifies the creation and management of multiple [[entities/hermes-agents|Hermes agents]], each configured with specific models and [[concepts/skills|skills]] through an improved onboarding experience.

The update also extends Hermes's capabilities into development, with new support for Unreal [[concepts/engine|Engine]] 5.8 MCP ([[concepts/mixed-reality|Mixed-Reality]] [[concepts/digital-compositing|Compositing]] Platform). This integration allows users to [[concepts/leverage-ai|leverage AI]] for building sophisticated 3D games, moving beyond simpler browser-based engines. The Desktop App itself received numerous [[concepts/quality-of-life|quality-of-life]] improvements, including the ability to open multiple chat sessions in separate [[entities/windows|windows]] for enhanced multitasking, a quick model selector at the bottom of the interface, and a built-in [[concepts/cli|terminal]], eliminating the need to switch between applications. A brand new Skills Hub, accessible via the Hermes dashboard, now offers a centralized repository to browse, install, and even security-scan hundreds of new skills.

Furthermore, Hermes Agent 0.17 features "Smarter [[concepts/memory|Memory]] Edits," a continuous [[concepts/self-improvement|self-improvement]] mechanism where the agent actively creates, updates, and refines its own skills based on interactions and tasks. This leads to significantly improved performance and [[concepts/resilience|adaptability]] over time, requiring no direct user action beyond providing more prompts and commands. Finally, the integration with Telegram has been enhanced with "Better Telegram Formatting," allowing Hermes to produce richer, more organized outputs, including tables, lists, and various bolding and streaming effects, making data and information easier to consume within the [[concepts/communication|messaging]] app.

In conclusion, the Hermes Agent 0.17 update delivers a comprehensive suite of enhancements that significantly boost its versatility, efficiency, and user-friendliness across various platforms and [[concepts/scenarios|use cases]]. The core takeaway is that users now have "super intelligence at their fingertips," capable of [[concepts/complex-tasks|complex tasks]], game development, and self-improvement. The presenter emphasizes that many of these advanced features can be activated and utilized simply by instructing the Hermes agent to do so, highlighting its intuitive, command-driven nature.
