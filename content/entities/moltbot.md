# Moltbot

[[concepts/local-ai-assistants|Moltbot]] is a robotic claw project implemented on [[entities/raspberry-pi|Raspberry Pi]] [[concepts/hardware|hardware]]. The project was originally named [[concepts/remote-chat|Clawdbot]] before being renamed to Moltbot. It was documented and demonstrated in a video by [[entities/gary-explains|Gary Explains]], a technology education channel.

## Development and Implementation

The project represents an attempt to create a functional robotic claw system using accessible hardware. The choice of Raspberry Pi as the computing platform makes it a relatively affordable option for [[concepts/robotics|robotics]] experimentation compared to some commercial alternatives. According to project documentation, [[concepts/cost|cost]] considerations were a factor in the [[concepts/design|design]] decisions, particularly when evaluating other claw solutions like [[concepts/automated-information-pipelines|OpenClaw]].
