# Practical Commands

Practical Commands represent a collection of actionable concepts derived from Sandy Lee AI's educational materials on [[concepts/ai-assisted-coding|Claude Code]], designed to make technical functionality accessible to non-technical users. These [[concepts/commands|commands]] bridge the gap between abstract programming concepts and their real-world [[concepts/software|applications]], focusing on what users need to do rather than how the underlying systems work.

The framework emphasizes clarity and usability by breaking down complex tool interactions into understandable steps. Rather than requiring users to understand code syntax or system [[concepts/architecture|architecture]], Practical Commands allow users to accomplish tasks through [[concepts/conceptual-understanding|conceptual understanding]] of what actions are available and when to use them. This approach acknowledges that effective technology use doesn't necessarily require technical expertise.

These commands are situated within broader discussions of [[concepts/ai-agent|AI agent]] capabilities and the [[concepts/agentic-loop|agentic loop]]—the cycle through which AI systems interpret requests, execute actions, and deliver results. Understanding Practical Commands helps users recognize what types of requests yield actionable outcomes and how to frame their needs in ways that align with available tools and capabilities.
