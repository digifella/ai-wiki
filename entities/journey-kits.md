# Journey Kits

Journey Kits is a software project that has become a documented case study regarding the financial implications of AI-assisted development workflows. The project gained public attention through an analysis by technology commentator Matthew Berman, whose video examination titled "The dark side of vibe coding" highlighted significant and unexpected billing overruns. These costs were incurred during the deployment of the project on Vercel's cloud infrastructure platform.

The deployment demonstrated how AI-assisted coding workflows, while potentially accelerating development velocity, can generate substantial cloud infrastructure expenses. The case serves as a practical example of the hidden costs associated with rapid, AI-driven software creation, specifically focusing on the disparity between development speed and operational billing.
