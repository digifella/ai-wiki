# Bootcamp Sessions

Bootcamp Sessions are guided learning experiences within the Vyond platform designed to help users create animated videos. These sessions provide structured tutorials and hands-on practice for both new and experienced users working with Vyond's animation tools. They serve as an onboarding and skill development resource, enabling users to build proficiency with the platform's core features and workflows.

## AI Assistance

Bootcamp Sessions integrate AI assistance features that support users throughout the learning process. ## Stock Characters in Vyond Go

Within Vyond Go, Bootcamp Sessions help users understand how to select and work with stock characters. The sessions provide instruction on accessing the character library, customizing character selections, and incorporating them into animations as part of the broader animation creation workflow.
