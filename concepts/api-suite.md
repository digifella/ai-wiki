# API Suite for Building and Deploying Autonomous AI Agents

**[[entities/claude|Claude]] [[concepts/managed-agents|Managed Agents]]**: A comprehensive suite of [[concepts/open-standard-protocols|APIs]] aimed at facilitating the development and deployment of [[concepts/agentic-systems|autonomous agents]]. This platform empowers developers to create sophisticated agents with tailored personas, tools, and capabilities while also providing [[concepts/secure|secure]] [[concepts/sandbox-environments|sandbox environments]] equipped with necessary packages and [[concepts/network-controls|network controls]].

## Key Features
- **Agent Definition**: Developers can define specific agent attributes such as personality traits, tool integrations, and functional abilities.
- **[[concepts/sandbox-environments|Sandbox Environments]]**: Securely isolated spaces for testing and deploying agents without risking the broader system.
- **Orchestrated Sessions**: Agents operate within structured sessions to ensure efficient and effective [[concepts/workflow-automation|task execution]].
