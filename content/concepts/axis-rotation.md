# Axis Rotation

Axis Rotation refers to the three-dimensional manipulation of two-dimensional [[concepts/images|images]], a capability enabled by the [[concepts/2d-image-rotation|AI Rotate Object]] tool available in [[concepts/beta-version|Photoshop Beta]]. This feature allows users to rotate flat, 2D photographs and images along multiple axes, creating the visual effect of viewing the image from different angles or perspectives. Rather than simply warping or stretching the original content, the tool generates plausible visual information to fill areas that would be revealed by the rotation.

## Technical Approach

The AI Rotate Object tool uses machine [[concepts/learning|learning]] to analyze image content and infer how surfaces and objects should appear when viewed from different angles. This approach allows the tool to create reasonable extensions of the image geometry without requiring explicit 3D modeling. The generated content aims to maintain visual [[concepts/logical-consistency|consistency]] with the original image's style, lighting, and subject matter.

## Practical Use

Users can apply axis rotation to photographs and illustrations to explore alternative viewpoints or create dynamic compositional variations. The tool is particularly useful for visualizing how an image might appear if the camera angle or subject orientation had been different at the time of capture. This capability bridges 2D image editing and 3D visualization without requiring the user to work with 3D models or complex technical workflows.
