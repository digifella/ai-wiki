# C Language

C is a general-[[concepts/motivation|purpose]], procedural programming language created in the early 1970s by Dennis Ritchie [[concepts/assistive-technology|at]] Bell [[entities/labs|Labs]]. It emerged as an evolution of the earlier B language and was designed to provide a balance between low-level [[concepts/hardware|hardware]] access and high-level [[concepts/abstraction-layer|abstraction]]. C became foundational to modern computing, serving as the [[concepts/adoption|implementation]] language for Unix and influencing the [[concepts/design|design]] of countless subsequent languages including C++, C#, Java, and JavaScript.

## Core Characteristics

C is characterized by a minimal set of [[concepts/keywords|keywords]], a simple syntax, and direct [[concepts/memory|memory]] manipulation through pointers. These features grant programmers fine-grained [[concepts/power|control]] over system resources while remaining relatively portable across different hardware platforms. The language relies on explicit [[concepts/memory-management|memory management]] rather than automatic garbage collection, placing responsibility on developers to allocate and deallocate memory correctly.

## Influence and Use

The simplicity and efficiency of C made it the preferred language for operating systems, embedded systems, compilers, and performance-critical [[concepts/software|applications]] throughout the late 20th century. Despite the emergence of higher-level languages, C remains widely used in industry and is standard in computer [[concepts/science|science]] education. Its design principles have shaped programming language [[concepts/theory|theory]] and practice for decades.
