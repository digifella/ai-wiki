# Gemini 3.0 Pro

Google's advanced AI model for complex [[concepts/reasoning|reasoning]] and multi-step task execution, designed to handle sophisticated user queries and generate high-quality content.

## Key Features
- **[[concepts/advanced-reasoning|Advanced reasoning]]**: Capable of "[[concepts/human-cognition|thinking]]" through complex layouts (demonstrated in [[entities/google-stitch]] 2.0).
- **Integrated with [[concepts/google-search|Google]] products**: Powers [[concepts/ai-design-agent|AI design agent]] [[entities/google-stitch]] 2.0 for rapid UI [[concepts/design|design]] generation.
