# Adobe Firefly

[[entities/adobe|Adobe]] Firefly is [[concepts/adobe|Adobe]]'s [[concepts/generative-ai|generative AI]] model for creating and editing images, integrated into [[entities/creative-cloud|Creative Cloud]] applications like [[concepts/photoshop|Photoshop]], Illustrator, and Express. It enables [[concepts/text-to-image-generation|text-to-image generation]], [[concepts/image-editing|image editing]], and [[concepts/style|style]] transfer using natural [[concepts/natural-language-prompting|language prompts]].

## Key Features

- **[[concepts/layer-control|Prompt-to-Edit]]**: Allows direct image modification via natural language prompts (e.g., "make the sky bluer"), distinct from [[concepts/photoshop|Photoshop]] [[concepts/generative-fill|Generative Fill]] in workflow focus. Both support [[concepts/iterative-refinement|iterative refinement]] for materials/textures/mood, but Firefly's implementation prioritizes intuitive [[concepts/instruction-based-editing|prompt-based editing]] within its interface.
  - Detailed comparison with Photoshop's [[concepts/generative-fill|Generative Fill]] in [[entities/julianne-kost|Julianne Kost]]'s video (2026-04-14).
- **[[concepts/text-to-image-generation|Text-to-Image Generation]]**: Creates original images from descriptive text prompts using Adobe's proprietary model trained on licensed content.
- **Generative Fill Integration**: Works alongside [[entities/adobe-photoshop|Adobe Photoshop]] for enhanced editing capabilities.
