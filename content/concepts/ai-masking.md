# AI Masking
[[concepts/ai-based-selection|AI Masking]] is a feature that utilizes [[concepts/ai-technologies|artificial intelligence]] to automatically create accurate masks for various elements within an image. This technology is particularly useful in [[concepts/software|software]] [[concepts/software|applications]] such as [[entities/adobe-photoshop|Adobe Photoshop]] and [[concepts/lightroom|Lightroom Classic]], where it significantly speeds up the editing process by automating tedious tasks like [[concepts/layer-masks|masking]].
