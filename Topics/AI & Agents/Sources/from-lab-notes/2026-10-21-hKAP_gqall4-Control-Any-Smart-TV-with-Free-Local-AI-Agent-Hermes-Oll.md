## Control Any Smart TV with Free Local AI Agent (Hermes + Ollama)
**Clip title:** Control Any Smart TV with Free Local AI Agent (Hermes + Ollama)
**Author / channel:** Fahd Mirza
**URL:** https://www.youtube.com/watch?v=hKAP_gqall4

### Summary
Sure! Here is a summary of the video content:

The video discusses how to modernize an older smart TV using a local, free AI model. The speaker demonstrates this process on a 10-year-old LG TV, but notes the steps apply to any smart TV. The key steps include enabling developer mode on the TV, obtaining its IP address, and connecting an AI coding agent. The speaker uses the Hermes agent and the Qwen3 model, running locally via Ollama. 

The video provides specific instructions for both LG and Android TVs. For LG TVs, users must install the "Developer Mode" app from the LG App Store, log in, and enable developer mode. For Android TVs, users go to settings, click the OS build number seven times to enable developer mode, and turn on USB debugging. The speaker emphasizes the importance of getting the TV's IP address from the network settings.

The speaker then demonstrates how to install and configure the Hermes agent and Ollama. A specific prompt is provided in the speaker's GitHub repository, designed to instruct the AI agent to ask before making changes, turn off apps instead of deleting them, and keep an undo list. This ensures the TV is not accidentally broken. The speaker encourages viewers to try the method, experiment with prompts, and factory reset the TV if anything goes wrong.
