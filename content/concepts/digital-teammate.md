# Digital Teammate

An AI-powered assistant that collaborates with humans in [[concepts/automation-tools|workflow automation]], providing expertise and task execution without requiring constant human supervision.

Examples:
* **[[entities/claude-co-work|Claude Cowork]]**: A tool for building automated marketing workflows using the [[entities/claude|Claude]] ecosystem ([[concepts/claude-chat|Claude Chat]] for planning, [[entities/claude-cowork|Claude Cowork]] for workflow building, [[concepts/claude-code|Claude Code]] for code generation) (see 2026 04 14 [[concepts/claude-ai|Claude]] coworker [[entities/grace-leung|Grace Leung]] channel).
