## Conway's Base 13 Function: Explaining its Unique Mathematical Definition
**Clip title:** Conway's Base 13 Function - Numberphile
**[[entities/tasia-custode|Author]] / channel:** Numberphile
**URL:** https://www.youtube.com/watch?v=zsBaApyf_Ns

### Summary
This [[entities/numberphile|Numberphile]] video introduces [[concepts/conways-base-13-function|Conway's Base 13 Function]], a mathematical concept designed by [[entities/chef-john|John]] Horton Conway, which challenges our intuitive understanding of what a function can represent. The presenter, [[entities/asaf-karagila|Asaf Karagila]], begins by explaining the common perception of a function: a rule that assigns a unique output (y) to every input (x), often visualized as a continuous or discontinuous graph. He illustrates this with simple examples like `f(x) = x^2 + 1` and also highlights step functions, which, despite jumps, still adhere to the unique output rule. The core idea is that for any given input, the function's output is predetermined and constant.

To understand Conway's function, the video first delves into number bases, specifically base 13. Unlike the familiar base 10 system with digits 0-9, base 13 requires thirteen unique symbols. Conventionally, this is achieved by using 0-9 followed by A, B, and C to represent values 10, 11, and 12, respectively. Thus, in base 13, the number 13 is written as "10". Any real number can be expressed in base 13, similar to how [[concepts/irrational_number|irrational numbers]] like Pi have infinite decimal expansions in base 10. This foundational understanding of alternate [[concepts/number-systems|number systems]] is crucial for comprehending the intricate definition of Conway's function.

Conway's function operates by taking a real number expressed in base 13 and converting it into a real number in base 10 through a specific, albeit complex, set of rules. The function scans the [[concepts/base-13-representation|base 13 representation]] for specific patterns of digits, particularly looking for the non-standard digits A, B, or C. For example, if the last 'A' in the base 13 sequence is followed by a run of only 0-9 digits and then a 'B', those 0-9 digits are interpreted as a decimal number, and 'A' dictates the sign (positive), while 'B' marks the end of this interpretable sequence. If a number's base 13 expansion doesn't conform to these specific patterns (e.g., an infinite sequence of A's, B's, or C's after a certain point), the function is defined to output 0. The key takeaway here is that while the [[concepts/algorithm|algorithm]] guarantees a unique base 10 output for any given base 13 input, many vastly different base 13 inputs can result in the same base 10 output.

The truly mind-blowing aspect of Conway's Base 13 Function emerges when considering its graph. Due to its construction, any real number (e.g., Pi or the square root of 2) can be found as the output of the function for an infinite number of different inputs. Moreover, these inputs can be arbitrarily close to each other on the x-axis. If one were to graph this function, zooming out would reveal that the graph appears to fill the *entire* two-dimensional plane. This defies the intuitive [[entities/notion|notion]] of a function having a single, discernible line or curve. Despite this chaotic visual and many-to-one mapping, it remains a mathematically valid function because its rule is consistently applied, producing a unique result for each specific input. The number 13 is not inherently special beyond providing convenient symbols for the [[concepts/algorithm|algorithm]]; the same principle could apply to other bases.
