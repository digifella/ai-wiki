# Raspberry Pi

The Raspberry Pi is a small, affordable single-board computer designed for educational purposes and hobbyist projects. Originally developed by the Raspberry Pi Foundation, it has become widely used as [[concepts/hardware|hardware]] for personal computing tasks ranging from basic programming education to more complex infrastructure [[concepts/software|applications]].

## Self-Hosting and Personal Cloud Applications

Raspberry Pi devices serve as practical hardware platforms for self-hosting services and building personal cloud servers. Their low power consumption, compact size, and relatively modest processing [[concepts/capabilities|capabilities]] [[entities/make|make]] them suitable for [[concepts/running|running]] lightweight server applications, particularly when paired with appropriate software stacks and network configuration tools. Users can deploy services on Raspberry Pi hardware to maintain greater [[concepts/power|control]] over their data and reduce reliance on commercial cloud providers.

## Edge AI and IoT Deployment

The computing capabilities of Raspberry Pi devices support [[concepts/edge-ai|edge AI]] [[concepts/inference|inference]] and [[concepts/internet-of-things|Internet of Things]] applications. [[concepts/models|Models]] can be optimized to run directly on the hardware, enabling [[concepts/local-data-processing|local data processing]] without constant [[concepts/cloud-integration|cloud connectivity]]. This makes Raspberry Pi relevant for deployments requiring real-time [[concepts/responses|responses]] or operating in environments with limited network availability.
