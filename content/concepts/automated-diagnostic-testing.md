# Automated Diagnostic Testing

Automated diagnostic testing refers to systems that autonomously evaluate and optimize AI [[concepts/model-behavior|model behavior]] through iterative modification of test frameworks and evaluation criteria. Rather than relying on static, manually-designed test suites, these systems dynamically adjust their diagnostic harnesses—the structured frameworks used to measure performance—based on observed outcomes and identified gaps in test coverage. This approach enables continuous refinement of evaluation methods with minimal manual intervention between test cycles.

## Iterative Harness Modification

The core mechanism involves the systematic adjustment of test [[concepts/parameters|parameters]], metrics, and methodologies in response to model performance data. When a diagnostic system identifies areas where existing tests provide insufficient insight into model behavior, it can modify the evaluation harness to probe these gaps. This [[concepts/iterative-refinement|iterative process]] creates a [[concepts/feedback|feedback]] loop where evaluation frameworks evolve alongside the systems being tested, allowing for more comprehensive coverage of edge cases and failure modes than would be feasible with predetermined test suites.

## Self-Evolving Evaluation Systems

Automated diagnostic testing enables partial autonomy in the [[concepts/quality-assurance|quality assurance]] process by reducing dependency on human-designed test specifications. As AI systems themselves become more sophisticated, the challenge of comprehensively [[concepts/testing|testing]] them increases proportionally. Self-modifying diagnostic systems can adapt faster than manual test suite updates, though they require clearly defined optimization objectives and safeguards to ensure that evolved tests remain meaningful rather than optimizing for artifacts or becoming detached from genuine performance requirements.
