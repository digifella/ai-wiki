# Privacy Controls

Privacy Controls are configuration options within Claude Code that allow users to manage how their workflows, code, outputs, and personal data are processed and stored. These settings enable developers and organizations to enforce privacy practices aligned with their internal policies and regulatory requirements. By offering granular configuration capabilities, Privacy Controls form a foundational element of Claude Code's overall security posture and help users maintain control over sensitive information throughout their development workflow.

## Configuration Scope

Privacy Controls typically govern several key areas of system behavior, including data retention policies, output logging, workspace isolation, and access permissions. Users can adjust these settings to determine whether code snippets, execution results, and session data are retained for improvement purposes, stored locally, or transmitted to external systems. Organizations can enforce Privacy Controls across teams to ensure consistent compliance with data protection standards.

## Integration with Security Framework

Privacy Controls work in conjunction with Claude Code's broader security infrastructure to provide defense-in-depth protection. Rather than operating in isolation, these controls complement authentication mechanisms, encryption protocols, and access management systems. This integrated approach allows organizations to implement privacy-by-design principles, where data handling constraints are embedded directly into how developers interact with the tool rather than added as afterthought restrictions.
