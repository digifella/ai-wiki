# Instructions

Instructions are formal directives or guidelines provided to AI agents to shape their behavior, capabilities, and decision-making processes. In the context of Claude AI, instructions define how the model should approach tasks, interact with users, and execute specific functions or skills. They serve as the foundational layer for customizing agent behavior beyond the model's default training.

## Function in Agent Systems

Instructions operate as a control mechanism within agentic AI systems, establishing constraints and preferences that guide how an agent interprets requests and generates responses. Rather than relying solely on training data, instructions allow developers and users to specify desired behavior for particular contexts or use cases. This enables Claude to adapt its approach to domain-specific requirements, communication styles, or operational parameters without requiring model retraining. Instructions can range from high-level behavioral guidelines to detailed specifications for particular tasks or workflows.

## Practical Application

Effective instructions typically communicate purpose, relevant constraints, and expected output formats or quality standards. They work alongside other customization mechanisms like system prompts and skill definitions to create coherent agent behavior. Instructions are particularly valuable when deploying Claude for specialized applications where consistency and adherence to specific protocols matter—such as customer service, technical analysis, or content generation within defined parameters. The clarity and specificity of instructions directly influence how well an AI agent performs its intended function.
