# Planning Mode

Planning Mode is a feature integrated into [[concepts/google-search|Google]]'s [[concepts/open-source|open-source]] [[concepts/autonomous-coding|Gemini CLI]], a terminal-based [[entities/agent|agent]] designed to assist developers in [[concepts/command-line-interface|command-line]] environments. The feature enables the CLI to break down [[concepts/complex-tasks|complex tasks]] into structured steps before execution, allowing for more deliberate and transparent task completion. This capability reflects broader developments in [[concepts/ai-agent|AI agent]] [[concepts/design|design]] where explicit planning improves [[concepts/software-reliability|reliability]] and user understanding of agent behavior.

## Integration with Gemini CLI

The [[concepts/cli-tool|Gemini CLI]] represents [[entities/google|Google]]'s effort to [[entities/make|make]] their [[concepts/large-language-model|large language model]] accessible as a [[concepts/developer|developer]] tool within terminal workflows. Planning Mode functions as part of this toolkit, helping developers understand how the agent [[entities/will|will]] approach problems and providing checkpoints before actions are taken. This is particularly relevant for tasks involving system operations, where previewing intended actions reduces the risk of unintended consequences.

## Developer-Focused Design

By incorporating planning [[concepts/capabilities|capabilities]] into a [[concepts/command-line-interaction|command-line interface]], the tool targets workflows where developers already operate in terminal environments. The explicit planning step bridges the gap between natural language requests and system execution, making the agent's [[concepts/reasoning|reasoning]] visible and potentially adjustable before committal to action.
