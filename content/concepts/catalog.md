# Catalog

A catalog in [[concepts/lightroom|Lightroom]] is a database file that stores all organizational information about your image collection, including [[concepts/metadata|metadata]], [[concepts/keywords|keywords]], ratings, flags, and editing [[concepts/adjustments|adjustments]]. Rather than modifying the original image [[concepts/files|files]], Lightroom maintains a separate catalog that references your photos and records all changes non-destructively. This [[concepts/architecture|architecture]] allows photographers to manage large collections efficiently without altering the original files on disk.

## Purpose and Function

The [[concepts/lightroom-catalog|Lightroom catalog]] serves as the central hub for [[concepts/photo-management|photo management]] and [[concepts/photography-workflow|editing workflow]]. It tracks the location of every image in your collection, maintains a history of edits and adjustments, and enables quick searching and filtering through thousands of photos using metadata criteria. The catalog also stores virtual copies—alternate versions of the same photo with different editing treatments—without duplicating the original files.

## Organization and Performance

Effective [[concepts/flags|catalog management]] requires understanding how Lightroom stores and retrieves information. Photographers can organize [[concepts/images|images]] into folders and collections, apply hierarchical keywords and [[concepts/star-ratings|star ratings]], and use the catalog's search functions to locate specific photos. As catalogs grow larger, regular maintenance—including backing up the catalog file and optimizing its database—helps maintain performance and prevents data loss.
