# Recurring Prompts

Recurring Prompts is a feature within [[concepts/claude-code-20|Claude Code 2.0]] that enables [[concepts/agentic-ai|AI agents]] to execute tasks on a looped or scheduled basis. This capability allows users to set up automated workflows that run [[concepts/assistive-technology|at]] specified intervals, reducing the need for manual re-invocation of prompts and enabling continuous or periodic task execution without constant user intervention.

## Integration with Google Workspace

The feature integrates with [[concepts/google-workspace|Google Workspace]] [[concepts/software|applications]], allowing [[concepts/temporary-cron-jobs|scheduled tasks]] to interact directly with [[concepts/google-search|Google]]'s [[concepts/productivity-tools|productivity tools]]. This [[concepts/integration|integration]] enables workflows that can automatically process, update, or generate content across [[entities/google-docs|Google Docs]], Sheets, [[entities/gmail|Gmail]], and other Workspace services on a recurring schedule.

## Use Cases

Recurring Prompts are designed for [[concepts/automation|automation]] [[concepts/scenarios|scenarios]] such as scheduled data processing, periodic report generation, routine content updates, and automated workflows that require consistent execution across multiple time intervals. This makes the feature particularly valuable for teams looking to streamline repetitive tasks and maintain regular automation without manual oversight.
