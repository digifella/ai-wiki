# AI-powered code editing

The use of [[concepts/large-language-models|large language models]] and specialized AI [[concepts/agents|agents]] to automate, assist, or generate [[concepts/software|software]] code, aiming to significantly increase [[entities/developer|developer]] velocity and [[concepts/accessibility|accessibility]] for non-coders.

## Key Capabilities
- **Productivity Enhancement**: Tools such as **[[entities/codellm|CodeLLM]]** are designed to potentially increase productivity by 10x.
- **Core Functionalities**:
    - Building applications from various inputs.
    - [[concepts/automated-code-fixing|Automated code fixing]] and [[concepts/debugging|debugging]].
    - Generating new code segments.
- **Advanced Implementations**: Recent advancements include **[[concepts/claude-code|Claude Code]]** 4.1.
