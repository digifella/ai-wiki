# Hermes Agent

**[[concepts/hermes-agent|Hermes Agent]]** is an open-source [[concepts/ai-agentic-framework|AI agentic framework]] developed by [[entities/nous-research]]. It is designed to facilitate the creation and management of [[concepts/autonomous-ai-systems|autonomous AI]] agents, with recent updates focusing on automated recurring task capabilities.

## Key Features

*   **/loop Feature**: Introduces automated recurring task functionality, allowing agents to execute tasks on a scheduled or continuous basis.
*   **Agentic Framework**: Provides a robust environment for building complex AI workflows.
*   **Open Source**: Fully accessible for community contribution and [[concepts/customization|customization]].
