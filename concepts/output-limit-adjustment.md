# Output Limit Adjustment & Hidden Features

Output Limit Adjustment is a configuration option within [[entities/claude-code]] that allows users to modify the maximum length of generated text. This setting provides [[concepts/granular-control|granular control]] over the volume of output Claude produces in response to specific prompts, enabling developers to tailor the verbosity of responses to align with their particular requirements.

The feature addresses practical constraints in [[concepts/ai-agent-workflows|AI agent workflows]], particularly for users operating within strict token budgets or working in contexts where conciseness is critical. By reducing output limits, users can receive more focused responses that avoid unnecessary elaboration, thereby optimizing resource usage and improving efficiency in [[concepts/automations|automated systems]].

Conversely, increasing the limit allows for more comprehensive outputs when detailed explanations or extensive [[concepts/code-generation|code generation]] are required. This flexibility ensures that the AI agent can adapt its behavior to diverse [[concepts/scenarios|use cases]], balancing the need for brevity against the necessity for depth depending on the specific task at hand.
