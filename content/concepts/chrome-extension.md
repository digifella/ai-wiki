# Chrome Extension

A lightweight [[concepts/software|software]] module that extends functionality of the Google Chrome browser, enabling custom features through user scripts or integrated tools.

- [[entities/claude|Claude]] updates. [[entities/nate-b-jones|Nate B Jones]] channel: [[entities/anthropic|Anthropic]]'s "[[concepts/dom|Christmas Claude]]" updates signal [[concepts/strategic-pivot|strategic shift]] toward [[concepts/agentic-system|agentic system]] (moving from chat assistant to integrated tools)
- Requires user permission for data access and can interact with web pages via content scripts
- Published via Chrome Web Store with version control and [[concepts/security|security]] sandboxing
- Common [[concepts/scenarios|use cases]]: ad-blocking, [[concepts/productivity-tools|productivity tools]], [[concepts/developer|developer]] utilities, and AI integrations
