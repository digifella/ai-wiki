# AI Work Team

An [[concepts/orchestrated-system|orchestrated system]] of [[concepts/agentic-ai|AI agents]] collaborating on [[concepts/complex-tasks|complex tasks]] through shared context, workspace, and file access, moving beyond isolated chatbot interactions.

## Key Features
- **Shared Workspace**: Agents operate within a unified environment with persistent context and file access (unlike manual copy-paste between chats).
- **Autonomous Orchestration**: Agents dynamically coordinate tasks without human intervention for each step.
- **Context [[concepts/preservation|Preservation]]**: [[concepts/continuity|Continuity]] across agent interactions for complex project execution.

## Implementation with Claude Code
- **[[entities/claude|Claude]] Code** enables building and managing collaborative [[concepts/ai-agent|AI agent]] teams (see [[entities/claude-code]]).
- [[concepts/tutorial|Tutorial]] demonstrates transitioning from basic [[concepts/ai-bots|chatbots]] to orchestrated [[concepts/agentic-systems|agent systems]].
- Core workflow: Agents share context/files → collaborate on tasks → deliver integrated outputs.
