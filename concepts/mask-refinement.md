# Mask Refinement

**Mask Refinement** refers to the advanced selection and edge-processing capabilities introduced in **[[entities/lightroom-desktop-95|Lightroom Desktop 9.5]]**. This update significantly enhances the precision of local adjustments, allowing for more natural integration of edits within complex image regions.

## Key Updates in Lightroom Desktop 9.5

The following features define the current state of mask refinement and related workflows:

*   **Mask Refinement**: Improved algorithms for edge detection and feathering, reducing halo artifacts and improving selection accuracy for complex subjects.
*   **[[concepts/render-to-dng|Render to DNG]]**: A new workflow allowing users to render processed edits into a new DNG file, preserving the full raw data and edit history for non-destructive further processing.
*   **Crop and Expand**: Continued support for generative expansion techniques to extend image boundaries.

## Color Accuracy and Skin Tone Correction

For precise color management, particularly regarding human subjects, [[concepts/adobe-camera-raw|Adobe Camera Raw]] (ACR 18.4 and newer) introduces the **VectorScope**. This tool addresses the unreliability of human perception in color judgment by providing objective data for [[concepts/skin-tone-correction|skin tone correction]].

*   **VectorScope Utility**: Enables photographers to achieve perfectly accurate skin tones by visualizing color data against standard skin tone lines.
*   **[[concepts/non-destructive-workflow|Non-Destructive Workflow]]**: Aligns with the broader philosophy of [[concepts/non-destructive-editing|Non-destructive Editing]] by allowing precise color adjustments without altering original pixel data.
*   **Detailed Analysis**: See [[lab-notes/2026-09-16-Camera-Raw-VectorScope-for-Precise-Skin-Tone-Correction|Camera Raw VectorScope for Precise Skin Tone Correction]] for specific techniques and workflow integration.
