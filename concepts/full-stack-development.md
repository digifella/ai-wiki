# Full-stack development

[[concepts/web-development|Full-stack development]] encompasses building both [[concepts/frontend-development|front-end]] (client-side) and back-end (server-side) components of [[concepts/web-applications|web applications]].

## Core Aspects
- **Front-end**: HTML, CSS, [[concepts/javascript|JavaScript]], and frameworks ([[entities/react|React]], Vue, Angular)
- **Back-end**: Server [[concepts/open-source-philosophy|logic]], [[concepts/open-standard-protocols|APIs]], and databases ([[entities/nodejs|Node.js]], [[entities/python|Python]], PostgreSQL)
- **DevOps**: Deployment pipelines ([[concepts/docker|Docker]], Kubernetes), [[concepts/cicd-pipelines|CI/CD]] practices
- **Database**: Schema design, optimization (SQL, NoSQL)
