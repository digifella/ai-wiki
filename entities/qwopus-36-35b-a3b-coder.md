# Qwopus 3.6-35B-A3B-Coder

**[[entities/qwopus-coder|Qwopus 3.6-35B-A3B-Coder]]** is a specialized [[concepts/smart-coding-agent|coding agent]] model derived from the [[entities/qwen-36-35b-a3b]] base architecture. Developed by Jackrong, it is characterized by its "thinking-off" capability, high [[concepts/token-optimization|token efficiency]], and integration of [[entities/mixture-of-experts]] (MoE) techniques to optimize performance.

## Key Characteristics

- **Architecture**: Built on the [[concepts/qwen-36-35b-a3b|Qwen 3.6-35B]] A3B foundation, utilizing a [[concepts/mixture-of-experts|Mixture of Experts]] structure to balance computational load and [[concepts/llm-inference-speed|inference speed]].
- **Performance**: Capable of generating code at approximately 160 [[concepts/text-generation-speed|tokens per second]].
- **Agentic Capabilities**: Features [[concepts/agentic-code-self-correction|agentic code self-correction]] [[concepts/causes|mechanisms]], allowing the model to identify and fix its own bugs during generation.
- **Efficiency**: Designed for token-efficient [[concepts/coding|coding]] tasks, reducing unnecessary verbosity while maintaining code quality.
