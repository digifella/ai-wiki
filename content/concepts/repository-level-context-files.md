# Repository-level context files

[[concepts/files|Files]] in repository root (e.g., `[[concepts/agents|AGENTS]].md`, `[[concepts/claude-ai|CLAUDE]].md`) providing context to AI [[concepts/agents|agents]] for [[concepts/coding|coding]] tasks. Common practice to guide AI behavior.

* **[[entities/eth-zurich|ETH Zurich]] study (2026)**: Repository-level context files (e.g., `AGENTS.md`, `CLAUDE.md`) can **degrade** AI [[entities/agent|agent]] performance, contradicting industry practice.
* **Study title**: "Evaluating [[concepts/agentsmd|AGENTS.md]]: Are Repository-Level Context Files Helpful for [[concepts/ai-coding-assistance|Coding Agents]]?"
* **Performance Impact**: [[entities/claude|Claude]].md and [[concepts/agentsmd|agents.md]] files can cause [[entities/claude|Claude]] to perform worse.
* **Source**: Channel [[entities/theo|Theo]] (<https://www.youtube.com/watch?v=GcNu6wrLTJc>)
* **Backlink**: 2026 04 14 AI can work worse with [[concepts/claudemd|Claudemd]] and agentsmd files Channel Theo
