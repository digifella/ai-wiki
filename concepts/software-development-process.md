# Software Development Process

A structured approach to designing, developing, testing, and maintaining software.

## Key Concepts
- **[[concepts/agile-methodologies|Agile Methodologies]]**: [[concepts/iterative-development|Iterative development]] with continuous [[concepts/feedback|feedback]].
- **Waterfall Model**: Linear, sequential approach to [[concepts/coding|software development]].
- **DevOps**: Integration of development and operations for continuous delivery.
- **[[concepts/bmad-method|BMAD Method]]**: A universal [[concepts/ai-agent-framework|AI agent framework]] for [[concepts/agile-ai-driven-development|Agile AI-driven development]].
