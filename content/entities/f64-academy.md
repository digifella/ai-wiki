# F64 Academy

F64 Academy is an educational YouTube channel operated by [[entities/blake-rudis|Blake Rudis]] that focuses on [[concepts/photoshop|Adobe Photoshop]] tutorials and digital photography instruction. The channel provides practical guidance on using Photoshop's various tools and features, targeting both beginner and intermediate users interested in [[concepts/photo-editing|photo editing]] and manipulation techniques.

## Content and Focus

The channel covers a range of Photoshop functionality, including tutorials on [[concepts/tint-adjustment|color adjustment]] tools such as the Color and Vibrance features available in [[entities/adobe-photoshop-2025|Photoshop 2025]]. Content is structured to help viewers understand both the technical operation of tools and their practical application in real-world editing workflows.
