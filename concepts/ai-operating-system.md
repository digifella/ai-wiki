# AI Operating System

An [[concepts/ai-operating-system]] is an integrated computational framework that combines [[entities/claude]], an [[concepts/ai-assistant|AI assistant]], with [[entities/obsidian]], a note-taking and [[concepts/knowledge-management|knowledge management]] platform. This system creates a persistent environment where an AI can maintain [[concepts/continuity|continuity]] across multiple sessions by accessing and updating stored information in a structured format. Rather than treating each conversation as isolated, the framework leverages a shared [[concepts/knowledge-base|knowledge base]] that the AI can reference, modify, and build upon over time.

## Architecture and Function

The system operates across three primary layers: [[concepts/claude-ai|Claude]] serves as the computational and [[concepts/reasoning|reasoning]] [[concepts/engine|engine]], [[concepts/obsidian|Obsidian]] functions as the persistent knowledge repository with [[concepts/qec-framework|structured note-taking]] capabilities, and an integration layer enables bidirectional communication between the two platforms. [[concepts/claude|Claude]] can query existing [[concepts/notes|notes]], extract relevant context, and write new information back to the vault, while Obsidian's linking and tagging systems organize knowledge in a graph structure that the AI can traverse and utilize.
