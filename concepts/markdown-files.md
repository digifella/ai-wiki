# Markdown Files

**[[concepts/markdown|Markdown]]** is a lightweight markup language for creating formatted text using a plain-text editor. It is the foundational format for [[entities/obsidian]], [[concepts/static-website|static site]] generators, and increasingly, AI-native [[concepts/knowledge-bases|knowledge bases]].

## Core Characteristics
- **Plain Text**: Human-readable and [[concepts/app-updates|version-control]] friendly.
- **Syntax**: Uses symbols (`#`, `*`, `-`, `[]`) for structure (headers, lists, links).
- **Extensibility**: Supports HTML embedding and custom extensions (e.g., Callouts, MathJax).

## Evolution in AI Contexts
Traditional Markdown serves as a static [[entities/storage|storage]] format. Recent developments aim to standardize Markdown for dynamic AI consumption:

- **[[concepts/compounding-knowledge|Karpathy's LLM Wiki]]**: [[entities/andrej-karpathy|Andrej Karpathy]] proposed using Markdown-based wikis as personal knowledge [[concepts/number-systems|bases]] for [[concepts/large-language-models]] (LLMs), emphasizing simplicity and [[concepts/accessibility|accessibility]] for [[concepts/agentic-ai|AI agents]].
- **[[concepts/google-search|Google]]'s OKF**: [[entities/google|Google]] has proposed the **[[concepts/data-management|Open Knowledge Format]]** (OKF) to standardize these structures for better AI interoperability.
	- See: [[lab-notes/2026-07-03-Googles-OKF-Standardizing-Karpathys-LLM-Wiki-for-AI-Inte|Google's OKF: Standardizing Karpathy's LLM Wiki for AI Interoperability]]
	- This shift moves from ad-hoc Markdown usage to a standardized schema for [[concepts/ai-agents|AI agents]] to parse and [[concepts/purpose|reason]] over personal knowledge bases.
