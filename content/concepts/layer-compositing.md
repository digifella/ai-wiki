# Layer Compositing

Layer compositing is a fundamental technique in digital [[concepts/image-editing|image editing]] that involves combining multiple image layers to create a final composite. This process typically includes arranging layers in a specific order, adjusting their [[concepts/opacity|opacity]], and applying blending modes to [[concepts/power|control]] how pixels from different layers interact with one another.

## Blending and Adjustment

Modern image editing [[concepts/software|software]] like [[concepts/photoshop|Photoshop]] provides specialized features for refining composited layers. The [[concepts/beta-version|Harmonize feature]] allows editors to blend layers together while simultaneously applying color and [[concepts/photo-tonal-adjustments|tonal adjustments]], helping to unify disparate source [[concepts/images|images]] and create cohesive results. This approach reduces the need to work on [[concepts/adjustments|adjustments]] in isolation, instead treating blending and color correction as integrated steps in the compositing [[concepts/workflow|workflow]].

## Practical Applications

Layer compositing is used across various creative disciplines, from [[concepts/photo-retouching|photo retouching]] and restoration to [[concepts/digital-painting|digital painting]] and complex visual effects. Photographers often composite multiple exposures to achieve results that single frames cannot provide, while designers layer graphical elements to build complex layouts. The technique requires understanding how different [[concepts/layer-styles|blend modes]] affect underlying layers and how [[concepts/adjustment-layers|adjustment layers]] interact with the layer stack.
