# Security exposure

Vulnerabilities in systems or processes that could be exploited to cause harm, including data breaches, unauthorized access, or operational disruption.

## Examples
- [[concepts/shadow-ai]]: Unauthorized [[concepts/ai-projects|AI projects]] within corporate environments (e.g., employees using [[concepts/generative-ai|generative AI]] tools without IT approval), creating unmanaged security risks like [[concepts/data-leakage|data leakage]] and [[concepts/compliance|compliance]] violations, as highlighted by IBM's [[entities/jeff-crume|Jeff Crume]] (2026).
