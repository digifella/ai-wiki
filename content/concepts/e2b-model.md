# E2b Model

[[concepts/e2b|E2b]] Model refers to [[concepts/23b-parameter-models|Google Gemma 4]], a [[concepts/multimodal-ai|multimodal AI]] model with 2.3 billion [[concepts/parameters|parameters]] designed specifically for [[concepts/edge-deployment|edge deployment]]. The model is optimized to run efficiently on resource-constrained devices, making it suitable for on-device [[concepts/inference|inference]] without requiring constant [[concepts/cloud-integration|cloud connectivity]] or significant computational infrastructure.

## Multimodal Capabilities

[[concepts/e4b-model|Gemma 4]] combines [[concepts/text|text]] and image processing in a single [[concepts/architecture|architecture]], allowing it to understand and generate [[concepts/responses|responses]] based on both modalities. This multimodal [[concepts/design|design]] enables a broader [[concepts/range|range]] of [[concepts/software|applications]] compared to text-only [[concepts/models|models]] while maintaining the efficiency constraints necessary for edge devices.

## Edge Deployment Focus

The 2.3B parameter scale represents a deliberate balance between model capability and [[concepts/computational-efficiency|computational efficiency]]. This size category targets edge [[concepts/deployment|deployment]] [[concepts/scenarios|scenarios]] where latency, [[concepts/power|power]] consumption, and local processing are priorities, supporting applications in mobile devices, IoT systems, and other resource-limited environments.
