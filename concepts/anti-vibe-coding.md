# Anti-vibe coding

A development [[concepts/philosophy|philosophy]] rejecting "[[concepts/3d-game-development|vibe coding]]" (tools generating code for non-programmers) in favor of professional, focused [[concepts/coding|coding]] with intelligent assistants that augment [[concepts/expertise|expertise]] without replacing it.

- **[[entities/junie|Junie]] (JetBrains)**: [[concepts/smart-coding-agent|Smart coding agent]] designed for professional engineers, [[concepts/acting|acting]] as a deeply integrated intelligent assistant rather than generating thousands of lines from scratch.
