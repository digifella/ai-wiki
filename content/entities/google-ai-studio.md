[[concepts/google-search|Google]]'s browser-based prototyping environment for [[concepts/prompting|prompting]], [[concepts/testing|testing]], and shipping [[concepts/gemini|Gemini]]-based workflows and building full-stack [[concepts/web-applications|web applications]] with Firebase [[concepts/integration|integration]].

## Comparison with Gemini Web App
- **[[entities/gemini-app|Gemini]] Web App (gemini.google.com):** Consumer-friendly [[concepts/chat-application|chat interface]] for everyday questions and basic assistance, similar to [[entities/chatgpt|ChatGPT]].
- **[[entities/google-ai|Google AI]] Studio (aistudio.google.com):** Advanced, powerful, and versatile environment for [[concepts/power-users|power users]] and professionals to build, test, and ship complex [[concepts/workflow|workflows]].

## Full-Stack Web App Development
- Integration with firebase for [[concepts/user-accounts|user accounts]], [[concepts/database-storage|database storage]], and [[concepts/file-uploads|file uploads]].
- Transformation of [[concepts/static-website|static website]] designs into functional web [[concepts/software|applications]].
- Example use case: Building [[entities/profit-studio|Profit Studio]] with Firebase integration.
