# Graphics Processing Units (GPUs)

A **Graphics Processing Unit** (GPU) is a specialized electronic circuit designed to rapidly manipulate and alter [[concepts/memory|memory]] to accelerate the creation of [[concepts/images|images]] in a frame buffer intended for output to a display device. GPUs are used in embedded systems, mobile phones, workstations, desktops, laptops, game consoles, and game computers.

- [[concepts/cuda]]: [[concepts/gpu-parallel-computing|GPU parallel computing]] platform developed by Nvidia that allows developers to use GPUs for [[concepts/general-purpose-computation|general-purpose computation]].
- General-[[concepts/motivation|Purpose]] Computing on Graphics Processing Units (GPGPU): The use of a graphics processing unit as a general-purpose manycore processor, in conjunction with the [[concepts/cpu|CPU]], to solve a range of complex [[concepts/computational-problems|computational problems]].

## Nvidia CUDA

### Summary
Nvidia [[concepts/cuda|CUDA]] is a [[concepts/general-purpose-computing|parallel computing]] platform and programming model developed by Nvidia that allows [[concepts/software|software]] developers to use a graphical processing unit for general [[concepts/purpose|purpose]] processing. It was launched in 2007 by [[entities/ian-buck|Ian Buck]] and [[entities/john-nicholls|John Nicholls]], extending the functionality of GPUs far beyond their traditional role in rendering images.
