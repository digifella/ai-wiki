# Phi 4

Phi 4 is a [[concepts/statistical-language-modeling|language model]] designed for GPU-based [[concepts/chat-completion|chat completion]] tasks and is available through [[concepts/microsoft-foundry-local|Microsoft Foundry Local]]. It is part of the [[entities/phi|Phi family]] of models developed by [[entities/microsoft|Microsoft]] for [[concepts/local-deployment|local deployment]] [[concepts/scenarios|scenarios]].

## Deployment and Availability

The model is accessed through [[concepts/agent-factory|Microsoft Foundry]] Local, which provides infrastructure for [[concepts/running|running]] language models on GPU [[concepts/hardware|hardware]]. This [[concepts/deployment|deployment]] approach enables users to run chat completion workloads locally rather than relying solely on cloud-based [[concepts/inference|inference]] endpoints.

## Use Cases

Phi 4 is configured for [[concepts/ai-chatbots|conversational AI]] [[concepts/software|applications]], supporting chat completion tasks where it can generate contextual [[concepts/responses|responses]] to user inputs. Its local deployment capability makes it suitable for applications requiring [[concepts/on-device-inference|on-device inference]] or those with specific data residency requirements.
