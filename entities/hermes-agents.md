# Hermes agents

**[[entities/hermes-agent|Hermes]] agents** are a class of [[concepts/autonomous-ai-agent]]s designed for high-efficiency [[concepts/workflow-automation|task execution]] through [[concepts/iterative-learning|iterative refinement]] [[concepts/loops|loops]] rather than static [[concepts/instruction-sets|instruction sets]].

## Core Architecture
- **[[concepts/loop-engineering|Loop Engineering]] Paradigm**: Moves beyond traditional [[entities/prompt-engineering]] by utilizing continuous [[concepts/feedback|feedback]] cycles to refine agent behavior.
  - Shifts focus from crafting "perfect single [[concepts/instructions|instructions]]" to designing robust interaction loops that allow the agent to self-correct and optimize over time.
  - Aims to maximize output quality ("10x improvement") by reducing reliance on initial prompt [[concepts/accuracy|precision]].
- **Autonomous Design**: Agents operate with higher degrees of independence, managing their own [[concepts/context-windows|context windows]] and decision trees within defined constraints.
