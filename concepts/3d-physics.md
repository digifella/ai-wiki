# 3D Physics

[[concepts/simulation|Simulation]] of physical phenomena in three-dimensional space, governing motion, forces, collisions, and interactions. Core to game development, VR, and [[entities/national-academies|engineering]] simulations.

### Core Components
- rigid body dynamics: Motion of non-deformable objects under forces
- collision detection: [[concepts/algorithms|Algorithms]] determining object intersections
- [[concepts/physics|physics]] [[concepts/engine|engine]]: Software implementing physics (e.g., Bullet, PhysX)
- inverse kinematics: Solving joint movements for articulated bodies
