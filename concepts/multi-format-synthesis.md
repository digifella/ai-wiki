# Multi-format synthesis

The process of integrating, analyzing, and transforming information from disparate, heterogeneous data sources into a unified, coherent output.

### Key Capabilities
- **[[concepts/citation-grounding|Source Grounding]]**: Anchoring AI [[concepts/reasoning|reasoning]] in specific, user-provided [[concepts/training-data|datasets]] to significantly minimize [[concepts/ai-hallucinations]].
- **Heterogeneous Input Support**: The ability to ingest and cross-reference multiple formats, including:
	- PDF
	- [[entities/google-docs]]
	- [[concepts/google-slides]]
	- [[concepts/audio-modality|Audio]]
	- URLs
- **Automated Transformation**: Converting synthesized data into structured, actionable assets:
	- [[concepts/data-tables]]
	- [[concepts/infographic]]
	- Slide Generation
	- [[concepts/video-generation]]

### Practical Implementation
- [[entities/notebooklm]]: Functions as a full content system designed for high-fidelity synthesis and maximum [[concepts/productivity|productivity]].
