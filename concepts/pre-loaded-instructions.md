# Pre-loaded Instructions

[[concepts/instructions|Instructions]] embedded within an [[concepts/ai-system|AI system]] or tool, enabling immediate execution without additional configuration. This concept eliminates repetitive setup steps for [[concepts/recurring-tasks|recurring tasks]].

## Key Characteristics
- **Context-aware**: Tailored to specific domains (e.g., meetings, reporting)
- **Reduced [[concepts/cognitive-load|cognitive load]]**: Eliminates user input for standard workflows
- **Scalable**: Multiple [[concepts/instruction-sets|instruction sets]] coexist for different [[concepts/scenarios|use cases]]
