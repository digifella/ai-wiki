# BMAD method

Universal [[entities/openclaw|AI agent framework]] for Agile development that integrates full [[concepts/software|software]] development lifecycle, preventing non-production-ready code from [[concepts/development-speed|AI-assisted development]].

## Key Points
- Addresses critical gap: AI enables rapid app/website creation but bypasses proper [[concepts/software-development-process|software development process]] (e.g., [[concepts/testing|testing]], version control), resulting in non-production code
- Evolved from simple [[concepts/ai-assisted-coding|AI coding]] to sophisticated [[concepts/context-engineering|context engineering]] (tools: [[entities/cursor|Cursor]], [[entities/claude-code]])
- Streamlines entire development [[concepts/workflow|workflow]] through [[concepts/ai-agent|AI agent]] [[concepts/integration|integration]]
- Introduced in [video](https://youtu.be/fD8NLPU0WYU)
- Highlights the progression from simple coding to sophisticated [[concepts/context-engineering|context engineering]]
- Emphasizes the lack of proper [[concepts/software|software]] development process in [[concepts/application-development-automation|AI-driven development]]
