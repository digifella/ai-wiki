## Claude Made My Old Android TV Feel Brand New!
**Clip title:** Claude Made My Old Android TV Feel Brand New!
**Author / channel:** Ansub Khan
**URL:** https://www.youtube.com/watch?v=fP2SGGVsaB0

### Summary
Sure, here is a summary of the video content:

The video discusses how to revamp an Android TV to make it feel brand new and run faster without buying any new hardware or sketchy apps. The speaker shares their experience of using Claude, an AI assistant, to clean up their old Android TV. Claude built a completely new home screen from scratch, free of ads and bloatware, and turned off unnecessary apps and background services.

The video outlines the steps to achieve this:
1. Enable developer options on the Android TV by going to Settings > Device Preferences > About and clicking "Build" seven times.
2. Turn on USB debugging in the developer options.
3. Find the TV's IP address in the network settings.
4. Use Claude Code (or desktop app) to run a specific prompt from a GitHub page (linked in the description), substituting the TV's IP address and desired apps.
5. Allow USB debugging on the TV when prompted.
6. Claude will analyze the TV's apps, categorize them, and ask the user which ones to turn off.
7. Claude will turn off bloatware, ads, and background services without deleting them, freeing up significant memory and speeding up the TV.

The conclusion highlights that by using Claude to clean up the TV, the speaker was able to free up about 90% more memory (increasing from 370MB to 600-650MB), resulting in a faster, ad-free home screen and smoother operation without having to purchase a new TV or streaming stick.
