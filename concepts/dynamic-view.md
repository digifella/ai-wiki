# Dynamic View

Dynamic View refers to a collection of interface and functionality updates released for Google's Gemini AI platform. These changes are designed to enhance how users interact with and organize information, representing Google's efforts to improve the presentation and management of Gemini's capabilities. The goal is to make the platform more adaptable to different user workflows and specific information needs.

## Disco

A key component of this update is Disco, a feature that allows users to explore topics in greater depth through a visual, non-linear interface. This tool facilitates a more exploratory approach to information retrieval, enabling users to navigate complex subjects without following a rigid, linear path. By visualizing connections between concepts, Disco aims to support deeper understanding and more flexible inquiry patterns within the Gemini environment.

## GenTabs

The update also introduces GenTabs, which focuses on improving the organization of generated content. This functionality helps users manage multiple outputs or threads of conversation more effectively, streamlining the process of reviewing and utilizing AI-generated material. Together, Disco and GenTabs represent a shift toward a more modular and user-centric design for the Gemini platform.
