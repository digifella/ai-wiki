# Image Processing Automation

Image processing [[concepts/automation|automation]] refers to the use of [[concepts/ai-technologies|artificial intelligence]] and [[concepts/machine-learning-systems|machine learning systems]] to streamline and accelerate [[concepts/image-editing|image editing]] workflows. [[concepts/photoshop|Adobe Photoshop]] version 27.6 introduced enhanced generative features that automate routine image processing tasks, reducing manual effort required for common editing operations. These tools leverage [[concepts/neural-networks|neural networks]] trained on large image datasets to perform [[concepts/adjustments|adjustments]], enhancements, and content generation with minimal user input.

## Generative Features in Photoshop 27.6

The latest version includes improved [[concepts/generative-fill|generative fill]] and expand [[concepts/capabilities|capabilities]], allowing users to extend image boundaries and fill areas using [[concepts/ai-driven-content-generation|AI-driven content generation]]. These features analyze surrounding pixels and patterns to create contextually appropriate fills that maintain visual coherence. Additionally, the update provides enhanced [[concepts/object-removal|object removal]] and replacement tools that use machine learning to intelligently reconstruct backgrounds and surfaces.

## Workflow Integration

The automation features integrate into standard Photoshop workflows through updated menus and dialog systems. Rather than replacing traditional tools, the generative functions operate alongside conventional editing methods, giving users flexibility in choosing between automated and manual approaches. The system processes requests through cloud-based APIs, including [[concepts/gemini-25-models|Gemini 2.5]] models, which handle the computational requirements for real-time image processing.

These developments reflect broader industry trends toward AI-assisted creative tools that augment rather than replace human [[concepts/decision-making|decision-making]] in image editing and [[concepts/design|design]] work.
