# Camera Raw

## Overview
**Camera Raw** is a plugin and interface within the [[entities/adobe|Adobe]] ecosystem used for processing raw image files. It serves as the bridge between raw sensor data and final edited images, offering non-destructive adjustments to exposure, color, and detail.

## Key Features
- **Non-Destructive Editing:** Adjustments are stored as sidecar files or metadata, preserving original pixel data.
- **Raw Processing Engine:** Utilizes Adobe's proprietary algorithms for demosaicing and tone mapping.
- **Integration:** Seamlessly works with [[concepts/adobe-photoshop|Photoshop]] and Lightroom.
