# Prompting 2.0

**Prompting 2.0** represents a paradigm shift in interacting with [[concepts/large-language-models|Large Language Models]] (LLMs), moving away from rigid, structured instruction sets toward leveraging [[concepts/unstructured-input|unstructured input]] for advanced comprehension. This approach emphasizes context density and natural language flow over syntactic precision.

## Core Concepts
- **Unstructured Input:** Prioritizes raw, unformatted data and natural language context over strict JSON or XML schemas.
- **Advanced Comprehension:** Relies on the model's ability to infer intent from broad context rather than explicit step-by-step commands.
- **[[concepts/context-length|Context Window]] Utilization:** Maximizes the effective use of available context to provide the model with comprehensive background information.

## Key Developments
- **Karpathy's Methodology:** [[entities/andrej-karpathy|Andrej Karpathy]] has popularized techniques that demonstrate significant performance improvements using this approach.
- **Viral Adoption:** The methodology gained rapid traction in the AI community for its "insane results" in complex [[concepts/reasoning|reasoning]] tasks.
