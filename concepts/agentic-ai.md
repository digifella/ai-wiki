# Agentic Coding

Agentic AI refers to AI systems designed to perform specific tasks autonomously, such as [[entities/kombai]] for [[concepts/frontend-development|frontend development]] integration with IDEs, increasingly incorporating efficient [[concepts/reasoning-models|open-source models]] like [[lab-notes/2026-07-31-Poolsides-Laguna-S-2.1-Efficient-Open-Source-Agentic-Cod|Poolside's Laguna S 2.1: Efficient Open-Source Agentic Coding for Local Hardware]] for local hardware deployment.

## Key Developments

*   **Laguna S 2.1 Integration**: Poolside's Laguna S 2.1 represents a significant advancement in efficient open-source [[concepts/autonomous-ai-coding-agent|agentic coding]] for local hardware [[lab-notes/2026-07-31-Poolsides-Laguna-S-2.1-Efficient-Open-Source-Agentic-Cod|Poolside's Laguna S 2.1: Efficient Open-Source Agentic Coding for Local Hardware]].
    *   **Architecture**: Utilizes a [[entities/mixture-of-experts|Mixture-of-Experts]] (MoE) architecture with 118 billion parameters.
    *   **Efficiency**: Optimized for performance on local hardware, reducing reliance on cloud inference for [[concepts/agentic-patterns|agentic workflows]].
    *   **Context**: Discussed in the video "Laguna S 2.1: The Best Local Agentic Coder?" by the [[concepts/prompt-based-modeling|Prompt Engineering]] channel.
