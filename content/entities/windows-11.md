# Windows 11

Windows 11 is a major operating system release by Microsoft, succeeding [[entities/windows-10|Windows 10]]. It was officially announced in June 2021 and released to the public on October 5, 2021. The operating system introduced a redesigned [[concepts/user-interface|user interface]] with a centered taskbar and Start menu, representing a significant visual departure from its predecessor.

## Key Features

The system includes updated design elements, improved [[concepts/software-performance|performance optimization]], and integration with Microsoft's [[concepts/cloud-computing|cloud services]]. Windows 11 introduced stricter [[concepts/hardware-requirements|hardware requirements]] compared to Windows 10, including mandatory support for TPM 2.0 (Trusted Platform Module) and UEFI firmware, which raised compatibility concerns for users with older [[concepts/hardware|hardware]].

## System Requirements and Support

Windows 11 requires compatible [[concepts/central-processing-units|processors]] from Intel (8th generation or newer) or AMD (Ryzen 2000 series or newer), along with at least 4GB of RAM and 64GB of [[entities/storage|storage]]. Microsoft has provided regular updates and feature releases since launch, with support scheduled to continue through October 2025. The operating system is available in multiple editions, including Home, Pro, Enterprise, and Education versions.
