# Mcp Servers

[[concepts/external-tools|Model Context Protocol]] (MCP) servers are a standardized interface for connecting [[concepts/ai-powered-applications|AI applications]] to [[concepts/external-data|external data]] sources and tools. They enable [[concepts/models|models]] like [[concepts/claude-ai|Claude]] and [[concepts/gemini|Gemini]] to access real-time information, perform web extraction, and interact with specialized services through a consistent protocol. MCP servers act as intermediaries that handle the communication between [[concepts/ai-models|AI models]] and external systems, abstracting away [[concepts/implementation-details|implementation details]] while maintaining [[concepts/security|security]] and [[concepts/software-reliability|reliability]].

## Configuration and Integration

MCP servers can be configured in both the [[concepts/autonomous-coding|Gemini CLI]] and [[entities/claude-desktop|Claude Desktop]] environments. This [[concepts/setup|setup]] allows developers to connect [[concepts/web-crawling|web data extraction]] services and other tools to their AI workflows without modifying the core application [[concepts/code|code]]. The configuration process typically involves specifying server endpoints and [[concepts/authentication|authentication]] credentials, making it straightforward to integrate multiple data sources into a single [[concepts/ai-powered-application|AI-powered application]].

## Common Use Cases

A primary application of MCP servers is web [[concepts/data-extraction|data extraction]], where they facilitate structured access to online information. Services like [[concepts/bright-data|Bright Data]] can be connected via MCP to provide AI models with [[concepts/capabilities|capabilities]] for [[concepts/scraping|scraping]], monitoring, and processing web content [[concepts/assistive-technology|at]] scale. Beyond [[concepts/information-extraction|data extraction]], MCP servers support broader integrations including database access, API connections, and specialized [[concepts/software|software]] tools, enabling AI models to operate more effectively in real-world [[concepts/scenarios|scenarios]].
