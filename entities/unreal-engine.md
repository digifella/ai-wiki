# Unreal Engine

**Unreal [[concepts/engine|Engine]]** is a proprietary real-time 3D [[concepts/fat-rendering|rendering]] engine developed by [[entities/epic-systems|Epic]] Games. It is widely used in video game development, virtual production, and architectural visualization.

## Key Features
- **Real-time [[concepts/visual-rendering|Rendering]]:** Advanced lighting, [[concepts/shadows|shadows]], and post-processing effects.
- **Blueprints:** [[concepts/node-based-interface|Visual scripting]] system for non-programmers.
- **[[concepts/physics|Physics]] & Animation:** Built-in [[concepts/physics-simulation|physics simulation]] and animation tools.
- **Cross-platform Support:** Deploys to PC, [[concepts/cli|console]], mobile, and VR/AR platforms.
