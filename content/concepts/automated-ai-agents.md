# Automated AI Agents

Automated [[concepts/agentic-ai|AI agents]] are [[concepts/software|software]] systems that combine [[concepts/large-language-model-llm|large language models]] (LLMs) with [[concepts/ai-driven-workflow-automation|workflow automation]] tools to execute tasks with minimal human intervention. These agents use [[concepts/natural-language-processing|natural language processing]] to understand objectives, plan action sequences, and interact with external systems or data sources. By integrating automation platforms with language models, they can perform complex multi-step operations autonomously.

## Local Deployment with Open-Source Models

[[concepts/running|Running]] AI agents locally offers advantages in [[concepts/privacy|privacy]], cost, and [[concepts/power|control]] compared to [[concepts/cloud-based-solutions|cloud-based solutions]]. [[concepts/reasoning-models|Open-source models]] like those from the [[concepts/gpt-4|gpt-oss]] initiative can be deployed on personal infrastructure using tools like Ollama, which simplifies the installation and management of large language models. This approach eliminates dependency on external APIs and allows [[concepts/customization|customization]] for specific [[concepts/scenarios|use cases]].

## Integration with Automation Platforms

N8N is a workflow automation platform that can connect with local language models to build agent pipelines. It provides a visual interface for designing multi-step workflows where [[concepts/ai-models|AI models]] process information and trigger actions across integrated services. This combination enables users to create automated agents without extensive programming knowledge, connecting LLMs to databases, APIs, and other business tools through a node-based workflow system.
