# Color Ranges

Color Ranges in [[entities/lightroom-classic|Lightroom Classic]] refers to the targeted adjustment of specific color ranges within an image using HSL ([[concepts/hue|Hue]], Saturation, Lightness) controls. Rather than adjusting all colors uniformly, this approach allows photographers to isolate and modify individual color ranges—such as reds, oranges, yellows, greens, cyans, blues, and magentas—independently. This selective [[concepts/power|control]] enables precise [[concepts/photo-tonal-adjustments|color grading]] without affecting the rest of the image.

## The Color Mixer Tool

Lightroom Classic provides the [[concepts/color-mixer|Color Mixer]] as the primary interface for working with color ranges. This tool displays individual color [[concepts/range-sliders|range sliders]] that control hue, saturation, and lightness for each color channel. Photographers can adjust these [[concepts/parameters|parameters]] to shift color tones, intensify or reduce [[concepts/color-vibrancy|color vibrancy]], or brighten and darken specific colors within a defined [[concepts/range|range]]. The [[concepts/hslcolor-mixer|Color Mixer]] offers a more intuitive [[concepts/workflow|workflow]] compared to the older Hue/Saturation panel, with real-time [[concepts/feedback|feedback]] as [[concepts/adjustments|adjustments]] are made.

## Common Applications

Targeted color range adjustments are useful for correcting [[concepts/color-casts|color casts]] in specific areas, enhancing [[concepts/skin-tones|skin tones]] while preserving other colors, or creatively manipulating particular hues in landscape or product photography. This technique is especially valuable when the subject contains multiple colors that require different treatment, allowing each color to be refined independently without compromising overall image balance.
