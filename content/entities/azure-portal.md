# Azure Portal

The [[concepts/azure-portal|Azure Portal]] is [[entities/microsoft|Microsoft]]'s web-based interface for managing Azure [[concepts/cloud-computing|cloud services]] and resources. It provides a centralized platform where developers and administrators can deploy, configure, and monitor [[concepts/software|applications]] and infrastructure on Azure's cloud platform.

## Agentic RAG Implementation

The Azure Portal supports the development of [[concepts/agentic-ai|AI agents]] using Agentic [[concepts/answer-generation|Retrieval-Augmented Generation]] (RAG), a technique that combines [[concepts/large-language-model-llm|large language models]] with retrieval systems to provide contextually informed [[concepts/responses|responses]]. This approach allows [[concepts/ai-agents|AI agents]] to access [[concepts/external-knowledge|external knowledge]] sources and dynamically retrieve relevant information to answer queries or complete tasks with greater [[concepts/accuracy|accuracy]] and relevance than traditional language [[concepts/models|models]] alone.

## Practical Application

A [[concepts/tutorial|tutorial]] demonstrating how to build an [[concepts/ai-agent|AI agent]] using [[concepts/agentic-rag-systems|Agentic RAG]] in Azure involves configuring retrieval systems, integrating language models, and setting up the necessary Azure resources through the Portal. This method is particularly useful for specialized applications such as financial analysis, where the [[entities/agent|agent]] needs to reference specific data sources and provide informed recommendations based on current information rather than relying solely on [[concepts/training-data|training data]].
