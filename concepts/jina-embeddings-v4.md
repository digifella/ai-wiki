# Jina Embeddings V4

Jina Embeddings V4 is a universal embedding model designed to process diverse content modalities, including text, images, and other formats, into a shared vector space. By converting these varied inputs into comparable numerical representations, the model facilitates retrieval systems capable of executing cross-modal searches. This architecture allows queries in one format to retrieve results in another, enabling the alignment of different data types within a unified embedding space.

The model supports complex retrieval tasks that require understanding across modalities, making it suitable for applications where traditional text-only embeddings are insufficient. Its multilingual capabilities further extend its utility in global contexts, allowing for the retrieval of information across different languages while maintaining semantic consistency. This design ensures that the model remains effective for a wide range of AI agent workflows involving heterogeneous data sources.
