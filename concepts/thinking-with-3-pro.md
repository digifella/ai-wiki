# Thinking with 3 Pro & SmolLM3

A mode enabling complex, multi-step [[concepts/reasoning|reasoning]] (10-15 steps) and visible [[concepts/multi-step-reasoning|chain-of-thought]] processes.

## Gemini 3 Pro
A mode in [[entities/gemini-3]] enabling complex, multi-step [[concepts/reasoning|reasoning]] (10-15 steps) with simultaneous processing of video, images, and code. Requires selecting **"[[concepts/human-cognition|Thinking]] with 3 Pro"** and enabling **"[[entities/canvas|Canvas]]"** in [[concepts/google-workspace|Google Workspace]].

Key capabilities:
- Executing extended [[concepts/reasoning|reasoning]] chains
- Multimodal input processing
- Direct integration with [[entities/google-workspace]]

For detailed applications, see 2026 04 14 8 [[concepts/gemini|Gemini]] [[concepts/use-cases|use cases]].

## SmolLM3
- Part of the `[[concepts/3-billion-parameter-model|SmolLM3-3B]]` family from [[concepts/open-source-machine-learning|Hugging Face]].
- Features an advanced "[[concepts/thinking-mode|thinking mode]]" that displays the [[concepts/reasoning-steps|reasoning process]] before generating a final [[concepts/solution|answer]].
