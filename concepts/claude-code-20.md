# Claude Code 2.0

Claude Code 2.0 is an update to Anthropic's AI-assisted coding platform that expands automation capabilities for developers. The release introduces support for loops and scheduled tasks, enabling developers to construct multi-step workflows that can execute repeatedly or at specified times. These control flow enhancements allow for more complex automation scenarios beyond single-execution tasks, providing developers with greater flexibility in designing workflows.

## Key Features

The platform adds Google Workspace integration, allowing developers to automate tasks involving Google's productivity suite. The update also includes Skills 2.0, which enhances the framework for building and deploying custom capabilities. Together, these additions extend the types of applications and integrations that developers can build with Claude's coding assistance.
