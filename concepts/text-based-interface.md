# Text-Based Interface

A **Text-Based Interface** (TBI) is a [[concepts/user-interface|user interface]] paradigm where interaction is mediated primarily through textual input and output, rather than graphical elements like [[concepts/buttons|buttons]] or menus. This approach leverages the [[concepts/accuracy|precision]] and flexibility of natural language or command-line syntax to execute complex operations.

## Core Characteristics
- **Direct Manipulation via Language**: Users describe desired outcomes or actions using text prompts or [[concepts/commands|commands]].
- **[[concepts/abstraction-layer|Abstraction]] of Complexity**: Hides underlying technical processes (e.g., [[concepts/fat-rendering|rendering]] engines, file systems) behind a natural language layer.
- **Efficiency**: Allows for rapid execution of multi-step workflows without navigating multiple GUI screens.

## Applications & Examples

### Video Editing
Traditional [[concepts/video-editing|video editing]] relies on timeline-based GUIs requiring manual clipping, dragging, and dropping. Text-based approaches abstract this by allowing users to define edits via prompts.

- **Video-Use**: An [[concepts/open-source|open-source]] tool that integrates with [[entities/claude-code]] to transform it into a prompt-driven video editor. It eliminates the need for traditional timeline manipulation by interpreting text prompts to perform editing tasks.
