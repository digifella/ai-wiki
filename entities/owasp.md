# OWASP

OWASP (Open Worldwide Application Security Project) is a nonprofit organization dedicated to improving software security through education, tools, and community collaboration. Founded to address the growing need for secure software development practices, OWASP develops and maintains security guidance, standards, and best practices for software developers, security professionals, and organizations worldwide.

## Core Publications and Guidance

OWASP is best known for publishing the OWASP Top 10, a regularly updated list of the most critical security risks in web applications. The organization has expanded this framework to address emerging areas of technology, including the Top 10 Security Risks for AI Agentic Applications, which provides guidance on securing AI systems that operate autonomously. These publications serve as industry reference standards for identifying and mitigating common security vulnerabilities.

## Mission and Scope

The organization operates through a global community of security professionals, developers, and researchers who contribute to its projects and initiatives. OWASP provides free resources, including documentation, tools, and frameworks designed to help organizations build and maintain secure software throughout the development lifecycle. Its work spans multiple domains including web application security, API security, cloud security, and emerging technology risks.
