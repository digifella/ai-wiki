# AI agent coding behavior

The optimization of [[concepts/agentic-ai]]' performance, [[concepts/accuracy|accuracy]], and adherence to project-specific [[concepts/open-standards|standards]] through structured contextual injection.

## Key Methodologies
- **[[concepts/claudemd]] Implementation**: A pattern for enhancing agentic behavior by providing a persistent, project-specific instruction file that outlines [[concepts/coding|coding]] standards, build [[concepts/commands|commands]], and [[concepts/testing|testing]] protocols (inspired by [[entities/andrej-karpathy]]).
- **Contextual Scaffolding**: Utilizing structured documentation to guide [[concepts/llm]] [[concepts/reasoning|reasoning]], reducing [[concepts/data-hallucination|hallucination]] during complex [[concepts/software-engineering|software engineering]] tasks.
