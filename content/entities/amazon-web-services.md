# Amazon Web Services

Amazon Web Services (AWS) is a subsidiary of Amazon that provides on-demand [[concepts/cloud-computing|cloud computing]] platforms and APIs to individuals, companies, and governments on a metered, pay-as-you-go basis. Launched in 2006, AWS offers a comprehensive suite of cloud services including computing power, [[entities/storage|storage]], databases, networking, and analytics tools. The platform operates through a global infrastructure of data centers distributed across multiple geographic regions, allowing customers to deploy [[concepts/software|applications]] and services with low latency.

## Core Services and Offerings

AWS provides foundational services such as Elastic [[concepts/compute|Compute]] Cloud (EC2) for virtual servers, Simple Storage Service (S3) for object storage, and Relational Database Service (RDS) for managed databases. Beyond infrastructure, the platform offers higher-level services including machine [[concepts/learning|learning]] tools, content delivery networks, security services, and enterprise applications. These services can be used independently or combined to build complex distributed systems.

## Market Position

As a pioneer in cloud computing, AWS maintains a significant share of the global cloud infrastructure market. The service has become foundational to modern [[concepts/web-applications|web applications]], data processing, and enterprise IT operations. AWS generates substantial revenue for Amazon and operates as one of the company's most profitable divisions, supporting businesses of all sizes from startups to Fortune 500 companies.
