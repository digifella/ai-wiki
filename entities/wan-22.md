# Wan 22

[[concepts/14b-parameter-model|Wan 2.2]] is a [[concepts/video-generation|video generation]] model designed to create videos from text prompts or static images. The model supports both [[concepts/text-to-video|text-to-video]] and [[concepts/image-to-video-model|image-to-video generation]] tasks, enabling users to produce [[concepts/dynamic-video-content|dynamic video content]] from various input formats.

## Local Deployment

[[concepts/text-to-video-model|Wan 2.2]] can be run locally using [[concepts/comfyui|ComfyUI]], a [[concepts/node-based-interface|node-based interface]] for [[concepts/tts-model|generative models]]. This allows users to generate videos on their own hardware without relying on [[concepts/cloud-based-services|cloud-based services]].
