# Network Effects

**Network effects** (or network externalities) describe a phenomenon where the value of a good or service increases as the number of users increases. This positive [[concepts/feedback|feedback]] [[concepts/loop|loop]] drives [[concepts/adoption|adoption]] and creates barriers to entry for competitors.

## Core Mechanisms
- **Direct Network Effects**: Value increases directly through user connectivity (e.g., Telephony, Social Media).
- **Indirect Network Effects**: Value increases via complementary goods/services (e.g., Operating Systems attracting app developers).
- **Two-Sided Markets**: Interdependence between distinct user groups (e.g., platforms connecting buyers and sellers).

## Dynamics & Implications
- **Critical Mass**: Minimum user base required to sustain self-reinforcing growth.
- **Lock-in & [[concepts/vendor-lock-in|Switching Costs]]**: High [[concepts/inertia|inertia]] once a network standard is established.
- **Winner-Takes-All**: Tendency toward monopoly or oligopoly due to [[concepts/computational-scaling|scaling]] advantages.
