# Claude

## Key Developments & Techniques

- **[[concepts/prompting-20|Prompting 2.0]] Paradigm**: Integration of [[entities/andrej-karpathy|Andrej Karpathy]]'s "[[concepts/prompting|Prompting]] 2.0" methodology, which shifts focus from rigid instruction structures to leveraging [[concepts/unstructured-input|unstructured input]] for enhanced [[concepts/llm-comprehension|LLM comprehension]] [[lab-notes/2026-08-09-Karpathys-Prompting-2.0-Leveraging-Unstructured-Input-fo|Karpathy's Prompting 2.0: Leveraging Unstructured Input for Advanced LLM Comprehension]].
- **Unstructured Input Handling**: Optimized for processing raw, [[concepts/unstructured-data|unstructured data]] streams, allowing [[concepts/claude-ai|Claude]] to derive context and intent more effectively than traditional token-based prompting.
- **Viral Methodology**: Recognized for "insane results" in advanced comprehension tasks, marking a significant departure from conventional prompting strategies.
- **[[concepts/generative-prediction|Generative Prediction]]**: Operates as a generative [[concepts/user-attention-prediction|prediction]] system to process unstructured input for enhanced LLM comprehension.
- **Claude Watermarks**: Recent developments include the introduction of [[concepts/watermarks|Claude Watermarks]] for content provenance.
