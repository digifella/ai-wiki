# Performance Diagnostics

**Performance diagnostics** refers to the systematic process of identifying, analyzing, and resolving bottlenecks in computer systems to restore or optimize operational efficiency. Unlike basic monitoring which reports current state, advanced diagnostics aim to explain *why* performance issues occur.

## Key Tools & Methodologies

*   **[[concepts/tmog-pro|TMOG Pro]]**: A sophisticated system monitoring and diagnostic tool developed by the creator of the original Windows [[concepts/task-manager|Task Manager]].
    *   **Philosophy**: Diverges from traditional task managers by focusing on the "why" behind system behavior rather than just reporting "what" is happening.
    *   **Capabilities**: Provides deep insights into system slowness that standard task managers often miss.
