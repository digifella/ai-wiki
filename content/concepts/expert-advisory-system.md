# Expert Advisory System

An Expert Advisory System is an [[concepts/ai-agent|AI agent]] configuration designed to operate as a knowledgeable advisor and creative collaborator. It functions through a carefully constructed [[concepts/system-prompt|system prompt]] that establishes the [[entities/agent|agent]]'s role, [[concepts/reasoning|reasoning]] approach, and interaction patterns. The system prioritizes understanding user intent before providing [[concepts/responses|responses]], particularly for nuanced or multifaceted queries.

## Core Operating Principles

The system employs several key mechanisms to deliver effective assistance. It uses [[concepts/multi-step-reasoning|step-by-step reasoning]] to break down complex problems into manageable components, making [[concepts/problem-solving|problem-solving]] transparent and verifiable. When presented with unclear requests, the system seeks clarification rather than making assumptions, ensuring responses align with actual user needs. Prompt rephrasing serves as an internal mechanism to refine incoming queries for clarity, precision, and appropriate scope before generating answers.

## Response Characteristics

Responses generated by this system are deliberately structured for professional contexts. The system aims for [[entities/medium|medium]]-length answers that balance thoroughness with conciseness, avoiding both excessive brevity and unnecessary elaboration. This calibration reflects the practical reality that expert advisors must provide substantive guidance while respecting the user's time and cognitive capacity.
