# Cloud Computing

Cloud computing refers to the delivery of computing resources and services—including servers, [[entities/storage|storage]], databases, [[concepts/software|software]], and processing [[concepts/power|power]]—over networks, typically the internet. Rather than maintaining physical infrastructure locally, users access these resources on-demand from remote data centers operated by cloud service providers. This model enables organizations and individuals to scale computational capacity dynamically based on immediate needs, paying only for resources consumed.

## Infrastructure and Deployment

Cloud platforms provide the underlying infrastructure necessary for [[concepts/running|running]] applications and services [[concepts/assistive-technology|at]] scale. This includes [[concepts/virtual-machines|virtual machines]], [[concepts/containerization|containerization]] systems, and managed services that abstract away [[concepts/hardware|hardware]] complexity. The distributed [[entities/nature|nature]] of cloud infrastructure makes it particularly suited for deploying [[concepts/artificial-intelligence-models|machine learning models]] and AI systems, where substantial [[concepts/computational-resources|computational resources]] are required during both [[concepts/training|training]] and [[concepts/inference|inference]] phases. Cloud providers offer various [[concepts/deployment|deployment]] options—public clouds accessible to any user, private clouds for single organizations, and hybrid arrangements combining both approaches.

## Practical Applications

Cloud computing has become foundational to modern computational workflows, particularly in domains requiring significant processing power. Organizations use cloud platforms to train large-scale [[concepts/ai-models|AI models]], run data analysis pipelines, and serve applications to global audiences. The [[concepts/accessibility|accessibility]] of cloud resources has lowered barriers to entry for computational research and development, allowing smaller teams to access infrastructure previously available only to well-resourced institutions.
