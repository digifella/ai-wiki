# Docling

[[concepts/docx|Docling]] is an [[concepts/open-source|open-source]] toolkit developed by [[entities/ibm-research|IBM Research]] for processing documents within [[concepts/ai-technologies|artificial intelligence]] workflows. It is designed to handle various document formats and extract content in a structured manner suitable for downstream [[concepts/ai-powered-applications|AI applications]].

## Document Processing Capabilities

The toolkit provides functionality for parsing and converting documents into formats that can be readily used by AI systems. This includes extracting [[concepts/text|text]], layout information, and other structured content from source documents, reducing manual [[concepts/data-preprocessing|preprocessing]] steps in document-heavy AI pipelines.

## Integration and Use Cases

Docling is intended for [[concepts/integration|integration]] into AI workflows where document understanding is required. Organizations use it to automate the ingestion and [[concepts/preparation|preparation]] of document content, enabling more efficient processing of information across enterprise systems and AI [[concepts/software|applications]].
