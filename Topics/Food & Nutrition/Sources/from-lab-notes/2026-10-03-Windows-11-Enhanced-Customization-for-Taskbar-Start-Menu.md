## Windows 11: Enhanced Customization for Taskbar, Start Menu, and Search
**Clip title:** [[concepts/microsoft-windows|Windows]] 11 Just Got WAY More Customizable
**[[entities/tasia-custode|Author]] / channel:** Kevin Stratvert
**URL:** https://www.youtube.com/watch?v=FsTq4NPIBqY

### Summary
When [[entities/windows-11|Windows 11]] first launched, many users noted a significant reduction in [[concepts/customization|customization]] options compared to previous Windows versions. The video highlights that after some time, [[entities/microsoft|Microsoft]] is now reintroducing many of these sought-after features and adding new ones, allowing users to personalize their operating system [[concepts/experience|experience]] more thoroughly. The key areas receiving these [[concepts/software-updates|updates]] include the Taskbar, the Start Menu, and the Windows Search functionality.

A major enhancement is the ability to customize the Taskbar. Users can now move the taskbar from its default bottom position to the top, left, or right sides of the screen, a long-requested feature. Additionally, the taskbar's size can be adjusted to "small" or "default," though the video [[concepts/notes|notes]] that when placed on the sides, only the icons shrink, not the overall width of the bar. Users also gain [[concepts/granular-control|granular control]] over which elements appear on the taskbar, with options to hide or display the Search box (as a full box, an icon and label, or just an icon), Task View, Widgets, and various system tray icons. For quick desktop access, a handy feature allows users to click the far right corner of the taskbar or use the `Windows + D` shortcut to instantly minimize all open windows.

Further [[concepts/customization|customization]] extends to the Start Menu and Windows Search. The Start Menu now offers size options—"Automatic," "Small," and "Large"—to make it more compact or expansive. Users can also control which sections are displayed, such as "Pinned" applications, "Recent" items, or "All installed [[concepts/apps|apps]]," enabling a much cleaner and more tailored menu by turning off unused categories. A significant [[concepts/privacy|privacy]] and efficiency improvement comes with new search settings that allow users to disable web search results and Microsoft Store suggestions. This ensures that Windows Search focuses solely on local content—[[concepts/apps|apps]], documents, settings, folders, and photos—providing a less cluttered and more relevant search [[concepts/experience|experience]] for on-device content, with the presenter suggesting a web browser for internet searches.

In conclusion, these [[concepts/software-updates|updates]] signify Microsoft's response to [[concepts/user-feedback|user feedback]], restoring and expanding [[concepts/personalization|personalization]] capabilities in Windows 11. By providing more control over the Taskbar's position and content, the Start Menu's layout, and the focus of search results, the company is empowering users to create a [[concepts/computation|computing]] environment that is more efficient, intuitive, and uniquely tailored to their individual preferences.
