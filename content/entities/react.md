# React

JavaScript library for building user interfaces, emphasizing component-based [[concepts/architecture|architecture]] and virtual [[concepts/dom|DOM]] for efficient rendering. Developed and maintained by Facebook ([[entities/meta-ai|Meta]]).

## Key Features
- Declarative syntax for predictable UI updates
- Unidirectional data [[concepts/flow|flow]]
- JSX (JavaScript XML) for templating
- Ecosystem includes React Router, Redux, and Next.js
