# Apache 2.0
[[concepts/apache-2.0|Apache 2.0]] is a permissive [[concepts/open-source|free software]] [[concepts/license|license]] that guarantees users the right to use, modify, distribute and commercially deploy any licensed [[concepts/software|software]] without needing the copyright holder's permission.

### Key Features of Apache 2.0 License
- **Permissive [[concepts/licensing|Licensing]]:** Allows for both proprietary and [[concepts/open-source|open-source]] derivative works.
- **No Copyleft:** Does not require derivative works to be distributed under the same license.
- **Patent Protection:** Grants a patent license from contributors to users, protecting against patent trolls.
