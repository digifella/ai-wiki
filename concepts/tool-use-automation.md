# tool-use automation

The capability of [[concepts/ai-models|AI models]] to interact with external software, datasets, and environments to execute [[concepts/agentic-tasks|autonomous tasks]] and workflows.

## Key Mechanisms
- [[concepts/model-context-protocol|Model Context Protocol (MCP)]]: A [[concepts/universal-plug|universal plug]]-and-play technology that enables [[concepts/ai-models|AI models]] to connect directly to [[concepts/external-data|external data]] sources and tools, overcoming the limitations of traditional [[concepts/chat-interfaces|chat interfaces]] restricted to uploaded files.

## Agentic Implementations
- [[concepts/claude-code|Claude Code]]: Uses powerful [[concepts/agentic-ai|AI agents]] and MCP to transform standard [[concepts/ai-bots|chatbots]] into agents capable of interacting with external systems.
