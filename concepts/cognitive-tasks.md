# Cognitive Tasks

**Cognitive tasks** refer to [[concepts/cognition|mental processes]] required to perform actions, including perception, [[concepts/memory|memory]], [[concepts/reasoning|reasoning]], and [[concepts/problem-solving-skills|problem-solving]]. In the context of [[concepts/artificial-general-intelligence]], the capacity to execute a wide range of these tasks autonomously is a primary benchmark for intelligence.

## Key Perspectives

### Shane Legg on Minimal AGI
Shane Legg, Co-founder of [[entities/google-deepmind]], proposes a functional definition of AGI centered on [[concepts/workflow-automation|task execution]]. Key insights from his recent discussions include:

*   **Definition of [[concepts/minimal-agi|Minimal AGI]]:** Legg defines "minimal AGI" as an artificial agent capable of performing cognitive tasks across a broad spectrum of domains, rather than excelling in a single narrow field.
*   **Trajectory:** The path to AGI involves [[concepts/computational-scaling|scaling]] current architectures to handle the [[concepts/abstraction|generalization]] required for diverse cognitive loads.
*   **Superintelligence:** The transition from AGI to superintelligence hinges on the agent's ability to recursively improve its own cognitive task performance.
