# Camera App Design

[[concepts/camera-app|Camera app]] [[concepts/design|design]] focuses on creating mobile photography software that bridges the gap between smartphone convenience and professional image capture [[concepts/capabilities|capabilities]]. These [[concepts/software|applications]] aim to give mobile users greater [[concepts/power|control]] over photographic [[concepts/parameters|parameters]] and post-processing workflows, moving beyond the standard features built into device operating systems. The field emerged as smartphone cameras became technically sophisticated enough to support advanced photographic techniques.

## Adobe Project Indigo

[[concepts/on-device-editing|Adobe Project Indigo]] represents a notable development in mobile camera application design. Introduced by [[entities/colin-smith|Colin Smith]] of [[entities/colin-smith-channel|PhotoshopCAFE]], the application was built specifically to enable advanced mobile photography workflows. The project demonstrates an effort by established software companies to create dedicated tools that leverage mobile device [[concepts/hardware|hardware]] while providing professional-grade capture and editing capabilities within a single application.

## Design Considerations

Camera app design typically addresses the challenge of presenting complex photographic controls on mobile interfaces without overwhelming casual users. Successful applications balance [[concepts/accessibility|accessibility]] with depth, offering simplified modes for standard photography while providing [[concepts/manual-controls|manual controls]] for [[concepts/exposure|exposure]], focus, and [[concepts/photo-tonal-adjustments|color grading]] for users seeking greater creative control. The design of these apps also considers how mobile workflows integrate with broader creative processes, from capture through editing and sharing.
