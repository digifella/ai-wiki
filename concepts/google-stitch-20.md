# Google Stitch 20

[[concepts/clickable-prototyping|Google Stitch 2.0]] is an [[concepts/ai-technologies|artificial intelligence]] design agent developed by Google that automates the conversion of design concepts into visual outputs. The platform accepts multiple input formats, including text descriptions and hand-drawn sketches, allowing designers to rapidly transform initial [[concepts/ideas|ideas]] into concrete design assets. By facilitating this transition, the tool aims to reduce iteration time within standard [[concepts/design-workflows|design workflows]].

## Functionality

The system processes diverse input types, such as textual briefs and freehand sketches, to generate corresponding visual designs. This capability enables users to bypass manual drafting for early-stage visualization, effectively streamlining the path from abstract concept to finished visual work. The agent focuses on interpreting user intent across different media to produce relevant design elements.
