# Automated feedback loops

A self-regulating mechanism where the output of a process is automatically evaluated against predefined criteria and fed back into the system to refine subsequent inputs or actions. In [[concepts/ai-coding|AI coding]], these loops are essential for reducing manual supervision and enabling autonomous agentic behavior.

### Key Workflows & Applications
- **[[concepts/test-driven-development|TDD]] for [[concepts/agentic-ai|AI Agents]]:** Implementing [[concepts/test-driven-development|Test-Driven Development]] as an automated evaluation layer for [[concepts/claude-code|Claude Code]] (an [[concepts/ai-coding|AI coding]] [[entities/agent|agent]]) to drive iterative [[concepts/code|code]] refinement and error correction (Source: [[entities/yifan|Yifan]], [[entities/beyond-the-hype|Beyond the Hype]]).
