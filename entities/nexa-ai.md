### Nexa SDK
An [[concepts/open-source|open-source]], ground-up toolkit designed for efficient [[concepts/ai-model-deployment|model deployment]] across local hardware.

#### Key Features
- **Multi-Backend Execution**: Enables running models across NPUs, GPUs, and CPUs.
- **[[concepts/privacy|Privacy]]-First**: Ensures all data remains local to the user's machine.
- **Format Versatility**: Supports multiple model formats, including [[concepts/gguf|GGUF]] and MLX.
- **Performance Optimized**: Engineered from scratch for maximum hardware efficiency.
- **Ecosystem Context**: Provides specialized differentiation from existing tools like [[entities/ollama]] and [[entities/llamacpp]].
