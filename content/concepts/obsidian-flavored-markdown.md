# Obsidian Flavored Markdown

[[concepts/obsidian|Obsidian]] Flavored Markdown is the [[concepts/markdown|markdown]] variant used within Obsidian, a personal [[concepts/knowledge-management|knowledge management]] application. It extends standard markdown with features designed for note-taking and [[concepts/knowledge-organization|knowledge organization]], including wikilinks (using `double bracket` syntax for internal links), tags, and block references. This flavor prioritizes interconnectedness between [[concepts/notes|notes]], enabling users to build networks of related information within their vault—the local folder [[concepts/structure|structure]] that contains all notes.

## Integration with AI and Version Control

Recent development practices have demonstrated [[concepts/integration|integration]] of Obsidian Flavored Markdown with [[concepts/terminal-based-ai-coding-agents|AI coding assistants]] and [[concepts/github-synchronization|GitHub synchronization]]. This approach allows automated workflows where [[concepts/ai-assisted-coding|Claude Code]] or similar tools can read, process, and generate markdown notes directly, with changes synchronized to version [[concepts/power|control]] systems. Such setups enable note creation and modification to be part of continuous development processes rather than manual, isolated activities.

The combination of Obsidian's markdown flavor with programmatic access creates possibilities for augmented personal knowledge management systems where AI can assist in organizing, linking, and surfacing information from a growing [[concepts/knowledge-base|knowledge base]].
