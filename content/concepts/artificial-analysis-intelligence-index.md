# Artificial Analysis Intelligence Index

The [[entities/artificial-analysis|Artificial Analysis]] Intelligence Index is a framework for evaluating and comparing [[concepts/large-language-model-llm|large language models]] and AI systems based on standardized [[concepts/performance-data-gathering|performance metrics]]. It assesses models across multiple dimensions including latency, throughput, [[concepts/cost|cost]] per token, and [[concepts/inference|inference]] efficiency. The index enables developers, researchers, and organizations to understand the practical trade-offs between different [[concepts/ai-models|AI models]] when selecting solutions for specific [[concepts/scenarios|use cases]].

## Evaluation Metrics

The index measures performance across several key dimensions relevant to [[concepts/deployment|production deployment]]. Latency captures response time, while throughput indicates how many requests a model can process simultaneously. Cost per token and overall [[concepts/pricing-structure|pricing structure]] help organizations evaluate economic viability. Inference efficiency metrics assess computational resource requirements relative to [[concepts/output|output]] quality, addressing both energy consumption and [[concepts/hardware|hardware]] needs.

## Application and Use Cases

The framework serves practitioners making model selection decisions for [[concepts/software|applications]] ranging from real-time conversational systems to batch processing tasks. By providing comparative data across models, the index helps clarify whether a smaller, faster model might suffice for a given application or whether higher capability is necessary. This is particularly relevant as the AI model landscape has expanded to include variants optimized for different deployment constraints, such as edge devices or latency-sensitive services.
