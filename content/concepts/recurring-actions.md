# Recurring Actions

Recurring Actions is a feature within [[entities/gemini-models|Google Gemini]] that enables users to schedule and automate tasks that need to be performed on a regular basis. The feature allows users to set up workflows that execute automatically at specified intervals without requiring manual intervention each time. This functionality integrates [[concepts/recurring-tasks|task scheduling]] capabilities directly into the [[concepts/gemini|Gemini]] interface, reducing the need for users to manually repeat the same operations.

## Use Cases

The feature is designed to support business workflows and productivity [[concepts/automation|automation]], allowing users to automate routine tasks such as data processing, report generation, or information gathering on a scheduled basis. By enabling recurring execution of predefined actions, users can maintain consistent workflows across their [[concepts/software|applications]] and projects without manual repetition.

## Integration Context

Recurring Actions operates within [[concepts/google-search|Google]]'s broader ecosystem of AI-powered [[concepts/productivity-tools|productivity tools]], including features in [[entities/notebook-lm|Notebook LM]] and other Gemini-integrated applications. The feature represents part of a larger trend toward AI-assisted [[concepts/ai-driven-workflow-automation|workflow automation]], alongside similar capabilities being developed in competing platforms and [[concepts/generative-apps|generative AI applications]].
