# Optical Character Recognition (OCR)

Optical Character Recognition (OCR) is a technology that converts [[concepts/images|images]] of text, tables, and documents into machine-readable text formats. In the context of [[concepts/agentic-ai|AI agents]] and retrieval-augmented generation (RAG) systems, OCR serves as a critical [[concepts/data-preprocessing|preprocessing]] step that enables the extraction and indexing of information from unstructured visual documents.

## OCR for Retrieval-Augmented Generation

Modern [[concepts/open-source|open-source]] OCR models have been developed specifically to handle table extraction and conversion to text, which is essential for RAG pipelines. These models allow AI systems to process documents containing [[concepts/json-structuring|structured data]] in table format, converting them into text that can be indexed and retrieved by language models. This capability is particularly important for systems that need to access information from scanned documents, PDFs, or images where data is presented in tabular form.

## Applications in AI Systems

OCR technology enables AI agents to work with a broader range of input sources beyond plain text documents. By converting visual representations of text and tables into structured text data, OCR expands the knowledge bases that [[concepts/contextualized-language-understanding|RAG systems]] can draw from, improving the relevance and [[concepts/accuracy|accuracy]] of retrieval-augmented [[concepts/responses|responses]].
