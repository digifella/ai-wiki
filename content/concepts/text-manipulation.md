# Text manipulation

The process of altering, parsing, or transforming [[concepts/integrity|character]] strings to facilitate [[concepts/data-cleaning|Data Cleaning]], [[concepts/data-extraction]], and [[concepts/data-formatting]].

## Core Techniques
- [[concepts/regular-expressions]] (Regex): Utilizing pattern-matching syntax to identify, isolate, or modify complex string sequences.
- String Parsing: Deconstructing text into constituent, identifiable components.
- Pattern Substitution: Replacing identified substrings with new values based on defined criteria.

## Tools & Applications
### Microsoft Excel
- [[concepts/native-integration|Native integration]] of [[concepts/regular-expressions]] via new specialized functions:
    - `REGEXEXTRACT`: Streamlines [[concepts/data-extraction]] by pulling specific patterns from unstructured cells.
    - `REGEXREPLACE`: Enables efficient Data Cleaning and pattern-based text replacement/formatting.
