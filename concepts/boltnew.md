# Boltnew

[[entities/boltnew|Boltnew]] is a structured methodology for developing software products by leveraging [[concepts/claude-ai|Claude]]'s [[concepts/code-generation|code generation]] capabilities. The approach prioritizes a documentation-first strategy, requiring the creation of a comprehensive markdown-based [[concepts/prd|product requirements document]] (PRD) before any implementation begins. This initial [[concepts/phase|phase]] establishes [[concepts/clarity-slider|clarity]] and [[concepts/logical-consistency|logical consistency]], providing a stable reference point that guides subsequent work and reduces [[concepts/ambiguity|ambiguity]] regarding project scope and objectives.

The methodology relies on two primary components working in concert: the [[concepts/markdown|markdown]] PRD and a [[concepts/task-manager|task manager]] for [[concepts/subagents|subagents]]. The PRD serves as the foundational blueprint, detailing the product's features, architecture, and constraints. The task manager then breaks down the requirements into executable steps, delegating specific [[concepts/coding|coding]] and refinement tasks to specialized subagents. This division of labor allows for [[concepts/parallel-processing|parallel processing]] of complex [[concepts/development-workflows|development workflows]] while maintaining alignment with the central requirements document.

By integrating detailed planning with [[concepts/code-execution|automated execution]], Boltnew aims to streamline the software [[concepts/software-development-process|development lifecycle]]. The structured interaction between the high-level PRD and the granular subagent tasks ensures that code generation remains focused and coherent. This system reduces the need for manual oversight during routine coding tasks, allowing developers to concentrate on architectural decisions and high-level [[concepts/problem-solving-skills|problem solving]].
