# Interactive Html Sites

Interactive HTML sites can be generated by converting [[concepts/ai-integrated-notebooks|NotebookLM]] [[concepts/mind-maps|mind maps]] using [[entities/gemini-models|Gemini AI]] as an intermediary tool. This [[concepts/workflow|workflow]] leverages [[concepts/notebooklm|NotebookLM]]'s ability to organize information visually through mind maps, then transforms that [[concepts/json-structuring|structured data]] into functional [[concepts/web-applications|web applications]]. The process bridges note-taking and [[concepts/website-building|web development]], allowing users to convert [[concepts/conceptual-frameworks|conceptual frameworks]] into clickable, navigable digital experiences without requiring extensive [[concepts/coding|coding]] knowledge.

## Core Workflow

The typical process involves creating a mind map in NotebookLM to establish the information [[concepts/hierarchy|hierarchy]] and [[concepts/relationships|relationships]] between concepts. This mind map is then provided to [[entities/gemini-ai|Gemini AI]], which generates HTML, CSS, and JavaScript [[concepts/code|code]] based on the map's [[concepts/structure|structure]]. Gemini AI interprets the [[concepts/nodes|nodes]] and connections in the mind map to create corresponding interactive elements, navigation systems, and visual layouts that reflect the original organizational logic.

## Applications

This approach has practical [[concepts/software|applications]] in [[concepts/client-onboarding|client onboarding]] processes, where complex information structures need to be presented in accessible, interactive formats. Organizations can automate the conversion of documentation and procedural guides from static mind maps into web-based tools that users can explore and navigate intuitively. The method also extends to converting NotebookLM-generated [[concepts/infographic-design|infographics]] into fully functional web applications, preserving visual relationships while adding interactivity.
