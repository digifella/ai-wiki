# Gemini App

[[concepts/gemini|Gemini]] App is an [[concepts/ai-powered-application|AI-powered application]] designed to assist users in generating content and creating presentations through an intuitive interface. The application leverages [[concepts/ai-technologies|artificial intelligence]] to streamline the [[concepts/content-creation|content creation]] process, making it accessible for users to produce structured outputs without extensive manual effort.

## Canvas Workflow

The application features a canvas-based [[concepts/workflow|workflow]] system that allows users to request content generation through natural [[concepts/natural-language-prompting|language prompts]]. Users can select the [[concepts/canvas|Canvas]] option and provide [[concepts/instructions|instructions]] such as "Please create a slide deck about [topic]" to initiate the creation process. This approach enables [[concepts/rapid-prototyping|rapid prototyping]] and [[concepts/iteration|iteration]] of presentation content.

## Export and Integration

Generated content can be exported directly to [[concepts/google-slides|Google Slides]], enabling seamless [[concepts/integration|integration]] with Google's productivity suite. The application utilizes [[entities/gemini-pro|Gemini Pro]] as its underlying AI model to [[concepts/power|power]] these generation and export [[concepts/capabilities|capabilities]], allowing users to move between the Gemini App environment and standard presentation tools.
