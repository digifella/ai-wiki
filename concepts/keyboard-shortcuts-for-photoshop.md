# Keyboard Shortcuts For Photoshop

Keyboard shortcuts in [[concepts/photoshop|Adobe Photoshop]] are customizable key combinations that trigger [[concepts/commands|commands]], activate tools, or execute functions without requiring menu navigation. They form a central part of efficient workflow in the application, allowing users to reduce repetitive mouse movements and menu searching. [[entities/adobe-photoshop|Photoshop]] ships with an extensive default set of shortcuts covering [[concepts/tool-selection|tool selection]], layer operations, view controls, and filter application.

## Common Shortcuts

Frequently used shortcuts include Ctrl+Z (Cmd+Z on Mac) for undo, Ctrl+S for save, and single-letter keys for tool activation such as V for the move tool or M for selection tools. View navigation shortcuts like the spacebar for temporary hand tool access and bracket keys for [[concepts/brush-size|brush size]] adjustment are integral to day-to-day use. Layer management relies heavily on shortcuts for operations like merging layers, creating new layers, and adjusting [[concepts/opacity|opacity]].

## Customization and Discovery

Users can view, modify, and create custom shortcuts through Photoshop's keyboard shortcuts dialog, accessible via the Edit menu. This flexibility allows individuals to tailor their setup to personal preferences or match conventions from other software. The application also provides keyboard shortcut hints throughout its interface, including in menu items and tooltips, helping users discover alternatives to mouse-dependent workflows.

[[concepts/expertise|Mastery]] of keyboard shortcuts significantly accelerates work in Photoshop, particularly for tasks performed repeatedly during [[concepts/image-editing|image editing]] and design projects. Different users emphasize different shortcuts based on their typical workflows, though certain combinations remain nearly universal across the user base.
