# Ollama
Framework for running [[concepts/large-language-models|Large Language Models]] locally on [[entities/macos|macOS]], [[entities/linux|Linux]], and [[entities/windows|Windows]].

## Details
- **Current Version**: `v0.20.2`
- **Core Functionality**: Facilitates [[concepts/local-llm|Local LLM inference]], model management, and REST [[concepts/third-party-app-integration|API integration]].
- **Privacy & [[concepts/security|Security]]**: Enables fully local processing, ensuring [[concepts/privacy|data privacy]] by keeping models and data on-premise. Often paired with [[concepts/cybersecurity-defense|security frameworks]] like [[entities/archest-ai|Archest.AI]] for production environments.
- **[[concepts/knowledge-management|Knowledge Management]] Integration**: 
  - Serves as the inference backend for local AI-powered [[concepts/note-management|note management]] systems.
  - Integrates with [[entities/obsidian|Obsidian]] and [[entities/hermes-agent|Hermes Agent]] to create hands-free, private knowledge workflows.
