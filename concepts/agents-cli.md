# agents-cli

**agents-cli** is an [[concepts/open-source|open-source]] [[concepts/command-line-interaction|command-line interface]] developed by [[entities/google]] designed to streamline the full lifecycle of [[concepts/ai-agent]] development, ranging from initial concept prototyping to reliable deployment. It combines [[concepts/programmatic-interaction|CLI automation]] with a "[[concepts/skills|Skills]]" architecture to simplify agent creation and management.

## Key Features & Architecture

- **CLI-Driven Workflow**: Provides a unified [[concepts/command-line-interface|command-line]] environment for building, testing, and deploying [[concepts/agentic-ai|AI agents]] without requiring complex GUI configurations or extensive boilerplate code.
- **Skills Integration**: Utilizes a modular "Skills" system that allows developers to attach specific capabilities or functions to agents dynamically, enabling rapid [[concepts/iteration|iteration]] on agent behaviors.
- **Lifecycle Management**: Handles end-to-end development stages, reducing [[concepts/friction|friction]] between conceptual design and production-ready implementations.
