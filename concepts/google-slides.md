# Google Slides

[[entities/google-slides|Google Slides]] is a web-based presentation software available as part of [[concepts/google-workspace|Google Workspace]]. It allows users to create, edit, and share [[concepts/slide-decks|slide decks]] directly through a web browser without requiring [[concepts/software-installation|software installation]]. Presentations are automatically saved to [[concepts/google-drive|Google Drive]], providing cloud-based [[entities/storage|storage]] and [[concepts/accessibility|accessibility]] from any device with internet access.

## Collaboration Features

A primary strength of [[concepts/google-search|Google]] Slides is its real-time collaboration capability. Multiple users can work on the same presentation simultaneously, with changes visible to all collaborators instantly. Users can leave comments, suggest edits, and communicate within the platform, streamlining the [[concepts/feedback|feedback]] process during presentation development.

## Integration and Compatibility

[[entities/google|Google]] Slides integrates with other [[entities/google-workspace|Google Workspace]] applications, including [[entities/google-docs|Google Docs]], [[entities/google-sheets|Google Sheets]], and [[entities/gmail|Gmail]]. It supports importing presentations from [[entities/microsoft|Microsoft]] PowerPoint and exporting to various formats, including PDF and PowerPoint files. This flexibility allows users to work across different presentation tools and platforms as needed.

## Features and Functionality

The application offers a range of design [[concepts/templates|templates]], formatting options, and the ability to embed images, videos, and charts. Users can present directly from the platform with [[entities/speaker|speaker]] [[concepts/notes|notes]], presenter view, and real-time audience engagement features. Offline editing is also supported, allowing users to continue working without an internet [[concepts/connection|connection]] and synchronizing changes when reconnected.
