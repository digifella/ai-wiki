# MLX format

A model format optimized for the MLX framework, specifically engineered to leverage the unified [[concepts/memory|memory]] [[concepts/architecture|architecture]] of Apple [[concepts/silicon|Silicon]] for [[entities/high-performance|high-performance]] [[concepts/local-execution|local execution]].

### Compatibility & Tooling
- **[[concepts/nexa-sdk]]**: An [[concepts/open-source|open-source]] [[concepts/developer|developer]] toolkit for [[concepts/local-ai|local AI]] [[concepts/deployment|deployment]].
	- Supports MLX and GGUF formats.
	- Enables execution across multiple backends, including NPUs, GPUs, and CPUs.
	- Optimized for [[concepts/privacy|privacy]] by ensuring all data remains local.
