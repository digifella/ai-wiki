# This video announces and explains the new updates to [[entities/openai|OpenAI]]'s [[concepts/codex|Codex]] using 5.1 and [[concepts/cloud-agents|cloud agents]] on gi

---
---
<https://www.youtube.com/watch?v=6-I0-p-Lhug>

This video announces and explains the new updates to OpenAI's Codex, which now includes three new [[concepts/models|models]]:

* **[[entities/chatgpt-51|ChatGPT 5.1]]:** This model is excellent for planning and generating [[concepts/creative-ideas|creative ideas]]. The [[entities/speaker|speaker]] emphasizes its effectiveness as a creative partner for [[concepts/brainstorming|brainstorming]] and structuring projects.
* **[[entities/chatgpt-51-codex|ChatGPT 5.1 Codex]]:** A version of 5.1 specifically optimized for larger, more complex [[concepts/coding|coding]] tasks. It's designed to be more thorough, using more [[concepts/tokens|tokens]] and taking more time to ensure the [[concepts/code|code]] is correct the first time.
* **[[entities/chatgpt-51-codex-mini|ChatGPT 5.1 Codex Mini]]:** This is a faster, more lightweight model intended for smaller coding tasks like [[concepts/debugging|debugging]], making styling changes, and other quick tweaks. It's more efficient with tokens for these types of jobs.

The speaker demonstrates how to use these models within Visual Studio Code through the Codex extension. He outlines a new [[concepts/workflow|workflow]]:

1. Use ChatGPT 5.1 in "chat mode" to plan out the application [[concepts/structure|structure]] and features.
2. Switch to "[[concepts/agent-mode|agent mode]]" and use ChatGPT 5.1 Codex for the initial, large-scale build of the application.
3. For smaller fixes and refinements, use the faster and more efficient ChatGPT 5.1 Codex Mini.

The video also touches on the "Cloud Agents" feature in Codex, which allows users to run tasks in the cloud, even multiple versions of a task simultaneously, to compare results and select the best option.
Finally, the speaker briefly compares Codex with [[concepts/claude-code|Claude Code]]. While he [[concepts/notes|notes]] that the new updates are a massive improvement for Codex, he personally still prefers the results from Claude Code (specifically Sonnet 4.5) for its [[concepts/design|design]] and aesthetic output, though he acknowledges that the gap between the two is closing.
