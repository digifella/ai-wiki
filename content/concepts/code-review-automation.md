# Code review automation

The use of [[concepts/ai-agent|AI agent]] technology and [[concepts/automation-tools|automated workflows]] to evaluate code quality, identify bugs, and ensure adherence to architectural [[concepts/open-standards|standards]] during the development lifecycle.

### Specialized Frontend Automation
- [[entities/kombai]]: An AI agent [[concepts/motivation|purpose]]-built for [[concepts/front-end-development|frontend development]] that integrates directly into IDEs such as [[entities/vs-code]], [[entities/cursor]], and [[entities/windsurf|Windsurf]].
    - Specifically optimized for frontend-centric tasks, distinguishing it from general-[[concepts/purpose|purpose]] coding assistants.
    - Demonstrates significantly higher performance in code review tasks, with a 72% success rate compared to the 30-50% success rates seen in general-purpose tools like GitHub [[entities/copilot|Copilot]], [[entities/codepal|CodePal]], and [[entities/gemini]].
