# Foundry

Foundry is a development platform engineered for the creation of artificial intelligence applications that prioritize local execution on end-user devices. By emphasizing bare metal performance over cloud-dependent architectures, the platform enables developers to build software that processes data and performs computational tasks directly on the user's hardware. This architectural choice allows applications to operate independently of external server infrastructure, thereby enhancing user privacy and reducing latency.

The platform supports broad compatibility across multiple operating systems, including PC, macOS, and mobile environments. This cross-platform capability ensures that AI-driven tools can leverage the full processing power of diverse hardware configurations without requiring specialized server-side resources. The focus on local execution allows for robust performance on standard consumer devices, making advanced AI capabilities accessible without the need for high-end cloud computing subscriptions.
