# Model Context Protocols

Model Context Protocols (MCPs) are frameworks that enable [[concepts/agentic-ai|AI agents]] and [[concepts/coding|coding]] tools to access and utilize [[concepts/external-data|external data]] sources and services more effectively. By standardizing how context information is passed to language models, MCPs help AI systems make better-informed decisions and generate more accurate code suggestions. This protocol layer sits between [[concepts/ai-models|AI models]] and the tools, documents, and systems they need to interact with.

## Application in AI Coding

Patrick Ellis, CTO and co-founder, has discussed how MCPs contribute to achieving significant productivity gains when integrated into [[concepts/ai-coding-workflows|AI coding workflows]]. By allowing [[concepts/ai-coding-assistance|coding agents]] to maintain richer context about a [[concepts/code|codebase]]—including documentation, configuration files, and project [[concepts/structure|structure]]—these protocols enable more relevant and contextually appropriate code generation. Ellis emphasizes that while AI coding tools have become technically capable, their effectiveness depends heavily on the quality and completeness of context available to them.

## Use in Agent Systems

MCPs are particularly valuable for [[concepts/business-applications|business applications]] where domain-specific knowledge must be accessed reliably. When deployed in agent-based systems for small and [[entities/medium|medium]] enterprises, these protocols enable [[concepts/specialized-sub-agents|specialized agents]] to draw from multiple knowledge sources simultaneously, allowing them to handle [[concepts/complex-tasks|complex tasks]] that require understanding both general coding patterns and [[concepts/organization|organization]]-specific requirements.
