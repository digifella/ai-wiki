# AI Agent Skills

[[concepts/financial-analyst-ai|AI Agent]] [[concepts/skills|Skills]] are modular, executable capabilities designed to extend the functional boundaries of [[concepts/large-language-models]] (LLMs) by providing structured execution paths for [[concepts/complex-tasks|complex tasks]].

### Core Functionality
- **Bridging Knowledge Gaps:** They address the inherent deficiency in [[concepts/llm]] [[concepts/procedural-knowledge]], allowing agents to move beyond linguistic [[concepts/reasoning|reasoning]] into structured, actionable execution.
- **Standardization:** Currently emerging as an open standard adopted by major [[concepts/ai-coding|AI Coding]] Platforms to facilitate interoperability between agents and [[concepts/external-tools|external tools]].
- **Structural Framework:** Provide the necessary structure to transform high-level semantic intent into reliable, repeatable, and programmatic workflows.
