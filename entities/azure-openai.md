# Azure OpenAI

[[entities/azure|Azure]] [[concepts/whisper-transcription|OpenAI]] is [[entities/microsoft|Microsoft]]'s cloud-based service that provides access to [[entities/openai|OpenAI]]'s [[concepts/large-language-model-llm|large language models]] and AI capabilities through the Azure platform. It integrates OpenAI's models with Microsoft's enterprise [[concepts/cloud-based-services|cloud infrastructure]], enabling organizations to build [[concepts/ai-powered-applications|AI applications]] with the [[concepts/security|security]], [[concepts/compliance|compliance]], and integration benefits of Azure.

## Integration with Microsoft Foundry

Azure OpenAI serves as a core component of [[concepts/agent-factory|Microsoft Foundry]], a [[concepts/unified-platform|unified platform]] for building AI applications and agents. [[concepts/ai-app-factory|Microsoft Foundry]] leverages Azure OpenAI's models alongside other Azure services to provide a comprehensive factory for developing, deploying, and managing AI-powered applications and [[concepts/agentic-systems|autonomous agents]] at enterprise scale.
