# Release Priority

**[[concepts/deployment|Release]] Priority** is a camera setting that determines whether the shutter releases immediately upon half-pressing the shutter button (prioritizing [[concepts/speed|speed]]) or waits for focus confirmation (prioritizing [[concepts/sharpness|sharpness]]).

## Key Interactions

*   **Fujifilm [[concepts/afmf|AF+MF]] Override:** On [[entities/fujifilm|Fujifilm cameras]], enabling **AF+MF** (Auto Focus + [[concepts/manual-focus|Manual Focus]]) can override standard [[concepts/focus-priority|Focus Priority]] behaviors.
    *   When AF+MF is active, the camera allows manual focus adjustment even while the shutter is half-pressed.
    *   This interaction may cause the shutter to release before the focus is fully locked, resulting in blurry photos [[lab-notes/2026-10-03-Fujifilm-AFMF-overrides-Focus-Priority-causing-blurry-ph|Fujifilm AF+MF overrides Focus Priority, causing blurry photos.]].
    *   See [[entities/pal2tech]] for detailed analysis of this specific setting [[concepts/conflict|conflict]].
