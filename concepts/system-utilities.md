# System Utilities

**System utilities** refer to software designed to analyze, configure, optimize or maintain computer systems. In the context of mobile operating systems, these utilities often manifest as hidden or advanced settings that allow for deeper control over device behavior, [[concepts/privacy|privacy]], and [[concepts/media-management|media management]].

## iOS 27 System Utilities

Recent [[concepts/software-updates|updates]] to [[entities/ios]] have introduced several subtle functionalities that expand the scope of system utilities available to users. Based on the latest analysis, the following features enhance [[concepts/user-control|user control]] and [[concepts/experience|experience]]:

- **Privacy Settings**: Enhanced [[concepts/causes|mechanisms]] for tracking and [[concepts/data-management|data management]], providing users with clearer visibility into app permissions.
