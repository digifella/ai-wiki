# Marp

Marp is a [[concepts/markdown|markdown]]-based presentation system that enables users to create [[entities/google-slides|slides]] directly from [[concepts/markdown-guide|markdown syntax]]. Rather than using traditional presentation [[concepts/software|software]] with graphical interfaces, Marp allows presentations to be written as plain text markdown files, which are then rendered into [[concepts/slide-decks|slide decks]]. This approach integrates presentation creation into text-based workflows and version control systems.

## Technical Approach

The system converts markdown files into presentations through automated rendering, making it compatible with [[concepts/developer|developer]]-oriented tools and practices. Presentations created with Marp can be exported to various formats including HTML and PDF, and the markdown source files remain human-readable and easy to edit.

## Integration with AI Tools

Marp gained [[concepts/attention-mechanisms|attention]] in discussions about AI-assisted [[concepts/content-creation|content creation]], particularly in relation to tools like [[concepts/ai-assisted-coding|Claude Code]]. The system's text-based [[entities/nature|nature]] makes it suitable for AI code generation, where language models can directly produce markdown that generates complete presentations. This capability has been highlighted as a practical application of AI in automating presentation [[concepts/development-workflows|development workflows]].
