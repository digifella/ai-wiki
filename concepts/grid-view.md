# Grid View

**Grid View** is a [[concepts/user-interface|user interface]] feature within [[entities/adobe-camera-raw]] that allows users to view multiple images simultaneously in a tiled layout. This facilitates rapid comparison, culling, and [[concepts/logical-consistency|consistency]] checks across a batch of photos.

## Key Features in ACR 18.7

The introduction of Grid View in [[concepts/camera-raw|Camera Raw]] 18.7 enhances [[concepts/efficiency-principles|workflow efficiency]] by providing better visual context during editing.

- **Simultaneous Comparison**: Enables side-by-side or multi-panel viewing of images, aiding in [[concepts/exposure|exposure]] and [[concepts/color-uniformity|color consistency]] checks.
- **Workflow Integration**: Works in tandem with the improved [[concepts/match-exposure]] function to streamline [[concepts/batch-processing|batch processing]].
- **Panel Flexibility**: Part of the broader UI [[concepts/software-updates|updates]] in version 18.7, which also includes [[concepts/undockable-panels|Undockable Panels]] for customizable workspace layouts.
