## God's Eye View (GEV) 3D Spatial Intelligence Simulator Walkthrough
**Clip title:** God’s Eye View Blew Up. Here's What You Can Do With It.
**Author / channel:** Bilawal Sidhu
**URL:** https://www.youtube.com/watch?v=o_FJ1NIH9yw

### Summary
This video provides a comprehensive overview and walkthrough of "[[concepts/vision-model|God's Eye View]]" (GEV), an open-source [[concepts/3d-spatial-intelligence|3D spatial intelligence]] simulator that has garnered significant [[concepts/attention-mechanism|attention]] and viral success since its launch. The creator, [[entities/bilawal-sidhu|Bilawal Sidhu]], addresses common questions regarding how to run the application for both technical and non-technical users, and then demonstrates its powerful features, highlighting its potential beyond just a "spy satellite simulator."

For non-coders, GEV can be easily installed using the one-click Pinokio launcher, available for Windows, Mac, and Linux, which provides an officially supported and bug-fixed version. Coders or those interested in "hacking" on the project are encouraged to clone the GitHub repository and use AI coding agents (such as Codex, [[entities/cursor|Cursor]], or Anti-Gravity) by providing a prompt, simplifying the setup process significantly. The creator strongly encourages community contributions through pull requests to integrate new features and enhance existing ones.

The core of the video is a detailed walkthrough of GEV's interface and capabilities. Users can explore a 2D Esri globe or switch to a 3D [[entities/google|Google]] Photorealistic Tiles view, which is free for personal and non-commercial use via [[entities/google|Google]] Maps Platform or a Cesium Ion community account. Key features demonstrated include "Live Flights" (displaying real-time commercial and military air traffic sourced from tens of thousands of volunteer receivers globally), "Traffic & CCTV Coverage" (showing color-coded traffic congestion and real-time, low-frame-rate camera feeds in cities like Austin and London), and "Routes & AI Navigation" (allowing users to ask the AI to plot and fly routes between any two points). Other data layers available include real-time earthquake data, [[entities/nasa|NASA]] FIRMS active fire detection via thermal imaging, mapped data centers, and submarine cables, illustrating the planet's vast digital and physical [[concepts/infrastructure|infrastructure]]. The interface also offers various visual presets (like night vision, FLIR), location search, and voice control (requiring an [[entities/openai|OpenAI]] API key) for hands-free navigation and querying general world knowledge.

Ultimately, Bilawal Sidhu positions GEV as a versatile foundation for understanding and interacting with the real world, rather than just a simple simulator. He showcases how users can leverage the open-source code to build their own tools, such as reconstructing disaster events (like the Nepal flood using open-source data and YouTube/Facebook videos), integrating new data layers, and enhancing existing functionalities like automatic license plate readers or software-defined radios. The project benefits from an active GitHub community with ongoing discussions and pull requests. The creator expresses excitement for collective innovation, emphasizing that GEV is free for non-commercial use, and hints at the possibility of a future hosted/commercial version (GEV.2) if there is sufficient interest, which would address the limitations of non-commercial API usage.
