# Task Manager

A system utility used to monitor and manage running processes, applications, and [[concepts/computational-resources|system resources]].

## Core Functions
- **Process Management**: View and terminate active processes.
- **Resource Monitoring**: Track CPU, [[concepts/memory|memory]], disk, and network usage.
- **Startup Control**: Manage applications that launch at boot.
- **[[concepts/ai-performance-evaluation|Performance Metrics]]**: Real-time graphs of system load.

## Limitations & Advanced Diagnostics
Traditional task managers often report "what" is happening but lack deep diagnostic context. For complex slowness issues, [[concepts/advanced-tools|advanced tools]] are required:
- **[[concepts/tmog-pro|TMOG Pro]]**: A sophisticated [[concepts/monitoring-and-alerting|system monitoring]] and diagnostic tool developed by the [[concepts/creator|creator]] of the original [[concepts/microsoft-windows|Windows]] Task Manager.
- **[[concepts/philosophy|Philosophy]]**: Diverges from traditional task managers by providing deeper diagnostic insights rather than just reporting current states.
