# Data Formulator

[[concepts/backend-application|Data Formulator]] is an [[concepts/ai-powered-application|AI-powered application]] developed by [[entities/microsoft|Microsoft]] that generates data visualizations through [[concepts/natural-language-processing|natural language processing]]. The system uses a [[concepts/large-language-model|large language model]] as its computational backend, allowing users to create visualizations by describing their data requirements in natural language rather than [[concepts/writing|writing]] traditional visualization [[concepts/code|code]]. This approach aims to reduce the technical barrier for users without programming expertise to produce professional data visualizations.

## Technical Implementation

The application is built on LLM technology, which interprets user requests and translates them into visualization specifications. Data Formulator can be installed via [[concepts/python|Python]]'s [[concepts/package-manager|package manager]] using standard installation [[concepts/commands|commands]], making it accessible to users within Python [[concepts/developer-platforms|development environments]]. The system bridges the gap between raw data analysis and visual presentation by automating the [[concepts/code-generation|code generation]] process typically required for creating charts and graphs.

## Use Cases

Data Formulator is designed for data analysis workflows where visualization serves as a communication and exploratory tool. By accepting natural language input, it enables analysts and non-technical users to quickly generate visual representations of datasets without requiring deep knowledge of visualization libraries or programming syntax.
