# Claude 35 Sonnet

Claude 3.5 Sonnet is an AI model developed by [[entities/anthropic-institute|Anthropic]] that supports context files for enhanced performance in [[concepts/development-workflows|development workflows]]. Research has examined the effectiveness of repository-level context files, specifically [[concepts/agents|AGENTS]].md and [[concepts/claude-ai|CLAUDE]].md files, in improving Claude's ability to understand and work within codebases.

## Context Files and Effectiveness

Studies have investigated whether structured context files improve Claude's performance on development tasks. These files serve as [[concepts/instructions|instructions]] and documentation that Claude can reference when analyzing code or providing assistance. The research appears to focus on empirical measurement of how well such files help the model maintain [[concepts/logical-consistency|consistency]] and [[concepts/accuracy|accuracy]] across multiple interactions within a project.

The findings from this research contribute to understanding [[concepts/best-practices|best practices]] for integrating [[concepts/large-language-model-llm|large language models]] into development workflows, particularly regarding how to [[concepts/structure|structure]] information so that AI assistants can effectively leverage it.
