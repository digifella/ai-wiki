# Jina Embeddings V4

[[concepts/universal-embedding-models|Jina Embeddings v4]] is a [[concepts/image-embeddings|universal embedding model]] engineered to process diverse content modalities, including text, images, and other formats, into a shared [[concepts/embedding-spaces|vector space]]. By converting these varied inputs into comparable [[concepts/numerical-representations|numerical representations]], the model facilitates [[concepts/document-retrieval|retrieval]] systems that can execute cross-modal searches, allowing queries in one format to retrieve results in another.

The architecture supports both multilingual and [[concepts/multimodal-capabilities|multimodal capabilities]], enabling its application across different linguistic and visual domains. This design allows for effective retrieval tasks that transcend single-[[concepts/modality|modality]] limitations, making it suitable for complex [[concepts/knowledge-bases|information retrieval]] [[concepts/scenarios|scenarios]] where data exists in multiple forms and languages.
