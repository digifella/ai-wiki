# Canvas interface

The [[concepts/canvas|Canvas]] interface is a visual workspace in [[concepts/ai-tools|AI tools]] (e.g., [[entities/google-gemini|Google Gemini]] 3) enabling multi-step [[concepts/reasoning|reasoning]] and simultaneous processing of [[concepts/text|text]], [[concepts/images|images]], video, and [[concepts/code|code]]. Key [[concepts/capabilities|capabilities]] include:
- Executing 10-15 steps of [[concepts/coherent-reasoning|coherent reasoning]]
- Processing video/images/code simultaneously
- Integrating directly with [[concepts/google-workspace|Google Workspace]] tools (e.g., creating [[concepts/slide-decks|slide decks]] via "Please create a slide deck about..." and exporting to [[entities/google-slides|Google Slides]])
- Enabling "[[concepts/thinking-with-3-pro|Thinking with 3 Pro]]" for [[concepts/complex-tasks|complex tasks]] like automating wiki updates
