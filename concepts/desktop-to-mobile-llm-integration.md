# Desktop To Mobile Llm Integration

Desktop To Mobile LLM Integration is a feature introduced in AnythingLLM version 1.12 that extends the accessibility of privately self-hosted large language models to mobile devices. This capability allows users to interact with their locally deployed models via smartphones and tablets, maintaining the privacy and control inherent to self-hosted infrastructure. By bridging the gap between desktop-centric management and mobile accessibility, the update ensures that private data remains within the user's controlled environment regardless of the access point.

The integration enables seamless communication between the desktop application and mobile clients, allowing for continuous interaction with AI agents without compromising data security. Users can manage their knowledge bases and initiate conversations from mobile devices while the underlying processing and storage remain on their local hardware. This architecture supports the core principle of self-hosting by ensuring that sensitive information does not leave the user's private network during mobile sessions.

This functionality addresses the need for mobility in AI workflows, providing flexibility for users who require access to their private LLMs outside of a traditional desktop setting. It maintains the integrity of the self-hosted model by keeping all data processing and storage local, thereby preventing exposure to external servers. The feature represents a significant step in making self-hosted AI tools more practical for everyday use across different device types.
