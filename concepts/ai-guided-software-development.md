# AI Guided Software Development

[[concepts/agent-steering|AI-guided software development]] integrates [[concepts/ai-generated-code|AI code]] agents, such as [[concepts/claude-ai|Claude]], into [[concepts/process-driven-engineering|structured engineering]] workflows to augment rather than replace human developers. This approach positions AI as a tool for handling specific technical tasks—[[concepts/code-generation|code generation]], testing, refactoring, and documentation—while developers retain [[concepts/accountability|responsibility]] for architectural decisions, code review, and project direction. The methodology emphasizes maintaining human oversight and control throughout the development process.

## Workflow Integration

In practice, [[concepts/software-engineering-workflows|AI-guided development]] embeds [[concepts/agentic-ai|AI agents]] into existing development pipelines and processes. Developers direct the AI toward specific objectives, providing context about [[concepts/code|codebase]] structure, project requirements, and technical constraints. The AI then handles discrete tasks like generating boilerplate code, [[concepts/writing|writing]] unit tests, or identifying refactoring opportunities. Developers review and validate outputs before integration, ensuring quality and alignment with project standards.

## Key Responsibilities

The division of labor in AI-guided development reflects different strengths of humans and machines. [[concepts/ai-agents|AI agents]] [[entities/excel|excel]] at [[concepts/thematic-analysis|pattern recognition]], code synthesis, and handling repetitive technical work. Human developers retain authority over system design, API decisions, dependency management, and any changes requiring [[concepts/expertise|domain knowledge]] or judgment about long-term maintainability. Code review remains a critical checkpoint where human developers assess both [[concepts/accuracy|correctness]] and architectural fit.

## Practical Applications

Common applications include accelerating routine development tasks, reducing time spent on boilerplate and test writing, and assisting with documentation generation. Teams use [[concepts/ai-connectors|AI agents]] to explore refactoring options or debug complex issues by generating multiple diagnostic approaches. The approach has proven effective in both greenfield projects and maintenance work on existing codebases, though effectiveness depends on clear [[concepts/task-description|task specification]] and [[concepts/developer|developer]] familiarity with the tool's capabilities and limitations.
