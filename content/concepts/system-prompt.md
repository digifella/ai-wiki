# System Prompt

A system prompt is an initial instruction or set of guidelines provided to an [[concepts/ai-agent|AI agent]] [[concepts/assistive-technology|at]] the start of a conversation or [[concepts/workflow|workflow]] to define its behavior, constraints, and objectives. In the context of [[concepts/claude-ai|Claude]] and [[concepts/cursor|Cursor]], [[concepts/system-prompts|system prompts]] establish the [[concepts/parameters|parameters]] for how the AI should approach tasks, such as generating presentation content.

## Presentation Generation Workflow

One practical application involves using [[concepts/claude|Claude]] in conjunction with [[entities/cursor|Cursor]] (a code editor) to create presentations. This workflow leverages Claude's [[concepts/text-generation|text generation]] [[concepts/capabilities|capabilities]] to produce presentation content, which can then be formatted as HTML [[concepts/output|output]]. The generated HTML [[concepts/files|files]] serve as a foundation that can be further refined or exported into other formats.

## Export Capabilities

After the initial presentation is created, Claude can assist in exporting the output to alternative file formats. Users can request conversion to PDF, allowing presentations generated through this workflow to be shared in universally accessible formats. This flexibility makes the approach suitable for various [[concepts/distribution|distribution]] and presentation contexts.
