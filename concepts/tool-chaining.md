# Tool chaining

The practice of connecting multiple tools or services in a sequence to automate [[concepts/complex-workflows|complex workflows]], where the output of one tool serves as the input for the next. This approach enhances [[concepts/productivity|productivity]] by reducing manual intervention and enabling sophisticated automation.

## Recent Examples

- **[[entities/google-opal|Google Opal]] (Experimental)**: An experimental tool from [[entities/google-labs|Google Labs]] that allows users to describe, create, and share [[concepts/ai-mini-apps|AI mini-apps]] using natural language, effectively chaining multiple AI capabilities together.
