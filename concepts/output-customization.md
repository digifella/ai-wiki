## Output Customization
### Overview
Output [[concepts/customization|customization]] in [[concepts/coding|software development]] encompasses modifying the way data is presented or delivered to users based on specific requirements and preferences. This can include adjusting text formatting, layout design, error messages, logging details, among other aspects.

### Key Concepts
- **[[concepts/cli-tools|Configuration]] Files**: These files contain settings that control how a program operates.
- **[[concepts/environment-variables|Environment Variables]]**: External settings used by software applications for configuration purposes without altering the code itself.
- **[[concepts/integration|API Integration]]**: Customizing third-party service outputs to fit within an application’s [[concepts/user-interface|user interface]] or [[concepts/data-structure|data structure]].
- **AI-Generated File Outputs**: Modern [[concepts/agentic-ai|AI agents]], such as the updated [[concepts/notebooklm|NotebookLM]], now support the generation of branded, [[concepts/editable-files|editable files]] and deep data analysis, shifting from simple [[concepts/summarization|summarization]] to actionable document creation [[lab-notes/2026-07-06-Updated-NotebookLM-AI-Agent-for-Branded-Editable-Files-a|Updated NotebookLM: AI Agent for Branded, Editable Files and Data Analysis]].
