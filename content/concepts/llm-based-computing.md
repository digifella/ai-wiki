# LLM Based Computing

LLM-based computing represents a paradigm shift in how software systems are conceptualized and constructed. Rather than traditional imperative programming where developers write explicit [[concepts/instructions|instructions]], [[concepts/large-language-model-llm|large language models]] function as a new computational substrate—capable of processing natural language inputs and generating outputs that perform meaningful work. This approach treats LLMs not merely as tools for [[concepts/text-generation|text generation]], but as foundational computing systems that can handle [[concepts/reasoning|reasoning]], planning, and [[concepts/problem-solving|problem-solving]] tasks.

## Software 3.0 Framework

The concept of "[[concepts/software-30|Software 3.0]]," articulated by researchers like [[entities/andrej-karpathy|Andrej Karpathy]], proposes that LLMs serve as operating systems for [[concepts/ai-powered-applications|AI applications]]. Just as traditional operating systems manage [[concepts/hardware|hardware]] resources and provide a runtime environment for applications, LLM-based systems provide an execution environment for intelligent tasks. In this model, prompts function similarly to programs or system calls, directing the model to perform specific operations, while the model's learned [[concepts/weights|weights]] encode vast amounts of knowledge that serve as system [[concepts/memory|memory]] and processing [[concepts/capabilities|capabilities]].

## Practical Implications

This computational model enables new architectural possibilities for [[concepts/coding|software development]]. Rather than hand-coding specific logic paths, developers can leverage the model's inherent ability to understand context, generate novel solutions, and adapt to varied inputs. This approach has practical applications in [[concepts/agentic-ai|AI agents]], reasoning systems, and [[concepts/complex-problem-solving|complex problem-solving]] [[concepts/scenarios|scenarios]] where traditional algorithms would require extensive manual specification. The trade-offs include less deterministic behavior compared to conventional computing, but potential gains in flexibility and capability across diverse domains.
