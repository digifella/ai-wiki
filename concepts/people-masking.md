# People Masking

People Masking is an artificial intelligence-driven feature within Adobe Lightroom Classic that automates the selection of human subjects in photographs. By utilizing machine learning algorithms, the tool identifies individuals within an image and generates precise masks around them. This functionality allows users to isolate people from the background or other elements without the need for manual, pixel-by-pixel selection.

The feature operates through single-click presets that trigger the AI to analyze the photo and create the necessary selection masks. This automation significantly reduces the time required for complex edits, enabling photographers to apply localized adjustments to skin tones, lighting, or background blur with minimal effort. The system distinguishes between multiple subjects, allowing for individual or group-based masking within a single image.

Implementation of this tool relies on Adobe’s Sensei AI engine, which processes image data to detect facial features and body contours. Users can refine the automatically generated masks using standard selection tools if necessary, ensuring accuracy in challenging lighting conditions or complex compositions. The feature is integrated directly into the Develop module, streamlining the workflow for portrait and group photography editing.
