# Image Size

Image Size is a feature in [[concepts/adobe-photoshop|Adobe Photoshop]] that allows users to adjust the dimensions of [[concepts/digital-images|digital images]]. Historically, enlarging images resulted in noticeable quality degradation, as software relied on interpolation [[concepts/algorithms|algorithms]] to estimate pixel values for the expanded image. Modern versions of Photoshop have integrated artificial intelligence-driven upscaling tools that enable users to increase image dimensions while maintaining greater visual fidelity than traditional methods.

## AI-Powered Upscaling

The feature now includes Generative Upscale, which utilizes machine learning models to reconstruct missing details and textures when enlarging an image. This approach differs from standard interpolation by inferring plausible content rather than simply averaging neighboring pixels. It is particularly effective for increasing resolution in complex areas such as hair, foliage, or architectural details where traditional methods often produce artifacts or blurring.

For users requiring more control or working with specific file types, the toolset also incorporates Preserve Details 2.0. This algorithmic method optimizes the balance between sharpness and noise reduction during enlargement. It serves as an alternative to generative methods, offering a deterministic upscaling process that preserves existing edge structures while minimizing the introduction of new, potentially inaccurate details.
