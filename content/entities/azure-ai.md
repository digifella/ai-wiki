# Azure AI

[[concepts/azure-ai|Azure AI]] is [[entities/microsoft|Microsoft]]'s comprehensive suite of [[concepts/ai-technologies|artificial intelligence]] services designed to enable organizations to build, train, and deploy custom [[concepts/ai-models|AI models]] and [[concepts/software|applications]]. These services are integrated within the Azure cloud platform, providing scalable infrastructure and managed services for AI workloads of varying complexity.

## Core Capabilities

The platform encompasses [[concepts/machine-learning-model|machine learning model]] development, [[concepts/training|training]] infrastructure, and [[concepts/deployment|deployment]] options for both traditional and [[concepts/generative-apps|generative AI applications]]. Azure AI includes pre-built models and APIs alongside tools for creating custom solutions tailored to specific business needs. Services are designed to support various AI paradigms, from supervised learning to more advanced architectures like [[concepts/answer-generation|retrieval-augmented generation]] (RAG) systems.

## Applications and Use Cases

Organizations use Azure AI to implement solutions across multiple domains, including [[concepts/natural-language-processing|natural language processing]], [[concepts/computer-vision|computer vision]], and [[concepts/expert-systems|knowledge-based systems]]. One notable application is [[concepts/agentic-rag-systems|agentic RAG systems]], which leverage Azure AI services to answer domain-specific questions by retrieving information from particular document sources rather than relying on general [[concepts/language-data|training data]].
