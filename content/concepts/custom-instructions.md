# Custom Instructions

Persistent [[concepts/instructions|instructions]] applied to all [[entities/chatgpt|ChatGPT]] interactions, enabling consistent context and behavior. Define roles, goals, and preferences to tailor [[concepts/responses|responses]] without repeating context per conversation.

## Related Features

- [[entities/chatgpt|ChatGPT]] Projects: Dedicated "[[concepts/contextual-information|smart workspaces]]" for organizing ongoing tasks (e.g., client projects, [[concepts/marketing-campaigns|marketing campaigns]], [[concepts/writing|writing]] a book). Maintains context across multiple chats within the project, ensuring each new chat is "dialed in" to the task. [Video guide](https://www.youtube.com/watch?v=We5RZBECvPs)
