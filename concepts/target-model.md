# Target Model

The **Target Model** is the primary, high-capacity [[concepts/large-language-model-llm|Large Language Model (LLM)]] responsible for generating final outputs in [[concepts/inference|inference]] pipelines. In standard [[concepts/autoregressive-decoding|autoregressive generation]], the Target Model computes probabilities for the next token sequentially, which is computationally expensive. In [[concepts/gpu-accelerated-inference|accelerated inference]] architectures, particularly those utilizing [[concepts/speculative-decoding]], the Target Model serves as the authoritative verifier for [[concepts/tokens|tokens]] proposed by a smaller, faster [[concepts/draft-model]].

## Role in Speculative Decoding

In [[concepts/llm-inference-acceleration|speculative decoding]] frameworks, the Target Model's role shifts from pure generation to [[concepts/verification|verification]]:

- **Verification**: The Target Model evaluates tokens generated by the [[concepts/draft|Draft]] Model in parallel. If the Target Model agrees with the Draft Model's [[concepts/user-attention-prediction|prediction]], the token is accepted, saving computation.
- **Correction**: If the Target Model disagrees, it rejects the proposed token and generates the correct token itself, resetting the speculative process.
- **Accuracy [[concepts/preservation|Preservation]]**: The Target Model ensures that the output distribution remains identical to that of standard autoregressive decoding, maintaining quality while improving throughput.
