# Notes

A note is a digital or physical record of information, typically brief and written for later reference. Notes form the foundational unit of personal [[concepts/knowledge-management|knowledge management]] ([[concepts/pkm|PKM]]) systems.

### Key Applications
- [[entities/evernote]]: v11 (2026) features rebuilt technical foundations for speed/sync [[concepts/software-reliability|reliability]], three AI features for [[concepts/second-brain]] enhancement, new brand identity, and [[concepts/quality-of-life|quality-of-life]] improvements.
- [[entities/notion|Notion]]: Combines notes, databases, and collaboration in a single workspace.
- [[entities/obsidian]]: Uses bidirectional linking and graph view for knowledge exploration.

### Evernote v11 Highlights
- First major release since v10 (2020), rebuilt core infrastructure
- Three AI features focused on [[concepts/second-brain]] [[concepts/capabilities|capabilities]]
- Improved sync performance and reliability
- New visual brand identity
