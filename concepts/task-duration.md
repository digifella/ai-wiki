# Task Duration

**Task Duration** refers to the estimated or actual time required to complete a specific Task from start to finish. It is a critical variable in Project Management, Resource Planning, and Agile workflows.

## Core Components
- **Estimated Duration**: Predicted time based on historical data, complexity, and available resources.
- **Actual Duration**: Time recorded upon completion.
- **Variance**: The difference between estimated and actual duration, used to refine future Estimation models.

## Estimation Factors
- **Complexity**: Technical difficulty, [[concepts/ambiguity|ambiguity]], and required [[concepts/skill]] level.
- **Dependencies**: Preceding tasks that must complete before this task begins.
- **Resource Availability**: Focus time, interruptions, and tool efficiency.
