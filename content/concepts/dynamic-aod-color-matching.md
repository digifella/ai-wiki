# Dynamic AOD Color Matching

Feature in [[entities/android-16|Android 16]] that dynamically adjusts [[concepts/always-on-display|Always-On Display]] (AOD) clock colors to match the dominant hues of the current Wallpaper, creating visual harmony. Implemented in the [[entities/june-2025-pixel-drop|June 2025 Pixel Drop]].

Key [[concepts/implementation-details|implementation details]]:
- AOD clock color palette algorithm analyzes wallpaper's primary colors in real-time
- Reduces visual [[concepts/dissonance|dissonance]] between lock screen elements and wallpaper
- Part of Lock Screen [[concepts/design|design]] overhaul in Android 16
