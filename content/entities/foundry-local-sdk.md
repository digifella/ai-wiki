# Foundry Local SDK

[[concepts/foundry-local-sdk|Foundry Local SDK]] is a [[concepts/coding|software development]] kit designed for building [[concepts/software|applications]] that leverage [[concepts/ai-technologies|artificial intelligence]] while prioritizing [[concepts/local-execution|local execution]]. Rather than relying on [[concepts/cloud-ai|cloud-based AI]] services, the SDK enables developers to run [[concepts/ai-models|AI models]] directly on end-user devices, including PCs, [[entities/macos|macOS]] systems, and mobile platforms. This approach allows applications to function without continuous server connectivity while maintaining data [[concepts/privacy|privacy]] by processing information locally.

## Performance and Compatibility

The SDK is optimized to take advantage of [[concepts/bare-metal-performance|bare-metal performance]] across different [[concepts/hardware|hardware]] configurations. Developers can build applications that adapt to varying system [[concepts/capabilities|capabilities]], whether targeting high-end workstations or resource-constrained mobile devices. This flexibility enables broader device compatibility while maintaining efficient execution of AI-driven features.

## Development Approach

The SDK provides the necessary tools and libraries for developers to integrate [[concepts/offline-ai|local AI]] capabilities into their applications. By supporting multiple platforms through a single development kit, it reduces fragmentation in the development process and allows [[concepts/code|code]] to be optimized for [[concepts/local-inference|local inference]] rather than requiring constant network communication.
