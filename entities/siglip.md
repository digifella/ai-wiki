# SigLIP

**SigLIP** ([[concepts/siglip-image-encoder|Sigmoid Language-Image Pre-training]]) is a [[concepts/computer-vision|vision]]-language architecture developed by [[entities/google]]. It utilizes a sigmoid loss function, providing a more efficient and scalable alternative to the softmax loss used in CLIP for Multimodal pre-training.
