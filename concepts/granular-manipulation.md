Granular manipulation refers to the ability to make precise and localized changes in complex data or media without affecting other parts of the system. This concept is crucial for advanced editing techniques that aim to achieve high fidelity and control over modifications.

### Granular Manipulation with JSON Control

**The issue**: [[concepts/ai-models|AI models]] often struggle with making minor, specific changes within an image without causing unintended alterations elsewhere in the [[concepts/writing|composition]]. This is frequently referred to as "[[concepts/data-hallucination|hallucination]]" or degradation of overall image quality.

**The [[concepts/solution|solution]]**: The introduction of [[concepts/nano-banana-2|Nano Banana 2]] (specifically [[entities/gemini-3|Gemini 3]].1 Pro) by [[entities/google|Google]] allows for granular manipulation through JSON control. Users can now input detailed specifications using [[concepts/javascript|JavaScript]] Object Notation, enabling precise and localized changes in AI-generated images without compromising the [[concepts/integrity|integrity]] of other elements within the image.
