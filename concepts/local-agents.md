# Local Agents

**Local agents** refer to [[concepts/ai-models|AI systems]] that operate on user-controlled hardware, prioritizing data [[concepts/privacy|privacy]], offline functionality, and [[concepts/hidden-engineering|seamless integration]] with personal [[concepts/productivity|productivity]] workflows. This paradigm shifts control from centralized cloud providers to the individual user, enabling [[concepts/agentic-performance|autonomous task execution]] within a [[concepts/second-brain|personal knowledge management]] context.

## Key Characteristics
- **Privacy & Sovereignty**: Data remains on-device, reducing [[concepts/exposure|exposure]] to [[concepts/third-party-apis|external APIs]].
- **Integration**: Connects with local tools (e.g., [[concepts/obsidian|Obsidian]], file systems, local databases).
- **Autonomy**: Executes complex, [[concepts/multi-step-tasks|multi-step tasks]] without constant human intervention.
- **[[concepts/open-source|Open Source]]**: Often built on transparent, community-driven models allowing for [[concepts/customization|customization]].

## Current Landscape
Recent developments highlight a surge in open-source projects focusing on [[concepts/local-execution|local execution]] and [[concepts/user-control|user control]]. Notable trends include:
- Emphasis on **[[concepts/time-savings|productivity enhancement]]** through [[concepts/local-ai|local AI]] agents.
- Focus on **user control** over data and [[concepts/model-weights|model weights]].
- Integration of **creative workflows** with [[concepts/automated-agent|automated agent]] assistance.
