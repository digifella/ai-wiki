# User Control

**User [[concepts/power|control]]** refers to the level of autonomy users have over their data and interactions within a system or application. It encompasses settings, preferences, and [[concepts/capabilities|capabilities]] that allow users to customize and manage their experience according to their needs.

## Key Aspects of User Control

- **[[concepts/ai-workflow|Customization]]:** Ability to tailor user interfaces, features, and functionalities.
- **[[concepts/privacy|Privacy]] Settings:** Tools for controlling access and visibility of personal information.
- **[[concepts/data-management|Data Management]]:** Features enabling users to import, export, and sync data across platforms.
- **User Support and Troubleshooting:** Resources available for resolving issues related to system control.
