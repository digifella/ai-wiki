# Repository-level context files

Files in repository root (e.g., `AGENTS.md`, `[[concepts/claude-ai|CLAUDE]].md`) providing context to [[concepts/agentic-ai|AI agents]] for [[concepts/coding|coding]] tasks. Common practice to guide AI behavior.

* **[[entities/eth-zurich|ETH Zurich]] study (2026)**: Repository-level context files (e.g., `AGENTS.md`, `CLAUDE.md`) can **degrade** [[concepts/ai-agent|AI agent]] performance, contradicting industry practice.
* **Study title**: "Evaluating [[concepts/agentsmd|AGENTS.md]]: Are Repository-Level Context Files Helpful for [[concepts/ai-coding-assistance|Coding Agents]]?"
* **Performance Impact**: [[entities/claude|Claude]].md and [[concepts/agentsmd|agents.md]] files can cause [[entities/claude|Claude]] to perform worse.
