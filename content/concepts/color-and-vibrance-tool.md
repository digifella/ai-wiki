# Color And Vibrance Tool

The [[concepts/adjustment-layers|Color and Vibrance tool]] is a feature introduced in [[entities/adobe-photoshop-2025|Photoshop 2025]] that enhances [[concepts/photo-tonal-adjustments|color grading]] [[concepts/capabilities|capabilities]] within the application. It represents an evolution in [[entities/adobe|Adobe]]'s approach to non-destructive [[concepts/tint-adjustment|color adjustment]], providing users with refined controls for modifying [[concepts/color-saturation|color saturation]] and intensity across [[concepts/images|images]].

## Overview and Functionality

This tool allows photographers and designers to adjust color properties with greater precision than previous methods. The Color and Vibrance [[concepts/adjustments|adjustments]] can be applied selectively to different [[concepts/color-ranges|color ranges]], enabling targeted modifications to specific hues while preserving others. The tool integrates into [[concepts/photoshop|Photoshop]]'s adjustment [[concepts/workflow|workflow]] as a non-destructive layer, allowing users to refine their edits without permanently altering the original image data.
