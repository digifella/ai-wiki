# Native Capabilities

Native Capabilities refers to a multi-modal researcher tool constructed using [[concepts/langgraph-framework|LangGraph]] and [[concepts/google-search|Google]]'s [[concepts/gemini-25-models|Gemini 2.5]] models. The system is designed to perform [[concepts/comprehensive-investigations|comprehensive investigations]] by leveraging the combined strengths of LangGraph's [[concepts/agent-collaboration|agent orchestration]] framework and Gemini 2.5's multi-modal processing abilities. This approach enables the tool to handle various types of input data and generate diverse outputs as part of systematic research workflows.

## Architecture and Implementation

The tool is built on LangGraph, a framework that provides structured graph-based execution for [[concepts/agentic-ai|AI agents]]. By integrating Google's Gemini 2.5 models, the system gains access to advanced language understanding and multi-modal capabilities, allowing it to process and analyze different forms of information within a single research pipeline. This architecture supports complex investigation tasks that would otherwise require multiple specialized systems.

## Use Cases

Native Capabilities are positioned for scenarios requiring thorough information gathering and analysis across multiple modalities. The combination of LangGraph's orchestration and Gemini 2.5's processing power makes the tool suitable for research [[concepts/software|applications]] where comprehensive data investigation is needed, though specific [[concepts/deployment|deployment]] examples and limitations remain documented elsewhere in the [[concepts/knowledge-base|knowledge base]].
