[[entities/google|Google]] Colab is a free, cloud-based Jupyter [[concepts/notebook|notebook]] environment that enables collaborative [[entities/python|Python]] [[concepts/coding|coding]] with GPU/TPU acceleration, requiring no local setup. It integrates seamlessly with [[concepts/google-search|Google]] [[concepts/motivation|Drive]] and pre-installs libraries for [[concepts/machine-learning|machine learning]].

## Key Features
- **Free GPU/TPU access**: Accelerates [[concepts/training-process|model training]] without hardware investment
- **Pre-installed ML stack**: Includes TensorFlow, PyTorch, and common data [[concepts/science|science]] libraries
- **[[entities/google-drive|Google Drive]] sync**: Persistent [[entities/storage|storage]] for [[concepts/notebook-tools|notebooks]] and data
- **Collaborative editing**: Real-time co-authoring with version history
