# Prism ML

**[[concepts/prism-ml|Prism ML]]** is an [[concepts/open-source|open-source]] organization focused on making [[concepts/artificial-intelligence-models|machine learning models]] accessible, efficient, and runable locally. The project emphasizes extreme [[concepts/quantization-techniques|quantization techniques]] to reduce [[concepts/hardware-requirements|hardware requirements]] for [[concepts/excellence|high-quality]] [[concepts/inference|inference]].
