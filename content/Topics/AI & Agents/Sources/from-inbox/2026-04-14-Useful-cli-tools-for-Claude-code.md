# 12 CLI Tools for the Claude Code [[concepts/workflow|Workflow]]

This list covers [[concepts/cli|command-line]] tools that pair well with [[concepts/ai-coding|AI coding]] assistants (like Claude Code) to improve terminal productivity, system monitoring, and file management.

## Git & Version Control

### 1\. [Lazygit](https://github.com/jesseduffield/lazygit)

A terminal UI for [[entities/git-commands|git commands]].

* **Use Case:** Monitoring changes made by Claude Code in real-time.
* **Features:** Visualizes file changes, branch management, commit history, and stashing without leaving the terminal.
* **Why it's useful:** Helps audit the rapid changes an AI [[entities/agent|agent]] makes to your codebase.

## File Viewing & Editing

### 2\. [Glow](https://github.com/charmbracelet/glow)

A markdown reader for the command line.

* **Use Case:** Quickly reading `CLAUDE.md`, documentation, or readme files.
* **Features:** Renders markdown with proper formatting and colors directly in the terminal.

### 3\. [Neovim](https://neovim.io/)

* **Use Case:** A more powerful alternative to Glow when deep editing is required.
* **Features:** Configurable hotkeys for jumping between headers, sections, and code blocks.

## AI & [[concepts/hardware|Hardware]] Analysis

### 4\. [LLMfit](https://github.com/janhq/llmfit)

* **Use Case:** Determining which local LLMs your computer can run.
* **Features:** Displays current hardware stats and ranks [[concepts/models|models]] ([[entities/llama|Llama]], [[entities/mistral-ai|Mistral]], etc.) by "fit" based on your VRAM/RAM.

### 5\. [Models](https://github.com/anthropics/models)

* **Use Case:** Checking pricing and specs for AI providers.
* **Features:** Prints tables showing pricing per token, [[concepts/context-window|context window]] sizes, agent changelogs, and benchmarks for various providers ([[entities/anthropic|Anthropic]], [[entities/openai|OpenAI]], etc.).

## Package & File Management

### 6\. [Taproom](https://github.com/unflxw/taproom)

* **Use Case:** Managing Homebrew installations.
* **Features:** specific to MacOS; lists all installed Casks and Formulas to help clean up or audit installed [[concepts/software|software]].

### 7\. [Ranger](https://github.com/ranger/ranger)

* **Use Case:** navigating the file system.
* **Features:** A file browser with keybindings similar to VI. Essential for headless Linux servers where you don't have a GUI Finder.

## Navigation & Utilities

### 8\. [Zoxide](https://github.com/ajeetdsouza/zoxide)

A smarter replacement for the `cd` command.

* **Use Case:** Jumping between directories quickly.
* **Features:** Remembers your most frequently used directories. Allows "fuzzy jumping" (e.g., typing `z muse` to jump to `/desktop/pixelmuse` without typing the full path).

### 9\. [Chafa](https://github.com/hpjansson/chafa)

* **Use Case:** Viewing images inside the terminal.
* **Features:** Renders images (PNG/JPG) using ASCII/ANSI characters. Useful for checking assets generated by AI without opening a preview window.

### 10\. [CSVlens](https://github.com/YS-L/csvlens)

* **Use Case:** Viewing and filtering CSV files.
* **Features:** A terminal UI specifically designed for reading large dataset files.

### 11\. [Eza](https://github.com/eza-community/eza)

A modern replacement for `ls`.

* **Use Case:** Listing files with better visuals.
* **Features:** Adds icons, git status [[concepts/integration|integration]], and grid views.
* _Tip:_ Alias `ls` to `eza` in your shell config for a permanent upgrade.

## System Monitoring

### 12\. [Btop](https://github.com/aristocratos/btop)

* **Use Case:** System resource monitoring.
* **Features:** Shows [[concepts/cpu|CPU]], [[concepts/memory|Memory]], Network, and Process usage. Useful for watching resource consumption when running heavy AI tasks or VMs.

### 13\. [Mactop](https://github.com/context-labs/mactop)

* **Use Case:** [[entities/apple|Apple]] Silicon specific monitoring.
* **Features:** Displays real-time metrics for Apple M-series chips (Power usage, GPU usage, Neural Engine usage).
