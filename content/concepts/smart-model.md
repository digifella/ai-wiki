# Smart Model

Smart Model refers to the integration of GPT-5 into [[concepts/document-insights|Microsoft 365 Copilot]] and [[entities/copilot-studio|Copilot Studio]], representing an advancement in [[concepts/capabilities|AI capabilities]] within Microsoft's productivity suite. This integration brings improved speed and [[concepts/reasoning|reasoning]] performance to [[concepts/enterprise-ai|enterprise AI agents]] and copilots built on the Microsoft platform.

## Key Capabilities

The Smart Model leverages GPT-5's enhanced [[concepts/speed|processing speed]] and [[concepts/reasoning-capabilities|reasoning capabilities]] to deliver faster [[concepts/responses|responses]] and more sophisticated [[concepts/problem-solving|problem-solving]] within Microsoft 365 [[concepts/software|applications]]. These improvements enable Copilot Studio users to build more capable [[concepts/agentic-ai|AI agents]] that can handle [[concepts/complex-tasks|complex tasks]] across Microsoft's ecosystem of business tools.

## Implementation Context

The Smart Model is designed for organizations utilizing Microsoft 365 Copilot and developers working with Copilot Studio. It represents part of Microsoft's broader strategy to integrate advanced [[concepts/large-language-model-llm|large language models]] into its enterprise [[concepts/productivity-tools|productivity tools]], allowing users to access improved AI capabilities without requiring separate third-party services.
