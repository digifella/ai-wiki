# Multilingual language modeling

Multilingual language modeling involves [[concepts/training|training]] [[concepts/large-language-models]] to understand and generate text across multiple languages by leveraging shared vocabularies and semantic representations, enabling Cross-lingual Transfer.

## Recent Advancements
- **[[concepts/3-billion-parameter-model|SmolLM3-3B]] (via HuggingFaceTB)**:
    - A 3-billion parameter model belonging to the [[concepts/smollm-family|SmolLM family]].
    - Features an advanced "[[concepts/thinking-with-3-pro|thinking mode]]" that exposes the model's [[concepts/reasoning|reasoning]] process prior to generating the final [[concepts/solution|answer]].
    - Capable of efficient [[concepts/local-deployment|local deployment]] using [[entities/vllm|vLLM]] (as demonstrated by [[entities/fahd-mirza]]).
