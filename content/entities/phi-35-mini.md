# Phi 35 Mini

[[entities/phi|Phi]] 35 Mini is a lightweight [[concepts/statistical-language-modeling|language model]] developed by [[entities/microsoft|Microsoft]] designed for [[concepts/local-deployment|local deployment]] and execution. It is available through [[concepts/gpu-accelerated-inference|Foundry Local]], a platform that enables users to run language [[concepts/models|models]] on their own infrastructure rather than relying on cloud-based APIs. The model is optimized for [[concepts/chat-completion|chat completion]] tasks and [[concepts/scenarios|scenarios]] where [[concepts/computational-resources|computational resources]] are limited.

## Deployment and Use Cases

The model supports local [[concepts/deployment|deployment]], making it suitable for [[concepts/software|applications]] requiring data [[concepts/privacy|privacy]], reduced latency, or operation in environments without reliable [[concepts/cloud-integration|cloud connectivity]]. As a smaller-scale model, Phi 35 Mini is intended to balance capability with efficiency, allowing it to run on modest [[concepts/hardware|hardware]] configurations while maintaining functional performance for [[concepts/ai-chatbots|conversational AI]] tasks.
