## AI Rotate Object

This concept describes a feature in [[concepts/beta-version|Photoshop Beta]] (version 27.5.0 or higher) that allows users to rotate and manipulate 2D objects within an image as if they existed in a 3D space.

### Summary
- **AI-Powered Tool:** The new "Rotate Object" tool uses AI technology.
- **Manipulation Capabilities:** Allows rotation along different axes, adjustment of perspective.
- **Usage in Beta Version:** Available for [[concepts/testing|testing]] and [[concepts/feedback|feedback]] in Photoshop Beta versions starting from 27.5.0 or higher.
