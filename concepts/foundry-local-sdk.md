# Foundry Local Sdk

The [[entities/foundry-local-sdk|Foundry Local SDK]] is a [[concepts/coding|software development]] kit designed to enable the creation and deployment of [[concepts/ai-technologies|artificial intelligence]] applications that operate directly on end-user devices. By processing models locally on personal computers, [[concepts/portable-devices|mobile devices]], and other client hardware, the SDK allows applications to function without constant internet connectivity. This architecture significantly reduces latency associated with remote [[concepts/computation|computation]] and enhances user [[concepts/privacy|privacy]] by keeping data on the device.

The SDK provides unified development tools and libraries optimized for multiple platforms, including [[concepts/microsoft-windows|Windows]], [[entities/macos|macOS]], and mobile operating systems. This cross-platform support ensures that developers can build consistent AI experiences across diverse hardware environments. The framework handles the complexities of [[concepts/inference|model inference]] and resource management, allowing developers to focus on application [[concepts/open-source-philosophy|logic]] rather than low-level hardware optimization.

By shifting computation from cloud-based servers to the client side, the Foundry Local SDK addresses key challenges in scalability and [[concepts/software-reliability|reliability]]. Applications built with this toolkit are less dependent on network stability and can deliver real-time responses even in offline [[concepts/scenarios|scenarios]]. This approach is particularly beneficial for [[concepts/use-cases|use cases]] requiring high privacy standards or low-latency interactions, such as real-time video processing or [[concepts/personal-assistant|personal assistant]] features.
