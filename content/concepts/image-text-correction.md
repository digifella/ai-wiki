# Image Text Correction

Image [[concepts/text|text]] correction is the process of identifying and fixing errors in text that has been automatically extracted from visual sources such as [[concepts/infographic-design|infographics]], screenshots, and other image-based documents. As [[concepts/optical-character-recognition-ocr|optical character recognition (OCR)]] and AI-powered text extraction tools have become more accessible, the need to correct their [[concepts/output|output]] has grown, since these systems frequently misidentify characters, spacing, or formatting elements present in the original image.

## Common Tools and Methods

[[entities/adobe-acrobat|Adobe Acrobat]] and [[entities/canva|Canva]] both offer text extraction features that can pull text from [[concepts/images|images]]. Adobe Acrobat's OCR [[concepts/capabilities|capabilities]] are designed primarily for document digitization, while Canva's "Grab Text" feature focuses on extracting text from visual designs and graphics. Both tools produce results that typically require manual review and correction. AI assistance can [[concepts/speed|speed]] up this correction process by suggesting likely corrections based on context and common OCR errors, though human [[concepts/verification|verification]] remains important for [[concepts/accuracy|accuracy]]-critical [[concepts/software|applications]].

## Practical Considerations

The correction [[concepts/workflow|workflow]] generally involves extracting text from the image using one of these tools, then comparing the output against the original source to identify discrepancies. Common errors include confusion between similar characters (0 vs O, 1 vs l), incorrect spacing, or misread specialized terms. The time required for correction depends on text complexity, image quality, and the accuracy of the initial extraction. For infographics containing varied fonts, colors, and layouts, correction can be more labor-intensive than for standardized document formats.
