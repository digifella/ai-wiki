# AI-powered application

An **AI-powered application** is [[concepts/software|software]] that utilizes [[concepts/large-language-model|large language models]] (LLMs) or other [[concepts/ai-technologies|artificial intelligence]] architectures as a functional backend to automate complex [[concepts/reasoning|reasoning]], [[concepts/data-transformation|data transformation]], or content generation.

### Implementations
* **[[entities/data-formulator|Data Formulator]] (Microsoft):** An application designed to create [[concepts/rich-data-visualizations|rich data visualizations]] by leveraging an LLM as its backend.
    * **[[concepts/setup|Setup]]:** Installed via [[entities/python|Python]]'s [[entities/pip|PIP]]: `pip install data_formulator`.
