# Sentiment analysis

Sentiment analysis is a fundamental [[concepts/natural-language-processing]] (NLP) task focused on determining the emotional tone or subjective opinion within [[concepts/unstructured-text|unstructured text]].

## Related NLP Tasks
* [[concepts/text-classification]]
* [[concepts/named-entity-recognition|Named Entity Recognition]] (NER)
* opinion mining

## Methodological Context
* **Generative vs. Non-Generative Tasks:** Using [[concepts/large-language-models]] (LLMs) for specific, non-generative tasks (like classification or extraction) presents unique challenges compared to traditional NLP methods.
* **[[concepts/contextual-awareness|LangExtract]] (Google):** An [[concepts/open-source|open-source]] [[entities/python|Python]] library designed for [[concepts/document-processing|information extraction]] from unstructured text using [[entities/gemini]] models. It serves as a specialized approach for tasks that require precise extraction rather than pure generation.
