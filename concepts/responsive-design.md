# Responsive Design

**Responsive Design** is an approach to web design that makes web pages render well on a variety of devices and window or screen sizes. It ensures optimal viewing and interaction [[concepts/experience|experience]], facilitating easy navigation and reading across different environments (mobile, desktop, tablet).

Core principles include:
*   Fluid [[concepts/grids|grids]] and layouts
*   Flexible images and media
*   CSS media queries
