# Cloudyeti

CloudYeti is a YouTube channel focused on the practical implementation of local [[concepts/ai-technologies|artificial intelligence]] systems. The content is primarily targeted at developers and technology practitioners who aim to deploy [[concepts/ai-models|AI models]] on personal hardware, offering an alternative to exclusive reliance on [[concepts/cloud-based-services|cloud-based services]]. The channel emphasizes self-hosted solutions, providing technical guidance on managing and optimizing [[concepts/computing-architecture|AI infrastructure]] within private environments.

The channel’s primary focus includes analyzing local AI return on investment (ROI) and optimizing [[concepts/developer|developer]] workflows. It provides tutorials and demonstrations for running [[concepts/open-models|open-source models]], such as [[concepts/ai-driven-code-editing|Qwen Code]], using tools like Ollama. By detailing the setup and performance of these local environments, the channel aims to help users understand the [[concepts/cost-benefit-analysis|cost-benefit analysis]] of [[concepts/local-ai-processing|on-premise AI]] deployment compared to traditional cloud APIs.
