# No Intel N

No [[entities/intel|Intel]] (N) is a feature designed to help users identify and manage profiles that lack matched Intel information. The system uses color-coded visual [[concepts/indicators|indicators]] on [[concepts/stakeholder-profiles|profile cards]] to quickly signal the status of Intel data: profiles with matched Intel display "N intel" in green, while those missing Intel information show "⚠ no intel" in amber. These indicators update automatically whenever a profile is saved, created, or imported via CSV.

## Filter and Management

A dedicated "⚠ No Intel (N)" filter tab appears within the profile type bar, allowing users to isolate and view only those profiles missing matched Intel data. This filter displays an exact count of affected profiles, making it straightforward to prioritize which profiles require Intel information to be added or matched.
