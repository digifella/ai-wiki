# Interconnected Parts

Interconnected Parts is an architectural framework for [[concepts/ai-agents|AI agents]] developed by [[entities/anthropic-institute|Anthropic]], introduced through updates released in late 2024 known as "[[concepts/dom|Christmas Claude]]." The framework establishes [[concepts/design|design principles]] for how [[concepts/agentic-ai|autonomous AI systems]] should organize their internal capabilities and coordinate with [[concepts/external-tools|external tools]] and environments.

## Core Principles

The framework emphasizes that effective [[concepts/agentic-frameworks|agentic systems]] require well-defined connections between different functional components. Rather than treating an [[concepts/ai-agent|AI agent]] as a monolithic [[concepts/decision-making|decision-making]] entity, Interconnected Parts describes how agents should separate concerns—such as [[concepts/reasoning|reasoning]], planning, [[concepts/acting|tool use]], and execution—into distinct but coordinated subsystems. This modular approach enables clearer behavior, improved [[concepts/debugging|debugging]], and more reliable [[concepts/autonomous-operation|autonomous operation]].

## Integration with External Systems

A key aspect of Interconnected Parts is its approach to [[concepts/planning-errors|tool integration]]. The framework provides guidance on how agents should interface with external services, APIs, and systems while maintaining coherent [[concepts/goal-oriented-behavior|goal-directed behavior]]. This includes considerations for how agents handle [[concepts/feedback|feedback]] from tool execution, manage dependencies between sequential actions, and adapt when external systems have limitations or constraints.

The framework represents Anthropic's practical approach to agent design during a period of rapid development in autonomous [[concepts/ai-models|AI systems]], offering both technical architecture guidance and principles for developing more capable and controllable [[concepts/agentic-applications|agentic applications]].
