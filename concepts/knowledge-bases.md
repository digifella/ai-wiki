# Information retrieval

[[concepts/source-discovery|Information retrieval]] (IR) is the process of obtaining relevant information from a collection of data, typically through search engines, databases, or other techniques. It supports [[concepts/decision-making|decision-making]] and efficient knowledge access by matching user queries with stored information.

## Key Features
- **Efficient search**: Uses [[concepts/data-indexing|indexing]] and ranking [[concepts/algorithms|algorithms]] to quickly locate relevant documents or data from large collections.
- **Query processing**: Handles user intent through [[concepts/natural-language-processing|natural language processing]] and [[concepts/search-relevance|relevance ranking]].
- **Data integration**: Supports multiple formats including text, images, and structured databases for comprehensive access.
- **Modern augmentation**: Incorporates techniques like [[concepts/retrieval-augmented-generation-rag]] to enhance [[concepts/statistical-language-modeling|language model]] outputs with up-to-date, contextually relevant information retrieved from knowledge [[concepts/number-systems|bases]].

- **Customer support**: Powering search systems for FA
