# Data indexing

Organizing data for efficient [[concepts/document-retrieval|retrieval]], enabling rapid [[concepts/information-access|access to information]] in databases, search engines, and [[concepts/retrieval-augmented-generation-rag]] systems. Critical for reducing latency and improving accuracy in [[concepts/knowledge-bases|information retrieval]].

## Key techniques
- **LLM-enhanced indexing**: Using [[concepts/large-language-models]] to create semantic indexes (beyond keyword matching), improving [[concepts/recall|recall]] in [[concepts/contextualized-language-understanding|RAG systems]] (e.g., boosting [[concepts/recall|recall]] from 50-60% to 95% by generating context-aware index representations).
- **[[concepts/structured-query-generation|Structured query generation]]**: LLMs transforming [[concepts/natural-language-search|natural language queries]] into optimized, structured formats for precise matching against indexed data.
- **Hybrid indexing**: Combining traditional vector indexes with [[concepts/metadata|metadata]] tagging for multi-dimensional retrieval (e.g., filtering by document type + semantic relevance).
