# Hy4

**Hy4** is a 770-billion parameter AI model developed by [[entities/tencent]]. It serves as a preview version for the company's next-generation [[concepts/large-language-models|large language models]].

## Key Developments

### Model Optimization & Shrinkage
*   **Angelslim Breakthrough:** Tencent successfully reduced the size of the 1.5TB Hy4 model to 214GB.
*   **Technique:** The reduction was achieved using **[[concepts/sherry-quantization|Sherry Quantization]]**, a proprietary method detailed in recent technical reports.
*   **Impact:** This significant compression allows for more efficient deployment and [[concepts/ai-inference|inference]] without proportional loss in capability.
