# Automated Research Workflows

[[concepts/ai-driven-research|Automated Research Workflows]] is a [[concepts/multi-modal-researcher|multi-modal researcher]] tool designed to streamline complex research tasks by integrating multiple data processing [[concepts/capabilities|capabilities]]. Built on [[concepts/google-search|Google]]'s [[concepts/gemini-25-models|Gemini 2.5]] models, the system leverages the [[concepts/langgraph-framework|LangGraph]] and [[entities/langchain|LangChain]] frameworks to coordinate research activities across different input types, including [[concepts/text|text]], [[concepts/images|images]], and other formats. This [[concepts/architecture|architecture]] allows researchers to work with heterogeneous data sources within a single, unified [[concepts/workflow|workflow]] environment rather than managing separate tools for different media types.

## Technical Foundation

The tool is constructed using LangGraph and LangChain, frameworks that enable the orchestration of language model-driven workflows. By utilizing Gemini 2.5's multi-modal capabilities, the system can process and interpret various content types simultaneously, allowing for more integrated analysis. This approach reduces context-switching overhead and enables researchers to maintain [[concepts/continuity|continuity]] across different stages of their work.

## Use Cases

The platform is intended to support researchers who need to synthesize information from multiple sources and formats. Rather than manually converting between tools or formats, users can feed diverse inputs directly into the workflow, where the underlying models handle the interpretation and coordination of analysis tasks.
