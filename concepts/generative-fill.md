# Generative Fill

Generative Fill is a feature within [[entities/adobe-firefly|Adobe Firefly]] that enables users to modify images through natural [[concepts/natural-language-prompting|language prompts]]. Rather than relying on traditional selection tools and manual editing techniques, users describe their desired changes in text form, and the system generates content to match the description. This approach combines conventional [[concepts/image-editing|image editing]] workflows with AI-assisted content generation, reducing the technical [[concepts/skill|skill]] required for complex image modifications.

## How It Works

Users select or define an area within an image and provide a text description of what they wish to add, remove, or replace. The underlying model analyzes the surrounding context and the provided prompt to synthesize new pixels that blend seamlessly with the existing image. This process allows for the insertion of objects, extension of backgrounds, or alteration of specific elements without the need for [[concepts/manual-masking|manual masking]] or layering.

## Integration and Utility

The feature is designed to integrate directly into Adobe’s creative ecosystem, allowing professionals to iterate quickly on visual concepts. By leveraging [[concepts/generative-ai|generative AI]], it streamlines tasks that traditionally require advanced [[concepts/digital-compositing|compositing]] [[concepts/skills|skills]], such as removing unwanted objects or expanding [[concepts/canvas|canvas]] boundaries. This functionality supports a more intuitive workflow where creative intent is communicated through language rather than complex tool manipulation.
