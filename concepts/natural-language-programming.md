# Natural language programming

A programming paradigm where software [[concepts/instructions|instructions]] are expressed in human languages rather than formal, machine-oriented syntax. This approach leverages [[concepts/large-language-models]] (LLMs) to bridge the gap between human intent and executable [[concepts/open-source-philosophy|logic]], serving as a foundation for [[concepts/no-code]] and Low-code development.

## Related Concepts & Context

### R Programming Language
While Natural Language Programming aims to replace formal syntax with human intent, formal languages like **[[concepts/R-programming-language|R programming language]]** remain critical for [[concepts/statistical-computing|statistical computing]] and [[concepts/webgpu|graphics]]. R provides a structured environment for data analysis that contrasts with the emergent logic of LLM-based generation.
