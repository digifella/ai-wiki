# Flowise

[[concepts/flowise|Flowise]] is an [[concepts/open-source|open-source]] platform for building and deploying LLM-powered [[concepts/software|applications]] with a visual interface.

## Key Features
- Visual [[concepts/workflow|workflow]] builder for LLM chains
- Supports [[concepts/integration|integration]] with multiple LLM providers
- Extensible through custom [[concepts/nodes|nodes]] and [[concepts/plugins|plugins]]
- Designed for [[concepts/rapid-prototyping|rapid prototyping]] of [[concepts/ai-powered-applications|AI applications]]

## Advanced Use Cases
- [[entities/anthropic]]-inspired multi-[[entities/agent|agent]] [[concepts/visualization-generation|deep research]] agent: Flowise [[concepts/adoption|implementation]] overcoming single LLM limitations ([[concepts/data-hallucination|hallucination]], depth) via human-like [[concepts/iterative-research|iterative research]] approach
