# Canvas Feature

The [[concepts/canvas|Canvas]] feature integrates [[concepts/gemini-models|Gemini Pro]] with [[concepts/google-slides|Google Slides]] to allow users to generate presentation [[concepts/slide-decks|slide decks]] through AI assistance. By leveraging [[concepts/generative-ai|generative AI]], the tool streamlines the creation process, enabling users to produce slide content directly from [[concepts/text-prompts|text prompts]]. This integration eliminates the need to manually construct slides from scratch, providing a more efficient workflow for presentation development.

To utilize Canvas, users input prompts describing the desired [[concepts/visual-slide-design|presentation structure]] and content. Gemini Pro processes these requests and generates the corresponding slide material, which is then formatted for immediate use. Users can subsequently edit the generated content and export the final presentation directly to Google Slides, ensuring seamless compatibility with existing [[concepts/google-workspace-tools|Google Workspace tools]].
