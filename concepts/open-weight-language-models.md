# Open-weight language models

[[concepts/large-language-models]] whose trained parameters ([[concepts/weights|weights]]) are released publicly, allowing for independent download, deployment, and [[concepts/fine-tuning]].

## Key Characteristics
- **[[concepts/local-execution]]**: Capability to run models on personal hardware (PCs) and [[concepts/portable-devices|mobile devices]], reducing dependence on [[concepts/cloud-computing]].
- **Data [[concepts/privacy]]**: [[concepts/on-device-processing|On-device processing]] ensures sensitive data is not transmitted to external servers.
- **[[concepts/cost-efficient-solutions|Cost Efficiency]]**: Often available for free, bypassing the need for recurring [[concepts/subscription-models|Subscription models]] or per-token API fees.
- **[[concepts/edge-computing]]**: Enables [[entities/high-performance|high-performance]] AI functionality on portable and distributed hardware.

## Notable Examples
- **[[concepts/gemma-4|Google Gemma]] 4**:
    - Supports local, [[concepts/private-execution|private execution]] on both computers and mobile phones.
    - Offers a free-to-use model with no subscription requirements.
