# Alibaba Ai

[[entities/alibaba|Alibaba]]'s AI department develops and maintains [[concepts/large-language-model-llm|large language models]] and [[entities/ai-tools|AI tools]], with a focus on practical [[concepts/software|applications]] for [[concepts/coding|software development]] and enterprise [[concepts/scenarios|use cases]]. The department is known for the [[entities/qwen|Qwen]] series of [[concepts/models|models]], which include various versions designed for different computational requirements and specialized tasks.

## Qwen Code and Local Development

[[concepts/ai-driven-code-editing|Qwen Code]] is a [[concepts/command-line-interface|command-line]] tool developed by Alibaba for local, [[concepts/ai-coding-assistance|AI-assisted coding]] workflows. The tool is designed to reduce dependency on cloud-based or paid coding assistance services by enabling developers to run [[concepts/ai-models|AI models]] locally on their machines. This approach allows teams to maintain code [[concepts/privacy|privacy]] while accessing AI-powered [[concepts/code-generation|code generation]] and analysis [[concepts/capabilities|capabilities]].

## Model Development

Alibaba has released multiple iterations of the [[concepts/qwen-model|Qwen model]] family, including specialized variants such as [[concepts/qwen3-model|Qwen 3.6]]-Plus, which incorporates [[concepts/tool-use-capabilities|agentic coding capabilities]] and [[concepts/multimodal-reasoning|multimodal reasoning]] features. The company has positioned these models as [[concepts/open-source|open-source]] alternatives capable of handling complex coding tasks, with emphasis on reducing reliance on proprietary paid models for software [[concepts/development-workflows|development workflows]].
