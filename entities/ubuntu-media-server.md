# Ubuntu Media Server

Ubuntu Media Server is a self-hosted media server project built on the Ubuntu operating system, designed to operate within a budget constraint of under $100. The project provides users with an alternative to subscription-based streaming services by enabling them to host, store, and manage their own media content on local hardware rather than relying on commercial platforms with recurring fees.

## Purpose and Scope

The project addresses the growing cost of multiple subscription streaming services by allowing users to maintain control over their media library on personal hardware. By leveraging the open-source nature of Ubuntu and affordable hardware components, the initiative aims to reduce long-term expenses associated with commercial streaming subscriptions. This approach emphasizes data privacy and ownership, allowing individuals to curate their digital collections without third-party interference or ongoing monthly charges.

## Technical Implementation

The server infrastructure relies on standard Ubuntu Linux distributions, which provide a stable and secure foundation for media management software. Users typically install open-source media server applications, such as Plex, Jellyfin, or Emby, to handle media transcoding, library organization, and remote access. The low-cost hardware requirement encourages the repurposing of older computers or the assembly of entry-level mini-PCs, making the solution accessible to a wider audience interested in digital self-sufficiency.
