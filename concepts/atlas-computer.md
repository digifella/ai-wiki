# Atlas computer

## Overview
The Atlas computer was a pioneering British supercomputer developed at the University of Manchester in the early 1960s. It was notable for being one of the first machines to implement virtual [[concepts/memory|memory]] and time-sharing concepts, significantly influencing subsequent computer architecture.

## Key Innovations
- **Virtual Memory**: First commercial implementation, allowing [[concepts/software|programs]] to use more memory than physically available.
- **Time-Sharing**: Enabled multiple users to interact with the computer simultaneously.
- **Multiprogramming**: Allowed multiple jobs to reside in memory at once, improving efficiency.
