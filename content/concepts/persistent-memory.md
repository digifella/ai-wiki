# Persistent Memory Concept Wiki Page

Persistent [[concepts/memory|memory]] refers to technology that allows data to be stored and accessed quickly while retaining the attributes of non-volatile memory. This page integrates various concepts related to persistent memory, its [[concepts/software|applications]] in AI and [[concepts/knowledge-management|knowledge management]] tools like [[concepts/obsidian|Obsidian]].
