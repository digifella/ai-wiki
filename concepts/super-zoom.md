# Super Zoom

Super Zoom refers to a set of [[concepts/ai-powered-upscaling|AI-powered upscaling]] tools integrated into [[concepts/beta-version|Photoshop Beta]] that enable users to enlarge images while maintaining or improving visual quality. These tools leverage [[concepts/generative-ai|generative AI]] technology to intelligently reconstruct image details when [[concepts/computational-scaling|scaling]] up, addressing a traditional limitation of digital image enlargement where simple [[concepts/scaling|scaling]] typically results in blurring or pixelation.

## Available Tools

[[entities/photoshop-beta|Photoshop Beta]] offers multiple upscaling approaches, each with different underlying [[concepts/algorithms|algorithms]] and [[concepts/scenarios|use cases]]. These tools represent [[entities/adobe|Adobe]]'s implementation of generative upscaling technology, allowing photographers and designers to resize images substantially without the quality degradation associated with conventional interpolation methods.
