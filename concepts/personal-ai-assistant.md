# Personal AI Assistant

A personal [[entities/ai-assistant|AI assistant]] is a self-hosted software agent that operates on user-controlled [[concepts/infrastructure|infrastructure]] to perform tasks, manage information, and interact with external services via natural language.

## Key Features
- Self-hosted (runs on user's infrastructure, no third-party data processing)
- Integrates with [[concepts/productivity-tools|productivity tools]]: [[entities/gmail|Gmail]], [[entities/asana|Asana]], [[entities/slack]], [[entities/telegram]]
- Executes [[concepts/real-world-tasks|real-world tasks]] through [[concepts/chat-application|chat interface]]
- Supports custom [[concepts/automation-tools|workflow automation]]
- Increasingly capable of proactive behavior and ultrafast [[concepts/ai-inference|inference]], aligning with industry shifts toward [[concepts/proactive-ai|proactive AI]] agents
