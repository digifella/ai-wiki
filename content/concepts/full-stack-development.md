# Full-stack development

Full-stack development encompasses building both [[concepts/frontend-development|front-end]] (client-side) and back-end (server-side) components of [[concepts/web-applications|web applications]].

## Core Aspects
- **Front-end**: HTML, CSS, JavaScript, and frameworks ([[entities/react|React]], Vue, Angular)
- **Back-end**: Server logic, APIs, and databases ([[entities/nodejs|Node.js]], [[entities/python|Python]], PostgreSQL)
- **DevOps**: [[concepts/deployment|Deployment]] pipelines ([[concepts/docker|Docker]], Kubernetes), CI/CD practices
- **Database**: Schema [[concepts/design|design]], optimization (SQL, NoSQL)
