# App Drawer Consolidation

[[concepts/app-drawer|App Drawer]] [[concepts/consolidation|Consolidation]] is a [[concepts/design|design]] feature introduced in [[entities/android-16|Android 16]] that reorganizes how [[concepts/software|applications]] appear in the device's app drawer. The feature groups related applications into logical categories, reducing visual clutter and simplifying navigation for users with large numbers of installed applications. This organizational approach presents apps in a more structured layout, making it easier to locate specific applications without scrolling through an extensive unorganized list.

## How It Works

The consolidation system automatically categorizes installed applications into predefined groups such as productivity, entertainment, utilities, and communication. Users can access these grouped categories within the app drawer interface, collapsing or expanding sections as needed. This hierarchical organization allows users to quickly navigate to the category containing their desired application rather than searching through alphabetical or chronological listings.

## User Experience Impact

By reducing the number of visible items displayed [[concepts/assistive-technology|at]] once, App Drawer Consolidation improves the overall browsing experience on devices with hundreds of installed applications. The feature maintains search functionality alongside the new categorical layout, allowing users to switch between browsing by category or searching by application name. This dual-approach design accommodates both browsing and targeted search behaviors.
