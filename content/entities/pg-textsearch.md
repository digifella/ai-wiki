# pg_textsearch

[[concepts/open-source|Open-source]] [[concepts/postgresql-extension|PostgreSQL extension]] providing native [[concepts/bm25]] ranking and [[concepts/search-relevance|search relevance]], eliminating the need for external search engines (e.g., Elasticsearch) for many [[concepts/use-cases|use cases]], particularly in AI and [[concepts/rag]] [[concepts/software|applications]].

## Key Features
- Native [[concepts/bm25-ranking|BM25 ranking]] for precise search relevance
- Seamless [[concepts/integration|integration]] with PostgreSQL without external dependencies
- Optimized for [[concepts/rag]] [[concepts/workflow|workflows]] requiring high-quality [[concepts/document-retrieval|document retrieval]]
- Reduces infrastructure complexity by avoiding external search services

## Use Cases
- AI-powered [[concepts/full-text-search|document search]] in [[concepts/rag]] systems
- Real-time search within PostgreSQL without Elasticsearch
- Applications requiring low-latency, high-[[concepts/accuracy|accuracy]] [[concepts/text|text]] search
