# One Shot Image Generation Models

One shot image generation [[concepts/models|models]] are [[concepts/machine-learning-systems|machine learning systems]] designed to create visual content from minimal input—typically a single example or reference image. These models leverage deep [[concepts/learning|learning]] techniques to synthesize new [[concepts/images|images]] that match the [[concepts/style|style]], composition, or characteristics demonstrated by the input, without requiring extensive [[concepts/training|training]] on large datasets for each new task.

## PaperBanana Framework

[[concepts/plain-text-descriptions|PaperBanana]] is a framework developed by researchers [[concepts/assistive-technology|at]] [[concepts/google-search|Google]] and [[entities/peking-university|Peking University]] for [[concepts/automated-academic-illustration|automated academic illustration]]. The system addresses a specific use case within creative pursuits: generating scientific [[concepts/diagrams|diagrams]] and illustrations suitable for academic papers and research documents. By automating illustration generation, the framework aims to reduce the manual effort required in academic publishing while maintaining visual [[concepts/logical-consistency|consistency]] and clarity.

The framework operates within the broader context of one-shot learning approaches, where models adapt to new [[concepts/visual-generation|visual generation]] tasks with minimal example data. This capability is particularly valuable in academic contexts, where illustrations often follow established conventions but require [[concepts/customization|customization]] for individual papers and research domains.
