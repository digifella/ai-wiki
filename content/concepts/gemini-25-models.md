# Gemini 25 Models

Gemini 2.5 is a [[concepts/multimodal-ai|multimodal AI]] model developed by [[concepts/google-search|Google]] that can process and generate text, [[concepts/images|images]], and other content types. These models serve as the foundation for advanced [[concepts/ai-agentic-applications|AI agent applications]], particularly in research and investigation workflows.

## Integration with LangGraph

Gemini 2.5 models are integrated with LangGraph, a framework for building stateful, multi-step [[concepts/ai-agent-workflows|AI agent workflows]]. This combination enables the creation of sophisticated tools that can coordinate [[concepts/complex-reasoning|complex reasoning]] tasks across multiple stages. The LangGraph framework provides the orchestration layer that allows Gemini 2.5's capabilities to be chained together in structured, repeatable patterns.

## Multimodal Researcher Applications

A notable application of Gemini 2.5 within LangGraph is the multimodal researcher tool, designed to conduct [[concepts/comprehensive-investigations|comprehensive investigations]] by processing diverse information types. This tool leverages the model's ability to understand and analyze both text and visual content, generating detailed research outputs that synthesize findings across different media formats. Such applications demonstrate how Gemini 2.5 can handle complex, multi-step analytical tasks that require sustained [[concepts/reasoning|reasoning]] and [[concepts/information-synthesis|information synthesis]].
