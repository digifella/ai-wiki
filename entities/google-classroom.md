# Google Classroom

[[concepts/google-search|Google]] Classroom is a free web service developed by [[entities/google|Google]] for education that allows teachers to create, distribute, and grade assignments. It integrates with other [[concepts/google-workspace|Google Workspace]] tools and serves as a centralized hub for classroom communication and resource sharing.

## Key Features
- Assignment creation and distribution
- Gradebook functionality
- Real-time collaboration on documents
- Parent and student communication tools
- Integration with Google [[concepts/motivation|Drive]], [[entities/google-docs|Docs]], and Meet

## Integrating with NotebookLM
Google Classroom can host courses created from [[entities/notebooklm]]. Steps:

- **Prerequisites**:
  - Fully populated [[entities/notebooklm]] [[concepts/notebook|notebook]] (with sources and generated assets)
  - Google account
- **Course Setup**:
  1. Navigate to [classroom.google.com](https://classroom.google.com)
  2. Click **Create Class**
  3. Use [[concepts/ai-integrated-notebooks|NotebookLM]]-generated content (documents, summaries, exercises) as course materials
  4. Post assignments directly in Classroom
