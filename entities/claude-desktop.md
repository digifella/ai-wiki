# Claude Desktop

Claude Desktop is a native desktop application developed by Anthropic that provides direct access to the Claude AI assistant. Unlike web-based alternatives, the application runs locally on the user's machine, offering native performance and seamless integration with the operating system. It provides a streamlined interface for interacting with Claude's capabilities on computers running macOS and Windows.

The application supports configuration with Model Context Protocol (MCP) servers, which extend its functionality for specialized tasks such as data extraction. This integration allows users to connect Claude to local tools and data sources, enabling more complex workflows and customized interactions beyond standard conversational capabilities.
