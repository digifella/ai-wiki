# Unified System

The Unified System refers to the integration of the GPT-5 language model into Microsoft's enterprise AI infrastructure. This architecture provides advanced natural language processing capabilities across Microsoft's software ecosystem, enabling organizations to utilize the model through established enterprise channels rather than requiring separate, standalone tools.

The primary distribution channels for this integration are Microsoft 365 Copilot and Copilot Studio. Microsoft 365 Copilot embeds GPT-5 directly into productivity applications such as Word, Excel, and Outlook, allowing users to access AI assistance within their existing workflows. Copilot Studio serves as the platform for developers and IT administrators to build, customize, and deploy specialized AI copilots tailored to specific organizational needs.

This unified approach allows enterprise users to leverage GPT-5's capabilities without managing disparate interfaces. By consolidating access through Microsoft 365 and Copilot Studio, the system simplifies deployment and ensures that AI features are available across the broader Microsoft 365 suite.
