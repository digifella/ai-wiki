# Home Screen App List Access

Home Screen App List Access is a navigation feature introduced in [[entities/android-16|Android 16]] that provides users with direct access to the [[concepts/app-drawer|App Drawer]] from their home screen. The feature is implemented as a dedicated "App list" option within the home screen overlay menu, allowing users to quickly browse and launch installed applications without requiring additional navigation steps or gestures.

The "App list" option appears in the home screen overlay menu, which users can access through standard home screen interactions. This menu-based approach integrates the application launcher directly into the system's primary navigation layer, streamlining the process of locating and opening [[concepts/apps|apps]]. By placing this function within the overlay menu, Android 16 reduces the [[concepts/proper-distance|physical distance]] and time required to switch between the home screen and the full application grid.

This implementation is part of the broader tools-platforms-[[concepts/infrastructure|infrastructure]] domain, focusing on improving system usability and interface efficiency. It offers an alternative to traditional swipe-up gestures or dedicated drawer [[concepts/buttons|buttons]], catering to user preferences for menu-driven navigation. The feature ensures that the App Drawer remains readily accessible regardless of the current home screen layout or widget configuration.
