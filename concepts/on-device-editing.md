# Photography Software

Photography software encompasses tools for image capture, processing, and editing, spanning [[concepts/apps|mobile applications]] and desktop suites. This domain includes [[concepts/on-device-editing|on-device editing]] solutions like [[entities/adobe-project-indigo]] and professional desktop environments like [[entities/adobe-camera-raw]].

## On Device Editing

On device editing refers to the capability to perform [[concepts/photo-editing|photo editing]] and [[concepts/adjustments|adjustments]] directly within a camera application on a mobile device, rather than requiring transfer to a desktop or separate editing software. This approach streamlines the [[concepts/photography-workflow|photography workflow]] by enabling photographers to refine images immediately after capture, using the same device where the photo was taken.

### Workflow Advantages

The primary advantage of on device editing is efficiency. By consolidating capture and editing into a single tool and location, photographers eliminate the need to transfer files between devices or manage multiple applications. This is particularly valuable in situations where rapid [[concepts/iteration|iteration]] or timely sharing of images is necessary. Mobile photographers can make adjustments such as [[concepts/exposure|exposure]] correction, [[concepts/photo-tonal-adjustments|color grading]], cropping, and filtering without leaving the [[concepts/camera-app|camera app]].

## Desktop Processing: Adobe Camera Raw

While mobile apps handle immediate adjustments, [[concepts/desktop-apps|desktop software]] like [[entities/adobe-camera-raw]] (ACR) provides advanced control for complex edits. Recent [[concepts/software-updates|updates]] have integrated AI-driven tools to enhance [[concepts/accuracy|precision]] and [[concepts/speed|speed]].
