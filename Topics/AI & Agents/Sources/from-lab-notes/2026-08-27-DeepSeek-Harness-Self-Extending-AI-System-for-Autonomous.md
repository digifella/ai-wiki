## DeepSeek Harness: Self-Extending AI System for Autonomous Customization and Functionality
**Clip title:** [[entities/deepseek-ai|DeepSeek]]’s New AI System Shouldn’t Be Possible
**Author / channel:** Two Minute Papers
**URL:** https://www.youtube.com/watch?v=L9mMfAFwbl4

### Summary
This video introduces [[concepts/deepseek-harness|DeepSeek Harness]], an innovative free and [[concepts/open-source-ai|open-source AI]] system designed to empower AI agents to be "self-extending." Unlike traditional AI systems where functionality is pre-programmed, [[concepts/ai-agent|DeepSeek Harness]] allows the AI itself to write, extend, and customize its own capabilities and user interface based on user prompts. This represents a significant step towards more autonomous and adaptable AI.

The presenter highlights four key aspects that differentiate DeepSeek Harness. Firstly, the user interface is completely rewritable and customizable through plugins, demonstrated by adding a "flying whale" animation or a playable Snake game directly into the UI. Secondly, the agents within the harness can be customized. For instance, a "code review mode" was created on the fly, instructing the AI to analyze code, identify issues, and rank them by severity, effectively giving the AI a new persona and specialized skill.

The most crucial feature is the AI's ability to write its own programs and create new functionalities that didn't previously exist. The video illustrates this with several examples: developing a "research mode" to fact-check document claims against academic papers, creating a "[[concepts/local-ai|local AI]] lab" to monitor GPU usage and token speed, and even generating a "storyboard" agent for video production based on a simple description. This self-extension capability means users can simply request a new function, and the AI builds it specifically for them.

Finally, DeepSeek Harness is presented as incredibly lean and efficient. Performance comparisons show it achieving a competitive success rate while being significantly more cost-effective than other AI agents like Pi Agent, [[entities/claude|Claude]] Code, Open Code, and [[concepts/hermes-agent|Hermes Agent]]. The system's robustness is attributed to a "Track R" mechanism, which ensures that every change comes with built-in cleanup and reversal instructions, preventing the program from "falling apart" as it dynamically extends. This deep integration allows for safe and reversible modifications, baked directly into the system. The overarching conclusion is that as AI grows smarter, the operating systems around them should no longer be fixed but rather dynamically tailored and recreated on the fly, a vision that DeepSeek Harness actively supports through its open-source and adaptable architecture.
