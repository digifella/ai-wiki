# LangGraph Studio

[[concepts/langgraph-framework|LangGraph]] Studio is a visual [[concepts/coding-workspace|development environment]] designed for building, [[concepts/debugging|debugging]], and monitoring [[concepts/agentic-patterns|agentic workflows]] and [[concepts/multi-agent-systems|multi-agent systems]] within the [[concepts/langgraph|LangGraph]] ecosystem.

## Implementations & Use Cases
- **[[concepts/gemini|Gemini]] 2.5 [[concepts/multi-modal-researcher|Multi-modal Researcher]]**: An advanced research [[entities/agent|agent]] built using LangGraph and [[entities/google-gemini-25]].
    - Utilizes [[entities/gemini|Gemini]]'s native multi-modal [[concepts/capabilities|capabilities]] to perform [[concepts/comprehensive-investigations|comprehensive investigations]].
    - Operates via user-defined inputs (e.g., specific research topics) to generate diverse, detailed outputs.
    - Source: [[entities/langchain|LangChain]] ([Video](https://www.youtube.com/watch?v=6Ww5uyS0tXw))
