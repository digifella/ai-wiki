# Token pricing

The [[concepts/pricing|pricing]] mechanism used by [[concepts/large-language-models]] (LLMs) to charge for [[concepts/inference|inference]], typically calculated based on the volume of text processed.

## Core Components
- **Input [[concepts/tokens|Tokens]]:** The cost applied to the prompt and any provided context sent to the model.
- **Output Tokens:** The cost applied to the text generated by the model (usually priced higher than input tokens).
- **Model Tiering:** Cost variance based on model complexity, ranging from high-[[concepts/reasoning-models|reasoning models]] (e.g., [[entities/gemini-3-pro]]) to efficiency-optimized models.

## Current Market Benchmarks
- **[[entities/gemini-3-flash|Gemini 3 Flash]]:** A model optimized for speed, efficiency, and [[concepts/low-cost-deployment|low-cost deployment]].
    - **Price:** $0.50 per million input tokens.
    - **Efficiency:** High performance-to-cost ratio, scoring 78% on [[concepts/swe-bench-verified|SWE-bench Verified]].
