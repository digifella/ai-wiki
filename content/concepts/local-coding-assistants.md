# Local coding assistants

Systems and frameworks that utilize locally hosted [[concepts/large-language-models]] (LLMs) to provide AI-driven programming [[concepts/capabilities|capabilities]]—such as [[concepts/ai-coding|code generation]], refactoring, and agentic terminal execution—within a private or offline environment.

## Core Technologies
- [[entities/ollama]]: A streamlined platform for [[concepts/running|running]] and managing LLMs locally.
- [[entities/claude-code]]: An [[entities/prompt-engineering|agentic coding]] tool designed to interface with the [[entities/anthropic|Anthropic]] API.
- [[entities/glm-47-flash|GLM-4.7-Flash]]: A 30B parameter [[entities/mixture-of-experts]] (MoE) model used for efficient [[concepts/local-inference|local inference]].

## Recent Developments
- **[[concepts/anthropic-api-compatibility|Anthropic API Compatibility]]**: [[entities/ollama]] now supports the [[entities/anthropic-institute|Anthropic]] API standard, enabling tools built specifically for [[entities/claude-4|Claude]] to interact with local [[concepts/models|models]].
- **Local Agentic [[concepts/workflow|Workflows]]**: Users can now run [[entities/claude-code]] locally by routing its requests through [[entities/ollama]] using models such as [[entities/glm-47-flash|GLM-4.7-Flash]].
