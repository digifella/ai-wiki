# Software 2.0

**Software 2.0** refers to the paradigm shift where programs are no longer explicitly written by humans in traditional code ([[concepts/software-10|Software 1.0]]), but are instead learned by MachineLearning models from data. This concept, popularized by [[entities/andrej-karpathy]], highlights the transition from hand-crafted algorithms to [[concepts/neural-networks|neural networks]] that define the logic through weights and biases.

## Key Concepts

*   **Paradigm Shift**: The move from explicit, rule-based programming to implicit, data-driven specification of behavior.
*   **Neural Networks as Programs**: In Software 2.0, the "code" is the architecture and the trained weights of a neural network, optimized via gradient descent rather than manual logic.
*   **Innovation Opportunities**: As noted in recent analyses, this shift opens new avenues for innovation in ArtificialIntelligence and DeepLearning applications.
