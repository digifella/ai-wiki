# File Based Architecture

File Based Architecture refers to an approach to [[concepts/system-message-modification|autonomous agent design]] that leverages [[entities/anthropic-institute|Anthropic]]'s [[concepts/ai-assisted-coding|Claude Code]] tool as a general-[[concepts/motivation|purpose]] system for research, analysis, and [[concepts/knowledge-management|knowledge management]] tasks beyond traditional [[concepts/coding|software development]]. Rather than treating [[concepts/code-execution|code execution]] as primarily a programming function, this [[concepts/architecture|architecture]] uses file manipulation, data processing, and systematic workflows as the core mechanism through which an [[concepts/ai-agent|AI agent]] interacts with information and produces outputs. The methodology emerged in the mid-2020s as practitioners experimented with extending [[concepts/claude-ai|Claude]]'s code [[concepts/capabilities|capabilities]] into domains such as historical research, anthropological analysis, content generation, and [[concepts/automated-synthesis|knowledge synthesis]].

## Core Components

The architecture typically involves the [[entities/agent|agent]] managing multiple file types—[[concepts/markdown|markdown]] documents, HTML outputs, data [[concepts/files|files]], and structured [[concepts/notes|notes]]—as both input sources and delivery mechanisms. Rather than relying solely on conversational interaction, the system creates persistent artifacts and iteratively refines them through code-based operations. This allows the agent to maintain context across extended research sessions, organize complex information hierarchically, and generate publication-ready outputs without manual reformatting.

## Applications and Evolution

Documentation from 2026 shows practical implementations spanning [[concepts/ai-driven-research|AI-powered research]] note [[concepts/integration|integration]] ([[concepts/claude-code|Claude Code]] with [[concepts/obsidian|Obsidian]]), interactive content generation from research materials, video content optimization, and multi-[[concepts/multi-agent-orchestration|agent coordination]] through [[concepts/context-management|context management]]. The approach proved particularly effective for tasks requiring systematic data handling, such as converting narrative research into structured formats or generating comprehensive documentation from fragmented sources. File-based architecture represented a shift in how autonomous [[concepts/agents|agents]] could be deployed for [[concepts/knowledge-work|knowledge work]], emphasizing [[concepts/structured-output|structured output]] and [[concepts/persistent-state|persistent state]] management over ephemeral conversation.
