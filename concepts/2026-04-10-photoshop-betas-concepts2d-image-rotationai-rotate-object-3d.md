# 2026 04 10 Photoshop Betas Concepts2d Image Rotationai Rotate Object 3d

AI Rotate Object is a beta feature in Adobe Photoshop that enables users to rotate objects within 2D images using AI-assisted 3D transformation capabilities. Unlike traditional 2D rotation tools that simply pivot content around a fixed axis, this feature analyzes the spatial and dimensional properties of objects in photographs and applies three-dimensional rotation principles to generate results that appear consistent with the scene's perspective.

The tool utilizes generative fill technology to reconstruct the background areas exposed by the rotation, ensuring that lighting, shadows, and textures align naturally with the new object orientation. This allows for realistic manipulation of subjects without the need for manual cloning or complex masking, effectively bridging the gap between 2D photo editing and 3D modeling workflows.

Users can access this functionality through the context menu or specific object selection tools, where the AI automatically detects the subject's boundaries and depth map. The feature is currently available exclusively in the Photoshop beta channel, allowing Adobe to gather user feedback on accuracy and performance before potential integration into the stable release.
