# Prompting 2.0

**[[concepts/prompting|Prompting]] 2.0** represents a [[concepts/mindset-shift|paradigm shift]] in interacting with [[concepts/large-language-models|Large Language Models]] (LLMs), moving away from rigid, structured [[concepts/instruction-sets|instruction sets]] toward leveraging [[concepts/unstructured-input|unstructured input]] for advanced comprehension. This approach emphasizes context [[concepts/density|density]] and natural language [[concepts/flow|flow]] over syntactic [[concepts/accuracy|precision]].

## Core Concepts
- **Unstructured Input:** Prioritizes raw, unformatted data and natural language context over strict JSON or XML schemas.
- **Advanced Comprehension:** Relies on the model's ability to infer intent from broad context rather than explicit step-by-step [[concepts/commands|commands]].
- **[[concepts/context-length|Context Window]] Utilization:** Maximizes the effective use of available context to provide the model with comprehensive background information.

## Key Developments
- **[[concepts/karpathy|Karpathy]]'s Methodology:** [[entities/andrej-karpathy|Andrej Karpathy]] has popularized techniques that demonstrate significant performance improvements using this approach.
- **Viral [[concepts/adoption|Adoption]]:** The methodology gained rapid traction in the AI community for its "insane results" in complex [[concepts/reasoning|reasoning]] tasks.
