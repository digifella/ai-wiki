# Koen

Koen is an automation system designed to streamline the creation and distribution of AI-generated video content across multiple social media platforms. The system combines Claude Code, an AI-assisted coding tool, with Blotato, a multi-platform distribution service, to reduce manual intervention in content production and posting workflows. By integrating these technologies, Koen aims to optimize the efficiency of digital media campaigns through automated scripting and synchronized publishing.

## Operational Workflow

The process leverages Claude Code to automate the generation and formatting of video assets, handling tasks such as script writing, scene composition, and media assembly. This automated production phase is directly linked to Blotato, which manages the subsequent distribution. Once the content is generated, the system utilizes Blotato’s API to publish the videos simultaneously across various social networks, ensuring consistent branding and timing without requiring manual upload steps.

This integration allows for a continuous loop of content creation and deployment, minimizing the latency between ideation and publication. By automating both the technical aspects of video rendering and the logistical challenges of multi-platform posting, Koen serves as a tool for scaling digital media output while maintaining a standardized operational structure.
