# High-Bandwidth Memory (HBM)

High-Bandwidth [[concepts/memory|Memory]] (HBM) is a type of memory technology designed for [[concepts/production-grade-infrastructure|high-performance computing]] and graphics [[concepts/software|applications]] where bandwidth-intensive operations are required. HBM differs from traditional DDR memory by stacking multiple DRAM dies vertically, allowing for significantly higher [[concepts/data-management|data transfer]] rates within the same physical footprint.

- **Key Characteristics**:
  - Higher bandwidth compared to standard DRAM.
  - Lower power consumption relative to [[concepts/performance-gains|performance gains]].
  - Smaller form factor due to [[concepts/vertical-stacking|vertical stacking]] of chips.

- **Applications**:
  - [[concepts/graphics-processing-units-gpus|Graphics processing units (GPUs)]].
  - [[concepts/machine-learning|Machine learning]] and AI workloads.
  - [[entities/high-performance|High-performance]] computing systems.
