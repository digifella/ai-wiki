# Ai Generated Shorts

Ai Generated Shorts is an automated workflow that combines Claude Code, an AI coding assistant, with Blotato, a content distribution platform, to streamline the creation and publishing of short-form video content. The system integrates video generation, editing, and multi-platform distribution into a coordinated process, reducing manual effort across these separate stages. The workflow utilizes Claude Code to handle the technical aspects of content production, including script generation, asset assembly, and video rendering. By leveraging spec-driven development principles, the system ensures that the technical execution aligns with predefined content specifications before distribution.

The process begins with the generation of video scripts and the assembly of necessary media assets using Claude Code. This stage focuses on the structural and visual components of the short-form video, ensuring that the output meets the required technical standards for various platforms. The automated nature of this phase allows for rapid iteration and scaling of content production without significant human intervention in the coding or rendering steps.

Once the video assets are rendered, the workflow transitions to the distribution phase via Blotato. This platform manages the uploading and scheduling of content across multiple social media channels simultaneously. By connecting the production engine with the distribution network, the system creates a closed-loop pipeline that minimizes the gap between content creation and audience reach, optimizing efficiency for creators focused on short-form video metrics.
