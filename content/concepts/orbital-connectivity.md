# Orbital Connectivity

## Definition
Network topology enabling transit between peripheral [[concepts/nodes|nodes]] without routing through a central core. Contrasts with Radial Transit Network [[concepts/models|models]] where all [[concepts/flow|flow]] converges on a single center. Essential for Polycentric Urbanism and reducing CBD saturation.

## Strategic Attributes
- **Decentralization**: Distributes travel demand across multiple hubs; mitigates single-point failures.
- **Cross-Town Efficiency**: Reduces travel distance/time for suburban-to-suburban trips by eliminating radial detours.
- **Polycentric Support**: Reinforces multiple activity centers, promoting balanced regional development.
- **[[concepts/resilience|Resilience]]**: Diversifies network redundancy against disruptions in core infrastructure.
