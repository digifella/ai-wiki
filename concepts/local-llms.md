# Local LLMs

**[[concepts/cloud-based-services|Local LLMs]]** refer to [[concepts/large-language-models|large language models]] that are run locally on personal hardware rather than via cloud [[concepts/open-standard-protocols|APIs]]. This approach emphasizes data [[concepts/privacy|privacy]], offline capability, and the democratization of powerful [[concepts/ai-tools|AI tools]].
