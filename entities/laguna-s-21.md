# Laguna S 2.1

**[[concepts/local-inference|Laguna S 2.1]]** is an efficient, [[concepts/open-source|open-source]] [[concepts/agentic-ai|agentic coding]] model developed by Poolside. It is designed to run effectively on local hardware, leveraging a [[concepts/mixture-of-experts|Mixture-of-Experts]] (MoE) architecture to optimize performance and resource usage.

## Key Specifications
- **Parameters:** 118 billion
- **Architecture:** [[entities/mixture-of-experts|Mixture-of-Experts]] (MoE)
- **Primary Use Case:** [[concepts/autonomous-ai-coding-agent|Agentic coding]] tasks
- **Deployment:** Optimized for local hardware execution

## Context & Analysis
The model represents a significant step in making high-capability [[concepts/ai-coding-agents|coding agents]] accessible without reliance on cloud-based [[concepts/inference|inference]]. Its MoE structure allows it to activate only a subset of parameters for each task, enhancing efficiency compared to [[concepts/dense-models|dense models]] of similar scale.
