# Gbrain

**Gbrain** is an [[concepts/open-source|open-source]] "[[concepts/personal-knowledge-management-pkm|second brain]]" tool designed to provide [[concepts/ai-agent]]s with persistent, searchable [[concepts/memory|memory]] capabilities. It addresses the limitation of traditional agents lacking long-term context by augmenting them with a dedicated [[concepts/knowledge-base|knowledge base]].

## Key Features & Integration
- **Persistent Memory**: Enables [[concepts/agentic-ai|AI agents]] to retain and retrieve information across sessions, functioning as an externalized cognitive layer.
- **Searchable Knowledge Base**: Provides structured access to stored data, allowing agents to query past interactions or stored [[concepts/factual-knowledge|facts]].
- **Agent Augmentation**: Specifically highlighted for integration with [[entities/hermes-agent]], enhancing its operational scope beyond [[concepts/short-term-memory|immediate context]] [[entities/windows|windows]].
- **Open-Source Architecture**: Allows for [[concepts/customization|customization]] and community-driven development of [[concepts/memory-structures|memory structures]].
