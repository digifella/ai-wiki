# AI-generated infographics

Visual assets produced via [[concepts/generative-ai]]. While highly efficient for Data Visualization, they frequently suffer from typographic inaccuracies and hallucinations in text rendering.

## Editing & Text Correction
To address spelling mistakes or inaccuracies occurring in tools like [[entities/gemini]], the following [[concepts/workflow|workflows]] are used:
- **Adobe Acrobat**: Method for directly editing text within PDF versions of [[concepts/infographic-design|infographics]].
- **[[entities/canva|Canva]] 'Grab Text'**: Feature used to extract and edit text layers within static [[concepts/images|images]].
