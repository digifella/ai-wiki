# API pricing

## Overview
API pricing refers to the [[concepts/pricing-structure|cost structure]] for accessing [[concepts/artificial-intelligence-models|machine learning models]] via [[concepts/application-programming-interfaces-apis|application programming interfaces]]. Key factors include token-based pricing, model [[concepts/version-numbers|versioning]], and [[concepts/compute-costs|compute costs]].

## Anthropic Fable 5.1/Mythos 5.1 Pricing Analysis
Recent reviews highlight significant shifts in pricing strategies for [[concepts/frontier-intelligence|frontier models]].

- **Performance vs. Cost:** Analysis of [[concepts/claude-fable-51]] and [[concepts/mythos-51]] indicates substantial performance improvements, but requires scrutiny of [[concepts/real-world-costs|real-world costs]] versus claimed pricing [[lab-notes/2026-09-02-Anthropic-Fable-5.1Mythos-5.1-Review-Performance-Pricing|Anthropic Fable 5.1/Mythos 5.1 Review: Performance, Pricing Claims, and Real-World Costs]].
