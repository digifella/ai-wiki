# Action-based automation

A [[concepts/mindset-shift|paradigm shift]] in [[concepts/ai-automation]] moving from temporal/scheduled triggers to reactive, event-driven execution.

### Core Mechanics
- **Traditional Automation:** Operates on a temporal schedule (e.g., an "alarm clock" model) triggered by specific time intervals.
- **[[concepts/event-based-automation|Action-based Automation]]:** Responds to specific occurrences, state changes, or incoming data, enabling dynamic [[concepts/business-event-response|Business Event Response]].

### Emerging Technologies
- [[concepts/claude-ai|Claude]] Routines (by [[entities/anthropic]]): Represents a significant evolution in the field, transitioning automation from time-based triggers to action-specific workflows.
