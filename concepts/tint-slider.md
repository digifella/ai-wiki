# Tint Slider

The Tint Slider is a color adjustment control introduced in Photoshop 2025's Color and Vibrance tool. It enables users to shift the overall color temperature of an image along a warm-to-cool spectrum, making it a straightforward method for addressing color casts that result from various lighting conditions. Common applications include correcting the blue tint cast by overcast daylight or the orange tint produced by tungsten bulbs.

## How It Works

The slider operates on a linear axis, with negative values pushing colors toward cooler (blue) tones and positive values shifting toward warmer (yellow/red) tones. This mechanism allows for precise correction of white balance issues without requiring manual channel mixing or complex curve adjustments. By adjusting the slider, users can neutralize unwanted color casts or creatively alter the mood of an image through temperature manipulation.

## Usage Context

This tool is particularly effective for post-processing RAW files where white balance settings can be adjusted non-destructively. It serves as a primary method for balancing mixed lighting scenarios, such as combining indoor tungsten light with outdoor daylight. The integration into the Color and Vibrance panel provides a unified interface for managing both saturation and temperature, streamlining the workflow for photographers and digital artists.
