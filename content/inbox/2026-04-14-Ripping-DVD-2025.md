# Ripping DVD - 2025

---
---
Try [[entities/vlc|VLC]] first (with [[concepts/libdvdcss|libdvdcss]] library installed)
If no good, try Handbrake (same install)
If no good, try [[entities/makemkv|MakeMKV]] (back up to [[concepts/dvd-iso|DVD iso]] then use Handbrake)
Note: VLC can open dvd iso [[concepts/files|files]] but you need to drag and drop it into VLC (open via menu does not show the DVD iso files).
