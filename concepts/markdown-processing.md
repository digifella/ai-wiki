# Markdown Processing

The transformation and structural parsing of [[concepts/markdown|markdown]] text into structured, machine-readable data formats or complex information architectures.

## Applications & Workflows
- **[[concepts/knowledge-graph|Knowledge Graph]] Construction**:
    - Implementing the Cocoindex [[concepts/data-transformation|data transformation]] framework to convert collections of [[concepts/markdown|markdown]] documents into [[concepts/real-time-knowledge-graph|real-time knowledge graphs]].
    - Using [[concepts/large-language-models|Large Language Models (LLMs)]] to extract semantic [[concepts/relationships|relationships]] and [[concepts/nodes|entities]] during the processing pipeline.
    - Integrating processed data with [[entities/neo4j|Neo4j]] as a [[concepts/graph-database|graph database]] to power [[concepts/llm-rag|LLM RAG]] systems.
