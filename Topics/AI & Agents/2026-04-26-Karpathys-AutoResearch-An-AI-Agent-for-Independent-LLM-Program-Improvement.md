## Karpathy's AutoResearch: An AI Agent for Independent LLM Program Improvement
**Clip title:** I Used Karpathy’s Autoresearch to Train an LLM!
**Author / channel:** Thu Vu
**URL:** https://www.youtube.com/watch?v=XXR0zZ0_16M

### Summary
This video explores the burgeoning field of AI-generated code, noting that over 41% of global code is projected to be AI-generated by 2026. The main topic revolves around "[[concepts/autoresearch|AutoResearch]]," an [[concepts/open-source|open-source]] project by [[entities/andrej-karpathy|Andrej Karpathy]] (former Tesla Director of AI and [[entities/openai|OpenAI]] co-founder), which enables an [[concepts/ai-coding|AI coding]] [[entities/agent|agent]] to autonomously improve a program in a [[concepts/loop|loop]]. This initiative signifies a significant shift in human-[[concepts/ai-collaboration|AI collaboration]], moving beyond "[[concepts/vibe-coding|vibe coding]]" (human prompts, AI writes, human reviews) and "[agentic engineering](https://en.wikipedia.org/wiki/Agentic_Engineering)" (human orchestrates agents) to "[independent research](https://en.wikipedia.org/wiki/Independent_Research)," where humans act more as "research advisors" by setting direction and letting the AI run independently.

The core of [[concepts/automated-code-modification|AutoResearch]]'s [[concepts/design|design]] is built upon three distinct [[concepts/files|files]]: `prepare.py`, `train.py`, and `program.md`. The `prepare.py` file handles immutable aspects like data [[concepts/preparation|preparation]] and defining the evaluation metric. The `train.py` file serves as the [[entities/agent|agent]]'s sandbox, containing the training code that the [[concepts/ai-agent|AI agent]] is allowed to modify and iterate upon. Crucially, `program.md` contains the human-written [[concepts/instructions|instructions]], research directions, principles, and constraints, guiding the AI's experiments. The [[concepts/iterative-refinement|iterative process]], dubbed a "ratchet [[concepts/loop|loop]]," involves the AI proposing hypotheses by modifying `train.py`, committing changes, running training for a fixed budget (e.g., 5 minutes), and evaluating the results against the defined metric. If an improvement is observed, the commit is kept; otherwise, it's reverted, ensuring that only progress is maintained.

For an AI agent to be "self-improving" in this context, three conditions must be met: a clear, automatically measurable metric (ideally a single number), a single file for the agent to edit, and a time-boxed experimental loop. The video demonstrates this by attempting to train a tiny [[concepts/statistical-language-modeling|language model]] on folklore and mythology datasets using [[entities/mistral|Mistral]] Vibe, an [[concepts/open-source|open-source]] [[concepts/command-line-interface|command-line]] [[concepts/coding-assistant|coding assistant]] that supports agentic capabilities, including an "auto-approve" (dangerous) mode. After setting up the environment, installing dependencies, and preparing the data, the AI agent is given [[concepts/instructions|instructions]] via `program.md` to begin its [[concepts/autonomous-research|autonomous research]].

Over several hours, the agent ran multiple experiments, making various modifications to the `train.py` file in an attempt to optimize the validation bits-per-byte (val_bpb) metric. Out of eleven experiments, six resulted in kept improvements, visibly decreasing the metric in a step-like graph. While the generated story samples still lacked perfect coherence, the final iterations showed notable improvements in [[concepts/grammar|grammar]] and sentence [[concepts/structure|structure]] compared to the baseline. The key takeaway emphasizes that while AI agents can effectively handle the execution and iterative aspects of research, the human role in defining worthwhile research directions, understanding the problem, and providing the ultimate judgment for what constitutes "better" remains paramount. This ability to frame problems for autonomous agents is presented as a vital skill for the future.
