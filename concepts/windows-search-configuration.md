# Windows Search configuration

## Overview
Configuration of the [[concepts/microsoft-windows|Windows]] search [[concepts/experience|experience]] involves managing [[concepts/data-indexing|indexing]] options, start menu layout, and taskbar integration. While early versions of [[entities/windows-11]] restricted [[concepts/user-control|user control]], recent [[concepts/software-updates|updates]] have restored and expanded [[concepts/customization|customization]] capabilities.

## Key Customization Areas
- **Start Menu Layout**: Users can now pin/unpin [[concepts/apps|apps]], adjust grid [[concepts/density|density]], and manage recently added items visibility.
- **Taskbar Integration**: Search box can be toggled between "Search box" (visible) and "Search icon" (compact) modes.
- **Indexing Options**: Control over what file types and locations are indexed for faster [[concepts/document-retrieval|retrieval]].
- **Search History**: Manage or clear local search history and disable cloud-based search suggestions.
