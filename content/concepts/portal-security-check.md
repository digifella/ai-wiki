# Portal Security Check

A Portal Security Check is a verification process conducted on the [[concepts/asic-login-portal|ASIC Company Portal]] when accessing company information using an Australian Company Number (ACN). The check is designed to authenticate user access and validate the legitimacy of information requests before displaying sensitive company data.

## Process and Access

When a user enters an ACN into the ASIC Company Portal, the system performs a security check to confirm the validity of the request. In the case of Calliston Consultants, this process generated a response page indicating ASIC's official position on data access and presenting the user with available options for proceeding. The security mechanism appears to be a standard control point in the portal's [[concepts/knowledge-bases|information retrieval]] workflow.

## Purpose

The security check serves to protect company information held by ASIC and ensure that access requests comply with regulatory requirements. By implementing this verification step at the point of ACN entry, the portal maintains control over who can view certain company records and under what circumstances that access is permitted.
