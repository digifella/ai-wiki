# Uiux Design

[[concepts/design|UI/UX design]] encompasses the creation and optimization of user interfaces and user experiences in digital products. UI ([[concepts/user-interface|user interface]]) focuses on the visual and interactive elements—[[concepts/buttons|buttons]], menus, layouts, and visual [[concepts/feedback|feedback]]—while UX ([[concepts/user-experience-design|user experience]]) addresses the broader journey a user takes when interacting with a product, including how intuitive, efficient, and satisfying that interaction feels. These two disciplines are distinct but interdependent, requiring a holistic approach to ensure that aesthetic decisions support functional goals.

## Core Principles

Effective design relies on several foundational concepts that guide user interaction. **Affordances** refer to the perceived properties of an object that suggest how it can be used, allowing users to understand functionality without explicit instruction. **Visual hierarchy** organizes elements to indicate importance, guiding the user’s eye through the interface in a logical sequence. **Grids** provide a structural framework that ensures consistency, alignment, and balance across different screen sizes and components.

## Typography and Layout

**Typography** plays a critical role in readability and information architecture. Proper selection of typefaces, sizes, and spacing enhances legibility and establishes a clear visual tone. Combined with strategic use of whitespace and grid systems, typography helps break down complex information into digestible chunks. These elements work together to reduce cognitive load, ensuring that users can navigate the interface efficiently and with minimal friction.
