# Appearance Change

Appearance Change refers to the computational process of modifying visual elements within [[concepts/images|images]] through [[concepts/ai-assisted-editing|AI-assisted editing]]. This capability enables users to alter aspects of an image's composition, [[concepts/style|style]], or specific features based on textual [[concepts/instructions|instructions]] rather than manual manipulation. The approach represents a shift from traditional pixel-level editing tools toward instruction-driven workflows where [[concepts/natural-language-descriptions|natural language descriptions]] guide the transformation process.

## HiDream-E1.1

[[entities/hidream-e11|HiDream-E1.1]] is an instruction-based [[concepts/open-source-image-editing|open-source AI image editing]] model designed to perform appearance changes. The model supports [[concepts/dynamic-resolution|dynamic resolution]], allowing it to process images [[concepts/assistive-technology|at]] varying [[concepts/musical-scales|scales]] and dimensions. As an instruction-based system, it accepts textual prompts that specify desired edits, translating these descriptions into corresponding visual modifications within the source image.

The open-source [[entities/nature|nature]] of HiDream-E1.1 makes the model and its underlying [[concepts/architecture|architecture]] publicly available for research, development, and community-driven improvements. This [[concepts/accessibility|accessibility]] facilitates broader [[concepts/adoption|adoption]] and experimentation with instruction-based image editing workflows across different [[concepts/software|applications]] and [[concepts/scenarios|use cases]].
