# Color Palette Manipulation

The Color Mixer in Lightroom Classic enables photographers to adjust specific color ranges within an image using HSL (Hue, Saturation, Luminance) controls. Rather than applying broad adjustments across an entire photograph, this tool isolates individual color channels—such as reds, oranges, yellows, greens, cyans, blues, and magentas—allowing independent modifications to each. This selective approach proves particularly useful when one color in an image requires correction without affecting surrounding tones.

## How HSL Adjustments Work

The three components of HSL manipulation serve distinct purposes. The Hue slider shifts a color's position on the color wheel, allowing photographers to change how a specific color appears without altering its brightness or intensity. The Saturation slider controls color intensity, from muted tones to vibrant hues. The Luminance slider adjusts brightness within a specific color range, brightening or darkening reds without affecting blues, for example.

## Practical Applications

Color Palette Manipulation proves effective for correcting color casts in specific regions, enhancing particular colors to draw viewer attention, or achieving stylistic consistency across a series of photographs. Photographers commonly use these controls to correct skin tones, intensify sky blues, mute distracting colors, or create cohesive color grading across an image series. The non-destructive nature of Lightroom adjustments allows photographers to refine these changes iteratively without permanently altering the original image file.
