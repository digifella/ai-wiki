# Dynamic Wallpaper Matching

Dynamic Wallpaper Matching is a system feature introduced in [[entities/android-16|Android 16]] that automatically adjusts device wallpapers and [[concepts/gui-interface|visual interface]] elements to coordinate with user preferences and system settings. The functionality was released in 2025 as part of the [[entities/june-2025-pixel-drop|June 2025 Pixel Drop]] update and is available on compatible hardware, including the [[entities/pixel-9-pro-xl|Pixel 9 Pro XL]].

The feature operates by analyzing the color palettes, [[concepts/contrast|contrast]] levels, and design elements within a user-selected wallpaper. It then generates coordinated visual themes across the device interface, ensuring that system UI components harmonize with the chosen background image. This process aims to provide a cohesive aesthetic [[concepts/experience|experience]] by aligning visual cues with the user's selected wallpaper and current system configuration.
