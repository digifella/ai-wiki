# Coding

Coding refers to the practice of [[concepts/writing|writing]], testing, and maintaining source code in local [[concepts/developer-platforms|development environments]]. Developers use text editors, integrated [[concepts/sandbox-environments|development environments]] (IDEs), [[concepts/app-updates|version control]] systems, and related tools to build software applications on their own machines before deployment to [[concepts/production-grade-infrastructure|production systems]]. This foundational activity enables programmers to [[concepts/scientific-experiment|experiment]], debug, and refine their work in [[concepts/disconnection|isolation]] before sharing or releasing code.

## Development Tools and Environments

Local coding relies on a variety of tools tailored to different programming languages and workflows. Text editors range from minimal, language-agnostic tools to full-featured IDEs that provide syntax highlighting, code completion, [[concepts/debugging|debugging]] capabilities, and integrated [[concepts/cli|terminal]] access. The landscape is increasingly influenced by [[concepts/ai-integration|AI integration]], where models assist in [[concepts/code-generation|code generation]], refactoring, and [[concepts/complex-tasks|agentic task execution]].

## AI-Assisted Coding and Agentic Models

Recent advancements in [[concepts/llm-integration|LLM integration]] have introduced agentic capabilities that extend beyond simple code completion to autonomous [[concepts/productivity|productivity]] workflows.

*   **Solar Open 2 LLM**: An [[concepts/open-weight|open-weight]] [[concepts/large-language-model|large language model]] developed by Upstage in Korea, highlighted for its impressive agentic capabilities in office productivity and coding demonstrations [[lab-notes/2026-07-30-Solar-Open-2-LLM-Agentic-Capabilities-for-Productivity-a|Solar Open 2 LLM: Agentic Capabilities for Productivity and Coding Demonstrations]].
*   **[[concepts/agentic-patterns|Agentic Workflows]]**: Unlike traditional chat-based assistants, models like Solar Open 2 can execute multi-step tasks, interact with local environments, and manage complex coding projects autonomously.
*   **Open-Weight Advantage**: The open nature of Solar Open 2 allows developers to [[concepts/deployment|deploy]] it locally, enhancing [[concepts/privacy|privacy]] and enabling deeper integration with local [[concepts/developer-tools|developer tools]] without reliance on external API constraints.
