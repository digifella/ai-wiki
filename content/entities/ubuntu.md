# Ubuntu

Ubuntu is a free and [[concepts/open-source|open-source]] [[entities/linux|Linux]] [[concepts/distribution|distribution]] based on Debian. It is designed for personal computers, servers, and [[concepts/cloud-computing|cloud computing]] environments. Ubuntu is maintained by Canonical Ltd. and is one of the most widely used Linux distributions globally, known for its ease of use and regular release cycle.

The distribution emphasizes [[concepts/accessibility|accessibility]] and community-driven development. Ubuntu releases new versions every six months, with long-term support (LTS) versions available every two years, providing stability for users who require extended support periods. The name "Ubuntu" comes from a Zulu word meaning "humanity towards others."

Ubuntu is available in multiple editions tailored to different [[concepts/scenarios|use cases]], including a desktop version for personal computers, a server version for data centers, and specialized variants for IoT and cloud [[concepts/deployment|deployment]]. The distribution includes a comprehensive [[concepts/software|software]] repository containing thousands of pre-packaged applications available through the apt [[concepts/package-manager|package manager]].
