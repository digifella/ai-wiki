# Skills

Skills in [[concepts/agentic-ai|AI agents]] refer to the capabilities and functions that enable these systems to perform specific tasks effectively. For AI-powered [[concepts/agents|agents]], skills represent distinct competencies—such as code execution, data retrieval, document analysis, or creative generation—that extend beyond basic language understanding. These capabilities are often implemented through tool integration, allowing agents to interact with external systems, APIs, and programming environments rather than relying solely on [[concepts/text-generation|text generation]].

## Code Execution as a Core Skill

Code execution has emerged as a particularly valuable skill for AI agents in professional contexts. The ability to write, test, and run code enables agents to handle complex computational tasks, data processing, and [[concepts/coding|software development]] workflows more efficiently than [[concepts/markdown|markdown]]-based alternatives. This skill is especially relevant for engineering tasks where agents can autonomously validate solutions and iterate on problems.

## Integration with External Tools

Modern AI agents acquire skills through integration with [[concepts/specialized-tools|specialized tools]] and platforms. These might include design [[concepts/software|software]], [[concepts/web-crawling|web scraping]] utilities, [[concepts/knowledge-management|knowledge management]] systems, or domain-specific APIs. Such integrations allow agents to move beyond language generation and perform actionable work within established workflows and environments. The effectiveness of an agent often depends on the breadth and quality of skills available to it.
