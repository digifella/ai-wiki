# AI code completion

[[concepts/auto-completion-suggestions|AI code completion]] is the practice of using [[concepts/ai-technologies|artificial intelligence]] to predict and suggest code snippets, functions, or entire blocks of code in real-time as developers type, significantly accelerating development cycles and reducing errors.
