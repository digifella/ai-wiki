# Prompt Refinement Loop

A repetitive "back-and-forth" interaction pattern between a user and an [[concepts/llm]] (such as [[entities/chatgpt]], [[entities/claude]], or [[entities/gemini]]) characterized by iterative attempts to steer the model toward a desired [[concepts/output|output]].

### Core Problems
- **Time Inefficiency**: Significant time is wasted through continuous manual [[concepts/adjustments|adjustments]] and follow-up queries.
- **User Dissatisfaction**: The iterative [[entities/nature|nature]] often leads to frustration when the model fails to grasp intent.
- **Operational [[concepts/friction|Friction]]**: Represents a costly productivity bottleneck for solopreneurs and small teams.

### Mitigation Strategies
- Reduce reliance on the [[concepts/loop|loop]] by using [[concepts/google-gemini-gems]] to pre-configure [[concepts/instructions|instructions]], personas, and constraints.
- Move from reactive [[concepts/prompting|prompting]] to proactive, structured workflows.
