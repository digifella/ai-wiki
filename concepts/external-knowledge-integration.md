# External knowledge integration

The process of augmenting [[concepts/large-language-models]] with data from outside their original training set to enhance accuracy and utility within [[concepts/agentic-ai]].

## context engineering
The [[concepts/art|art and science]] of optimizing the [[concepts/context-window]] by strategically injecting the necessary information at each step of an Agent's trajectory.

- **Core Components**:
    - [[concepts/instructions|Instructions]] ([[concepts/system-prompts|System Prompts]]).
    - External knowledge (e.g., via [[concepts/rag]]).
    - [[concepts/tool-feedback]] and execution outputs.
- **Implementation**: Frameworks like [[concepts/langgraph-framework|LangGraph]] provide structured support for managing these context-shifting strategies.
