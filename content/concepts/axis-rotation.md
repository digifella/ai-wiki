# Axis Rotation

Axis rotation is a technique for three-dimensional manipulation of two-dimensional [[concepts/images|images]], enabling users to rotate flat photographs and images along multiple axes. Rather than applying simple 2D transformations like skewing or stretching, axis rotation creates the visual effect of viewing an image from different angles or perspectives in three-dimensional space. This approach simulates how an object would appear if physically rotated away from the viewer.

## Technical Implementation

The [[concepts/2d-image-rotation|AI Rotate Object]] tool in [[concepts/beta-version|Photoshop Beta]] provides the primary [[concepts/adoption|implementation]] of axis rotation for creative work. When a user rotates an image along an axis, the tool generates visual content to fill areas that would become visible through the rotation. This generative approach differs from traditional rotation methods that either leave empty spaces or require manual [[concepts/content-creation|content creation]]. The tool uses [[concepts/machine-learning|machine learning]] to infer plausible visual information consistent with the existing image content and perspective.

## Applications

Axis rotation is useful for adjusting the apparent perspective of photographs, creating alternative viewing angles of flat artwork, and generating composition variations without requiring new photographs or source material. The technique is particularly relevant for product photography, [[concepts/design|design]] mockups, and conceptual visualization where showing an object from multiple angles enhances presentation or communication.
