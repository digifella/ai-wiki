# Audio Project

## Overview
An audio-project involves creating, editing, and enhancing [[concepts/audio-modality|audio]] content, often for educational, entertainment, or professional purposes.

## Key Concepts
- **[[entities/notebooklm|NotebookLM]]**: A tool for generating [[concepts/audio-overviews|audio overviews]] from [[concepts/text|text]] sources.
- **Elevlabs**: A platform for enhancing and modifying [[concepts/tone|voice]] characteristics in audio [[concepts/files|files]].

## Workflow
- Generate an [[concepts/audio-overview|audio overview]] using [[concepts/notebooklm|NotebookLM]].
- Download the audio file and upload it back to [[concepts/ai-integrated-notebooks|NotebookLM]] to generate a [[concepts/text-transcript|text transcript]].
- Use Elevlabs to change or enhance the voice in the audio file.
