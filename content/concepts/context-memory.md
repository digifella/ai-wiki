# Context Memory

The ability of an AI system to retain and utilize past interactions, [[concepts/user-control|user preferences]], and contextual data to enhance subsequent [[concepts/responses|responses]] and task execution without repetitive input. Enables [[concepts/continuity|continuity]] in [[concepts/complex-workflows|complex workflows]] and personalized assistance.

**Core Mechanisms**:
- [[concepts/persistent-state|Persistent state]] management across sessions
- Dynamic [[concepts/context-window|context window]] adaptation
- User behavior pattern recognition

**[[concepts/software|Applications]]**:
- [[concepts/custom-ai-assistants|Custom AI assistants]] via [[entities/gemini]]'s "Gems" feature:
  - *[[concepts/meeting-prep-strategist|Meeting Prep Strategist]]*: Retains historical meeting data, participant roles, and agenda context for automated [[concepts/preparation|preparation]]
  - *Automated Weekly Business Report*: Leverages past reports and metrics to generate context-aware summaries
- Reduced cognitive load through contextual [[concepts/recall|recall]] (e.g., remembering project specifics without re-explanation)
