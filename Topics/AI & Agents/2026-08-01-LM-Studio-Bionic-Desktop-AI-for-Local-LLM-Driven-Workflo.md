## LM Studio Bionic: Desktop AI for Local LLM-Driven Workflows
**Clip title:** [[concepts/lm-studio|LM Studio]] Just Got a Huge Upgrade — This Changes Everything (Bionic)
**Author / channel:** Bart Slodyczka
**URL:** https://www.youtube.com/watch?v=3txBLHPG_rg

### Summary
LM Studio Bionic is a newly released, free desktop application designed as an intelligent agent for interacting with open [[concepts/demystifying-llms|Large Language Models]] (LLMs) locally on your computer. It serves as a replacement for previous tools like [[concepts/ai-assisted-coding|Claude Code]] and [[concepts/ad-generation|Claude Cowork]], allowing users to leverage the power of [[concepts/ai-models|AI models]] for various tasks directly on their device. While users can download and run numerous local models, Bionic also offers access to larger, frontier [[concepts/open-weight-models|open models]] (like GLM 5.2 and [[concepts/kimi-k3|Kimi K3]]) hosted on LM Studio's [[concepts/secure|secure]] cloud servers, which operate with a "Zero Data [[concepts/storing|Retention]]" policy, though these [[concepts/cloud-based-models|cloud-based models]] require a billing setup.

The application distinguishes itself with two primary operational modes: Work Mode and Code Mode. Work Mode creates a managed sandbox environment on your computer, similar to Claude Cowork, enabling users to create and edit documents, research topics, summarize notes, draft reports, create presentations, and brainstorm ideas. All changes are automatically saved locally, ensuring user [[concepts/privacy|data privacy]]. Code Mode connects Bionic to a local working directory, allowing it to assist with coding tasks such as finding features, [[concepts/debugging|debugging]], refactoring, implementing new functionalities, adding tests, updating documentation, and reviewing code changes. A built-in browser panel facilitates live preview and editing of web-related projects.

Beyond its core Work and Code functionalities, Bionic introduces several notable features. It supports real-time voice transcription through a locally downloaded multilingual model (Voxtral by [[entities/mistral|Mistral]] AI), processing speech directly on the device. The application's native local processing capabilities for LLMs are powered by MLX and [[concepts/inference-engine|llama.cpp]] runtimes, supporting various formats like GGPUF and MLX. Additionally, Bionic includes a built-in web search (requiring a billing setup for LM Studio's service) and integrates with various external services via Managed Connected Providers (MCPs). These MCPs allow Bionic to interact with popular platforms like GitHub, Linear, Notion, S and Atlassian, as well as custom-configured services like ClickUp, extending its automation and workflow capabilities.

The [[concepts/user-interface|user interface]] of Bionic is intuitive, featuring a familiar chat-like input box, a model selector for choosing between downloaded local models and cloud-hosted options, and a transcription button for voice input. Projects and historical chats are organized in a left-hand panel, while an auxiliary tab on the right displays project-specific files and folders. The video demonstrates Bionic effectively summarizing AI news from the web into a professional [[concepts/markdown|markdown]] document and integrating with ClickUp to create tasks and generate an HTML report based on the task information, which can then be served locally for preview. Overall, LM Studio Bionic presents itself as a highly capable and evolving tool for [[concepts/local-ai|local AI]], offering robust features for both creative and technical tasks, with continuous [[concepts/software-updates|updates]] aimed at improving functionality and addressing initial issues.
