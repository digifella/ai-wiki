# Discontinuous Function

A function that is not continuous function at one or more points in its domain. At these points, the limit of the function does not equal the function's value, or the limit does not exist.

## Key Characteristics
- **Limit Mismatch:** $\lim_{x \to c} f(x) \neq f(c)$
- **Visual Breaks:** Graphs exhibit jumps, holes, or asymptotes.
- **Classification:** Includes jump discontinuity, removable discontinuity, and essential discontinuity.

## Pathological Examples
Standard discontinuities (e.g., step functions) are intuitive. However, certain functions exhibit extreme discontinuity properties that challenge standard intuition:

- **[[concepts/conways-base-13-function|Conway's Base 13 Function]]:** A function defined on the real numbers that takes on every real value in every interval, no matter how small. It is a classic example of a function that is discontinuous everywhere yet defined everywhere.
- **Intuitive Challenge:** While standard functions map inputs to unique outputs, this concept challenges the [[concepts/visual-representation|visual representation]] of functions, often defying the expectation that a function's graph can be drawn without lifting the pen.
