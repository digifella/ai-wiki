# Obsidian Flavored Markdown

Obsidian Flavored Markdown (OFM) is the specific markdown dialect utilized by the Obsidian personal knowledge management application. Built upon the CommonMark specification, OFM extends standard syntax with features tailored for interconnected note-taking and knowledge organization. Unlike standard markdown variants that prioritize linear document structure, OFM emphasizes bidirectional linking and relationship mapping to support non-linear information retrieval.

The dialect introduces several key extensions to facilitate this interconnected workflow. Notable features include internal wiki-style links for connecting notes, tags for categorization, and support for mathematical notation via LaTeX. These additions allow users to create a web of information rather than a series of isolated documents, enabling complex knowledge graphs and backlinking capabilities that are central to the Obsidian ecosystem.

Integration with external tools enhances the utility of OFM in technical workflows. For instance, developers can utilize Claude Code AI to generate or refactor markdown content, ensuring syntax compliance while automating documentation tasks. Furthermore, synchronization with GitHub allows users to version control their vaults, leveraging standard Git operations to manage changes across multiple devices and collaborate on shared knowledge bases.
