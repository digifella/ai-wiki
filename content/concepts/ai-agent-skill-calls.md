# AI Agent Skill Calls

AI Agent Skill Calls are standardized method interfaces that enable [[concepts/ai-technologies|artificial intelligence]] [[concepts/agents|agents]] to invoke specific functions and capabilities within [[concepts/organization|organizational systems]]. They serve as the technical foundation for agent-first architectures, where [[concepts/agentic-ai|autonomous AI systems]] operate as primary decision-makers and task executors. By providing a common protocol for agents to request and execute actions, Skill Calls reduce the complexity of integrating multiple agents with various backend systems and [[concepts/software|applications]].

## Standardization and Industry Adoption

[[entities/anthropic-institute|Anthropic]], [[entities/openai|OpenAI]], and Microsoft have collaborated on a [[concepts/agent-first-organizational-infrastructure|unified AI skill format]] designed to support agent-first organizational infrastructure. This standardization effort aims to establish consistent conventions for how agents communicate with tools and services across different platforms and providers. The agreement reflects industry recognition that interoperability [[concepts/open-standards|standards]] become increasingly important as AI agents become more prevalent in business operations.

## Technical Function

Skill Calls define how agents specify which actions to perform, what [[concepts/parameters|parameters]] are required, and how results should be returned. Rather than requiring custom integration logic for each agent-system combination, a standardized format allows agents from different providers to interact with the same organizational tools. This approach facilitates more flexible [[concepts/deployment|deployment]] of agents and reduces engineering overhead when incorporating new capabilities or switching between AI platforms.
