# Typography

Typography is the art and technique of arranging type to make written language legible, readable, and appealing when displayed. It involves selecting typefaces, point sizes, line lengths, line-spacing (leading), and letter-spacing (tracking).

### Key Concepts
- **Legibility**: The extent to which letters in a font are different from each other.
- **Readability**: How easily text can be read over prolonged periods of time.
- **[[concepts/hierarchy|Hierarchy]]**: Using typography to create visual hierarchy by varying font sizes, [[concepts/weights|weights]], styles, and colors.
- **Grids**: Layout systems that provide [[concepts/structure|structure]] for arranging elements on a page.
