# iPad USB-C Port

The [[concepts/usb-c-connectivity|iPad USB-C port]] is a high-[[concepts/speed|speed]] interface used for power delivery, data transfer, and expanding iPadOS functionality through peripheral integration.

## Functionality & Use Cases
- **Peripheral Expansion:** Enables [[concepts/connection|connection]] of External [[entities/storage|Storage]], USB Hubs, SD Card Readers, and Keyboards to extend the device's utility.
- **Creative Workflows:** Provides the backbone for professional Creative Workflows by allowing direct access to high-[[concepts/network-speed|bandwidth]] peripherals.
- **Display Support:** Facilitates external Display connectivity via [[concepts/usb-30|USB-C]] to HDMI adapters for desktop-class setups.
- **Enhanced [[concepts/productivity|Productivity]]:** Supports five practical methods for extending functionality beyond basic charging to improve Productivity.
