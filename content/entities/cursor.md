# Cursor

AI-powered [[concepts/code|code]] editor designed for developers, featuring advanced [[concepts/software|code]] completion, refactoring, and integrated chat for code assistance. Built to replace traditional editors with [[concepts/ai-driven-productivity|AI-driven productivity]] workflows.
