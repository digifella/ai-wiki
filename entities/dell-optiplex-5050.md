# Dell Optiplex 5050

The [[entities/dell|Dell]] Optiplex 5050 is a small form factor [[concepts/personal-computer|desktop computer]] that has been repurposed as an [[concepts/media-server|Ubuntu media server]]. This configuration allows the machine to serve media content to other devices on a network while running the [[entities/ubuntu|Ubuntu Linux]] operating system.

## Use Case

As a [[concepts/home-server|media server]], the Optiplex 5050 can host and stream video, [[concepts/audio-modality|audio]], and other media files to connected devices throughout a home or office network. This setup has been documented as a cost-effective alternative to maintaining multiple subscription-based [[concepts/streaming-services|streaming services]], with total project costs reported under $100 when using refurbished or second-hand hardware.

## Configuration

The machine runs Ubuntu [[entities/linux|Linux]], which provides a lightweight and stable environment for media server applications. The compact form factor of the Optiplex 5050 makes it suitable for placement in living spaces or entertainment centers without consuming significant space.
