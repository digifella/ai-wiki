# Google My Maps

[[entities/google-my-maps|Google My Maps]] is a web-based mapping application that allows users to create custom maps by layering annotations, markers, and shapes onto [[entities/google-maps|Google Maps]] base layers. The tool requires only a Google account and a standard web browser, making it accessible to users without specialized geographic [[concepts/knowledge-management|information systems]] (GIS) knowledge. Users can add various map elements including point markers with custom icons, polylines, polygons, and text annotations to organize and visualize geographic information.

## Features and Functionality

The application supports multiple layers within a single map, enabling users to organize data by category or theme. This layering system allows for complex [[concepts/information-visualization|data visualization]] where different sets of information can be toggled on or off independently. Users can import data from spreadsheets or CSV files to automatically plot locations, facilitating the integration of external datasets into the visual map interface.

## Collaboration and Sharing

Google My Maps facilitates collaborative work by allowing multiple users to edit a single map simultaneously. Maps can be shared with specific individuals or made public, depending on the user's [[concepts/privacy|privacy]] settings. This functionality supports both personal planning, such as travel itineraries, and [[concepts/professional-use|professional use]] cases like project planning or data analysis, by providing a shared spatial context for team members.
