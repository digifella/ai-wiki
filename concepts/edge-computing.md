# Edge Computing

## Summary
[[concepts/edge-deployment|Edge computing]] processes data near the source to reduce latency and [[concepts/network-speed|bandwidth]], exemplified by CPU-optimized [[concepts/ai-models|AI models]] like [[entities/kitten-tts|Kitten TTS]], [[concepts/google-search|Google]] [[concepts/gemma-4|Gemma 4]], and specialized compact models for [[concepts/function-calling|function calling]].
