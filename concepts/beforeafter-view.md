# Before/After View

The **Before/After View** is a UI mechanism in [[entities/adobe-photoshop]] that allows users to [[concepts/feynmans-three-step-scientific-method|compare]] the current state of an image with a previous state or a reference image. This feature is critical for [[concepts/non-destructive-workflow|non-destructive editing]] workflows, allowing precise [[concepts/adjustments|adjustments]] by visualizing changes in real-time.

## Recent Enhancements (2026)

In the September 2026 [[concepts/beta-software|Beta release]], [[entities/adobe|Adobe]] introduced significant improvements to the Before/After View, integrating it more closely with [[concepts/ai-driven-workflows|AI-driven workflows]].

- **Enhanced Comparison Tool**: The [[concepts/beta-version|beta version]] features an improved Before/After slider and split-view interface, offering higher fidelity and responsiveness during large file comparisons [[lab-notes/2026-09-09-Photoshop-Beta-Enhanced-BeforeAfter-View-and-AI-Dynamic|Photoshop Beta: Enhanced Before/After View and AI Dynamic Layers]].
- **[[concepts/ai-dynamic-layers|AI Dynamic Layers]] Integration**: The Before/After View now works in tandem with **AI Dynamic Layers**, allowing users to toggle between the original AI-generated layer state and the final composited result instantly. This facilitates better control over [[concepts/generative-fill|generative fill]] and neural filter outputs.
- **[[concepts/efficiency-principles|Workflow Efficiency]]**: These [[concepts/software-updates|updates]] aim to reduce context-switching and improve the accuracy of visual judgments during complex edits.
