# Pictory

Pictory is a [[concepts/video-creation|video creation]] tool designed to produce animated videos as part of a broader creative workflow. It functions alongside complementary [[concepts/software|applications]] like [[concepts/ai-integrated-notebooks|NotebookLM]] and [[entities/google-nano-banana-pro|Nano Banana Pro]], where each tool handles a distinct phase of video production. The tool is particularly suited for converting written content or scripts into visual animated formats.

## Workflow Integration

Within the creative pipeline documented by Charles Terence [[entities/harper|Harper]], Pictory operates as an output stage following content [[concepts/preparation|preparation]] and scripting work done in other applications. Users typically begin with NotebookLM to organize and develop source material, then use Pictory to transform that content into animated video presentations, often in [[concepts/whiteboard|whiteboard]] animation style.
