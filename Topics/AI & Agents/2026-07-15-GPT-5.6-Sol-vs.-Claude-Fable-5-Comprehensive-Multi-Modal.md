The video highlights how each model approached tasks involving physical design, creative [[concepts/writing|writing]], game development for vintage and modern hardware, and interactive [[concepts/problem-solving|problem-solving]].

One set of tests involved physical design, where models were tasked with replicating a missing computer front panel for an Acer Predator G7700. This included generating a 3D-printable model based on reference photos and measurements, with a specific requirement for the design to be separable into attachable pieces due to printer volume limitations. GPT-5.6 Sol was quicker and produced a more faithful recreation of the original design, though both required some manual intervention in CAD software to be truly printable. Claude's initial attempt was notably inferior, lacking the correct tapering and intricate details, though a second attempt showed some improvement, it still required significant human adjustment. Both models also generated magazines, with Claude's "Ghost Signal" being visually consistent and readable, while GPT's "Counterweight" was more abstract and challenging to comprehend.

The video also delved into game development, testing the AIs' ability to create functional games. For a retro PC test, models were asked to develop an open-[[entities/earth|world]] crime game for a vintage iBook (Mac OSX 10.4 Tiger), requiring them to handle network transfer, compilation, and execution. GPT-5.6 Sol excelled, seamlessly delivering a playable 3D game named "LowRider City" with period-correct [[concepts/webgpu|graphics]], functioning gameplay, and map areas. Claude Fable 5, while eventually producing a graphically superior game, required extensive troubleshooting, manual Xcode installations, and ultimately crashed or presented a black screen. In a similar vein, for an [[entities/apple|Apple]] [[concepts/computer-vision|Vision]] Pro mixed reality skateboard simulator, GPT-5.6 Sol successfully fixed initial menu navigation issues to deliver a playable game with procedural levels and good [[concepts/style|visual style]]. Claude also managed to resolve its crashing issue after [[concepts/feedback|feedback]], but the game world turned almost entirely black, [[concepts/fat-rendering|rendering]] it unusable.

Finally, the models were tasked with creating a 3D PC repairman game with a detailed storyline, interactive scenes, cutscenes, and [[concepts/text-to-speech-model|text-to-speech]] (TTS) [[concepts/communication|dialogue]]. GPT-5.6 Sol delivered a highly interactive game where players performed tasks like replacing a CMOS battery, complete with [[concepts/tone|voice]] [[concepts/acting|acting]] and cinematic elements. Claude Fable 5 also produced a functional game with a storyline, but it featured a frustrating mini-game in a server room and some invisible characters, hindering the overall [[concepts/experience|experience]]. Overall, GPT-5.6 Sol consistently demonstrated higher autonomy, efficiency, and accuracy in these complex, multi-step challenges compared to Claude Fable 5, which often required more human intervention to achieve usable or competitive results.
