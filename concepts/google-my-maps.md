# Google My Maps

Google My Maps is a web-based mapping application that allows users to create custom maps by layering annotations, markers, and shapes onto Google Maps base layers. The tool requires only a Google account and a standard web browser, making it accessible to users without specialized geographic information systems (GIS) knowledge. Users can add various map elements including point markers with custom icons, polylines, polygons, and text annotations to organize and visualize geographic information.

## Features and Functionality

The application supports multiple layers within a single map, enabling users to organize related geographic data and toggle visibility of different element groups. Maps can include custom styling for markers and shapes, allowing visual differentiation of features. Text descriptions and images can be attached to individual map elements, and users can search for locations to add to their maps. The tool provides basic measurement and drawing capabilities for creating custom geographic representations.

## Collaboration and Sharing

Maps created in Google My Maps can be shared with other users, enabling collaborative editing when sharing permissions are configured appropriately. Shared maps can be viewed-only or editable depending on the creator's settings. Maps can be embedded in websites or exported in various formats, though export options are more limited compared to dedicated GIS software.
