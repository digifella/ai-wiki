# External Data

External Data refers to information and resources that exist outside of an AI model's [[concepts/training-data|training data]] or built-in [[concepts/knowledge-base|knowledge base]]. In the context of the [[concepts/external-tools|Model Context Protocol]] (MCP), external data encompasses files, databases, APIs, and other information sources that [[concepts/agentic-ai|AI agents]] can access and integrate into their [[concepts/reasoning|reasoning]] and decision-making processes.

## Role in Agent Architecture

The Model Context Protocol enables [[concepts/ai-models|AI models]] like [[concepts/claude-ai|Claude]] to connect with external data sources in a standardized way. Rather than relying solely on pre-trained knowledge, MCP allows these models to function as [[concepts/agents|agents]] by providing real-time access to dynamic information. This [[concepts/connection|connection]] transforms static [[concepts/ai-chatbots|AI chatbots]] into systems capable of retrieving current data, performing lookups, and executing actions based on information retrieved from external systems.

## Practical Applications

External data integration is essential for [[concepts/scenarios|use cases]] where AI agents need to work with current information, proprietary databases, or [[concepts/specialized-tools|specialized tools]]. Examples include accessing company documents, querying live databases, retrieving real-time market data, or interacting with external APIs. By standardizing how AI models connect to these resources, MCP eliminates the need for custom integrations with each individual data source.
