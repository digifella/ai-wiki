# Various Outputs

Various Outputs is a [[concepts/multi-modal-researcher|multi-modal researcher]] tool built using [[concepts/langgraph-framework|LangGraph]] and [[concepts/google-search|Google]]'s [[concepts/gemini-25-models|Gemini 2.5]] [[concepts/models|models]]. The system is designed to conduct [[concepts/comprehensive-investigations|comprehensive investigations]] across different types of input data and produce diverse [[concepts/output|output]] formats. By leveraging [[entities/gemini-25|Gemini 2.5]]'s multi-modal [[concepts/capabilities|capabilities]], the tool can process and analyze various forms of information including [[concepts/text|text]], [[concepts/images|images]], and other media types.

## Architecture and Implementation

The tool is constructed using [[concepts/langgraph|LangGraph]], a framework that enables the creation of [[concepts/multi-agent-workflows|agent workflows]] through graph-based state management. This [[concepts/architecture|architecture]] allows the researcher to [[concepts/structure|structure]] complex investigation processes as interconnected [[concepts/nodes-and-edges|nodes and edges]], where each component can specialize in different aspects of the research task. The [[concepts/integration|integration]] with Gemini 2.5 models provides the underlying language and [[concepts/reasoning-capabilities|reasoning capabilities]] needed to execute these investigations.

## Capabilities

The system performs comprehensive investigations by combining [[concepts/multi-modal-input|multi-modal input]] processing with structured [[concepts/workflow|workflow]] execution. It generates various outputs based on investigation results, making it suitable for [[concepts/software|applications]] requiring diverse report formats or analysis types. The combination of LangGraph's orchestration capabilities with Gemini 2.5's model performance enables systematic exploration of topics and synthesis of findings across different modalities.
