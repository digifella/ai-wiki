# Image Size

Image Size is a feature in [[concepts/adobe-photoshop|Adobe Photoshop]] that allows users to adjust the dimensions of [[concepts/digital-images|digital images]]. Historically, enlarging images resulted in noticeable quality degradation, as software relied on interpolation [[concepts/algorithms|algorithms]] to estimate pixel values for the expanded image. Modern versions of Photoshop have integrated artificial intelligence-driven upscaling tools that enable users to increase image dimensions while maintaining greater visual fidelity than traditional methods.

## AI-Powered Upscaling Tools

The Image Size dialog box now includes advanced upscaling options that utilize [[concepts/machine-learning|machine learning]] to reconstruct image details. [[concepts/ai-powered-upscaling|Generative Upscale]] uses [[concepts/generative-ai|generative AI]] to add plausible new details to cropped or enlarged areas, effectively expanding the [[concepts/canvas|canvas]] beyond the original boundaries while maintaining [[concepts/coherence|coherence]]. This tool is particularly useful for extending backgrounds or increasing [[concepts/solution|resolution]] in ways that standard interpolation cannot achieve.

For standard enlargement without adding new content, Preserve Details 2.0 offers a refined [[concepts/algorithm|algorithm]] that reduces noise and artifacts during the [[concepts/computational-scaling|scaling]] process. This method provides a balance between [[concepts/sharpness|sharpness]] and smoothness, allowing for significant increases in pixel dimensions while minimizing the blurring or jagged edges commonly associated with older resizing techniques. These tools collectively allow for higher quality output when preparing images for large-format printing or high-resolution displays.
