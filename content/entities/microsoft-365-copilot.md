# Microsoft 365 Copilot

AI-powered productivity assistant integrated across [[entities/microsoft-365|Microsoft 365]] [[concepts/software|applications]] (Word, Excel, $\text{Teams}$, Outlook), enabling natural language generation, data analysis, and [[entities/claude-co-work|task automation]] while leveraging organizational data securely.

## Key Features
- **[[concepts/custom-ai-agent|Custom AI Agent]] Creation**: Build internal [[concepts/agentic-ai|AI agents]] (e.g., customer service bots) without [[concepts/coding|coding]]
- **Data [[concepts/security|Security]]**: Operates within organizational data boundaries
- **Cross-App [[concepts/integration|Integration]]**: Works within Word, Excel, Teams, and Outlook
- **Natural Language Interface**: Generates content and analyzes data via conversational prompts
