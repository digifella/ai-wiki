# Ctrl + T

Ctrl + T is a keyboard shortcut in [[entities/excel|Microsoft Excel]] that opens the "Create Table" dialog, allowing users to quickly format a range of data as an official [[concepts/excel-table|Excel table]]. This feature is fundamental to creating dynamic spreadsheets, as tables provide [[concepts/json-structuring|structured data]] organization with built-in functionality for sorting, filtering, and referencing.

## Use in Dynamic Timelines

In the context of project timeline creation, using Ctrl + T to establish a properly formatted table enables the use of dynamic formulas and features that automatically adjust as data changes. When a dataset is converted to a table, [[entities/microsoft-excel|Excel]] assigns it a name and creates [[concepts/structured-references|structured references]], making it easier to build formulas that expand or contract with the underlying data without manual adjustment.

## Benefits for Project Management

Tables created with Ctrl + T support features like total rows, conditional formatting, and automatic formula extension that are particularly useful for project timelines. These capabilities allow users to build timelines that update automatically when tasks are added or removed, maintaining the [[concepts/integrity|integrity]] of schedules, dependencies, and visual elements without requiring constant manual reconfiguration.
