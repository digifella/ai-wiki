# Windows 10

[[concepts/microsoft-windows|Windows]] 10 is a [[concepts/personal-computer|personal computer]] operating system developed by [[entities/microsoft|Microsoft]], released in 2015. It succeeded [[entities/windows|Windows]] 8 and introduced a modified [[concepts/user-interface|user interface]] combining elements of both Windows 7 and Windows 8, including the return of the Start Menu alongside modern tiles and [[concepts/apps|apps]]. The system supports both traditional desktop and tablet modes, making it compatible with a range of hardware devices.

## Technical Context

Windows 10 runs on x86-64 architecture and is commonly used as a host operating system for virtualization, [[concepts/containerization|containerization]], and [[concepts/developer-platforms|development environments]]. In documentation contexts involving [[concepts/media-server|Ubuntu media server]] setups, Windows 10 may serve as the host machine from which [[entities/ubuntu|Ubuntu]] systems are configured, deployed, or accessed remotely, particularly in hybrid [[concepts/development-workflows|development workflows]].

The operating system has received continuous [[concepts/software-updates|updates]] through Windows Update, with Microsoft delivering feature and [[concepts/security|security]] updates regularly. This makes Windows 10 a practical baseline platform for users working across multiple operating systems or coordinating between Windows-based workstations and Linux-based servers.
