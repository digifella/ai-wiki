# Kombai

Kombai is the first-ever AI [[entities/agent|agent]] [[concepts/motivation|purpose]]-built for [[concepts/frontend-development|frontend development]], directly integrating into popular IDEs like [[entities/vs-code]], [[entities/cursor|Cursor]] (IDE), and [[entities/windsuf|Windsuf]].

**Key Features and Differentiators:**
- **Specialized for Frontend:** Optimized specifically for frontend tasks, outperforming general-[[concepts/purpose|purpose]] tools (e.g., GitHub [[entities/copilot|Copilot]], [[entities/codepal|CodePal]], [[entities/gemini]]) in [[concepts/code|code]] review (72% success vs. 30-50%).
- **Seamless [[concepts/ide-integration|IDE Integration]]:** Works natively within [[entities/vs-code]], [[concepts/cursor|Cursor]] (IDE), and [[entities/windsuf|Windsuf]] for real-time assistance during development.
