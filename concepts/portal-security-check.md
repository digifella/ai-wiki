# Portal Security Check

A Portal Security Check is a security verification process conducted on the ASIC Company Portal when users access company information using an Australian Company Number (ACN). This mechanism serves to authenticate user access and validate the legitimacy of information requests before any sensitive company data is displayed to the requestor.

When a user enters an ACN into the ASIC Company Portal, the system initiates a security check to confirm the validity of the request. This process ensures that the entity associated with the provided number is legitimate and that the user has the appropriate authorization to view the requested details. By verifying these parameters, the system prevents unauthorized access and maintains the integrity of the data provided through the platform.
