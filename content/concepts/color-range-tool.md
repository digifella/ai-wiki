# Color Range Tool

The Color [[concepts/range|Range]] Tool is a feature in [[entities/adobe-lightroom|Adobe Lightroom]] designed to create precise masks based on specific colors in an image. Rather than selecting areas by shape or luminosity alone, this tool allows users to isolate and adjust particular [[concepts/color-ranges|color ranges]], making it especially useful for complex editing [[concepts/scenarios|scenarios]] where traditional [[concepts/layer-masks|masking]] methods fall short.

## Application in Sky Masking

One practical application of the Color Range Tool is refining sky masks when foreground elements obscure the sky. When trees, branches, or other objects overlap the sky area, standard [[concepts/masking|masking]] techniques may struggle to distinguish between the sky and the overlapping elements. The Color Range Tool can selectively target the blue tones of the sky while ignoring the darker tones of branches in front, allowing editors to adjust the sky independently without affecting the foreground elements.

## Workflow Advantage

By targeting color rather than spatial selection, the Color Range Tool provides more [[concepts/power|control]] in complex compositions. This approach has become increasingly relevant in recent versions of [[entities/lightroom-classic|Lightroom Classic]], which have incorporated AI-powered enhancements alongside traditional masking [[concepts/capabilities|capabilities]]. The tool allows for refined [[concepts/adjustments|adjustments]] to [[concepts/exposure|exposure]], color, and other [[concepts/parameters|parameters]] within the selected color range, giving editors precise creative control.
