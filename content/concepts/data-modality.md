# Data Modality

Data modality refers to the distinct types of input data that [[concepts/ai-technologies|artificial intelligence]] systems, particularly [[concepts/large-language-model-llm|large language models]] (LLMs), can process and interpret. In traditional single-[[concepts/modality|modality]] systems, LLMs operated exclusively on [[concepts/text|text]]. However, advances in [[concepts/multimodal-ai|multimodal AI]] have expanded the [[concepts/range|range]] of data types that modern language [[concepts/models|models]] can handle, enabling them to process and reason across multiple forms of information simultaneously.

## Common Data Modalities

The primary data modalities in contemporary multimodal systems include text, [[concepts/images|images]], [[concepts/audio-modality|audio]], and video. Text remains the foundational modality for most LLMs, while visual data such as photographs, [[concepts/diagrams|diagrams]], and charts has become increasingly central to multimodal [[concepts/software|applications]]. Audio and video represent emerging modalities that extend the capability of language models to process real-world information in its diverse natural forms.

## Processing and Integration

[[concepts/multimodal-large-language-models|Multimodal LLMs]] process different data modalities through specialized [[concepts/encoding|encoding]] mechanisms that convert each input type into numerical representations the model can understand. These representations are then integrated within the model's [[concepts/architecture|architecture]], allowing it to draw connections and generate outputs based on [[concepts/relationships|relationships]] between different modalities. This approach enables systems to perform tasks like image captioning, visual [[concepts/fact-based-queries|question answering]], and cross-modal [[concepts/reasoning|reasoning]] that would be impossible with text alone.
