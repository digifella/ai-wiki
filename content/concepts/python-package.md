# Python package

A Python package is a directory containing [[entities/python|Python]] modules (`.py` files) organized with an `__init__.py` file, enabling modular code [[concepts/distribution|distribution]] via PyPI. Packages are installed using `pip` and form the foundation of Python's ecosystem for reusable code.

## Example packages

- **[[entities/data-formulator|data_formulator]]** (Microsoft [[concepts/backend-application|Data Formulator]]): AI-powered [[concepts/visualization-generation|data visualization]] tool using [[concepts/llm-backend|LLM backend]]. Installed via `pip install data_formulator`, launched with `data_formulator` or `python -m data_formulator`. Requires AI [[concepts/model-configuration|model configuration]].
