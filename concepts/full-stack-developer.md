# Full-stack developer

A software engineer capable of developing both [[concepts/frontend-development|front-end]] and back-end components of a [[concepts/web-application|web application]]. Requires [[concepts/excellence|proficiency]] in:
- Front-end technologies (HTML, CSS, [[concepts/javascript|JavaScript]] frameworks)
- Back-end systems (server [[concepts/open-source-philosophy|logic]], databases, [[concepts/open-standard-protocols|APIs]])
- DevOps practices (deployment, [[concepts/cicd-pipelines|CI/CD]])
- Cross-functional collaboration

## AI Coding Assistants
Full-stack developers increasingly leverage [[concepts/ai-tools|AI tools]] for [[concepts/productivity|productivity]]. Key comparisons:

- **[[concepts/claude-code|Claude Code]] ([[entities/anthropic|Anthropic]])**:
  Terminal-based (CLI) interface; acts as a full-stack [[concepts/developer|developer]] assistant (end-to-end support)

- **[[entities/github-copilot-agent|GitHub Copilot Agent]] (GitHub/Microsoft)**:
  IDE-integrated ([[entities/vs-code|VS Code]]) for contextual code suggestions; focuses on completion within development workflow

For detailed comparison, see 2026 04 14 [[concepts/ai-assisted-coding|Claude code]] vs [[concepts/auto-completion-suggestions|GitHub copilot]].
