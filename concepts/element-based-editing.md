# Element Based Editing

Element Based Editing is a structured methodology for [[concepts/ai-image-generation|AI image generation]] that utilizes JSON formatting to define and control visual components with high [[concepts/accuracy|precision]]. Instead of relying solely on natural [[concepts/natural-language-prompting|language prompts]], this technique decomposes a desired image into discrete, named elements such as objects, figures, backgrounds, and lighting conditions. These components are then specified programmatically, allowing for [[concepts/granular-control|granular control]] over the final output.

This approach is particularly effective with [[concepts/ai-models|AI models]] that support [[concepts/chat-prompt|structured input]], such as [[concepts/google-search|Google]]'s [[concepts/gemini|Gemini]]. By interpreting JSON-formatted specifications, these models can accurately parse and execute complex visual [[concepts/instructions|instructions]] that might be ambiguous in standard [[concepts/text-prompts|text prompts]]. The method enables users to manipulate specific attributes of individual elements without affecting the entire [[concepts/writing|composition]], offering a more deterministic workflow for creative pursuits.

The technique facilitates a shift from descriptive prompting to declarative design. Users define the [[concepts/hierarchy|hierarchy]] and properties of visual layers, which the AI then renders according to the defined schema. This reduces the trial-and-error nature of traditional [[concepts/prompt-based-modeling|prompt engineering]] and allows for reproducible results, making it suitable for applications requiring consistent visual standards or [[concepts/iterative-learning|iterative refinement]] of specific image components.
