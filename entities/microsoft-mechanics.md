## Microsoft Foundry

[[concepts/agent-factory|Microsoft Foundry]] is a platform introduced by Microsoft to streamline the development of [[concepts/ai-powered-applications|AI applications]] and [[concepts/agentic-ai|AI agents]]. It provides developers with unified tools and infrastructure to build, [[concepts/deployment|deploy]], and manage AI-powered solutions. The platform aims to simplify the process of creating sophisticated [[concepts/ai-agents|AI agents]] that can automate [[concepts/complex-workflows|complex workflows]] and tasks across enterprise environments.
