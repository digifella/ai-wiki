# Flowise

2026 04 14 [[entities/anthropic-institute|Anthropic]] multi [[entities/agent|agent]] [[concepts/deep-research-agent|deep Research agent]]

## Overview
Flowise is an [[concepts/open-source|open-source]] tool for building customizable [[concepts/large-language-model|large language model]] (LLM) [[concepts/software|applications]]. It provides a visual interface to [[concepts/design|design]] and deploy [[concepts/complex-workflows|complex workflows]] involving multiple LLMs, APIs, and other components.

## Key Features
- **Visual [[concepts/workflow|Workflow]] Designer**: Drag-and-drop interface for creating LLM workflows.
- **Modular Components**: Pre-built modules for common tasks like [[concepts/text-generation|text generation]], [[entities/api-calls|API calls]], and data processing.
- **[[concepts/customization|Customization]]**: Supports custom [[entities/python|Python]] [[concepts/code|code]] for advanced [[concepts/scenarios|use cases]].
- **[[concepts/deployment|Deployment]]**: Easy [[concepts/deployment|deployment]] of workflows as [[concepts/web-applications|web applications]].

## Use Cases
- **Research [[concepts/automation|Automation]]**: Building [[concepts/agents|agents]] that can perform [[entities/deep-research|deep research]] tasks.
- **Chatbots**: Creating [[concepts/conversational-ai|conversational agents]] with complex logic.
- **Data Processing**: Automating [[concepts/data-extraction|data extraction]] and transformation tasks.
