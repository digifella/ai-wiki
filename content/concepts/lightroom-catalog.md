# Lightroom catalog

Backlinks: 2026 04 14 [[concepts/catalog|Lightroom catalog]] system

A database used by [[concepts/lightroom]] to manage [[concepts/metadata|metadata]], edits, and [[concepts/organization|organization]] without altering the original Image [[concepts/files|files]].

### Key Principles
- **Database vs. Files**: A common misconception is that the catalog contains actual photos; it does not.
- **The "Cookbook" Analogy**: The catalog functions like a cookbook (containing [[concepts/instructions|instructions]]/recipes), whereas the photos are the ingredients.
- **[[concepts/workflow|Workflow]] Management**: Essential for maintaining a non-destructive [[concepts/photo-editing|Photo editing]] workflow.
