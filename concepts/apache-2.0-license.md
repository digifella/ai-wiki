# Apache 2.0 License

The Apache License 2.0 is a permissive open-source software license maintained by the Apache Software Foundation. Released in 2004, it grants users the freedom to use, modify, and distribute software under clear legal terms. The license has become one of the most widely adopted in the open-source ecosystem, used by major projects including the Apache web server, Kubernetes, Apache Spark, and numerous cloud infrastructure tools.

## Key Features

The Apache 2.0 License is permissive, meaning it places minimal restrictions on how software can be used or redistributed. It explicitly grants rights to use the software for any purpose, modify the source code, and distribute copies or modifications. Unlike copyleft licenses such as the GPL, Apache 2.0 does not require derivative works to be released under the same license, allowing proprietary modifications and commercial use.

## Patent Protection and Attribution

A distinctive feature of Apache 2.0 is its explicit patent grant clause, which protects users from patent claims related to the licensed software. Contributors implicitly grant patent rights to recipients, reducing legal risk in patent-heavy domains. The license also requires that modified versions include prominent notices of changes and retain copyright, patent, trademark, and attribution notices from the original work.

## Compatibility

Apache 2.0 is generally compatible with many other open-source licenses, though some combinations require careful attention. It is compatible with permissive licenses like MIT and BSD, but has known compatibility issues with certain versions of the GPL due to differing patent claim provisions. This compatibility profile makes Apache 2.0 suitable for projects that may integrate code from multiple sources.
