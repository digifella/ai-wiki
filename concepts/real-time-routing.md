# Real Time Routing

Real Time Routing is a system capability within Microsoft 365 Copilot and Copilot Studio that dynamically directs user requests to appropriate processing pathways during active query execution. This mechanism replaces static configuration rules with an adaptive approach that analyzes incoming requests and their immediate context. By evaluating these factors in real time, the system determines the most suitable backend services or response mechanisms for each specific interaction.

The integration of GPT-5 into these platforms enhances the intelligence and performance of this routing logic. The updated model allows for more nuanced understanding of user intent and system load, enabling more efficient allocation of computational resources. This results in faster response times and improved accuracy in handling complex or ambiguous queries across the Microsoft 365 ecosystem.
