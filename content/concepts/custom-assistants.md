# Custom Assistants

Specialized [[concepts/llm]] configurations designed to execute specific tasks with minimal user intervention.

### The Prompting Inefficiency Problem
- Standard usage of [[entities/chatgpt]], [[entities/claude]], and [[entities/gemini]] often requires an inefficient "back-and-forth" chat loop to refine outputs.
- This [[concepts/iterative-refinement|iterative process]] results in time loss and dissatisfaction, creating significant [[concepts/friction|friction]] for Solopreneurs and Small Teams.

### Optimization via Pre-configured Agents
- Google Gems solve this by [[concepts/encoding|encoding]] specific [[concepts/instructions|instructions]] into the agent, enabling [[concepts/workflow-automation]] by bypassing the need for repetitive [[concepts/prompting|prompting]].
