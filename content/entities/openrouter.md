# OpenRouter

OpenRouter is an API aggregator that provides unified access to multiple [[concepts/large-language-model-llm|large language models]] through a single interface. Rather than requiring developers to maintain separate integrations with individual model providers, OpenRouter consolidates various LLMs into one platform, simplifying the process of model selection and [[concepts/deployment|deployment]].

## Functionality

The service allows users to query different language [[concepts/models|models]]—including both proprietary and [[concepts/open-source|open-source]] options—through standardized API endpoints. This aggregation approach enables flexibility in model choice, [[concepts/cost|cost]] comparison, and experimentation across different architectures without changing underlying application [[concepts/code|code]].

## Supported Models

OpenRouter supports a [[concepts/range|range]] of models spanning different providers and [[concepts/capabilities|capabilities]]. Notable models accessible through the platform include [[entities/qwen|Qwen]] variants, the [[concepts/autonomous-workflow-automation|Hermes Agent]] series, and [[entities/nvidia|NVIDIA]]'s [[entities/ai-assistant|Nemotron]] models, among others. The platform's model roster has expanded to include multimodal and [[concepts/ai-agentic-applications|agentic AI systems]].
