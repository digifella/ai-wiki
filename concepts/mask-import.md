# Mask Import

Mask Import is a feature in Adobe Lightroom Classic that utilizes artificial intelligence to automatically generate selections of specific elements within a photograph. Instead of requiring users to manually paint or draw masks using traditional selection tools, the feature applies pre-trained models to identify and isolate common photographic subjects such as landscapes and people. This automation significantly reduces the time spent on manual selection work, allowing photographers to proceed directly to editing adjustments.

The tool provides single-click presets that analyze the image content to create precise masks for sky, background, and subject isolation. These presets are designed to handle complex edges and varying lighting conditions, which traditionally required extensive manual refinement. By leveraging machine learning, the system can distinguish between foreground and background elements with greater accuracy than standard color-range selections.

Users can apply these AI-generated masks to adjust exposure, color, and clarity independently for different parts of the image. The feature supports non-destructive editing, meaning the original mask data can be modified or replaced at any time. This capability streamlines the workflow for landscape and portrait photographers who frequently need to make localized adjustments to skies, backgrounds, or subjects.
