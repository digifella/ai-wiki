# Color Variance Control

A feature in [[entities/adobe|Adobe]] [[concepts/camera-raw|Camera Raw]]'s [[concepts/point-color]] tool that enables precise adjustment of [[concepts/color-ranges|color ranges]] by controlling the tolerance (variance) of a selected color. The [[concepts/color-contrast|variance slider]] defines how broadly the adjustment applies to similar hues, allowing targeted corrections without affecting unrelated areas.

## Key Usage (Julianne Kost Demonstration)

- Uses the [[concepts/eyedropper-tool|eyedropper tool]] to select a specific color (e.g., green from trees) in a landscape image with reflections
- Adjusts Hue, Saturation, and Luminance for the selected [[concepts/color-range-control|color range]]
- Controls the spread of the adjustment via the variance slider (new in [[entities/camera-raw-filter|Camera Raw]])
