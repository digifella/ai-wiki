# Data Formulator

Data Formulator is an AI-powered application developed by Microsoft that generates data visualizations through natural language interfaces. The system utilizes a large language model as its computational backend, enabling users to create visual representations by describing their data and intended outputs in conversational language. This approach eliminates the need for writing traditional visualization code, thereby lowering the technical barrier for data exploration and analysis.

The platform operates by interpreting user prompts to infer data structures and appropriate chart types, automatically translating these intents into executable visualization code. By bridging the gap between high-level analytical goals and low-level implementation details, it allows users to iterate rapidly on their data stories without requiring expertise in programming languages such as Python or R.

As part of Microsoft's broader efforts in AI-assisted development, Data Formulator serves as a tool for democratizing data analysis. It focuses on the interaction model between the user and the visualization engine, demonstrating how large language models can be applied to structured data tasks beyond simple text generation.
