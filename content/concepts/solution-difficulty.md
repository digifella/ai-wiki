# Solution Difficulty - Concept Summary

[[concepts/solution|Solution]] difficulty is a measure of how challenging it is to find the solution to a problem given that verifying the solution is relatively straightforward. This concept is central in [[concepts/theoretical-computer-science|theoretical computer science]] and [[concepts/complexity-classes|computational complexity]] [[concepts/theory|theory]].

### Key Points
- A problem is classified as **P** (Polynomial time) if there exists an algorithm that can solve it efficiently.
- Problems are considered **NP** (Nondeterministic Polynomial time) when solutions can be verified efficiently but finding a solution might not be efficient.
- The question whether P = NP remains one of the most significant [[concepts/unsolved-problems|unsolved problems]] in computer science, with implications across [[concepts/cryptography|cryptography]], optimization, and algorithm [[concepts/design|design]].
