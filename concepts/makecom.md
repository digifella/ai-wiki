# Make.com

**Make.com** (formerly Integromat) is a visual automation platform that enables users to connect [[concepts/apps|apps]], automate workflows, and manage data without extensive [[concepts/coding|coding]]. It serves as a central orchestration layer for integrating disparate services, particularly in [[concepts/no-code]] and [[concepts/ai-driven-task-automation|AI Workflow Automation]] contexts.

## Capabilities & Integrations

- **Visual Orchestration**: Drag-and-drop interface for creating complex multi-step [[concepts/scenarios|scenarios]] involving HTTP requests, data transformations (JSON/XML), and conditional [[concepts/open-source-philosophy|logic]].
- **API Connectivity**: Supports native modules for hundreds of apps and generic HTTP/REST connectors for custom integrations.
- **[[concepts/ai-app|AI App]] Backend**: Acts as the middleware layer connecting [[concepts/frontend-development|front-end]] AI interfaces with backend services like databases and [[concepts/authentication|authentication]] providers.

## Recent Developments: Zero-Code Full-Stack AI Apps

As of mid-2026, Make.com has become a critical component in rapid zero-code [[concepts/ai-application-development|AI application development]] when paired with [[concepts/google-search|Google]]'s ecosystem:

*   **Integration with [[entities/google-ai-studio]] and Firebase**: Workflows can now bridge the gap between [[concepts/generative-ai-models|generative AI models]] and persistent data layers.
*   **Full-Stack Architecture**: Enables creation of complete applications where Make.com handles the logic, Firebase provides real-time [[concepts/database-storage|database storage]] and authentication, and [[concepts/user-accounts|Google AI Studio]] serves the [[concepts/inference|model inference]].
*   **Rapid Deployment**: Allows for login systems and database interactions to be implemented in seconds via standardized modules, reducing development time significantly compared to traditional coding methods.
