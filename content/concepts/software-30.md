# Software 3.0

[[concepts/llm-based-computing|Software 3.0]] is a conceptual framework proposed by [[entities/andrej-karpathy|Andrej Karpathy]] that reimagines [[concepts/large-language-model-llm|Large Language Models]] (LLMs) as a fundamentally new computing paradigm. Rather than viewing LLMs as chatbots or language tools, Karpathy positions them as general-[[concepts/motivation|purpose]] computational machines capable of executing [[concepts/complex-tasks|complex tasks]] through natural language interfaces. This perspective suggests that LLMs represent a shift as significant as previous transitions in software [[concepts/architecture|architecture]].

## LLMs as Operating Systems

Central to Software 3.0 is the idea that LLMs function analogously to operating systems. Just as traditional OSs manage [[concepts/hardware|hardware]] resources and provide abstractions for [[concepts/software|applications]], LLMs manage information processing and can orchestrate multiple specialized subsystems. They can receive inputs in natural language, perform [[concepts/reasoning|reasoning]], call [[concepts/external-tools|external tools]], and generate outputs—functioning as a [[concepts/unified-interface|unified interface]] for diverse computational tasks. This contrasts with Software 2.0 (conventional [[concepts/neural-networks|neural networks]] optimized end-to-end), where the entire system is monolithic.

## Implications for Development

The Software 3.0 framework suggests that future [[concepts/coding|software development]] [[entities/will|will]] increasingly involve instructing and guiding LLMs rather than traditional explicit programming. Developers would interact with these systems through natural language specifications, enabling faster [[concepts/iteration|iteration]] and more accessible [[concepts/app-creation|software creation]]. The approach acknowledges both the [[concepts/capabilities|capabilities]] and limitations of current LLMs while proposing they represent a meaningful departure from both classical [[concepts/software-engineering|software engineering]] and earlier [[concepts/machine-learning|machine learning]] paradigms.
