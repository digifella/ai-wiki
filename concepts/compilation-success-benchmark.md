# Compilation success benchmark

A metric evaluating the [[concepts/success|success]] rate of development tasks, often measured through controlled benchmarks. While "compilation" traditionally refers to code translation, modern usage extends this to broader success metrics like code review and [[concepts/feature-implementation|feature implementation]].

**Key examples:**
- [[entities/kombai|Kombai]] for Design of Front-ends: Benchmarks show [[entities/kombai|Kombai]] (specialized frontend [[concepts/ai-agent|AI agent]]) outperforms general tools ([[entities/github|GitHub]] [[entities/copilot|Copilot]], [[entities/codepal|CodePal]], [[concepts/gemini|Gemini]]) in code review (72% success vs. 30-50%) and feature implementation.
