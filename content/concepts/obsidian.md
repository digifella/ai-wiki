# Obsidian
[[entities/obsidian|Obsidian]] is a powerful [[concepts/open-source|open-source]] note-taking application that allows users to create highly interconnected personal [[concepts/knowledge-bases|knowledge bases]] and workflows. It features advanced link syntax, [[concepts/plugins|plugins]] for [[concepts/ai-workflow|customization]], and support for various data formats including [[concepts/markdown|Markdown]].

## Key Features
- **Link Syntax**: Enables deep linking between [[concepts/notes|notes]] and [[concepts/files|files]].
- **Plugins & Community Ecosystem**: A wide [[concepts/range|range]] of extensions can be installed to enhance functionality.
- **Data Import/Export**: Supports multiple file types for easy migration or [[concepts/integration|integration]] with other tools.
- **Graph Visualization**: Provides visual insights into the [[concepts/structure|structure]] of your note-taking system.
