## Chroma

Chroma is an advanced AI [[concepts/solution|solution]] provider specializing in retrieval-augmented generation (RAG) technologies. Key features include:

- **[[concepts/agentic-ai|Self-Editing Search Agent]]**: A groundbreaking model introduced as part of the Context series, aimed at enhancing search efficiency and effectiveness for RAG [[concepts/software|applications]].
  - [[concepts/self-editing-search-agents|Chroma Context-1]] is a [[concepts/efficient-rag|self-editing search agent]] specifically trained for [[concepts/answer-generation|Retrieval Augmented Generation]] (RAG).
  - Derived from [[concepts/gpt-oss-20b|gpt-oss-20B]] with 20B [[concepts/parameters|parameters]].

- **Next Evolution of Retrieval-Augmented Generation**: As seen in [Chroma Context-1](https://www.youtube.com/watch?v=7f1bHER4kRM), Chroma's latest offering is a 20B parameter model that outperforms larger models in retrieval tasks.
  - Boasts [[concepts/retrieval-performance|retrieval performance]] comparable to much larger, frontier-scale [[concepts/large-language-models|Large Language Models (LLMs)]].

- **Key Differentiators**: Achieves superior performance with smaller resource footprints, making it an efficient alternative for RAG applications.
