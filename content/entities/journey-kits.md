# Journey Kits

Journey Kits is a project [[concepts/deployment|deployment]] that became the subject of a detailed case study on [[concepts/ai-assisted-coding|AI coding]] [[concepts/cost|cost]] management and cloud infrastructure expenses. The project is primarily known through [[entities/matthew-berman|Matthew Berman]]'s video analysis titled "The dark side of [[concepts/3d-game-development|vibe coding]]," which examines unexpected billing issues that arose during its deployment on [[entities/vercel|Vercel]].

## Cost Overruns and Billing Lessons

The [[entities/ai-coding-assistant|Journey Kits deployment]] encountered significant cost overruns related to [[concepts/ai-coding-assistance|AI-assisted coding]] practices, which Berman documented as a cautionary example of how seemingly efficient development approaches can result in unexpectedly high cloud service bills. The case illustrates practical challenges in managing expenses when using [[concepts/ai-coding-workflows|AI coding tools]] in conjunction with serverless infrastructure, particularly regarding how resource consumption can escalate beyond initial projections.

The project serves as a documented reference point for developers considering similar technology stacks, highlighting the importance of monitoring and cost controls when combining [[concepts/ai-coding|AI coding]] assistance with platforms like Vercel.
