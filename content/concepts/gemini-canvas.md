# Gemini Canvas

A collaborative [[concepts/script-building|script-building]] feature within Pro) that transforms structured content (e.g., [[entities/notebooklm]] notes) into cinematic video scripts for Google Veo-powered [[concepts/video-generation|video generation]].

## Core Workflow
- **Input:** Business [[concepts/philosophy|philosophy]] or narrative content stored in [[entities/notebooklm]]
- **[[concepts/script-building|Script Building]]:** Use [[entities/gemini|Gemini]] [[entities/canvas|Canvas]] to generate a [[concepts/cinematic-ad|30-second commercial]] script
- **[[concepts/video-generation|Video Generation]]:** Render final output via [[concepts/google-vids]] (using [[entities/google-veo|Google Veo]])

## Key Integration Points
- [[entities/notebooklm]] content → [[concepts/gemini|Gemini]] Canvas script → [[concepts/veo|Google Veo]] video
- Requires Pro) subscription
- Uses [[concepts/google-search|Google]] [[concepts/motivation|Drive]] for [[concepts/asset-management|asset management]]

## Example Use Case
Creating a cinematic 30-second commercial from [[concepts/business-philosophy|business philosophy]] notes stored in [[entities/notebooklm]].
