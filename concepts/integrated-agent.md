# Integrated Agent

An Integrated Agent is an artificial intelligence system architecture that unifies distinct cognitive and operational capabilities into a single, cohesive framework. Unlike modular systems where components such as reasoning, tool use, and decision-making operate in isolation, integrated agents coordinate these functions within a unified structure. This design allows the system to manage complex, multi-step tasks by maintaining context and state across different operational phases, reducing the latency and error propagation often associated with chaining separate models or services.

The concept gained significant attention through Anthropic's "Christmas Claude" updates, which emphasized a strategic shift toward agentic capabilities. These updates focused on enhancing the model's ability to plan and execute actions autonomously, moving beyond simple text generation to become a functional agent capable of interacting with external environments. The integration aims to create a more robust and efficient workflow for users requiring complex problem-solving and automation.

By consolidating these functions, integrated agents offer a more streamlined approach to handling intricate workflows. This architecture supports deeper contextual understanding and more reliable execution of long-horizon tasks, distinguishing it from earlier approaches that relied on external orchestration layers to connect disparate AI components.
