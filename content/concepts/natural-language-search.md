# Natural Language Search

Natural Language Search refers to [[concepts/ai-powered-search|AI-powered search]] functionality that allows users to query digital assets using everyday language rather than structured [[concepts/keywords|keywords]] or [[concepts/metadata|metadata]] tags. This approach leverages machine [[concepts/learning|learning]] to interpret user intent and match it against image content, properties, and [[concepts/contextual-information|contextual information]].

## Implementation in Adobe Lightroom

[[entities/adobe-lightroom|Adobe Lightroom]] introduced Natural Language Search [[concepts/capabilities|capabilities]] as part of its April 2024 update. The feature enables photographers and creatives to locate [[concepts/images|images]] by describing what they're looking for in conversational terms—for example, searching for "sunset over mountains" or "close-up of blue eyes"—rather than relying on manual tagging systems. This [[concepts/integration|integration]] represents part of a broader [[concepts/adoption|adoption]] of [[entities/ai-tools|AI tools]] within Adobe's creative suite to streamline [[concepts/asset-management|asset management]] workflows.

## Technical Foundation

The search functionality is supported by [[concepts/ai-models|AI models]], including integration with [[entities/gemini-models|Gemini AI]] as of April 2024. These [[concepts/models|models]] process natural language queries and match them against [[concepts/image-analysis|image analysis]] data, allowing the system to understand both visual content and contextual metadata simultaneously.
