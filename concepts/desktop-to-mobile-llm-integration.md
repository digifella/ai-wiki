# Desktop To Mobile LLM Integration

Desktop To Mobile LLM Integration refers to the capability introduced in AnythingLLM 1.12 that extends privately self-hosted large language models to mobile devices. This feature allows users to access their LLMs through mobile channels while maintaining the privacy and control advantages of self-hosted infrastructure. Rather than relying on cloud-based services, users can interact with their locally deployed models from smartphones and tablets.

## Implementation and Access

The integration works by connecting desktop deployments with mobile accessibility, enabling consistent interaction across different device types. Users maintain a single self-hosted LLM instance while accessing it through multiple interfaces and platforms. This approach allows organizations and individuals to leverage their existing infrastructure investments across a broader range of devices without creating separate deployments or compromising on data governance.

## Privacy and Control Benefits

By keeping LLM interactions within a self-hosted environment, Desktop To Mobile LLM Integration preserves data privacy throughout the interaction chain. Conversations and model outputs remain within controlled infrastructure rather than being transmitted to external services. This architectural choice is particularly relevant for users handling sensitive information or operating in regulated environments where data residency requirements apply.
