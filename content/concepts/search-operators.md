# Search Operators

Specialized characters and [[concepts/commands|commands]] used within Search Engines to refine queries, improve precision, and filter results.

## Core Syntax
- `""` (Quotes): Forces an exact phrase match.
- `-` (Minus): Excludes specific terms from the search.
- `OR`: Searches for results containing any of the specified terms.
- `site:`: Restricts results to a specific Domain.
- `filetype:`: Limits results to particular file formats (e.g., PDF, [[concepts/docx|DOCX]]).
