# Google Slides

[[entities/google-slides|Google Slides]] is a web-based [[concepts/presentation-tool|presentation tool]] available as part of [[concepts/google-workspace|Google Workspace]]. It enables users to create, edit, and share [[concepts/slide-decks|slide decks]] collaboratively in real-time, with multiple users able to work on the same presentation simultaneously. Like other Google Workspace [[concepts/software|applications]], Slides stores presentations in [[concepts/google-drive|Google Drive]] and provides version history tracking.

## Creating Presentations

Google Slides presentations can be created manually through the interface, or generated using AI assistance. Users can leverage [[entities/gemini-app|Gemini Pro]] to create slide deck drafts by using the [[concepts/canvas-feature|Canvas feature]] and requesting a presentation on a specific topic, which can then be exported to Slides format for further refinement and [[concepts/customization|customization]].

## Collaboration and Sharing

The platform's collaborative features allow teams to work together on presentations with real-time updates visible to all participants. Users can share presentations with specific people or [[entities/make|make]] them publicly accessible, with granular permission controls for viewing, commenting, and editing [[concepts/capabilities|capabilities]].
