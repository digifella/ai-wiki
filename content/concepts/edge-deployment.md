# edge deployment

The practice of [[concepts/running|running]] computational workloads and [[concepts/inference|Inference]] [[concepts/assistive-technology|at]] the network periphery, closer to the data source or end-user, to minimize latency, reduce bandwidth consumption, and enhance [[concepts/privacy|privacy]].

### Core Objectives
- **Latency Reduction:** Minimizing the physical distance data travels.
- **Bandwidth [[concepts/ai-workflow|Optimization]]:** Processing data locally to avoid saturating backbone networks.
- **Decentralization:** Reducing reliance on centralized [[concepts/cloud-computing|Cloud Computing]] infrastructures.
