# Text Embeddings

Text embeddings are numerical [[concepts/vector-representations|vector representations]] of text that capture semantic meaning in a format suitable for [[concepts/artificial-intelligence-models|machine learning models]]. By converting words, phrases, or documents into high-dimensional vectors, embeddings enable computational systems to perform similarity comparisons, clustering, and retrieval tasks. They form a foundational component of modern [[concepts/ai-powered-applications|AI applications]], particularly in retrieval-augmented generation (RAG) systems where they facilitate matching between queries and relevant documents.

## Jina Embeddings v4

Jina Embeddings v4 is a [[concepts/image-embeddings|universal embedding model]] designed to handle multiple modalities and languages within a single framework. This multimodal capability allows it to process and embed both text and other content types, making it particularly suited for comprehensive RAG approaches that need to work across diverse data sources and languages. The model addresses the practical need for systems that can seamlessly integrate multilingual and multimodal [[concepts/knowledge-bases|information retrieval]] without requiring separate embedding models for different content types.
