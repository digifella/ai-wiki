# Brush Size Control

Brush size control in Adobe Photoshop refers to the ability to adjust brush dimensions during active painting and editing work. Rather than accessing brush settings through menus or panels, Photoshop provides keyboard shortcuts that allow artists to modify brush properties in real time without interrupting their workflow. This method of control is particularly useful when working on detailed digital art, photo editing, or illustration projects where frequent size adjustments are necessary.

## Keyboard Shortcuts

The primary method for controlling brush size in Photoshop uses the square bracket keys on the keyboard. The left bracket key ([) decreases brush size, while the right bracket key (]) increases it. These shortcuts work with most painting and editing tools, including the Brush, Pencil, Eraser, and Clone Stamp tools. The adjustment increments vary depending on the current brush size, allowing for both fine-tuning and rapid changes.

## Hardness Adjustment

Brush hardness, which controls the softness or crispness of brush edges, can be adjusted using bracket keys in combination with the Shift modifier. Pressing Shift+[ decreases hardness (making edges softer), while Shift+] increases hardness (making edges crisper). This allows artists to fine-tune both size and edge quality without switching tools or opening the brush panel.
