# Embedding Capabilities

Dense [[concepts/vector-representations|vector representations]] mapping [[concepts/unstructured-data|unstructured data]] to continuous vector spaces for similarity computation, clustering, and [[concepts/document-retrieval|retrieval]].

## Core Properties
- Preserves semantic structure; proximity correlates with meaning.
- Enables cross-modal alignment (text, image, [[concepts/audio-modality|audio]]) in unified latent spaces.
- Critical component for [[concepts/vector-databases]], [[concepts/rag]] pipelines, and [[concepts/anomaly|anomaly]] detection.
