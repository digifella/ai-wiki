# /learn Command

The `/learn` command is a feature of the [[entities/hermes-agent]], an [[concepts/open-source|open-source]] [[concepts/self-evolution|self-improving AI]] operator developed by [[entities/nous-research]]. It enables [[concepts/autonomous-skill-creation|autonomous skill creation]], allowing the agent to teach itself new capabilities dynamically.

## Key Features
- **Autonomous [[concepts/skill|Skill]] Creation**: The agent can generate and integrate new [[concepts/skills|skills]] without manual intervention.
- **[[concepts/self-improvement|Self-Improvement]]**: Part of the broader [[concepts/agentic-ai|Hermes Agent]] architecture designed for continuous [[concepts/learning|learning]] and adaptation.
- **Integration**: Works within the [[entities/hermes|Hermes]] [[concepts/ai-agent-ecosystem|Agent ecosystem]] to expand operational capabilities.
