## Full Control AI Image Editing with JSON Prompting (Gemini Nano Banana 2)
**Clip title:** Full Control AI [[concepts/image-editing|Image Editing]] with JSON [[concepts/prompting|Prompting]] ([[entities/gemini|Gemini]] [[entities/nano-banana-2|Nano Banana 2]])
**Author / channel:** Hongzhao
**URL:** https://www.youtube.com/watch?v=gbnmDRcKM0Q

### Summary
This video demonstrates [[entities/google-gemini|Google Gemini]]'s advanced [[concepts/ai-image-editing|AI image editing]]
capabilities, leveraging its "[[concepts/nano-banana-2|Nano Banana 2]]" and "[[entities/nano-banana-pro|Nano Banana Pro]]" models
to offer precise and consistent control over image modifications. The core
technique highlighted is the use of [[concepts/json|JSON (JavaScript Object Notation)]] to
extract and manipulate image data, moving beyond traditional manual editing
or simple [[concepts/text|text]] prompts. The presenter showcases how users can achieve
detailed and consistent changes by understanding and editing an image's
underlying "DNA" in [[concepts/json-format|JSON format]].

The process begins by uploading an image to [[entities/gemini|Gemini]] and prompting it to
extract all visual information into a [[concepts/structured-json|structured JSON]] file. This JSON
outlines everything from room type and [[concepts/style|style]] to specific furniture items,
colors, materials, and even architectural features. Users can then
re-upload the original image, paste the generated JSON, and directly modify
specific properties within the code – for instance, changing the color of a
black leather lounge chair to red. This method ensures that while a
specific detail is altered, the overall style and other elements of the
image remain perfectly consistent, avoiding unintended changes that often
occur with less precise [[concepts/ai-assisted-editing|AI editing]].

Beyond direct [[concepts/json-manipulation|JSON manipulation]], Gemini offers more intuitive editing
options. The video demonstrates how users can upload their own portrait
photos and ask Gemini to describe the photography techniques (lighting,
composition, color palette, post-processing) in another image, generating a
JSON description of that style. This style JSON can then be applied to the
user's photos, recreating the desired aesthetic. Furthermore, Gemini
includes built-in brush and text tools for direct, on-image [[concepts/adjustments|adjustments]],
allowing users to point to an object, describe a change (like "turn the
couch red" or "put a teddy bear on the chair"), and have Gemini implement
it automatically and consistently.

Additional powerful features showcased include adjusting the aspect ratio
of an image, which Gemini intelligently expands or crops while maintaining
context and detail. The AI also offers "[outpainting](https://en.wikipedia.org/wiki/Outpainting)" to extend [[concepts/images|images]] and
generate full-body shots from existing portraits, and an upscaling
capability to enhance blurry images to 4K resolution with improved
[[concepts/sharpness|sharpness]] and detail. The presenter also briefly introduces an external,
free watermark removal tool built with [[entities/google-ai-studio|Google AI Studio]], adding a practical
utility for image cleanup. The overarching takeaway is that Gemini provides
a versatile and powerful suite of [[concepts/ai-tools|AI tools]] for highly controlled and
consistent image editing, catering to both technical users comfortable with
JSON and those preferring more direct, intuitive methods.
