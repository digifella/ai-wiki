# Lm Link

LM Link is a [[concepts/remote-access|remote access]] feature within [[entities/lm-studio|LM Studio]] that allows users to run language [[concepts/models|models]] on [[concepts/portable-devices|portable devices]]. Rather than requiring substantial [[concepts/computational-resources|computational resources]] on a mobile or lightweight device, LM Link enables these devices to connect to and utilize language models [[concepts/running|running]] on more powerful machines.

## Use Case

The feature is designed to support the [[concepts/deployment|deployment]] of private [[concepts/ai-powered-applications|AI applications]] on portable devices without the need to run full [[concepts/inference|model inference]] locally. This approach allows users to maintain data [[concepts/privacy|privacy]] while gaining access to capable language models in mobile or field [[concepts/scenarios|scenarios]].

## Integration with LM Studio

LM Link functions as part of the broader LM Studio ecosystem, which provides a desktop environment for running and managing language models locally. The remote access capability extends LM Studio's functionality beyond single-machine deployment to distributed or mobile [[concepts/use-cases|use cases]].
