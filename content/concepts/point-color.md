# Point Color

A selective [[concepts/tint-adjustment|color adjustment]] feature in [[entities/adobe|Adobe]] [[concepts/camera-raw|Camera Raw]], located within the [[concepts/color-mixer|Color Mixer]], that targets specific [[concepts/color-ranges|color ranges]] within an image. The [[concepts/color-variance-control|Color Variance Control]] slider enables precise [[concepts/llms|definition]] of the color [[concepts/range|range]] affected by [[concepts/adjustments|adjustments]].

Key usage and demonstrations:
- **[[concepts/workflow|Workflow]] (via [[entities/julianne-kost]]):**
    - Select target color using [[concepts/eyedropper-tool|eyedropper tool]] (e.g., green from trees in landscape image)
    - Adjust **[[concepts/hue|Hue]]**, **Saturation**, and **Luminance** for selected color range
    - Use **Color Variance [[concepts/power|Control]]** to expand/contract affected color range
- **Feature Insights (via [[entities/glyn-dewis]]):**
    - Use the **Variance** slider to control the specific range of colors affected by a Point Color adjustment after sampling a color.
