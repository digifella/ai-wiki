# Local Computation

Local computation refers to the practice of [[concepts/running|running]] [[concepts/agentic-ai|AI agents]] and [[concepts/machine-learning-systems|machine learning systems]] on personal [[concepts/hardware|hardware]] rather than relying on cloud-based services. This approach involves deploying [[concepts/reasoning-models|open-source models]] and tools directly on individual computers or local servers, enabling users to process data and perform AI tasks without transmitting information to external platforms.

## Private Data Processing

A primary advantage of local computation is data [[concepts/privacy|privacy]]. By operating AI systems locally, sensitive information remains on the user's hardware and is never sent to third-party servers. This makes local computation particularly suitable for implementations like private Retrieval-Augmented Generation (RAG) systems, where proprietary documents or confidential data need to be analyzed while maintaining complete control over access and [[entities/storage|storage]].

## Tools and Implementations

Several [[concepts/open-source|open-source]] tools facilitate local computation, including [[concepts/data-embedding|InsightsLM]], which provides a locally-deployable alternative to cloud-based services like [[entities/googles-notebooklm|Google's NotebookLM]]. These tools enable users to set up fully functional [[concepts/ai-productivity-agents|AI agent systems]] on standard personal computers, reducing both infrastructure costs and dependency on external service providers.
