# Chord anatomy

## Overview
The structural [[concepts/writing|composition]] of musical [[concepts/notes|notes]] played simultaneously to create [[concepts/musical-harmony|Harmony]]. Chords serve as the foundational element for adding emotional depth and character to a [[concepts/melody]].

## Key Components
- **Foundations**: The basic building blocks required for constructing functional Harmony.
- **Anatomy**: The internal arrangement and structural layers of notes within a chord.
- **Scale [[concepts/relationships|Relationships]]**: The functional [[concepts/connection|connection]] between Scale structures and chord construction.

## Core Relationships
- [[concepts/melody]] $\leftrightarrow$ Harmony: Chords provide the harmonic context that enhances melodic expression.
- Scale $\leftrightarrow$ Chord: Chords are derived from the intervals and notes found within specific Scale patterns.
