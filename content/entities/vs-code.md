# VS Code

[[entities/vscode|VS Code]] is a free, [[concepts/open-source|open-source]] code editor developed by [[entities/microsoft|Microsoft]] and released in 2015. Built on Electron, it provides a lightweight yet feature-rich environment for [[concepts/coding|software development]] across multiple programming languages including [[concepts/python|Python]], JavaScript, C++, Java, and many others. The editor runs on [[entities/windows|Windows]], [[entities/macos|macOS]], and [[entities/linux|Linux]], making it accessible to developers across different platforms.

## Architecture and Extensibility

The application uses a modular [[concepts/architecture|architecture]] centered around an extensive extension marketplace, allowing users to customize functionality for specific workflows and languages. Built-in features include syntax highlighting, code completion, [[concepts/debugging|debugging]] tools, and integrated terminal support. This extensibility has made VS Code a foundation for specialized development tools, including AI-assisted code editors built as forks of the original project.

## Adoption and Community

Since its release, VS Code has become one of the most widely used code editors in the [[concepts/developer|developer]] community. Its popularity stems from a combination of performance, ease of use, and the large ecosystem of community-maintained extensions. The project benefits from active development and regular updates from Microsoft, alongside significant contributions from the open-source community.
