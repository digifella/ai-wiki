# Output Quality

**Output Quality** refers to the accuracy, coherence, relevance, and utility of generated content relative to user intent and domain standards. It is a primary metric for evaluating [[concepts/large-language-model|Large Language Model]] (LLM) performance, often weighed against cost and latency.

## Key Evaluation Dimensions
- **Accuracy:** Factual correctness and logical consistency.
- **Coherence:** Structural integrity and flow of the generated text.
- **Relevance:** Alignment with specific prompt constraints and context.
- **Utility:** Practical applicability of the output for the intended use case.
