# Skills Testing Overview

[[concepts/skills|Skills]] [[concepts/testing|testing]] is a process designed to evaluate the proficiency and effectiveness of [[concepts/ai-tools|AI tools]] in performing specific tasks and functions. This involves assessing various features such as [[concepts/loops|loops]], [[concepts/temporary-cron-jobs|scheduled tasks]], and [[concepts/integration|integration]] capabilities with platforms like [[concepts/google-workspace|Google Workspace]].

### Key Features
- **Loops**: Automated repetitive actions that improve [[concepts/workflow|workflow]] efficiency.
- **Scheduled Tasks**: Allows for the [[concepts/automation|automation]] of time-sensitive tasks to streamline processes.
- **[[entities/google-workspace|Google Workspace]] Access**: Integration with Google Workspace tools enhances collaboration and productivity.
- **Built-in Skills Testing ([[concepts/skills-20|Skills 2.0]])**: A new feature designed to systematically assess [[concepts/ai-workflow|AI capabilities]] and performance
