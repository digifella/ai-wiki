# ChatGPT 5.1

[[entities/chatgpt-51-codex|ChatGPT 5.1]] is a version update of [[entities/openai|OpenAI]]'s [[concepts/statistical-language-modeling|language model]] announced in 2026. The release introduced [[concepts/cloud-agents|cloud agents]] capability as a significant feature addition to the [[concepts/codex|Codex]] system, marking a step toward more autonomous AI functionality in [[concepts/coding|coding]] and [[concepts/development-workflows|development workflows]].

## Cloud Agents Capability

The cloud [[concepts/agents|agents]] feature enables the model to operate with greater autonomy in cloud environments, allowing for distributed task execution and [[concepts/integration|integration]] with external services. This represents an expansion of the model's practical [[concepts/software|applications]] beyond traditional chat-based interactions.
