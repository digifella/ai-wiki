# API Access & Multimodal AI Breakthroughs

## Google Workspace Access

[[concepts/google-workspace|Google Workspace]] access is a capability introduced in [[entities/claude-code]] 2.0 that enables interaction with Google Workspace applications and services. This feature expands integration possibilities beyond standalone coding environments, allowing work with Google's productivity suite including Docs, Sheets, Gmail, and other collaborative tools. The capability was documented in a 2026 video by Simon Scrapes.

### Functionality

The access capability allows reading, creating, and modifying content within Google Workspace applications. This integration facilitates workflows combining coding tasks with document manipulation and [[concepts/data-management|data management]] across Google's platform ecosystem.

### Integration Scope

By incorporating Google Workspace access, [[concepts/claude-code-20|Claude Code 2.0]] extends its utility beyond isolated [[concepts/developer-platforms|development environments]] into collaborative and productivity-focused contexts. This integration allows users to automate workflows that bridge [[concepts/code-generation|code generation]] with external [[concepts/productivity-tools|productivity tools]].
