# Nano Banana Pro

## Overview
[[entities/nano-banana-pro|Nano Banana Pro]] is an advanced [[concepts/ai-image-editing|AI image editing]] model by Google [[concepts/gemini|Gemini]], designed for precise and consistent control over image modifications. It builds upon the capabilities of its predecessor, [[entities/nano-banana-2]], enhancing the ability to manipulate [[concepts/images|images]] through JSON [[concepts/data-extraction|data extraction]] and manipulation.

### Key Features:
- **[[concepts/json|JSON Manipulation]]:** Utilizes JavaScript Object Notation (JSON) for detailed editing.
- **Precision Control:** Offers fine-grained control over image details.
- **[[concepts/logical-consistency|Consistency]]:** Ensures uniformity across multiple edits.

## Video Creation Integration
[[entities/google-nano-banana-pro|Nano Banana Pro]] is now used in conjunction with [[entities/notebooklm|Notebookly]] and [[entities/pictory|Pictory]] for creating animated [[concepts/whiteboard|whiteboard]] videos. The [[concepts/workflow|workflow]] includes:
- Uploading scripts to [[entities/notebooklm|NotebookLM]] to generate [[concepts/slide-decks|slide decks]]
- Applying [[entities/google-nano-banana-pro|Nano Banana Pro]] for precise [[concepts/image-editing|image editing]] within [[entities/google-slides|slides]]
- Rendering final output via [[entities/pictory|Pictory]]
