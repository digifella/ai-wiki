# Gemini 3.0

Google's latest AI model featuring enhanced multimodal processing and professional workflow integration, distinct from [[concepts/gemini|Gemini]] Pro.

## Key Changes (from Jeff Su's review)

- **Improved [[concepts/multimodal-understanding|Multimodal Understanding]]**: [[concepts/gemini|Gemini]] 3 processes [[concepts/images|images]], video, and audio simultaneously rather than treating them as separate inputs.
- **Enhanced Code Generation**: Better support for complex programming tasks across multiple languages.
- **Contextual [[concepts/memory|Memory]]**: Retains 5x longer conversation context for professional documentation.
- **Real-time Collaboration**: Direct integration with [[entities/google-workspace]] for team editing.
- **Customizable [[concepts/agents|Agents]]**: Pre-built workflows for sales, HR, and project management.
