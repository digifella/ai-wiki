# 2.11BSD

**2.11BSD** is a version of the [[entities/uc-berkeley|Berkeley]] Software Distribution (BSD) [[concepts/unix|Unix]] operating system, specifically designed for the [[concepts/pdp-11]] family of minicomputers. It represents one of the last major releases of BSD for the [[concepts/pdp-11-architecture|PDP-11 architecture]] before the transition to the VAX and later [[entities/intel|Intel]] architectures.

## Key Characteristics
- **Architecture:** Optimized for the DEC PDP-11 and VAX-11 [[concepts/central-processing-units|processors]].
- **Legacy:** Serves as a critical bridge between early Unix variants and modern BSD-derived systems (such as FreeBSD and OpenBSD).
- **File System:** Utilizes the Fast File System (FFS) in later patches, improving performance on magnetic disk drives.

## Modern Revival and Hardware Challenges
Recent efforts have focused on running 2.11BSD on physical vintage hardware to preserve and demonstrate its capabilities in a modern context.

- **[[concepts/pdp-1173|PDP-11/73]] Modernization:** A significant project documented by [[entities/daves-garage]] involves upgrading a mid-1970s PDP-11/73 to host a public website.
- **Performance Paradox:** Despite hardware upgrades resulting in a 4× [[concepts/speed|speed]] increase, the system initially failed to boot due to complex hardware/software integration challenges [[lab-notes/2026-10-05-PDP-1173-Modernization-Overcoming-HardwareSoftware-Chall|PDP-11/73 Modernization: Overcoming Hardware/Software Challenges to Host Public Website]].
- **Integration Goals:** The project aims to overcome decades-old [[concepts/hardware-limitations|hardware limitations]] to bring this 1970s-era OS into the modern internet age.
