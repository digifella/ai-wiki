# Graft

**[[concepts/ai-agent|Graft]]** is an open-source [[concepts/context-layer|context layer]] designed to optimize the efficiency and cost-effectiveness of AI coding agents, particularly when operating within [[concepts/large-codebases|large codebases]]. It addresses the challenge of [[concepts/context-length|context window]] limitations and high API costs by managing how code context is retrieved and injected into models like [[entities/claude-code]] and [[entities/openai]] models.

## Key Features
- **Context Optimization:** Reduces the amount of irrelevant code sent to the LLM, lowering token usage and costs.
- **Performance Improvement:** Enhances the accuracy and speed of AI agents by providing more relevant, curated context.
- **Compatibility:** Designed to work seamlessly with major AI coding assistants.
