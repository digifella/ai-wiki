# State Space Model

A state space model ([[concepts/ssm|SSM]]) is a mathematical framework representing dynamic systems through state variables and transition functions. In [[concepts/machine-learning|machine learning]], SSMs provide efficient sequence modeling with linear complexity, making them ideal for long-context processing in [[concepts/large-language-models|large language models (LLMs)]].
