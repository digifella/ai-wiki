# BDH architecture

**[[entities/the-deep-view|BDH architecture]]** refers to the computational framework developed by [[entities/pathway|Pathway]] designed to overcome the limitations of current [[concepts/large-language-models|Large Language Models]] (LLMs). This architecture emphasizes [[concepts/real-time-analytics|real-time data processing]] and dynamic state management, enabling [[concepts/ai-models|AI systems]] to operate beyond static [[concepts/model-inference|inference]] boundaries.

## Key Concepts

*   **Beyond LLM Limitations**: Addresses the static nature of traditional LLMs by introducing continuous, stateful [[concepts/computation|computation]].
*   **Real-Time Processing**: Enables [[concepts/ai-powered-applications|AI applications]] to [[concepts/react-framework|react]] to [[concepts/dynamic-data-feeds|live data streams]] rather than relying solely on pre-trained static [[concepts/parameters|weights]].
*   **Dynamic State Management**: Allows for the maintenance and updating of context during execution, crucial for complex, [[concepts/continuous-task-execution|long-running AI tasks]].
