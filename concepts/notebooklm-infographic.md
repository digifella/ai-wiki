# NotebookLM Infographic

[[concepts/ai-integrated-notebooks|NotebookLM]] is [[concepts/google-search|Google]]'s [[concepts/ai-driven-research|AI-powered research]] and note-taking platform that generates [[concepts/infographic-design|infographics]] from [[concepts/notebooklm-sources|source materials]]. These infographics visually summarize key information and concepts, making them useful for presentations and educational content. The platform uses [[entities/gemini-models|Gemini AI]] to analyze uploaded documents, web content, and [[concepts/notes|notes]], then automatically creates visual representations of the material.

## Converting to Interactive Web Applications

NotebookLM-generated infographics can be transformed into [[concepts/interactive-html-web-applications|interactive web applications]] through integration with [[entities/gemini-ai|Gemini AI]]. This workflow typically involves extracting the [[concepts/infographic|infographic]] structure and data, then using [[concepts/gemini|Gemini]] to generate HTML, CSS, and [[concepts/javascript|JavaScript]] code that recreates the visualization as an interactive [[concepts/experience|experience]]. Users can input the infographic details or use [[concepts/google-ai|Gemini]] to analyze the original infographic image and produce web-ready code that maintains the original design while adding interactivity features.

## Design and Customization

The platform supports [[concepts/customization|customization]] of [[concepts/infographic-creation|infographic design]] to suit professional presentation standards. Users can adjust visual elements, [[concepts/branding|branding]], and layout through [[concepts/notebooklm|NotebookLM]]'s interface or further refine outputs using [[entities/gemini-app|Gemini]] [[concepts/ai-templates|AI prompts]]. This flexibility allows creators to align generated infographics with specific organizational guidelines or project requirements before conversion to other formats.

## Related Workflows

[[entities/notebook-lm|NotebookLM]]'s capabilities extend beyond infographics to other content types, including [[concepts/mind-maps|mind maps]] and slide presentations. Similar conversion processes can transform these outputs into [[concepts/interactive-html-sites|interactive HTML sites]] or unwatermarked [[concepts/video-resource|video content]] using [[entities/gemini-pro|Gemini]] AI assistance, providing multiple pathways for repurposing AI-generated research visualizations across different media formats.
