# Single Click Editing

Single Click Editing is a workflow feature in Adobe Lightroom Classic that enables photographers to apply multiple automated AI masks to an image with a single action. Instead of manually creating and adjusting individual masks for different sections of a photograph, users can save and apply preset combinations that automatically isolate specific elements such as skies, subjects, or backgrounds. This functionality streamlines repetitive editing tasks, particularly for photographers working with consistent subjects or conditions.

## Technical Implementation

The feature operates by leveraging Adobe’s machine learning models to detect and segment distinct regions within a photograph. When a user selects a preset, the software generates a composite mask that applies specific adjustments to each identified area simultaneously. This process replaces the traditional manual masking workflow, where users would typically create separate masks for the sky, foreground, and subject, then fine-tune each individually. The system dynamically adapts to the content of the image, ensuring that adjustments remain localized to the intended elements without bleeding into adjacent areas.

## Application in Photography

This tool is primarily utilized in landscape and portrait photography, where consistent compositional elements require uniform treatment across multiple images. For landscape photographers, presets often target sky replacement or foreground enhancement, while those focused on people photography may use masks to isolate subjects for background blur or skin tone adjustments. By automating the segmentation and initial adjustment phase, the feature reduces the time spent on technical masking, allowing editors to focus on creative refinement and batch processing efficiency.
