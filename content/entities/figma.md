## Figma

### Overview
Figma is a web-based UI [[concepts/design|design]] tool that allows designers to create, collaborate and share designs directly in the browser. It supports real-time collaboration, enabling multiple users to work on the same project simultaneously.

### Key Features
- Real-time Collaboration: Multiple users can work on the same file [[concepts/assistive-technology|at]] once.
- Vector Design Tools: Includes a full suite of vector design tools for creating complex shapes and graphics.
- Prototyping: Ability to create interactive prototypes directly from designs.
- Plugin Ecosystem: Extensive library of [[concepts/plugins|plugins]] that extend functionality.
