# Openrag

[[concepts/retrieval-augmented-generation-rag|OpenRAG]] is a framework developed by IBM for constructing agentic [[concepts/answer-generation|retrieval-augmented generation]] (RAG) systems. The framework was publicly explained and promoted by IBM [[concepts/developer|Developer]] Relations Engineer [[entities/david-jones-gilardi|David Jones-Gilardi]]. It enables developers to build [[concepts/ai-models|AI systems]] that combine language models with [[concepts/knowledge-bases|information retrieval]] capabilities, allowing agents to access and [[concepts/purpose|reason]] over [[concepts/external-data|external data]] sources dynamically.
