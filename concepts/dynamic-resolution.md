# dynamic resolution

Dynamic [[concepts/solution|resolution]] refers to the ability of a system to adjust output resolution in real-time based on content complexity, resource constraints, or user requirements, avoiding fixed-resolution limitations.

**Recent Implementation in [[concepts/ai-image-editing|AI Image Editing]]:**
- [[entities/hidream-e11|HiDream-E1.1]] (2026) supports dynamic resolution for flexible [[concepts/image-editing|image editing]], improving upon OmniGen2 and [[entities/flux-kontext-dev|Flux Kontext Dev]] with higher accuracy and quality.
- Demonstrated capability: [[concepts/detail-removal|detail removal]] (e.g., eliminating raindrops from street scenes while preserving background [[concepts/logical-consistency|consistency]]).
