# Claude Chatbot

[[concepts/claude-ai|Claude]] is an AI chatbot developed by [[entities/anthropic-institute|Anthropic]], functioning primarily as a [[concepts/large-language-model|large language model]] that processes text input to generate conversational responses. By default, it operates as a text-based [[concepts/ai-chatbots|conversational AI]], engaging with users through [[concepts/communication|dialogue]] while drawing on knowledge from its [[concepts/custom-dataset|training data]]. This standard mode allows for interaction across a wide range of topics, serving as a general-purpose assistant for [[concepts/knowledge-bases|information retrieval]] and creative tasks.

The functionality of Claude extends beyond standard conversational interaction through the implementation of the [[concepts/external-tools|Model Context Protocol]] (MCP). This protocol enables Claude to function as an [[concepts/ai-agent|AI agent]], allowing it to interact with external tools and systems. By leveraging MCP, Claude can perform actions that require access to real-time data or specific software environments, thereby expanding its utility from passive information provider to active problem solver.

This agentic capability represents a significant evolution in how the model interacts with its environment. Instead of relying solely on internal parameters, the integration of MCP allows Claude to execute [[concepts/commands|commands]], query databases, and manipulate files within defined constraints. This shift transforms the chatbot from a static text generator into a dynamic agent capable of completing complex, multi-step workflows that require external [[concepts/enterprise-integration|system integration]].
