# File Removal From Evernote

In 2026, [[entities/evernote|Evernote]] implemented significant changes to its [[concepts/pricing-structure|pricing structure]], [[concepts/prompting|prompting]] many users to reconsider their continued use of the platform. For users deciding to leave Evernote, removing stored files and data became an important practical concern. The process of [[concepts/file-removal|file removal]] typically involves exporting [[concepts/notes|notes]] and attachments before account deletion, which ensures users retain access to their information after leaving the service.

## Export Process

Evernote provides built-in export functionality that allows users to download their notes in standard formats. Users can export individual notes, [[concepts/notebook-tools|notebooks]], or their entire account. The platform supports export to formats including ENEX (Evernote's native XML format) and PDF, which can be imported into alternative note-taking applications or archived locally. The export process can be initiated through the application settings or web interface, depending on the user's Evernote subscription tier.

## Data Preservation

Exported files should be verified and organized before account deletion, as recovery options are limited once an account is closed. Users may need to convert exported files to compatible formats if transitioning to a different note-taking platform. It is advisable to store exported data across multiple locations to prevent loss due to hardware failure or accidental deletion.

## Account Deletion

Once files have been successfully exported and backed up, users can proceed with account deletion through Evernote's account settings. Account deletion is typically permanent and results in the removal of all remaining data from Evernote's servers. Some platforms offer a grace period before permanent deletion, allowing users to restore their account if needed.
