# Graphics Processing Units (GPUs)

A **[[concepts/webgpu|Graphics]] Processing Unit** (GPU) is a specialized electronic circuit designed to rapidly manipulate and alter [[concepts/memory|memory]] to accelerate the creation of images in a frame buffer intended for output to a display device. GPUs are used in embedded systems, mobile phones, workstations, desktops, laptops, game consoles, and game computers.

- [[concepts/cuda]]: [[concepts/gpu-parallel-computing|GPU parallel computing]] platform developed by [[entities/nvidia|Nvidia]] that allows developers to use GPUs for [[concepts/general-purpose-computation|general-purpose computation]].
- General-Purpose Computing on Graphics Processing Units (GPGPU): The use of a graphics processing unit as a general-purpose manycore [[concepts/cpu|processor]], in conjunction with the CPU, to solve a range of complex [[concepts/computational-problems|computational problems]].

## Nvidia CUDA

### Summary
[[entities/nvidia|Nvidia]] [[concepts/cuda|CUDA]] is a [[concepts/general-purpose-computing|parallel computing]] platform and programming model developed by [[concepts/unsloth-optimization|Nvidia]] that allows software developers to use a graphical processing unit for general purpose processing. It was launched in 2007 by [[entities/ian-buck|Ian Buck]] and [[entities/john-nicholls|John Nicholls]], extending the functionality of GPUs far beyond their traditional role in [[concepts/visual-rendering|rendering]] images.
