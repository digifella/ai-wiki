# Skills Testing Overview

[[concepts/skills|Skills]] testing is a process designed to evaluate the [[concepts/excellence|proficiency]] and effectiveness of [[concepts/ai-tools|AI tools]] in performing specific tasks and functions. This involves assessing various features such as [[concepts/loops|loops]], [[concepts/temporary-cron-jobs|scheduled tasks]], and integration capabilities with platforms like [[concepts/google-workspace|Google Workspace]].

### Key Features
- **Loops**: Automated repetitive actions that improve [[concepts/efficiency-principles|workflow efficiency]].
- **Scheduled Tasks**: Allows for the automation of time-sensitive tasks to streamline processes.
- **[[entities/google-workspace|Google Workspace]] Access**: Integration with [[concepts/google-workspace-tools|Google Workspace tools]] enhances collaboration and [[concepts/productivity|productivity]].
- **[[concepts/built-in-skills-testing|Built-in Skills Testing]] ([[concepts/skills-20|Skills 2.0]])**: A new feature designed to systematically assess [[concepts/ai-workflow|AI capabilities]] and performance
