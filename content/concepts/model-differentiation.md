# Model Differentiation

The strategic identification of unique functional advantages and architectural boundaries that distinguish one [[concepts/large-language-model|Large Language Model]] (LLM) from another.

## Key Differentiators

- **Ecosystem & Workspace [[concepts/integration|Integration]]**: The level of native connectivity with existing productivity [[concepts/software|software]] suites.
    - Example: [[entities/gemini]] leverages native [[entities/google-workspace]] integration via `@` command triggers to access user data and tools.
- **[[concepts/reasoning|Reasoning]] [[concepts/capabilities|Capabilities]]**: The sophistication of a model's [[concepts/advanced-reasoning]] and complex logic processing.
- **Feature-Specific Functionality**: The [[concepts/adoption|implementation]] of end-to-end workflows and specialized [[concepts/tool-selection|tool-use]] capabilities within a specific application environment.
