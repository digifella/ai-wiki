# Layer Styles

Layer Styles are a set of effects and adjustment tools in [[concepts/photoshop|Adobe Photoshop]] that modify the appearance and blending behavior of individual layers. These features allow designers and photographers to apply visual effects—such as [[concepts/shadows|shadows]], glows, strokes, and bevels—directly to layer content without permanently altering the underlying pixels. Layer Styles remain editable, making them non-destructive [[concepts/adjustments|adjustments]] that can be modified or removed [[concepts/assistive-technology|at]] any time during the editing process.

## Blend If Settings

The [[concepts/blend-if-sliders|Blend If sliders]] are a core component of Layer Styles that [[concepts/power|control]] layer transparency based on brightness and color values. These settings allow users to hide portions of a layer or reveal underlying layers based on specific tonal ranges or individual color channels. By adjusting the "This Layer" and "Underlying Layer" sliders, designers can create complex transparency effects without requiring manual [[concepts/layer-masks|masking]], enabling [[concepts/selective-blending|selective blending]] based on luminosity or color data within the image.

## Common Applications

Layer Styles are widely used for creating dimensional effects in graphic [[concepts/design|design]], [[concepts/composite-imaging|photo compositing]], and digital [[concepts/art|art]]. Effects like drop shadows add depth, inner glows create luminous qualities, and strokes define layer boundaries. The Blend If feature is particularly useful in professional workflows for isolating tonal ranges, removing unwanted [[concepts/color-casts|color casts]], or compositing elements together based on their brightness characteristics, making complex [[concepts/masking|masking]] tasks more efficient.
