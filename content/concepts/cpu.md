## CPU (Central Processing Unit)

The central processing unit or CPU is the primary component of a computer that carries out [[concepts/instructions|instructions]] from [[concepts/software|software]] programs and performs computations. It acts as the brain of the computer system, coordinating all tasks within the machine.

### Key Points
- **Role**: The CPU executes instructions stored in [[concepts/memory|memory]] to perform data manipulation tasks.
- **[[concepts/architecture|Architecture]]**: Modern CPUs are typically based on complex instruction set computing (CISC) or reduced instruction set computing (RISC) architectures.
- **Performance Metrics**: Commonly measured by clock speed, cache size, core count, and technology node.
