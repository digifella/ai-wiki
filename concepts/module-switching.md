# Module Switching

**Module switching** refers to the operational transition between distinct functional interfaces within a software application, particularly in complex creative suites. In [[concepts/lightroom-desktop|Adobe Lightroom Classic]], this involves toggling between modules such as Library, Develop, Map, Book, Slideshow, Print, and Web.

## Stability and Performance Implications

Module switching is a known [[concepts/stress|stress]] point for application stability, often triggering [[concepts/memory|memory]] management issues or plugin conflicts.

- **Persistent Crash Vectors:** Users have reported debilitating freezes and crashes specifically during routine module transitions or tasks like copying [[concepts/develop-settings|develop settings]] [[lab-notes/2026-10-05-AI-Driven-Troubleshooting-of-Persistent-Adobe-Lightroom|AI-Driven Troubleshooting of Persistent Adobe Lightroom Classic Crashes]].
- **[[concepts/historical-context|Historical Context]]:** For some users, these crashes persisted for years, affecting routine tasks such as rating photos or changing modules, indicating deep-seated catalog or [[concepts/engine|engine]] instability rather than simple user error.
- **AI-Driven [[concepts/solution|Resolution]]:** Recent approaches involve using AI to analyze catalog data and application logs to identify the root cause of these persistent crashes, moving beyond traditional troubleshooting steps like reinstalling or resetting preferences.
