# Microsoft Support

Core assistance framework for [[entities/microsoft|Microsoft]] products and services, including [[entities/microsoft-365]], [[entities/windows]], and [[entities/azure|Azure]].

## Copilot Agents Integration
- **Function**: [[concepts/agents|Agents]] look up [[concepts/policies|policies]] and respond to user queries (e.g., [[entities/microsoft-365]] [[concepts/training|training]] support)
- **Status**: [[concepts/agentic-systems|Autonomous agents]] in preview mode
- **Example [[concepts/adoption|Implementation]]** ([[entities/georgia-engel|Georgia Engel]], [[entities/dan-polifiori|Dan Polifiori]]):
  - [[concepts/purpose|Purpose]]: Assist with [[entities/microsoft-365]] training and support
  - Features: Answers FAQs, guides through common tasks/issues
  - [[concepts/tone|Tone]]: Friendly, helpful, collaborative; [[concepts/responses|responses]] must be clear
