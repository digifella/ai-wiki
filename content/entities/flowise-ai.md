# Flowise AI

[[concepts/flowise|Flowise AI]] is an [[concepts/open-source|open-source]], [[concepts/no-code|no-code]] platform for building and deploying LLM-powered [[concepts/software|applications]] and [[concepts/agents|agents]] through visual workflows.

## Key Features

- **[[entities/anthropic-institute|Anthropic]]-inspired multi-[[entities/agent|agent]] research agent flow**: Built to overcome single LLM limitations ([[concepts/data-hallucination|hallucination]], insufficient depth) by emulating human [[concepts/iterative-research|iterative research]] through a multi-agent system (inspired by [[entities/anthropic]]'s research approach).
- **[[concepts/visualization-generation|Deep research]] capability**: Uses iterative [[concepts/agent-collaboration|agent collaboration]] to refine queries and validate results, significantly improving research depth and [[concepts/accuracy|accuracy]].
- **Community resources**: Detailed implementation guide available via [[concepts/date-2026-04-13|2026]] 04 14 Anthropic multi agent [[concepts/deep-research-agent|deep Research agent]] (video [[concepts/tutorial|tutorial]] by [[entities/leon-van-zyl|Leon van Zyl]], GitHub [[concepts/code|code]] repository).
