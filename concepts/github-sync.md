# GitHub Sync for Obsidian Wiki

[[concepts/github-synchronization|GitHub sync]] allows users to keep their [[concepts/obsidian|Obsidian]] wiki [[concepts/software-updates|updates]] in a version-controlled repository on [[entities/github|GitHub]]. This feature facilitates collaboration and ensures that all changes are backed up offsite.

## Key Concepts
- **[[concepts/app-updates|Version Control]]**: Managing the history of document changes, enabling recovery of previous versions.
- **Collaboration**: Multiple contributors can work simultaneously without conflicts through merge requests or pull requests.
- **Backup**: Ensures data is safe from [[concepts/local-storage|local storage]] issues and provides a remote copy for easy access.
