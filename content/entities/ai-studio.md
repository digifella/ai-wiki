# AI Studio

AI Studio is [[concepts/google-search|Google]]'s platform for interacting with and building [[concepts/software|applications]] using [[concepts/ai-models|AI models]]. It has evolved from its initial [[concepts/design|design]] as a straightforward [[concepts/model-playground|model playground]] into a more sophisticated environment designed for developing agent-based applications.

## Infrastructure and Capabilities

The platform underwent a major [[concepts/infrastructure-upgrade|infrastructure upgrade]] that expanded its functionality beyond simple model interaction. This upgrade introduced [[concepts/agent-powered-environment|agent-powered environment]] [[concepts/capabilities|capabilities]], enabling users to build more complex applications that [[concepts/leverage-ai|leverage AI]] [[concepts/agents|agents]] for [[concepts/autonomous-task-execution|autonomous task execution]] and [[concepts/decision-making|decision-making]]. The enhanced infrastructure supports full-stack [[concepts/app-creation|application development]] within the platform.

## Integration and Use Cases

AI Studio integrates with other [[entities/google|Google]] [[entities/ai-tools|AI tools]] and services, including [[concepts/ai-integrated-notebooks|NotebookLM]], which can be used to generate content like [[concepts/mind-maps|mind maps]] that can be converted into interactive web-based applications. This interconnected approach allows developers to move between different stages of [[concepts/ai-application-development|AI application development]] while maintaining [[concepts/continuity|continuity]] in their projects.
