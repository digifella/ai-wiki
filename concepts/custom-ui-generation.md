# Custom Ui Generation

Custom [[concepts/ui-generation|UI Generation]] refers to the automated creation of user interfaces tailored to specific applications or [[concepts/scenarios|use cases]] within [[concepts/ai-productivity-agents|AI agent systems]]. Rather than relying on pre-built [[concepts/templates|templates]] or static designs, this capability enables [[concepts/ai-models|AI systems]] to dynamically generate interface elements based on task requirements, user preferences, and contextual needs. This approach allows for more flexible and responsive user experiences that adapt to individual workflows and specific operational contexts.

## Implementation in AI Systems

In [[concepts/agentic-frameworks|agentic systems]], custom UI generation allows agents to construct functional interfaces on the fly to facilitate interaction with [[concepts/external-tools|external tools]] or data sources. By analyzing the current context and the specific goals of the agent, the system can render necessary controls, displays, or input fields without manual intervention. This dynamic adaptation ensures that the interface remains relevant to the immediate task, reducing [[concepts/friction|friction]] in [[concepts/complex-workflows|complex workflows]] where standard layouts may be insufficient.
