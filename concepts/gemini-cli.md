# Gemini Cli

[[concepts/cli-tool|Gemini Cli]] is a [[concepts/cli-tools|command-line interface]] that provides terminal-based access to [[concepts/google-search|Google]]'s [[concepts/gemini-models|Gemini AI models]]. It enables developers and users to interact with Gemini through text [[concepts/commands|commands]], making the model's capabilities available in command-line environments and scripting contexts. This approach facilitates integration into [[concepts/development-workflows|development workflows]], automation tasks, and allows programmatic access to Gemini without requiring graphical interfaces.

## Model Context Protocol Support

A key feature of Gemini Cli is its support for [[concepts/external-tools|Model Context Protocol]] (MCP) servers. This enables the tool to connect to [[concepts/external-data|external data]] sources and tools via the MCP standard, allowing the AI to access real-time information and execute specific functions within the terminal environment. By leveraging MCP, Gemini Cli extends its utility beyond simple [[concepts/text-generation|text generation]], supporting [[concepts/complex-workflows|complex workflows]] that require [[concepts/contextualized-language-understanding|dynamic context retrieval]] and tool execution directly from the command line.
