# Software Automation

Core concept of using automated tools to execute software tasks, reducing manual intervention. Current paradigms are shifting from pure "[[concepts/reasoning|reasoning]]" models toward specialized classification systems for practical automation needs.

## Key Developments

- **[[concepts/zero-shot-prompting|Jev Classification]] Model**: A new paradigm proposed by [[entities/typesafe-ai]] focusing on "System 1" classification rather than [[concepts/complex-reasoning|complex reasoning]] for automation tasks.
- **[[concepts/contrast|Contrast]] with Frontier Labs**: While labs like [[entities/openai]], Anthropic, and others focus on "reasoning" capabilities, this approach addresses the practical latency and cost constraints of software automation.
