# Flowise

2026 04 14 [[entities/anthropic-institute|Anthropic]] multi agent [[concepts/deep-research-agent|deep Research agent]]

## Overview
[[entities/flowise-ai|Flowise]] is an [[concepts/open-source|open-source]] tool for building customizable [[concepts/large-language-model|large language model]] (LLM) applications. It provides a [[concepts/gui-interface|visual interface]] to design and [[concepts/deployment|deploy]] [[concepts/complex-workflows|complex workflows]] involving multiple LLMs, [[concepts/open-standard-protocols|APIs]], and other components.

## Key Features
- **Visual Workflow Designer**: Drag-and-drop interface for creating LLM workflows.
- **Modular Components**: Pre-built modules for common tasks like [[concepts/text-generation|text generation]], [[entities/api-calls|API calls]], and data processing.
- **[[concepts/customization|Customization]]**: Supports custom [[entities/python|Python]] code for advanced [[concepts/scenarios|use cases]].
- **Deployment**: Easy deployment of workflows as [[concepts/web-applications|web applications]].

## Use Cases
- **[[concepts/slide-deck-automation|Research Automation]]**: Building agents that can perform [[entities/deep-research|deep research]] tasks.
- **[[concepts/ai-bots|Chatbots]]**: Creating [[concepts/conversational-ai|conversational agents]] with complex [[concepts/open-source-philosophy|logic]].
- **Data Processing**: Automating [[concepts/data-extraction|data extraction]] and transformation tasks.
