# Appearance Change

Appearance Change refers to the computational process of modifying visual elements within [[concepts/images|images]] through AI-assisted editing. This capability enables users to alter aspects of an image's composition, style, or specific features based on textual [[concepts/instructions|instructions]] rather than manual manipulation. The approach represents a shift from traditional pixel-level editing tools toward instruction-driven workflows where [[concepts/natural-language-descriptions|natural language descriptions]] guide the transformation process.

## HiDream-E1.1

HiDream-E1.1 is an instruction-based [[concepts/open-source|open-source]] [[concepts/ai-image-editing|AI image editing]] model designed to facilitate appearance modifications in digital images. The model operates through text-guided editing, allowing users to describe desired changes in natural language rather than manually selecting and adjusting pixels. A distinguishing feature of HiDream-E1.1 is its support for [[concepts/dynamic-resolution|dynamic resolution]], enabling it to process images at varying sizes and aspect ratios while maintaining edit quality.

The model's open-source [[entities/nature|nature]] makes it accessible to researchers, developers, and creative practitioners interested in instruction-driven image editing workflows. As part of the broader category of appearance change tools, HiDream-E1.1 demonstrates how [[concepts/ai-models|AI models]] can interpret and execute visual modifications based on user intent expressed through language.
