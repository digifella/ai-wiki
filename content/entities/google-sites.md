# Google Sites
[[entities/google-sites|Google Sites]] is a web-based service provided by [[concepts/google-search|Google]] that allows users to create and share information in the form of personal or professional websites. It can be used for simple informational sites, project management pages, team communication hubs, documentation repositories, and more.

## Features
- Easy-to-use interface for creating static web content.
- [[concepts/integration|Integration]] with other [[entities/google|Google]] services such as Docs, Sheets, [[entities/google-slides|Slides]], [[entities/gmail|Gmail]], and [[concepts/ambition|Drive]].
- Collaborative editing [[concepts/capabilities|capabilities]] that allow multiple users to work on the same site simultaneously.
- Customizable themes and [[concepts/templates|templates]] to match personal or organizational branding.
- Supports embedding media from various sources including [[entities/youtube|YouTube]], [[entities/google-photos|Google Photos]], and [[concepts/google-drive|Google Drive]].
