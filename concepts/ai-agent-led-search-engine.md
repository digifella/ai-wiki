# AI agent-led search engine

**AI agent-led search engines** represent a [[concepts/mindset-shift|paradigm shift]] from keyword-based [[concepts/document-retrieval|retrieval]] to intent-driven, autonomous [[concepts/information-synthesis|information synthesis]]. Unlike traditional search models that return static lists of links, these systems [[concepts/deployment|deploy]] [[concepts/llm]] as active agents capable of planning queries, executing searches, [[concepts/retrieving|retrieving]] documents, and synthesizing answers.

## Core Mechanics
- **Autonomous Query Planning**: Agents decompose complex user prompts into sub-tasks and specific search queries.
- **[[concepts/acting|Tool Use]] & [[concepts/integration|API Integration]]**: Direct interaction with search [[concepts/open-standard-protocols|APIs]], web scrapers, and database endpoints.
- **[[concepts/reasoning|Reasoning]] & Synthesis**: [[concepts/post-retrieval-optimization|Post-retrieval processing]] to filter noise, resolve contradictions, and generate coherent responses.
