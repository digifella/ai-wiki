# Generative Upscale

[[concepts/ai-powered-upscaling|Generative Upscale]] is an artificial intelligence-powered image enlargement feature available in [[entities/adobe-photoshop-beta|Adobe Photoshop Beta]]. It utilizes [[concepts/artificial-intelligence-models|machine learning models]] to increase [[concepts/image-resolution|image resolution]] beyond the original file dimensions by reconstructing visual details rather than relying on traditional mathematical interpolation. This approach allows the tool to generate plausible pixel information that maintains visual [[concepts/coherence|coherence]] at larger [[concepts/musical-scales|scales]].

Unlike conventional upscaling methods that estimate pixel values based on surrounding pixels, Generative Upscale employs [[concepts/generative-ai|generative artificial intelligence]] to infer and create new content. This process enables the [[concepts/preservation|restoration]] of fine details and textures that are often lost or blurred during standard resizing operations, resulting in higher quality outputs for enlarged images.

The feature is designed to assist creative professionals in preparing low-resolution assets for high-resolution displays or print media. By leveraging Adobe's [[concepts/cloud-ai|cloud-based AI]] models, the tool processes the image data to fill in missing information, offering a solution for [[concepts/scenarios|scenarios]] where traditional sharpening or [[concepts/computational-scaling|scaling]] techniques fail to preserve image [[concepts/honesty|integrity]].
