# Meeting Prep Strategist

A Meeting Prep Strategist is a specialized [[entities/ai-assistant|AI assistant]] created using [[entities/gemini-models|Google Gemini]]'s [[concepts/gems-feature|Gems feature]]. Gems allow users to configure custom versions of [[concepts/gemini|Gemini]] with specific [[concepts/instructions|instructions]], knowledge, and behavioral [[concepts/parameters|parameters]], enabling the creation of task-focused assistants beyond standard chatbot interactions.

## Purpose and Application

This type of assistant is designed to help professionals prepare for meetings by organizing information, generating talking points, analyzing agendas, and synthesizing relevant background materials. Rather than manually gathering and processing meeting-related information, users can delegate these preparatory tasks to a configured [[concepts/ai-assistant|AI assistant]] that operates according to predefined strategies and frameworks.

## Implementation

Creating a Meeting Prep Strategist involves using [[entities/gemini-app|Gemini]]'s Gems interface to establish [[concepts/custom-instructions|custom instructions]] for how the assistant should analyze meeting contexts, [[concepts/structure|structure]] [[concepts/preparation|preparation]] materials, and present recommendations. The assistant can be configured to handle specific meeting types, organizational contexts, or professional domains, making it more effective than generic [[entities/ai-tools|AI tools]] for this [[concepts/workflow|workflow]].
