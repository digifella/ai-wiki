## Overview
**Lean Launcher** is a Windows application launcher designed to minimize context switching and streamline workflows, with specific optimizations for Obsidian users. It addresses the friction often encountered when switching between desktop environments and note-taking applications.

## Key Features
- **Streamlined Quick Capture:** Facilitates rapid input and capture of thoughts directly into Obsidian, reducing the latency between idea generation and documentation.
- **Workflow Integration:** Optimized for Windows environments to bridge the gap between system-level actions and application-specific workflows.
- **Context Switching Reduction:** Designed to mitigate the cognitive load associated with switching between multiple applications.
