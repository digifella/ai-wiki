# Manual Control Mode

A state where the user maintains direct oversight and decision-making authority over AI systems, preventing uncontrolled [[concepts/automation|automation]]. Essential for mitigating [[concepts/ai-hallucinations|AI hallucinations]], ethical risks, and loss of agency.

## Key Integration: Jeff Su's "Cockpit Rule"
- **Mental model for [[concepts/ai-delegation|AI delegation]]**: Determines when to *delegate* (AI handles routine tasks), *collaborate* (AI augments human judgment), or *avoid* AI entirely (high-stakes decisions requiring human nuance).
- **Directly enables Manual Control Mode**: Prevents over-reliance on AI by maintaining human-in-the-loop decision points.
- **Baseline expectation**: "Using AI" is now table stakes (like Word proficiency); Manual Control Mode separates practitioners who *own* AI from those *controlled by* it.

## Related Concepts
- AI Autonomy: Opposite state where AI operates without human oversight.
- [[entities/prompt-engineering]]: Baseline skill now required but insufficient without Manual Control.
- [[concepts/regulation|AI Governance]] Framework: Structured implementation of Manual Control Mode principles.
