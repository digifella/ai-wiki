# Multi Modal Researcher

A Multi Modal Researcher is an [[concepts/ai-agent|AI agent]] built using [[concepts/google-search|Google]]'s [[concepts/gemini-25-models|Gemini 2.5]] models and orchestrated through the [[concepts/langgraph-framework|LangGraph framework]]. This tool is designed to conduct [[concepts/comprehensive-investigations|comprehensive investigations]] by leveraging [[concepts/multimodal-capabilities|multimodal capabilities]]—the ability to process and analyze text, [[concepts/images|images]], and other data types simultaneously. The system combines the [[concepts/thinking-and-reasoning-capabilities|advanced reasoning]] capabilities of Gemini 2.5 with LangGraph's [[concepts/agentic-patterns|agentic workflows]] to [[concepts/structure|structure]] complex research tasks.

## Architecture and Capabilities

The researcher operates by breaking down investigation tasks into structured workflows managed by LangGraph, which handles [[concepts/multi-agent-orchestration|agent coordination]] and state management. Gemini 2.5 provides the underlying intelligence for analyzing diverse input formats and synthesizing findings across different data modalities. This combination allows the agent to perform tasks that require understanding [[concepts/relationships|relationships]] between text documents, visual content, and [[concepts/contextual-information|contextual information]] in a unified manner.

## Use Cases and Output

The tool is designed to generate [[concepts/various-outputs|various outputs]] from its investigations, ranging from summaries and reports to extracted insights and [[concepts/json-structuring|structured data]]. By operating as an agent rather than a simple API call, the Multi Modal Researcher can iterate through research steps, refine queries, and validate findings across multiple sources and formats. This makes it suitable for complex research scenarios where multimodal analysis and autonomous investigation workflows provide advantages over traditional single-mode analysis.
