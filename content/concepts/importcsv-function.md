# IMPORTCSV function

A [[entities/microsoft-excel]] function used for dynamic CSV [[concepts/data-management|data management]] and automated reporting.

## Key Capabilities
- **Multi-CSV [[concepts/integration|Integration]]**: Enables the instant linking and aggregation of multiple CSV [[concepts/files|files]] into a single workbook.
- **Dynamic [[concepts/data-management|Data Management]]**: Facilitates efficient analysis of [[concepts/training-data|datasets]] from various sources, specifically addressing complex business [[concepts/scenarios|scenarios]].
- **Automated Reporting**: Streamlines [[concepts/workflow|workflows]] by allowing data to update dynamically as external source files are modified.
