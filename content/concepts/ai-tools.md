# AI Tools for Web Development Workflow

**[[concepts/summary|Summary]]:** This page compiles information on how various AI tools can be integrated into the development workflow to create [[concepts/interactive-html-web-applications|interactive web applications]]. A focus is placed on transforming static content like [[concepts/infographic|infographics]] into dynamic, user-friendly websites using advanced technologies.

## Overview
AI tools are increasingly being used in web [[concepts/development-workflows|development workflows]] to automate processes and enhance functionalities of [[concepts/web-applications|web applications]].

### Key Concepts
- **[[concepts/infographic|Infographic]] Transformation:** The process of converting an infographic from a static format into an interactive website.
- **[[concepts/gemini|Gemini]] AI:** A powerful AI framework by [[entities/google|Google]] that can be utilized for tasks such as data analysis, [[concepts/content-creation|content generation]], and [[concepts/user-interface|user interface]] [[concepts/design|design]] in [[concepts/website-building|web development]] projects.
- **[[entities/google-sites|Google Sites]] [[concepts/integration|Integration]]:** Utilizing [[concepts/google-search|Google]]'s platform to host and publish the transformed [[concepts/infographic-design|infographics]] and other dynamic web [[concepts/software|applications]].
