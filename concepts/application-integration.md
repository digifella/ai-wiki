# Application Integration

[[concepts/service-integration|Application integration]] refers to the process of connecting and coordinating different software applications or systems to enable seamless data exchange and interoperability. This can involve [[concepts/open-standard-protocols|APIs]], middleware, or specialized integration platforms that facilitate communication between disparate systems.

### Key Concepts:
- **APIs**: [[concepts/application-programming-interfaces-apis|Application Programming Interfaces]] allow two separate services or [[concepts/apps|apps]] to communicate with each other.
- **Middleware**: Software layer that connects two separate apps enabling them to work together more efficiently.
- **Integration Platforms**: Tools like iPaaS (integration platform as a service) automate and manage the process of integrating applications.
