# Bonsai
## Overview
A technology/framework associated with [[concepts/model-efficiency]] (specifically [[entities/bitnet]]) designed for extreme efficiency in [[concepts/on-device-ai]].

## Key Capabilities
- **[[concepts/model-efficiency|Model Compression]]**: Achieves up to 90% reduction in file size compared to [[concepts/full-precision|full-precision]] [[concepts/models|models]].
- **[[concepts/memory-efficiency|Memory Efficiency]]**: Reduces [[concepts/memory|memory]] consumption by up to 15x.
- **[[concepts/edge-deployment|Edge Deployment]]**: Enables high-[[concepts/parameter-models|parameter models]] (e.g., 27B [[concepts/parameters|parameters]]) to run on mobile [[concepts/hardware|hardware]] and smartphones.
- **Hardware Shift**: Facilitates a transition toward efficient [[concepts/local-computation|local computation]], potentially reducing reliance on the GPU-centric era.
