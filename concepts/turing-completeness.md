# Turing Completeness

Turing completeness is a property of an abstract machine (or programming language) that means it can [[concepts/compute|compute]] any function or [[concepts/algorithm|algorithm]]. The term was introduced by Alan Turing in his influential 1936 paper "On Computable Numbers, with an Application to the Entscheidungsproblem." A system is said to be Turing complete if and only if it can simulate a [[concepts/turing-machine|Turing machine]].

### Key Points
- **Definition**: Turing completeness refers to a system's ability to simulate any [[concepts/turing-machines|Turing machine]].
- **Implications**: Turing-complete systems are capable of solving any problem that can be solved computationally, given enough time and [[concepts/memory|memory]].
- **Examples**: Most general-purpose programming languages (e.g., [[entities/python|Python]], C++, Java) and some game engines (like Unity and [[entities/unreal-engine|Unreal]] [[concepts/engine|Engine]]).
