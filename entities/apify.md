# Apify

[[concepts/apify|Apify]] is a cloud-based automation platform designed primarily for [[concepts/web-crawling|web scraping]] and web [[concepts/data-extraction|data extraction]]. It provides tools and infrastructure for users to automate the process of collecting data from websites, whether for business intelligence, price monitoring, lead generation, or other data-driven applications.

## Key Features

The platform offers both visual and code-based approaches to building scrapers. Users can create automation workflows using Apify's visual builder or write custom scripts using [[concepts/javascript|JavaScript]]. The platform handles [[concepts/technical-infrastructure|technical infrastructure]] concerns such as proxy rotation, browser management, and [[concepts/computational-scaling|scaling]], allowing users to focus on defining what data to extract and from which websites.

Recent developments include:
*   **[[concepts/context-standardization|MCP Integration]]**: [[concepts/apify-mcp-connectors|Apify MCP Connectors]] enable advanced [[concepts/agentic-ai|AI agents]], such as [[concepts/hermes-agent|Hermes Agent]], to access restricted web data and perform complex automation tasks more effectively [[lab-notes/2026-06-16-Apify-MCP-Connectors-Empower-Hermes-Agent-for-Restricted|Apify MCP Connectors Empower Hermes Agent for Restricted Web Data Automation]].

## Use Cases

Apify serves various practical applications including e-commerce price tracking, real estate data collection, job listing aggregation, and competitive intelligence gathering. Organizations use it to automate repetitive data collection tasks that would otherwise require manual effort or custom development.
