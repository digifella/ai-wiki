# Chatgpt Superpower

[[entities/chatgpt|ChatGPT]] Superpower is a [[concepts/productivity|productivity]] framework developed by [[entities/jeff-su|Jeff Su]] that demonstrates how a focused set of [[concepts/ai-tools|AI tools]] can effectively handle the majority of professional work tasks. Rather than adopting numerous specialized platforms, the framework advocates for using a carefully selected combination of [[concepts/complementary-tools|complementary tools]] that work together to address common needs across productivity, [[concepts/content-creation|content creation]], and [[concepts/knowledge-management|knowledge management]]. The approach prioritizes simplicity and integration over tool proliferation.

## Core Principle

The framework is built on the observation that most professional workflows can be streamlined by leveraging a central [[concepts/large-language-model|large language model]], such as ChatGPT, as the primary [[concepts/engine|engine]] for [[concepts/reasoning|reasoning]] and drafting. This core tool is supported by a minimal stack of specialized applications for specific functions like [[concepts/video-editing|video editing]], design, or data analysis. By reducing the number of platforms an individual must master, the method aims to lower [[concepts/cognitive-load|cognitive load]] and increase execution [[concepts/speed|speed]].

## Implementation Strategy

Su’s methodology emphasizes the integration of these tools into a cohesive workflow rather than using them in [[concepts/disconnection|isolation]]. The central AI model handles tasks such as [[concepts/brainstorming|brainstorming]], outlining, and initial drafting, while auxiliary tools are engaged only when specific capabilities are required. This strategy encourages users to evaluate whether a new tool adds significant value or merely adds complexity to their existing process. The goal is to maintain a [[concepts/lean|lean]] [[concepts/tech-stack|tech stack]] that [[concepts/musical-scales|scales]] with the user’s needs without becoming unwieldy.
