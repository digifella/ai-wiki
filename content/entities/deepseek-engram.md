# Deepseek Engram

[[concepts/computational-reasoning|Deepseek Engram]] is a machine [[concepts/learning|learning]] technique that introduces [[concepts/conditional-memory|conditional memory]] through [[concepts/scalable-lookup|scalable lookup]] mechanisms. The approach adds a new dimension of sparsity to [[concepts/large-language-model|large language model]] (LLM) [[concepts/architecture|architecture]], enabling more efficient [[concepts/memory|memory]] access and computation patterns.

## Conditional Memory and Sparsity

The core [[concepts/innovation|innovation]] centers on making memory retrieval conditional rather than uniform. Instead of accessing all memory elements equally, the system uses scalable lookup to selectively retrieve only relevant information based on input context. This conditional approach reduces computational overhead by avoiding unnecessary memory operations, improving overall [[concepts/memory-efficiency|model efficiency]].

## Technical Approach

The technique leverages sparsity as an architectural principle, allowing the model to skip irrelevant computations and memory accesses. By implementing scalable lookup mechanisms, [[concepts/engram|Deepseek Engram]] enables systems to maintain large memory capacities without proportional increases in computational [[concepts/cost|cost]] during [[concepts/inference|inference]] or [[concepts/training|training]].
