# Neural Filters

[[entities/neural-filter|Neural Filters]] are [[concepts/ai-powered-tools|AI-powered tools]] integrated into [[concepts/photoshop|Adobe Photoshop]] that automate [[concepts/photo-enhancement|image enhancement]] and manipulation tasks. Built on [[concepts/artificial-intelligence-models|machine learning models]], they enable photographers and designers to perform complex operations—such as upscaling, detail [[concepts/preservation|preservation]], and [[concepts/style-transfer|style transfer]]—without requiring manual adjustment. These filters represent [[entities/adobe-photoshop|Photoshop]]'s approach to embedding [[concepts/ai-technologies|artificial intelligence]] directly into its core workflow, allowing users to apply sophisticated computational techniques to images efficiently.

## Image Upscaling and Detail Preservation

Photoshop offers two primary neural upscaling options with different computational approaches. [[concepts/ai-powered-upscaling|Generative Upscale]] uses [[concepts/generative-ai|generative AI]] to enlarge images while synthesizing additional visual content, making it suitable for creative interpretations where some detail invention is acceptable. [[concepts/image-size|Preserve Details 2.0]] takes a more conservative approach, focusing on enlarging images while maintaining fidelity to original details and minimizing artifacts. Users can select between these tools depending on whether their priority is creative enhancement or faithful reproduction of source material.

## Style Transfer and Creative Applications

The [[concepts/landscape-mixer|Landscape Mixer]] neural filter applies [[concepts/style|style]] transfer techniques to modify images based on learned aesthetic characteristics. This tool allows users to adjust the stylistic qualities of photographs by referencing learned patterns from landscape imagery, enabling consistent visual treatments across multiple images or selective style application to portions of an image.

Neural Filters operate as part of Photoshop's broader integration of [[concepts/machine-learning|machine learning]] capabilities, allowing these operations to run either locally on a user's machine or through cloud-based processing depending on computational requirements and user preference.
