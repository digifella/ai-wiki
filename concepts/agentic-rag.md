# Agentic RAG

[[concepts/agentic-rag-systems|Agentic RAG]] ([[concepts/answer-generation|Retrieval-Augmented Generation]]) extends [[concepts/traditional-rag|traditional RAG]] with [[concepts/agent-capabilities|agent capabilities]], enabling multi-step [[concepts/reasoning|reasoning]], dynamic [[concepts/acting|tool use]], and context-aware interactions to provide domain-specific answers from curated [[concepts/knowledge-bases|knowledge bases]] rather than general knowledge.

*   Implementation example: [Azure AI guide](https://youtu.be/xXTuxKdzZrI) ([[concepts/azure-innovation-station|Azure Innovation Station]]) using [[concepts/e-books|e-books]] as [[concepts/knowledge-base|knowledge base]]
*   Implementation example: [Cole Medin - RAG 2.0 with Knowledge Graphs](https://youtu.be/p0FERNkpyHE) ([[concepts/rag-20|RAG 2.0]] agentic RAG plus [[concepts/knowledge-graphs|knowledge graphs]]) for advanced agent search in [[concepts/custom-knowledge-bases|custom knowledge bases]]
*   Focuses on combining Agentic RAG with [[concepts/knowledge-graphs|knowledge graphs]] to optimize how agents search and utilize custom [[concepts/knowledge-bases|knowledge bases]]
*   Requires active [[concepts/azure-subscription|Azure subscription]] for deployment
*   Focuses on document-specific [[concepts/document-retrieval|retrieval]] (e.g., [[concepts/e-books|e-books]]) over general knowledge
*   Enables agent-like behavior through structured RAG workflows
*   Guide for creating an [[concepts/ai-agent|AI agent]] using Agentic RAG in [[concepts/azure-ai|Azure AI]] and [[concepts/foundry|foundry]]
