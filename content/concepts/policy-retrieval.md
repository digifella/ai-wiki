# Policy Retrieval

A mechanism for dynamically accessing and delivering policy information in response to user queries, typically through [[concepts/automations|automated systems]].

- **Agent-based implementation**: [[entities/copilot|CoPilot]] [[concepts/agents|Agents]] (currently in preview) perform [[concepts/policy-lookup|policy lookup]] and [[concepts/response-generation|response generation]] as core functions.
- **Agent [[concepts/design|design]] requirements**: Must maintain friendly, helpful tone with clear [[concepts/responses|responses]]; examples include [[entities/georgia-engel|Georgia Engel]]'s Microsoft 365 [[concepts/training|training]] agent for FAQs and task guidance.
- **Current state**: Autonomous agents remain in preview mode with limited [[concepts/deployment|deployment]] capabilities.
