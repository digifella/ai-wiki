# Data Formulator

[[concepts/backend-application|Data Formulator]] is an [[concepts/ai-powered-application|AI-powered application]] developed by [[entities/microsoft|Microsoft]] that generates data visualizations through natural language interfaces. The system utilizes a [[concepts/large-language-model|large language model]] as its computational backend, enabling users to create visual representations by describing their data and intended outputs in conversational language. This approach eliminates the need for [[concepts/writing|writing]] traditional visualization code, thereby lowering the technical barrier for users who lack programming [[concepts/expertise|expertise]] or familiarity with specific visualization libraries.

The application accepts [[concepts/natural-language-descriptions|natural language descriptions]] of datasets and analytical goals, processing these inputs to generate appropriate chart types and layouts. By interpreting user intent directly, it automates the mapping of data fields to visual encodings, allowing for rapid [[concepts/iteration|iteration]] and exploration of data insights without requiring manual configuration of complex software parameters.
