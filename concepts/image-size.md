# Image Size

Image Size is a feature in [[concepts/photoshop|Adobe Photoshop]] that allows users to adjust the dimensions of [[concepts/digital-images|digital images]]. Historically, enlarging images resulted in noticeable quality degradation, as software relied on interpolation algorithms to estimate pixel values for the expanded image. Modern versions of Photoshop have integrated artificial intelligence-driven upscaling tools that enable users to increase image dimensions while maintaining greater visual fidelity than traditional methods.

## AI-Powered Upscaling Tools

Photoshop's Image Size dialog includes machine learning-based upscaling algorithms designed to improve enlargement quality. **Generative Upscale** uses generative AI to intelligently reconstruct detail when scaling images up, allowing for larger enlargements with synthesized content that matches the style and content of the original image. **Preserve Details 2.0** is an algorithm focused on maintaining sharpness and texture definition during upscaling, making it effective for photographs and detailed imagery where clarity is prioritized.

## Practical Application

These AI upscaling options address a longstanding limitation in digital image editing: the difficulty of enlarging images without visible loss of quality. By leveraging machine learning trained on large image datasets, these tools can make informed decisions about how to fill in pixel information at larger sizes. Users can choose between different upscaling methods depending on their specific needs—whether prioritizing detail preservation or generating complementary new content.
