# Instagram Carousel Creation

Instagram [[concepts/carousel-creation|Carousel Creation]] is a content production workflow that combines [[concepts/anthropic-ai|Claude AI]] with [[entities/canva|Canva]] to create multi-slide Instagram posts. The process uses [[concepts/claudemd|Claude]]'s [[concepts/text-generation|text generation]] capabilities to develop carousel content—including headlines, captions, educational sequences, and narrative arcs—while Canva provides design [[concepts/templates|templates]] and visual tools to implement these concepts. This integration streamlines the production of [[concepts/social-media-carousels|carousel posts]], which typically perform well on Instagram's platform due to their interactive nature and capacity to present information across multiple [[concepts/google-slides|slides]].

## Content Development

[[concepts/2026-04-08-anthropic|Claude AI]] generates the conceptual and textual foundation for carousels. Users can prompt [[concepts/claude-ai|Claude]] to brainstorm carousel themes, structure information across multiple [[entities/google-slides|slides]], write compelling copy for each slide, and develop narrative progressions that encourage users to swipe through content. This text-first approach helps creators clarify their message before moving to design.

## Design Implementation

Once content is drafted, creators use Canva to visually execute the carousel. Canva's carousel-specific templates provide [[concepts/standardized-layouts|standardized layouts]] that accommodate the generated text while maintaining visual [[concepts/logical-consistency|consistency]] across slides. Designers can customize colors, [[concepts/typography|typography]], imagery, and [[concepts/branding|branding]] elements while working from [[concepts/claude|Claude]]'s structured content outline.

## Practical Applications

This workflow suits various content types including educational series, product highlights, [[concepts/storytelling|storytelling]] sequences, and engagement-focused posts. The separation of [[concepts/content-creation|content development]] and design allows creators to work efficiently—Claude handles ideation and copy rapidly, while Canva focuses on visual polish and brand consistency.
