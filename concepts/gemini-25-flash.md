# Gemini 2.5 Flash

**[[entities/gemini-25-flash|Gemini 2.5 Flash]]** is a [[concepts/large-language-model|large language model]] variant within the [[entities/google-gemini|Gemini]] family, optimized for [[concepts/speed|speed]] and efficiency. It serves as the underlying API [[concepts/engine|engine]] for various [[concepts/web-tools|agentic frameworks]] and [[concepts/automated-content-creation|automated workflows]].

## Key Capabilities
- High-throughput [[concepts/model-inference|inference]] suitable for real-time applications.
- Supports complex [[concepts/agentic-loops|agentic loops]] and recursive [[concepts/workflow-automation|task execution]].
- Integrates with [[concepts/open-source|open-source]] frameworks like [[concepts/hermes-agent]].

## Integrations & Use Cases

### Hermes Agent Integration
The model powers the backend for **[[entities/hermes-agent|Hermes Agent]]**, an open-source [[concepts/ai-agentic-framework|AI agentic framework]] developed by [[entities/nous-research|Nous Research]]. Specifically, it enables the `/loop` feature, which facilitates [[concepts/automated-recurring-tasks|automated recurring tasks]].
