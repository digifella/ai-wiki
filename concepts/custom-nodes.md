# Custom Nodes

**Custom Nodes** are third-party extensions for [[entities/comfyui]] that expand the base functionality of the [[concepts/node-based-interface|node-based interface]]. They allow users to integrate new models, automate repetitive tasks, and streamline complex image generation pipelines without modifying core code.

## Key Functions
- **[[concepts/ai-driven-workflow-automation|Workflow Automation]]**: Reducing manual steps in generation loops.
- **[[concepts/prompt-based-modeling|Prompt Engineering]]**: Advanced handling of text inputs and conditioning.
- **Model Integration**: Support for specific LoRA, Checkpoint, or control mechanisms not present in the vanilla [[concepts/installation|installation]].
