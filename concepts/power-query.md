# Power Query

An [[concepts/etl-extract-transform-load|ETL (Extract, Transform, Load)]] [[concepts/engine|engine]] used for [[concepts/data-cleaning]] and [[concepts/data-transformation|Data Transformation]] within [[entities/excel]] and Power BI.

## Core Capabilities
- Automates repetitive data manipulation workflows.
- Manages large-scale [[concepts/training-data|datasets]] where manual [[entities/excel]] intervention is impractical or inefficient.
- **[[concepts/data-cleaning|Data Cleaning]] Techniques**:
