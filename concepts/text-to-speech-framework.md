# Text-to-Speech Framework

A [[concepts/text-to-speech-model|text-to-speech]] framework is a software system designed to convert written text into spoken words. These frameworks typically include tools, libraries, and [[concepts/open-standard-protocols|APIs]] that enable developers to integrate text-to-speech functionality into applications.

## Key Features
- **[[concepts/multilingual-speech-synthesis|Voice Synthesis]]**: Converts text into audible speech.
- **[[concepts/customization|Customization]]**: Allows [[concepts/adjustments|adjustments]] to voice characteristics ([[entities/pitch|pitch]], [[concepts/speed|speed]], [[concepts/tone|tone]]).
- **Multi-[[concepts/multilingual-support|language Support]]**: Capable of synthesizing speech in various languages.
- **Integration**: Can be embedded into applications, websites, or devices.
