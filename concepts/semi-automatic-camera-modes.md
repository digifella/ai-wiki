# Semi-Automatic Camera Modes

**Semi-automatic camera modes** refer to camera settings where the photographer manually controls one exposure parameter while the camera automatically calculates the other. This approach balances creative control with operational speed, contrasting with fully Manual Mode or fully Automatic Mode.

## Core Modes
- **[[concepts/aperture|Aperture]] Priority (Av/A):** User sets aperture; camera sets [[concepts/shutter-speed|shutter speed]]. Best for controlling Depth of Field.
- **Shutter Priority (Tv/S):** User sets shutter speed; camera sets aperture. Best for controlling Motion Blur or freezing action.
- **Program Auto (P):** Camera sets both, but allows user to shift the exposure pair (Program Shift) or override ISO.

## Professional Workflow Integration
Recent analysis highlights a strategic preference among professionals for semi-automatic modes over pure manual control in dynamic environments. This preference extends to post-processing workflows where [[concepts/non-destructive-workflow|non-destructive editing]] is prioritized.

### Post-Processing Equivalents
Modern software tools offer "semi-automatic" or intelligent tonal controls that mirror the efficiency of camera modes:
- **[[concepts/adobe-photoshop|Photoshop]] [[concepts/light-adjustment-layer|Light Adjustment Layer]]:** Integrates powerful tonal controls (similar to [[concepts/camera-raw|Camera Raw]]) into a non-destructive layer.
- **Functionality:** Allows for precise adjustment of highlights, [[concepts/shadows|shadows]], [[concepts/whites|whites]], and [[concepts/blacks|blacks]] without permanently altering the base image data.
- **Workflow Benefit:** Provides the "creative control" of manual adjustment with the "operational speed" of automated tonal mapping algorithms.
