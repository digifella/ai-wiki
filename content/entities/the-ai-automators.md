# The Ai Automators

[[entities/philschmid|The AI Automators]] is a video presentation by [[entities/daniel-walsh|Daniel Walsh]] demonstrating the setup and operation of [[concepts/data-embedding|InsightsLM]], an [[concepts/open-source|open-source]] alternative to [[entities/googles-notebooklm|Google's NotebookLM]]. The [[concepts/tutorial|tutorial]] focuses on establishing a fully local [[concepts/adoption|implementation]] of the tool, enabling users to run the system on their own infrastructure rather than relying on [[concepts/cloud-based-services|cloud-based services]].

## Key Features

[[concepts/document-based-interface|InsightsLM]] functions as a local [[concepts/answer-generation|Retrieval-Augmented Generation]] (RAG) system, allowing users to process and extract insights from documents without transmitting data to external servers. By [[concepts/running|running]] [[concepts/agentic-ai|AI agents]] locally, users can maintain [[concepts/privacy|privacy]] and [[concepts/power|control]] over their data while utilizing the same core functionality found in the proprietary [[concepts/ai-integrated-notebooks|NotebookLM]] platform.
