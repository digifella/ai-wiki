# Kiro

[[entities/amazon|Amazon]]'s new [[concepts/ai-code-editor|AI code editor]], [[entities/bolt|Kiro]], is a [[concepts/vs-code-fork|VS Code fork]] positioned within the AI [[concepts/code|code]] editor market. Key details:

- **Identity**: Built as a [[entities/vs-code|VS Code]] fork (requiring significant engineering overhead for updates; Amazon's resources mitigate this)
- **Market Positioning**: Competes with [[entities/cursor|Cursor]] (AI editor) and [[entities/wind-surf|Wind Surf]] (AI editor), both [[concepts/vs-code-forks|VS Code forks]]
- **Strategic Intent**: Analyzed as part of Amazon's broader [[concepts/ai-development|AI development]] tool strategy
