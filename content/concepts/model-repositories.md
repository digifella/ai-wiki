# Model Repositories

[[concepts/open-source-machine-learning|Hugging Face]] is an [[concepts/open-source|open-source]] platform that serves as a centralized hub for [[concepts/artificial-intelligence-models|machine learning models]], datasets, and [[concepts/code|code]]. The platform provides infrastructure for hosting and sharing [[concepts/pre-trained-models|pre-trained models]] across various domains including [[concepts/natural-language-processing|natural language processing]], [[concepts/computer-vision|computer vision]], and [[concepts/speech-recognition|speech recognition]]. Users can access thousands of models contributed by the community, reducing the need to train models from scratch.

## Platform Features

The Hugging Face ecosystem includes tools for model discovery, version [[concepts/power|control]], and collaborative development. The platform supports standard formats and libraries like [[concepts/transformers|Transformers]], enabling developers to download models and integrate them into [[concepts/software|applications]] with minimal [[concepts/setup|setup]]. Model cards on the platform provide documentation about each model's [[concepts/capabilities|capabilities]], limitations, and intended [[concepts/scenarios|use cases]].

## Application Customization

Hugging Face enables [[concepts/customization|customization]] of models for specific use cases through [[concepts/fine-tuning|fine-tuning]] and adapter techniques. Developers can modify pre-trained models using their own datasets to improve performance on domain-specific tasks. The platform also supports Spaces, which allows users to build and deploy interactive applications and demos directly on Hugging Face infrastructure without requiring separate hosting.
