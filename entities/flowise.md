# Flowise

[[concepts/flowise|Flowise]] is an [[concepts/open-source|open-source]] platform for building and deploying LLM-powered applications with a [[concepts/gui-interface|visual interface]].

## Key Features
- Visual workflow builder for LLM chains
- Supports integration with multiple LLM providers
- Extensible through custom [[concepts/nodes|nodes]] and [[concepts/plugins|plugins]]
- Designed for [[concepts/rapid-prototyping|rapid prototyping]] of [[concepts/ai-powered-applications|AI applications]]
