# Intelligent Tools

Intelligent Tools refers to a suite of [[concepts/ai-powered-applications|AI-powered applications]] and features integrated across Google's product ecosystem. These tools leverage [[concepts/generative-ai|generative AI]] capabilities to enhance [[concepts/productivity|productivity]], [[concepts/content-creation|content creation]], and information processing across different domains. By embedding AI assistance directly into existing platforms, Google has made these capabilities more accessible to users working within familiar workflows rather than requiring separate applications.

## Key Products

[[concepts/google-vids|Google Vids]] is a [[concepts/video-creation|video creation]] tool that uses generative AI to automate aspects of video production, such as script generation and asset selection. [[concepts/ai-integrated-notebooks|NotebookLM]] serves as an AI-first notebook that allows users to upload documents and interact with them through conversational queries, enabling deeper analysis and [[concepts/summarization|summarization]] of personal knowledge bases. [[concepts/full-stack-applications|Google AI Studio]] provides a platform for developers to experiment with and build applications using Google's [[concepts/demystifying-llms|large language models]], offering tools for [[concepts/prompt-based-modeling|prompt engineering]] and [[concepts/ai-model-fine-tuning|model fine-tuning]].

These products collectively represent Google's strategy to integrate generative AI into both consumer and developer workflows. The focus remains on augmenting [[concepts/human-performance|human capabilities]] by reducing friction in content creation and [[concepts/knowledge-bases|information retrieval]] tasks. This approach aims to make advanced AI functionalities available to a broader audience through intuitive interfaces and [[concepts/hidden-engineering|seamless integration]] with existing Google services.
