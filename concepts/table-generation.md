# Table Generation

Table Generation is a feature within NotebookLM that automatically creates structured data tables from various source materials. The system extracts information from inputs such as YouTube videos, websites, and uploaded documents, then organizes the extracted content into a tabular format. This capability enables users to synthesize and compare data without the need for manual data entry.

## Process and Functionality

The process involves parsing unstructured or semi-structured information from multiple sources and converting it into organized rows and columns. By transforming diverse content types into a consistent grid structure, the feature allows for easier analysis and cross-referencing of facts. Users can generate these tables to summarize key points, extract specific details, or map relationships between different pieces of information found across their uploaded sources.
