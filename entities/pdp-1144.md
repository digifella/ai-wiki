# Pdp 1144

The PDP-11/44 is a 16-bit minicomputer manufactured by Digital Equipment Corporation (DEC), released in 1979 as part of the widely used PDP-11 series. It occupied the mid-range segment of the PDP-11 lineup, offering enhanced capabilities compared to earlier models while remaining more accessible than the highest-end offerings. The system featured improved memory management and floating-point processing capabilities, making it suitable for scientific, educational, and commercial applications.

## Technical specifications

The PDP-11/44 was built around the KA11-B processor module, which utilized the PDP-11/45 architecture but with a faster clock speed. It supported up to 512 KB of main memory and included a hardware multiply and divide unit, which significantly accelerated arithmetic operations for scientific computing. The system typically utilized the UNIBUS or Q-Bus architecture for peripheral connectivity, allowing for flexible expansion with various storage and I/O devices common to the era.
