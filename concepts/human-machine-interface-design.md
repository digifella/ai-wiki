# Human-machine interface design

Human-machine interface (HMI) design focuses on optimizing the interaction between users and complex systems, prioritizing [[concepts/cognitive-load|cognitive load]] reduction, intuitive [[concepts/systems|feedback loops]], and error tolerance. In high-stakes environments like aerospace, effective HMI design is critical for situational [[concepts/conscious-thought|awareness]] and operational safety.

## Key Principles
- **Cognitive Fit**: Aligning interface metaphors with user mental models.
- **Information [[concepts/hierarchy|Hierarchy]]**: Prioritizing critical data visibility over secondary metrics.
- **[[concepts/feedback|Feedback]] Latency**: Minimizing delay between action and system response.
