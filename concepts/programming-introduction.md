# Programming Introduction

**Programming** is the process of designing and building an executable computer program to accomplish a specific computing result. It involves tasks such as analysis, [[concepts/algorithm|algorithm]] development, and [[concepts/verification|verification]] of [[concepts/accuracy|correctness]].

## Core Concepts
- **Syntax**: The set of rules that defines the combinations of symbols that are considered to be a correctly structured document or fragment in that language.
- **Semantics**: The meaning or [[concepts/open-source-philosophy|logic]] behind the code.
- **Variables & Data Types**: [[entities/storage|Storage]] locations paired with symbolic names, containing some known or unknown quantity of information or value, referred to as the variable's value.

## Key Languages & Paradigms
- [[entities/python]]: High-level, interpreted, general-purpose.
- [[concepts/javascript]]: High-level, often compiled, concurrent, dynamic, weakly typed.
- R: [[concepts/statistical-computing|Statistical computing]] and [[concepts/webgpu|graphics]]; vector-based language.
- Data Structures: Arrays, Linked Lists, Trees, Hash Tables.
- [[concepts/algorithms|Algorithms]]: Sorting, Searching, Recursion.
