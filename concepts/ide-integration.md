# IDE integration

Integration of intelligent agents within IDEs to enhance professional [[concepts/development-workflows|development workflows]] without replacing [[entities/developer|developer]] [[concepts/expertise|expertise]].

- [[entities/junie|Junie]], JetBrains' new [[concepts/smart-coding-agent|smart coding agent]], positions itself as an "[[concepts/anti-vibe-coding|Anti-Vibe Coding]]" tool specifically for [[concepts/professional-software-engineers|professional software engineers]] (not for non-coders).
- Avoids "[[concepts/vibe-coding|vibe coding]]" trends by focusing on deeply integrated, context-aware assistance rather than generating large codebases from scratch.
- Designed to complement [[concepts/developer|developer]] workflow within IDE rather than automate entire features.
- Part of JetBrains' strategy to provide professional-grade AI assistance in JetBrains ecosystem.
- [[entities/kombai|Kombai]], the first [[concepts/ai-agent|AI agent]] purpose-built for [[concepts/frontend-development|frontend development]], integrates into IDEs ([[entities/vs-code|VS Code]], [[concepts/cursor|Cursor]], [[entities/windsuf|Windsuf]]) and outperforms general tools (e.g., [[entities/github|GitHub]] [[entities/copilot|Copilot]], [[entities/codepal|CodePal]], [[concepts/gemini|Gemini]]) in frontend tasks (e.g., code review: 72% [[concepts/success|success]] vs. 30-50%).
- [[concepts/bmad-method|BMAD method]] for [[concepts/coding|coding]]: A universal [[concepts/ai-agent-framework|AI agent framework]] for [[concepts/agile-ai-driven-development|Agile AI-driven development]], addressing the lack of proper [[concepts/software-development-process|software development process]] in [[concepts/ai-generated-code|AI-generated code]].
