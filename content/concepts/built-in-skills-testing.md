# Built In Skills Testing

Built In Skills Testing refers to the integrated [[concepts/testing|testing]] capabilities within [[concepts/claude-code-20|Claude Code 2.0]], [[entities/anthropic-institute|Anthropic]]'s [[concepts/ai-coding-assistance|AI-assisted coding]] platform. These testing features are designed to validate code functionality as part of the development workflow, allowing developers to verify their implementations without leaving the [[concepts/coding|coding]] environment.

## Core Features

Claude Code 2.0 introduced several updates that enhance the testing and [[concepts/automation|automation]] capabilities of the platform. These include improved loop functionality for iterative processes, scheduled task execution for automated workflows, and integration with [[entities/google-workspace|Google Workspace]] for collaborative [[concepts/developer-platforms|development environments]]. The [[concepts/skills-20|Skills 2.0]] framework further extended these capabilities to enable more sophisticated code validation and testing [[concepts/scenarios|scenarios]].

The built-in testing approach represents an effort to streamline the development process by combining code generation, execution, and validation within a single interface. This integration aims to reduce the [[concepts/friction|friction]] between [[concepts/writing|writing]] code and confirming its correctness, though the scope and specific capabilities of the testing system depend on the particular [[concepts/implementation-details|implementation details]] within Claude Code 2.0.
