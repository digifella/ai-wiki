# NotebookLM Infographic

[[concepts/ai-integrated-notebooks|NotebookLM]] is [[concepts/google-search|Google]]'s [[concepts/ai-driven-research|AI-powered research]] and note-taking platform that generates [[concepts/infographic-design|infographics]] from source materials. These infographics visually summarize key information and concepts, making them useful for presentations and educational content. The platform uses [[entities/gemini-models|Gemini AI]] to analyze uploaded documents, web content, and [[concepts/notes|notes]], then automatically creates visual representations of the material.

## Converting to Interactive Web Applications

NotebookLM-generated infographics can be transformed into [[concepts/interactive-html-web-applications|interactive web applications]] through [[concepts/integration|integration]] with [[entities/gemini-ai|Gemini AI]]. This [[concepts/workflow|workflow]] typically involves extracting the [[concepts/infographic|infographic]] [[concepts/structure|structure]] and data, then using [[concepts/gemini|Gemini]] to generate HTML, CSS, and JavaScript [[concepts/code|code]] that recreates the visualization as an interactive experience. Users can input the infographic details or use Gemini to analyze the original infographic image and produce web-ready code that maintains the original [[concepts/design|design]] while adding interactivity features.

## Design and Customization

The platform supports [[concepts/customization|customization]] of [[concepts/infographic-creation|infographic design]] to suit professional presentation [[concepts/open-standards|standards]]. Users can adjust visual elements, branding, and layout through [[concepts/notebooklm|NotebookLM]]'s interface or further refine outputs using Gemini AI prompts. This flexibility allows creators to align generated infographics with specific organizational guidelines or project requirements before conversion to other formats.

## Related Workflows

NotebookLM's [[concepts/capabilities|capabilities]] extend beyond infographics to other content types, including [[concepts/mind-maps|mind maps]] and slide presentations. Similar conversion processes can transform these outputs into [[concepts/interactive-html-sites|interactive HTML sites]] or unwatermarked video content using Gemini AI assistance, providing multiple pathways for repurposing AI-generated research visualizations across different media formats.
