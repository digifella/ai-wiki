# Open Webui

Open Webui is a web-based interface designed to facilitate the [[concepts/local-deployment|local deployment]] and interaction with [[concepts/large-language-model-llm|large language models]] (LLMs) on personal computers and mobile devices. It provides an accessible way for users to run [[concepts/models|models]] like [[entities/llama-31|Llama 3.1]] and [[entities/mistral|Mistral]] without relying on [[concepts/cloud-based-services|cloud-based services]] or external APIs, enabling private [[concepts/inference|inference]] on consumer [[concepts/hardware|hardware]].

## Core Functionality

The platform enables users to download, configure, and run [[concepts/open-source|open-source]] language models locally. By abstracting away much of the technical complexity involved in model [[concepts/setup|setup]] and management, Open Webui allows users to interact with these models through a user-friendly [[concepts/chat-application|chat interface]], similar to commercial LLM [[concepts/software|applications]] but operating entirely on [[concepts/local-infrastructure|local infrastructure]].

## Privacy and Control

[[concepts/running|Running]] models through Open Webui ensures that user queries and interactions remain on the user's device rather than being transmitted to external servers. This approach gives users direct [[concepts/power|control]] over their data and [[concepts/model-behavior|model behavior]] while avoiding subscription fees associated with [[concepts/cloud-ai|cloud-based AI]] services.
