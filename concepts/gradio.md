# Gradio

**[[concepts/azure-portal|Gradio]]** is an [[concepts/open-source|open-source]] [[concepts/python|Python]] library designed to quickly build and share [[concepts/machine-learning|machine learning]] demos. It allows developers to create user-friendly web interfaces for their models with minimal code, [[concepts/access-democratization|democratizing access]] to complex functionalities without requiring specialized [[concepts/frontend-development|front-end]] or animation [[concepts/skills|skills]].

## Key Features
- **[[concepts/rapid-prototyping|Rapid Prototyping]]:** Create functional UIs for [[concepts/ai-models|ML models]] in minutes.
- **No Front-End Required:** Handles HTML, CSS, and [[concepts/javascript|JavaScript]] generation automatically.
- **Sharing:** Easily share demos via public links or local networks.
- **Integration:** Works seamlessly with popular ML frameworks like TensorFlow, PyTorch, and scikit-learn.
