# Local AI Assistant

A [[concepts/software|software]] application that operates entirely on a user's device, providing [[concepts/privacy|privacy]]-preserving, always-available assistance without requiring [[concepts/cloud-integration|cloud connectivity]] for core functionality.

## Key Characteristics
- **[[concepts/local-execution|Local Execution]]**: No internet dependency for core operations
- **24/7 Availability**: Runs continuously without [[concepts/cloud-based-solutions|cloud services]]
- **[[concepts/autonomous-task-execution|Autonomous Task Execution]]**: Handles [[concepts/complex-workflows|complex workflows]] independently
- **[[concepts/privacy|Privacy]] Focus**: User data remains on-device

## Examples
- **[[concepts/openclaw|OpenClaw]]** (formerly [[concepts/local-ai-assistants|ClawdBot]]/MoltBot): [[concepts/local-ai|Local AI]] assistant described as a "blank [[entities/canvas|canvas]]" with infinite potential.
