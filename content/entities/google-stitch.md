# Google Stitch

An [[concepts/design|AI-native design]] [[entities/canvas|canvas]] engineered for the creation of UX for [[concepts/software|applications]] and websites.

### Key Features
- **[[concepts/vibe-design|Vibe Design]]:** Employs a "vibe [[concepts/design|design]]" methodology, allowing users to generate complex interfaces through natural language interaction.
- **[[concepts/conversational-interface|Conversational Interface]]:** Functions as an [[concepts/ai-assistant|AI assistant]], enabling the generation of UX assets through [[concepts/dialogue|dialogue]] rather than manual manipulation.
- **AI-Native [[concepts/workflow|Workflow]]:** Streamlines the [[concepts/design-thinking|design process]] by treating the creation of web and app interfaces as a generative, conversational task.
- **Free [[entities/figma|Figma]] Alternative:** Evolved from a basic screenshot tool to a robust, free [[concepts/ai-assisted-prototyping|AI-native design canvas]] positioning it as a direct competitor to Figma.

### Workflow Impact
- **Process [[concepts/ai-workflow|Optimization]]:** Enables text-based inputs (e.g., [[concepts/markdown|markdown]]) to replace traditional, high-[[concepts/cost|cost]] design meeting-heavy workflows.
