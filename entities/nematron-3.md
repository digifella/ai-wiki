# Nemotron 3

Nemotron-3 is a family of open-source large language models developed and released by NVIDIA. The collection comprises multiple model variants designed to address diverse computational and deployment contexts, ranging from resource-constrained environments to more capable configurations. All models within the family are made available under open-source licensing terms.

## Nemotron-3 Nano

The Nemotron-3 Nano is a 30-billion-parameter variant within the Nemotron-3 family. This specific model size represents a balance between computational efficiency and task performance, making it suitable for deployment in environments with limited hardware resources while maintaining competitive capability for various natural language processing tasks.
