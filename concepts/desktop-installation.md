# Desktop Installation

## Overview
Process of installing software applications on a local desktop environment. For [[entities/ai]] tools, this often involves managing dependencies, [[concepts/python|Python]] environments, and [[concepts/gpu-based-processing|GPU acceleration]] configurations.

## ComfyUI
**[[concepts/comfyui|ComfyUI]]** is a free, [[concepts/open-source|open-source]] tool for generating AI content including images, videos, [[concepts/audio-modality|audio]], and 3D models. It utilizes a **Node-Based** workflow interface.

- **Key Features:**
  - Supports multiple media types (image, video, [[concepts/audio|audio]], 3D).
  - Visual node-based architecture allows for customizable generation pipelines.
