# Remove Tool

The Remove Tool is a feature in [[concepts/photoshop|Adobe Photoshop]] introduced in the July 2025 update, available in both the general release and [[concepts/beta-version|Photoshop Beta]] versions. It was highlighted as one of five significant features in that release cycle designed to improve user workflow and productivity.

## Functionality

The Remove Tool functions as a content-aware removal feature within Photoshop, enabling users to delete unwanted elements from [[concepts/images|images]]. The tool works by analyzing surrounding pixels and automatically filling removed areas with contextually appropriate content, reducing the need for manual retouching work.

## Availability

As part of the July 2025 update, the Remove Tool became available to Photoshop users across both stable and beta release channels, making it accessible to users seeking early access to new features as well as those preferring production-ready [[concepts/software|software]].
