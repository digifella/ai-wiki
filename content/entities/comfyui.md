# Comfyui

ComfyUI is a node-based interface for [[concepts/running|running]] [[concepts/generative-ai-models|generative AI models]] locally on personal computers. It provides a visual workflow system that allows users to connect different processing nodes to create custom pipelines for image and [[concepts/video-generation|video generation]] tasks without requiring extensive programming knowledge.

## Video Generation with WAN2.2

ComfyUI supports the WAN2.2 model, a recent advancement in [[concepts/ai-generated-videos|generative video]] technology that enables both [[concepts/text-to-video|text-to-video]] and [[concepts/image-to-video-model|image-to-video generation]] locally. The WAN2.2 model can be installed and executed within the ComfyUI environment, allowing users to generate video content from text prompts or transform existing [[concepts/images|images]] into video sequences on their own [[concepts/hardware|hardware]] rather than relying on [[concepts/cloud-computing|cloud services]].

## Setup and Usage

Users can install the WAN2.2 models within ComfyUI through standard package integration methods. Once configured, the models become available as nodes within the interface, where they can be connected to input nodes (text prompts or images) and output nodes to process and generate video content through a visual workflow.
