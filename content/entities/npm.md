# npm

Node [[concepts/package-manager|Package Manager]]; the default package manager for [[entities/nodejs|Node.js]].

## Core Functionality
- Manages JavaScript dependencies and package lifecycles.
- Facilitates global installation of [[concepts/cli|command-line]] interface (CLI) tools.
- **Recent Tooling Updates:**
    - Used to update [[entities/claude-code]] via `npm install -g @anthropic-ai/claude-code`.
