# Local installation

[[concepts/deployment|Deployment]] of [[concepts/software|software]] or [[concepts/models|models]] on a user's own device/server rather than [[concepts/cloud-based-solutions|cloud services]], offering [[concepts/power|control]], [[concepts/privacy|privacy]], and reduced internet dependency.

**Examples:**
- [[entities/fahd-mirza|Fahd Mirza]] - Videorefer model [[concepts/running|running]] locally: Step-by-step guide for installing [[entities/alibaba|Alibaba]]'s [[concepts/videorefer-suite|VideoRefer Suite]] ([[concepts/apache-2-license|Apache 2 license]]), a video model enhancing LLMs with [[concepts/spatial-temporal-object-understanding|spatial-temporal object understanding]] through fine-grained [[concepts/object-tracking|object tracking]] in videos.
- Zero2launch - Guide for local [[concepts/n8n|n8n]] deployment via [[concepts/docker|Docker]], integrating AI [[concepts/agentic-ai|agents]] with the [[concepts/model-context-protocol|Model Context Protocol (MCP)]] for seamless interaction with [[concepts/external-tools|external tools]] and [[concepts/api|APIs]].
