# Layer Styles

Layer Styles are a set of non-destructive effects and adjustment tools in [[concepts/photoshop|Adobe Photoshop]] that modify the [[concepts/presence|appearance]] and blending behavior of individual layers. Rather than permanently altering [[concepts/digital-images|pixel data]], Layer Styles apply visual effects—such as [[concepts/shadows|shadows]], glows, strokes, bevels, and overlays—as editable properties that can be modified or removed at any time. This non-destructive approach allows designers and photographers to [[concepts/scientific-experiment|experiment]] with effects while preserving the original layer content.

## Common Effects

Layer Styles include several standard effect categories. Drop Shadow and Inner Shadow add depth through shadow placement. Outer [[entities/glow|Glow]] and Inner Glow create luminous halos around layer content. Stroke applies colored or patterned outlines, while Bevel and Emboss create three-dimensional surface effects. Satin, Color Overlay, Gradient Overlay, and Pattern Overlay apply surface treatments, and Outline provides additional [[concepts/image-contrast|edge definition]] options.

## Blend If Settings

The [[concepts/blend-if-sliders|Blend If]] feature within Layer Styles controls layer [[concepts/opacity|transparency]] based on brightness and color values. This slider-based system allows layers to blend selectively—either hiding or revealing portions of a layer based on tonal ranges in the active layer or underlying layers. [[concepts/blend-if|Blend If]] operates independently of layer opacity, enabling sophisticated [[concepts/digital-compositing|compositing]] effects without additional [[concepts/layer-masks|layer masks]].

Layer Styles can be saved as presets, copied between layers, and scaled proportionally across different image sizes, making them valuable for maintaining visual [[concepts/logical-consistency|consistency]] across multiple design elements or projects.
