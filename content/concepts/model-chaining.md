# Model chaining

Model chaining is a technique in AI where multiple models or components are sequentially connected to process [[concepts/complex-tasks|complex tasks]], leveraging specialized capabilities of each model through coordinated execution.

## Examples
- **Google Opal (Experimental)**: [[entities/google-labs|Google Labs]]' experimental tool enabling natural language description of AI mini-apps, chaining multiple models together to create functional [[concepts/software|applications]] without code.
