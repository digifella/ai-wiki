# Icloud

Icloud is a project focused on building a low-[[concepts/cost|cost]] [[entities/ubuntu|Ubuntu]]-based [[concepts/media-server|media server]] as an alternative to subscription-based [[concepts/streaming-services|streaming services]]. The project aims to provide users with a self-hosted [[concepts/solution|solution]] that can consolidate media consumption while minimizing ongoing costs, with estimates suggesting a complete [[concepts/setup|setup]] can be achieved for under $100.

## Purpose and Scope

The primary goal of the Icloud project is to demonstrate how individuals can reduce dependence on commercial [[concepts/movie-streaming|streaming platforms]] such as [[concepts/netflix|Netflix]] by deploying their own [[entities/ubuntu-media-server|Ubuntu media server]]. This approach allows users to maintain greater [[concepts/power|control]] over their media libraries and eliminates recurring subscription fees over time.

## Technical Implementation

The project utilizes Ubuntu as its operating system foundation, leveraging its stability and [[concepts/open-source|open-source]] [[entities/nature|nature]] to create a functional media server environment. The documentation includes video tutorials and technical guides that walk through the setup and configuration process for users with varying levels of technical expertise.
