# Manual Control Mode

A state where the user maintains direct oversight and [[concepts/decision-making|decision-making]] authority over [[concepts/ai-models|AI systems]], preventing uncontrolled automation. Essential for mitigating [[concepts/ai-hallucinations|AI hallucinations]], ethical risks, and loss of agency.

## Key Integration: Jeff Su's "Cockpit Rule"
- **Mental model for [[concepts/ai-delegation|AI delegation]]**: Determines when to *delegate* (AI handles routine tasks), *collaborate* (AI augments human judgment), or *avoid* AI entirely (high-stakes decisions requiring human nuance).
- **Directly enables Manual Control Mode**: Prevents [[concepts/autopilot-mode|over-reliance on AI]] by maintaining human-in-the-[[concepts/loop|loop]] decision points.
- **Baseline expectation**: "Using AI" is now table stakes (like Word [[concepts/excellence|proficiency]]); Manual Control Mode separates practitioners who *own* AI from those *controlled by* it.
