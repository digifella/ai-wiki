# Context engineering

The practice of structuring and managing [[concepts/contextual-information|contextual information]] to guide [[concepts/ai-models|AI systems]] toward [[concepts/excellence|high-quality]], production-ready outputs in [[concepts/software-engineering|software development]]. It bridges the gap between raw AI [[concepts/ai-coding|code generation]] and professional development standards by establishing clear [[concepts/evolutionary-pressures|environmental constraints]], data pipelines, and process integration.

## Key developments
- **[[concepts/bmad-method|BMAD method]] for [[concepts/coding|coding]]**: A universal [[concepts/ai-agent-framework|AI agent framework]] for [[concepts/agile-ai-driven-development|Agile AI-driven development]], introduced via [video](https://youtu.be/fD8NLPU0WYU) (see 2026 04 14 [[entities/bmad-code|BMAD method]] for [[concepts/coding|coding]]).
  - Addresses evolution from simple [[concepts/prompt-chaining|prompt chaining]] to structured [[concepts/agent-harness-engineering|Agent Harness Engineering]].
- **[[concepts/anthropic-ai|Anthropic Claude]] 5 Optimization**: Significant shifts in [[concepts/ai-performance-optimization|context engineering]] for Claude 5 models (Opus 5, Sonnet 5, Fable 5) focusing on efficient [[concepts/system-prompt-optimization|system prompt optimization]].
  - Details on these architectural and contextual improvements are documented in [[lab-notes/2026-07-30-Anthropic-Claude-5-Efficient-Context-Engineering-and-Sys|Anthropic Claude 5: Efficient Context Engineering and System Prompt Optimization]].
  - Emphasizes reducing context window waste while maintaining high-fidelity [[concepts/instruction-following|instruction adherence]].
