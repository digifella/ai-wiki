# Recurring Tasks

Recurring tasks are a productivity feature in AI-powered applications and workflow tools that automate repetitive actions on a predetermined schedule. Rather than manually executing the same action multiple times, users configure tasks to run automatically at specified intervals or times. This approach reduces manual overhead and improves consistency in routine operations.

Typical applications of recurring tasks include scheduling regular reports, sending periodic reminders, updating data at set times, and generating automated notifications. In the context of modern software platforms, this functionality allows users to maintain operational continuity without constant intervention.

Google Gemini has introduced a Scheduled Actions feature within its web application, enabling users to schedule these tasks directly through the interface. This integration simplifies the setup process for users who require automated workflows, aligning with broader trends in infrastructure tools that prioritize ease of use and accessibility.
