# Owasp

OWASP (Open Worldwide Application Security Project) is a nonprofit foundation dedicated to improving software security through education, tools, and community collaboration. Founded to address the growing need for secure software development practices, the organization develops and maintains security guidance, standards, and best practices for software developers, security professionals, and organizations worldwide. Its mission focuses on providing practical, open-source resources that help individuals and enterprises build, purchase, and maintain secure applications.

The organization is best known for its open-source projects and community-driven initiatives that address critical vulnerabilities in application security. Among its most prominent contributions is the OWASP Top 10, a standard awareness document for developers and web application security. It represents a broad consensus about the most critical security risks to web applications and serves as a foundational reference for security training and testing.

In recent years, OWASP has expanded its scope to address emerging technologies, including artificial intelligence. The organization recently published security guidance specifically tailored for AI Agentic Applications, highlighting the OWASP Top 10 Security Risks for AI Agentic Applications. This effort reflects the foundation's ongoing commitment to adapting its security frameworks to cover new attack vectors and technological landscapes as they evolve.
