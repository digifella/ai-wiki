# OpenAI Codex

[[concepts/codex|OpenAI Codex]] is an AI system developed by OpenAI that translates natural language [[concepts/instructions|instructions]] into executable code. Built on [[concepts/large-language-model|large language model]] technology, Codex was trained on a broad dataset of publicly available code and serves as a specialized tool for [[concepts/code-generation|code generation]] tasks. The system can understand and generate code across multiple programming languages, making it applicable to a wide [[concepts/range|range]] of development contexts.

## Applications and Products

Codex powers several developer-facing tools and [[concepts/software|applications]]. Most notably, it serves as the underlying engine for [[concepts/auto-completion-suggestions|GitHub Copilot]], an AI pair programmer that provides code completion suggestions within code editors. Beyond [[concepts/ide-integration|IDE integration]], Codex has been deployed in autonomous desktop applications that can perform [[concepts/complex-tasks|complex tasks]] through agentic [[concepts/reasoning|reasoning]] and [[concepts/ai-driven-workflow-automation|workflow automation]], extending its use beyond traditional code completion.

## Technical Capabilities

The system demonstrates proficiency in understanding [[concepts/natural-language-descriptions|natural language descriptions]] and translating them into functional code. This capability enables both direct code generation from text prompts and the automation of multi-step workflows that combine reasoning with [[concepts/code-execution|code execution]]. While Codex excels at code-related tasks, its effectiveness compared to other [[concepts/large-language-model-llm|large language models]] varies depending on the specific application domain and use case.
