# Personal AI Assistant

A personal [[entities/ai-assistant|AI assistant]] is a self-hosted [[concepts/software|software]] [[entities/agent|agent]] that operates on user-controlled infrastructure to perform tasks, manage information, and interact with external services via natural language.

## Key Features
- Self-hosted (runs on user's infrastructure, no third-party data processing)
- Integrates with [[concepts/productivity-tools|productivity tools]]: [[entities/gmail|Gmail]], [[entities/asana|Asana]], [[entities/slack]], [[entities/telegram]]
- Executes [[concepts/real-world-tasks|real-world tasks]] through [[concepts/chat-application|chat interface]]
- Supports custom [[concepts/automation-tools|workflow automation]]

- [[concepts/local-ai-assistants|Clawdbot]] ([[concepts/openclaw|OpenClaw]]): [[concepts/self-hosted-ai-assistant|Self-hosted AI assistant]] connecting to Gmail, Asana, [[entities/slack]], and [[entities/telegram]] for task execution via chat.
