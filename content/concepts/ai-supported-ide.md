# AI-supported IDE

An evolution of the traditional Integrated [[concepts/coding-workspace|Development Environment]] (IDE) that incorporates [[concepts/large-language-models|Large Language Models]] (LLMs) to automate and augment the [[concepts/software|software]] development lifecycle.

## Core Capabilities
- **Automated Development**: Simplifies building [[concepts/software|applications]], fixing existing [[concepts/code|code]], and generating new code from diverse inputs.
- **Productivity Multiplier**: Aimed at providing up to 10x productivity gains for both professional developers and non-coders.
- **[[concepts/workflow|Workflow]] [[concepts/integration|Integration]]**: Seamlessly handles [[concepts/debugging|debugging]], refactoring, and [[concepts/rapid-prototyping|rapid prototyping]].

## Notable Implementations & Tools
- **[[entities/codellm|CodeLLM]]**: An AI-powered code editor specifically designed to maximize [[entities/developer|developer]] throughput and streamline complex [[concepts/coding|coding]] tasks.
- **[[concepts/claude-code|Claude Code]] 4.1**: A significant tool within the modern `[[concepts/ai-coding|AI coding]]` ecosystem.
