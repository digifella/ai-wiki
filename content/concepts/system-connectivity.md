# System Connectivity

System connectivity refers to the ability of different computers, [[concepts/software|software]] applications, and networks to communicate with and share information with each other. In the context of [[concepts/ai-assisted-coding|Claude Code]], it describes how the [[entities/ai-assistant|AI assistant]] connects to various tools, platforms, and systems to perform tasks beyond simple text conversation. For non-technical users, it's helpful to think of system connectivity as similar to how different appliances in a home can work together—a smart thermostat can communicate with your phone, which communicates with your home network, and so on.

## How It Works in Practice

When you interact with Claude Code, system connectivity allows the AI to access external resources and integrate with existing workflows. This might include connecting to databases, retrieving information from websites, or [[concepts/code-execution|executing code]] that interacts with other software. Rather than operating in isolation, Claude Code can pull in information and execute actions across multiple connected systems, making it more useful for complex, real-world tasks.

## Why It Matters

Understanding system connectivity helps non-technical users appreciate what AI assistants can accomplish. Instead of being limited to generating text, connected systems enable AI to be more practical—automating routine work, pulling current information, or integrating with tools you already use. This connectivity is foundational to how modern [[entities/ai-tools|AI tools]] add practical value to both personal and professional environments.
