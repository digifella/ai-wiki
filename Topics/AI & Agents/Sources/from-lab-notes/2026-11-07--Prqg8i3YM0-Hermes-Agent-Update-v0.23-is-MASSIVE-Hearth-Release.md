### Summary
**Main Topic**
The video provides a comprehensive update on Hermes Agent v0.23.0, also known as "The Hearth Release." The speaker discusses major updates focused on centralization within the Hermes desktop app, browser workspaces, multi-machine management, and enhanced group chat control.

**Key Points Discussed**
- **Browser Workspace and Multi-Machine Management:** Hermes gateway can now serve the desktop workspace in a browser tab. The speaker explains that registered gateways stay connected while the window is open, allowing users to run background tasks on home servers while working locally on laptops.
- **Group Chat and Sub-Agent Control:** The update brings new practical features to group chats, including lead bots to choose who answers unaddressed messages, room purposes and shared notes, and scheduled deliveries. Additionally, the new advanced delegation plugin enables granular control over models and profiles for sub-agents.
- **Terminal and Plugin Improvements:** Hermes terminal now supports inline images and conversation rewinds. Plugin maintenance is simplified with a bulk update command, optional auto-update settings, and official integrations for meshy and ElevenLabs. Paid MCP tools now support declared prices and spending limits.
- **Upgrade Considerations and Requirements:** The speaker highlights that old browser tools have been removed, requiring prompts and skills to use `browser.exec`. The MCP server launch command has also changed from `hermes mcp serve` to `hermes mcp-serve`. Desktop requirements include macOS 13 or later, or 64-bit Windows.

**Conclusion/Takeaways**
The Hearth Release brings significant centralization and utility improvements to Hermes Agent, making multi-machine and multi-agent workflows more seamless. Users are advised to review their custom browser instructions and MCP server commands before updating to ensure compatibility. Overall, the update offers powerful new tools for better control over AI agents, chats, and automated tasks.
