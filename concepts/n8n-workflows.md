# N8n Workflows

N8n is a workflow automation platform that enables organizations to build data pipelines connecting diverse applications and services. N8n workflows consist of nodes representing individual operations or integrations, linked together to form end-to-end processes. The platform provides a visual builder interface that allows both technical and non-technical users to design, test, and deploy automation without extensive coding.

## Document Processing for AI Agents

N8n workflows facilitate the integration of diverse file formats into AI agents through Retrieval-Augmented Generation (RAG) architectures. By leveraging specialized document parsing tools such as Docling, LlamaParse, and Mistral OCR, these workflows can extract structured data from complex inputs including PDFs, images, and scanned documents. This capability ensures that unstructured content is accurately processed and indexed, allowing AI agents to retrieve relevant context for more precise and informed responses.
