# Dataset Curation

Dataset curation involves the systematic collection, [[concepts/organization|organization]], and [[concepts/preparation|preparation]] of data for machine [[concepts/learning|learning]] and [[concepts/ai-powered-applications|AI applications]]. In the context of security infrastructure and data processing pipelines, effective curation ensures that datasets meet quality [[concepts/open-standards|standards]] and are suitable for their intended [[concepts/scenarios|use cases]].

## OCR and Data Extraction

Optical character recognition (OCR) plays a significant role in dataset curation by converting [[concepts/images|images]] of text and [[concepts/json-structuring|structured data]] into machine-readable formats. The Nanonets OCR Small model represents an [[concepts/open-source|open-source]] approach to this problem, specifically designed for extracting tabular data and converting it into text suitable for retrieval-augmented generation (RAG) systems. This type of tool is particularly valuable when working with scanned documents, PDFs, or images containing structured information that needs to be integrated into larger knowledge systems.

## Application in RAG Systems

Dataset curation becomes especially critical when preparing data for RAG (retrieval-augmented generation) [[concepts/software|applications]], which rely on accurate, well-organized information sources. By using specialized OCR models to extract and standardize tabular data, organizations can build more reliable datasets that improve the [[concepts/accuracy|accuracy]] and relevance of AI system [[concepts/responses|responses]]. The availability of open-source solutions in this area reduces barriers to implementation and allows for greater [[concepts/customization|customization]] based on specific security and infrastructure requirements.
