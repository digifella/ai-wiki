# Bright Data

Bright Data is an MCP ([[concepts/external-tools|Model Context Protocol]]) server designed to facilitate [[concepts/web-crawling|web data extraction]] and [[concepts/scraping|scraping]] capabilities. It integrates with [[concepts/ai-development|AI development]] environments, particularly the [[concepts/autonomous-coding|Gemini CLI]] and [[entities/claude-desktop|Claude Desktop]], enabling users to access web data collection features through these interfaces.

## Integration with MCP Servers

The server functions as part of the broader Model Context Protocol ecosystem, which allows AI assistants and [[concepts/cli-tools|CLI tools]] to connect with external services and data sources. When configured with the Gemini CLI or Claude Desktop, Bright Data enables these tools to perform web scraping and [[concepts/information-extraction|data extraction]] tasks as part of their workflow.

## Configuration and Use

Users can configure Bright Data as an [[concepts/mcp-server|MCP server]] within their [[concepts/coding-workspace|development environment]] to enhance the capabilities of their AI assistants. This setup allows for programmatic access to web data extraction features, supporting tasks that require gathering information from websites or online sources.
