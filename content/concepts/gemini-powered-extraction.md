# Gemini-powered extraction

The process of utilizing [[entities/gemini]] [[concepts/models|models]] to perform [[concepts/document-processing|Information Extraction]], specifically transforming [[concepts/unstructured-text|unstructured text]] into [[concepts/structured-output]].

## Key Tools & Libraries
* [[concepts/contextual-awareness|LangExtract]]
    * An [[concepts/open-source|open-source]] library developed by [[entities/google]].
    * **Core Function:** Converts unstructured [[concepts/text|text]] $\rightarrow$ [[concepts/structured-output]].
    * **Key Features:**
        * Custom Schema: Allows users to define specific targets for extraction.
        * Data Visualization: Provides integrated visualization of extracted information.
