# Color Grading panel

The **[[concepts/photo-tonal-adjustments|Color Grading]] panel** is a core interface in [[concepts/photo-enhancement|photo editing]] software (e.g., [[entities/adobe-lightroom|Adobe Lightroom]], [[concepts/adobe-photoshop|Photoshop]]) used to adjust the color balance, tint, and saturation of [[concepts/shadows|shadows]], midtones, and highlights. It allows for precise control over the visual [[concepts/earths-atmosphere|atmosphere]] and emotional [[concepts/tone|tone]] of an image.

## Key Concepts
- **Shadows/Midtones/Highlights:** Separate [[concepts/color-wheels|color wheels]] or sliders for different tonal ranges.
- **Color [[concepts/musical-harmony|Harmony]]:** Using complementary or analogous colors to create visual [[concepts/cohesion|cohesion]].
- **Emotional Impact:** Strategic color choices to evoke specific feelings (e.g., warmth for nostalgia, cool tones for melancholy).
