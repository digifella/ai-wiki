# Lunar Return

The lunar return refers to the upcoming missions that [[entities/will|will]] see humanity returning to the Moon after a prolonged absence, marking significant advancements in [[concepts/space-exploration|space exploration]] and technology. This term encapsulates not only the physical journey but also the technological innovations and scientific objectives associated with renewed lunar activity.

- **[[concepts/artemis-program|Artemis Program]]:** [[entities/nasa|NASA]]'s initiative aimed at establishing sustainable human exploration of the Moon.
