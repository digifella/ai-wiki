# Beginner IT Guidelines

Core principles for new IT professionals focusing on system hygiene, organization, and standard operating procedures.

## File and Directory Management

Proper [[concepts/structured-naming|naming conventions]] are critical for system compatibility, searchability, and professional collaboration. See [[lab-notes/2026-06-24-Essential-Guidelines-for-Professional-File-and-Directory|Essential Guidelines for Professional File and Directory Naming]] for detailed implementation.

*   **Avoid Special Characters:** Use alphanumeric characters, hyphens, or underscores. Avoid spaces, slashes, colons, or question marks which can break scripts or paths.
*   **[[concepts/logical-consistency|Consistency]]:** Adopt a standardized format (e.g., `YYYY-MM-DD_ProjectName_Version`) across all directories.
*   **Case Sensitivity:** Assume case sensitivity even on case-insensitive OSs to prevent cross-platform errors.
*   **Descriptive Names:** Ensure names reflect content without relying on file extensions alone.
