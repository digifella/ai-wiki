# Adobe Photoshop Beta

[[entities/adobe-photoshop|Adobe Photoshop]] Beta is a [[concepts/testing|testing]] version of Adobe's flagship [[concepts/image-editing|image editing]] [[concepts/software|software]] that introduces experimental [[concepts/ai-technologies|artificial intelligence]]-powered features alongside traditional editing [[concepts/capabilities|capabilities]]. The beta release aims to gather [[concepts/user-feedback|user feedback]] on new tools before they are incorporated into the main production version of [[concepts/photoshop|Photoshop]].

## Key Features

The [[concepts/beta-version|beta version]] includes the [[concepts/contextual-task-bar|Harmonize feature]], an AI tool designed to assist with image [[concepts/adjustments|adjustments]] and [[concepts/logical-consistency|consistency]]. Another prominent capability is the Rotate Object 3D tool, which enables users to manipulate and rotate two-dimensional [[concepts/images|images]] in three-dimensional space, expanding creative possibilities beyond standard 2D editing workflows.

These [[concepts/ai-powered-tools|AI-powered tools]] represent Adobe's ongoing [[concepts/integration|integration]] of machine [[concepts/learning|learning]] technologies into its creative suite, allowing beta testers to explore how artificial intelligence can streamline and expand traditional image editing workflows. Participation in the beta program typically requires enrollment through Adobe's official channels and provides users with early access to features under development.
