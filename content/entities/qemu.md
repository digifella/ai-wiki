# Qemu

Qemu is a free and [[concepts/open-source|open-source]] emulator and virtualizer that enables users to run operating systems and [[concepts/software|programs]] on different [[concepts/hardware|hardware]] architectures. It supports emulation of various [[concepts/central-processing-units|processors]] including x86, ARM, PowerPC, and MIPS, making it useful for [[concepts/coding|software development]], [[concepts/testing|testing]], and [[concepts/running|running]] [[concepts/vintage-computing|legacy systems]] on modern hardware.

## Usage and Capabilities

The emulator can operate in two primary modes: full system emulation, which simulates an entire computer including BIOS and peripherals, and user-mode emulation, which allows running individual applications compiled for different architectures. Qemu is commonly used in [[concepts/development-workflows|development workflows]], continuous [[concepts/integration|integration]] environments, and for creating [[concepts/virtual-machines|virtual machines]] on [[entities/linux|Linux]] systems when combined with the KVM (Kernel-based Virtual Machine) module.

## Common Applications

Developers frequently use Qemu to test software across multiple platforms without requiring physical hardware for each target [[concepts/architecture|architecture]]. It is also employed in [[concepts/security|security]] research, embedded systems development, and by system administrators for running [[concepts/isolated-environments|isolated environments]]. The tool integrates well with other virtualization frameworks and is available across major operating systems including Linux, [[entities/windows|Windows]], and [[entities/macos|macOS]].
