# Prompt Chaining

Sequential [[concepts/prompting|prompting]] technique where outputs from one prompt feed into subsequent prompts to solve [[concepts/complex-tasks|complex tasks]] through [[concepts/iterative-refinement|iterative refinement]].

## Core Principles
- **Modular Workflow**: Breaks down multi-step problems into manageable prompt sequences
- **Context [[concepts/preservation|Preservation]]**: Maintains relevant context across sequential prompts
- **Error Containment**: Isolates failures to single steps without collapsing entire workflow

## Key Applications
- **Complex [[concepts/reasoning|Reasoning]]**: Step-by-step [[concepts/problem-solving|problem solving]] (e.g., [[concepts/multi-step-reasoning|Chain-of-Thought]])
- **Content Generation**: Multi-stage creative [[concepts/workflow|workflows]] (e.g., outline $\rightarrow$ draft $\rightarrow$ edit)
- **Tool [[concepts/integration|Integration]]**: Chaining specialized [[concepts/ai-tools|AI tools]]
- **[[concepts/no-code|No-Code Development]]**: Building [[concepts/ai-mini-applications|AI mini-applications]]
