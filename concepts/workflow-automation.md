# Workflow Automation

[[concepts/ai-driven-workflow-automation|Workflow automation]] utilizes technology to execute repetitive tasks and sequences without manual intervention, aiming to increase efficiency and reduce human error in knowledge work and creative pipelines.

## Core Concepts
*   **[[concepts/action-based-automation|Reactive Automation]]:** Traditional rule-based execution of predefined steps.
*   **Proactive AI Agents:** Systems like [[entities/gemini-spark]] and [[entities/chatgpt-work]] that anticipate needs and initiate actions.
*   **LLM-Driven Orchestration:** Using [[concepts/demystifying-llms|large language models]] to manage complex node-based interfaces such as [[entities/comfyui]] and coordinate agents like [[entities/hermes-agent]].
*   **Privacy-Focused Desktop Apps:** Leveraging local LLMs (e.g., via [[entities/lm-studio-bionic]]) and coding agents to keep data on-device.
*   **2026 Landscape:** Characterized by OpenAI's shift toward proactive AI "Dots" and the ultrafast [[entities/gpt-6-astra]] model, emphasizing deep integration into daily workflows.

## Recent Advancements in RPA
*   **Direct Unstructured Data Decisions:** Traditional RPA tools excel at automating repetitive "steps" (e.g., clicking buttons, copying data) but struggle with decision-making. New approaches focus on direct interpretation of unstructured data.
*   **Image Decision Models:** Advancements allow RPA systems to make decisions based on forms, scans, and screenshots without relying on [[concepts/structured-data-extraction|structured data extraction]].
*   **Integration with [[entities/hermes-agent]]:** These models complement self-learning agents by providing the visual perception layer necessary for complex, non-digital workflows.
