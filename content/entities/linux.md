# Linux

Linux is a free and [[concepts/open-source|open-source]] operating system kernel created by Linus Torvalds in 1991. It serves as the core component of various Linux distributions, which combine the kernel with additional [[concepts/software|software]] to create complete operating systems. Linux powers a wide range of devices, from personal computers and servers to embedded systems and mobile devices [[concepts/running|running]] [[entities/android|Android]].

## Key Characteristics

The open-source [[entities/nature|nature]] of Linux allows developers worldwide to view, modify, and distribute the source code. This collaborative development model has resulted in a stable, [[concepts/secure|secure]], and continuously improving operating system. Linux is known for its portability, efficiency, and strong community support, making it popular in both enterprise and hobbyist environments.

## Applications

Linux supports numerous applications across different domains. Among these are multimedia tools for [[concepts/video-compression|video compression]] and processing, which allow users to reduce file sizes while maintaining acceptable quality. Beyond multimedia, Linux runs web servers, databases, development tools, and scientific computing applications, making it a versatile choice for both personal and [[concepts/professional-use|professional use]].
