# Git

Git is a distributed [[concepts/app-updates|version control]] system that tracks changes to files and code over time. Created by Linus Torvalds in 2005, it enables multiple developers to work on the same project simultaneously by maintaining complete repository history on each contributor's [[concepts/personal-computer|local machine]]. Git operates primarily through [[concepts/command-line-interface|command-line interface]] (CLI) tools, though graphical clients exist for various platforms.

## Core Functionality

The system works by creating snapshots of project states, called [[concepts/commits|commits]], which are organized into branches for parallel development. Developers can merge branches to combine work, revert to previous versions if needed, and resolve conflicts when changes overlap. Git's distributed nature means no single central server is required, though many workflows use remote repositories as [[concepts/coordination|coordination]] points.

## Relevance to AI-Assisted Coding

Git has become particularly relevant in [[concepts/ai-assisted-coding|AI-assisted coding]] workflows, where [[concepts/large-language-model-llm|large language models]] and [[concepts/code-generation|code generation]] tools integrate with [[concepts/developer-platforms|development environments]]. Version control becomes essential for tracking [[concepts/ai-generated-code|AI-generated code]] changes, maintaining code quality through diff review, and managing the [[concepts/iterative-refinement|iterative refinement]] of AI outputs. Most modern IDEs and [[concepts/coding|coding]] assistants include native Git integration to streamline these workflows.
