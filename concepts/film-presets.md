# Film Presets

Film Presets are a collection of camera raw processing tools introduced in Adobe Camera Raw 18.3 and Lightroom Classic 15.3. These presets emulate the visual characteristics of traditional analog film stocks, allowing photographers to apply film-inspired color grading and tonal adjustments to digital images. By simulating the appearance of various film types, the feature bridges the gap between digital capture and classic photographic aesthetics.

The presets function within Adobe's raw processing engine, enabling users to alter the look of their photographs without altering the underlying raw data. This non-destructive workflow ensures that original image information remains intact while providing immediate access to curated film-like profiles. The integration allows for consistent application of these aesthetic qualities across large batches of photos, streamlining the post-processing workflow for users seeking specific analog looks.

Alongside the release of these presets, Adobe updated other core functionalities in the same software versions. These updates include improvements to depth range masking, enhanced lens correction capabilities, deeper integration with Firefly AI for generative features, and optimized background processing. Together, these changes aim to improve both the creative flexibility and technical performance of Adobe's raw processing ecosystem.
