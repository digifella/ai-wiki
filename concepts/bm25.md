# BM25

Probabilistic ranking function for [[concepts/knowledge-bases|information retrieval]] scoring document relevance to a query.

## Database Integration

- [[entities/pg-textsearch|pg_textsearch]]: [[concepts/open-source|Open-source]] [[concepts/postgresql-extension|PostgreSQL extension]] implementing state-of-the-art [[concepts/bm25-ranking|BM25]], eliminating need for external search engines (e.g., Elasticsearch) in many [[concepts/scenarios|use cases]].
- Particularly effective for RAG ([[concepts/answer-generation|Retrieval Augmented Generation]]) applications by enabling database-native text search with relevance scoring.
- Reduces [[concepts/infrastructure|infrastructure]] complexity while maintaining [[concepts/search-relevance|search relevance]] for [[concepts/ai-driven-workflows|AI-driven workflows]].

## Agentic Search Resurgence

- **Unreasonable Effectiveness**: Despite the rise of dense [[concepts/data-embedding|vector embeddings]], [[concepts/lexical-scoring-function|BM25]] retains critical value in [[concepts/llm-driven-agentic-search|LLM-driven agentic search]] due to its lexical [[concepts/accuracy|precision]] and low latency.
- **Search Inside [[concepts/agent-loops|Agent Loops]]**: As defined by [[entities/jo-kristian-bergum|Jo Kristian Bergum]], [[concepts/agentic-search|agentic search]] involves "search inside an [[concepts/operational-loop|agent loop]]" where BM25 provides reliable, deterministic [[concepts/document-retrieval|retrieval]] for grounding LLM actions, complementing [[concepts/natural-language-search|semantic search]].
- **Hybrid Approaches**: Modern architectures often combine BM25's lexical matching with vector similarity to balance [[concepts/recall|recall]] and precision, reducing the need for complex external search infrastructure.
- For detailed analysis, see [[lab-notes/2026-10-03-BM25s-Unreasonable-Effectiveness-in-LLM-Driven-Agentic-S|BM25's Unreasonable Effectiveness in LLM-Driven Agentic Search]].
