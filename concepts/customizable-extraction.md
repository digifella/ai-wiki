# Customizable Extraction

Customizable Extraction refers to the ability to configure and tailor [[concepts/data-extraction|data extraction]] workflows within [[entities/googles-notebooklm|Google's NotebookLM]] platform. This feature allows users to specify which types of information they want to extract from source documents, rather than relying on a fixed or generic extraction process. The capability addresses the practical need for flexible information handling in research and analysis workflows, where different projects require different data structures and content priorities.

## Implementation in NotebookLM

Within NotebookLM, customizable extraction is primarily utilized to manage complex data formats such as tables and simulations. Users can define specific parameters to isolate relevant data points from unstructured or semi-structured sources, ensuring that the extracted information aligns with the specific requirements of their analysis. This functionality supports more precise data manipulation, allowing researchers to focus on key metrics or [[concepts/storytelling|narrative]] elements without processing irrelevant content.

The update enhances the platform's utility for technical and [[entities/tomasz-janowski|academic]] users who require [[concepts/structured-outputs|structured outputs]] from diverse document types. By enabling tailored extraction rules, NotebookLM reduces the manual effort typically associated with [[concepts/data-cleaning|data cleaning]] and organization. This integration facilitates a more efficient workflow for users who need to synthesize information from multiple sources while maintaining control over the granularity and format of the resulting data.
