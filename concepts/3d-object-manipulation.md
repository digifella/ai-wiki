# 3d Object Manipulation

3D Object Manipulation refers to techniques for rotating, repositioning, and transforming two-dimensional images to simulate three-dimensional space. Rather than creating true 3D models from scratch, these methods analyze existing 2D photographs and generate plausible views from different angles. This approach allows users to interact with flat photographic content as though it possessed depth and spatial dimensions, without requiring traditional [[concepts/3d-modeling|3D modeling]] [[concepts/expertise|expertise]] or specialized software knowledge.

## AI-Assisted Rotation

Recent advances in [[concepts/generative-ai|generative artificial intelligence]] have enabled tools like the AI [[concepts/photoshop-tool|Rotate Object feature]] in [[concepts/beta-version|Photoshop Beta]] to automate this process. The system infers the geometry of the subject and the surrounding environment to synthesize new perspectives that maintain visual [[concepts/logical-consistency|consistency]]. This capability allows for the rotation of objects within a scene, effectively altering their orientation relative to the camera while preserving lighting and shadow [[concepts/relationships|relationships]].

The technology relies on [[concepts/deep-learning-models|deep learning models]] trained on vast datasets of images to predict missing pixels and reconstruct occluded areas. By estimating [[concepts/depth-maps|depth maps]] and surface normals from a single input image, the software can render the object from a new viewpoint. This reduces the manual effort previously required for complex [[concepts/digital-compositing|compositing]] tasks, making spatial [[concepts/adjustments|adjustments]] accessible to users without technical backgrounds in [[concepts/computer-graphics|computer graphics]].
