# Azure Portal

[[entities/microsoft|Microsoft]]'s web-based unified management interface for provisioning, configuring, and monitoring Azure resources.

## Key Features
- Centralized dashboard for all Azure services
- [[concepts/resource-group|Resource group]] management
- Cost analysis and billing
- Role-based [[concepts/permission-management|access control]] (RBAC)
- Integration with Azure CLI/PowerShell

## Access
- URL: `portal.azure.com`
- Requires valid Azure account with active subscription

## Python Libraries for Visualization & UI
The following [[concepts/python|Python]] libraries are often cited for their ability to simplify [[concepts/complex-tasks|complex tasks]], [[concepts/access-democratization|democratizing access]] to advanced functionalities without specialized [[concepts/frontend-development|front-end]] or animation [[concepts/skills|skills]]. See [[lab-notes/2026-10-13-Summary-of-5-Illegal-Python-Libraries-Manim-Faker-Gradio|Summary of 5 'Illegal' Python Libraries: Manim, Faker, Gradio, Diagrams]] for a detailed breakdown.

- **Manim**: [[concepts/engine|Engine]] for creating precise mathematical animations, often used to visualize complex [[concepts/ai-models|AI models]] or algorithmic logic.
- **[[concepts/faker|Faker]]**: Library for generating fake data, useful for testing [[concepts/resource-provisioning|resource provisioning]] scripts and simulating user inputs in [[concepts/azure-ai|Azure AI]] environments.
- **[[concepts/gradio|Gradio]]**: Tool for building quick web-interface prototypes and demos for [[concepts/artificial-intelligence-models|machine learning models]], facilitating rapid [[concepts/iteration|iteration]] of [[concepts/ai-models|AI models]].
- **[[concepts/diagrams|Diagrams]]**: Python library for creating [[concepts/system-architecture|system architecture]] diagrams, aiding in the documentation of [[concepts/azure-subscription|Azure Subscription]] structures and [[concepts/agentic-rag|agentic RAG]] pipelines.
