# Autopilot Mode

Over-reliance on AI without critical engagement, leading to diminished personal [[concepts/skills|skills]] and potential errors. Basic [[concepts/ai-proficiency|AI proficiency]] is now a baseline (like [[entities/microsoft-word|Microsoft Word]]); to advance, develop specific skills to avoid autopilot.

## Core Skill: The Cockpit Rule
A mental model for intentional AI use:
- **Delegate**: When AI handles tasks reliably (e.g., data processing).
- **Collaborate**: When AI refines outputs (e.g., [[concepts/writing|writing]], [[concepts/coding|coding]]).
- **Avoid**: When human judgment is essential (e.g., ethical decisions).
