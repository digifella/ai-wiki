# Gpt 5 Model

GPT-5 is a [[concepts/large-language-model|large language model]] developed by OpenAI, designed for advanced natural language understanding and generation. As part of the GPT series, it builds upon transformer-based architecture to enhance [[concepts/advanced-reasoning|complex reasoning]], nuanced [[concepts/text-generation|text generation]], and broader [[concepts/language-processing|natural language processing]] capabilities.

## Integration with Claude Code

The model can be integrated into the [[concepts/claude-ai|Claude]] [[concepts/code-environment|Code environment]] via a local [[concepts/external-tools|Model Context Protocol]] (MCP) server. This setup allows developers to utilize GPT-5's [[concepts/compute-capacity|processing power]] within [[concepts/ai-assisted-coding|Claude Code]] while maintaining [[concepts/local-control|local control]] over the [[concepts/connection|connection]]. The [[concepts/mcp-server|MCP server]] acts as an intermediary, facilitating communication between the Claude Code interface and the GPT-5 model endpoints.
