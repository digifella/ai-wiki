# Multimodal Decision-Making

**Multimodal [[concepts/decision-making|decision-making]]** refers to the process by which [[concepts/ai-models|AI systems]] evaluate inputs from multiple data modalities (e.g., text, images, [[concepts/audio-modality|audio]]) to generate structured, actionable decisions or outputs. This approach enhances context understanding and accuracy compared to unimodal systems.
