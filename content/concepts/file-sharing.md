# File Sharing

File sharing is the practice of distributing or providing access to digital [[concepts/files|files]] among multiple users, often over a network, enabling collaboration, data exchange, and resource sharing.

**Modern implementations**:
- Shared workspaces for [[concepts/agentic-ai|AI agents]] (e.g., [[entities/claude-code]]-built teams) that allow [[concepts/agents|agents]] to share context, files, and workspace for collaborative task execution, moving beyond basic chatbots
- Autonomous AI work teams (see: [[concepts/claude-code|Claude Code]] and [[entities/agent|agent]] team - [[entities/grace-leung|Grace Leung]]) where agents coordinate through shared files without manual copy-pasting
