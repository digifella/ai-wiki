# Foundry Local Sdk

The Foundry Local SDK is a software development kit designed to enable developers to build applications with integrated artificial intelligence capabilities optimized for local execution. By allowing AI models to run directly on end-user devices, the SDK eliminates the dependency on cloud-based AI services. This architecture reduces latency in AI-powered features and ensures functionality without the need for constant server connectivity.

The SDK supports development and deployment across multiple platforms, including Windows PCs, macOS systems, and mobile devices. This cross-platform compatibility allows developers to create consistent AI-driven experiences for users regardless of their operating system or hardware configuration. The focus on local execution ensures that applications remain responsive and private, as data processing occurs on the device rather than being transmitted to external servers.
