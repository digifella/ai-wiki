# Grok Bot

**[[entities/grokky|Grok Bot]]** is an [[concepts/ai-agent|AI agent]] platform positioned as a "seamless, integrated AI agent [[concepts/cloud-computer|cloud computer]]." It distinguishes itself from self-hosted alternatives like OpenClaw by prioritizing ease of installation and out-of-the-box usability.

- **Installation Model:** Marketed as the first AI agent designed for immediate installation without complex local [[concepts/infrastructure|infrastructure]] setup.

- **Core Function:** Acts as a cloud-based computer for AI agents, handling backend complexity to allow users to focus on agent logic.
