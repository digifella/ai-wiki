# Multi-step Tasks

**Multi-step tasks** refer to [[concepts/complex-workflows|complex workflows]] requiring sequential execution, state management, and often [[concepts/iterative-learning|iterative refinement]] to achieve a final goal. In the context of [[concepts/ai-agents|AI agents]], these tasks are increasingly automated through specialized features designed for recurrence and loop-based execution.

## Key Developments

### Hermes Agent /loop Feature
Recent [[concepts/software-updates|updates]] to the [[concepts/hermes-agent]] framework by [[entities/nous-research|Nous Research]] introduce significant capabilities for handling recurring workflows.

*   **Automated Recurrence:** The new `/loop` feature enables automated, recurring [[concepts/workflow-automation|task execution]], reducing the need for manual intervention in repetitive multi-step processes.
*   **[[concepts/agentic-framework|Agentic Framework]]:** [[entities/hermes-agent|Hermes Agent]] is an [[concepts/open-source-framework|open-source framework]] designed to facilitate complex agentic behaviors, including the management of long-running or iterative tasks.
*   **Demo Insights:** A hands-on demonstration highlights the practical application of these [[concepts/loops|loops]], showcasing how the framework manages state and execution [[concepts/flow|flow]] over time.
