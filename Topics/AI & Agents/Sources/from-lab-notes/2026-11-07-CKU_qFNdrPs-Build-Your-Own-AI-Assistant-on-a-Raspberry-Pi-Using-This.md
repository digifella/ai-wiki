## Build Your Own AI Assistant on a Raspberry Pi Using This Tiny Open-Source AI Model
**Clip title:** Build Your Own AI Assistant on a Raspberry Pi Using This Tiny Open-Source AI Model
**Author / channel:** Gary Explains
**URL:** https://www.youtube.com/watch?v=CKU_qFNdrPs

### Summary
Here's a summary of the video content:

The video presented by Gary explains the use of the Needle AI model, a lightweight, open-source tool calling AI model that can run locally on a Raspberry Pi. Needle functions by taking plain language input and determining the appropriate function to call, making it suitable for privacy-focused and low-resource environments. Gary details the setup process, including creating a virtual Python environment and installing necessary packages like "cactus-needle," "requests," and "piper-tts" for speech functionality. 

Gary provides several examples of how to implement Needle in Python, ranging from simple scripts that check the CPU temperature of a Raspberry Pi to more complex assistants that integrate multiple tools, such as getting weather information and recognizing voice commands. The video demonstrates how to use the `@needle.tool` decorator to define functions and how Needle matches plain language queries to these functions using language embeddings. 

The main takeaway is that Needle enables users to build powerful, privacy-respecting voice assistants and local automation tools on low-cost hardware like the Raspberry Pi. By running models locally without relying on cloud services, developers can maintain complete control over their data and ensure fast response times for their custom applications.

#### Description
