# Agentic Coding

**Agentic coding** refers to the paradigm where [[concepts/large-language-models|Large Language Models]] (LLMs) act autonomously to plan, execute, and debug code, rather than merely generating snippets. This approach shifts the developer's role from writer to reviewer, leveraging AI agents that can interact with the local environment, file system, and terminal.

## Core Concepts

- **Autonomy**: Agents operate with minimal human intervention, handling multi-step workflows.
- **Local Execution**: Running models locally ensures data [[concepts/privacy|privacy]] and reduces latency, critical for sensitive development environments.
- **Tool Use**: Agents utilize external tools (compilers, linters, browsers) to verify code correctness.

## Local Agentic Ecosystem

The shift toward local-first AI tools has enabled robust agentic workflows on personal hardware. A key development in this space is the introduction of specialized variants designed for Windows environments.

- **[[concepts/model-performance|Model Performance]] in [[concepts/agentic-tasks|Agentic Tasks]]**: Recent evaluations of [[entities/claude|Claude]] Sonnet 5.5: [[concepts/performance-benchmarks|Performance Benchmarks]], [[concepts/cost-efficiency|Cost Efficiency]], and Agentic Coding demonstrate significant advancements in handling complex agentic workloads. Benchmarks indicate superior performance in 3D game physics simulation and multi-language code generation compared to previous iterations.
- **Cost Efficiency**: The integration of models like Claude Sonnet 5.5 highlights the trade-off between cloud-based high-performance agentic capabilities and local execution constraints, offering developers a reference point for cost-effective agentic deployment strategies.
- **Cross-Platform Compatibility**: Agentic workflows are increasingly optimized for diverse environments, including Windows-specific toolchains, ensuring broader accessibility for [[concepts/local-ai|local AI]] development.
