# Adjustments

Adjustments in [[concepts/photo-editing|photo editing]] refer to modifications made to images within [[concepts/lightroom|Lightroom]] to enhance [[concepts/exposure|exposure]], color, [[concepts/contrast|contrast]], and other visual properties. These techniques form a foundational part of the post-processing workflow, allowing photographers to correct technical issues and achieve desired aesthetic results. The adjustment system operates on a non-destructive basis: the original image file remains unchanged while all edits are recorded in the [[concepts/catalog|Lightroom catalog]], preserving the photographer's ability to revert or modify changes at any point.

## Catalog Management

Proper organization within the [[concepts/lightroom-catalog|Lightroom catalog]] is essential for efficient adjustment workflows. This involves organizing images into collections and using [[concepts/metadata|metadata]] to track editing status and versions. The catalog structure allows photographers to group related images and apply consistent adjustments across multiple photos, which is particularly useful when processing images from the same shoot or [[concepts/session|session]].

## Common Adjustment Categories

[[entities/adobe-lightroom|Lightroom]] provides adjustment tools organized into logical groups: [[concepts/exposure-settings|exposure controls]] manage overall brightness and highlights/shadows; color adjustments include white balance, saturation, and vibrance; [[concepts/tone|tone]] curve adjustments offer precise control over tonal ranges; and [[concepts/clarity-slider|clarity]] and [[concepts/texture|texture]] sliders affect localized contrast and surface detail. Additional tools address specific issues such as [[concepts/lens-correction|lens distortion correction]], chromatic aberration removal, and noise reduction. Most adjustments can be applied selectively using masks and adjustment brushes rather than affecting the entire image uniformly.

The non-destructive nature of Lightroom adjustments means photographers can safely [[concepts/scientific-experiment|experiment]] with different approaches to achieve their desired results, with the flexibility to [[concepts/feynmans-three-step-scientific-method|compare]] before-and-after versions or return to the original unedited state at any stage of the [[concepts/editing-workflow-optimization|editing process]].
