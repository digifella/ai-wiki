[[concepts/opacity|Transparency]] control refers to techniques in [[concepts/design|graphic design]] software such as [[concepts/photoshop|Photoshop]] that allow users to manipulate the transparency of elements within an image or layer based on specific attributes.

## Key Concepts

* **[[concepts/layer-styles|Layer Styles]]**: [[concepts/advanced-blending|Advanced blending]] options within layers.
* **[[concepts/blend-if|Blend If]] Sliders**: Specific controls within Layer Styles for [[concepts/fine-tuning|fine-tuning]] transparency and blend modes.
* **[[concepts/brightness-levels|Brightness Levels]]**: The range of lightness values that can be used to control the visibility of a layer or element.
