# Appearance Change

[[concepts/presence|Appearance]] Change refers to the computational process of modifying visual elements within [[concepts/digital-images|digital images]] using [[concepts/ai-assisted-editing|AI-assisted editing]] systems. Unlike traditional methods that require manual adjustment of individual pixels or specific components, this approach allows for alterations to [[concepts/combining-photos|image composition]], [[concepts/style|style]], and specific features through [[concepts/human-readable-instructions|natural language instructions]]. Users describe desired modifications in text format, and the system interprets these prompts to generate the corresponding visual [[concepts/software-updates|updates]].

A prominent example of this technology is [[entities/hidream-e11|HiDream-E1.1]], an instruction-based [[concepts/open-source-image-editing|open-source AI image editing]] model. This specific implementation supports [[concepts/dynamic-resolution|dynamic resolution]], enabling high-fidelity edits across varying image dimensions. By leveraging [[concepts/language-processing|natural language processing]], such systems bridge the gap between user intent and technical execution, allowing for complex visual transformations without requiring specialized [[concepts/design|graphic design]] software or manual layer manipulation.
