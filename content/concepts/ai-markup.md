# AI Markup

AI Markup is an [[entities/adobe-photoshop|Adobe Photoshop]] feature leveraging [[concepts/ai-technologies|artificial intelligence]] to automate layer [[concepts/organization|organization]] and annotation, enhancing workflow efficiency for [[concepts/image-editing|image editing]].

## Key Features
- Automated [[concepts/layer-renaming|layer renaming]] via [[concepts/ai-assistant]]
- Context-aware markup suggestions for [[concepts/design|design]] elements
- Integration with [[concepts/photoshop|Photoshop]] for the Web interface
