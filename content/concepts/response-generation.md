# Response Generation

The process of creating meaningful, contextually appropriate replies to user inputs via AI systems.

* [[concepts/agents|Agents]] (e.g., [[entities/copilot|CoPilot]] Agents) perform actions like [[concepts/policy-lookup|policy lookup]] and response generation.
* Autonomous agents are currently in preview mode.
* Example: [[entities/georgia-engel|Georgia Engel]]'s Microsoft 365 support agent (see Creating [[concepts/copilot-chat|CoPilot]] Agents) responds in a friendly, helpful, collaborative tone.
