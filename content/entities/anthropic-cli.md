# Anthropic Cli

Anthropic Cli is a [[concepts/command-line-interface|command-line interface]] tool developed by [[entities/anthropic-institute|Anthropic]] that enables users to interact with Anthropic's AI systems and services from the terminal. The tool provides programmatic access to [[concepts/claude-ai|Claude]] and related models, allowing developers to integrate Anthropic's capabilities into scripts, [[concepts/automation|automation]] workflows, and command-line [[concepts/software|applications]].

## Functionality and Use Cases

The CLI supports various operations including model invocation, file handling, and project management. Users can leverage it for tasks such as code analysis, data processing, and [[concepts/ai-driven-workflow-automation|workflow automation]]. The tool integrates with local file systems and supports the execution of AI-assisted tasks without requiring a graphical interface, making it suitable for server environments and development pipelines.

## Integration with Claude Capabilities

The Anthropic Cli serves as a bridge between command-line environments and Claude's features, including code execution and extended context capabilities. This allows developers to incorporate Claude's [[concepts/reasoning|reasoning]] and [[concepts/coding|coding]] abilities directly into automated workflows and build [[concepts/agentic-ai|AI agents]] that can perform multi-step tasks with minimal manual intervention.
