# Conversational interface

A [[concepts/user-interface|user interface]] that enables interaction through natural language (text or [[concepts/tone|voice]]), mimicking human conversation to reduce [[concepts/cognitive-load|cognitive load]] and improve [[concepts/accessibility|accessibility]]. Common in [[concepts/ai-assistant]] systems for intuitive [[concepts/workflow-automation|task execution]].

## Key characteristics
- Natural language understanding (NLU) for processing user input
- Context-aware [[concepts/response-generation|response generation]]
- [[concepts/multimodal-support|Multimodal support]] (text/voice)
- [[concepts/error-management|Error recovery]] via conversational follow-up

## Examples
- **[[entities/codellm|CodeLLM]]**: AI-powered code editor using conversational interface to boost [[concepts/productivity|productivity]] (10x claimed) for developers/non-coders; enables [[concepts/application-building|application building]], code fixing, and [[concepts/code-generation|code generation]] via natural language (dual modes of operation).
- [[concepts/ai-assistant]] tools for general [[entities/claude-co-work|task automation]]
- [[concepts/ai-coding]] platforms with chat-based workflows
