## God's Eye View (GEV) 3D Intelligence Console: Installation and Feature Guide
**Clip title:** God’s Eye View Blew Up. Here's What You Can Do With It.
**Author / channel:** Bilawal Sidhu
**URL:** https://www.youtube.com/watch?v=o_FJ1NIH9yw

### Summary
The video provides a comprehensive walkthrough and update on "God's Eye View" (GEV), an open-source, [[concepts/3d-intelligence-console|3D intelligence console]] for Planet Earth that recently went viral. The creator, [[entities/bilawal-sidhu|Bilawal Sidhu]], addresses common user questions regarding how to install and run the software, along with a detailed demonstration of its extensive features. The project's unexpected popularity, which saw its GitHub repository hit number one trending and attracted [[concepts/attention-mechanism|attention]] from notable tech figures like Brendan Eich (creator of JavaScript and Firefox), underscored the need for this instructional video.

For non-coders, GEV can be easily installed via the Pinokio one-click installer, which offers an officially supported and bug-fixed version. Coders or those interested in hacking on the project can directly clone the GitHub repository and use any [[concepts/ai-coding-agent|AI coding agent]] (like CodeX or [[entities/cursor|Cursor]]) to set it up and contribute through pull requests. Once launched, users are presented with a 2D Esri Globe, which can be upgraded to [[entities/google|Google]]'s Photorealistic 3D Tiles by adding API keys (Google Maps and Cesium Ion, with free non-commercial options available). The interface is divided into data layers (including live flights, military flights, earthquakes, satellites, street traffic, and more), a scene editor, display settings, and a context menu, allowing for highly customizable views, from tactical spy satellite aesthetics to minimalist maps, and even a celestial mode showing the sun and moon.

The video then dives into GEV's powerful interactive capabilities, showcasing the ability to track real-time commercial and military flights (sourced from thousands of volunteer receivers globally), view live traffic data with intensity heatmaps, and access public CCTV camera snapshots (with intentionally low frame rates for [[concepts/privacy|privacy]]). Users can search for any location, jump to preset spots, follow individual flights from a "cockpit view" with telemetry data, and even use voice commands (requiring an [[entities/openai|OpenAI]] API key) to control the map, request information about locations, and trace routes. Advanced features include displaying [[entities/nasa|NASA]] satellite data for active fires, mapping global [[concepts/infrastructure|infrastructure]] like submarine cables and data centers, and even reconstructing past events like the Nepal floods using various open-source media.

Ultimately, GEV is presented not merely as a spy satellite simulator but as a versatile foundation for understanding and interacting with the real world. Sidhu encourages users to leverage its open-source nature to build their own applications, track diverse phenomena (environmental, geopolitical, local [[concepts/infrastructure|infrastructure]]), and contribute to its ongoing development. Future plans, contingent on community interest, include developing a hosted version for easier commercial use, exploring paid plans for advanced features like voice mode, and potentially delving into historical data tracking. The project aims to create a collective, open-source "window" for humanity to observe and comprehend our complex world.
