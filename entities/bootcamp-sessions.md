# Bootcamp Sessions

Bootcamp Sessions are guided learning experiences within the Vyond platform designed to help users create animated videos. These sessions provide structured tutorials and hands-on practice for both new and experienced users working with Vyond's animation tools. They serve as an onboarding and skill development resource, enabling users to build proficiency with the platform's core features and workflows.

## AI Assistance

Bootcamp Sessions integrate AI assistance features that support users throughout the learning process. These AI-powered tools help guide users through complex tasks, offering real-time suggestions and automated support to streamline the animation creation workflow.

## Vyond Go Integration

The sessions also cover selecting stock characters within Vyond Go. This component focuses on utilizing the platform's library of pre-designed assets to accelerate production, allowing users to efficiently assemble scenes and customize characters without starting from scratch.
