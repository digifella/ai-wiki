# Wan 22

[[concepts/14b-parameter-model|Wan 2.2]] is a [[concepts/video-generation|video generation]] model designed to create videos from text prompts or static [[concepts/images|images]]. The model supports both [[concepts/text-to-video|text-to-video]] and [[concepts/image-to-video-model|image-to-video generation]] tasks, enabling users to produce [[concepts/dynamic-video-content|dynamic video content]] from various input formats.

## Local Deployment

Wan 2.2 can be run locally using [[concepts/comfyui|ComfyUI]], a node-based interface for generative models. This allows users to generate videos on their own [[concepts/hardware|hardware]] without relying on cloud-based services. Installation and usage guides for the model within the ComfyUI environment are available through community documentation and video tutorials.
