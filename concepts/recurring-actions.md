# Recurring Actions

Recurring Actions is a feature within Google Gemini that enables users to automate tasks scheduled to run at regular intervals. Rather than manually executing the same workflow repeatedly, users can configure actions to trigger automatically on a defined schedule—whether daily, weekly, monthly, or at custom intervals. This reduces manual overhead and ensures consistent task execution without requiring user intervention each time the action is due.

Users establish Recurring Actions by specifying the task type, the desired frequency, and the specific parameters for each instance. The system handles the execution logic, allowing the agent to perform the designated function at the predetermined times. This capability is particularly useful for routine data processing, report generation, or other repetitive operations that benefit from consistent timing and reduced human oversight.

By integrating scheduling directly into the application, the feature streamlines workflows that would otherwise demand constant monitoring or manual initiation. It allows users to set up complex automation chains that operate in the background, ensuring that time-sensitive or periodic duties are completed reliably. This approach minimizes the risk of human error associated with manual repetition and frees up user time for more complex decision-making tasks.
