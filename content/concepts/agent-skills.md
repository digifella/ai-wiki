# Agent Skills

[[concepts/agent-skills]] (formerly [[concepts/claude-code]]) are specialized capabilities and toolsets that enable [[concepts/large-language-models|Large Language Models (LLMs)]] and [[concepts/agent-harnesses|Agent Harnesses]] to execute complex, multi-step tasks with high precision.

### Key Insights
- **Definition**: Agent Skills are reusable instruction manuals (folders containing [[concepts/instructions|instructions]], scripts, and resources) that teach models how to perform tasks, what tools to use, and what [[concepts/open-standards|standards]] to follow.
- **Efficiency [[concepts/ai-workflow|Optimization]]**: Utilizing Code (e.g., [[entities/python|Python]]) for [[concepts/web-scraping]] tasks is significantly more efficient and reliable than relying on [[concepts/markdown|Markdown]] parsing.
  - Agent Skills have become a "killer tool" for bridging the gap between model [[concepts/reasoning|reasoning]] and actionable execution within [[concepts/agentic-patterns|agentic workflows]].
- **Task Execution**: These [[concepts/skills|skills]] function as a "killer tool" for bridging the gap between model [[concepts/reasoning|reasoning]] and actionable execution within [[concepts/agentic-ai]].
  - [[concepts/best-practices|Best practices]] highlight that Code enhances [[concepts/model-efficiency|LLM efficiency]] over [[concepts/markdown|Markdown]] for [[concepts/scraping|scraping]] tasks.
- **Evolution**: The technology is evolving from basic instructions into more robust, programmatic, and open-ended execution capabilities.
