# Color And Vibrance Tool

The [[concepts/adjustment-layers|Color and Vibrance tool]] is a non-destructive adjustment layer introduced in [[entities/adobe-photoshop-2025|Photoshop 2025]] that provides refined control over [[concepts/color-saturation|color saturation]] and tonal intensity. As an adjustment layer, modifications made through this tool do not permanently alter the underlying image data, preserving the original pixel information and enabling flexible editing workflows. This approach allows users to revisit and modify color [[concepts/adjustments|adjustments]] at any point during the [[concepts/editing-workflow-optimization|editing process]] without degrading image quality.

## Functionality

The tool operates by separating color and vibrance controls to offer more precise adjustments than traditional saturation methods. It allows users to increase color intensity while minimizing the risk of oversaturation in [[concepts/skin-tones|skin tones]] and other sensitive areas. This separation enables nuanced editing where global color shifts can be applied without uniformly affecting all hues in the image.
