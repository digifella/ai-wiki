# Desktop Interface

Desktop Interface refers to the graphical layout and interactive elements that users encounter when accessing [[concepts/perplexity-ai|Perplexity]], an AI-powered search engine. A comprehensive [[concepts/tutorial|tutorial]] on navigating this interface was produced by content creator [[entities/enovair|Enovair]] and published on YouTube in April 2026. The video demonstrates practical usage of Perplexity's features, with the creator noting it as her single most-used AI tool.

## Tutorial Content

The video serves as a guide for users new to or unfamiliar with Perplexity's desktop environment. It covers how to interact with the search interface and leverage the platform's [[concepts/capabilities|AI capabilities]] for [[concepts/knowledge-bases|information retrieval]]. The tutorial emphasizes practical application rather than theoretical explanation, making it a resource-focused introduction to the platform's core functionality.
