# Bonsai Image

**[[concepts/bonsai|Bonsai]] Image** refers to a class of image generation models developed by **[[concepts/prism-ml|Prism ML]]** that utilize extreme [[concepts/quantization-techniques|quantization techniques]], specifically reducing [[concepts/accuracy|precision]] to 1-bit or ternary formats, to enable efficient [[concepts/local-inference|local inference]].

## Core Concepts
- **[[concepts/1-bit-llm|1-bit Quantization]]**: Drastically reduces [[concepts/code-size|model size]] and [[concepts/memory|memory]] footprint compared to standard 16-bit or 8-bit floating-point models.
- **[[concepts/ternary-models|Ternary Models]]**: In addition to binary 1-bit models, [[entities/bonsai|Bonsai]] supports ternary [[concepts/parameter-reduction|quantization]] for potential fidelity improvements while maintaining extreme compression.
- **[[concepts/local-execution|Local Execution]]**: Designed to run on [[concepts/consumer-grade-hardware|consumer-grade hardware]] without reliance on cloud [[concepts/open-standard-protocols|APIs]].
- **Quality [[concepts/storing|Retention]]**: Maintains high-fidelity image generation despite extreme parameter compression.
