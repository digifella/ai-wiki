# iPhone 13 Pro

High-end smartphone from Apple (2021), featuring A15 Bionic chip, 120Hz ProMotion display, and triple-camera system with 3x [[concepts/optical-zoom|optical zoom]].

## Key Features
- **Camera System**: 12MP main, 12MP ultra-wide, 12MP [[concepts/telephoto-lens|telephoto]] (3x [[concepts/optical-zoom|optical zoom]]); Photonic Engine for [[concepts/low-light-performance|low-light performance]]
- **Display**: 6.1" Super Retina XDR OLED
- **Performance**: A15 Bionic chip with 6-core [[concepts/cpu|CPU]]
- **Battery**: 3,095mAh (up to 22h video playback)

## Software Updates
- [[entities/adobe-lightroom]]'s new beta Adobe [[concepts/camera-app|Camera App]] supports iPhone 13 Pro and later, offering:
  - Advanced zoom capabilities
  - Enhanced [[concepts/night-photography|night photography]]
  - [[concepts/reflection-removal|Reflection removal]] ([[entities/windows|windows]]/glasses)
- Overheating issues initially reported have been resolved
