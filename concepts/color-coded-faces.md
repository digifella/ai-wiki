# Color-coded faces

Visual technique assigning distinct colors to [[concepts/faces|faces]] (e.g., of 3D objects) to enhance differentiation, [[concepts/thematic-analysis|pattern recognition]], and user interaction.

**Key applications**:
- Rubik's Cube: Standard color scheme (white, yellow, red, orange, blue, green) for each face to enable solving
- [[concepts/information-visualization|Data Visualization]]: Color-[[concepts/coding|coding]] 3D surface faces for categorical representation
- [[concepts/user-interface|User Interface]] Design: Distinguishing interactive elements in 3D software (e.g., CAD tools)

**Recent implementation**:
- [[entities/gpt-5|GPT 5]] - [[entities/mathew-berman|Mathew Berman]]: [[concepts/gpt-5|GPT-5]] generated a fully interactive Rubik's Cube simulator ([[concepts/htmljavascript|HTML/JavaScript]]/[[concepts/threejs|Three.js]]) featuring "proper color-coded faces" with [[concepts/dynamic-sizing|dynamic sizing]] (up to 20x20x20), camera controls, [[concepts/layer-rotation|layer rotation]], and "Solve" functionality.
