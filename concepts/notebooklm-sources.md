# NotebookLM sources

[[concepts/ai-integrated-notebooks|NotebookLM]] sources are the foundational documents or data uploaded to [[concepts/notebooklm|NotebookLM]] that generate its responses and outputs. These sources enable contextual, source-verified [[concepts/content-creation|content creation]].

- **Course creation use case**: Leverage [[entities/notebook-lm|NotebookLM]]'s generated content (based on sources) to build interactive [[concepts/online-courses|online courses]] via [[entities/google-classroom|Google Classroom]].
  - *Prerequisites*:
    - Fully populated [[concepts/notebooklm-notebook|NotebookLM notebook]] (sources + generated assets)
    - [[concepts/google-search|Google]] account
  - *Setup*:
    1. Navigate to [classroom.google.com](https://classroom.google.com) → Click "Create Class"
