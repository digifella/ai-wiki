# Gentabs

Gentabs, also known as Disco, is a feature in Google Gemini that enables users to organize multiple conversations within a single interface. Rather than managing separate chat sessions, users can create and maintain multiple tabs, each with its own independent conversation history and context. This allows simultaneous work on different topics or inquiries without losing track of previous exchanges or switching between different windows.

## Core Functionality

The feature operates by preserving distinct conversation threads in separate tabs within the same Gemini session. Each tab maintains its own message history and context, allowing users to switch between topics fluidly. This approach reduces the friction of managing multiple parallel conversations and provides a more organized workspace for complex or multi-faceted discussions.

## Use Cases

Gentabs is particularly useful for users juggling multiple research topics, brainstorming sessions, or projects simultaneously. Rather than having to remember details from previous conversations or reconstruct context, users can reference their earlier exchanges by simply selecting the relevant tab. This structure supports more flexible and exploratory workflows within a single tool.
