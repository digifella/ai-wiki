# Power Query

An [[concepts/etl|ETL]] (Extract, Transform, Load) engine used for [[concepts/data-cleaning]] and [[concepts/data-transformation|Data Transformation]] within [[entities/excel]] and [[concepts/power|Power]] BI.

## Core Capabilities
- Automates repetitive data manipulation [[concepts/workflow|workflows]].
- Manages large-scale [[concepts/training-data|datasets]] where manual [[entities/excel]] intervention is impractical or inefficient.
- **[[concepts/data-cleaning|Data Cleaning]] Techniques**:
    - Provides automated steps for removing blank rows, serving as a scalable alternative to [[concepts/go-to-special]] or Filter methods.
