# Bug Bounty Programs

## Overview
**Bug bounty [[concepts/software|programs]]** are crowdsourced [[concepts/security|security]] initiatives where organizations invite ethical hackers and security researchers to identify vulnerabilities in their systems, applications, or [[concepts/infrastructure|infrastructure]] in exchange for rewards.

## Emerging Challenges: AI Agent Control
The rapid advancement of **[[concepts/ai-agent-control]]** introduces new vectors for [[concepts/vulnerability|vulnerability]] discovery and exploitation, impacting how bug bounty programs must evolve.

### Key Implications for Bug Bounties
*   **[[concepts/rule-enforcement|Rule Enforcement]] Bypasses:** [[concepts/ai-agents|AI agents]] are increasingly capable of bypassing traditional security rules and constraints, requiring bug bounty scopes to explicitly address agentic behavior and automated exploitation techniques [[lab-notes/2026-09-11-AI-Agent-Control-Cybersecurity-Challenges-in-Rule-Enforc|AI Agent Control: Cybersecurity Challenges in Rule Enforcement and Bypasses]].
*   **Securing [[concepts/agentic-skills|Agentic Skills]]:** Programs must now evaluate vulnerabilities related to the security of [[concepts/ai-agent-skills|AI agent skills]] and [[concepts/tool-use-capabilities|tool-use capabilities]], not just traditional code flaws.
*   **Automated Discovery:** The use of AI in bug hunting accelerates vulnerability identification but also raises the bar for defenders, necessitating more sophisticated rule enforcement [[concepts/causes|mechanisms]].
