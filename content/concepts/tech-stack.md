# Tech Stack

A tech stack refers to the combination of programming languages, frameworks, tools, and platforms that developers use to build [[concepts/software|applications]]. In the context of [[concepts/agentic-ai|AI agents]], tech stacks have become increasingly important as developers integrate [[concepts/artificial-intelligence-models|machine learning models]], APIs, and specialized libraries into their workflows. Understanding which tools and technologies are most commonly adopted provides insight into industry trends and [[concepts/best-practices|best practices]].

## Survey Comparisons

Recent [[concepts/developer|developer]] surveys, including the Pragmatic Engineer 2025 survey and the [[entities/artificial-analysis|Artificial Analysis]] survey, have tracked which [[entities/ai-tools|AI tools]] and technologies developers are actively using. These surveys capture [[concepts/adoption|adoption]] patterns across different experience levels and domains, revealing preferences for specific frameworks, model providers, and development platforms. Comparing these surveys helps identify which tools are gaining traction and which are becoming standard in professional [[concepts/developer-platforms|development environments]].

## Adoption Trends

The surveys indicate varying levels of adoption for different [[concepts/ai-development|AI development]] tools and platforms. Developers select tools based on factors including ease of integration, community support, documentation quality, and compatibility with existing systems. Tracking these adoption patterns over time provides valuable data for understanding how the AI developer ecosystem is evolving and which technologies are becoming foundational to modern development practices.
