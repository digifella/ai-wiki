# Recurring Tasks

Recurring tasks are a productivity feature that enables users to automate repetitive actions within [[concepts/ai-powered-applications|AI applications]] and [[concepts/workflow|workflow]] tools. Rather than manually repeating the same action multiple times, recurring tasks allow users to set up actions that execute on a predetermined schedule, reducing manual overhead and improving [[concepts/logical-consistency|consistency]].

## Scheduled Actions in Google Gemini

[[entities/gemini-models|Google Gemini]] introduced a [[concepts/recurring-actions|Scheduled Actions]] feature that lets users create recurring tasks directly within the [[concepts/web-application|web application]]. This feature can be accessed through the Settings menu and represents part of [[concepts/gemini|Gemini]]'s broader push toward [[concepts/ai-driven-workflow-automation|workflow automation]] [[concepts/capabilities|capabilities]]. The functionality allows users to define tasks that run automatically [[concepts/assistive-technology|at]] specified intervals without requiring manual intervention each time.

## Use Cases and Implementation

Recurring tasks are particularly valuable in [[concepts/scenarios|scenarios]] where consistent, time-based actions are needed—such as regular data checks, scheduled reminders, or automated report generation. By integrating recurring task capabilities into AI assistants and platform tools, these [[concepts/software|applications]] become more capable of supporting ongoing workflow requirements rather than serving only single, isolated interactions.
