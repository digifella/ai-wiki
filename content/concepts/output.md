# Output

Output refers to the configuration and optimization of how [[concepts/ai-assisted-coding|Claude Code]] generates, formats, and delivers results to users. Within Claude Code's [[concepts/hidden-settings|hidden settings]], output preferences control aspects such as code formatting, response verbosity, syntax highlighting, and file [[concepts/structure|structure]] generation. These settings enable users to tailor how information is presented according to their specific workflow requirements and [[concepts/coding-workspace|development environment]].

## Workflow Integration

Output settings directly impact how efficiently Claude Code integrates into existing development processes. Configurable output formats allow developers to specify whether code should be generated as standalone snippets, complete files, or modular components. Response formatting options can be adjusted to match project conventions, reducing the need for manual reformatting and improving integration speed with version control systems and build pipelines.

## Privacy and Data Handling

[[concepts/output-control|Output configuration]] includes controls over what information is logged, cached, or retained after code generation sessions. Hidden settings in this domain allow users to specify data retention [[concepts/policies|policies]] and control whether generated code and intermediate outputs are stored locally or transmitted to external systems. This aspect of output management is particularly relevant for teams handling sensitive codebases or working under regulatory constraints.
