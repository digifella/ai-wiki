# Third Party Tool Integration

Third party [[concepts/planning-errors|tool integration]] refers to the use of external applications and services alongside [[entities/anthropic-institute|Anthropic]]'s [[concepts/claude-ai|Claude]] [[entities/ai-news-strategy-daily|AI platform]] to extend its functionality. These integrations allow users to connect Claude with [[concepts/specialized-tools|specialized tools]], data sources, and workflow applications from other providers, enabling customized solutions for specific [[concepts/scenarios|use cases]].

## Integration Landscape

Third party tools that integrate with Claude span various categories, including [[concepts/productivity|productivity]] applications, data analysis platforms, [[concepts/developer-platforms|development environments]], and automation services. Common integration points include API connections, plugin systems, and [[concepts/ai-driven-workflow-automation|workflow automation]] platforms that enable Claude to interact with [[concepts/external-data|external data]] sources and perform actions within connected applications.

## Platform Restrictions and Changes

Anthropic has implemented [[concepts/policies|policies]] governing third party tool integrations with its Claude platform. Notable restrictions have affected certain integration tools and services, including limitations on how [[concepts/third-party-applications|third party applications]] can access and utilize Claude's capabilities. These policies reflect Anthropic's approach to managing platform [[concepts/security|security]], user [[concepts/privacy|privacy]], and terms of service [[concepts/compliance|compliance]].

## Usage and Limitations

Users of Claude integrations operate within defined usage parameters and [[concepts/rate-limits|rate limits]] that vary depending on their subscription tier and the specific tools being integrated. These limitations are designed to manage platform resources and ensure equitable access across the user base. Integration capabilities may also differ between Claude's various access methods, including web interface, API, and third party platforms.
