# Nexa Sdk

[[concepts/gguf|Nexa Sdk]] is an [[concepts/open-source|open-source]] [[concepts/developer|developer]] toolkit designed to facilitate the execution of [[concepts/artificial-intelligence-models|artificial intelligence models]] on local [[concepts/hardware|hardware]]. It supports multiple computational backends, including [[concepts/neural-processing-units|Neural Processing Units]] (NPUs), Graphics Processing Units (GPUs), and standard CPU [[concepts/central-processing-units|processors]]. By enabling [[concepts/local-model|local model]] [[concepts/inference|inference]], the toolkit reduces dependency on [[concepts/cloud-ai|cloud-based AI]] services and allows developers to integrate machine [[concepts/learning|learning]] capabilities directly into [[concepts/software|applications]] [[concepts/running|running]] on user devices.

## Functionality and Use Cases

The toolkit abstracts hardware differences across supported backends, allowing developers to write code once and deploy across different device architectures. This approach is particularly relevant for [[concepts/edge-computing|edge computing]] scenarios where latency, [[concepts/privacy|privacy]], or connectivity constraints make cloud-based AI processing impractical. Developers can optimize model execution based on available hardware without rewriting application code for each target platform.
