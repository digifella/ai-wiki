# Gemma 3 architecture

The foundational [[concepts/architecture|architecture]] powering Google's [[entities/gemma]] model series, supporting [[concepts/multimodal-capabilities|multimodal capabilities]].

### Specialized Implementations
- [[concepts/dermatology-images|MedGemma 27B]]
    - Developed by Google; built on Gemma 3 architecture.
    - Optimized for medical text and image comprehension tasks.
    - **Model Variants**:
        - 4B multimodal (available in pre-trained and instruction-tuned versions).
        - 27B parameter version.
    - Reference: [Fahd Merza Overview](https://www.youtube.com/watch?v=QBuBvMA0oSw)
