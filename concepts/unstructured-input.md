# Unstructured Input

**Unstructured Input** refers to raw, non-formatted data (text, audio, video, code) provided to [[concepts/large-language-models]] without rigid schema constraints, relying on the model's inherent comprehension capabilities rather than explicit structural instructions.

## Key Developments

*   **[[concepts/prompting-20|Prompting 2.0]] Paradigm:** [[entities/andrej-karpathy|Andrej Karpathy]] introduced a shift from traditional structured prompting to leveraging LLMs' ability to comprehend unstructured context directly, achieving advanced results with minimal instruction overhead [[lab-notes/2026-08-09-Karpathys-Prompting-2.0-Leveraging-Unstructured-Input-fo|Karpathy's Prompting 2.0: Leveraging Unstructured Input for Advanced LLM Comprehension]].
*   **Viral Adoption:** The technique gained significant traction via the video "Andrej Karpathy just changed how he prompts [[entities/claude|claude]]]
*   **Leaner Prompts & External Context:** Recent shifts by [[entities/anthropic|Anthropic]] and [[entities/openai|OpenAI]] emphasize using leaner prompts and external context over complex internal instructions, further reducing the need for rigid schema constraints [[lab-notes/2026-08-26-Anthropic-and-OpenAIs-New-Prompting-Rules-Leaner-Prompts|Anthropic and OpenAI's New Prompting Rules: Leaner Prompts and External Context]].
