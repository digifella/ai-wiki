# Claude Desktop

[[concepts/claude|Claude]] Desktop is a native [[concepts/desktop-application|desktop application]] developed by [[entities/anthropic-institute|Anthropic]] that provides access to [[concepts/claude-ai|Claude]], an [[entities/ai-assistant|AI assistant]]. The application can be configured with [[concepts/external-tools|Model Context Protocol]] (MCP) servers, enabling extended functionality for [[concepts/information-extraction|data extraction]] and [[concepts/integration|integration]] with external tools and data sources.

## Configuration and MCP Servers

The desktop application supports integration with [[concepts/mcp-servers|MCP servers]], which are standardized tools that allow Claude to interact with external systems and datasets. This configuration capability makes Claude Desktop suitable for tasks requiring access to specialized data sources or automated workflows. Users can connect MCP servers such as [[concepts/bright-data|Bright Data]] and other compatible services to enhance Claude's [[concepts/capabilities|capabilities]] beyond its base functionality.

## Use Cases

By integrating MCP servers, Claude Desktop can be configured for various [[concepts/data-extraction|data extraction]] and analysis tasks. The combination of Claude's [[concepts/language-capabilities|language capabilities]] with protocol-based connections to external resources enables users to build custom workflows that leverage both the [[concepts/ai-assistant|AI assistant]] and specialized data access tools.
