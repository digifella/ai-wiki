# Mobile To Desktop AI Control

Mobile to desktop AI control refers to systems that enable [[concepts/agentic-ai|AI agents]] to operate and interact with desktop environments remotely, often initiated or managed from mobile interfaces. This capability allows AI assistants to execute tasks on personal computers, including [[concepts/software|software]] operation, file management, and system interactions, while maintaining control and oversight from mobile devices or remote locations.

## Anthropic Dispatch

[[entities/anthropic-institute|Anthropic]] introduced [[concepts/ubiquitous-ai-assistant|Dispatch]] as a platform for remote desktop AI integration, specifically designed to extend [[concepts/claude-ai|Claude]]'s capabilities beyond text-based interactions. Dispatch enables Claude to interact with desktop applications and systems, performing tasks that require graphical [[concepts/user-interface|user interface]] navigation and direct system control. The system addresses the gap between mobile-initiated requests and desktop-based execution, allowing users to delegate complex computer tasks to AI agents.

## Security and Implementation

The development of systems like Dispatch involves security considerations around [[concepts/remote-desktop|remote desktop]] access and [[concepts/ai-agent|AI agent]] permissions. Anthropic's [[concepts/local-ai-framework|OpenClaw framework]] appears to provide security protocols for managing what actions AI agents can perform on connected systems, ensuring that remote AI control maintains appropriate boundaries and safeguards. This technical [[concepts/architecture|architecture]] allows for controlled delegation of desktop tasks without compromising system [[concepts/integrity|integrity]].
