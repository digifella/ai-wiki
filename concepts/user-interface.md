# User Interface

**[[concepts/llms|Definition]]:** The user interface (UI) is the point of interaction between a human and a computer system or application. It includes both hardware interfaces (like keyboard and mouse) and software interfaces (like graphical elements on a screen).

## Key Concepts
- **[[concepts/gui-interface|Graphical User Interface]] (GUI):** Visual layout that allows users to interact with electronic devices through graphical icons and visual [[concepts/indicators|indicators]].
- **[[concepts/cli|Command Line]] Interface (CLI):** [[concepts/text-based-interface|Text-based interface]] where users give [[concepts/commands|commands]] via text for specific tasks like [[concepts/cli-tools|terminal]] or [[concepts/command-prompt|command prompt]].
- **[[concepts/responsive-design|Responsive Design]]:** [[concepts/interface-design|UI design]] that adapts to different screen sizes and orientations.

## AI Interface Customization
- **[[concepts/environment-interaction|Claude Code Mods]]:** Anthropic introduced "Mods" for [[concepts/claude-code|Claude Code]], allowing deep customization of the [[concepts/ai-assistant|AI assistant]]'s behavior and user interface.
- **Distinction from other tools:** Unlike "skills" (which instruct *how* to perform a task) or "connectors" (which link to external apps), mods directly alter Claude Code's internal work processes.
- **[[concepts/productivity|Productivity]] Impact:** These mods enable users to tailor the AI's output and interaction style for specific workflows, enhancing productivity.
