# Nexa SDK

An [[concepts/open-source|open-source]] [[concepts/developer|developer]] toolkit designed for running [[concepts/ai-models]] locally across various hardware backends.

### Key Features
- **Hardware Versatility**: Enables execution across NPU, GPU, and [[concepts/cpu]] backends.
- **Data [[concepts/privacy|Privacy]]**: Designed for [[concepts/local-inference|local inference]] to ensure all data remains private.
- **[[entities/high-performance|High Performance]]**: Built from scratch for optimized execution efficiency.
- **Format Compatibility**: Supports multiple model formats, including [[concepts/gguf|GGUF]] and MLX.
- **Ecosystem Context**: Serves as a powerful alternative to tools like [[entities/ollama]] and [[entities/llamacpp]].
