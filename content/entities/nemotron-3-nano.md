# Nemotron 3 Nano

Nemotron 3 Nano is a 30-billion-parameter [[concepts/statistical-language-modeling|language model]] developed by NVIDIA. As a member of the [[entities/ai-assistant|Nemotron]] 3 model family, it is designed to balance performance with [[concepts/computational-efficiency|computational efficiency]], making it suitable for [[concepts/deployment|deployment]] in resource-constrained environments while maintaining competitive capability across standard language understanding and generation tasks.

## Multimodal Capabilities

NVIDIA extended the Nemotron 3 Nano [[concepts/architecture|architecture]] to support multimodal inputs, creating [[concepts/nemotron-3-nano-model|Nemotron 3 Nano Omni]]. This variant integrates [[concepts/computer-vision|vision]] and language capabilities, enabling the model to process and reason over both text and image data as a unified agent model, expanding its application range beyond text-only tasks.
