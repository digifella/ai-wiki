# Foundry

[[concepts/rich-tooling|Foundry]] is a platform designed for developing [[concepts/ai-powered-applications|AI applications]] that prioritize [[concepts/local-execution|local execution]] rather than cloud-based processing. It supports [[concepts/deployment|deployment]] across multiple operating systems and device types, including [[entities/windows|Windows]] PCs, macOS, and mobile platforms, while leveraging [[concepts/bare-metal-performance|bare metal performance]] capabilities to optimize application efficiency.

## Core Capabilities

The platform enables developers to build AI applications that can run consistently across different [[concepts/hardware|hardware]] configurations without requiring code modifications. This cross-platform compatibility is achieved while maintaining direct access to underlying hardware resources, allowing [[concepts/software|applications]] to utilize full processing potential available on each device.

## Use Cases

Foundry is particularly suited for scenarios where [[concepts/running|running]] [[concepts/ai-models|AI models]] locally is preferable to cloud deployment, such as applications requiring low-latency [[concepts/inference|inference]], offline operation, or processing of sensitive data without external transmission. The platform has been demonstrated in contexts including retrieval-augmented generation (RAG) implementations and integration with broader AI ecosystems.
