# Built In Skills Testing

Built In [[concepts/skills-testing|Skills Testing]] refers to the integrated testing capabilities within [[entities/claude-code-20|Claude Code 2.0]], Anthropic's [[concepts/10x-developer-productivity|AI-assisted coding]] platform. These testing features enable developers to validate code functionality directly within the [[concepts/coding-workspace|development environment]], reducing the need to switch between applications and streamlining the overall coding workflow. By embedding testing tools into the coding interface, developers can verify their code without leaving the workspace.

## Key Features

Claude Code 2.0's testing [[concepts/infrastructure|infrastructure]] includes [[concepts/software-updates|updates]] to loop handling, scheduled [[concepts/workflow-automation|task execution]], and [[concepts/google-workspace-access|Google Workspace integration]].
