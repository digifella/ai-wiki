# Data Extraction

[[concepts/information-extraction|Data extraction]] is the process of extracting [[concepts/structured-output|structured data]] from unstructured or semi-structured sources such as text documents, web pages, and databases. This involves identifying relevant information and converting it into a format that can be easily utilized by [[concepts/software|software]] systems.

### Key Concepts
- **[[concepts/structured-data|Structured Data]]:** Refers to information organized in a pre-defined format.
- **[[concepts/unstructured-data|Unstructured Data]]:** Information that lacks an identifiable [[concepts/structure|structure]] or [[concepts/organization|organization]].
- **Semi-[[concepts/json-structuring|Structured Data]]:** Data that has some level of organization but not the strict rules found in structured data, such as XML or JSON [[concepts/files|files]].

### Tools and Technologies
- **[[concepts/regular-expressions|Regular Expressions]] (Regex):** A sequence of characters that define a search pattern.
- **[[concepts/natural-language-processing|Natural Language Processing (NLP)]]:** Techniques for analyzing human language to understand context, intent, entities, etc.
- **[[concepts/web-scraping|Web Scraping]]:** Automated methods for collecting data from websites.
- **[[entities/microsoft-excel|Microsoft Excel]] [[concepts/pattern-matching|REGEX Functions]]:** New capabilities including `[[concepts/regexextract|REGEXEXTRACT]]` and `[[concepts/regexreplace|REGEXREPLACE]]` for efficient [[concepts/scraping|data extraction]], cleaning, and formatting within spreadsheets.
