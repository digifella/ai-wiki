# fs-explorer

[[concepts/open-source|Open-source]] **[[concepts/agentic-ai|Agentic File Search]]** tool replacing [[concepts/traditional-rag|traditional RAG]] with human-like [[concepts/file-exploration|file exploration]].

## Core Innovation
- Replaces [[concepts/semantic-similarity|semantic similarity]] search with **[[concepts/agentic-exploration|agentic exploration]]** (mimics human file navigation)
- Solves key [[concepts/rag-limitations|RAG limitations]]:
  - ❌ Fails with complex file structures or [[concepts/unstructured-data|unstructured data]]
  - ❌ Requires precise semantic queries
  - ❌ Relies on brittle embedding [[concepts/data-preprocessing|preprocessing]]

## How It Works
- [[entities/agent|Agent]] actively explores file system through:
  - Path navigation
  - Content reading
  - Iterative query refinement
  - Contextual [[concepts/reasoning|reasoning]]
- Generates relevant results without vector similarity constraints
