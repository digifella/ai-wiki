# Zapier

Cloud-based automation platform connecting over 5,000 [[concepts/apps|apps]] to create [[concepts/no-code|no-code]] workflows (Zaps) triggered by events across applications. Enables data transfer between services without manual intervention.

## Key Features
- **[[concepts/application-integration|App Integration]]**: Supports [[entities/email|email]], CRM, social media, databases, and custom [[concepts/application-programming-interfaces-apis|APIs]]
- **Multi-Step Workflows**: Chain actions with conditional [[concepts/open-source-philosophy|logic]]
- **Zapier AI**: [[concepts/cloud-based-ai|Cloud-based AI]] for content generation and data processing (requires paid tier)

## Local LLM Integration with Ollama and MCP
- Integrates [[entities/ollama]] ([[concepts/local-llm|local LLM]] server) with Zapier via [[concepts/model-context-protocol]] (Model Control Protocol) for private [[concepts/financial-analyst-ai|AI agent]] execution
- Enables Zapier workflows to leverage [[concepts/hardware-heavy-models|local LLMs]] (e.g., via [[entities/ollama]]) instead of [[concepts/cloud-based-solutions|cloud services]] like [[entities/openai]] or [[entities/claude]]
- Provides enhanced [[concepts/privacy|privacy]]/security by processing data locally while maintaining Zapier's workflow capabilities
- Includes setup guide for connecting [[concepts/offline-large-language-models|local LLMs]] to Zapier for agent-based automation
