# Custom Bot

A Custom Bot is a specialized AI agent built within the Microsoft 365 Copilot ecosystem that extends the platform's default capabilities to perform specific tasks. Rather than relying solely on Copilot's general-purpose functionality, custom bots are configured with tailored instructions, data sources, and workflows to address particular organizational or individual use cases and business processes. These agents leverage Microsoft's underlying infrastructure to create personalized digital assistants that can interact with enterprise data and applications in a controlled manner.

## Configuration and Data Integration

The functionality of a custom bot is defined by its underlying configuration, which typically includes system prompts, knowledge bases, and action definitions. Administrators or developers connect the bot to specific Microsoft 365 data sources, such as SharePoint sites, OneDrive folders, or Microsoft Graph APIs, to enable context-aware responses. This integration allows the bot to retrieve, summarize, and manipulate information from within the user's existing digital workspace without requiring the user to manually switch between applications.

## Deployment and Management

Custom bots are managed through the Microsoft 365 admin center or Power Platform, where they are published as apps or channels within Teams. Access controls and permissions are inherited from the connected data sources, ensuring that the bot only exposes information the user is authorized to view. This architecture supports both individual productivity use cases and broader organizational automation, allowing for scalable deployment of specialized AI assistants across different departments or teams.
