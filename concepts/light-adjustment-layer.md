# Light Adjustment Layer

A feature in [[entities/adobe-photoshop]] designed to control lighting effects, specifically introducing a dedicated **[[concepts/glow-slider|Glow Slider]]** for precise luminance adjustments. This tool allows users to apply glow effects without manually creating complex layer masks or blend modes. It integrates [[entities/camera-raw|Camera Raw]]'s powerful tonal controls into a non-destructive layer format.

## Key Features
- **Glow Slider**: Simplifies the application of glow effects through a single control interface.
- **[[concepts/semi-automatic-camera-modes|Light Adjustment Layer]]**: Provides non-destructive lighting control, distinct from traditional exposure or levels adjustments.
- **Prompt to Edit**: Integration of [[concepts/ai-powered-editing|AI-driven editing]] capabilities to modify lighting based on natural language commands.
- **Tonal Controls**: Brings Camera Raw's comprehensive tonal adjustment tools directly into the layer workflow.
