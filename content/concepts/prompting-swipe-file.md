# Prompting Swipe File

A [[concepts/prompting|prompting]] swipe file is a curated collection of well-crafted prompts designed to enhance productivity and [[concepts/output|output]] quality when working with AI language [[concepts/models|models]]. The file serves as a reference resource for users seeking to optimize their interactions with tools like [[concepts/anthropic-ai|Claude AI]] and [[entities/gemini-25-flash|Gemini 2.5 Flash]], capturing proven prompt structures and techniques that consistently produce better results.

## Purpose and Application

The primary function of a prompting swipe file is to document effective prompt patterns that users have found successful in their workflows. Rather than starting from scratch with each interaction, users can reference the collection to apply established techniques to new tasks. This approach reduces experimentation time and helps maintain [[concepts/logical-consistency|consistency]] in prompt quality across different [[concepts/scenarios|use cases]].

## Composition

A typical prompting swipe file includes prompts organized by use case or productivity goal—such as content generation, analysis, [[concepts/summarization|summarization]], or [[concepts/problem-solving|problem-solving]]. Each entry may contain the prompt [[concepts/text|text]] itself, context about when it works effectively, and [[concepts/notes|notes]] on variations or modifications that improve results for specific domains. The file evolves over time as users discover and test new prompt structures.
