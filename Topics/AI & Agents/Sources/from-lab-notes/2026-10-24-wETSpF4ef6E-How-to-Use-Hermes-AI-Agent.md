## How to Use Hermes AI Agent
**Clip title:** How to Use Hermes AI Agent
**Author / channel:** Kevin Stratvert
**URL:** https://www.youtube.com/watch?v=wETSpF4ef6E

### Summary
**Main Topic**
The video provides a step-by-step tutorial on how to install and use Hermes AI Agent, a free, open-source AI agent that automates tasks, remembers user preferences, and connects with local AI models.

**Key Points Discussed**
* **Installation:** The speaker demonstrates downloading and installing Hermes on a Windows PC (with support also available for macOS and Linux) and connecting it to a local AI model (Qwen3.8 27B) to avoid subscription or API costs.
* **Basic Tasks:** The speaker shows how Hermes can interact with the computer's file system, such as creating folders and documents based on natural language prompts.
* **Browser Integration:** The speaker connects Hermes to a web browser to perform tasks like reviewing YouTube comments and drafting responses.
* **Memory and Customization:** The speaker explains Hermes's ability to retain user preferences and instructions across sessions, ensuring consistent tone and behavior.
* **Automation and Skills:** The speaker demonstrates creating reusable "skills" and scheduling automated jobs to run tasks (like checking YouTube comments) periodically.
* **Messaging Integration:** The speaker mentions that Hermes can connect to messaging apps like WhatsApp or Telegram for mobile access.

**Conclusions and Takeaways**
Hermes AI Agent offers a powerful, customizable solution for automating everyday tasks using open-source local AI models. Its memory retention, browser integration, scheduling capabilities, and messaging connectivity make it a versatile tool for managing workflows without ongoing subscription costs.
