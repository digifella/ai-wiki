# AI application

[[concepts/software|Software]] that leverages [[concepts/ai-technologies|artificial intelligence]] to perform tasks requiring human-like intelligence, such as data analysis, pattern recognition, or decision [[concepts/automation|automation]].

## Notable implementations

- **[[entities/microsoft|Microsoft]] [[entities/data-formulator|Data Formulator]]**: AI-powered tool for generating data visualizations using [[concepts/llm-backend|LLM backend]].
  - Installation: `pip install data_formulator`
  - Launch: `data_formulator` or `[[entities/python|python]] -m data_formulator`
  - Requires AI [[concepts/model-configuration|model configuration]] (e.g., via [[concepts/environment-variables|environment variables]])
  - Video demonstration: [Coding with Steven: Microsoft Data Formulator](https://www.youtube.com/watch?v=Yj9JVPUTGHE)
