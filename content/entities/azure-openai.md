# Azure OpenAI

Azure OpenAI is [[entities/microsoft|Microsoft]]'s cloud-based service that provides access to [[entities/openai|OpenAI]]'s [[concepts/large-language-model-llm|large language models]] and [[concepts/capabilities|AI capabilities]] through the Azure platform. It integrates OpenAI's [[concepts/models|models]] with Microsoft's enterprise cloud infrastructure, enabling organizations to build [[concepts/ai-powered-applications|AI applications]] with the [[concepts/security|security]], [[concepts/compliance|compliance]], and [[concepts/integration|integration]] benefits of Azure.

## Integration with Microsoft Foundry

Azure OpenAI serves as a core component of [[concepts/agent-factory|Microsoft Foundry]], a [[concepts/unified-platform|unified platform]] for building AI applications and [[concepts/agents|agents]]. Microsoft Foundry leverages Azure OpenAI's models alongside other Azure services to provide a comprehensive factory for developing, deploying, and managing AI-powered [[concepts/software|applications]] and [[concepts/agentic-systems|autonomous agents]] at enterprise scale.
