# Private Execution

Private execution refers to the capability of [[concepts/running|running]] [[concepts/artificial-intelligence-models|artificial intelligence models]] locally on a user's own [[concepts/hardware|hardware]] rather than sending data to remote servers. This approach prioritizes data [[concepts/privacy|privacy]] and [[concepts/security|security]] by keeping sensitive information on-device, eliminating the need to transmit it across networks to [[concepts/cloud-based-services|cloud-based services]]. Private execution is particularly valuable for organizations handling confidential information, medical records, or proprietary data.

[[concepts/model-customization|Open-weight models]] like [[concepts/23b-parameter-models|Google Gemma 4]] enable private execution by making [[concepts/model-weights|model weights]] publicly available, allowing developers and organizations to download and run them independently. This stands in [[concepts/contrast|contrast]] to closed models accessed only through APIs or [[concepts/cloud-computing|cloud services]]. By distributing the model weights openly, organizations can deploy [[concepts/capabilities|AI capabilities]] with full [[concepts/power|control]] over data handling and processing infrastructure.

The trade-offs of private execution include increased computational requirements on local hardware and responsibility for model maintenance and optimization. However, the benefits include reduced latency, offline functionality, and complete [[concepts/data-sovereignty|data sovereignty]]. Private execution is increasingly important as privacy regulations tighten and organizations seek alternatives to centralised AI services.
