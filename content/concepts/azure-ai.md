# Azure AI

[[entities/microsoft|Microsoft]] [[entities/azure|Azure]]'s suite of [[concepts/ai-technologies|artificial intelligence]] services for building, deploying, and managing [[concepts/ai-models|AI models]] and [[concepts/software|applications]]. Integrates with Azure services for enterprise-grade [[concepts/security|security]], scalability, and [[concepts/personalization|customization]].

## Key Services
- Azure [[entities/openai|OpenAI]] Service: Access to [[concepts/openai-models|OpenAI models]] with Azure security/[[concepts/compliance|compliance]]
- Azure Cognitive Search: [[concepts/ai-powered-search|AI-powered search]] with [[concepts/document-processing|document processing]]
- Azure [[entities/ai-studio|AI Studio]]: [[concepts/unified-platform|Unified platform]] for [[entities/agent|agent]] development and [[concepts/testing|testing]]
