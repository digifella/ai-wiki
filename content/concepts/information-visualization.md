# Information Visualization

[[concepts/information-design|Information visualization]] is the process of representing abstract data in a visual or graphical format to facilitate understanding and interpretation. This includes various methods such as charts, graphs, [[concepts/diagrams|diagrams]], and maps that help users explore large datasets, discover patterns, and communicate insights effectively.

## Key Concepts
- Visual [[concepts/encoding|encoding]]: Mapping quantitative and qualitative attributes to visual variables.
- Interaction [[concepts/design|design]]: Designing interfaces for exploration and manipulation of data.
- Perception and [[concepts/cognition|cognition]]: Understanding how humans perceive and process visual information.
- Data [[concepts/abstraction|abstraction]]: Simplifying complex data structures into manageable forms.

## Methods & Tools
- **[[concepts/mind-maps|Mind Maps]]:** Structured diagrams that represent visually hierarchical information, often created with tools like [[entities/notebooklm]] and enhanced using [[concepts/ai-technologies|AI technologies]] such as [[entities/google-gemini]].
  - Exporting [[concepts/mind-maps|mind maps]] from [[concepts/notebooklm|NotebookLM]] as [[concepts/images|images]] for further enhancement.
  - Leveraging [[concepts/gemini|Gemini AI]] to transform basic mind maps into engaging visuals (see 2026 04 08 Video 1).

## Enhancing Mind Maps with AI
- **Standard Mind Map Creation:** Using [[concepts/ai-integrated-notebooks|NotebookLM]] to generate initial mind maps from document uploads or web research.
  - Exporting the map as an image for external processing.
- **[[concepts/ai-workflow|AI Enhancement]] Methods:**
  - Generating rich, detailed versions of basic mind maps using [[entities/gemini-ai|Gemini AI]].
  - Making complex data more digestible and shareable through improved [[concepts/visual-representation|visual representation]].
