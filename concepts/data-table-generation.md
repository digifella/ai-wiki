# Data Table Generation

The process of converting unstructured or semi-structured information into organized, tabular formats.

### notebooklm Capabilities
- Recent [[concepts/software-updates|updates]] enable the transformation of various media sources into structured [[concepts/data-tables]].
- **Supported Sources:** [[entities/youtube|YouTube]] videos, websites, and uploaded files.
- **[[concepts/customizable-extraction|Customizable Extraction]]:**
    - Users can define specific columns and types of information to extract.
    - Allows for targeted data mining of specific [[concepts/nodes|entities]] (e.g., movie rankings, directors, or awards) directly from source transcripts or text.
