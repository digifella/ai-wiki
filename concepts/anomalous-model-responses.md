# Anomalous Model Responses

Phenomenon where [[concepts/large-language-models|Large Language Models]] (LLMs) produce bizarre, nonsensical, or degraded outputs in response to specific, seemingly innocuous input strings. Often linked to [[concepts/byte-pair-encoding]] artifacts and LLM [[concepts/glitch-tokens|Glitch Tokens]].

## Key Characteristics
- **Trigger Sensitivity**: Specific token sequences cause disproportionate degradation in [[concepts/output-quality|output quality]].
- **Output Degradation**: Responses may become repetitive, incoherent, or semantically void.
- **Tokenization Dependency**: Closely tied to how [[concepts/byte-pair-encoding]] maps subwords to integer IDs.
