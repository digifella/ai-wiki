# BitNet
[[concepts/1-bit-llm|BitNet]] refers to a specialized architecture for [[concepts/model-efficiency]] designed to enable efficient [[concepts/edge-computing|edge computing]] and large-scale [[concepts/ai-model-deployment|model deployment]] on personal hardware.

### Key Characteristics
- **Extreme [[concepts/model-efficiency|Quantization]]**: Utilizes 1-bit [[concepts/weights|weights]] to minimize computational and [[concepts/memory-overhead|memory overhead]].
- **[[concepts/on-device-ai|On-Device Deployment]]**: Enables high-[[concepts/parameter-models|parameter models]] (e.g., 27B) to run on mobile devices/smartphones.
- **Resource [[concepts/ai-workflow|Optimization]]**:
    - ~90% reduction in model file size compared to [[concepts/full-precision|full-precision]] models.
    - Up to 15x reduction in [[concepts/memory|memory]] consumption.
- **Hardware Impact**: Represents a potential [[concepts/mindset-shift|paradigm shift]] that reduces reliance on high-end GPUs for [[concepts/inference|inference]].
