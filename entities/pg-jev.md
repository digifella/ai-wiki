# PG-Jev

**PG-Jev** is a [[concepts/postgresql-extension|PostgreSQL extension]] that enables [[concepts/natural-language-querying|natural language querying]] directly within SQL, facilitating [[concepts/ai-driven-decision-modeling|AI-driven decision modeling]] for filtering, ranking, and classifying database rows.

- **Core Functionality:** Allows users to apply plain English conditions to database operations without [[concepts/writing|writing]] complex SQL syntax.
- **Differentiation:** Positioned not merely as a theoretical [[concepts/decision-model|decision model]] but as a practical tool for [[concepts/real-world-data|real-world data]] manipulation.
- **Key Capabilities:**
  - Natural language input processing
  - Dynamic [[concepts/row-filtering|row filtering]]
