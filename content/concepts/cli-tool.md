# Cli Tool

[[concepts/autonomous-coding|Gemini CLI]] is an [[concepts/open-source|open-source]] [[concepts/command-line-interface|command-line interface]] tool developed by [[concepts/google-search|Google]] that functions as an [[concepts/autonomous-ai-coding-agent|autonomous AI coding agent]]. It enables developers to interact with [[entities/google|Google]]'s [[entities/gemini-models|Gemini AI]] model directly from the terminal, facilitating [[concepts/code-generation|code generation]], analysis, and [[concepts/coding|software development]] tasks through natural language [[concepts/commands|commands]].

## Capabilities

The tool is designed to assist with software [[concepts/development-workflows|development workflows]] by accepting user [[concepts/instructions|instructions]] and generating code or modifications in response. As an [[concepts/ai-agent|autonomous agent]], it can perform iterative tasks and [[entities/make|make]] decisions based on code context, reducing manual intervention in routine development activities.

## Availability

[[concepts/gemini-cli|Gemini CLI]] is distributed as open-source [[concepts/software|software]], making it freely available for developers to use, modify, and contribute to. This approach aligns with Google's strategy of making advanced [[concepts/ai-development|AI development]] tools accessible to the broader programming community.
