# Google Slides Integration

[[concepts/google-slides|Google Slides]] Integration refers to the incorporation of [[concepts/gemini|Gemini AI]] capabilities directly into Google Slides, Google's cloud-based presentation software. This integration enables users to leverage [[concepts/generative-ai|generative AI]] to assist in creating, formatting, and populating [[concepts/slide-decks|slide decks]]. The feature operates within the existing Google Slides interface, allowing users to generate content, suggest layouts, and refine presentations without switching between applications.

## Functionality

The integration allows users to prompt Gemini to generate text content for slides, create outlines from existing documents, and suggest design layouts based on the provided topic. Users can input specific [[concepts/instructions|instructions]] to adjust the [[concepts/tone|tone]], length, or structure of the generated material. The [[concepts/artificial-intelligence-tool|AI tool]] is accessible via a [[concepts/sidebar|sidebar]] within the Google Slides editor, facilitating a seamless workflow for [[concepts/writing|drafting and editing]] presentations.

## Availability

This feature is available to users with compatible [[concepts/google-workspace|Google Workspace]] accounts, including those on [[concepts/paid-plans|paid plans]] and eligible free accounts. Access may vary based on region and account type, with some advanced capabilities reserved for specific [[concepts/pricing-tiers|subscription tiers]]. The integration is designed to work alongside existing Google Slides tools, enhancing [[concepts/productivity|productivity]] by automating initial content generation and structural suggestions.
