# Pdp 1144

The PDP-11/44 is a 16-bit minicomputer manufactured by Digital Equipment Corporation, released in 1979 as part of the widely-used [[concepts/pdp-11|PDP-11]] series. It occupied the mid-range segment of the PDP-11 lineup, offering enhanced capabilities compared to earlier models while remaining more accessible than the highest-end offerings. The system featured improved [[concepts/memory-management|memory management]] and floating-point processing capabilities, making it suitable for scientific, educational, and commercial applications.

## Technical specifications

The PDP-11/44 was built around the standard PDP-11 architecture, utilizing a 16-bit word length and the instruction set common to the series. It supported larger memory configurations than earlier PDP-11 models and included memory management hardware that enabled more sophisticated software environments and multi-user capabilities.
