# Chatbot Setup Process

Setting up [[concepts/ai-chatbots|AI chatbots]] for [[concepts/legal-work|legal work]] requires configuring [[concepts/custom-instructions|custom instructions]] that establish baseline parameters for how each system responds to professional queries and documentation tasks. The three primary platforms—[[entities/chatgpt|ChatGPT]], [[concepts/claude-ai|Claude]], and [[concepts/gemini|Gemini]]—each provide [[concepts/customization|customization]] features accessible through their settings interfaces. These features allow users to define role-specific behaviors, response formats, and knowledge boundaries appropriate for legal practice.

## Configuration Fundamentals

Custom [[concepts/instructions|instructions]] function as standing [[concepts/recommendations|directives]] that persist across conversation sessions. Users can specify that the chatbot should adopt a particular [[concepts/expertise|expertise]] level, follow specific citation formats, maintain document confidentiality protocols, or flag legal disclaimers automatically. The [[concepts/installation|setup process]] typically involves completing a structured questionnaire where users describe their role, primary [[concepts/scenarios|use cases]], and preferred response [[concepts/style|style]]. This foundational configuration helps ensure [[concepts/logical-consistency|consistency]] when the chatbot handles routine legal research, [[concepts/legal-document-review|contract review]] [[concepts/preparation|preparation]], or documentation drafting.

## Platform-Specific Features

Each platform implements customization differently. ChatGPT's system allows users to set instructions directly within account settings that apply to all conversations. [[concepts/claude|Claude]] provides similar functionality through custom instructions that shape [[concepts/model-behavior|model behavior]] while maintaining [[concepts/opacity|transparency]] about the system's limitations. [[concepts/google-ai|Gemini]]'s customization occurs primarily through [[concepts/prompt-based-modeling|prompt engineering]] within individual conversations, though some persistent settings are available. [[concepts/legal-professionals|Legal professionals]] should review each platform's documentation to understand how instructions interact with the underlying model's training and [[concepts/ai-safety|guardrails]].

## Best Practices for Setup

Effective chatbot configuration for legal work should include clear statements about the chatbot's non-lawyer status, appropriate [[concepts/use-cases|use cases]] (such as research assistance rather than legal advice), and [[concepts/document-interaction|document handling]] expectations. Instructions should specify citation preferences, relevant practice areas, and any jurisdiction-specific considerations. Regular review of configured instructions ensures they remain aligned with evolving workflows and comply with professional [[concepts/accountability|responsibility]] standards.
