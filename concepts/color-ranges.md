# Color Ranges

Color Ranges in Lightroom Classic refers to the targeted adjustment of specific color ranges within an image using HSL (Hue, Saturation, Lightness) controls. Rather than applying adjustments uniformly across an entire image, this approach isolates individual color ranges—such as reds, oranges, yellows, greens, cyans, blues, and magentas—for independent modification. This selective control enables precise color grading without affecting other colors in the photograph.

## How It Works

The feature operates by allowing users to define a specific hue range within the HSL panel. Once a target color is selected, the interface provides sliders to adjust the width of the range and the transition between the selected and unselected areas. This ensures that adjustments to hue, saturation, or lightness are applied only to pixels falling within the defined boundaries, minimizing unwanted artifacts or color shifts in adjacent tones.

## Practical Application

This functionality is particularly useful for correcting skin tones, enhancing skies, or isolating specific elements for creative grading. By narrowing the range, editors can modify a specific shade of blue in the sky without altering the blue in a subject's clothing. Conversely, widening the range allows for broader adjustments while maintaining smooth transitions, ensuring that the final image retains natural color continuity despite localized edits.
