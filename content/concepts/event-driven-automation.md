# Event-driven automation

A [[concepts/workflow|workflow]] paradigm where execution is triggered by specific state changes, $\text{stimuli}$, or occurrences, rather than pre-defined intervals.

### Key Concepts
- **Mechanism**: Unlike [[concepts/time-based-automation]] (which functions like an alarm clock triggering at fixed intervals), event-driven systems [[entities/react|react]] to real-time "actions" or "events."
- **Evolution of [[concepts/ai-automation]]**: Recent shifts focus on moving away from scheduled execution toward reactive, action-based logic.

### Recent Developments
- **[[concepts/claude-ai|Claude]] Routines**: A new implementation by [[entities/anthropic]] designed for action-based [[concepts/ai-automation-agents|AI automation]], specifically optimized for [[concepts/business-event-response|business event response]].
- **[[entities/claude-co-work|Claude CoWork]]**: Facilitates [[concepts/workflow-automation|workflow automation]] via local file access and [[concepts/ai-projects|AI projects]], aimed at bridging the "awareness gap" regarding [[concepts/capabilities|AI capabilities]].
