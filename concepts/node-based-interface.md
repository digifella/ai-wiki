# Node-Based Interface

A **Node-Based Interface** (NBI) is a [[concepts/gui-interface|graphical user interface]] paradigm where functionality is represented as discrete [[concepts/nodes|nodes]] connected by directed edges (wires). Data flows between nodes, allowing users to construct [[concepts/complex-workflows|complex workflows]], [[concepts/open-source-philosophy|logic]] chains, or data processing pipelines visually rather than through linear code or menu-driven [[concepts/commands|commands]].

## Core Characteristics

- **Visual Data [[concepts/flow|Flow]]**: Explicit representation of input/output [[concepts/relationships|relationships]].
- **Modularity**: Functions are encapsulated in reusable nodes.
- **Non-Linear Execution**: [[concepts/parallel-processing|Parallel processing]] and conditional branching are visually intuitive.
- **[[concepts/amnesia|Statelessness]]**: Nodes typically process inputs to produce outputs without retaining [[concepts/hidden-state|internal state]] between executions.
