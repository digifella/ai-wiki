# Background Agents

**Background Agents** are autonomous software processes or AI-driven [[concepts/nodes|entities]] that operate independently of direct user interaction, executing tasks, [[concepts/monitoring-systems|monitoring systems]], or managing data in the background. They are critical for maintaining system state, automating workflows, and enabling [[concepts/model-intelligence|persistent intelligence]] in [[concepts/ai-models|AI Systems]].

## Key Characteristics
- **Autonomy**: Operate without continuous human input.
- **[[concepts/data-persistence|Persistence]]**: Maintain state and context over time.
- **Integration**: Interface with various [[concepts/open-standard-protocols|APIs]], [[concepts/communication|messaging]] systems, and engines.

### Muse Code: Fan-Out AI Agent with Vision for Complex Coding and Repair
[[entities/meta|Meta]]'s **[[concepts/ai-coding-agent|Muse Code]]** represents a specialized class of persistent agents designed for [[concepts/complex-coding-workflows|complex coding workflows]]. Unlike tools limited to "toy scripts," [[entities/muse-code|Muse Code]] operates directly within the user's [[concepts/cli|terminal]] to handle extensive projects and "messy jobs."

- **Persistent Context**: Maintains persistent "agent" state across complex, multi-step [[concepts/coding|coding]] tasks.
- **[[concepts/computer-vision|Vision]] Integration**: Utilizes [[concepts/vision-capabilities|vision capabilities]] to interpret codebases and environment context.
- **[[concepts/fan-out-architecture|Fan-Out Architecture]]**: Employs a fan-out mechanism to manage [[concepts/parallel-processing|parallel processing]] of coding and repair tasks.
- **Terminal-Native**: Designed to streamline workflows by operating directly within the terminal environment.
