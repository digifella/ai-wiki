# Native Integration

Native [[concepts/integration|integration]] refers to the built-in connectivity features that allow [[concepts/software|applications]] to function seamlessly across different platforms and tools. In the context of [[entities/gemini-models|Google Gemini]], native integration encompasses the application's direct connections with other [[concepts/google-search|Google]] services and third-party platforms, enabling users to work with unified functionality without requiring additional [[concepts/plugins|plugins]] or manual data transfers.

## Gemini's Integration Capabilities

[[entities/google-ai-ultra|Google Gemini]]'s native integration features enable direct interaction with [[entities/google-workspace|Google Workspace]] applications, including Docs, Sheets, and [[entities/google-slides|Slides]]. These connections allow users to access Gemini's [[concepts/capabilities|AI capabilities]] within their existing workflows. The application also supports integration with [[concepts/external-tools|external tools]] and services, expanding its utility beyond the Google ecosystem for collaborative work and content generation tasks.

## Cross-Platform Functionality

The end-to-end functionality of Gemini is designed to work across multiple devices and platforms. Users can access core features consistently whether working on desktop, mobile, or web-based interfaces. This cross-platform approach ensures that integrated workflows remain functional regardless of the user's preferred working environment or device.
