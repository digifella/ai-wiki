# Smart Objects

Smart Objects are specialized layer containers in Adobe Photoshop that preserve original source content while enabling non-destructive editing workflows. When a layer is converted to a Smart Object, Photoshop embeds or links the source material within the layer, keeping the underlying data intact regardless of transformations applied. This allows editors to scale, rotate, warp, and otherwise modify images multiple times without degrading image quality or losing the original pixel information.

The primary advantage of this technology is its support for iterative design processes. Because the source data remains unaltered, adjustments such as color grading, filtering, and image enhancement can be modified or removed at any stage of the project. This non-destructive nature ensures that the original image quality is maintained even after extensive manipulation, providing greater flexibility compared to standard raster layers.

Smart Objects also facilitate efficient workflow management through linking. Instead of embedding the file data directly, users can link to external source files, allowing updates to the original asset to automatically reflect within the Photoshop document. This feature is particularly useful for managing complex projects involving multiple assets or for maintaining consistency across different design files.
