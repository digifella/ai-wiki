# Agent Scaling

Agent [[concepts/computational-scaling|scaling]] refers to the methods and frameworks for expanding [[concepts/ai-agent|AI agent]] capabilities and deployment across different contexts and complexity levels. [[concepts/claude-ai|Claude]]'s 2026 update introduced several key components designed to make [[concepts/agent-development|agent development]] more accessible and manageable for developers working with increasingly sophisticated [[concepts/voice-assistants|autonomous systems]].

## Advisor Strategy

The [[concepts/advisor-strategy|Advisor Strategy]] framework provides a structured approach for agents to seek [[concepts/recommendations|guidance]] and validation during [[concepts/decision-making|decision-making]] processes. This pattern helps agents handle uncertainty by [[concepts/consulting|consulting]] additional resources or [[concepts/verification|verification]] steps before executing critical actions, reducing the risk of autonomous errors in production environments.

## Monitor Tool

The [[concepts/monitor-tool|Monitor Tool]] enables [[concepts/real-time-observation|real-time observation]] and tracking of agent behavior and [[concepts/performance-data-gathering|performance metrics]]. It allows developers to maintain visibility into agent operations, identify bottlenecks, and gather data on how agents perform under different conditions. This observability is essential for iterative improvement and [[concepts/debugging|debugging]] complex agent behaviors.

## Managed Agents

[[concepts/managed-agents|Managed Agents]] represent a hosted or semi-automated approach to [[concepts/agent-deployment|agent deployment]], where infrastructure and [[concepts/coordination|coordination]] responsibilities are partially handled by a platform rather than requiring complete custom implementation. This [[concepts/abstraction|abstraction]] layer lowers the barrier to entry for developers building agent-based applications while maintaining control over core [[concepts/open-source-philosophy|logic]] and decision-making processes.
