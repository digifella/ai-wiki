# Recurring Actions

Recurring Actions is a feature within [[concepts/gemini|Google Gemini]] that enables users to automate tasks scheduled to run at regular intervals. Rather than manually executing the same workflow repeatedly, users can configure actions to trigger automatically on a defined schedule—whether daily, weekly, monthly, or at custom intervals. This reduces manual overhead and ensures consistent [[concepts/workflow-automation|task execution]] without requiring user intervention each time the action is due.

## Configuration

Users establish Recurring Actions by specifying the task to be automated, defining the frequency and timing of execution, and setting any necessary parameters or conditions. The configuration interface allows customization of intervals to match specific business or personal needs. Once configured, the action runs according to its schedule with minimal ongoing management required from the user.

## Use Cases

Recurring Actions are suited for tasks that benefit from regular, predictable execution, such as data collection, report generation, status checks, or routine notifications. By automating these workflows, users can redirect their attention to higher-value activities while ensuring that recurring responsibilities are handled consistently and on schedule.
