# Gemini Pro

[[entities/gemini-app|Gemini Pro]] is an AI tool that can be used to generate prompts for other [[concepts/ai-powered-applications|AI applications]]. A notable [[concepts/workflow|workflow]] involves using Gemini Pro to write prompts that are then executed through [[entities/nanobanana-pro|Nanobanana Pro]] via an API interface.

## Cost Optimization

One primary application of this workflow is reducing expenses associated with multiple AI tool subscriptions and usage. By leveraging Gemini Pro's prompt generation [[concepts/capabilities|capabilities]] as an intermediary step, users can optimize their use of other [[entities/ai-tools|AI tools]], potentially decreasing overall costs when managing multiple AI applications.

## Practical Implementation

The [[concepts/integration|integration]] between Gemini Pro and Nanobanana Pro represents a practical approach to AI tool stacking, where the strengths of different [[concepts/software|applications]] are combined through API connections to create a more efficient workflow.
