# AlphaGo

**AlphaGo** is a series of [[entities/ai]] [[concepts/software|programs]] developed by [[entities/deepmind]] to play the board game Go. It was the first computer program to defeat a professional human Go player without handicaps, marking a significant milestone in [[concepts/ai-technologies|Artificial Intelligence]] and [[concepts/machine-learning]].

## Key Milestones
- **2015**: Defeated European Go champion Fan Hui.
- **2016**: Defeated Lee Sedol, a nine-dan professional, in a five-game match.
- **2017**: AlphaGo [[concepts/concept-of-nothingness|Zero]] achieved superhuman performance by training solely through self-play, surpassing previous versions.

## Technical Architecture
- Utilizes [[concepts/deep-neural-networks]] combined with Monte Carlo Tree Search (MCTS).
- Employs Policy Networks to select moves and Value Networks to evaluate board positions.
- Transitioned from supervised [[concepts/learning|learning]] on human games to [[concepts/machine-learning]] via self-play.
