# Lr Lightroom

Lr is a camera application developed by [[entities/adobe|Adobe]] for [[entities/iphone|iPhone]] devices, currently in beta. The app is designed specifically for [[entities/iphone-13-pro|iPhone 13 Pro]] and later models, leveraging the advanced camera hardware available in these devices.

## Features

The application offers several computational photography capabilities. These include advanced zoom functionality, enhanced night mode for low-[[concepts/light|light]] photography, and a [[concepts/reflection-removal|reflection removal]] tool designed to eliminate unwanted reflections from [[entities/windows|windows]] and glasses. The app integrates with [[entities/adobe|Adobe]]'s [[concepts/lightroom|Lightroom]] ecosystem, allowing users to capture and process images within a unified workflow.

## Development Status

As a beta product, Lr has undergone refinement following initial releases. Early versions experienced thermal management issues that caused device overheating; subsequent [[concepts/software-updates|updates]] addressed these performance concerns. The app represents [[concepts/adobe|Adobe]]'s effort to extend [[entities/adobe-lightroom|Lightroom]]'s functionality from post-processing software into the image capture stage itself.
