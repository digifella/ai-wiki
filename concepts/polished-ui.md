# Polished Ui

Ollama has introduced a native graphical user interface (GUI) to complement its existing command-line interface (CLI) and application programming interface (API). This release marks a significant expansion in how users interact with the platform, providing a more accessible entry point for individuals who may be unfamiliar with terminal-based workflows or direct API integrations.

The new interface allows users to download, run, and manage large language models through a visual environment rather than relying solely on text commands. By abstracting the underlying technical complexity, the GUI simplifies the process of model selection and configuration, enabling broader adoption among developers and non-technical users alike.

This addition does not replace the CLI or API but serves as an alternative front-end for those who prefer a point-and-click experience. It maintains compatibility with the core Ollama engine, ensuring that users can switch between interfaces without losing access to the platform's full capabilities.
