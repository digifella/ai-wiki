# LiDAR

**LiDAR** ([[concepts/light|Light]] Detection and Ranging) is a technology that uses laser beams to measure distance and create [[concepts/3d-point-clouds|Point Cloud data]].

## Mobile Scanning via iPhone Pro
- **[[concepts/arkit|ARKit]] Workflow**: Uses the integrated LiDAR sensor to capture spatial environment data.
- **3DGS Compatibility**: Data captured via ARKit can be converted into formats compatible with [[concepts/3d-gaussian-splatting|3D Gaussian Splatting]] (3DGS) training software to generate high-fidelity 3D models.
