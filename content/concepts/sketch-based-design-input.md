# sketch-based design input

A [[concepts/design-thinking|design methodology]] where hand-drawn or digital sketches serve as primary input for AI systems to generate refined UI layouts and production [[concepts/code|code]]. Enables rapid [[concepts/iteration|iteration]] from initial ideation to functional prototypes.

**Key characteristics:**
- Accepts freehand sketches or rough digital drawings as input
- Generates layered, production-ready UI designs and code within seconds
- Reduces manual design-to-dev handoff time

**[[concepts/adoption|Implementation]] example:**
- [[entities/google-stitch|Google Stitch]] 2.0: [[concepts/ai-design-agent|AI design agent]] powered by [[entities/gemini-3|Gemini 3]].0 Pro that converts sketches into professional UIs with heatmap predictions for user [[concepts/attention-mechanisms|attention]]. Produces code in under 60 seconds.
