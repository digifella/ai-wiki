# 2D Image Rotation

2D Image Rotation refers to the process of rotating flat, two-dimensional [[concepts/images|images]]. Traditionally, this involved simple directional turns at fixed angles (90°, 180°, 270°) or free rotation within a plane. These operations preserve the image's fundamental two-dimensional character while changing its orientation relative to the viewer. Standard rotation tools have been a basic feature of image editing [[concepts/software|software]] for decades.

## AI-Assisted 3D Manipulation

Recent advances in AI-assisted image editing have expanded the capabilities of image rotation beyond standard planar transformations. [[concepts/beta-version|Photoshop Beta]]'s AI Rotate Object tool represents a notable development in this direction, enabling users to manipulate selected objects within 2D images as though they were three-dimensional. Rather than simply rotating the entire image or flattened layers, this tool uses machine [[concepts/learning|learning]] to infer the three-dimensional [[concepts/structure|structure]] of objects and allow rotation along multiple axes, creating the visual effect of viewing an object from different angles.

This approach differs from traditional 3D modeling by operating on existing 2D images rather than requiring three-dimensional data or assets. The AI estimates depth and form based on visual context, allowing for rotations that appear physically plausible while working within the constraints of the original photograph or artwork.
