# Gema 3 Model

The Gema 3 Model is a conceptual framework for interacting with [[concepts/demystifying-llms|Large Language Models]] (LLMs) by treating them as structured, queryable systems rather than opaque text [[concepts/central-processing-units|processors]]. Instead of relying solely on [[concepts/natural-language-prompting|natural language prompting]], the framework proposes systematic access to and modification of internal representations and learned knowledge through structured operations. This approach aims to move beyond conventional [[concepts/behavioral-types|interaction patterns]] toward more direct manipulation of model internals.

## Core Mechanism

The framework utilizes Larql, a query language designed to access and modify the internal database structures of Large Language Models. Larql provides a method for querying and modifying these structures, allowing for precise [[concepts/document-retrieval|retrieval]] and alteration of the data embedded within the model. This mechanism enables users to interact with the model's underlying architecture directly, facilitating operations that are not typically possible through standard text-based interfaces.
