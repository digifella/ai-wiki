# Loop Based Workflow

Loop Based Workflow is an [[concepts/ai-assisted-coding|AI coding]] technique that leverages loops as a fundamental mechanism for structuring [[concepts/problem-solving|problem-solving]] approaches. The technique draws its name from the "Ralph" method, popularized in a video by [[entities/gary-explains|Gary Explains]], which demonstrates how iterative loops can be used to guide AI systems through [[concepts/coding|coding]] tasks. Rather than attempting to solve problems in a single pass, this approach breaks tasks into repeatable cycles that progressively refine outputs or work toward solutions.

## Core Mechanism

The technique involves creating [[concepts/feedback|feedback]] loops where an AI system evaluates its own work, identifies gaps or errors, and iterates on solutions. Each loop [[concepts/iteration|iteration]] serves as an opportunity to improve upon previous attempts, validate logic, or clarify requirements. This cyclical [[concepts/structure|structure]] mirrors human problem-solving processes and can be particularly effective for complex coding challenges where initial attempts are unlikely to be optimal.

## Application in AI Coding

Loop Based Workflow has become relevant in the context of AI-assisted programming, where [[concepts/large-language-model-llm|large language models]] are prompted to generate, test, and refine code. By structuring interactions as loops rather than single queries, users can guide AI systems to produce more robust solutions. The approach is applicable across various programming contexts and can be adapted to different problem domains and complexity levels.
