# Proactive AI Assistant

A Proactive [[concepts/ai-assistant|AI Assistant]] is an [[concepts/ai-technologies|artificial intelligence]] agent designed to anticipate user needs and initiate actions without explicit prompts, aiming to maintain workflow [[concepts/continuity|continuity]] and reduce [[concepts/cognitive-load|cognitive load]].

## Key Characteristics
- **Always-on Availability**: Operates continuously in the background, monitoring context and environment.
- **Anticipatory Action**: Predicts next steps based on user behavior, calendar, and communication patterns.
- **Orchestration**: Acts as a central hub to bridge disparate tools and services within a user's ecosystem.
- **Context [[concepts/conscious-thought|Awareness]]**: Maintains state across sessions to provide relevant, personalized assistance.

## Notable Implementations

### OpenAI Dots
[[concepts/whisper-transcription|OpenAI]] has introduced "[[entities/dots|Dots]]," an always-on, proactive [[concepts/personal-ai-assistant|personal AI assistant]] agent currently in early access for [[entities/chatgpt]] Pro and Enterprise users. Dots functions as a [[concepts/orchestrator-model|central orchestrator]] within the ChatGPT ecosystem, designed to enhance workflow continuity by seamlessly connecting various user components.
