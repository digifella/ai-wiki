# Agent Harnesses

Agent harnesses are computational frameworks that enable AI agents to execute code directly rather than relying solely on natural language generation. By integrating programming capabilities into agent systems, these harnesses allow language models to interact with external APIs, databases, web services, and other computational tools. This architecture addresses a fundamental limitation of text-only language models: the gap between describing an action and actually executing it in external systems.

## Code vs. Markdown Efficiency

The efficiency of agent operations is significantly enhanced when using code for tasks such as web scraping compared to using markdown. Code provides precise, executable instructions that can handle complex data structures and dynamic content, whereas markdown is primarily a formatting language that lacks the logic required for direct data extraction and manipulation. Consequently, harnesses that prioritize code execution reduce the ambiguity and error rates associated with parsing unstructured text outputs, leading to more reliable and faster integration with external digital environments.
