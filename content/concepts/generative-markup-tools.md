# Generative Markup Tools
Generative markup tools leverage [[concepts/ai-technologies|artificial intelligence]] to automate and enhance the creation of content and [[concepts/design|design]] elements. These tools are increasingly being integrated into popular [[concepts/design|graphic design]] [[concepts/software|applications]] like Adobe [[concepts/photoshop|Photoshop]] and [[entities/adobe-photoshop|Photoshop for the Web]].

## Key Features

- **[[concepts/layer-renaming|Automated Layer Renaming]]:** The [[concepts/ai-assistant|AI Assistant]] in [[entities/adobe-photoshop|Adobe Photoshop]] can automatically rename layers, which significantly speeds up editing processes.
- **[[concepts/design|Generative Design]] Capabilities:** With new generative markup tools, users can create complex designs and layouts with minimal input. These capabilities are driven by advanced [[concepts/machine-learning|machine learning]] algorithms.
- **Web-based [[concepts/ai-integration|AI Integration]]:** Integration of [[concepts/generative-markup-tools|AI Markup tools]] specifically within [[entities/adobe-photoshop|Photoshop for the Web]].
