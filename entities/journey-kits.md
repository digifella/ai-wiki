# Journey Kits

Journey Kits is a software project deployment that became a documented case study in AI-assisted development costs and cloud infrastructure expenses. The project gained public attention through analysis by technology commentator Matthew Berman, whose video examination titled "The dark side of vibe coding" highlighted significant and unexpected billing overruns that occurred during deployment on Vercel's platform.

## Cost Overruns and Lessons

The Journey Kits deployment demonstrated how AI-assisted coding workflows, while potentially accelerating development velocity, can generate substantial unforeseen charges when deployed on usage-based cloud infrastructure. The case illustrated the importance of monitoring and setting cost controls during development cycles that rely on AI tools and cloud services, particularly when infrastructure costs scale with computational usage rather than being fixed expenses.

The incident has been referenced in discussions about responsible AI tool adoption and the practical infrastructure considerations developers should account for when choosing between rapid development velocity and cost predictability.
