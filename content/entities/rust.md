# Rust

This YouTube [[concepts/tutorial|tutorial]] demonstrates the process of constructing a real-time [[concepts/knowledge-graph|knowledge graph]] using [[concepts/large-language-model-llm|Large Language Models]] and the [[concepts/etl-framework|Cocoindex framework]]. The video, published on the Cocoindex channel, provides practical guidance on transforming document collections into structured knowledge representations suitable for LLM-based [[concepts/answer-generation|retrieval augmented generation]] (RAG) [[concepts/software|applications]].

## Technical Components

The tutorial covers the integration of three main technical elements: Large Language Models for semantic processing, the Cocoindex [[concepts/data-transformation|data transformation]] framework for handling [[concepts/file-ingestion|document ingestion]] and processing, and Neo4j as the underlying [[concepts/graph-database|graph database]] for storing and querying the knowledge graph. This combination enables dynamic updating and querying of knowledge structures in real time.

## Application Domain

The approach is specifically designed for [[concepts/llm-rag|LLM RAG]] systems, where [[concepts/knowledge-graphs|knowledge graphs]] serve as structured retrieval sources to ground [[concepts/statistical-language-modeling|language model]] [[concepts/responses|responses]] in verified information. The real-time aspect suggests the framework supports continuous addition and updating of knowledge from new or streaming document sources.
