# Universal Machine

The **Universal Machine** is a theoretical model of [[concepts/computation|computation]] introduced by [[entities/alan-turing|Alan Turing]] in his 1936 paper "On Computable Numbers". It demonstrated that a single machine could simulate the logic of any other computational machine, forming the conceptual foundation for the Stored-program computer.

## Core Concepts
- **Universality**: A universal machine can compute any computable function given the appropriate description (program) and input.
- **Turing Completeness**: A system is Turing complete if it can simulate a universal Turing machine.
- **Church-Turing Thesis**: The hypothesis that any function that would naturally be regarded as computable is computable by a Turing machine.
