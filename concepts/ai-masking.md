# AI Masking
[[concepts/ai-based-selection|AI Masking]] is a feature that utilizes [[concepts/ai-technologies|artificial intelligence]] to automatically create accurate masks for various elements within an image. This technology is particularly useful in software applications such as [[entities/adobe-photoshop|Adobe Photoshop]], [[concepts/lightroom|Lightroom Classic]], and [[concepts/camera-raw|Adobe Camera Raw (ACR)]], where it significantly speeds up the [[concepts/editing-workflow-optimization|editing process]] by automating tedious tasks like [[concepts/layer-masks|masking]].
