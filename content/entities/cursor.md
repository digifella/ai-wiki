# Cursor

AI-powered [[concepts/code|code]] editor designed for developers, featuring advanced code completion, refactoring, and integrated chat for code assistance. Built to replace traditional editors with AI-driven productivity workflows.

- [[entities/kombai]]: First AI [[entities/agent|agent]] [[concepts/motivation|purpose]]-built for [[concepts/frontend-development|frontend development]], integrating directly into Cursor. Benchmarks show 72% code review success vs. 30-50% for GitHub [[entities/copilot|Copilot]], [[entities/codepal|CodePal]], and [[entities/gemini]].
- [[entities/vs-code]]: Primary competitor IDE with similar [[concepts/ai-integration|AI integration]] capabilities.
- [[entities/windsuf|Windsuf]]: Alternative IDE mentioned in [[entities/kombai|Kombai]]'s [[concepts/integration|integration]] support.
