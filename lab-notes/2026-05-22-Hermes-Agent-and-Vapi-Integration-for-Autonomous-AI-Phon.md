The system also supports inbound calls and uses [[concepts/custom-tools|custom tools]], like an `ask_hermes` tool, enabling a Vapi [[concepts/tone|voice]] agent to query the main Hermes Agent for additional context or information during a live conversation, making the voice agent significantly more intelligent and dynamic.
