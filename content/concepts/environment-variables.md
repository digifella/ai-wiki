# Environment Variables

Environment variables in [[concepts/ai-assisted-coding|Claude Code]] are configuration settings that [[concepts/power|control]] [[concepts/workflow-optimization|workflow optimization]], [[concepts/output|output]] handling, and [[concepts/privacy|privacy]] features. These 12 [[concepts/hidden-settings|hidden settings]] allow developers to customize how [[concepts/claude-code|Claude Code]] processes tasks, manages data, and enforces [[concepts/security|security]] protocols without modifying core code [[concepts/structure|structure]].

## Configuration and Implementation

Environment variables function as named [[concepts/parameters|parameters]] that can be set before Claude [[concepts/code-execution|Code execution]] begins. They provide a standardized method for adjusting behavior across different workflows without requiring code changes. Proper configuration of these settings enables more efficient task processing and reduces the need for repeated manual [[concepts/adjustments|adjustments]] during development and [[concepts/deployment|deployment]] phases.

## Use Cases and Benefits

These settings are particularly valuable for teams managing multiple Claude Code instances or those requiring consistent output formatting across different projects. By leveraging environment variables, developers can implement [[concepts/privacy-controls|privacy controls]], optimize computational resource usage, and establish standardized output protocols that align with organizational requirements or project-specific constraints.
