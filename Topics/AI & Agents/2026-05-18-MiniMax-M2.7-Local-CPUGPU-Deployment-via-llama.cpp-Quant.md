## MiniMax-M2.7 Local CPU/GPU Deployment via llama.cpp Quantization
**Clip title:** [[entities/m27|MiniMax M2.7]] Running Locally on [[concepts/cpu|CPU]] + GPU - Everyone Can Do It
**Author / channel:** Fahd Mirza
**URL:** https://www.youtube.com/watch?v=Pc27eBNSrhc

### Summary
This video provides a comprehensive guide to locally deploying and [[concepts/testing|testing]] the recently open-sourced [[entities/m27|MiniMax-M2.7]] [[concepts/llm|large language model]]. The main topic revolves around demonstrating how this massive 229 billion parameter [[concepts/mixture-of-experts|Mixture of Experts]] (MoE) model, which in [[concepts/full-precision|full precision]] would require 230GB, can be run efficiently on a single [[concepts/nvidia-h100|NVIDIA H100]] GPU (equipped with 80GB [[concepts/vram|VRAM]]) and an [[entities/intel-xeon-platinum|Intel Xeon Platinum]] [[concepts/cpu|CPU]] with 125GB of system [[concepts/ram|RAM]] on an [[entities/ubuntu|Ubuntu]] 22.04 LTS system. The core tool enabling this feat is `llama.cpp`, specifically utilizing a 4-bit IQ4_XS quantized version of the model, which significantly reduces its size to 122GB.

The [[concepts/deployment|deployment]] process begins with setting up the `llama.cpp` environment, including [[concepts/cloning|cloning]] its [[entities/github|GitHub]] repository and building it with [[concepts/compute-unified-device-architecture|CUDA]] support using CMake. To manage the model's substantial size relative to the GPU's [[concepts/vram|VRAM]], `llama.cpp` intelligently splits the workload, offloading 60 [[concepts/transformer-layers|transformer layers]] to the [[concepts/nvidia-h100|H100 GPU]] and running the remaining layers on the CPU's system [[concepts/ram|RAM]]. This hybrid approach is crucial for enabling [[concepts/local-inference|local inference]] of such a large model. The video details the [[concepts/command-line-interface|command-line]] steps for installing the [[concepts/open-source-machine-learning|Hugging Face]] CLI, logging in, and downloading the quantized MiniMax-M2.7 model, which itself is a hefty 108GB file, emphasizing the need for adequate disk space.

Once installed and configured, the video showcases the model's capabilities through practical demonstrations via a web UI powered by `llama.cpp`. The model successfully handles a conversational prompt with a friendly and helpful response. More impressively, it performs [[concepts/complex-tasks|complex tasks]] such as generating a complete, self-contained HTML file for a "Matrix rain" and fluid particle [[concepts/simulation|simulation]] based on detailed requirements, demonstrating strong [[concepts/coding|coding]] and [[concepts/reasoning|reasoning]] abilities. Furthermore, the model exhibits excellent multilingual proficiency by accurately translating the phrase "1,2,3 Go" into 77 different global and low-resource languages. During these tests, the H100 GPU utilized approximately 67GB of VRAM, with the CPU handling a significant portion of the workload, confirming the effectiveness of the CPU/GPU offloading strategy.
