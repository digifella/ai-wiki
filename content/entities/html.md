# HTML

HTML (HyperText Markup Language) is the standard markup language for creating web pages and [[concepts/web-applications|web applications]]. It defines content [[concepts/structure|structure]] using elements (tags) and attributes.

## Key Features
- **Semantic structure**: HTML5 introduced semantic tags (`<header>`, `<article>`, `<footer>`) for [[concepts/accessibility|accessibility]] and SEO
- **Multimedia [[concepts/integration|integration]]**: [[concepts/native-support|Native support]] for `<audio>`, `<video>`, and `<[[entities/canvas|canvas]]>`
- **Form handling**: Rich input controls and validation attributes
- **[[concepts/accessibility|Accessibility]]**: Built-in ARIA support for screen readers
