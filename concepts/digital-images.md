# Digital Images

## Overview
A **Digital Image** is a numerical representation of a two-dimensional image, typically acquired by electronic means. Unlike analog images, digital images consist of a fixed number of picture elements known as **Pixels** (picture elements), each containing specific intensity or color values.

### Core Components
- **[[concepts/solution|Resolution]]**: The number of pixels per unit of measurement (e.g., PPI, DPI).
- **Bit Depth**: The number of [[concepts/classical-bits|bits]] used to represent the color of a single pixel.
- **Color Models**: Standards for representing colors, such as RGB (Red, Green, Blue) for emission-based displays and CMYK for printing.
- **File Formats**: [[concepts/json-structuring|Structured data]] [[concepts/containerization-technology|containers]] that define how image data is stored.
  - **Lossless**: PNG, GIF, TIFF — preserve exact original data.
  - **Lossy**: JPEG, WebP — use compression [[concepts/algorithms|algorithms]] to reduce file size at the cost of minor data loss.

## Data Structure & Representation
Digital images are fundamentally arrays of numbers. In an 8-bit grayscale image, values range from 0 (black) to 255 (white). In 24-bit color images, each pixel is composed of three 8-bit channels (R, G, B).

### Compression Techniques
Most digital image [[entities/storage|storage]] utilizes compression to manage file size:
1. **Entropy [[concepts/encoding|Encoding]]**: Statistical compression like Huffman [[concepts/coding|Coding]] or Arithmetic Coding.
2. **Transform Coding**: Converting spatial data into frequency data to identify redundant information.
   - **Discrete Cosine Transform (DCT)**: Used heavily in JPEG compression. It separates image data into low-frequency components (general structure) and high-frequency components (fine details). Human [[concepts/computer-vision|vision]] is less sensitive to high-frequency changes, allowing aggressive [[concepts/parameter-reduction|quantization]] (data removal) of these coefficients without noticeable quality loss.

## Security & Data Hiding
Due to the discrete nature of pixel data, digital images serve as vectors for [[concepts/data-hiding|data concealment]], distinct from [[concepts/cryptography]] (which obscures content) and Steganography (which hides the existence of content).

### Steganographic Methods
See [[lab-notes/2026-06-05-Steganography-in-Digital-Images-Concealing-Data-via-LSB|Steganography in Digital Images: Concealing Data via LSB and DCT Coefficients]] for detailed analysis.

*   **[[concepts/lsb-least-significant-bit|Least Significant Bit]] (LSB) Substitution**:
    *   Modifies the least significant bit of pixel values to embed binary data.
    *   **Pros**: Simple implementation; high capacity.
    *   **Cons**: Highly vulnerable to compression (e.g., converting to JPEG) or noise addition, as LSBs are often discarded or altered during processing.
    *   Best suited for lossless formats like BMP or PNG.

*   **DCT Coefficient Manipulation**:
    *   Embeds data within the coefficients generated by the Discrete Cosine Transform.
    *   **Pros**: More robust against common [[concepts/image-input-processing|image processing]] operations and compression artifacts compared to LSB.
    *   **Cons**: Lower payload capacity; requires more complex encoding/decoding algorithms.
    *   Primary method for hiding data in JPEG files.
