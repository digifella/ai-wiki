# Automated AI Agents

Automated AI agents are [[concepts/software|software]] systems that combine [[concepts/large-language-model-llm|large language models]] (LLMs) with [[concepts/ai-driven-workflow-automation|workflow automation]] tools to execute tasks with minimal human intervention. These [[concepts/agents|agents]] use [[concepts/nlp|natural language processing]] to understand objectives, plan action sequences, and interact with external systems or data sources. By integrating [[concepts/automation|automation]] platforms with language models, they can perform complex multi-step operations that would otherwise require manual coordination or custom scripting.

## Local Deployment with N8N and Ollama

Organizations seeking to run [[concepts/agentic-ai|AI agents]] without relying on cloud-based APIs can deploy them locally using [[concepts/open-source|open-source]] tools. N8N is a workflow automation platform that provides a visual interface for building and orchestrating complex processes, while Ollama enables the [[concepts/local-execution|local execution]] of open-source language models like [[concepts/gpt-4|GPT-OSS]]. This combination allows users to maintain full control over their data and [[concepts/computational-resources|computational resources]] while leveraging LLM capabilities for decision-making and task execution.

The local deployment approach involves configuring N8N to call the [[concepts/statistical-language-modeling|language model]] [[concepts/running|running]] on Ollama, enabling the agent to process natural language inputs and generate [[concepts/responses|responses]] or actions based on the workflow context. This [[concepts/architecture|architecture]] is particularly valuable for organizations with sensitive data, specific [[concepts/compliance|compliance]] requirements, or limited internet connectivity, as it avoids external API dependencies while still providing the [[concepts/ai-in-robotics|intelligent automation]] capabilities of modern AI systems.
