# Keyboard-Centric Interface

A [[concepts/minimalist-design|design philosophy]] prioritizing keyboard navigation and shortcuts over mouse interaction to minimize context switching and maximize cognitive [[concepts/flow|flow]].

## Core Principles
- **Minimize Context Switching:** Reduce the need to move hands between keyboard and mouse.
- **[[concepts/speed|Speed]] and Efficiency:** Prioritize rapid execution of [[concepts/commands|commands]] and navigation.
- **[[concepts/obsidian|Obsidian]] Integration:** Leverage [[concepts/plugins|plugins]] and workflows that support keyboard-first interaction within the Obsidian ecosystem.

## Related Tools & Concepts
- [[concepts/quick-capture]]: Rapid input methods for immediate note-taking.
- Window Manager: Tools for managing application focus and layout via keyboard.
- Launcher: Global search and execution interfaces.
