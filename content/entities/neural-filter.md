# Neural Filter

[[concepts/neural-filters|Neural Filters]] are AI-driven tools in [[concepts/photoshop|Adobe Photoshop]] designed to enhance and upscale [[concepts/images|images]] intelligently. These filters leverage machine [[concepts/learning|learning]] algorithms to process images with greater sophistication than traditional upscaling methods, allowing users to enlarge images while maintaining or improving detail quality.

## Key Upscaling Tools

Photoshop offers several neural filter options for [[concepts/image-resolution|image upscaling]]. [[concepts/ai-powered-upscaling|Generative Upscale]] uses generative AI to intelligently enlarge images and add detail. Preserve Details 2.0, accessible through the Image Size dialog, focuses on maintaining fine details and textures during the upscaling process. These tools represent different approaches to the same problem—increasing image resolution without excessive loss of quality.

## Application and Availability

Neural Filters have been available in Photoshop, with certain tools initially appearing in beta versions before wider release. Users can access these features through Photoshop's filter menu and image [[concepts/computational-scaling|scaling]] options, making advanced upscaling accessible to photographers and designers without requiring separate [[concepts/software|software]] or [[concepts/plugins|plugins]].
