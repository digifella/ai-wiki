# Decision-Making AI

**[[concepts/decision-making|Decision-making]] AI** refers to [[concepts/artificial-intelligence|artificial intelligence]] systems optimized for rapid, deterministic choice generation rather than sequential text [[concepts/user-attention-prediction|prediction]]. This paradigm shifts focus from generative fluency to [[concepts/computational-efficiency|computational efficiency]] and [[concepts/speed|speed]], often utilizing specialized architectures to bypass the latency inherent in traditional [[concepts/large-language-models|Large Language Models]] (LLMs).

## Key Architectures & Systems

### TypeSafe AI's Jev
A prominent example of this paradigm is [[lab-notes/2026-09-24-TypeSafe-AIs-Jev-High-Speed-Low-Cost-Decision-Making-AI|TypeSafe AI's Jev: High-Speed, Low-Cost Decision-Making AI]]. Unlike standard LLMs that generate output token-by-token, Jev is engineered for high-speed, low-cost execution.

*   **Core Mechanism:** Designed to make rapid, decisive choices from a predefined set of options, contrasting with the [[concepts/autoregressive-generation|sequential generation]] of models like [[concepts/gpt-5|GPT-5]].
*   **Performance Profile:** Optimized for speed and [[concepts/cost-efficiency|cost-efficiency]], targeting [[concepts/scenarios|use cases]] requiring immediate action rather than creative text synthesis.
*   **Source Analysis:** Detailed in the video [[entities/typesafe-ai|TypeSafe AI]]'s Jev: High-Speed, [[entities/jev|Low-Cost Decision-Making AI]](https://www.youtube.com/watch?v=qBBRRsH0rQc) by [[entities/two-minute-papers|Two Minute Papers]], which highlights its capabilities and inherent limitations ("the catch").

## Comparison with LLMs

| Feature | Traditional LLMs (e.g., GPT-5) | Decision-Making AI (e.g., Jev) |
| :--- | :--- | :--- |
| **Output Mode** | [[concepts/sequential-text-generation|Sequential text generation]] | Rapid choice selection |
| **Latency** | Higher (due to token-by-token processing) | Low (optimized for speed) |
| **Cost** | Higher computational overhead | Low-cost execution |
| **Primary Use** | Creative [[concepts/writing|writing]], [[concepts/reasoning|reasoning]], chat | Real-time decisioning, automation |
