# Three.js

[[concepts/javascript|JavaScript]] library for creating and [[concepts/fat-rendering|rendering]] 3D [[concepts/webgpu|graphics]] in the browser using WebGL.

- Built on WebGL for [[entities/high-performance|high-performance]] 3D [[concepts/visual-rendering|rendering]].
- Scene graph organization for complex 3D object hierarchies.
- Supports lighting models, materials, textures, and animation systems.
- [[concepts/gpt-5|GPT 5]] - [[entities/mathew-berman|Mathew Berman]] demonstrated a fully interactive Rubik's Cube simulator (20x20x20) with [[concepts/dynamic-sizing|dynamic sizing]], [[concepts/color-coded-faces|color-coded faces]], camera controls, [[concepts/layer-rotation|layer rotation]], and "Solve" button using Three.js.
