# Scraping

Scraping refers to the automated process of extracting data from websites or other digital sources for analysis and use in various [[concepts/software|applications]]. It is a crucial tool in [[concepts/web-development|web development]], data science, and SEO, among others.

## Key Points

- Scraping involves using software tools and scripts to gather information from online platforms efficiently.
- Commonly used languages and libraries for scraping include [[entities/python|Python]] with BeautifulSoup or Scrapy, JavaScript with Puppeteer, and more recently [[concepts/agent-harnesses|Agent Skills]] (formerly [[concepts/claude-code|Claude Skills]]) enhancing efficiency in [[concepts/large-language-models|large language models (LLMs)]].
