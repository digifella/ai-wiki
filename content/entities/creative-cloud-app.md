# Creative Cloud App

Creative Cloud App refers to Adobe's suite of cloud-based creative [[concepts/software|software]] applications, including [[concepts/photoshop|Photoshop]], which are available through subscription. The apps integrate cloud [[entities/storage|storage]], collaboration features, and access to both stable and beta versions of software.

## Photoshop Beta and the Harmonize Feature

The [[entities/adobe-photoshop-beta|Photoshop Beta version]] includes experimental features not yet available in the standard release. One such feature is "Harmonize," a tool designed to assist with color and [[concepts/photo-tonal-adjustments|tonal adjustments]] across image elements. The feature has specific functionality [[concepts/parameters|parameters]] and known limitations that users should understand before implementation.

## AI-Assisted Tools

Recent updates to Adobe Photoshop have introduced AI-assisted capabilities, including [[concepts/ai-driven-layer-management|automated layer renaming]] and [[concepts/generative-markup-tools|generative markup tools]]. These features aim to streamline workflow by automating routine tasks, though their effectiveness may vary depending on project requirements and user expertise.
