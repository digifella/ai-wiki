# Generative Editing

Generative Editing refers to AI-powered capabilities integrated into [[concepts/adobe-photoshop|Adobe Photoshop]] version 27.6 that enable users to automatically generate, modify, and enhance image content. These features leverage [[concepts/artificial-intelligence-models|machine learning models]] to perform tasks traditionally requiring manual work or specialized technical [[concepts/skills|skills]]. The tools are designed to integrate seamlessly into Photoshop's existing workflow, allowing both professional designers and casual users to accomplish complex edits more efficiently.

## Core Capabilities

The generative features in Photoshop 27.6 include content-aware fill enhancements, object generation, and expansion tools. Content-aware fill utilizes [[concepts/generative-ai|generative AI]] to analyze surrounding pixels and context, producing more realistic and coherent results than previous iterations when removing objects or filling backgrounds. Object generation allows users to create new elements within an image by providing [[concepts/text-prompts|text prompts]], which the system interprets to generate matching visual content. Expansion tools enable the extension of image boundaries beyond the original [[concepts/canvas|canvas]], using generative [[concepts/algorithms|algorithms]] to fill the new space with contextually appropriate details.

## Workflow Integration

These tools are embedded directly into the standard Photoshop interface to minimize the learning curve for existing users. Users can access generative functions through familiar panels and menus, such as the Properties panel or contextual taskbars. This integration ensures that generative editing complements traditional raster-based workflows rather than replacing them. The system processes requests locally or via cloud-based servers, depending on the specific feature and user subscription status, to deliver results that align with the artistic intent of the project.
