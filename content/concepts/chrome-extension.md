# Chrome Extension

A lightweight [[concepts/software|software]] module that extends functionality of the [[concepts/google-search|Google]] Chrome browser, enabling custom features through user scripts or integrated tools.

- Requires user permission for data access and can interact with web pages via content scripts
- Published via Chrome Web Store with version [[concepts/power|control]] and [[concepts/security|security]] sandboxing
- Common [[concepts/scenarios|use cases]]: ad-blocking, [[concepts/productivity-tools|productivity tools]], [[concepts/developer|developer]] utilities, and AI integrations
