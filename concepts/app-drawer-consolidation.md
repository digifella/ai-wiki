# App Drawer Consolidation

[[concepts/app-drawer|App Drawer]] [[concepts/consolidation|Consolidation]] is a design feature introduced in [[entities/android-16|Android 16]] that reorganizes how applications are displayed and accessed on a device. Rather than presenting a flat, alphabetical list of all installed applications, the feature groups related [[concepts/apps|apps]] into logical categories based on their function or purpose. This categorical organization reduces visual clutter and simplifies navigation, particularly beneficial for users with large numbers of installed applications.

The implementation relies on system-level classification to automatically sort applications into distinct sections such as "Social," "[[concepts/productivity|Productivity]]," or "Games." This approach allows the system to dynamically adjust the layout as users install or remove applications, ensuring that the app drawer remains organized without requiring manual intervention. The consolidation aims to improve discoverability by placing frequently used or functionally similar applications in closer proximity to one another.

From a platform perspective, this change represents a shift in the Android [[concepts/user-interface|user interface]] paradigm, moving away from the traditional monolithic app drawer model. It integrates with the broader Android 16 design [[concepts/software-updates|updates]] to provide a more streamlined [[concepts/experience|experience]] across various device form factors. The feature is designed to be adaptive, considering factors such as screen size and user [[concepts/behavioral-types|interaction patterns]] to optimize the display of application icons and labels.
