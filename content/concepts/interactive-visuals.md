# Interactive Visuals

Interactive visuals refer to graphical representations of information that allow users to interact with them for a more dynamic and engaging experience. This can include charts, [[concepts/diagrams|diagrams]], maps, and other visual elements that respond to user input such as clicks or mouse movements.
