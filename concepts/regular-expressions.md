# Regular Expressions

A sequence of characters that defines a search pattern, primarily used for [[concepts/pattern-matching|Pattern Matching]], [[concepts/text-manipulation|text manipulation]], and complex string validation.

### microsoft excel
Recent [[concepts/software-updates|updates]] introduce native Regex support via specialized functions to streamline [[concepts/data-extraction]], [[concepts/data-cleaning|Data Cleaning]], and [[concepts/data-formatting|Data Formatting]]:
- `[[concepts/regexextract|REGEXEXTRACT]]`: Extracts specific substrings or patterns from a text string.
- `[[concepts/regexreplace|REGEXREPLACE]]`: Identifies patterns and replaces them with specified text.
