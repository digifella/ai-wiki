# Memory

**Memory** refers to the mechanisms by which [[concepts/ai-agent]]s store, retrieve, and utilize information to maintain context across interactions. In [[concepts/web-tools|agentic frameworks]] like [[concepts/hermes-agent]], memory is critical for executing complex, multi-step workflows and maintaining state during [[concepts/automated-recurring-tasks|Automated Recurring Tasks]].

## Key Concepts

- **Context Retention**: The ability of an agent to recall previous inputs and actions to inform future decisions.
- **State Management**: Tracking the current status of tasks, particularly in Recurring Task loops.
- **Agentic Frameworks**: Tools like [[concepts/hermes-agent]] that orchestrate memory and execution logic.

## Recent Developments

- **[[entities/hermes-agent|Hermes Agent]] /loop Feature**:
  - Introduced in [[concepts/hermes-agent]] (developed by [[entities/nous-research|Nous Research]]) to support [[concepts/multi-step-tasks|automated recurring tasks]].
  - Enables agents to execute Loop structures for persistent or periodic operations.
