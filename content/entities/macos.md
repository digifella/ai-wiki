# Macos

macOS is the operating system developed and maintained by [[entities/apple|Apple]] for its line of [[entities/mac|Macintosh]] computers. First released in 2001 as Mac OS X, it succeeded the Classic Mac OS and has since become one of the primary computing platforms alongside [[entities/windows|Windows]] and [[entities/linux|Linux]]. The system is built on a Unix-based foundation, specifically derived from Darwin, which provides stability and [[concepts/security|security]] features.

## Architecture and Features

macOS uses a graphical [[concepts/user-interface|user interface]] built on the Aqua [[concepts/design|design]] language and includes integrated [[concepts/software|software]] such as Finder for file management, Safari for web browsing, and Mail for [[entities/email|email]]. The operating system supports both [[entities/intel|Intel]] and Apple [[concepts/silicon|Silicon]] [[concepts/central-processing-units|processors]], with the transition to Apple's custom chips beginning in 2020. System updates are released annually under macOS version numbering, with each release typically named after California locations.

## Development and Ecosystem

The platform supports a wide [[concepts/range|range]] of [[concepts/third-party-applications|third-party applications]] distributed through the Mac App Store and other channels. macOS is closely integrated with Apple's other operating systems—[[entities/ios|iOS]], iPadOS, and watchOS—through features like [[entities/icloud|iCloud]] synchronization and Handoff. The system is primarily distributed as a free upgrade to existing Mac users, with new versions generally becoming available each fall.
