# File Size Reduction

Techniques to decrease digital file size while maintaining acceptable quality across file types.

- **[[concepts/video-compression|Video Compression]]**: Use Handbrake (free, [[concepts/open-source|open-source]], cross-platform tool) for [[concepts/transcoding|transcoding]] videos without significant quality loss. Supports multiple codecs and is ideal for resizing, converting, and compressing video files (originally designed for [[concepts/dvd-ripping|DVD ripping]]).
