# AI-generated infographics

Visual assets produced via [[concepts/generative-ai]]. While highly efficient for [[concepts/information-visualization|Data Visualization]], they frequently suffer from typographic inaccuracies and hallucinations in text [[concepts/visual-rendering|rendering]].

## Editing & Text Correction
To address spelling mistakes or inaccuracies occurring in tools like [[entities/gemini]], the following workflows are used:
- **[[entities/adobe-acrobat|Adobe Acrobat]]**: Method for directly editing text within PDF versions of [[concepts/infographic-design|infographics]].
- **[[entities/canva|Canva]] '[[concepts/canva-grab-text-feature|Grab Text]]'**: Feature used to extract and edit text layers within static images.
