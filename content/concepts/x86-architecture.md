# X86 Architecture

X86 is a family of instruction set architectures (ISAs) based on the Intel 8086 processor, introduced in 1978. The [[concepts/architecture|architecture]] defines the set of [[concepts/commands|commands]] that a processor understands and executes. Beginning with 16-bit [[concepts/instructions|instructions]] in the original 8086, the architecture expanded to 32-bit (x86-32) in the 1980s with the Intel 80386, and later to 64-bit (x86-64) in the 2000s. This backward compatibility—where newer [[concepts/central-processing-units|processors]] can generally run older [[concepts/software|software]]—has been a defining characteristic that contributed to the architecture's longevity.

## Prevalence and Market Position

X86 processors dominate personal computers, workstations, and server markets. Major manufacturers including Intel and AMD produce x86-compatible processors. The architecture remains the standard choice for most desktop operating systems, including [[entities/windows|Windows]], macOS (until the 2020 transition to ARM), and various Linux distributions. This market dominance has made x86 the most widely deployed processor architecture across [[concepts/computing-infrastructure|computing infrastructure]].

## Technical Characteristics

The x86 architecture uses a complex instruction set (CISC) design, meaning individual instructions can perform relatively complex operations. This contrasts with simpler reduced instruction set (RISC) architectures. The architecture includes extensive built-in features for [[concepts/memory|memory]] management, privilege levels for security, and extensive instruction extensions added over decades, including support for multimedia operations and virtualization. These additions have made the modern x86 instruction set substantially more complex than its original form.
