# Nemotron 3 Nano

[[entities/nemotron-3-ultra|Nemotron 3 Nano]] is a 30-billion-parameter [[concepts/statistical-language-modeling|language model]] developed by [[entities/nvidia|NVIDIA]]. As a member of the [[entities/ai-assistant|Nemotron]] 3 model family, it is designed to balance performance with [[concepts/computational-efficiency|computational efficiency]], making it suitable for [[concepts/deployment|deployment]] in resource-constrained environments while maintaining competitive capability across standard language understanding and generation tasks.

## Multimodal Capabilities

NVIDIA extended the Nemotron 3 Nano [[concepts/architecture|architecture]] to support multimodal inputs, creating [[concepts/nemotron-3-nano-model|Nemotron 3 Nano Omni]]. This variant integrates [[concepts/computer-vision|vision]] and [[concepts/language-capabilities|language capabilities]], enabling the model to process and reason over both [[concepts/text|text]] and image data as a unified [[entities/agent|agent]] model, expanding its application [[concepts/range|range]] beyond text-only tasks.
