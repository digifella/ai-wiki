# Adobe Camera Raw 18.6

**[[concepts/adobe-camera-raw|Adobe Camera Raw]] 18.6** introduces significant creative editing capabilities, most notably a new "[[entities/glow|Glow]]" effect. This update allows for enhanced atmospheric [[concepts/adjustments|adjustments]] and refined tonal control in post-processing workflows.

## Key Features

*   **New [[concepts/glow-effect|Glow Effect]]**: A groundbreaking feature allowing users to add a soft, luminous glow to highlights and midtones, enhancing mood and depth in images.
*   **Creative Editing [[concepts/software-updates|Updates]]**: Improvements to existing tools to support more nuanced [[concepts/creative-control|artistic control]].
*   **Workflow Integration**: Seamless compatibility with existing [[entities/adobe-photoshop|Photoshop]] and [[entities/lightroom-classic]] pipelines.
