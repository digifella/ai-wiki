# HTML/JavaScript

Core web technologies for building interactive websites and applications.

- **[[concepts/code-generation|Code generation]]**: [[concepts/gpt-5|GPT-5]] demonstrates advanced [[concepts/ai-coding]] capabilities by producing complex HTML/JavaScript code, such as a fully interactive Rubik's Cube simulator using [[concepts/threejs]] ([[concepts/dynamic-sizing|dynamic sizing]] up to 20x20x20, [[concepts/color-coded-faces|color-coded faces]], camera controls, [[concepts/layer-rotation|layer rotation]], "Solve" button).
- **[[concepts/interactive-simulation|Interactive simulation]]**: Real-time user-interactive web simulations (e.g., Rubik's Cube) via HTML, [[concepts/javascript|JavaScript]], and [[concepts/threejs]].
- **[[concepts/multimodal-understanding|Multimodal understanding]]**: Interpreting visual/textual prompts to generate relevant code (demonstrated in Rubik's Cube task).
- **[[concepts/reasoning-skills|Reasoning skills]]**: Generating logically consistent code for [[concepts/complex-tasks|complex tasks]] requiring [[concepts/spatial-understanding|spatial reasoning]].
