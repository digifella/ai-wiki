# Koen

Koen is an automation system designed to streamline the creation and distribution of AI-generated video content across multiple social media platforms. The system combines Claude Code, an AI-assisted coding tool, with Blotato, a multi-platform distribution service, to reduce manual intervention in content production and posting workflows.

## How It Works

The process leverages Claude Code to automate the generation and formatting of video content according to platform-specific requirements. Once content is generated, Blotato handles the distribution phase by simultaneously posting to multiple networks, ensuring consistent delivery without manual oversight.
