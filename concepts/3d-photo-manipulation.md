# 3D Photo Manipulation

[[concepts/3d-photo-adjustments|3D photo manipulation]] refers to techniques that use depth information to create three-dimensional effects within two-dimensional photographs. In [[concepts/photoshop|Photoshop]], this is primarily achieved through [[concepts/depth-maps|depth maps]]—grayscale representations that assign depth values to different areas of an image. In these maps, lighter values indicate objects closer to the viewer while darker values represent distant elements. This depth information allows [[entities/adobe-photoshop|Photoshop]]'s 3D processing tools to understand and manipulate the spatial [[concepts/relationships|relationships]] within a photograph.

## Creating and Using Depth Maps

Depth maps can be generated through several methods. Photoshop can automatically generate them from standard photographs using [[concepts/machine-learning|machine learning]] [[concepts/algorithms|algorithms]], or they can be created manually by selectively painting and adjusting grayscale values. Users can also import pre-made depth maps or those generated by depth-sensing cameras and computational photography techniques. Once established, the [[concepts/depth-map|depth map]] serves as a guide for applying various 3D effects to the original image.

## Common Applications

With a depth map in place, photographers and designers can perform operations that would otherwise be impossible on flat images. These include selective focus [[concepts/adjustments|adjustments]] that blur background or foreground elements based on their depth, perspective shifts that create parallax effects, and lighting adjustments that respond to spatial relationships. Depth maps also enable the creation of 3D layers that can be repositioned or viewed from slightly different angles, producing the illusion of dimensional space.

## Practical Workflow

The typical workflow involves importing or creating a depth map, refining it to accurately represent the image's spatial structure, and then applying desired 3D effects. The accuracy of the depth map directly affects the quality of the final result, making careful map creation or selection essential for achieving convincing three-dimensional manipulations.
