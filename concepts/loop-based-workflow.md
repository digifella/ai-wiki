# Loop Based Workflow

Loop Based Workflow is an AI-assisted coding methodology that structures software development as a series of iterative cycles rather than relying on single-pass code generation. Popularized in technical discussions by Gary Explains, this approach acknowledges the limitations of large language models in producing complex, error-free code immediately. Instead of expecting a perfect final output, the workflow treats the AI as an agent that requires continuous feedback to refine its results.

The core mechanism involves a continuous loop between code generation and validation. An AI system produces an initial code snippet, which is then executed in a controlled environment. The results of this execution, including any error messages or unexpected behaviors, are fed back into the AI as context. This concrete feedback allows the model to understand the specific failure points and adjust its subsequent outputs accordingly, effectively learning from the immediate consequences of its previous actions.

This iterative process leverages the AI's ability to adapt to new information within a single session. By breaking down complex tasks into smaller, testable units, developers can guide the AI toward a working solution more efficiently than through prompt engineering alone. The workflow reduces the cognitive load on the developer by automating the trial-and-error phase, allowing the AI to handle the granular adjustments required to resolve bugs and meet functional requirements.
