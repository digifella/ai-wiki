# Self Improving Ai

[[concepts/self-evolution|Self-improving AI]] refers to [[concepts/action-oriented-ai|autonomous AI agents]] capable of modifying and enhancing their own code or models without human intervention. These systems use iterative processes to identify inefficiencies, test modifications, and implement improvements in their underlying [[concepts/algorithms|algorithms]] or architectures. The goal is to create [[concepts/feedback|feedback]] [[concepts/loops|loops]] where [[concepts/performance-gains|performance gains]] in one [[concepts/iteration|iteration]] enable more effective improvements in subsequent cycles.

## Technical Mechanisms

Self-improving systems typically operate through [[concepts/automated-software-analysis|automated code analysis]], testing frameworks, and modification pipelines. An [[concepts/ai-agent|AI agent]] might identify performance bottlenecks in its own [[concepts/open-source-philosophy|logic]], generate candidate improvements, evaluate them against [[concepts/defined-metrics|defined metrics]], and [[concepts/deployment|deploy]] successful changes autonomously.
