# Terminal command execution

Fundamental for system administration and automation. Key aspects:

- **Syntax**: `command [options] [arguments]`
- **Common [[concepts/commands|Commands]]**: `ls`, `cd`, `grep`, `sed`, `awk`, `curl`, `ssh`
- **Automation**: Shell scripts (`.sh`) for task chaining
- **[[concepts/security|Security]]**: Minimize `sudo` usage; prefer granular permissions
