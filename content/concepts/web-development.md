# Web Development Overview

[[concepts/website-building|Web development]] encompasses a broad range of disciplines and [[concepts/skills|skills]] dedicated to designing, developing, [[concepts/testing|testing]], and maintaining websites. This includes [[concepts/frontend-development|front-end]] (client side) web [[concepts/design|design]], back-end (server side) logic, database management, and server-side scripting.

## Tools & Technologies
- **[[concepts/htmlcss|HTML/CSS]]/JavaScript** - The core languages for building the [[concepts/structure|structure]], presentation, and interactivity of websites.
- **Web Frameworks** - Such as React, Angular, Vue.js for front-end development; Django, Flask for back-end development.
- **Version Control Systems** - Like Git for tracking changes in codebases.
- **Integrated [[concepts/developer-platforms|Development Environments]] (IDE)** - Tools like [[entities/vscode|VSCode]], [[entities/pycharm|PyCharm]] to enhance [[concepts/coding|coding]] efficiency.
- **AI Code Assistants** (e.g., [[concepts/claude-code|Claude Code]], [[concepts/nano-banana-2|Nano Banana 2]]) - Emerging tools enabling rapid [[concepts/no-code|no-code development]] of responsive, SEO-optimized websites with advanced features.
