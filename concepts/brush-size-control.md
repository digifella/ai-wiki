# Brush Size Control

Brush size control in [[concepts/adobe-photoshop|Adobe Photoshop]] refers to the ability to adjust brush dimensions during active painting and editing work. Rather than accessing brush settings through menus or panels, Photoshop provides keyboard shortcuts that allow artists to modify brush properties in real time without interrupting their workflow. This method of control is particularly useful when working on detailed digital art, [[concepts/photo-editing|photo editing]], or illustration projects where frequent size [[concepts/adjustments|adjustments]] are necessary.

## Keyboard Shortcuts

The primary mechanism for controlling brush size involves the square bracket keys. Pressing the right bracket key (`]`) increases the brush diameter, while the left bracket key (`[`) decreases it. Each press typically adjusts the size by a fixed increment, allowing for rapid scaling. For finer control, holding the Shift key while pressing the bracket keys reduces the adjustment increment, enabling more precise modifications to the brush diameter.

## Hardness Adjustment

In addition to size, the bracket keys can also control brush hardness when the Shift key is held down. Pressing `Shift + [` reduces the hardness, making the brush edges softer and more diffused. Conversely, `Shift + ]` increases the hardness, resulting in sharper, more defined edges. This dual functionality allows users to toggle between size and hardness adjustments seamlessly by simply changing whether the Shift key is engaged.

## Workflow Integration

These shortcuts are designed to keep the artist's hands on the keyboard, minimizing the need to switch between tools or open the Brush Settings panel. This efficiency is critical in professional workflows where maintaining momentum and focus is essential. The real-time nature of these controls ensures that changes are immediately visible on the canvas, facilitating a more intuitive and responsive creative process.
