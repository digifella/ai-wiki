# Mermaidlive

Mermaid.Live is a web-based editor and visualization tool for creating [[concepts/diagrams|diagrams]] using Mermaid.js syntax. It provides a live preview interface where users can write diagram [[concepts/code|code]] and immediately see the rendered [[concepts/output|output]], enabling rapid [[concepts/iteration|iteration]] and [[concepts/testing|testing]] of diagram definitions.

## Features and Capabilities

The tool supports multiple diagram types available in the Mermaid.js library, including flowcharts, sequence [[concepts/diagrams|diagrams]], class diagrams, state diagrams, and mindmaps. Users can create complex visual representations by [[concepts/writing|writing]] declarative diagram syntax, which the tool then renders in real-time.

## Integration and Extensions

Mermaid.Live includes [[concepts/integration|integration]] [[concepts/capabilities|capabilities]] with [[concepts/ai-integrated-notebooks|NotebookLM]]-based prompts, allowing users to generate diagram syntax through AI-assisted prompts. This feature enables users to describe their desired diagram in natural language and receive corresponding [[concepts/mermaidjs-syntax|Mermaid syntax]], reducing the [[concepts/learning|learning]] curve for diagram creation.
