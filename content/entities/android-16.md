# Android 16

[[entities/android|Android]] 16 is the stable release of the Android operating system, featuring significant UI refinements and functionality updates. Key changes include:

* **Lock Screen & [[concepts/always-on-display|Always-On Display]] (AOD):** The AOD clock dynamically matches the wallpaper's color palette.
* **Home Screen:**
  * New "App list" option in home screen overlay menu for direct [[concepts/app-drawer|App Drawer]] access.
