# Cowork

Cowork is a [[concepts/ai-driven-workflow-automation|workflow automation]] tool that integrates [[concepts/anthropic-ai|Claude AI]] with local file system access and project management capabilities. It enables users to automate [[concepts/complex-workflows|complex workflows]] by combining [[concepts/claude-ai|Claude]]'s [[concepts/natural-language-processing-nlp|language processing]] abilities with direct access to files and structured [[concepts/ai-projects|AI projects]] on their local machines.

## Core Functionality

The system operates by connecting Claude AI [[concepts/agents|agents]] to local file systems, allowing automated tasks to read, process, and modify files without manual intervention. This capability makes it particularly useful for [[concepts/document-processing|document processing]], [[concepts/data-transformation|data transformation]], and repetitive file-based workflows that would otherwise require manual handling or custom scripting.

## Integration with AI Projects

Cowork leverages AI projects as organizational units for workflow automation. By structuring [[concepts/automation|automation]] tasks within projects, users can manage multiple workflows, maintain context across related tasks, and coordinate Claude's actions across different aspects of their work environment. This project-based approach provides a way to group related [[concepts/automations|automations]] and maintain their configurations.
