# Portal Security Check

A Portal Security Check is a [[concepts/security|security]] [[concepts/verification|verification]] process conducted on the [[concepts/asic-login-portal|ASIC Company Portal]] when users access company information using an Australian Company Number (ACN). The check authenticates user access and validates the legitimacy of information requests before displaying sensitive company data to the requestor.

## Process

When a user enters an ACN into the [[concepts/asic-login-portal|ASIC Company Portal]], the system performs a security check to confirm the validity of the request. This verification step is designed to prevent unauthorised access to company records and ensure that only legitimate queries are processed. The security check validates both the ACN format and the user's authorisation to view the requested information.

## Application

Portal Security Checks are particularly relevant for professional advisory firms and consultants, such as Calliston Consultants, that require regular access to company information through the ASIC portal. By implementing these checks, the portal maintains the integrity of company records and protects sensitive business information from unauthorised disclosure.
