# Google Slides

[[concepts/google-slides|Google Slides]] is a cloud-based presentation software developed by [[concepts/google-search|Google]] as part of [[concepts/google-workspace|Google Workspace]]. It enables users to create, edit, and collaborate on [[concepts/slide-decks|slide decks]] entirely online, with all documents automatically stored in [[concepts/google-drive|Google Drive]]. The platform is accessible from any device with internet connectivity and a web browser, eliminating the need for [[concepts/local-installation|local installation]] or file management.

## Collaboration Features

The application emphasizes real-time collaboration, allowing multiple users to work on the same presentation simultaneously. Changes are synchronized instantly across all collaborators, and the platform includes commenting and suggestion features for [[concepts/feedback|feedback]]. Access controls enable users to determine sharing permissions and control who can view, edit, or comment on presentations.

## AI Integration

Google Slides has incorporated [[concepts/gemini|Gemini]], Google's [[concepts/ai-assistant|AI assistant]], to automate aspects of [[concepts/slide-deck-creation|slide deck creation]]. These capabilities assist users with generating content, designing layouts, and organizing information, though the extent of automation depends on the specific features available in different [[concepts/pricing-tiers|subscription tiers]].

## Availability

As a web-based application, Google Slides requires no [[concepts/software-installation|software installation]] and integrates with other [[concepts/google-workspace-tools|Google Workspace tools]] including [[entities/google-docs|Docs]], Sheets, and [[entities/gmail|Gmail]]. It is available to both individual users with Google accounts and organizations using [[entities/google-workspace|Google Workspace]] subscriptions.
