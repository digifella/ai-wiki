# Real Time Routing

Real Time Routing is a system capability within Microsoft 365 Copilot and Copilot Studio that dynamically directs user requests to appropriate processing pathways during active query execution. Instead of relying on static configuration rules, the system analyzes incoming requests and their context to determine the most suitable backend services or response mechanisms. This adaptive approach allows the routing logic to accommodate varying query types, complexity levels, and performance requirements in real time.

The implementation involves evaluating request characteristics to optimize resource allocation and response latency. By integrating advanced intelligence, the system can adjust its routing decisions based on the specific needs of each interaction, ensuring efficient handling of diverse workloads. This functionality supports the enhanced performance and reliability expected from the integration of large language models into the Microsoft 365 ecosystem.
