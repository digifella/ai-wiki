# AI Agent

An autonomous software entity capable of perceiving its environment, [[concepts/reasoning|reasoning]], and executing actions to achieve specific goals.

## Key Characteristics
- **Autonomy**: Operates without continuous human intervention.
- **Reactivity**: Responds to changes in the environment.
- **Proactiveness**: Takes initiative to achieve goals.
- **Local-First Execution**: Emerging frameworks prioritize running models on personal devices to ensure privacy and control, reducing reliance on [[concepts/cloud-based-services|cloud services]].

## Notable Implementations & Frameworks

### OpenJarvis
A local-first, [[concepts/open-source|open-source]] [[concepts/personal-ai-framework|personal AI framework]] developed by [[entities/stanford-university|Stanford University]]'s [[lab-notes/hazy-research|Hazy Research]] and Scaling Intelligence Labs. It enables users to run powerful [[concepts/ai-models|AI models]] directly on personal hardware using [[tools/ollama|Ollama]].
- **[[concepts/philosophy|Philosophy]]**: Prioritizes privacy and [[concepts/user-control|user control]] over cloud dependency.
- **Integration**: Tracks resource usage (e.g., wattage) for efficiency.
- **Reference**: [[lab-notes/2026-06-27-OpenJarvis-Stanfords-Local-First-Personal-AI-Framework-w|OpenJarvis: Stanford's Local-First Personal AI Framework with Ollama]]

### Other Key Agents
- **[[concepts/cloud-computer|Grok Bot]]**: Notable for its integration with [[concepts/cloud-computing|cloud computing]] and [[concepts/automation|automation]] workflows.
- **[[concepts/deepseek-harness|DeepSeek Harness]]**: A self-extending system focused on [[concepts/context-management|context management]].
- **Hermes**: An open-source agent model.
- **Graft**: Optimizes performance and cost for [[concepts/large-codebases|large codebases]].

## Security & Governance
- **OpenAI Medicare Incident**: A high-profile security incident involving an agent infiltration of the Australian Medicare portal, linked to government AI policies under [[people/anthony-albanese|Anthony Albanese]].
