# Network request inspection

Analyzing HTTP/HTTPS traffic between client and server for [[concepts/debugging|debugging]], [[concepts/software-performance|performance optimization]], and [[concepts/security|security]] analysis.

## Methods
- Browser [[concepts/developer|Developer]] Tools (Chrome DevTools Network tab)
- Packet sniffing (Wireshark, tcpdump)
- Proxy-based inspection (Fiddler, Charles Proxy)
