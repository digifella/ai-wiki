# Cloud-Based AI Services

[[concepts/cloud-ai|Cloud-based AI]] services provide a scalable and flexible platform for deploying [[concepts/ai-technologies|artificial intelligence]] applications without significant upfront infrastructure investments. These services range from [[concepts/natural-language-processing|natural language processing (NLP)]] to [[concepts/computer-vision|computer vision]], making them accessible to developers with varying levels of [[concepts/expertise|expertise]].

While [[concepts/cloud-based-services|cloud services]] offer scalability, local alternatives exist for specific high-[[concepts/computational-resources|compute]] tasks. For instance, [[lab-notes/2026-07-07-Local-AI-Video-Generation-Using-ComfyUI-Tutorial-Summary|Local AI Video Generation Using ComfyUI Tutorial Summary]] demonstrates generating AI videos on personal hardware using [[concepts/comfyui|ComfyUI]], eliminating cloud costs and providing [[concepts/local-control|local control]].
