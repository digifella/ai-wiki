# Screenshot Analysis

**Screenshot Analysis** refers to the process of interpreting visual data from user interfaces to extract information or trigger actions, particularly within the context of [[concepts/robotic-process-automation]] (RPA). It bridges the gap between traditional rule-based automation and [[concepts/unstructured-data]] processing.

## Core Concepts

*   **Beyond Step Automation**: Traditional RPA excels at automating repetitive "steps" (e.g., clicking [[concepts/buttons|buttons]], copying data) but struggles with decision-making [[concepts/nodes|nodes]]. Screenshot analysis enables [[concepts/decision-making]] within workflows.
*   **Unstructured Data Handling**: Critical for processing Forms, Scans, and dynamic Screenshots where [[concepts/json-structuring|structured data]] inputs are unavailable.
*   **Image Decision Models**: Advanced models that allow RPA bots to "see" and interpret visual states, enabling direct decisions based on unstructured visual input.
