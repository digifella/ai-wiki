# Desktop Apps

Desktop apps are [[concepts/software|software]] applications installed directly on a user's computer or device, where they run locally rather than through a web browser. Unlike [[concepts/web-applications|web applications]] that require internet connectivity and operate on remote servers, desktop apps execute on the user's own [[concepts/hardware|hardware]], giving them direct access to system resources, local [[concepts/files|files]], and operating system features. Common examples include word [[concepts/central-processing-units|processors]], image editors, development tools, and productivity software.

## Characteristics and Advantages

Desktop applications typically offer performance advantages over browser-based alternatives since they don't depend on network latency or server responsiveness. They can function offline, access local files and system settings directly, and often provide more sophisticated user interfaces tailored to specific workflows. Users maintain full [[concepts/power|control]] over when updates occur and can customize the application environment to suit their needs.

## Modern Context

The distinction between desktop and web applications has become less rigid in recent years. Many modern desktop apps use web technologies (Electron, for example) to build cross-platform applications, while web applications increasingly offer offline [[concepts/capabilities|capabilities]] and local file access. Some applications adopt a hybrid approach, combining desktop installation with cloud synchronization and browser-based interfaces. Desktop apps remain essential for tasks requiring [[entities/high-performance|high performance]], complex file manipulation, or offline functionality.
