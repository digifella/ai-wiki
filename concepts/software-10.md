# Software 1.0

**Software 1.0** refers to the traditional paradigm of programming where developers explicitly write deterministic rules, logic, and algorithms to solve problems. This contrasts with **[[concepts/software-20|Software 2.0]]**, where models are trained on data to implicitly learn these rules.

## Key Characteristics
- **Explicit Logic:** Code is hand-written by humans using high-level languages (e.g., Python, C++, Java).
- **Deterministic:** Given the same input, the program always produces the same output.
- **Rule-Based:** Behavior is defined by if-then statements, loops, and data structures.
- **Maintenance:** Requires manual debugging, refactoring, and updates by engineers.

## Context & Evolution
The concept gained prominence through discussions around the shift toward **Machine Learning** and **Deep Learning** as primary software development tools.

- **Software 1.0:** Humans write code; computers execute it.
- **Software 2.0:** Humans provide data and objectives; computers learn the code (weights/parameters).
