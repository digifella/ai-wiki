## Claude AI: Automated Marketing with Custom Skills, Design Systems, Orchestration
**Clip title:** [[concepts/digital-asset-generation|Claude Design]] + [[concepts/instructions|Claude Skills]]: Automate Your Marketing ([[concepts/api-cost-optimization|Claude Code]])
**Author / channel:** Grace Leung
**URL:** https://www.youtube.com/watch?v=Ph-maUAiSU8

### Summary
This video provides a comprehensive guide on building a powerful, automated [[concepts/marketing-workflow|marketing workflow]] system using [[concepts/claude-ai|Claude]]'s AI capabilities, focusing on custom skills, [[concepts/design|design]] systems, and an orchestration [[entities/agent|agent]]. The presenter outlines a strategy to move beyond treating AI as a mere tool to leveraging it as an integrated system, capable of automating most marketing tasks from [[concepts/design|design]] to campaign execution. The core idea is to create a "marketing skill stack" by categorizing tasks into Brand, Function, and Specialty skills, prioritizing brand [[concepts/logical-consistency|consistency]] as the foundation for all automated outputs.

The process begins with defining and extracting brand and design elements into reusable [[concepts/claude|Claude]] Skills. This involves setting up a project folder [[concepts/structure|structure]] within the [[entities/anthropic-claude|Claude]] Code [[concepts/desktop-application|desktop application]], populating a `_context` folder with brand guidelines ([[concepts/tone|voice]], [[concepts/style|style]], persona, product offerings), and creating a `CLAUDE.MD` file to direct Claude's navigation. A "Brand [[concepts/tone|Voice]] Skill" is built by [[concepts/prompting|prompting]] Claude to generate on-brand marketing copy based on the provided guidelines. Subsequently, the "[[concepts/ai-driven-design-platforms|Claude Design]]" tool is introduced to visually teach Claude the brand's aesthetic. Users can link project assets, upload logos, and input design notes to generate a comprehensive "Design System Skill," which captures colors, [[concepts/typography|typography]], UI components, and mockups. This design system is then exported as an integrable Claude Skill, allowing future campaigns to adhere to visual standards.

Once the foundational Brand and Design System skills are established, the video demonstrates automating marketing [[concepts/workflow|workflows]]. A "Campaign Planning Skill" is created to generate research-backed, on-brand campaign [[concepts/slide-decks|slide decks]]. This skill integrates external [[concepts/research-tools|research tools]] like [[concepts/gpt-41|Perplexity]] and leverages the pre-existing design system to produce detailed presentations, including KPIs, target personas, budget allocations, and tactical plans. Further, the process extends to building reusable marketing asset [[concepts/prompt-templates|templates]] within Claude Design, such as social [[concepts/social-media-carousels|carousel posts]] and animated videos. These [[concepts/templates|templates]] are then used by dedicated [[concepts/instruction-reuse|Claude Skills]] (e.g., "carely-carousel-design," "carely-animated-video") to generate various on-brand visual and motion assets directly from campaign briefs.

The ultimate step in creating an automated marketing system is building an "Orchestration [[entities/agent|Agent]]," termed "Campaign Manager Agent," within [[concepts/claude-code|Claude Code]]'s terminal. This agent is designed to orchestrate the entire campaign [[concepts/workflow|workflow]], calling upon the previously developed skills as needed. By simply providing a brief, the Campaign Manager Agent initiates market research, plans the campaign, generates [[concepts/slide-decks|slide decks]], creates social carousels, produces animated videos, and even sets up performance trackers and landing pages—all while maintaining brand [[concepts/logical-consistency|consistency]]. Finally, to ensure team collaboration and scalability, all created skills are published to a "[[concepts/instruction-reuse|Claude Skills]] Library" on [[entities/notion|Notion]], complete with [[concepts/version-numbers|versioning]] and file attachments, and an automated routine is set up to regularly sync new or updated skills to this central repository. This transforms individual [[concepts/ai-tools|AI tools]] into a coherent, automated, and shared marketing system.
