# CLI

[[concepts/command-line-interaction|Command Line Interface]] (CLI) is a [[concepts/text-based-interface|text-based interface]] for interacting with computer systems, enabling users to execute [[concepts/commands|commands]] via terminal or console. It provides direct, scriptable access to system functionality without graphical elements.

## Key Characteristics
- **Text-based interaction**: Input commands via keyboard, receive text output.
- **Scriptability**: Easily automate tasks through shell scripts or batch files.
- **[[concepts/model-efficiency|Resource efficiency]]**: Lower [[concepts/memory|memory]]/CPU overhead compared to GUIs.
- **Remote [[concepts/accessibility|accessibility]]**: Works over SSH or terminal emulators.
