# Copilot Studio

[[concepts/copilot-chat|Copilot]] Studio is a [[entities/microsoft|Microsoft]] platform designed for creating and deploying custom [[concepts/agentic-ai|AI agents]] within the [[entities/microsoft-365|Microsoft 365]] ecosystem. It enables users to build specialized [[concepts/ai-powered-applications|AI applications]] tailored to specific business needs and workflows without requiring extensive [[concepts/coding|coding]] [[concepts/expertise|expertise]]. The platform integrates advanced language models to power these custom agents.

## Integration with Microsoft 365

[[entities/copilot|Copilot]] Studio operates as part of [[concepts/microsoft-applications|Microsoft 365 Copilot]], allowing custom agents to leverage enterprise data and applications. This integration enables [[concepts/ai-agents|AI agents]] to interact with Microsoft 365 services and organizational information, making them applicable to various professional [[concepts/scenarios|scenarios]] including financial analysis, customer service, and [[concepts/workflow-automation|process automation]].

## Development and Deployment

The platform provides tools for configuring [[concepts/ai-agent|AI agent]] behavior, defining interactions, and testing functionality before deployment. Users can build agents through guided interfaces and configuration options, making the technology accessible to business users and developers alike. Custom agents created in [[entities/microsoft-copilot|Copilot]] Studio can be distributed across an organization through Microsoft 365 applications.
