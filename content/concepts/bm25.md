# BM25

Probabilistic ranking function for [[concepts/knowledge-bases|information retrieval]] scoring document relevance to a query.

## Database Integration

- [[entities/pg-textsearch|pg_textsearch]]: [[concepts/open-source|Open-source]] [[concepts/postgresql-extension|PostgreSQL extension]] implementing state-of-the-art BM25, eliminating need for external search engines (e.g., Elasticsearch) in many [[concepts/scenarios|use cases]].
- Particularly effective for RAG ([[concepts/answer-generation|Retrieval Augmented Generation]]) [[concepts/software|applications]] by enabling database-native text search with relevance scoring.
- Reduces infrastructure complexity while maintaining [[concepts/search-relevance|search relevance]] for AI-driven workflows.
