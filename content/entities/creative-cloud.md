# Creative Cloud

Creative Cloud is [[entities/adobe|Adobe]]'s comprehensive suite of cloud-based creative [[concepts/software|applications]] and services designed for professional and creative users. The suite includes industry-standard tools such as [[concepts/photoshop|Photoshop]], [[concepts/lightroom|Lightroom]], Illustrator, InDesign, and [[entities/premiere-pro|Premiere Pro]], among others. These applications are available through a subscription model and include cloud [[entities/storage|storage]], collaboration features, and regular updates with new functionality.

## Recent Developments

Adobe has been integrating [[concepts/ai-technologies|artificial intelligence]] features across Creative Cloud applications. Recent updates to Photoshop have introduced AI-assisted tools including [[concepts/ai-driven-layer-management|automated layer renaming]], generative markup [[concepts/capabilities|capabilities]], and AI-powered object manipulation features. Lightroom has received updates focusing on AI-driven search functionality and [[concepts/workflow|workflow]] improvements. A [[concepts/harmonize-feature|Harmonize tool]] has been introduced in beta versions, indicating Adobe's ongoing development of AI-enhanced creative features.
