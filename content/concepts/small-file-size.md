# Small file size

Critical for efficient [[entities/storage|storage]], transmission, and execution on resource-constrained systems. Enables:
- Minimal storage footprint
- Low bandwidth usage
- Reduced [[concepts/power|power]] consumption
- Feasibility in edge/mobile environments
