# HUD

A **[[concepts/hud-heads-up-display|Heads Up Display]] (HUD)** is a temporary overlay UI element that provides real-time [[concepts/adjustments|adjustments]] without leaving the current context.

In **[[entities/adobe-photoshop]]**, the HUD enables instant brush property adjustments:
- **Activation:**
  - *[[entities/mac|Mac]]:* `Ctrl + Option` + drag
  - *[[entities/windows|Windows]]:* `Ctrl + Alt` + right-click drag
- **Adjusts:** [[concepts/brush-size|brush size]] and hardness

Demonstrated by [[entities/julianne-kost]] in her [[concepts/photoshop|Photoshop]] [[concepts/tutorial|tutorial]].
