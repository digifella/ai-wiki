## Claude Code Mods: Customizing AI Behavior and User Interface for Productivity
**Clip title:** 9 NEW [[concepts/claude-ai|Claude]] Mods that can truly change how you work
**[[entities/tasia-custode|Author]] / channel:** Jay E | [[entities/jay-e-robonuggets|RoboNuggets]]
**URL:** https://www.youtube.com/watch?v=lDrAZ1wAyVs

### Summary
[[entities/anthropic-institute|Anthropic]] has introduced "[[concepts/mods|Mods]]" for [[concepts/ai-assisted-coding|Claude Code]], a significant update that allows users to deeply customize the behavior and [[concepts/user-interface|user interface]] of the [[concepts/ai-assistant|AI assistant]]. Unlike "[[concepts/skills|skills]]," which instruct [[concepts/claude-ai|Claude]] on *how* to perform a task, or "connectors," which link Claude to [[concepts/third-party-applications|external applications]], mods directly change [[concepts/ai-assisted-coding|Claude Code]]'s internal workings and visual presentation. This means users can now describe a desired feature, and Claude Code, leveraging its built-in `plugin-authoring` [[concepts/skill|skill]], can build that feature directly into itself, effectively transforming the tool to meet specific needs. This [[concepts/customization|customization]] extends to adding new UI elements, displaying information differently, or even integrating mini-games.

The video highlights several key mods designed to enhance [[concepts/productivity|productivity]] and [[concepts/opacity|transparency]] within Claude Code. "Savvy Progress" is a particularly useful mod that displays a live progress bar above the prompt, showing how close Claude is to completing a task. For more complex, multi-agent tasks, it provides a [[concepts/sidebar-interface|side panel]] detailing each sub-agent's model, progress, and estimated API costs, even featuring customizable pixel art "Claude crabs." Another valuable mod, "Filetree," introduces a dedicated file panel on the right side of the interface, visually indicating which files Claude is currently reading, editing, or has committed, which is especially crucial for developers and anyone managing multiple documents. Furthermore, the Anthropic-built "You Should Know" mod acts as a second agent, scanning Claude's output for critical information that might be overlooked in lengthy text, such as cost implications, and [[concepts/flags|flags]] it for the user.

Other impactful mods cater to various aspects of the [[concepts/user-experience-design|user experience]] and workflow. "Claude Skins" allows for aesthetic customization, enabling users to re-skin how Claude Code presents its work with different themes and colors, or even create their own. For cost-conscious users, "Cache Tax" helps manage Claude's "prompt cache" ([[concepts/short-term-memory|short-term memory]]), alerting users when the cache goes "cold" and a new prompt would incur a higher cost due to reloading the entire conversation. Safety is addressed by "Blast Radius," another Anthropic-created mod that halts potentially risky [[concepts/commands|commands]], like file deletions, and requires explicit human confirmation after detailing the affected files. "Reflect" allows users to save [[concepts/feedback|feedback]] as permanent rules in Claude's configuration file, ensuring personalized [[concepts/learning|learning]] and consistent improvements. Finally, the "[[concepts/cli|Terminal]] Browser" integrates a real web browser directly within the terminal, eliminating the need to switch applications when reviewing web pages or [[entities/github|GitHub]] pull requests, while "Replay Theater" enables users to step through every file edit Claude has made in a turn, providing a clear understanding of changes.

Creating and managing these mods is designed to be user-friendly; after ensuring Claude Code is updated, users can simply describe their desired modification, and Claude [[entities/will|will]] build it. While mods built by Claude are temporary by default, they can be saved as permanent [[concepts/plugins|plugins]]. Although mods themselves typically don't incur extra costs, using Claude Code requires a paid plan, and any mod that calls an AI model in the background will consume from the user's Claude usage. This innovative approach to customizable [[concepts/ai-tools|AI tools]] marks a significant step toward more malleable and hyper-personalized software, potentially paving the way for other [[concepts/ai-platforms|AI platforms]] to follow suit in empowering users with greater control over their AI assistants.
