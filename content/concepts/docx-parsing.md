# Docx Parsing

Docx parsing refers to the automated extraction and processing of content from [[entities/microsoft-word|Microsoft Word]] documents (.docx [[concepts/files|files]]). This capability is essential for AI workflows that need to ingest, analyze, or transform document [[concepts/big-data|data at scale]]. [[concepts/docling|Docling]], an [[concepts/open-source|open-source]] toolkit developed by [[entities/ibm-research|IBM Research]], provides structured methods for parsing docx files and other document formats while preserving layout, [[concepts/structure|structure]], and semantic information.

## Docling Toolkit

[[concepts/docx|Docling]] is designed to convert documents into machine-readable formats suitable for downstream [[concepts/ai-powered-applications|AI applications]]. It handles the complexity of extracting [[concepts/text|text]], tables, [[concepts/images|images]], and formatting from docx files while maintaining document structure. The toolkit supports [[concepts/integration|integration]] into AI pipelines where document content needs to be processed, indexed, or used as input for language [[concepts/models|models]] and other AI systems.

## Applications

Organizations like [[entities/red-hat|Red Hat]] have adopted Docling to manage document content within their technical workflows. By automating docx parsing, teams can reduce manual data entry, improve [[concepts/logical-consistency|consistency]] in [[concepts/document-processing|document processing]], and scale document handling across large document collections without losing critical structural information.
