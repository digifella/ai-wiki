# Pixel 9 Pro XL

The Pixel 9 Pro XL is a flagship smartphone manufactured by [[concepts/google-search|Google]]. It runs [[entities/android-16|Android 16]], Google's mobile operating system, and features a refined [[concepts/user-interface|user interface]] with several notable enhancements introduced in the [[entities/june-2025-pixel-drop|June 2025 Pixel Drop]] update.

## Display and Interface Features

The device includes an [[concepts/always-on-display|always-on display]] with dynamic lock screen functionality. The always-on display clock adapts its color palette to match the device's active wallpaper, providing visual coherence between system elements and user-selected backgrounds. The home screen has been updated with a new "App list" option accessible through the overlay menu, offering direct access to the [[concepts/app-drawer|app drawer]] for improved navigation.
