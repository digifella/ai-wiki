# Ubuntu Media Server

Ubuntu Media Server is a self-hosted media server project built on the Ubuntu operating system, designed to operate within a budget constraint of under $100. The project provides users with an alternative to subscription-based streaming services by enabling them to host, store, and manage their own media content on local hardware rather than relying on commercial platforms with recurring fees.

## Purpose and Scope

The project addresses the growing cost of multiple subscription streaming services by allowing users to maintain control over their media library on personal hardware. Users can store digital media files and access them through a self-hosted server environment, eliminating ongoing subscription expenses while maintaining ownership of their content and data.

## Technical Foundation

The project utilizes Ubuntu, a Linux distribution based on Debian, as its operating system foundation. This choice provides users with a stable, open-source platform with broad community support and documentation. The cost constraint encourages the use of existing hardware or affordable single-board computers and storage solutions to minimize overall system expenses.
