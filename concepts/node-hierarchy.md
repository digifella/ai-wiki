# Node Hierarchy

Node Hierarchy is a method for organizing and visualizing information by converting unstructured notes into hierarchical tree diagrams. This approach utilizes prompt-based automation, specifically through tools like NotebookLM, to process source material and generate structured outputs in Mermaid.js mindmap format. By bridging the gap between linear text documentation and graphical representation, it facilitates easier navigation and comprehension of complex information structures.

## Process and Implementation

The technique involves submitting source notes to a language model with a specific prompt engineered to extract relationships and logical groupings from the text. The model analyzes the semantic connections between concepts and structures them into a parent-child hierarchy. The resulting output is a Mermaid.js code block that renders as a mindmap, allowing users to visualize the organizational structure of their notes without manual diagramming. This automated workflow supports rapid iteration and maintains consistency in how information is categorized and displayed.
