# VS Code fork

A [[entities/vscode|VS Code]] fork is a customized version of the [[concepts/open-source|open-source]] [[entities/vs-code|VS Code]] editor, typically enhanced with proprietary features (e.g., [[concepts/ai-coding|AI coding]] assistance) while maintaining compatibility with the underlying [[concepts/code|codebase]]. Maintaining such a fork requires significant engineering effort to stay updated with [[entities/microsoft|Microsoft]]'s releases.

Notable examples:
- [[entities/cursor|Cursor]]: AI-powered code editor with [[concepts/code-generation|code generation]] and chat features.
- [[entities/wind-surf|Wind Surf]]: VS Code fork focused on AI-assisted [[concepts/development-workflows|development workflows]].
- [[entities/kiro|Kiro]]: [[entities/amazon|Amazon]]'s new [[concepts/ai-code-editor|AI code editor]], announced in [[concepts/date-2026-04-13|2026]], positioned as a competitive VS Code fork in the AI editor market.
