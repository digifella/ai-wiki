# Jeremy

Jeremy is a framework for building AI-powered [[concepts/software|applications]] designed to run efficiently on local [[concepts/hardware|hardware]]. It enables developers to create applications that leverage [[concepts/ai-technologies|artificial intelligence]] capabilities while executing directly on user devices rather than relying on cloud-based services.

## Cross-Platform Compatibility

The framework supports development across multiple platforms and hardware configurations, including standard PC setups, macOS systems, and mobile devices. Applications built with Jeremy can run on different hardware configurations without requiring modifications to the [[concepts/code|codebase]], facilitating broader [[concepts/deployment|deployment]] across diverse user environments.

## Performance Optimization

Jeremy emphasizes bare-metal performance optimization, allowing applications to access hardware resources efficiently for improved execution speed. This approach is particularly valuable for [[concepts/ai-powered-applications|AI applications]] where [[concepts/computational-efficiency|computational efficiency]] directly impacts responsiveness and usability on consumer-grade hardware.
