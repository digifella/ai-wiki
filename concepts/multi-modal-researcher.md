# Multi Modal Researcher

The Multi Modal Researcher is an AI agent designed to perform comprehensive investigations by processing and analyzing multiple data types simultaneously. Built on Google's Gemini 2.5 models and orchestrated through the LangGraph framework, the system leverages native multi-modal capabilities to understand and reason across text, images, and other input formats. This architecture allows the agent to extract insights from complex information sources that are difficult to analyze using text-based methods alone.

The agent's workflow is structured to handle diverse inputs, enabling it to synthesize information from visual and textual data concurrently. By utilizing LangGraph for orchestration, the system manages the state and transitions required for deep analysis, ensuring that relationships between different modalities are preserved during the investigation process. This approach facilitates a more holistic understanding of the subject matter compared to single-modality tools.

The primary output of the Multi Modal Researcher is a generated report or summary that reflects the integrated analysis of the provided data. The system is intended for use cases requiring detailed examination of mixed-media content, such as analyzing documents with embedded charts, interpreting visual evidence alongside textual descriptions, or conducting research across heterogeneous data sources. The tool aims to provide accurate and context-aware results by combining the reasoning strengths of Gemini 2.5 with the structural control of LangGraph.
