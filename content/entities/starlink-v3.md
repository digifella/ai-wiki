# Starlink V3

[[concepts/starlink-architecture|Starlink V3]] represents the third major generation of [[entities/spacex|SpaceX]]'s [[concepts/satellite-internet|satellite internet]] constellation [[concepts/architecture|architecture]], building upon the refinements introduced in Version 1.5. The evolution from earlier versions involves significant changes to satellite [[concepts/design|design]], [[concepts/signal-processing|signal processing]] [[concepts/capabilities|capabilities]], and network architecture to improve coverage, capacity, and latency characteristics across the global constellation.

## Technical Architecture

[[concepts/version-3|Version 3]] satellites incorporate updated phased array antenna systems and enhanced inter-satellite link capabilities compared to previous generations. These improvements enable more efficient signal routing through the constellation and reduce reliance on ground station infrastructure. The satellites also feature updated onboard computing systems designed to handle increased data throughput and more sophisticated beam management across service areas.

## Signal Physics and Performance

The transition to V3 includes refinements to signal processing and beam steering mechanisms that enhance the efficiency of spectrum utilization. These changes address interference mitigation, beam overlap optimization, and improved handoff procedures between satellites as they transit across coverage zones. The updated design [[concepts/parameters|parameters]] reflect operational lessons learned from the [[concepts/deployment|deployment]] and operation of earlier generation satellites.
