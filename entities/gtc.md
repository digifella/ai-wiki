# Gtc

Gtc is an enterprise-focused secure AI agent technology platform developed by NVIDIA. It is designed to enable organizations to deploy autonomous AI systems for business applications while maintaining security as a foundational architectural component. The platform provides tools and frameworks that address the enterprise demand for controlled deployment, ensuring compliance with organizational and regulatory standards.

The Gtc platform includes multiple variants tailored to different deployment scenarios. NemoClaw and OpenClaw represent distinct approaches within this ecosystem, offering specific capabilities for secure agent integration. These variants allow enterprises to select configurations that align with their specific operational requirements and security postures.
