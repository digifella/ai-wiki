# System Prompt

A system prompt serves as the initial set of instructions or guidelines provided to an AI agent at the beginning of a conversation or workflow. It establishes the agent's behavior, constraints, and objectives by defining parameters for how the model should approach tasks, interpret user requests, and format responses. These prompts function as standing instructions that persist throughout an interaction, shaping the agent's decision-making and output without requiring repetition in subsequent messages.

In the context of AI agents, system prompts act as a foundational layer that influences the model's persona and operational boundaries. They determine the scope of the agent's capabilities, such as whether it should act as a coding assistant, a creative writer, or a data analyst. By setting these parameters upfront, developers can ensure consistent performance and adherence to specific standards across different sessions.

For specialized workflows, such as generating presentations using tools like Claude and Cursor, the system prompt defines the technical requirements for output formats. It instructs the agent on how to structure code for HTML or PDF export, ensuring the final product meets the desired aesthetic and functional criteria. This precise configuration allows the AI to generate complex, multi-step outputs that align with the user's specific project goals.
