# Bonsai 8b Prismml

[[entities/bonsai-8b|Bonsai 8B]] is a mobile-optimized [[concepts/ai-technologies|artificial intelligence]] [[concepts/ai-inference|inference]] model designed for execution on edge devices rather than relying on cloud-based processing. The "8B" designation indicates the model contains approximately 8 billion parameters, positioning it within the small-to-[[entities/medium|medium]] range of contemporary language models. This [[concepts/parameter-count|parameter count]] represents a deliberate [[entities/national-academies|engineering]] trade-off between model capability and [[concepts/algorithm-efficiency|computational efficiency]], enabling deployment on [[concepts/consumer-grade-hardware|consumer-grade hardware]] with limited [[concepts/compute-capacity|processing power]] and [[concepts/memory|memory]].

## Architecture and Optimization

The [[concepts/prism-ml|Prismml]] framework serves as the underlying architecture for Bonsai 8B, focusing on minimizing latency and power consumption during [[concepts/edge-devices|on-device inference]]. By optimizing the model's structure for mobile [[concepts/central-processing-units|processors]], it allows complex AI tasks to be performed locally without requiring constant network connectivity. This approach enhances user [[concepts/privacy|privacy]] by keeping data on the device while maintaining sufficient performance for real-time applications.
