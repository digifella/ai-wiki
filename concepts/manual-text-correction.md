# manual text correction

The process of refining text within non-editable layers—such as [[concepts/ai-content-creation|AI-generated content]] or flattened images—to resolve [[concepts/typography|typography]] errors, spelling mistakes, or factual inaccuracies.

### Implementation Methods
- **[[entities/adobe-acrobat|Adobe Acrobat]]**: Used for direct [[concepts/text-manipulation|text manipulation]] within PDF-based [[concepts/infographic-design|infographics]].
- **[[entities/canva]] ('[[concepts/canva-grab-text-feature|Grab Text]]' feature)**: Enables extraction and editing of text embedded within static images.
- **Primary Use Case**: Remediation of inaccuracies or "hallucinated" text found in [[concepts/web-images-integration|AI-generated imagery]] (e.g., outputs from [[entities/gemini]]).
