# Slide deck generation

Automated or semi-automated creation of structured presentation content from source material, often used for educational, business, or documentation purposes.

## Key Workflows

- **[[concepts/audio-integration|NotebookLM integration]]**: Upload script → Generate slide deck → Export for video conversion
  - *Step 1*: Create new [[concepts/notebook|notebook]] in [[entities/notebooklm]], upload script via "Add Source" → "Upload [[concepts/files|Files]]"
  - *Step 2*: Generate structured slide deck from script
  - *Step 3*: Use [[concepts/output|output]] with [[entities/nano-banana-pro]] for [[concepts/whiteboard|whiteboard]] animation
  - *Step 4*: Refine video with [[entities/pictory|Pictory]]

## NotebookLM Enhancements

- **Research [[concepts/capabilities|Capabilities]]**: Includes [[entities/deep-research|Deep Research]] and [[concepts/fast-research|Fast Research]] for in-depth reports and rapid information gathering.
- **Studio Features**: Expanded toolkit including [[concepts/audio-overviews|Audio Overviews]], [[concepts/video-overviews|Video Overviews]], [[concepts/data-tables|Data Tables]], and Simulations.
