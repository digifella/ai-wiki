Hey there! 👋 My name is [[entities/nemotron|Nemotron]], and I’m built to be a versatile, text‑based [[concepts/ai-assistant|AI assistant]]. Here’s a quick rundown of what I can do for you:

### 🎯 Core Capabilities

|     |     |
| --- | --- |
| Area | What I can help with |
| Answering questions | Fact‑based queries, explanations of concepts, historical timelines, [[concepts/science|science]], tech, culture, and more. |
| Writing & editing | Essays, stories, poems, marketing copy, social‑media posts, emails, resumes, technical documentation, etc. |
| Creative projects | [[concepts/brainstorming|Brainstorming]] [[concepts/ideas|ideas]], [[concepts/plot-outlines|plot outlines]], [[concepts/integrity|character]] development, [[concepts/dialogue|dialogue]], world‑building, jokes, riddles, puzzles. |
| [[concepts/learning|Learning]] & tutoring | Explain math problems, [[concepts/physics|physics]] principles, programming concepts, language [[concepts/grammar|grammar]], study tips, flashcards, practice questions. |
| Programming assistance | Write, debug, and explain [[concepts/code|code]] in many languages ([[entities/python|Python]], JavaScript, Java, C++, [[entities/rust|Rust]], SQL, …); generate algorithms; refactor snippets; suggest [[concepts/best-practices|best practices]]. |
| Data & math | Perform calculations, create simple charts, walk through statistical [[concepts/reasoning|reasoning]], solve equations, generate formulas. |
| [[concepts/document-summarization|Summarization]] & extraction | Condense long articles, extract key points, create bullet‑point outlines, rewrite for different audiences. |
| Translation & language help | Translate short passages between many languages, explain idioms, improve phrasing, adapt [[concepts/tone|tone]]. |
| Planning & organization | Build schedules, to‑do lists, project plans, travel itineraries, meal plans, study timetables. |
| Role‑play & [[concepts/simulation-technology|simulation]] | Act as a character, simulate a conversation, run mock interviews, practice language scenarios. |

### 🛠️ Technical Limits

* No live browsing – I can’t pull in real‑time web results, check the latest stock prices, or verify brand‑new research papers published after my [[concepts/knowledge-cutoff|knowledge cutoff]] (June 2024).
* No personal data access – I can’t see your [[concepts/files|files]], emails, or any private information unless you paste it into the chat.
* No execution of code – I can write and explain code, but I can’t run it or guarantee that it [[entities/will|will]] work perfectly.
* Knowledge cutoff – My [[concepts/training-data|training data]] goes up to June 2024; anything that happened after that isn’t part of my built‑in knowledge (though I can often infer or extrapolate based on trends).

### 🤝 How to Get the Most Out of Me

1. Be specific – The clearer your request, the better the output.
	
	_Example:_ “Explain the difference between REST and GraphQL APIs in plain English with a simple analogy.”
	
2. Provide context – If you’re working on a project, tell me what stage you’re at, what you’ve tried, and what you need next.
3. Iterate – Feel free to ask follow‑up questions, request re‑phrasings, or ask for more detail.
4. Ask for formats – I can output in [[concepts/markdown|markdown]], bullet points, tables, code blocks, JSON, etc., just let me know what you need.
