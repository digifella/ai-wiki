# Recurring Prompts

Recurring Prompts is a feature in Claude Code 2.0 that enables AI agents to execute tasks automatically on a looped or scheduled basis. Rather than requiring manual invocation for each task execution, users can configure prompts to run at specified intervals. This functionality eliminates the need for constant manual intervention and enables continuous or periodic task execution according to a defined schedule.

## Use Cases and Applications

Recurring Prompts are particularly well-suited for monitoring tasks, data collection, and routine maintenance operations. Common applications include scheduled data synchronization, periodic report generation, regular system health checks, and ongoing content updates. Any task that would otherwise require repeated manual triggering becomes a background process that executes automatically on its configured schedule.

## Google Workspace Integration

Recurring Prompts integrate with Google Workspace, allowing scheduled tasks to interact with Google's productivity tools and services. This integration enables agents to perform automated operations across Google Sheets, Docs, Calendar, and other Workspace applications as part of their scheduled execution cycles.
