# AionUI

A free, [[concepts/open-source|open-source]], desktop-based platform designed for the management and [[concepts/automation|automation]] of Multi-Agent-AI systems.

### Key Features
- **[[concepts/agent-collaboration|Agent Orchestration]]:** Provides a centralized interface to run and manage diverse [[concepts/agentic-ai]].
- **Supported Integrations:** Compatible with [[entities/hermes]], [[entities/claude-code]], OpenCode, and [[entities/gemini]].
- **Functionality:** Optimized for multi-[[entities/agent|agent]] management and complex [[concepts/ai-automation]] workflows.
