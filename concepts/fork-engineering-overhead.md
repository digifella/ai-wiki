# Fork engineering overhead

Additional development and maintenance effort required to sustain a fork of a [[concepts/code|codebase]] (e.g., [[entities/vs-code|VS Code]]) as the original project evolves. Includes synchronization costs, patch management, and compatibility testing.

- **[[entities/kiro|Kiro]]**: [[entities/amazon|Amazon]]'s [[concepts/ai-code-editor]], a [[concepts/vs-code-fork|VS Code fork]] (similar to [[entities/cursor|Cursor]] and [[entities/wind-surf|Wind Surf]]). Incurs significant [[entities/national-academies|engineering]] overhead to stay updated with [[entities/microsoft|Microsoft]]'s releases, though Amazon's resources mitigate this burden.
- **Market context**: [[concepts/vs-code-forks|VS Code forks]] represent a common strategy in the [[concepts/ai-code-editor]] space, but require sustained investment to avoid divergence from upstream.
