# Markdown

Markdown is a lightweight markup language designed for easy readability and conversion to HTML and other formats. Created by [[entities/chef-john|John]] Gruber in 2004, it uses simple text-based syntax with symbols like asterisks, hashes, and brackets to indicate formatting such as bold, italics, headings, and links. The language prioritizes human-readable source [[concepts/text|text]] that remains legible even before rendering.

## Common Uses

Markdown has become the de facto standard for documentation in [[concepts/coding|software development]], particularly in version [[concepts/power|control]] platforms like [[entities/github|GitHub]] where README [[concepts/files|files]] and wikis are typically written in Markdown. It is widely used for creating technical blogs, API documentation, and [[concepts/knowledge-bases|knowledge bases]]. Many note-taking [[concepts/software|applications]], [[concepts/static-website|static site]] generators, and content management systems support Markdown as a primary input format.

## Key Characteristics

The syntax is minimal and intuitive, requiring no special editing tools—plain text editors suffice. This simplicity enables rapid [[concepts/content-creation|content creation]] while maintaining portability across different platforms and systems. Markdown files are typically saved with a `.md` extension and can be easily converted to HTML, PDF, or other formats using various [[concepts/central-processing-units|processors]] and tools. Its widespread [[concepts/adoption|adoption]] has led to several standardized variants, including CommonMark, GitHub Flavored Markdown (GFM), and MultiMarkdown, each extending the base syntax with additional features.
