# 2048 Game

[[entities/2048|2048]] is a sliding tile puzzle video game released in 2014 where players combine numbered tiles on a grid to create a tile with the value 2048. Gameplay involves swiping tiles in four cardinal directions to merge adjacent tiles of equal value, which double their combined number. The game concludes either when the player successfully creates a 2048 tile or when no valid moves remain on the grid.

## AI and Machine Learning Applications

The game's deterministic rules and constrained action space have made it a practical subject for algorithm research and [[concepts/ai-development|AI development]]. Its straightforward mechanics and quantifiable success conditions allow researchers to train and evaluate AI agents using various techniques. Matthew Berman has produced a video tutorial demonstrating how to train an AI to play 2048 locally using reinforcement learning, incorporating Nvidia hardware acceleration and the Unsloth library for efficient model training. This approach exemplifies how game environments with clear objectives can serve as accessible testbeds for machine learning development.
