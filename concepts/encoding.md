# Encoding

Encoding refers to the process of converting information or data into a specific format for [[entities/storage|storage]] or transmission. It plays a crucial role in various fields such as computer [[concepts/science|science]], telecommunications, and [[concepts/linguistics|linguistics]].

## Key Concepts

- **[[concepts/integrity|Character]] Encoding**: Converts characters from a character set (like ASCII or Unicode) into binary code.
  - ASCII
  - Unicode

- **Binary Encoding**: Represents data using zeros and ones for digital transmission.
  - binary

- **URL Encoding**: Transforms special characters in URLs to ensure correct interpretation by web browsers and servers.
  - URL Encoding

## Applications

- Data [[concepts/model-efficiency|Compression]]: Techniques like Huffman [[concepts/coding|coding]] or Run-length encoding are used.
  - [[concepts/data-compression|data compression]]

- [[concepts/cryptography|Cryptography]]: Methods such as Base64, ROT13, or more complex cryptographic protocols ensure data [[concepts/security|security]] and [[concepts/honesty|integrity]] during transfer.
