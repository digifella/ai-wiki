# License

The Apache 2.0 license is a permissive open-source software license maintained by the Apache Software Foundation. It grants users the freedom to use, modify, and distribute software under its terms while providing explicit patent protections to licensees. The license is widely adopted across software projects, frameworks, and tools due to its clear terms and compatibility with many other open-source licenses.

## Key Requirements and Terms

Apache 2.0 requires that modified versions of the software include a notice of the changes made. Distributions of the licensed software must retain the original copyright notice, license text, and disclaimer of warranty. Additionally, any state changes to source files must be documented to ensure transparency regarding modifications.

The license also mandates that any non-source code distributions, such as binary files, must include a copy of the license and copyright notices. This ensures that recipients are aware of their rights and the conditions under which the software is provided. The explicit patent grant protects users from patent litigation by contributors, offering a layer of legal security that distinguishes it from other permissive licenses like MIT or BSD.
