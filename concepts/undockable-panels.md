# Undockable Panels

**Undockable Panels** refer to interface elements in [[entities/adobe-camera-raw]] that can be detached from the main application window and moved independently. This feature enhances workflow flexibility by allowing users to arrange tools according to their specific monitor setup or preference.

## Key Updates

### Camera Raw 18.7 Enhancements
The following features were introduced in the 18.7 update, focusing on [[concepts/efficiency-principles|workflow efficiency]] and UI flexibility:

*   **Undockable Panels**: Allows panels to be detached and repositioned freely.
*   **[[concepts/match-exposure|Match Exposure]]**: Improved function for aligning exposure levels across images.
*   **[[concepts/grid-view|Grid View]]**: New browsing mode for reviewing multiple images.
