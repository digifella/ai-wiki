## Smolcoder: Optimizing Free Local LLMs for Development Tasks

**[[concepts/agent-skills|Smolcoder]]** is an open-source coding agent designed to optimize and enhance the use of free, [[concepts/local-llms|local large language models]] (LLMs) for [[concepts/development-tasks|development tasks]]. It addresses the performance gaps often found when running coding agents on non-commercial, locally hosted models.

### Key Details
- **Purpose:** Enhances the efficacy of free local LLMs for software development workflows.
- **Creator:** [[entities/leon-van-zyl|Leon van Zyl]]
- **Core [[concepts/business-model|Value Proposition]]:** Provides a high-quality alternative to commercial coding agents (e.g., [[entities/claude-code|Claude Code]]) by leveraging local resources.
- **Status:** Open-source project.
