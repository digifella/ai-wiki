# Sam Witte Author

Sam Witte is an author and content creator focused on practical machine [[concepts/learning|learning]] tutorials and guides. He specializes in demonstrating how to locally install and deploy [[concepts/large-language-model-llm|large language models]] using modern serving frameworks.

## Content and Focus

Witte has produced detailed guides for [[concepts/running|running]] the [[concepts/3-billion-parameter-model|SmolLM3-3B]] model, a 3-billion parameter [[concepts/statistical-language-modeling|language model]] from [[concepts/open-source-machine-learning|Hugging Face]], on local systems. His tutorials emphasize practical implementation using VLLM, an [[concepts/inference|inference]] serving framework designed for efficient model [[concepts/deployment|deployment]]. His work includes written guides, video demonstrations, and [[concepts/open-source|open-source]] code examples made available through platforms like GitHub and YouTube.

## Contribution to LLM Accessibility

By documenting the [[concepts/local-installation|local installation]] and serving process for models like SmolLM3-3B, Witte contributes to making language model deployment more accessible to developers and researchers who prefer to run models on their own infrastructure rather than relying on cloud-based APIs.
