# Brush Size Control

Brush size control in [[concepts/photoshop|Adobe Photoshop]] refers to the ability to adjust brush dimensions during active painting and editing work. Rather than accessing brush settings through menus or panels, Photoshop provides keyboard shortcuts that allow artists to modify brush properties in real time without interrupting their workflow. This method of control is particularly useful when working on detailed digital art, [[concepts/photo-editing|photo editing]], or illustration projects where frequent size [[concepts/adjustments|adjustments]] are necessary.

## Size Adjustment

The primary method for controlling [[concepts/brush-size|brush size]] uses the bracket keys found on a standard keyboard. Pressing the left bracket key `[` decreases the brush size, while the right bracket key `]` increases it. Each key press adjusts the size by a set increment, allowing for quick transitions between different brush dimensions. This approach is faster than navigating to brush panels or using dropdown menus, making it a standard practice among digital artists.

## Hardness Adjustment

[[concepts/brush-hardness|Brush hardness]], which controls the softness or crispness of brush edges, can be similarly adjusted using keyboard shortcuts. Holding Shift while pressing the bracket keys modifies the hardness value rather than the size. This dual-control system allows artists to fine-tune both brush characteristics simultaneously without accessing additional interface elements, maintaining a smooth and uninterrupted creative process.
