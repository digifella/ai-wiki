# Integrated Agent

An Integrated Agent is an [[concepts/ai-technologies|artificial intelligence]] [[concepts/system-architecture|system architecture]] that unifies distinct cognitive and operational capabilities into a single, cohesive framework. Unlike modular systems where components such as [[concepts/reasoning|reasoning]], [[concepts/acting|tool use]], and [[concepts/decision-making|decision-making]] operate in [[concepts/disconnection|isolation]], integrated agents coordinate these functions within a unified structure. This design allows the system to manage complex, [[concepts/multi-step-tasks|multi-step tasks]] more effectively by maintaining context and [[concepts/continuity|continuity]] across different operational phases.

The concept gained significant [[concepts/attention-mechanism|attention]] following [[entities/anthropic-institute|Anthropic]]'s [[concepts/deployment|release]] of the "[[concepts/dom|Christmas Claude]]" update series, which emphasized advanced agentic strategies. These [[concepts/software-updates|updates]] focused on improving how the model coordinates its internal processes to execute [[concepts/automated-business-operations|autonomous operations]], highlighting the shift from simple prompt-response interactions to sustained, [[concepts/goal-oriented-behavior|goal-oriented behavior]]. The integration of these capabilities enables the agent to plan, execute, and adapt its actions in real-time without requiring external intervention for each step.

By combining reasoning and decision-making with direct tool access, integrated agents reduce the latency and error rates associated with hand-offs between separate modules. This approach supports more robust [[concepts/autonomous-operation|autonomous systems]] capable of handling [[concepts/complex-tasks|intricate workflows]] that require dynamic adjustment of strategies based on intermediate results. The architecture represents a move toward more reliable and scalable AI assistance in environments where tasks are non-linear and require continuous evaluation.
