# Select Subject Tool

The Select Subject Tool is an AI-powered masking feature available in Adobe Lightroom and the Camera Raw Filter. It automatically detects and isolates primary subjects within photographs, such as people, animals, or distinct objects, by analyzing image content to identify visual boundaries. This functionality provides users with an automated starting point for masking, eliminating the need to manually trace complex edges from scratch.

The tool utilizes machine learning models trained on diverse datasets to recognize common subject types and their typical spatial relations. By processing the image data, it generates a precise selection mask that encompasses the identified subject. This automation significantly reduces the time required for initial selection, allowing editors to focus on refining the mask and applying adjustments.

Users can further refine the generated selection using additional masking tools within the same interface. The initial AI detection serves as a foundation that can be adjusted for precision, ensuring that the subject is accurately separated from the background. This workflow integrates seamlessly into the broader editing process, facilitating targeted adjustments to lighting, color, and clarity for specific elements within the image.
