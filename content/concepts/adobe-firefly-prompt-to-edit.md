# Adobe Firefly Prompt To Edit

Adobe Firefly's [[concepts/layer-control|Prompt-to-Edit]] is a generative AI feature that allows users to modify [[concepts/images|images]] through natural language [[concepts/instructions|instructions]] rather than traditional manual editing tools. Instead of selecting specific areas, adjusting [[concepts/parameters|parameters]], or navigating complex design [[concepts/software|software]] interfaces, users describe their desired changes in text form. The AI interprets these prompts and applies the corresponding edits to the image, making image editing more accessible to users without specialized design [[concepts/training|training]].

## How It Works

The feature processes [[concepts/natural-language-descriptions|natural language descriptions]] to understand user intent and then applies generative edits to specified regions of an image. Users can describe modifications such as changing colors, altering backgrounds, adjusting composition, or adding elements. The system identifies the relevant areas of the image and generates edits that match the textual description, maintaining coherence with the existing image content.

## Use Cases and Accessibility

Prompt-to-Edit streamlines workflows for both professional designers and casual users. Designers can iterate on compositions and variations more quickly by describing changes verbally rather than manually executing each step. For non-designers, the feature lowers the barrier to image editing by eliminating the need to learn specialized software tools and techniques. This makes image manipulation a more intuitive process for users across different skill levels.
