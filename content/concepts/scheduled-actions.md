# Scheduled Actions

[[concepts/recurring-actions|Scheduled Actions]] is a feature in [[entities/gemini-models|Google Gemini]] that enables users to schedule tasks directly within the [[concepts/web-application|web application]] interface. This functionality allows for [[concepts/automation|automation]] of routine activities without requiring users to manually trigger actions [[concepts/assistive-technology|at]] specific times. The feature was introduced as part of [[concepts/gemini|Gemini]]'s broader effort to expand its productivity [[concepts/capabilities|capabilities]].

## Functionality

The feature integrates [[concepts/recurring-tasks|task scheduling]] directly into [[entities/gemini-app|Gemini]]'s [[concepts/workflow|workflow]], allowing users to set up actions to execute at predetermined times or intervals. This eliminates the need for manual intervention and enables better time management for recurring or time-sensitive tasks within the platform.

## Context

[[concepts/schedulerschedule-tool|Scheduled Actions]] was among several new features released by [[entities/google-ai-ultra|Google Gemini]] in early 2026, representing the platform's evolution toward more comprehensive automation and [[concepts/productivity-tools|productivity tools]]. The feature addresses user needs for greater [[concepts/power|control]] over task execution timing and [[concepts/efficiency-principles|workflow efficiency]].
