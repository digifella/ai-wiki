# LLM Frameworks

[[concepts/ai-templates|LLM frameworks]] are software libraries and platforms designed to simplify the development and deployment of applications powered by [[concepts/large-language-model-llm|large language models]]. These frameworks provide abstractions over [[entities/api-calls|API calls]], prompt management, [[concepts/memory|memory]] handling, and [[concepts/planning-errors|tool integration]], allowing developers to build complex [[concepts/ai-powered-applications|AI applications]] more efficiently than working directly with model [[concepts/open-standard-protocols|APIs]].

## Core Functionality

LLM frameworks typically handle [[concepts/recurring-tasks|recurring tasks]] in [[concepts/ai-application-development|AI application development]], including managing conversations and [[concepts/context-windows|context windows]], organizing and optimizing prompts, [[concepts/retrieving|retrieving]] and processing documents, orchestrating multi-step [[concepts/multi-agent-workflows|agent workflows]], and integrating [[concepts/external-tools|external tools]] and APIs. By abstracting these concerns, frameworks reduce boilerplate code and let developers focus on application-specific [[concepts/open-source-philosophy|logic]].

## Emerging Approaches

Recent developments in LLM frameworks have introduced alternatives to traditional monolithic framework architectures. Solutions like [[entities/llamaindex|LlamaIndex]]'s [[concepts/chart-extraction|LiteParse]] demonstrate how specialized components can enable local, [[concepts/numerical-data-extraction|agentic document processing]] without requiring a full framework dependency. This reflects a broader trend toward modular, composable tools that developers can combine according to their specific needs rather than adopting comprehensive platforms.

## Common Examples

Popular LLM frameworks include [[entities/langchain|LangChain]], which emphasizes chaining [[concepts/statistical-language-modeling|language model]] calls with [[concepts/external-data|external data]] sources; AutoGen, designed for [[concepts/multi-agent-orchestration|multi-agent collaboration]]; and LlamaIndex, which specializes in document [[concepts/data-indexing|indexing]] and [[concepts/document-retrieval|retrieval]]. Each framework makes different trade-offs between ease of use, flexibility, and feature comprehensiveness, allowing teams to select tools suited to their project requirements.
