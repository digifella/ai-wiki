# Form filling

The process of automatically populating web forms with data, typically for [[concepts/automation|automation]], data entry, or [[concepts/testing|testing]].

## Tools
- **[[concepts/claude-code|Claude Code]] for controlling Chrome**: Enables direct control of the **[[entities/claude-in-chrome|Claude in Chrome]]** browser extension (Beta, v2.0.70 through 2.0.72) via CLI for form filling, website navigation, and button clicks.

## Updates
- Recent features added in December 2025 bridge terminal control with web browsing.
