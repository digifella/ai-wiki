# Pinokio

[[concepts/pinokio-tool|Pinokio]] is a tool designed to run [[concepts/open-source]] models directly on a local computer, automating the installation and execution of complex AI environments.

## Key Features & Benefits
- **[[concepts/local-execution|Local Execution]]:** Enables [[concepts/running|running]] advanced models, such as [[entities/ltx-2|LTX-2]] and [[entities/wan|Wan]], directly on personal [[concepts/hardware|hardware]].
- **[[concepts/privacy|Privacy]]:** Ensures all data processing and generation remain private on the local machine.
- **No Subscription Costs:** Eliminates the need for recurring [[concepts/saas]] fees or usage-based billing.
- **No [[concepts/usage-limits|Usage Limits]]:** Provides unrestricted access to models without the constraints found in cloud-based platforms.
- **[[concepts/ai-video-automation|AI video generation]]:** Specifically useful for hosting resource-intensive [[concepts/video-generation|video generation]] models.

## System Requirements
- **[[concepts/hardware|Hardware]]:** Requires a dedicated GPU to handle the intensive computational demands of local [[concepts/ai-models|AI models]].
