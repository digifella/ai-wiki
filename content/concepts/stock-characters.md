# Stock Characters

Stock characters are pre-designed, reusable character [[concepts/templates|templates]] used in [[concepts/video-creation|video creation]] platforms like [[entities/vyond-go|Vyond Go]]. These characters serve as starting points for users who want to quickly populate their animated videos without needing to create custom characters from scratch. Users can select from a library of existing stock characters that vary in appearance, [[concepts/style|style]], and demographic representation.

## Creation and Customization

[[entities/vyond|Vyond Go]] allows users to either choose from existing stock characters or create custom characters before generating a video. This flexibility accommodates different project needs—users with time constraints can select ready-made characters, while those seeking more specific visual representations can [[concepts/design|design]] their own. Custom characters can then be saved and reused across multiple projects.

## Integration with Scripts

Stock characters work in conjunction with Vyond Go's script upload functionality. Users can prepare or upload a script before [[concepts/video-generation|video generation]], which the platform then pairs with selected characters to create the final animated video. This [[concepts/workflow|workflow]] streamlines the video creation process by allowing users to plan their casting and [[concepts/dialogue|dialogue]] separately from the character design [[concepts/phase|phase]].
