# Open-Source System

A software system whose source code is publicly available for inspection, modification, and enhancement. Key characteristics include [[concepts/opacity|transparency]], community-driven development, and freedom from [[concepts/vendor-lock-in|vendor lock-in]].

## Core Principles
- **Transparency**: Code is accessible to verify [[concepts/security|security]] and functionality.
- **Collaboration**: Development is often community-led or open to external contributions.
- **Extensibility**: Architecture allows for modular additions and customizations.
