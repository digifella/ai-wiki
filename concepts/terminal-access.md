# Terminal Access

## Overview
Terminal access serves as the primary interface for interacting with AI Agents and executing automated workflows. Recent developments in [[concepts/web-tools|agentic frameworks]] have expanded terminal capabilities beyond simple command execution to include complex, recurring task automation.

## Hermes Agent Integration
The introduction of the [[concepts/hermes-agent]] framework by [[entities/nous-research|Nous Research]] has significantly impacted terminal access patterns, particularly through its new `/loop` feature.

- **[[concepts/automated-recurring-tasks|Automated Recurring Tasks]]**: The `/loop` command enables the automation of repetitive terminal operations, reducing manual intervention.
- **Framework Context**: [[entities/hermes-agent|Hermes Agent]] is an open-source [[concepts/ai-agentic-framework|AI agentic framework]] designed to enhance terminal interactivity and task management.
- **Demo Reference**: A hands-on demonstration of these capabilities was provided by [[entities/fahd-mirza|Fahd Mirza]], focusing on the integration of loops within the [[entities/hermes-ai-agent|Hermes]] environment.
