# Zapier Mcp

Zapier Mcp is an integration framework that enables connections between [[entities/zapier|Zapier]] and locally-run language models through the [[concepts/external-tools|Model Context Protocol]] (MCP). It allows users to operate [[concepts/agentic-ai|AI agents]] on their own [[concepts/hardware|hardware]] while maintaining access to Zapier's [[concepts/automation|automation]] capabilities, bridging cloud-based [[concepts/ai-driven-workflow-automation|workflow automation]] with local LLM deployments.

## Purpose and Use Cases

The framework facilitates [[concepts/autonomous-ai-agent|autonomous AI agent]] setups where locally-hosted models can trigger and interact with Zapier's extensive app integrations. This configuration is particularly relevant for users seeking to run language models on [[concepts/local-infrastructure|local infrastructure]] while automating business processes across multiple [[concepts/software|applications]]. It has been used in conjunction with tools like [[entities/ollama|Ollama]] for [[concepts/local-model|local model]] hosting and frameworks designed for [[concepts/ai-agent|autonomous agent]] operation.

## Integration Approach

Zapier Mcp operates through the Model Context Protocol, a standardized interface for connecting language models with external tools and services. This allows locally-run LLMs to access Zapier's automation platform as a tool, enabling actions like triggering workflows, sending data between apps, and executing multi-step automation sequences based on local model [[concepts/reasoning|reasoning]] and decision-making.
