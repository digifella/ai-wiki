# User Guides

User guides are instructional documents that provide step-by-step procedures for operating software, tools, and systems. They serve as reference materials for end users, breaking down complex processes into clear, manageable steps. User guides can take various formats, including written documentation, interactive tutorials, video walkthroughs, or embedded help systems within [[concepts/software|applications]].

## Creating CoPilot Agents

One application of user guides is documenting the process for building [[concepts/copilot-agents|CoPilot agents]]—[[concepts/agentic-systems|autonomous agents]] that can retrieve information from organizational [[concepts/policies|policies]] and provide [[concepts/responses|responses]] to user queries. These guides typically walk users through [[concepts/agent-configuration|agent configuration]], defining data sources, setting response [[concepts/parameters|parameters]], and [[concepts/testing|testing]] functionality. An example use case includes creating a [[entities/microsoft-365|Microsoft 365]] support agent that answers frequently asked questions and provides user guidance in a conversational manner.

Effective user guides for agent creation should address both technical [[concepts/setup|setup]] and [[concepts/best-practices|best practices]] for agent behavior, ensuring that the resulting agents deliver accurate, helpful responses while maintaining appropriate [[concepts/tone|tone]] and scope. Clear documentation in this area reduces [[concepts/adoption|implementation]] time and helps organizations deploy agents that meet their specific needs.
