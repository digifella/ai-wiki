# Numpy

NumPy is a fundamental [[entities/python|Python]] library for numerical computing and array operations. It provides support for large, multi-dimensional arrays and matrices, along with a comprehensive collection of mathematical functions to operate on these data structures. NumPy forms the foundation for much of the scientific Python ecosystem and is widely used in data science, machine [[concepts/learning|learning]], and scientific research.

The library introduces the ndarray object, which is more efficient than Python's built-in lists for numerical operations. NumPy arrays enable vectorized computations that execute much faster than equivalent Python loops, making it essential for performance-critical [[concepts/software|applications]]. The library also provides tools for linear algebra, Fourier transforms, and random number generation.

NumPy is typically installed and managed through [[concepts/package-managers|package managers]] like pip or UV (a modern, faster alternative to pip). It integrates seamlessly with other popular Python libraries such as Pandas, Matplotlib, and scikit-learn, making it a cornerstone of the scientific Python toolkit.
