# Super Heavy Booster 19

Super Heavy Booster 19 (B-19) is a first-stage booster developed by SpaceX as part of the Starship launch system. It was designated for use during Starship Flight Test 12, where it served as the lower stage paired with the Starship V3 upper stage. As a specific iteration within SpaceX's Super Heavy booster family, B-19 represents a configuration point in the company's development and testing program for the integrated Starship vehicle.

## Role in Testing Program

B-19 functioned within SpaceX's incremental flight test cadence, which aims to validate successive improvements to the Starship stack through operational flights. Each booster iteration incorporates design refinements and hardware modifications based on data from previous test flights. The pairing of B-19 with the V3 upper stage reflected the contemporary state of both vehicle components at the time of Flight Test 12.

## Development Context

As part of the Super Heavy booster family, B-19 contributed to SpaceX's broader effort to develop a fully reusable, heavy-lift launch system. The booster's design and performance characteristics were informed by the results and lessons from earlier test flights, with each iteration advancing toward operational capability for the Starship program's eventual mission objectives.
