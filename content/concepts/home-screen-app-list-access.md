# Home Screen App List Access

Home Screen App List Access is a navigation feature introduced in [[entities/android-16|Android 16]] that provides users with direct access to the [[concepts/app-drawer|App Drawer]] from their home screen. The feature is implemented as a dedicated "App list" option within the home screen overlay menu, streamlining the process of accessing installed [[concepts/software|applications]] without requiring additional navigation steps.

## Implementation

In Android 16, the "App list" option appears in the home screen overlay menu, which users can access through standard home screen interactions. This menu option serves as a shortcut to the full App Drawer, consolidating app management tools in a more accessible location. The feature integrates with existing Android [[concepts/home-screen-design|home screen UI]] patterns rather than introducing entirely new interaction [[concepts/models|models]].

## Functionality

By selecting the "App list" option, users are taken directly to the App Drawer where they can browse, search, and launch installed applications. This reduces the number of gestures or taps required to access the complete list of apps on a device, particularly beneficial for users who frequently need to launch less commonly-used applications or discover new apps on their device.
