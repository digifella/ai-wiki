# AI Commands

AI Commands refer to voice-based [[concepts/instructions|instructions]] and dictation powered by [[concepts/ai-technologies|artificial intelligence]]. They enable users to interact with [[concepts/software|applications]] through natural language input rather than traditional text or manual input methods. These [[concepts/commands|commands]] leverage [[concepts/artificial-intelligence-models|machine learning models]] to interpret spoken language and execute corresponding actions across software platforms, reducing reliance on keyboard and mouse input. Common applications include [[concepts/voice-assistants|voice assistants]], dictation software, and hands-free control systems integrated into [[concepts/productivity-tools|productivity tools]] and operating systems.

## Wispr Flow

Wispr Flow is an AI-powered dictation application that raised $30 million in funding. The app specializes in converting speech to text with a focus on [[concepts/nlp|natural language processing]] and integration across multiple platforms. It represents a notable commercial application of AI command technology in the productivity software space.
