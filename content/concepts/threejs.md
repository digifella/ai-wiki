# Three.js

JavaScript library for creating and rendering 3D graphics in the browser using WebGL.

- Built on WebGL for [[entities/high-performance|high-performance]] 3D rendering.
- Scene graph [[concepts/organization|organization]] for complex 3D object hierarchies.
- Supports lighting [[concepts/models|models]], materials, textures, and animation systems.
- [[concepts/gpt-5|GPT 5]] - [[entities/mathew-berman|Mathew Berman]] demonstrated a fully interactive Rubik's Cube simulator (20x20x20) with [[concepts/dynamic-sizing|dynamic sizing]], [[concepts/color-coded-faces|color-coded faces]], camera controls, [[concepts/layer-rotation|layer rotation]], and "Solve" button using Three.js.
