# Intel Matching

Intel Matching is a feature that automatically detects and displays whether profile records have associated intelligence data. The system assigns a visual indicator to each profile card: either "N intel" in green (indicating matched intelligence) or "⚠ no intel" in amber (indicating no matched intelligence). These [[concepts/indicators|indicators]] update automatically whenever a profile is saved, created, or imported via CSV.

## Filtering and Discovery

The feature includes a dedicated filter tab labeled "⚠ No Intel (N)" within the profile type bar, enabling users to quickly identify and review profiles that lack matched intelligence. This filter displays a count of affected profiles, making it straightforward to locate records requiring [[concepts/attention-mechanisms|attention]] or additional data integration.
