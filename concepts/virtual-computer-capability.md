# Virtual computer capability

The ability of an [[concepts/ai-system|AI system]] to emulate a virtual computer, executing complex, multi-step tasks end-to-end through external system interaction, code execution, and analysis.

- **Core functionality**:
  - Interacts with websites (e.g., browsing, form submission)
  - Runs code for analysis/automation (e.g., [[entities/python|Python]] scripts)
  - Conducts [[concepts/visualization-generation|deep research]] and synthesizes results

- **Example**: The [[concepts/chatgpt-agent]] ([[entities/openai|OpenAI]], 2026) combines Operator, [[entities/deep-research|Deep Research]], and [[concepts/conversational-fluency|conversational fluency]] to handle tasks like booking dog-friendly [[entities/hipcamp|Hipcamp]] sites through [[concepts/website-interaction|website interaction]] and analysis.

- **Additional details**:
  - Functions as its own virtual computer, handling [[concepts/complex-tasks|complex tasks]] from start to finish.
  - Capable of interacting with websites, running code, and conducting analysis.
