# Qwen Code

[[concepts/ai-driven-code-editing|Qwen Code]] is a [[concepts/command-line-interface|command-line]] [[concepts/ai-workflow-tool|AI workflow tool]] developed by [[entities/alibaba|Alibaba]]'s AI department that enables local [[concepts/coding|coding]] assistance and [[concepts/automation|automation]]. It provides developers with an interface to leverage [[entities/qwen|Qwen]]'s language [[concepts/models|models]] for [[concepts/code-generation|code generation]], [[concepts/debugging|debugging]], and other programming tasks without requiring [[concepts/cloud-dependencies|cloud dependencies]] or external [[entities/api-calls|API calls]].

## Installation and Usage

The tool is designed for straightforward [[concepts/local-installation|local installation]] and command-line operation. Users can run [[concepts/automated-code-understanding|Qwen Code]] directly on their machines, making it accessible for developers who prefer working with [[concepts/ai-coding-assistance|AI-assisted coding]] in their existing terminal workflows.

## Design Philosophy

Qwen Code positions itself as an alternative to cloud-based coding assistants by emphasizing [[concepts/local-execution|local execution]] and [[concepts/power|control]]. This approach aligns with Alibaba's broader strategy of providing [[concepts/open-source|open-source]] and locally-deployable [[entities/ai-tools|AI tools]] that reduce dependency on external services.
