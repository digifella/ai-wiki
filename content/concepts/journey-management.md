# Journey Management

Journey Management refers to a [[concepts/visual-editing|visual editing]] system designed to enable users to create and edit travel blogs through a sequential, block-based interface. Each blog post consists of modular content blocks containing [[concepts/text|text]] and photos arranged in a linear sequence, allowing authors to build narratives of their travels without requiring technical knowledge of HTML or markup languages.

## Current System and Gap

The existing journeys platform stores completed blogs as static HTML [[concepts/files|files]] in a content directory [[concepts/structure|structure]] organized by URL slug. However, this system lacks a visual editor, meaning travel blog content cannot be created or modified through a user-friendly interface. [[concepts/content-creation|Content creation]] currently requires direct file manipulation or backend access, creating a significant barrier to regular blog updates.

## Requirements

The needed system should function similarly to established visual editors like [[entities/adobe-express|Adobe Express]], providing an intuitive drag-and-drop or block-based interface. Users should be able to add, arrange, and edit text and photo blocks in sequence, with changes reflected immediately or through a straightforward publishing [[concepts/workflow|workflow]]. The editor must bridge the gap between the visual creation experience and the static HTML [[concepts/output|output]] currently used by the platform.
