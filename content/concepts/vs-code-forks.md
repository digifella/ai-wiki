# Vs Code Forks

[[entities/vscode|Visual Studio Code]]'s [[concepts/open-source|open-source]] foundation has enabled numerous community and commercial forks, each adapting the [[concepts/code|codebase]] for specific [[concepts/scenarios|use cases]] or user bases. These variants typically build on VS Code's core [[concepts/architecture|architecture]] while introducing modifications to features, [[concepts/licensing|licensing]], or bundled tools. The ecosystem reflects both the strength of VS Code's design and ongoing debates around open-source sustainability and commercial [[concepts/distribution|distribution]].

## Notable Forks and Alternatives

Several organizations have created significant forks or alternatives to VS Code. Amazon developed Kiro, an AI-focused code editor built on VS Code's foundation, positioning it as a tool for developers working with machine [[concepts/learning|learning]] and [[concepts/cloud-computing|cloud services]]. Other notable forks include VSCodium, a community-maintained build that removes telemetry and proprietary features, and various enterprise distributions that bundle additional tools or enforce specific configurations.

The proliferation of forks reflects divergent priorities within the [[concepts/developer|developer]] tools space: some emphasize [[concepts/privacy|privacy]] and open-source principles, others focus on [[concepts/development-speed|AI-assisted development]], and still others target specific programming languages or workflows. Most maintain compatibility with VS Code's extension ecosystem, allowing users to port their configurations and [[concepts/plugins|plugins]] between variants.
