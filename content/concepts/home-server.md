# Home server

A [[concepts/personal-cloud-server|Home server]] is a centralized computing [[entities/nodejs|node]] used for [[concepts/nas|NAS]] ([[concepts/network-attached-storage|Network Attached Storage]]), Virtualization, and hosting various self-hosted services.

    - **[[concepts/memory|Memory]]**: 16GB.
    - **[[concepts/capabilities|Capabilities]]**: Highly capable for both NAS [[entities/storage|storage]] and Virtualization tasks.
