# Experience Memory Graph

**[[concepts/experience|Experience]] [[concepts/memory|Memory]] Graph (EMG)** is a framework for enabling [[concepts/agentic-ai|AI agents]] to perform one-shot [[concepts/bug-fixing|error correction]] through graph-based [[concepts/learning|learning]]. It shifts the paradigm from iterative loop-based correction to structured graph traversal, allowing agents to retrieve and apply corrective knowledge from past experiences efficiently.

## Core Concepts
- **[[concepts/graph-based-error-correction|Graph-Based Error Correction]]**: Utilizes a graph structure to map errors to specific corrective actions or knowledge [[concepts/nodes|nodes]], enabling non-sequential [[concepts/document-retrieval|retrieval]].
- **One-Shot Learning**: Allows agents to correct errors based on a single prior example stored in the graph, reducing the need for extensive retraining or repeated trial-and-error.
- **Experience Memory**: The underlying [[concepts/data-structure|data structure]] that stores successful trajectories, failure modes, and their corresponding corrections as [[concepts/nodes-and-edges|nodes and edges]].
