# Table Generation

Table Generation is a feature in [[concepts/ai-integrated-notebooks|NotebookLM]] that enables users to automatically create [[concepts/json-structuring|structured data]] tables from various source materials. This functionality extracts and organizes information from sources such as [[entities/youtube|YouTube]] videos, websites, and documents into tabular format, allowing users to quickly synthesize and [[concepts/feynmans-three-step-scientific-method|compare]] data without manual data entry.

## Functionality and Use Cases

The feature processes unstructured content—including video transcripts, web pages, and [[concepts/text|text]] documents—and converts relevant information into organized table structures. This capability is particularly useful for research tasks, comparative analysis, and [[concepts/information-extraction|data extraction]] workflows where information needs to be presented in a standardized format for easier review and reference.

## Integration with NotebookLM

Table Generation represents one of several upgrades to [[concepts/notebooklm|NotebookLM]]'s [[concepts/capabilities|capabilities]], designed to improve how users interact with and extract value from their sources. By automating the table creation process, the feature reduces the manual work required to organize information and helps users work more efficiently with their research materials and reference documents.
