# LTX Desktop

**LTX Desktop** is the first native, free, [[concepts/open-source|open-source]], and fully local non-linear [[concepts/ai-video-editor|AI video editor]], powered by the [[entities/ltx-23|LTX 2.3]] multimodal [[concepts/engine|engine]]. It provides a desktop-native environment for private, hardware-accelerated [[concepts/video-creation|video creation]] and manipulation, removing reliance on cloud [[concepts/open-standard-protocols|APIs]] and [[concepts/subscription-models|subscription models]].

## Key Attributes
- **Local-First Architecture:** Executes entirely on user hardware, ensuring data [[concepts/privacy|privacy]] and eliminating cloud latency or API costs.
- **[[concepts/ltx-2|LTX 2]].3 Integration:** Leverages the [[entities/ltx-2|LTX 2]].3 model for advanced multimodal generation, supporting [[concepts/text-to-video|text-to-video]], [[concepts/image-to-video|image-to-video]], and video-to-video workflows.
- **Non-Linear Workflow:** Combines traditional [[concepts/non-linear-editing-workflow|timeline-based editing]] capabilities with AI-native tools, diverging from linear prompt-only interfaces.
- **Open Source:** Community-accessible [[concepts/code|codebase]] allowing for [[concepts/customization|customization]], extension, and [[concepts/opacity|transparency]].
- **Free Distribution:** Released without cost, reducing barriers to entry for local [[concepts/ai-film-direction|AI video production]].
