# Apache 2.0 license

The [[concepts/apache-2.0|Apache License 2.0]] is a permissive [[concepts/open-license|free software license]] issued by the Apache Software Foundation. It allows users to freely use, modify, distribute, and sublicense the software, provided they retain copyright notices and disclaimers.

## Key Characteristics
- **Permissive:** Unlike GPL licenses, it does not require derivative works to be [[concepts/open-source|open-source]].
- **Patent Grant:** Includes an explicit grant of patent rights from contributors to users, protecting against patent litigation for the licensed code.
- **Notice Requirement:** Requires [[concepts/preservation|preservation]] of copyright, license, and notice files in copies of the software.
- **State Changes:** Requires modified files to carry prominent notices stating that they were changed.
