# Foundry Local SDK

Foundry Local SDK is a software development kit that enables developers to build applications with integrated artificial intelligence capabilities optimized for local execution. Rather than relying on cloud-based AI services, the SDK allows AI models to run directly on end-user devices, eliminating the need for constant server connectivity and reducing latency in AI-powered features.

## Supported Platforms

The SDK supports development and deployment across multiple platforms, including Windows PCs, macOS systems, and mobile devices. This cross-platform compatibility allows developers to create consistent AI-enabled experiences regardless of the target device or operating system.

## Key Characteristics

By prioritizing local execution, the Foundry Local SDK addresses concerns around data privacy, network dependency, and response times inherent in cloud-based AI solutions. Developers using the toolkit can deploy pre-trained or custom AI models directly to user hardware, giving them control over model management and performance optimization at the edge.
