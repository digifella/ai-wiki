# Smart coding agent

[[concepts/ai-assistant]] integrated into IDEs that augments [[entities/developer|developer]] expertise through context-aware [[concepts/code|code]] suggestions, refactoring, and [[concepts/debugging]] without replacing [[concepts/developer|developer]] [[concepts/decision-making]].

Key characteristics:
- **Professional focus**: Targets experienced developers (not "[[concepts/3d-game-development|vibe coding]]" tools for non-developers)
- **Context-aware assistance**: Provides targeted help within current code context
- **Avoids bulk [[concepts/code-generation|code generation]]**: Does not blindly produce thousands of lines from scratch
- **Deep [[concepts/ide-integration]]**: Seamlessly works within existing [[concepts/workflow]]
- **[[concepts/subagent-orchestration|Subagent orchestration]]**: Advanced implementations like [[concepts/claude-code|Claude Code]] leverage [[concepts/subagents|subagents]] for [[concepts/task-specific-workflows|task-specific workflows]] and enhanced [[concepts/context-management|context management]]
