# Free Api Access

Free API access to [[concepts/advanced-ai-models|advanced AI models]] can be achieved by running them locally using [[concepts/open-source|open-source]] tools like [[concepts/task-specific-modeling|Ollama]]. This approach eliminates API costs while maintaining privacy, as all processing occurs on your own hardware rather than being sent to external servers. [[concepts/local-control|Local deployment]] is particularly useful for development, testing, and applications that do not require [[concepts/cloud-based-computer|cloud infrastructure]] or need to operate with reduced latency and [[concepts/data-sovereignty|data sovereignty]] requirements.

## Running Models Locally with Ollama

Ollama is an open-source platform that simplifies running [[concepts/demystifying-llms|large language models]] on personal devices. It manages the underlying infrastructure, allowing users to download and execute models such as [[concepts/llama-3|Llama 3]], [[entities/mistral-ai|Mistral]], and CodeLlama with minimal configuration. By serving these models via a [[concepts/local-api|local API]] endpoint, developers can interact with them using standard HTTP requests, effectively creating a private, cost-free alternative to commercial [[concepts/cloud-based-ai-services|cloud-based AI services]].
