# Canva Grab Text feature

A utility within [[entities/canva]] designed to identify and extract [[concepts/text|text]] from static [[concepts/images|images]], converting it into editable text elements.

### Key Capabilities & Comparisons
* **Correcting AI-Generated Assets:** Provides a practical method for directly editing text within AI [[concepts/infographic-design|Infographics]] to resolve spelling mistakes or inaccuracies generated by tools like [[entities/gemini]].
* **[[concepts/workflow|Workflow]] Comparison:**
	* **Canva 'Grab Text'**: A streamlined method for editing text embedded in images/infographics.
	* **[[entities/adobe-acrobat|Adobe Acrobat]]**: An alternative approach for text extraction and manipulation.
* **Reference:** [Edit Text in AI Infographics & Images in 60 seconds](https://www.youtube.com/watch?v=wsq6AbWVzbw) (via Educraft).
