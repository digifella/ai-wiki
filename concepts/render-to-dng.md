# Render to DNG

## Overview
A feature introduced in [[entities/lightroom-desktop-95|Lightroom Desktop 9.5]] that allows users to export processed images as DNG files, preserving the full dynamic range and metadata of the original RAW data while applying current edits.

## Key Updates (Lightroom Desktop 9.5)
*   **[[concepts/mask-refinement|Mask Refinement]]**: Enhanced precision in selecting and refining masks during the rendering process.
*   **[[concepts/crop-and-expand|Generative Expand]]**: Integration of AI-driven expansion capabilities within the export workflow.
*   **Workflow Impact**: Considered a significant change to the post-processing pipeline by industry experts [[lab-notes/2026-08-08-Lightroom-Desktop-9.5-Updates-Mask-Refinement-Render-to|Lightroom Desktop 9.5 Updates: Mask Refinement, Render to DNG, Generative Expand]].
