# Local Workspace

A **Local Workspace** is a self-contained environment where [[concepts/agentic-ai|AI agents]] collaborate by sharing a unified file system, context, and state without [[concepts/cloud-dependencies|cloud dependencies]]. Enables complex task orchestration with data [[concepts/privacy|privacy]] and offline capability.

## Key Features
- **Shared Context**: [[concepts/agents|Agents]] maintain continuous state across interactions (no isolated chat sessions)
- **File-Based Collaboration**: Direct [[concepts/file-sharing|file sharing]] and [[concepts/version-numbers|versioning]] within the workspace
- **Orchestration**: Agents trigger each other's workflows (e.g., [[concepts/code-generation|code generation]] → [[concepts/testing|testing]])

## Example: Claude Code AI Work Team
- [[entities/claude-code]] enables building [[entities/openclaw|autonomous agent]] teams that share a local workspace
- Agents]] collaborate on multi-step tasks (e.g., generate code → validate → document) without manual handoffs
- Eliminates context-switching between isolated chat sessions
