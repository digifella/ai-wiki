# Unreal Engine Integration

**[[entities/unreal-engine|Unreal Engine]] Integration** refers to the capability of connecting Unreal [[concepts/engine|Engine]] with external [[concepts/ai-models|AI systems]], specifically [[entities/hermes-agent]], to enable dynamic content generation, procedural [[concepts/open-source-philosophy|logic]], and [[concepts/ai-agent|autonomous agent]] behaviors within the engine environment.

## Key Developments

	- Introduces eight significant changes aimed at enhancing [[concepts/ai-agent-autonomy|agent autonomy]] and connectivity.
	- Specifically highlights improved Unreal Engine Integration alongside [[concepts/new-features|new features]] for iMessage and [[concepts/background-agents]].

## Technical Context

- **[[concepts/system-autonomy|Agent Autonomy]]**: Enables [[concepts/ai-agents|AI agents]] to operate within the Unreal Engine runtime, potentially handling NPC logic, environment interaction, or real-time asset modification.
- **Interoperability**: Bridges the gap between LLM-driven [[concepts/decision-making|decision making]] (via [[entities/hermes|Hermes]]) and high-fidelity rendering/physics [[concepts/simulation|simulation]] (via Unreal).
