# engram

In [[concepts/neuroscience|neuroscience]], an [[entities/deepseek-engram|engram]] refers to the physical trace of a [[concepts/memory|memory]] in the brain, representing the neural changes that encode and store information. First proposed by Richard Semon in 1904, it remains central to memory research.

## Modern Usage
- **[[entities/deepseek|DeepSeek]] engram**: A term coined by DeepSeek to describe their [[concepts/context-aware-knowledge-retrieval|context-aware knowledge retrieval]] system for LLMs, which eliminates redundant context processing by dynamically accessing relevant knowledge. This solves a key inefficiency in current LLMs (e.g., [[entities/chatgpt|ChatGPT]], [[concepts/gemini|Gemini]]) that reprocess entire contexts per query, significantly improving speed and resource efficiency. See [[entities/two-minute-papers]] video and note 2026 04 14 [[concepts/computational-reasoning|DeepSeek engram]].
