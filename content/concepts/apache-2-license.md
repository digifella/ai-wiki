# Apache 2 license

The [[concepts/apache-license|Apache License]], Version 2.0 is a permissive [[concepts/open-source|open-source]] [[concepts/license|license]] permitting free use, modification, and [[concepts/distribution|distribution]] of [[concepts/software|software]] with minimal restrictions. Key features include:
- Explicit patent grant from contributors
- Permits commercial use without requiring derivative works to be [[concepts/open-source|open-source]]
- Requires [[concepts/preservation|preservation]] of copyright and license notices
- No copyleft requirements

Example: [[concepts/videorefer-suite]] ([[entities/alibaba|Alibaba]]'s video model for [[concepts/spatial-temporal-object-understanding|spatial-temporal object understanding]] in LLMs) released under Apache 2 license — see [[entities/fahd-mirza|Fahd Mirza]] - Videorefer model [[concepts/running|running]] locally.
