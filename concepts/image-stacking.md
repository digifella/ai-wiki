# Image stacking

Combining multiple similar photos to select optimal elements (e.g., fixing closed eyes in group photos or merging elements from different shots).

- **Method**: Load images into a stack (in [[concepts/photoshop|Photoshop]]), auto-align layers (to compensate for non-tripod [[concepts/exercise|movement]]), then use [[concepts/layer-masks|Layer masks]] to selectively reveal parts of different layers.
- **[[concepts/scenarios|Use cases]]**:
  - Fixing imperfections in group photos (e.g., closed eyes) by combining the best elements from multiple shots.
  - Creating composite images with optimal features from several similar captures.
