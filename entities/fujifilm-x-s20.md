## Fujifilm X-S20 Overview

The [[entities/fujifilm-x-s20|Fujifilm X-S20]] is a high-end mirrorless digital [[concepts/camera-settings|camera]] designed for professional and advanced amateur photographers. - High-[[concepts/solution|resolution]] display

This function can be particularly useful in fast-paced environments or when using multiple cameras with specific setups.

### How to Access and Use the Lock Feature
- Navigate to the "Lock" option within the camera's menu system.
