# Long-Horizon Agentic Work

**[[concepts/computer-usage|Long-horizon agentic work]]** refers to complex, [[concepts/multi-step-tasks|multi-step tasks]] executed by [[concepts/autonomous-ai-systems|autonomous AI]] agents that require sustained [[concepts/reasoning|reasoning]], [[concepts/memory|memory]] management, and tool use over extended periods. Key challenges include context retention, [[concepts/error-correction|error correction]], and maintaining goal alignment across numerous intermediate steps.

## Key Enablers

*   **Extended Context Windows:** Models capable of processing large amounts of information simultaneously are critical for maintaining state in long-horizon tasks.
*   **Multimodal Reasoning:** Ability to interpret and generate text, code, images, and other data types enhances agent flexibility.
*   **[[concepts/open-weight-ai-models|Open-Weight Models]]:** Facilitate [[concepts/customization|customization]] and integration into specialized workflows without vendor lock-in.

## Recent Developments

*   **[[entities/muse-spark|Muse Spark]] 1.3:** [[entities/meta|Meta]]'s latest multimodal [[concepts/reasoning-model|reasoning model]], designed specifically for long-horizon agentic work.
    *   Features a **1 million token [[concepts/context-length|context window]]**, enabling deep state retention.
    *   Poised to be released as an **open-weight** model, allowing for broader community adaptation.
    *   Focuses on robust reasoning capabilities required for complex, multi-step agent workflows.
