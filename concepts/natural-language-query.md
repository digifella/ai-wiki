# Natural language query

A natural language query (NLQ) is a user input expressed in ordinary language (e.g., "Show me [[concepts/notes|notes]] about project X from last month") rather than structured syntax, enabling intuitive interaction with [[concepts/knowledge-management|information systems]] through [[concepts/natural-language-processing]] (NLP).

## Key Characteristics
- Human-readable and conversational
- Requires AI interpretation for system action
- Reduces [[concepts/cognitive-load|cognitive load]] compared to formal query languages

## Applications
- Search engines (e.g., [[concepts/google-search|Google]])
- [[concepts/voice-assistants|Virtual assistants]] (e.g., [[concepts/siri]], Alexa)
- Database interfaces (e.g., [[concepts/conversational-interface|Natural Language Interface]])
- Note-taking systems (e.g., [[entities/evernote|Evernote]] v11 features)

## Evernote v11 Integration
- Introduced AI-powered natural language query as core feature, enabling conversational search within notes
- Part of three major AI features enhancing [[concepts/second-brain]] functionality
- Built on rebuilt technical foundations (speed/sync/[[concepts/software-reliability|reliability]]) from V10 (2020)
