# Manim

**Manim** ([[concepts/mathematical-animation|Mathematical Animation]] [[concepts/engine|Engine]]) is a [[concepts/python|Python]] library for creating precise, programmatic animations, particularly for mathematical and scientific visualizations. It is widely used in the creation of educational content, such as the videos produced by 3Blue1Brown.

## Key Characteristics
- **Programmatic Control**: Animations are defined via code rather than keyframes, allowing for reproducibility and dynamic data-driven visuals.
- **Mathematical [[concepts/accuracy|Precision]]**: Built-in support for coordinate systems, graphs, and geometric transformations.
- **Community Ecosystem**: Extensive community contributions and [[concepts/templates|templates]] for common animation patterns.
