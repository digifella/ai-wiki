# Single Project Folder Workflow

A Single Project Folder [[concepts/workflow|Workflow]] is a content [[concepts/organization|organization]] system that uses [[concepts/anthropic-ai|Claude AI]] as a collaborative tool within a folder-based project [[concepts/structure|structure]]. Rather than distributing content across multiple disconnected tools and platforms, this approach centralizes marketing [[concepts/content-creation|content creation]] and management within a single project directory. The workflow leverages [[concepts/claude-ai|Claude]]'s [[concepts/capabilities|capabilities]] to process, generate, and refine content while maintaining a clear folder [[concepts/hierarchy|hierarchy]] that keeps related assets, drafts, and outputs together.

## Core Structure

The workflow organizes projects by consolidating all relevant [[concepts/files|files]]—source materials, work-in-progress content, final outputs, and reference documents—into one folder. This structure simplifies version [[concepts/power|control]], reduces context-switching between [[concepts/software|applications]], and makes it easier to reference previous work. [[concepts/claude|Claude AI]] integrates into this process as a content assistant, capable of ingesting source documents, summarizing information, generating outlines, and producing finished marketing copy directly within the project context.

## Integration with Skills Framework

This approach complements the "[[concepts/skills|Skills]] is Your NEW Content System" model by organizing content around specific competencies and knowledge areas rather than traditional content categories. The folder structure can reflect skill-based organization, allowing teams to build comprehensive content libraries that demonstrate expertise while maintaining clear connections between related materials and their developmental history.
