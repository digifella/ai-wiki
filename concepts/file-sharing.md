# File Sharing

File sharing is the practice of distributing or providing access to digital files among multiple users, often over a network, enabling collaboration, data exchange, and resource sharing.

**Modern implementations**:
- **AI [[concepts/agent-collaboration|Agent Collaboration]]**: Shared workspaces for [[concepts/agentic-ai|AI agents]] (e.g., [[entities/claude-code]]-built teams) that allow agents to share context, files, and workspace for collaborative [[concepts/workflow-automation|task execution]], moving beyond basic [[concepts/ai-bots|chatbots]].
- **Autonomous Teams**: [[concepts/ai-system|Autonomous AI]] work teams (see: [[concepts/claude-code|Claude Code]] and [[concepts/ai-work-team|agent team]] - [[entities/grace-leung|Grace Leung]]) where agents coordinate through shared files without manual copy-pasting.

**Covert & [[concepts/secure|Secure]] Distribution**:
- **Steganography**: Techniques for hiding sensitive data within other media, such as using [[concepts/command-line-interface|command-line]] utilities like `Steghide` to embed files within images for [[concepts/data-hiding|covert communication]], bypassing standard detection [[concepts/causes|mechanisms]]. See: [[lab-notes/2026-06-19-Covert-Communication-Hiding-Sensitive-Files-in-Images-Us|Covert Communication: Hiding Sensitive Files in Images Using Steghide]]
