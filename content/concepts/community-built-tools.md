# Community Built Tools

Community Built Tools refers to [[concepts/third-party-applications|third-party applications]], frameworks, and integrations developed by users and organizations around [[entities/anthropic-institute|Anthropic]]'s [[entities/claude-api|Claude API]] and [[concepts/models|models]]. These tools extend [[concepts/claude-ai|Claude]]'s [[concepts/capabilities|capabilities]] into specific workflows and [[concepts/scenarios|use cases]], ranging from [[concepts/code|code]] [[concepts/automation|automation]] to business [[concepts/workflow-enhancements|process optimization]]. The ecosystem demonstrates how [[concepts/claude|Claude]]'s underlying technology can be adapted for diverse [[concepts/software|applications]] beyond the official Claude interface.

## Key Application Areas

The community has developed tools addressing several primary domains. Code [[concepts/automation-tools|automation tools]] leverage Claude's programming capabilities for tasks like refactoring, [[concepts/testing|testing]], and documentation generation. Marketing and business [[concepts/workflow|workflow]] tools integrate Claude for content generation, analysis, and automation of repetitive tasks. [[concepts/execution-orchestration|AI agent orchestration]] frameworks enable developers to build autonomous systems that coordinate multiple Claude instances or combine Claude with other AI services.

## Development and Distribution

Community tools are typically built using [[entities/anthropic|Anthropic]]'s API and available through [[concepts/open-source|open-source]] repositories, marketplaces, or direct [[concepts/distribution|distribution]] channels. Developers building these tools work within Anthropic's API guidelines and [[concepts/pricing-structure|pricing structure]]. The growing ecosystem reflects increasing [[concepts/adoption|adoption]] of Claude for enterprise and specialized applications, with tools ranging from simple scripts to comprehensive platform integrations.
