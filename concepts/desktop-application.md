# Desktop Application

A desktop application is software installed and run locally on a user's computer, as opposed to web-based applications accessed through a browser. Desktop applications can access local files directly, interact with the operating system, and function offline without requiring internet connectivity.

## Claude CoWork

[[concepts/ad-generation|Claude CoWork]] is a desktop application designed to automate workflows by combining local file access with AI capabilities. The application enables users to create and manage [[concepts/ai-projects|AI projects]] that can read, process, and modify files stored on their computer. This [[concepts/cloud-independence|local-first architecture]] allows for direct integration of [[concepts/agentic-ai|AI agents]] into existing file-based workflows and project structures.

## LM Studio Bionic

[[lab-notes/2026-08-01-LM-Studio-Bionic-Desktop-AI-for-Local-LLM-Driven-Workflo|LM Studio Bionic: Desktop AI for Local LLM-Driven Workflows]] is a newly released, free desktop application designed as an intelligent agent for interacting with open [[concepts/demystifying-llms|Large Language Models]] (LLMs) locally on your computer. It serves as a replacement for previous iterations, focusing on local LLM-driven workflows.

## Use Cases

Desktop applications like [[concepts/ai-co-worker|Claude CoWork]] and [[lab-notes/2026-08-01-LM-Studio-Bionic-Desktop-AI-for-Local-LLM-Driven-Workflo|LM Studio Bionic]] are particularly suited for:

- **Privacy-First AI:** Running [[concepts/local-llm|local LLMs]] and AI agents without sending data to external servers.
- **Offline Functionality:** Accessing [[concepts/ai-projects|AI projects]] and tools without internet connectivity.
- **Direct File Access:** Seamlessly integrating with local file systems for [[concepts/ocr|OCR]], [[concepts/document-processing|document processing]], and automation.
- **[[concepts/ai-driven-workflow-automation|Workflow Automation]]:** Combining local file access with AI capabilities to automate complex tasks.
