# Desktop To Mobile LLM Integration

Desktop To Mobile [[concepts/llm-integration|LLM Integration]] is a feature introduced in [[entities/anything-llm|AnythingLLM]] version 1.12 that extends the [[concepts/accessibility|accessibility]] of privately self-[[concepts/server-based-llms|hosted large language models]] to [[concepts/portable-devices|mobile devices]]. This capability allows users to interact with their locally deployed models via smartphones and tablets, maintaining the [[concepts/privacy|privacy]] and control inherent to self-hosted [[concepts/infrastructure|infrastructure]]. By bridging desktop deployments with mobile interfaces, the integration enables continuous access to [[concepts/ai-tools|AI tools]] without relying on external [[concepts/cloud-based-services|cloud-based services]].

The implementation focuses on connecting existing desktop environments with mobile accessibility channels. This architecture ensures that data remains within the user's controlled environment while providing the flexibility to engage with the LLM from various locations. The feature supports standard mobile [[concepts/behavioral-types|interaction patterns]], allowing for seamless communication with the model regardless of the device being used.
