# Relight Layer

**Relight Layer** is an AI-powered feature in [[concepts/photoshop]] Beta designed for non-destructive [[concepts/lighting-manipulation|lighting manipulation]]. It serves as the modern replacement for the legacy "Lighting Effects" tool, which has been removed from the standard suite.

## Key Features
- **AI-Generated Lighting:** Automatically generates new [[concepts/light|light]] sources within an image based on layer content.
- **[[concepts/non-destructive-editing|Non-Destructive Workflow]]:** [[concepts/adjustments|Adjustments]] do not permanently alter the original [[concepts/digital-images|pixel data]].
- **Beta Availability:** Currently accessible only through the [[entities/photoshop-beta]] channel.
