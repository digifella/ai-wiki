# Model Differentiation

The strategic identification of unique functional advantages and architectural boundaries that distinguish one [[concepts/large-language-model|Large Language Model]] (LLM) from another.

## Key Differentiators

- **Ecosystem & Workspace Integration**: The level of native connectivity with existing [[concepts/productivity|productivity]] software suites.
    - Example: [[entities/gemini]] leverages native [[entities/google-workspace]] integration via `@` command triggers to access user data and tools.
- **[[concepts/reasoning|Reasoning]] Capabilities**: The sophistication of a model's [[concepts/advanced-reasoning]] and complex [[concepts/open-source-philosophy|logic]] processing.
- **Feature-Specific Functionality**: The implementation of end-to-end workflows and specialized [[concepts/tool-selection|tool-use]] capabilities within a specific application environment.
