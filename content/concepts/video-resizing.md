# Video resizing

Process of altering a video's dimensions (width/height) to reduce file size or adapt for specific platforms, often involving [[concepts/video-compression]] techniques to maintain quality.

## Key methods

- **Handbrake**: Free, [[concepts/open-source|open-source]] cross-platform tool ([[entities/windows|Windows]]/Mac/Linux) for [[concepts/transcoding|transcoding]], converting, and resizing videos. Originally designed for [[concepts/dvd-ripping|DVD ripping]], now supports multiple codecs. Enables compression to smaller file sizes without quality loss (see Compressing Video guide).
