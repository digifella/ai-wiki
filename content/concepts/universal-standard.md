# Universal Standard

[[entities/lm-studio|LM Studio]] is a local application that enables users to run [[concepts/large-language-model-llm|large language models]] (LLMs) on their own [[concepts/hardware|hardware]] without relying on [[concepts/cloud-computing|cloud services]]. When integrated with the [[concepts/external-tools|Model Context Protocol]] (MCP), it gains the ability to access external tools and information sources, including web browsing capabilities, while maintaining complete local operation.

## Local Web Browsing Setup

The Model Context Protocol provides a standardized interface for connecting LLMs to external resources and services. By configuring MCP within LM Studio, users can enable their [[concepts/offline-ai|local AI]] instance to browse the web and retrieve current information, bridging the gap between locally-[[concepts/running|running]] models and real-time data without sending queries or results to external servers.

## Practical Implementation

Setting up this configuration involves installing LM Studio, selecting an appropriate [[concepts/local-model|local model]], and configuring MCP with web-browsing tools. The process transforms LM Studio into what some refer to as a [[concepts/automated-agent|local AI command center]]—a unified environment where language models can reason about and interact with external information sources while remaining under the user's direct control and operating entirely on [[concepts/local-infrastructure|local infrastructure]].
