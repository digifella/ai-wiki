# Internet layer

The Internet layer (network layer) in the TCP/IP model handles packet routing across heterogeneous networks using logical addressing (IP). Core protocols include IP (Internet Protocol), ICMP (Internet Control Message Protocol), and IGMP (Internet Group Management Protocol).
