# Tool chaining

The practice of connecting multiple tools or services in a sequence to automate [[concepts/complex-workflows|complex workflows]], where the [[concepts/output|output]] of one tool serves as the input for the next. This approach enhances productivity by reducing manual intervention and enabling sophisticated [[concepts/automation|automation]].

## Recent Examples

- **[[entities/google-opal|Google Opal]] (Experimental)**: An experimental tool from [[entities/google-labs|Google Labs]] that allows users to describe, create, and share [[concepts/ai-mini-apps|AI mini-apps]] using natural language, effectively chaining multiple [[concepts/capabilities|AI capabilities]] together.
