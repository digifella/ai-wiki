# Grids

Grids are foundational layout structures used in [[concepts/uiux-design|UI/UX design]] to organize content and establish visual order. A grid divides a digital interface into columns and rows, creating a framework within which designers place elements like text, [[concepts/images|images]], [[concepts/buttons|buttons]], and other components. By constraining placement to a consistent system, grids enable coherence across a design and make it easier for users to scan and navigate interfaces.

## Purpose and Function

Grids serve multiple practical purposes in design work. They establish alignment and rhythm, reducing cognitive load for users by creating predictable patterns. Grids also facilitate responsive design—a grid system can adapt across different screen sizes, ensuring layouts remain functional on mobile devices, tablets, and desktops. Beyond [[concepts/user-experience-design|user experience]], grids streamline the design process itself, allowing designers to work more efficiently and enabling [[concepts/logical-consistency|consistency]] across teams working on design systems.

## Common Grid Types

Designers work with several grid approaches depending on project needs. Column grids divide horizontal space into vertical sections and are widely used for [[concepts/typography|typography]]-heavy layouts. Modular grids overlay rows and columns to create cells for organizing complex content. Baseline grids establish consistent vertical spacing, particularly important for typography and rhythm. Many modern interfaces combine these approaches or use flexible systems like CSS Grid that allow both structured and fluid layouts.
