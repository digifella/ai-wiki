# Generative Editing

Generative Editing refers to the suite of AI-powered capabilities integrated into Adobe Photoshop version 27.6 that enable users to automatically generate, modify, and enhance image content. These features leverage machine learning models to perform complex tasks that traditionally required manual effort or specialized technical skills. The tools are designed to integrate seamlessly into the existing Photoshop workflow, allowing both professional designers and casual users to accomplish edits more efficiently.

A primary component of this update is the expansion of Generative Fill and Generative Expand functionalities. These tools utilize Adobe's Firefly generative AI models to create new pixels that match the lighting, perspective, and texture of the surrounding image. Users can select specific areas of a canvas and use natural language prompts to add, remove, or replace elements, with the system generating plausible results based on the context of the original file.

The implementation focuses on reducing the technical barrier for common editing tasks. By automating processes such as background removal, object insertion, and content-aware scaling, the software aims to streamline the creative process. This integration allows for rapid iteration and experimentation, shifting the user's role from manual pixel manipulation to curating and refining AI-generated outputs within a familiar interface.
