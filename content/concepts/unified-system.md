# Unified System

GPT-5 has been integrated into Microsoft's [[concepts/enterprise-ai|enterprise AI]] ecosystem, becoming available through both [[concepts/document-insights|Microsoft 365 Copilot]] and [[entities/copilot-studio|Copilot Studio]]. This integration represents a [[concepts/consolidation|consolidation]] of Microsoft's [[concepts/capabilities|AI capabilities]] across its productivity and [[concepts/app-creation|application development]] platforms, allowing organizations to access advanced [[concepts/statistical-language-modeling|language model]] functionality through familiar Microsoft tools.

## Integration Scope

The [[concepts/deployment|deployment]] of GPT-5 across Microsoft 365 Copilot and Copilot Studio creates a [[concepts/unified-interface|unified interface]] for both end users and developers. Microsoft 365 Copilot provides access to GPT-5's capabilities within productivity [[concepts/software|applications]], while Copilot Studio enables organizations to build and customize AI-powered applications using the same underlying model. This unified approach simplifies the technical stack for enterprises adopting AI-assisted workflows.

## Practical Implementation

Organizations using Microsoft 365 can leverage GPT-5's improved [[concepts/reasoning|reasoning]] and processing capabilities for tasks within their existing applications. Developers working in Copilot Studio gain access to the same model for building custom solutions, reducing fragmentation between different AI platforms and creating a more coherent development experience.
