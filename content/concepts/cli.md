# CLI

[[concepts/command-line-interaction|Command Line Interface]] (CLI) is a text-based interface for interacting with computer systems, enabling users to execute [[concepts/commands|commands]] via terminal or console. It provides direct, scriptable access to [[concepts/capabilities|system functionality]] without graphical elements.

## Key Characteristics
- **Text-based interaction**: Input commands via keyboard, receive text output.
- **Scriptability**: Easily automate tasks through shell scripts or batch files.
- **Resource efficiency**: Lower [[concepts/memory|memory]]/CPU overhead compared to GUIs.
- **Remote [[concepts/accessibility|accessibility]]**: Works over [[concepts/ssh|SSH]] or terminal emulators.

## Integration with AI Development Tools
- **[[concepts/claude-code|Claude Code]]** (by [[entities/anthropic]]): Terminal-based [[concepts/cli-tool|CLI tool]] acting as a [[concepts/full-stack-developer|full-stack developer]], providing context-aware code suggestions directly in the terminal environment.
- **GitHub [[entities/copilot|Copilot]]** (by GitHub/Microsoft): Offers CLI integration for on-demand code generation and assistance within terminal workflows.

For detailed comparison of [[concepts/ai-coding|AI coding]] assistants with CLI capabilities, see 2026 04 14 [[concepts/ai-assisted-coding|Claude code]] vs [[concepts/auto-completion-suggestions|GitHub copilot]].
