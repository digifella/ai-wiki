# Nico Martin

Nico Martin is a [[concepts/developer|developer]] known for creating a local Chrome [[entities/agent|agent]] that enables [[concepts/browser-automation|browser automation]] without relying on external APIs or associated costs. The agent leverages [[concepts/transformers|Transformers]].js, a JavaScript library for [[concepts/running|running]] [[concepts/artificial-intelligence-models|machine learning models]] in the browser, combined with [[concepts/23b-parameter-models|Gemma 4]], [[concepts/google-search|Google]]'s [[concepts/open-weight|open-weight]] [[concepts/statistical-language-modeling|language model]], to perform automated tasks directly within a user's browser environment.

## Technical Approach

The key [[concepts/innovation|innovation]] in Martin's work is the use of local [[concepts/inference|model inference]] rather than [[concepts/cloud-based-services|cloud-based services]]. By running Gemma 4 locally through Transformers.js, the agent can execute browser automation tasks while maintaining data [[concepts/privacy|privacy]] and eliminating API key requirements or subscription fees. This approach represents an alternative to traditional browser automation frameworks that depend on external services or paid APIs.
