# Digit

Digit is a humanoid robot engineered for mobile manipulation tasks in industrial and logistics environments. The robot combines bipedal locomotion with articulated upper-body systems to perform complex handling operations in spaces designed for human workers. Its design enables navigation through varied warehouse environments while performing precise manipulation tasks, making it suitable for applications including package handling, sorting, and other logistics operations.

## Design and Capabilities

The robot integrates mobility with dexterous manipulation capabilities, featuring a bipedal locomotion system paired with functional arms and hands. This configuration allows Digit to operate in human-centered environments without requiring specialized infrastructure or significant workplace modifications. The robot is designed to handle objects of varying sizes and weights while navigating the types of terrain and obstacles commonly found in warehouse and distribution facilities.

## Applications

Digit addresses labor demands in warehouse automation and logistics sectors where both mobile navigation and precise object handling are required.
