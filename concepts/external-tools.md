# External Tools

The [[concepts/mcps|Model Context Protocol]] (MCP) is a standardized framework that enables [[concepts/agentic-ai|AI agents]] and workflows to connect with and utilize external tools and data sources. By establishing a common interface between [[concepts/ai-models|AI systems]] and external resources, MCP allows agents to access information and perform actions beyond their built-in capabilities. This integration extends the functional scope of AI systems, enabling them to interact with databases, [[concepts/open-standard-protocols|APIs]], file systems, and specialized software.

## Purpose and Function

External tools serve to overcome inherent limitations in [[concepts/reasoning-capabilities|AI model capabilities]]. While [[concepts/ai-models|large language models]] [[entities/excel|excel]] at [[concepts/reasoning|reasoning]] and [[concepts/text-generation|text generation]], they lack direct access to real-time information, the ability to modify systems, or specialized [[concepts/expertise|domain knowledge]] stored outside their [[concepts/custom-dataset|training data]]. By connecting to external tools, agents can bridge this gap.

Key aspects of MCP standardization include:
- **Solving Integration Complexity:** MCP addresses the inherent difficulties of integrating [[concepts/ai-models|AI language models]] with external tools, data, and control [[concepts/causes|mechanisms]] by providing an open standard.
- **Standardized Interaction:** It defines how models interact with external resources, ensuring consistent communication protocols across different systems.
