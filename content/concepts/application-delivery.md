# Application Delivery

2026 04 14 [[concepts/operating-system-deployment|Bootable container concept]] from IBM

## Overview
Application delivery refers to the processes and technologies used to deploy, manage, and maintain [[concepts/software|software]] [[concepts/software|applications]] across various environments.

## Key Concepts
- **[[concepts/containerization|Containerization]]**: Lightweight, portable runtime environments that package software with its dependencies.
- **[[concepts/cicd-pipelines|CI/CD Pipelines]]**: Automated workflows for continuous [[concepts/integration|integration]] and delivery of applications.
- **Infrastructure as [[concepts/code|Code]] (IaC)**: Managing infrastructure through code for [[concepts/logical-consistency|consistency]] and scalability.
