# Gemini Nano Banana 2

[[entities/gemini-app|Gemini]] [[concepts/camera-angle-control|Nano Banana 2]] is a variant of [[concepts/google-search|Google]]'s [[concepts/gemini|Gemini]] model family designed for AI-powered [[concepts/image-editing|image editing]] tasks. It distinguishes itself through support for [[concepts/json-based-prompting|JSON-based prompting]], which enables users to specify detailed editing [[concepts/instructions|instructions]] and [[concepts/parameters|parameters]] in structured format rather than natural language alone.

## JSON-Based Image Editing

The model's core capability centers on accepting JSON-formatted prompts to control image generation and editing operations. This structured approach allows for precise specification of editing parameters, [[concepts/metadata|metadata]] extraction, and reproducible results. The [[concepts/ai-translator-prompt|JSON prompting]] framework provides a more granular level of control compared to conventional [[concepts/text|text]] [[concepts/prompting|prompting]] methods.

## Performance and Use Cases

Gemini Nano Banana 2 is positioned as a rapid image generation and editing [[concepts/solution|solution]] suitable for professional workflows. It addresses [[concepts/scenarios|use cases]] where users require both [[concepts/speed|speed]] and precise control over [[concepts/output|output]] characteristics, making it applicable to iterative [[concepts/design|design]] work, batch image processing, and automated editing pipelines where [[concepts/logical-consistency|consistency]] and parameter control are prioritized.
