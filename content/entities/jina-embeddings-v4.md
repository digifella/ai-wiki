# Jina Embeddings V4

Jina Embeddings V4 is a [[concepts/image-embeddings|universal embedding model]] developed by Jina AI designed to handle multimodal input and support retrieval-augmented generation (RAG) [[concepts/software|applications]]. The model is built to convert various types of data into dense [[concepts/vector-representations|vector representations]] suitable for similarity search and machine [[concepts/learning|learning]] tasks.

## Technical Approach

The model addresses the challenge of creating unified embeddings across different data types and domains. By supporting multimodal inputs, Jina Embeddings V4 aims to reduce the need for separate embedding models for different content types, simplifying [[concepts/deployment|deployment]] in production systems that work with diverse data sources.

## Applications

Primary [[concepts/scenarios|use cases]] include [[concepts/contextualized-language-understanding|RAG systems]] where embeddings are used to retrieve relevant context from large document collections, as well as [[concepts/natural-language-search|semantic search]] and similarity matching tasks. The [[concepts/inclusive-conceptsdesigndesign|universal design]] positions the model as applicable across various industries and data modalities rather than specialized for a single domain.
