# Data Formulator

Microsoft's **[[concepts/backend-application|Data Formulator]]** is an [[concepts/ai-powered-application|AI-powered application]] that creates [[concepts/rich-data-visualizations|rich data visualizations]] using a [[concepts/llm|large language model]] (LLM) as its backend.

## Setup and Installation
- Install via [[entities/python|Python]] PIP: `pip install data_formulator`
- Launch with `data_formulator` or `[[entities/python|python]] -m data_formulator`
- Configure the AI model (required step)
