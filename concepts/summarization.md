# Summarization
Summarization is a process of condensing large amounts of text into concise summaries that capture the essence of the original content. It is widely used in various fields such as literature, journalism, and data analysis to provide quick insights without losing important details.

## Key Concepts
- **Text [[concepts/model-efficiency|Compression]]**: Reducing the volume of text while retaining key information.
- **[[concepts/natural-language-processing|Natural Language Processing (NLP)]]**: Techniques for interpreting human language and generating summaries from it.
- **Extraction vs [[concepts/abstraction|Abstraction]]**:
  - Extraction involves selecting existing sentences from the source document to form a summary.
  - [[concepts/abstraction-layer|Abstraction]] requires rewriting content using new words.

## Applications
- Literature review
- News aggregation
- Report generation
