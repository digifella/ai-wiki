# Image input processing

The [[concepts/numerical-analysis|computational analysis]] and transformation of digital [[concepts/images|images]] to extract features, detect patterns, or prepare data for downstream tasks.

## Key Concepts
- Image acquisition: Capture methods (cameras, sensors)
- Feature extraction: Identifying salient elements (edges, textures)
- [[concepts/photo-enhancement|Image enhancement]]: Improving quality (noise reduction, [[concepts/contrast|contrast]] adjustment)
