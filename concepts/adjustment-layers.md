# Adjustment Layers

Adjustment layers are [[concepts/non-destructive-editing|non-destructive editing]] tools in [[concepts/photoshop|Adobe Photoshop]] that apply color, tonal, and other visual corrections to an image without permanently altering the underlying [[concepts/digital-images|pixel data]]. By stacking adjustment layers above the base image layer, editors can modify brightness, [[concepts/contrast|contrast]], saturation, hue, curves, levels, and other properties while preserving the ability to revisit, modify, or remove these changes at any point in the [[concepts/photography-workflow|editing workflow]].

## Key Benefits

The primary advantage of adjustment layers is their non-destructive nature, which allows for flexible experimentation and revision. Changes can be toggled on or off by hiding the layer, adjusted by double-clicking the layer to reopen its dialog, or removed entirely without loss of image quality. Additionally, adjustment layers can be masked to affect only specific regions of an image, and their [[concepts/opacity|opacity]] can be reduced to blend effects subtly.

## Recent Developments: Light Adjustment Layer

As of [[entities/adobe-photoshop-beta|Photoshop Beta version]] 27.9, [[concepts/adobe|Adobe]] introduced a new "[[concepts/light|Light]]" adjustment layer, expanding the toolkit for non-destructive [[concepts/lighting-control|lighting control]].

*   **Functionality**: The new [[concepts/light-adjustment-layer|Light adjustment layer]] allows for direct manipulation of lighting properties within the layer stack, distinct from traditional color or [[concepts/photo-tonal-adjustments|tonal adjustments]].
*   **Integration**: It functions similarly to existing adjustment layers, supporting [[concepts/layer-masks|masking]], opacity control, and blending modes for precise application.
*   **Workflow Impact**: This feature enhances the ability to simulate complex lighting [[concepts/scenarios|scenarios]] without baking changes into the pixel data, maintaining full editability.
