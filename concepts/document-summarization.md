# Document Summarization

The computational process of condensing a source text into a shorter version while preserving essential semantic meaning, core information, and key themes. This process is a fundamental application of [[concepts/natural-language-processing]] (NLP) and [[concepts/ai-technologies|Artificial Intelligence]] (AI).

## Recent Developments
- [[entities/microsoft-365-copilot]] [[concepts/software-updates|updates]] (as of 2026-04-14):
    - [[entities/microsoft-word]] enhancement: Introduction of adjustable granularity for automatic summaries, allowing users to toggle between different levels of depth:
        - **Brief**: Rapid extraction of key points.
        - **Standard**: A balanced summary of the content.
        - **Detailed**: A comprehensive overview of the document.
