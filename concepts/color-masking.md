# Color Masking

Color masking is a selective editing technique that allows photographers and digital artists to apply adjustments to specific areas of an image based on color information. Rather than modifying an entire photograph uniformly, this method isolates regions according to color ranges, tonal values, or spatial boundaries. This approach provides precise control over which parts of an image receive particular edits, making it especially useful for targeted adjustments such as sky replacement, skin tone correction, or background enhancement.

The process typically involves defining a selection mask that corresponds to the desired color profile within the image data. Modern implementations often utilize AI-powered tools to automatically detect and refine these boundaries, reducing the manual effort required to create complex selections. These algorithms analyze pixel data to distinguish between similar hues, ensuring that the mask adheres closely to the subject's edges without bleeding into adjacent areas.

In software environments like Adobe Lightroom Classic, color masking is integrated into the local adjustment workflow. Users can select specific color ranges to adjust exposure, saturation, or clarity independently of the rest of the frame. This capability enables nuanced post-processing where global settings remain intact while localized corrections address specific lighting or color balance issues within the composition.
