# Azure Subscription

Logical container for managing Azure resources, billing, and access control. Each subscription is tied to a billing account and enables resource organization through resource groups.

## Key Features
- **Billing**: All resources within a subscription are billed collectively.
- **Resource Groups**: Logical [[concepts/containerization-technology|containers]] for organizing related resources (e.g., VMs, databases).
- **Access Control**: Managed via Azure Active Directory (AAD) and role-based access control (RBAC).
- **Quotas**: Subscription-specific limits on resource counts and types.

## Prerequisites
- Active Azure Subscription required for deploying Azure services (e.g., [[concepts/azure-ai]], Azure [[concepts/foundry|Foundry]]).
