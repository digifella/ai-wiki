# Ubuntu Media Server

Ubuntu Media Server is a self-hosted media server project built on the Ubuntu operating system, designed to operate within a budget constraint of under $100. The project provides users with an alternative to subscription-based streaming services by enabling them to host, store, and manage their own media content on local hardware rather than relying on commercial platforms with recurring fees.

## Purpose and Scope

The project addresses the growing cost of multiple subscription streaming services by allowing users to maintain control over their media library on personal hardware. By leveraging the open-source nature of Ubuntu, the initiative aims to reduce long-term expenses associated with commercial streaming platforms. It focuses on providing a functional, cost-effective infrastructure for individuals who wish to consolidate their digital media collections without ongoing monthly charges.

## Technical Approach

The solution utilizes standard Ubuntu server configurations to ensure stability and compatibility with existing media management software. The under-$100 hardware requirement encourages the use of refurbished or entry-level components, making the project accessible to users with limited financial resources. This approach prioritizes essential functionality and energy efficiency over high-end performance, targeting users who need reliable local storage and streaming capabilities rather than enterprise-grade processing power.
