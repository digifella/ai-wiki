# Terramaster

The [[concepts/m2-storage|TerraMaster F4-425 Plus]] is a network-attached [[entities/storage|storage]] ([[concepts/nas|NAS]]) device designed for small office and home environments. It functions as a centralized storage [[concepts/solution|solution]] that connects to a network, allowing multiple users and devices to access [[concepts/files|files]] simultaneously. The device is part of TerraMaster's broader line of NAS products aimed [[concepts/assistive-technology|at]] providing affordable data storage and management [[concepts/capabilities|capabilities]].

## Hardware Specifications

The F4-425 Plus features a quad-core processor and supports up to 8GB of [[concepts/ram|RAM]]. It accommodates four hard drives or solid-state drives, enabling users to configure storage capacity and redundancy according to their needs. The device includes standard network connectivity and operates using TerraMaster's TOS operating system, which provides the interface for managing storage, backups, and network access.

## Functionality

As an M.2 storage-compatible unit, the F4-425 Plus supports both traditional SATA drives and newer NVMe M.2 storage options, offering flexibility in [[concepts/ambition|drive]] selection. The NAS is capable of handling typical file storage, backup operations, and media serving tasks for small networks. It supports various RAID configurations to protect against data loss through drive redundancy.
