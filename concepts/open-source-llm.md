# Open-Source LLM

[[concepts/large-language-models|Large Language Models]] whose weights and architecture are publicly available for inspection, modification, and redistribution. This ecosystem enables local deployment, fine-tuning, and transparent auditing, reducing reliance on proprietary API providers.
