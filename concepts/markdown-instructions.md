# Markdown Instructions

[[concepts/markdown|Markdown]] is a lightweight markup language used for formatting text. It allows users to write in an easy-to-read, plain-text format and convert it to structured HTML.

## Core Principles
- **Simplicity**: Syntax is designed to be readable and writable without special software.
- **Portability**: Files are plain text, ensuring compatibility across platforms.
- **Extensibility**: Supports extensions for tables, footnotes, and task lists.

## Recent Developments in AI Agent Skills
- **[[concepts/self-evolving-ai-agent-skills-optimization|SkillOpt]] Integration**: [[concepts/2026-04-30-microsoft|Microsoft Research]] has introduced [[lab-notes/2026-06-24-SkillOpt-Microsofts-Text-Based-Evolution-of-AI-Agent-Ski|SkillOpt: Microsoft's Text-Based Evolution of AI Agent Skills]], a strategy for self-evolving [[concepts/agent-harnesses|agent skills]].
- **[[concepts/text-based-training|Text-Based Training]]**: [[entities/skillopt|SkillOpt]] utilizes human-readable [[concepts/markdown-files|Markdown files]] as "[[concepts/skill|skill]] documents" to train [[concepts/agentic-ai|AI agents]], moving away from opaque binary models toward interpretable text-based evolution.
- **[[concepts/local-execution|Local Execution]]**: The framework supports running these evolved [[concepts/skills|skills]] locally, enhancing [[concepts/privacy|privacy]] and control over agent behavior.
