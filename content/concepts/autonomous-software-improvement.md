# Autonomous software improvement

The capability of [[concepts/software|software]] systems to independently iterate upon, optimize, and modify their own source [[concepts/code|code]] and logic to achieve higher performance or functional maturity without direct human intervention.

## Key Mechanisms
- Self-modifying code and Self-evolving systems
- [[concepts/agentic-ai]] executing Automated [[concepts/software-engineering|software engineering]]
- Closed-[[concepts/loop|loop]] cycles involving LLM-based [[concepts/code-generation|code generation]], Automated [[concepts/testing|testing]], and [[concepts/machine-learning]]
