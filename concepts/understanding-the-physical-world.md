# Understanding The Physical World

[[concepts/cause-and-effect|VL-JEPA]] (Vision-Language [[concepts/joint-embedding-predictive-architecture|Joint-Embedding Predictive Architecture]]) is [[entities/meta|Meta]]'s approach to [[concepts/machine-learning|machine learning]] that represents an alternative to mainstream [[concepts/generative-ai-models|generative AI models]]. Rather than training systems to generate outputs token-by-token like [[concepts/large-language-model-llm|large language models]] or diffusion-based image generators, [[concepts/vl-jepa|VL-JEPA]] uses predictive [[concepts/learning|learning]] in a shared embedding space. The architecture learns by predicting missing or masked portions of data, training the model to understand [[concepts/relationships|relationships]] between visual and linguistic information without explicitly generating text or images.

## Architectural Approach

The system operates by [[concepts/encoding|encoding]] both visual and textual inputs into a common representational space, then learning to predict masked or hidden information within that space. This joint-embedding approach contrasts with [[concepts/agentic-ai|Agentic AI]] frameworks, which focus on [[concepts/agentic-performance|autonomous task execution]] and planning.

### Agentic AI Components
Recent definitions by [[entities/ibm|IBM]] outline five key terms essential for understanding [[concepts/agentic-ai|Agentic AI]] architecture, distinguishing it from passive predictive models like VL-[[concepts/jepa|JEPA]]. These components enable agents to plan tasks, write code, and operate with [[concepts/minimal-human-involvement|minimal human involvement]]:

*   **Planning:** The ability of an agent to break down complex goals into executable steps.
*   **[[concepts/memory|Memory]]:** [[concepts/causes|Mechanisms]] for retaining context and past interactions to inform future actions.
*   **Tools:** Integration with [[concepts/third-party-apis|external APIs]], code interpreters, or databases to perform actions beyond native model capabilities.
*   **[[concepts/reasoning|Reasoning]]:** The logical process used to evaluate options and make decisions within the agent's workflow.
*   **Autonomy:** The degree of independence an agent has in executing tasks without continuous human oversight.
